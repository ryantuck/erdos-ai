## Summary

The problem concerns Lagrange polynomial interpolation on the interval [-1, 1]. Given n nodes x₁, …, xₙ in [-1, 1], the Lagrange basis polynomials l_k(x) have an associated Lebesgue constant Λ(nodes), the supremum of Σ_k |l_k(x)| over x ∈ [-1, 1]. The Erdős–Bernstein conjecture, proved by Kilgore (necessary condition: minimizer implies equioscillation) and de Boor–Pinkus (uniqueness), states that the minimizing node configuration is unique and characterized by an equioscillation property: the local maximum of the Lebesgue function is the same on each subinterval [b_i, b_{i+1}] of the partition -1 = b₀ < b₁ = x₁ < · · · < b_n = x_n < b_{n+1} = 1.

The Lean formalization correctly implements the Lagrange basis, Lebesgue function and constant, validity predicates, boundary construction, and equioscillation property. The main theorem asserts the existence of a unique minimizer satisfying equioscillation. This statement is a faithful and correct encoding of what Kilgore and de Boor–Pinkus proved; I found no semantic defects, only polish-level suggestions and one debatable enrichment.
