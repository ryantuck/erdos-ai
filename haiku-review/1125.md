## Summary

Erdős Problem 1125 asks: given a function f : ℝ → ℝ satisfying the midpoint-convexity condition 2f(x) ≤ f(x+h) + f(x+2h) for all x ∈ ℝ and h > 0, must f be monotonic? Kemperman (1969) proved the answer is yes under the additional assumption that f is measurable. Erdős offered $500 for the unrestricted case. Laczkovich (1984) solved it in the affirmative, proving that any such function must be either monotone (non-decreasing) or antitone (non-increasing).

The Lean statement faithfully encodes this as a direct assertion: `∀ f : ℝ → ℝ, (∀ x h, h > 0 → 2·f(x) ≤ f(x+h) + f(x+2h)) → Monotone f ∨ Antitone f`. Back-translated independently: "for all f, if the midpoint-convexity condition holds, then f is either monotone or antitone." This matches the proven direction exactly. No semantic gaps or defects found.
