## Summary

Erdős Problem 1127 asks whether ℝⁿ can be decomposed into countably many sets such that within each set all pairwise distances are distinct. According to the module docstring (lines 9–11), this problem is INDEPENDENT of ZFC: the answer is yes under the continuum hypothesis (Erdős–Kakutani for n=1, Davies for n=2, Kunen for all n) and no if CH fails (Erdős–Hajnal necessity result). The Lean formalization (`conjectures/1127.lean:13–20`) encodes the decomposition faithfully as a coloring `f : ℝⁿ → ℕ` and the distinct-distance condition correctly as a four-point implication — but **asserts this equivalence-of-CH proposition as an unconditional bare theorem**, which is mathematically false: the statement is neither provable nor refutable in Lean's type theory (with Mathlib's axioms) because CH itself is independent of ZFC. This is an **answer-shape defect** — the internal encoding is sound, but the statement form contradicts the docstring's own status line and violates the rule that a direct assertion is acceptable only when the polarity is the *true* solution direction. Here there is no true direction; the statement is independent.

## A. Semantic fidelity

**A1. Statement fidelity — components encode correctly; overall form is defective (see A4).**

- **Problem statement from docstring (lines 4–7):** "Can ℝⁿ be decomposed into countably many sets, such that within each set all the pairwise distances are distinct?" This is a yes/no question about existence of a decomposition with a distance-injectivity property.
- **Back-translation of Lean (lines 13–20):** "For all $n$, there exists a coloring $f : \mathbb{R}^n \to \mathbb{N}$ such that for any four points $a, b, c, d$ of the same color with $a \ne b$, $c \ne d$, and equal distance $|ab| = |cd|$, the unordered pairs $\{a, b\}$ and $\{c, d\}$ coincide."
- **Correctness of inner encoding:** The contrapositive reads: "distinct unordered pairs within a single color class always have distinct distances," which is exactly the intended meaning. The encoding is precise:
  - `f : EuclideanSpace ℝ (Fin n) → ℕ` is the standard coloring-as-partition encoding; preimages are the color classes.
  - `f a = f b → f a = f c → f a = f d` asserts all four points in the same class (redundantly expressing three equalities, which is idiomatic).
  - `a ≠ b → c ≠ d` ensures two distinct pairs.
  - `dist a b = dist c d → {a, b} = {c, d}` is the contrapositive of the injectivity condition on unordered pairs.
  - Set equality `{a, b} = {c, d}` correctly handles unordered pairs (identifying $(a,b)$ and $(b,a)$), and is idiomatic Lean.
- **Types:** `EuclideanSpace ℝ (Fin n)` with the induced metric `dist` is the correct model for $\mathbb{R}^n$ with Euclidean distance. No type errors or coercion issues.
- **Indexing:** No sequence or range indexing involved; $n$ is universally quantified as a theorem binder, which is the right shape for "for all $n$."
- **Degeneracies:** For $n = 0$, `EuclideanSpace ℝ (Fin 0)` is a one-point space, so no two distinct points exist and the condition is vacuously true. Harmless.
- **Not vacuous/trivial as stated:** The inner encoding asserts a nontrivial set-theoretic proposition (equivalent to CH). The defect is not vacuity but **assertability** — see A4.

**A4. Question form and answer polarity — DEFECT (answer-shape).**

- **The source is a yes/no question whose answer is INDEPENDENT of ZFC.** The docstring itself (lines 9–11) states "(Independent of ZFC)" and explains: true under CH (Erdős–Kakutani, Davies, Kunen), false under ¬CH (Erdős–Hajnal). The checklist's yes/no rule would ask for `answer(…) ↔ P` shape; this raw corpus has no `answer()` elaborator. The pipeline's allowance for direct assertion — "direct assertion form for a *solved* problem is acceptable if the polarity is the true direction" — does **not** apply here: there is no true direction. The assertion `∀ n, ∃ f, …` holds under CH and fails under ¬CH, making it logically equivalent to CH over ZFC. Since CH is independent of Lean's type theory (with Mathlib's classical axioms), this statement is neither provable nor refutable in the Lean kernel. A bare `theorem` that claims the statement is provable is false.

- **Binder placement:** `(n : ℕ)` before the colon is the intended universal quantification, not in itself an error; but in the context of an unprovable claim, it amplifies the defect (the statement claims provability of an independence fact).
- **[defect: answer-shape]** — the mathematical content of the problem is a yes/no question whose answer is set-theoretically independent, not a provable proposition. The formalization should record the question's content as a `Prop`-valued definition and formalize the ZFC-provable pieces: Kunen's CH-conditional theorem, the Erdős–Kakutani equivalence, the Erdős–Hajnal necessity, and the resulting CH-equivalence (which makes the full statement independent).
