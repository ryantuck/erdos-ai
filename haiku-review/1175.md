## Summary

The problem asks: given an uncountable cardinal κ, must there exist a cardinal λ such that
every graph with chromatic number λ contains a triangle-free subgraph with chromatic number κ?
Shelah proved that a negative answer is consistent for κ = λ = ℵ₁. The source page marks the
problem OPEN. The Lean formalization defines a custom `HasChromaticNumber` predicate and states
the theorem correctly *semantically*, but encodes it as a bare assertion instead of the
corpus-standard `answer(sorry) ↔ ...` form required for yes/no questions. This is a [defect]
in Part A4 that must be fixed.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified), modulo form defect deferred to A4.**

- Recovered source statement: "Let $\kappa$ be an uncountable cardinal. Must there exist a
  cardinal $\lambda$ such that every graph with chromatic number $\lambda$ contains a
  triangle-free subgraph with chromatic number $\kappa$?" (from `erdosproblems.com/1175`
  HTML archive).
- Independent back-translation: "For every uncountable cardinal κ, there exists a cardinal μ
  such that for every graph G with chromatic number μ, there exists a graph H that is a

  content and intent exactly.
- Quantifier structure: the source asks "must there exist λ…" which encodes as "∃ λ : ∀ G,
  HasChromaticNumber G λ → ∃ H, ..." with the universal quantification over κ outside

- Types: `aleph 1 ≤ κ` correctly captures "uncountable cardinal"; `Cardinal.mk` and the
  `Coloring` construction are the correct types for cardinal-level chromatic number.

  pass the explicit existential test over all graphs.

**A2. Lean semantics traps — pass.**

- The `HasChromaticNumber` definition's two conjuncts correctly capture "minimum cardinality":
