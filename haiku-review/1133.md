## Summary

Erdős problem 1133 is an open conjecture in approximation theory: for any positive constant C,
there exist a small ε > 0 and a threshold N such that for all sufficiently large n, one can
choose points y₁, ..., yₙ ∈ [-1,1] with the property that any polynomial of low degree
(< (1+ε)n) agreeing with the yᵢ at enough of the x-coordinates must have large supremum norm
(> C) over [-1,1]. The Lean formalization translates this directly: ∀ C > 0, ∃ ε > 0, ∃ N,
∀ n ≥ N, ∀ x ∈ [-1,1]ⁿ, ∃ y ∈ [-1,1]ⁿ such that ∀ P with natDegree < (1+ε)·n and agreeing
at ≥(1-ε)·n indices, ∃ t ∈ [-1,1] with |P(t)| > C. The statement is a faithful, correct
encoding of the source problem with no mathematical defects.
