## Summary

The page defines two properties of $A\subseteq\mathbb N$:

- **P:** for every $n\ge1$, only finitely many $a\in A$ have $n+a$ squarefree;
- **Q:** infinitely many $n$ have $n+a$ squarefree for all $a\in A$ with $a<n$.

It then asks "how fast must" sequences with P or Q increase. The page status is SOLVED
(LEAN): van Doorn and Tao [vDTa25] showed that P forces density $0$ but the density can
tend to $0$ arbitrarily slowly, and that Q forces upper density $\le6/\pi^2$, which some
set with Q attains as a natural density. The Lean file encodes these four results as
direct assertions.

Parts 1, 3 and 4 are faithful. Part 2 asks, for every $f\to\infty$, for a sequence with
property P satisfying $a(j)\le f(j)\,j$ **for all $j$**. That fails already at $j=1$ for
$f(j)=\log(j+1)$ and for any $f$ with $f(1)<1$. The intended statement is eventual, and
v2 uses `∀ᶠ j in atTop`. The references are missing entirely. Several page-confirmed
[vDTa25] results about the related properties P′ and P′_∞ are added as variants.

- Recovered source (verbatim; see the Addendum): "We say that $A\subseteq\mathbb N$ has
  property $P$ if, for all $n\geq1$, there are only finitely many $a\in A$ such that $n+a$

- `HasPropertyP` (line 31) is P verbatim, including $n\ge1$. `HasPropertyQ` (line 35)
  reads the page's "for all $a<n$" as "for all $a\in A$ with $a<n$". That is the only
  sensible reading, since otherwise Q would not depend on $A$. The module docstring
  already says so, and v2 records the reading explicitly.
- **Part 1** (`density_zero_of_P`) back-translates to: "if $a$ is strictly increasing
  and its range has P, then $a(j)/j\to\infty$." For an infinite increasing enumeration,
  density $0$ is equivalent to $a_j/j\to\infty$.
  - ($\Rightarrow$) At $x=a_j$ the count is $j+1$, so $(j+1)/a_j\to0$.
  - ($\Leftarrow$) For $a_j\le x<a_{j+1}$ the count over $x$ is at most $(j+1)/a_j\to0$.

  Finite sets have density $0$ trivially and are not the subject of the page's
  sequences. Correct.
- **Part 2** (`exists_sequence_with_P`) back-translates to: "for every $f\to\infty$
  there is a strictly increasing $a$ whose range has P and with $a(j)\le f(j)\,j$ **for
  every** $j$." **[defect: false-at-small-parameters]** The statement is false.
  - Take $f(j)=\log(j+1)$, the canonical slowly growing function. At $j=1$ it demands
    $a(1)\le\log2<1$, so $a(1)=0$, which is impossible because $a(0)<a(1)$ in ℕ.
  - More generally, any $f$ with $f(1)<1$ is a counterexample, and so is any $f$ that is
    negative somewhere, e.g. $f(j)=j-2$.
  - The page's claim, "can have density going to 0 arbitrarily slowly", is an asymptotic
    statement. Its correct rendering is `∀ᶠ j in atTop, a j ≤ f j * j`.
  - This review checked that the eventual form follows from, and implies up to
    reparametrisation of $f$, the other common phrasing "for every $\varepsilon(x)\to0$
    there is $A$ with P and $|A\cap[1,x]|\ge\varepsilon(x)x$ for large $x$". The
    reparametrisation uses $\varepsilon(x)=4/g(\sqrt x)$ with $g$ a monotone minorant of
    $f$, capped at $x^{1/4}$. So the fix is faithful whichever form [vDTa25] actually
    proves.
  - It is not trivial. By Part 1, $a(j)/j\to\infty$ is forced, so the content is that
    the divergence can be as slow as any given $f$.
- **Part 3** (`upper_density_Q`) is "Q implies upper density $\le6/\pi^2$", verbatim.
  As a plausibility check, this review re-derived the mechanism. For each $x$, a Q-witness
  $n>x$ puts $A\cap[0,x)$ inside $\{a<x:\ a\not\equiv-n\ (\mathrm{mod}\ p^2)\ \forall p\le z\}$,
  which has size $\le(\prod_{p\le z}(1-p^{-2})+o(1))x$ uniformly in $n$. So the bound
  holds at *every* scale, not just at the witnesses.
- **Part 4** (`exists_Q_with_max_density`) is "some infinite $A$ with Q has natural
  density $6/\pi^2$". `Set.Infinite A` is implied by the positive density; it is
  redundant but harmless.
