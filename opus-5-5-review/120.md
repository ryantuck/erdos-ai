## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $A\subseteq\mathbb{R}$ be an infinite set. Must there be a set
  $E\subset \mathbb{R}$ of positive measure which does not contain any set of the shape $aA+b$
  for some $a,b\in\mathbb{R}$ and $a\neq 0$?"
- **Back-translation:** "for every infinite $A\subseteq\mathbb R$ there is a Borel set $E$
  with $\lambda(E)>0$ such that no $aA+b$ with $a\ne0$ is contained in $E$." That is the
  "yes" answer.
- **Borel versus Lebesgue measurability.** A Lebesgue-measurable $E$ of positive measure
  contains a compact $F$ of positive measure. Any affine copy in $F$ lies in $E$, so if $E$
  avoids all copies, so does $F$. Requiring a Borel `MeasurableSet` therefore loses nothing.
- **Measurability is necessary.** It is required, and that is right: the problem is about
  measurable sets.
- **Infinite measure.** `volume E ≠ 0` allows $\lambda(E)=\infty$. That is harmless:
  intersect with a bounded interval of positive measure.

  $b$.

- **The `dense_in_interval` argument.** If $aA+b\subseteq E$ with $E$ closed, then
  $a\overline A+b\subseteq E$, which contains an open interval. That is impossible for a
  nowhere dense $E$.
- **The `reduction` argument.**
  - Unbounded $A$ are covered by `unbounded`.
  - An infinite bounded $A$ contains a strictly monotone sequence converging to some point
    $p$. Translating by $-p$, and reflecting if the sequence increases, gives a decreasing
    null sequence $x$, and $A$ contains an affine image of $\mathrm{range}\,x$.
  - Any copy of $A$ inside $E$ contains a copy of $\mathrm{range}\,x$. So avoiding the
    latter avoids the former.
- **Not formalized:** the "many special cases" covered by the surveys. They are not
  itemized on the page.
