## Summary

The page (OPEN, a problem of Erdős and Purdy) defines $h_c(n)$ as the guaranteed size of a
largest line, among $n$-point sets with $\ge cn^2$ lines containing more than three points.
It asks whether $h_c(n)\to\infty$ for fixed $c$. The Lean asserts that for all $c>0$ and
$M$ there is $N$ such that for $n\ge N$ every such set has a line with $\ge M$ points. That
is the same proposition. v2 keeps it byte-identical and adds context and variants.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **The encoding.** $h_c(n)=\min_{P\text{ admissible}}\max_L|P\cap L|$, so
  $h_c(n)\to\infty$ $\iff$ $\forall M\,\exists N\,\forall n\ge N\,\forall$ admissible $P$
  with $|P|=n$: some line has $\ge M$ points. That is exactly the theorem.
- **"More than three points"** is $\ge4$, encoded as `4 ≤ ncard`, which is correct.
- **Vacuity for large $c$, same in source and Lean.**
  - Each pair of points lies on exactly one line, and a 4-rich line carries $\ge6$ pairs.
    So there are at most $\binom n2/6<n^2/12$ such lines.
  - For $c\ge1/12$ no set is admissible, and both the source's $h_c$ and the Lean
    statement are vacuous.
  - For small $c$, admissible sets exist for all large $n$ (grids). So the question has
    content, and the Lean is not trivially true.

**A2. Lean semantics traps: pass.**

- Lines are finrank-1 affine subspaces. The line set is finite (at most $\binom n2$), so
  `ncard` is genuine. This is the same analysis as #101.
- The existential line in the conclusion also requires finrank 1. Without that, the whole
  plane would trivially "contain $M$ points" for $M\le n$, so the guard is load-bearing,
  and it is present.

**A3. Definitions: pass.** `fourPlusRichLineCount` matches its docstring. It is the same
definition as #101's `fourRichLineCount`. No `sorry` in definitions.

  - Construction: a near-square $k\times\lceil n/k\rceil$ grid, $k=\lfloor\sqrt n\rfloor$,

    four-rich lines remain.

- `variants.not_sqrt_lower` (PROVED): the negation of "$\forall c\ \exists C>0$, eventually

    $\|v\|_\infty\approx m/k$ number $\approx n/k^3$, and each carries $\approx n/k$ lines
    with about $k$ points. That gives $\gg n^2/k^4$ lines with $\ge k$ points, which is
    $\gg n^2$ for fixed $k$.
  - Only infinitely many $n$ are needed, which is weaker and safer than upstream's
    `∀ᶠ n` form of Hunter's bound.

## E. Prior-review audit (`deepmind/ai-review/102.md`)

The prior review's correctness analysis is right: quantifier structure, finiteness, and
"more than 3" as $\ge4$. Errors:

1. **Misstated status of the upper bound.** It lists "Known upper bound: $h_c(n)\ll_c
   n^{1/2}$ is established" as a variant, and elsewhere implies that Erdős's original
   conjecture was this upper bound. The page says Erdős *suggested the lower bound*
   $h_c(n)\gg_cn^{1/2}$, which Hunter refuted. The upper bound is the "easy" direction. The
   review's own variant list conflates the two.
2. **Garbled #101 connection.** It writes "whether Problem 101 implies at least 5 collinear
   points". The precise relation is equivalence: $h_c(n)\ge5$ eventually, for all $c$, is
   #101.

   finiteness instance", the hypothesis $cn^2\le0$ would be false, making the theorem
   vacuously true.
   - `Set.ncard` does not depend on "instances". The line set is finite, so `ncard` is its
     size.
   - The hypothesis being false would make the implication true, which is not a vacuity
     risk the review should flag.
   - The real vacuity regime, $c\ge1/12$, which applies equally to the source, is not
     mentioned.
