## Summary

The page (PROVED) defines $F_k(N,\ell)$, the least number of $k$-term progressions that forces an $\ell$-term progression in an
$N$-set, and asks whether $F_3(N,4)=o(N^2)$ and whether $\log F_3(N,\ell)/\log N\to2$ for $\ell>3$. Fox and Pohoata [FoPo20]
proved $F_k(N,\ell)=N^{2-o(1)}$ with explicit bounds; [LSS24] improves them.

The Lean defines `ContainsAP` and `numAP` (counting pairs $(a,d)$, $d\ge1$) and states the two answers.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $1\leq k<\ell$ be integers and define $F_k(N,\ell)$ to be minimal such that every set $A\subset
  \mathbb{N}$ of size $N$ which contains at least $F_k(N,\ell)$ many $k$-term arithmetic progressions must contain an $\ell$-term
  arithmetic progression. Find good upper bounds for $F_k(N,\ell)$. Is it true that\[F_3(N,4)=o(N^2)?\]Is it true that for every

- **Back-translation, part 1** (lines 37–41): "For every $\varepsilon>0$, for large $N$, every $N$-set with at least $\varepsilon

- **Back-translation, part 2** (lines 53–58): "For every $\ell>3$ and $0<\varepsilon<2$, for large $N$, some $N$-set has at least
  $N^{2-\varepsilon}$ three-term progressions and no $\ell$-term progression", i.e. $F_3(N,\ell)>N^{2-\varepsilon}$.
- **Checks.**
  - *The limit.* $\log F_3/\log N\to2$ needs $F_3\ge N^{2-o(1)}$ (part 2) and $F_3\le N^{2+o(1)}$. The second is trivial: with at
    most $N^2$ progressions in an $N$-set, the threshold never needs to exceed $N^2+1$ (`numAP_le_sq`).
  - *`numAP`.* Pairs $(a,d)$ with $a\le\max A$, $1\le d\le\max A$ and all $k$ terms in $A$. For $k\ge2$ the bounds on $a,d$ lose
    nothing, so this is the number of $k$-term progressions (examples: $\{0,1,2,3\}$ has 2, $\{0,2,4\}$ has 1, $\{0,1,3\}$ has 0).
    For $k=1$ it is $|A|\cdot\max A$ (`numAP_one_example`); only $k=3$ is used.
  - *`ContainsAP`* requires $d\ge1$; `A ⊆ ℕ` with $0$ allowed is harmless (translation).
