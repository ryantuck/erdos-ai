## Summary

For unimodular $z_1,z_2,\dots$ and $M_n=\max_{|z|=1}\prod_{i\le n}|z-z_i|$, the page asks
three questions:

- (i) Is $\limsup M_n=\infty$? Wagner [Wa80] proved it.
- (ii) Is $M_n>n^c$ infinitely often? Beck [Be91] answered it.
- (iii) Is $\sum_{k\le n}M_k>n^{1+c}$ for large $n$? This was OPEN at capture, with \$100
  on it. The mirror now records `solved`.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $z_i$ be an infinite sequence of complex numbers such that
  $\lvert z_i\rvert=1$ for all $i\geq 1$, and for $n\geq 1$ let
  $p_n(z)=\prod_{i\leq n} (z-z_i)$. Let $M_n=\max_{\lvert z\rvert=1}\lvert p_n(z)\rvert$. Is it
  true that $\limsup M_n=\infty$? Is it true that there exists $c>0$ such that for infinitely
  many $n$ we have $M_n > n^c$? Is it true that there exists $c>0$ such that, for all large
  $n$, $\sum_{k\leq n}M_k > n^{1+c}$?"
- **Indexing.**
  - `prodPoly z_seq n = ∏ i ∈ range n` uses `z_seq 0, …, z_seq (n-1)`. With
    `z_seq i` $=z_{i+1}$ this is the page's $p_n$, and `maxModulus z_seq k` is the page's
    $M_k$ for $k\ge1$.
  - In (iii) the sum runs over `range (n + 1)`, so it adds $M_0=1$ (empty product). That
    shifts the sum by $1$, which does not affect "for all large $n$" with some $c>0$: shrink
    $c$ if needed.
- **(i)** `∀ B, ∃ n, M_n > B` is unboundedness. For a real sequence, that is equivalent to
  $\limsup M_n=\infty$: any finite set of indices has a finite maximum.
- **(ii) is in Beck's form:** $\exists c>0$, for all sequences and all $N\ge1$, some $n\le N$
  has $M_n>N^c$.
  - **It implies the question as asked.** Such an $n$ satisfies $M_n>N^c\ge n^c$. As
    $N\to\infty$ infinitely many distinct $n$ occur, since each fixed $M_n$ is finite.
  - **It holds for all $N\ge1$, not only large $N$.** Since $\max_{n\le N}M_n\ge M_1=2$,
    small $N$ are covered by taking $c$ small.
  - v2 adds the literal question as `part_ii_as_asked`.
- **Uniform versus per-sequence $c$.**
  - The input puts $\exists c$ before $\forall z$ in (ii) and (iii). On the page, $c$ is
    introduced after the sequence is fixed, so the literal reading lets $c$ depend on it.
    That is upstream's reading.
  - In Erdős's usage $c$ is normally an absolute constant, and Beck's $c$ is uniform. So
    the uniform reading is defensible, and it is the stronger of the two.
  - v2 keeps the uniform statements and adds the per-sequence ones as implied variants.
  - The input's uniform (iii) is true if the 2026 resolution's constant is absolute
    (DEFERRED).
