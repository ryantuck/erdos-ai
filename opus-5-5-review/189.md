## Summary

The page (DISPROVED (LEAN)) asks whether every finite colouring of $\mathbb R^2$ has a colour class containing the vertices of a
rectangle of every area. Graham proved the analogue for right triangles [Gr80]; Kovač [Ko23] gave a 25-colouring with no
monochromatic rectangle of area $1$; the parallelogram version is open.

The Lean defines rectangles ($C=B+D-A$, $AB\perp AD$, $A\ne B$, $A\ne D$) and their area $|AB\times AD|$, and asserts the "yes"
answer for every $k$ and every $f:\mathbb R^2\to\mathrm{Fin}\,k$.

## A. Semantic fidelity

**A1. Statement fidelity: DEFECT (fixed).**

- **Source** (verbatim): "If $\mathbb{R}^2$ is finitely coloured then must there exist some colour class which contains the
  vertices of a rectangle of every area?"; remarks: "This is false; Kovač [Ko23] provides an explicit (and elegantly simple)
  colouring using 25 colours such that no colour class contains the vertices of a rectangle of area $1$."
- **Back-translation** (lines 37–43): "For every finite colouring some colour class contains, for every $t>0$, the vertices of a

- **The refutation in Lean.**
  - *Identity.* With $u=B-A$, $w=D-A$ and $C=A+u+w$, the alternating sums $\Delta_1,\Delta_2$ of $x^2-y^2$ and $2xy$ over
    $A,B,C,D$ are $2(u_1w_1-u_2w_2)$ and $2(u_1w_2+u_2w_1)$, and
    $\Delta_1^2+\Delta_2^2=4\bigl((u\times w)^2+(u\cdot w)^2\bigr)=4\,\mathrm{area}^2$ since $u\cdot w=0$.
  - *One colour.* If the four floors $\lfloor q_j/s\rfloor$ agree modulo $5$, then $\Delta_j=s(5m_j+\rho_j)$ with $m_j\in\mathbb Z$
    and $|\rho_j|<2$ (`alt_sum`).
  - *Area $1$ is impossible.* If $m_1=m_2=0$, $\Delta_1^2+\Delta_2^2<8s^2=3.92<4$; otherwise some $(5m_j+\rho_j)^2>9$
    (`nine_lt_sq`), so $\Delta_j^2>9s^2=4.41>4$ (`no_monochromatic_unit_rectangle`).
  - *Conclusion.* With $k=25$ and this colouring, every colour class misses area $1$, which refutes the input
    (`erdos_problem_189`).
