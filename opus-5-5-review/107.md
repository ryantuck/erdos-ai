## Summary

The page states the Happy Ending problem (FALSIFIABLE, \$500 for a proof, \$100 for a
disproof). Let $f(n)$ be the least $N$ such that every $N$ points in the plane with no three
collinear contain a convex $n$-gon; prove $f(n)=2^{n-2}+1$. For each $n\ge3$ the Lean

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Equivalence with $f(n)=2^{n-2}+1$.** Write $\mathcal C(N)$ for "every $N$-point
  general-position set has a convex $n$-subset".
  - Supersets of a set with a convex $n$-subset still have one. So the first conjunct
    ("$\ge2^{n-2}+1$") is equivalent to $\mathcal C(2^{n-2}+1)$.
  - Subsets of a general-position set are in general position, and a convex $n$-subset of
    a subset is one of the whole set. So a $2^{n-2}$-point counterexample yields
    counterexamples for every $N\le2^{n-2}$, and $f(n)>2^{n-2}$.
  - Together: $f(n)=2^{n-2}+1$, matching upstream's `f n = 2^(n-2)+1` with
    `f := sInf cardSet`.
- **Convex $n$-gon.** For a general-position $T$, $|T|=n$ with every point an extreme
  point of $\mathrm{conv}(T)$ means exactly that $T$ is the vertex set of a convex $n$-gon.
- **$n\ge3$.** $f(3)=3$, and the formula is meant for $n\ge3$. The theorem binds `n` and
  `hn` before the colon, which is fine for a direct assertion.
- **Not vacuous.** The second conjunct is the proved Erdős–Szekeres construction. The first
  is the open content.

**A2. Lean semantics traps: pass.**

- `2 ^ (n - 2)`: ℕ subtraction is exact since $n\ge3$.

  order-theoretic. So using `Fin 2 → ℝ` in place of `EuclideanSpace` is harmless.
- `extremePoints ℝ` of the hull agrees with "not in the hull of the others" for finite
  sets.
