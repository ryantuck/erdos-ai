## Summary

The page defines $f(n)$ as the largest $k$ such that some $n$-point $A\subset\mathbb R^2$
has, for **every** $x\in A$, at least $k$ points of $A$ on one circle centred at $x$. It
asks whether $f(n)\le n^{o(1)}$ (the \$500 question), "or even"
$f(n)<n^{O(1/\log\log n)}$. At capture time (2026-03-05) the status was OPEN.

The Lean theorem instead asserts that there is $C>0$ such that for every finite $A$ with
$|A|\ge2$ and **every** $x\in A$, `maxEquidistantCount A x` $\le|A|^{C/\log\log|A|}$. That
is not $f(n)$, and it is false for trivial reasons. The docstring's own paraphrase ("if
every point of $A$ has at least $k$ … then $k\le$ …") is the right reading; the code does
not implement it.

Since then, both questions have been disproved. v2 introduces the max–min $f$
(`equidistantF`), states the negation of the \$500 question as the main theorem and the
negation of the stronger question as a variant, and adds page-stated bounds.

## A. Semantic fidelity

**A1. Statement fidelity: DEFECT (fixed).**

- **Source** (verbatim): "Let $f(n)$ be maximal such that there exists a set $A$ of $n$
  points in $\mathbb{R}^2$ in which every $x\in A$ has at least $f(n)$ points in $A$
  equidistant from $x$. Is it true that $f(n)\leq n^{o(1)}$? Or even
  $f(n) < n^{O(1/\log\log n)}$?"
- **Back-translation of `erdos_problem_92`:** "There is $C>0$ such that for every finite
  $A\subset\mathbb R^2$ with $|A|\ge2$ and every $x\in A$, the largest number of points of
  $A\setminus\{x\}$ on a common circle about $x$ is at most $|A|^{C/\log\log|A|}$."
- **[defect: wrong-quantifier-structure]** The source quantity is
  $f(n)=\max_{|A|=n}\min_{x\in A}\mathrm{maxEq}(A,x)$. The Lean bounds
  $\max_{|A|=n}\max_{x\in A}\mathrm{maxEq}(A,x)$ instead.
  - For a point $x$ together with $n-1$ points on a circle about $x$, the count at $x$ is
    $n-1$, while $n^{C/\log\log n}=e^{C\log n/\log\log n}=n^{o(1)}$. So for every $C$ the
    statement fails at all large $n$. With $C=1$, $n=100$: $100^{1/\log\log100}\approx20.4<99$.
  - So the input is false independently of the mathematics of the problem, and would stay
    false even if Erdős's conjecture had been true.
- **[defect: false-at-small-parameters]** At $|A|=2$, $\log(\log2)\approx-0.367<0$, so the
  exponent $C/\log\log2$ is negative and the bound is $2^{\text{negative}}<1$. The count at
  either point is $1$. False for every $C>0$, without any construction.
- **[defect: missing-part]** The input formalizes only the "or even"
  ($n^{O(1/\log\log n)}$) question. The primary question, $f(n)\le n^{o(1)}$, is the one
  carrying the \$500 prize. The input docstring mentions it but does not state it.
- **v2:**
  - Defines `HasEquidistantProperty k A` ($\forall x\in A,\ k\le$ `maxEquidistantCount A x`)
    and `equidistantF n = sSup {k | ∃ A, A.card = n ∧ HasEquidistantProperty k A}`.
  - For $n\ge1$ the set contains $0$ and is bounded by $n-1$, because
    `maxEquidistantCount A x ≤ |A.erase x|` for $x\in A$. So `sSup` is the true maximum,
    i.e. exactly the page's $f(n)$.
  - At $n=0$ it is Mathlib's junk value $0$, which is documented and irrelevant
    asymptotically.

**A2. Lean semantics traps: one defect (above); otherwise pass.**

- **`Real.log (Real.log n)`** is negative for $n=2$ and $0$ for $n\in\{0,1\}$
  (`Real.log 0 = 0`). With a division, that makes the input's bound junk at $|A|=2$. v2
  uses only `∀ᶠ n in atTop`, so small $n$ never enter.
- **`(n : ℝ) ^ o n`** is `Real.rpow`. Eventually $n\ge2$, so the base is positive and
  rpow is the genuine power.
- **`maxEquidistantCount`** is correct:
  - `A.sup` over $y\in A$ of $\#\{z\in A: z\neq x,\ d(x,z)=d(x,y)\}$;
  - the term $y=x$ contributes $0$;
  - an empty `sup` is $0$.

  It matches its docstring and is kept byte-identical.
- **`sSup` on ℕ** is the genuine maximum for $n\ge1$, as shown above. At $n=0$ the set is
  unbounded and the value is junk ($0$), which is documented.
- **`Tendsto o atTop (𝓝 0)`** is the standard rendering of $o(1)$. With an eventual
  inequality, "$\forall n$" and "$\forall^\infty n$" agree.

**A3. Definitions: pass.** No `sorry` in definitions. `maxEquidistantCount` is correct, as
shown in A2. The new definitions match their docstrings.

**A4. Question form and answer polarity: DEFECT (fixed).**

- The source asks two yes/no questions. The raw-corpus convention is a direct assertion of
  the asked direction while open, and of the *true* direction once solved.
- **[defect: wrong-polarity]** The problem is now disproved (A5). Even with a correct $f$,
  asserting the asked direction would assert a false statement.
- v2 states `¬ ∃ o, o → 0 ∧ ∀ᶠ n, f n ≤ n ^ o n` (main) and
  `¬ ∃ C > 0, ∀ᶠ n, f n < n ^ (C / log log n)` (variant). Each is the negation of the
  question as asked, so a proof settles the question with the answer "no".
