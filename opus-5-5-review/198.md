## Summary

The page (DISPROVED (LEAN)) asks whether the complement of every Sidon set contains an infinite arithmetic progression. The answer
is no: a lacunary set meeting every infinite progression is Sidon; AlphaProof's explicit example is $\{(n+1)!+n:n\ge0\}$.

The Lean defines Sidon sets (equal sums $a+b=c+d$ with $a\le b$, $c\le d$ force $a=c$, $b=d$) and "the complement contains an
infinite progression" ($a+nd\notin A$ for all $n$, some $d>0$), and asserts that not every infinite Sidon set has such a
complement.
