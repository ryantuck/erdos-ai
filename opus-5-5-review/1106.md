## Summary

The problem (OPEN) defines $p(n)$ as the partition function and $F(n)$ as the number of
distinct primes dividing $\prod_{1\le k\le n}p(k)$. It asks whether $F(n)\to\infty$ and
whether $F(n)>n$ for all large $n$. The first question was answered yes by Schinzel, via
Tijdeman, with details in Erdős–Ivić; Schinzel–Wirsing also proved $F(n)\gg\log n$. The
second question is open.

the asked direction respectively. There are no ℕ-arithmetic traps.
