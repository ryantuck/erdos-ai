## Summary

The page asks (OPEN), for every $r\ge4$ and $k\ge2$, whether a finite $f(k,r)$ exists
such that every graph with $\chi\ge f(k,r)$ contains a subgraph of girth $\ge r$ and
$\chi\ge k$. For each such $r$ and $k$ (binders before the colon), the Lean asserts
$\exists f$ such that every finite $G$ with `f ≤ χ(G)` has a `G.Subgraph` $G'$ with
`r ≤ girth G'.coe` and `k ≤ χ G'.coe`. This is the "yes" direction of the question. v2
keeps the theorem byte-identical and adds references and variants.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Subgraph.** `G.Subgraph` is an arbitrary, not necessarily induced, subgraph, which is
  what the Erdős–Hajnal question uses. `G'.coe` is the graph on its vertex subtype.
- **Finite graphs only (`Fintype V`), equivalent to all graphs.**
  - If an infinite $G$ has $\chi(G)\ge f$, then $G$ is not $(f-1)$-colourable. By de
    Bruijn–Erdős, some finite subgraph is not $(f-1)$-colourable.
  - Applying the finite statement to that subgraph yields the required $G'$, which is a
    subgraph of $G$ too.
  - Upstream quantifies over all `V : Type u` with `Nonempty V`. That is equivalent, given
    choice.
- **Girth.** Mathlib's `girth : ℕ∞` is $\top$ for acyclic graphs. So a forest has "girth
  $\ge r$", the standard convention.
- **The trivial case.** At $k=2$ the statement is trivially true: a single edge has
  $\chi=2$ and girth $\top$. That matches the source, which includes $k=2$. The content
  starts at $k\ge3$.
- **Not vacuous.** For $k\ge3$, a qualifying $G'$ must contain an odd cycle of length
  $\ge r$, which is real content.

**A2. Lean semantics traps: pass.**

- **Comparisons.** `f ≤ G.chromaticNumber` compares the cast `(f : ℕ∞)` with an `ℕ∞` value
  ($\top$ only for infinite graphs, so never here), and the girth comparison is likewise in
  `ℕ∞`.
- **No arithmetic.**
- **Instance binders.** The `[DecidableEq V]` and `[DecidableRel G.Adj]` binders are
  unnecessary but harmless. Both classes are subsingletons, so quantifying over them changes
  nothing.

**A3. Definitions: pass.** The input has no definitions. v2's `fMin` is `sInf` of the
