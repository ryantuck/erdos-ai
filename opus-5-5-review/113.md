## Summary

The conjecture: a bipartite $G$ has $\mathrm{ex}(n;G)\ll n^{3/2}$ if and only if $G$ is
2-degenerate. Janzer disproved it: for every $\varepsilon>0$ there is a 3-regular, hence not
2-degenerate, bipartite $H$ with $\mathrm{ex}(n;H)\ll n^{4/3+\varepsilon}$.

## A. Semantic fidelity

**A1. Statement fidelity: pass for the proposition; see A4/A5.**

- **Source** (verbatim): "If $G$ is bipartite then $\mathrm{ex}(n;G)\ll n^{3/2}$ if and only
  $G$ is $2$-degenerate, that is, $G$ contains no induced subgraph with minimal degree at
  least 3."
- **Back-translation of the inner proposition:** "for every finite graph $G$ with a proper
  2-colouring, $G$ is 2-degenerate iff there is $C>0$ with
  $\mathrm{ex}(n;G)\le Cn^{3/2}$ for all $n$."
  - **2-degeneracy:** `IsTwoDegenerateGraph` says every nonempty finite vertex set has a
    vertex with at most 2 neighbours inside it. That is "no (induced) subgraph of minimum
    degree $\ge3$".
  - **Turán number:** `turanNumber` is the maximum edge count of an $n$-vertex graph with no
    injective homomorphic copy of $G$, which is $\mathrm{ex}(n;G)$.
- **Direction of the disproof.**
  - In the Lean `IsTwoDegenerateGraph G ↔ ∃ C …`, Janzer's graph refutes the `←` half: a
    bound $\ll n^{3/2}$ (take $\varepsilon\le1/6$), yet the whole vertex set has minimum
    degree 3.
  - The page's wording calls this the "only if" direction, and the input docstring agrees.

**A2. Lean semantics traps: pass.**

- **$n=0$.** `turanNumber G 0 = 0`:
  - for nonempty $U$ the set is $\{0\}$;
  - for empty $U$ every graph contains $G$, so the set is empty and `sSup ∅ = 0`.

  Also `(0:ℝ) ^ (3/2 : ℝ) = 0`. So "for all $n$" is no stronger than "for large $n$": the
  finitely many small $n$ are absorbed into $C$.
- **`(3 / 2 : ℝ)`** is real division, so the exponent is $1.5$.
- **`ncard`** is genuine, because $S$ is finite.
- **`turanNumber`'s `sSup`** is bounded by $\binom n2$.
- **Edgeless $G$.**
  - When $G$ has no edges and $|U|\le n$, every graph contains $G$, so `turanNumber` is 0.
  - Mathlib's `extremalNumber` uses the same convention.
  - This does not affect the truth value.
- **Universes.** The negation `¬ ∀ (U : Type u) …` holds in every universe. `ULift` of
  Janzer's graph is a counterexample there, since containment, colourings and degeneracy
  are invariant under the equivalence.
