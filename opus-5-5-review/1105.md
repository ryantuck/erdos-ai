## Summary

The problem (PROVED) defines $\mathrm{AR}(n,G)$ as the maximum number of colours on the
edges of $K_n$ with no rainbow copy of $G$. It asks two things.

- Is $\mathrm{AR}(n,C_k)=\left(\frac{k-2}2+\frac1{k-1}\right)n+O(1)$? Montellano-Ballesteros
  and Neumann-Lara proved an exact formula implying it.
- For $n\ge k\ge5$, does $\mathrm{AR}(n,P_k)$ equal the Erdős–Simonovits–Sós formula?
  Yuan announced a proof. Simonovits–Sós proved it for $n\ge ck^2$.

The Lean colours `Sym2 (Fin n)` by `c : Sym2 (Fin n) → ℕ`. It defines a rainbow copy as an
embedding under which the edge-images of $G$ get distinct colours, which is correct. But
it counts the colours as `Set.ncard (Set.range c)`. `Sym2 (Fin n)` has $\binom n2$ edges
plus $n$ loops $s(i,i)$. An embedding never sends an edge of $G$ to a loop. So any
rainbow-free colouring can be extended with $n$ fresh colours on the loops, and no
colouring gains more than $n$ that way.

Hence `antiRamseyNumber G n` $=\mathrm{AR}(n,G)+n$ exactly. The cycle theorem then
asserts that $n+O(1)$ is bounded, and the path theorem asserts $\mathrm{AR}+n=\mathrm{AR}$.
Both are false. Everything else is right: the rainbow-copy predicate, the cycle and path
graphs, the real-valued $O(1)$ encoding, and the path formula's ℕ arithmetic.

  and $G$ is loopless, every image $s(\varphi u,\varphi v)$ is a genuine edge of $K_n$.
  Copies in $K_n$ need not be induced, and injective images are exactly the copies.
- **`antiRamseyNumber`: DEFECT.** It counts `Set.range c` over all of `Sym2 (Fin n)`.
  **[defect: wrong-definition-counts-non-edges]**
  - *Upper bound.* The colours used on edges number at most $\mathrm{AR}(n,G)$ for a
    rainbow-free $c$, and the loops add at most $n$.
  - *Lower bound.* Take an optimal rainbow-free edge colouring and give the $n$ loops
    $n$ fresh colours. Rainbow-ness depends only on edge colours, so the result is still
    rainbow-free, and it has $\mathrm{AR}(n,G)+n$ colours.
  - So the Lean value is exactly $\mathrm{AR}(n,G)+n$. The `sSup` is a genuine maximum,
    since the set is bounded by $|\mathrm{Sym2}(\mathrm{Fin}\,n)|$ and is nonempty because
    the monochromatic colouring is rainbow-free when $|E(G)|\ge2$.
  - **Exhaustive check:** over all 115 975 colourings of the 10 elements of
    `Sym2 (Fin 4)`, the Lean definition gives `antiRamseyNumber C₃ 4 = 7`, while
    $\mathrm{AR}(4,C_3)=3$ (edges only; the ESS value is $n-1$).
- **Consequences.**
  - The *cycle theorem* requires
    $|\mathrm{AR}(n,C_k)+n-\alpha_kn|\le C$, i.e. $|n+O(1)|\le C$ for all $n\ge k$. That is
    false for every $k$.
  - The *path theorem* requires $\mathrm{AR}(n,P_k)+n=\mathrm{AR}(n,P_k)$. That is false
    for every $n\ge k\ge5$; e.g. $k=n=5$ gives $10\ne5$.
  - Both theorems are false, not merely off by a constant.
- **Fix.** Count `c '' (⊤ : SimpleGraph (Fin n)).edgeSet`, the colours on $K_n$'s edges.
  This is exactly the source's $\mathrm{AR}$. The loop values of `c` become irrelevant, as
  they should be. Both theorem statements are unchanged and become the proved statements.

  respectively, so the degenerate $k\le2$ cases never arise.
- **Quantifiers.** The cycle part reads $\forall k\ge3\ \exists C\ \forall n\ge k$, which
  is $O(1)$ with a $k$-dependent constant. Requiring the bound for every $n\ge k$ rather
  than eventually is equivalent, since finitely many $n$ can be absorbed into $C$. The
