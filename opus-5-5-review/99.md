## Summary

The page asks (OPEN, \$100 for a counterexample, \$50 for a proof) whether, for large $n$,
every diameter-minimising $n$-point set with minimum distance 1 contains a unit equilateral
triangle. The Lean asserts the "yes" direction: there is $N_0$ such that every $A$ with
$|A|\ge N_0$ satisfying `MinimisesDiameter A` contains three points pairwise at distance 1.
For $|A|\ge2$ the helper functions compute the true minimum and maximum distance, so the
statement is right. The defect is the `sorry` in the definitions. v2 replaces those
definitions; their meaning is unchanged on sets with $|A|\ge2$.

## A. Semantic fidelity

**A1. Statement fidelity: pass (for $|A|\ge2$; see A3).**

- **Back-translation:** "There is $N_0$ such that every $A$ with $|A|\ge N_0$, minimum
  distance $\ge1$, and diameter $\le$ that of every equal-size set with minimum distance
  $\ge1$, contains distinct $a,b,c$ with $|ab|=|bc|=|ac|=1$."
- **"$\ge1$" versus the page's "$=1$".** A competitor $B$ with minimum distance $\delta>1$
  rescales by $1/\delta$ to minimum distance 1 and a smaller diameter. So the
  minimum-diameter value, and the set of minimisers, is the same under either convention,
  and every minimiser has minimum distance exactly 1. The conventions are equivalent.
- **Minimisers exist for each $n\ge2$.** Translate one point to the origin. The admissible
  configurations with diameter at most that of a fixed admissible set form a compact set,
  and the diameter is continuous on it. So the hypothesis is satisfiable and the statement
  is not vacuous.
- **The $n=4$ failure** (the square) is absorbed by $\exists N_0$, as intended.

**A2. Lean semantics traps: pass, apart from A3.**

- No ℕ arithmetic traps.
- The `offDiag` image is the set of pairwise distances.
- `min'`/`max'` are the genuine extrema when that set is nonempty, i.e. $|A|\ge2$.

**A3. Definitions: DEFECT (fixed).**

- **[defect: sorry-in-definition]** At lines 12 and 19, `(by sorry)` supplies the
  `Nonempty` proof required by `Finset.min'` and `Finset.max'`. Consequences:
  - Each definition depends on `sorryAx`. `FABLE_REVIEW.md` A3 requires no `sorry` inside
    any definition; only theorem proof bodies may carry it.
  - For $|A|\le1$ the "proof" is of a false proposition, so the value is unspecified, and
    no lemma can pin it down.
  - The main theorem is unaffected only because a prover can choose $N_0\ge2$. Any variant
    that touches small sets inherits the problem.
- **Fix (v2):** `if h : (…).Nonempty then (…).min' h else 0`, and likewise for `max'`.
  - The values are unchanged for $|A|\ge2$. For $|A|\le1$ they are the documented junk
    value `0`, which agrees with `Metric.diam` for `diameter`.
  - A useful side effect: `MinimisesDiameter A` is now provably false for $|A|\le1$, since
    `minPairwiseDist A = 0 < 1`.
  - `Finset.offDiag` needs no `DecidableEq` in this Mathlib (checked in
    `.lake/packages/mathlib/Mathlib/Data/Finset/Prod.lean`), and `Finset.Nonempty` is
    decidable. So the change introduces no new instance requirement.
- `IsEquilateralTriangle` and `MinimisesDiameter` match their docstrings.
