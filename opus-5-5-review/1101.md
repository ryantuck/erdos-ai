## Summary

The problem (OPEN) fixes a pairwise coprime sequence $u_1<u_2<\cdots$ with
$\sum 1/u_i<\infty$. The integers not divisible by any $u_i$ are $a_1<a_2<\cdots$, and
$t_x$ is defined by $u_1\cdots u_{t_x}\le x<u_1\cdots u_{t_x+1}$. The sequence $u$ is called
*good* if $\max_{a_k<x}(a_{k+1}-a_k)<(1+\epsilon)t_x\prod(1-1/u_i)^{-1}$ for every
$\epsilon>0$ and all large $x$. The page then asks two questions. Is there a good sequence
with $u_n<n^{O(1)}$ (Erdős believed not)? Is there one with $u_n\le e^{o(n)}$ (Erdős
believed so)?

The Lean file bundles the admissible sequences as `GoodSeqData` and defines the sifted set,
$t_x$ (via `Nat.find`), the maximal gap (via `sSup`), the Euler-type product (via `⨆` of

question. Back-translated independently, both theorems say exactly what Erdős
conjectured, and each is decision-equivalent to its question. The definitions are exact

**A2. Lean semantics traps: pass. One finite-$x$ discrepancy, proven immaterial.**

- **ℕ subtraction.** `Nat.find … - 1` in `tOfX` truncates only when `Nat.find = 0`, that
  is, only when $x<\mathrm{partialProd}\,0=1$, i.e. $x=0$. For $x\ge1$, let $n\ge1$ be the
  least index with $x<\mathrm{partialProd}\,n$. Then
  $\mathrm{partialProd}(n-1)\le x<\mathrm{partialProd}\,n$, and
  $\mathrm{partialProd}\,t=u_1\cdots u_t$ in source indexing. So `tOfX` is **exactly**
  $t_x$, with a junk value `0` at $x=0$ where the source's $t_x$ does not exist. This was
  checked numerically against the defining inequalities for the prime squares on
  $1\le x<5\cdot10^4$. Other subtractions: `(b - a).toNat` has $b>a$, so it is exact. In
  `inverseProd`, `(u i : ℝ) - 1` is real subtraction with value $\ge1$.
- **Division.** `u i / (u i - 1)` has denominator $\ge1$. `log (u n) / n` is $0$ at
  $n=0$, which is harmless under `atTop`. No ℕ division appears anywhere.
- **`Finset.range n`** in `inverseProd` gives $\prod_{i<n}$. The iSup over all $n$ makes
  any off-by-one irrelevant.
- **`sSup` / `⨆` junk values.** `maxGap` is the `sSup` of a finite subset of ℕ: $0<a<b\le x$
  with $b$ the successor of $a$. So it is a genuine maximum, or $0$ when the set is empty.
  `inverseProd` is the `⨆` in ℝ of increasing partial products. These are bounded because
  $\log\prod_{i<n}\frac{u_i}{u_i-1}=-\sum\log(1-1/u_i)\le2\sum1/u_i<\infty$. So the
  supremum is the value of the infinite product. It is not Mathlib's junk `0` for
  unbounded sets.
- **Filter encodings.** `∀ ε > 0, ∀ᶠ x in atTop` is the source's "for all $\epsilon>0$, if
  $x$ is sufficiently large". `∃ᶠ n in atTop` is "infinitely many $n$". `Tendsto … (nhds 0)`
  is the $o(1)$. The source's $x$ may be real, while Lean's is ℕ. On a real $x$,
  $\max_{a_k<x}$ depends only on $\lceil x\rceil$ and $t_x$ only on $\lfloor x\rfloor$. The
  two differ only where $t$ jumps, which the $(t+1)/t\to1$ argument below absorbs.
- **The discrepancy.** `maxGap` requires `b ≤ x`: the *right* endpoint of the gap is at
  most $x$. The source takes $\max_{a_k<x}$: the *left* endpoint is below $x$. So the Lean
  version omits the gap that straddles $x$. This is real, not invented. For
  $u_i=p_i^2$ (sifted set = squarefree numbers), the two maxima first differ at $x=4$:
  Lean gives $1$ and the source gives $2$, from the gap $3\to5$. They differ at 36 values
  of $x\le2\cdot10^6$. However, the resulting notions of *goodness* coincide. Write $L(x)$
  for the Lean maximum and $G(x)$ for the source maximum.
  - Every gap with right endpoint $\le x$ has left endpoint $<x$, so $L\le G$ and
    source-good implies Lean-good.
  - Conversely, assume Lean-goodness and fix $\epsilon$. Let $a_K<x\le a_{K+1}$, with
    straddling gap $g$. Since $\mathrm{partialProd}\,t\ge2^t$, we have
    $t_y\le\log_2y$. So Lean-goodness at $y=a_{K+1}$ gives
    $g<(1+\epsilon)P\log_2(x+g)$. Hence $g<x$ for large $x$, so $a_{K+1}<2x$. Since
    $\mathrm{partialProd}(t_x+2)\ge2\,\mathrm{partialProd}(t_x+1)>2x$, we get
    $t_{a_{K+1}}\le t_x+1$. Every gap counted by $G(x)$ ends at or before $a_{K+1}$, so
    $G(x)\le L(a_{K+1})<(1+\epsilon)(t_x+1)P\le(1+\epsilon)^2t_xP$ for large $x$, because
    $t_x\to\infty$.

  So `IsGoodSeq` is extensionally the source's goodness, and both theorems mean what the
  source asks. It is still worth aligning the definition: the page's sieve lower bound
  (B2) is *literally* true only for $G$. The gap produced by the Chinese remainder theorem
  can end beyond $x$, so transferring the bound to $L$ needs a separate $o(x)$ gap bound.
  [polish, applied in v2]
- **Vacuous bounded quantifiers.** For $x\le1$ the gap set is empty and `maxGap` is 0.
  This is invisible under `atTop`.
- **Strict inequalities.** `<` in `IsGoodSeq` and `StrictMono` match the source. `≤` in
