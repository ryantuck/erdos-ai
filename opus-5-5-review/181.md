## Summary

The page (OPEN at capture) asks to prove $R(Q_n)\ll2^n$, where $Q_n$ is the $n$-dimensional hypercube. It records the trivial
bound $R(Q_n)\le R(K_{2^n})\le C^{2^n}$, Tikhomirov's $R(Q_n)\ll2^{(2-c)n}$ [Ti22], and that Erdős and Sós could not decide
whether $R(Q_n)/2^n\to\infty$ [Er93].

The Lean defines $Q_n$ on `Fin n → Bool` with Hamming-distance-one adjacency, containment as an injective homomorphism, and
$R(H)$ as the least $N$ such that every graph on `Fin N` or its complement contains $H$. It asserts $\exists C>0\ \forall n\ge1,\
R(Q_n)\le C\,2^n$.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $Q_n$ be the $n$-dimensional hypercube graph (so that $Q_n$ has $2^n$ vertices and $n2^{n-1}$
  edges). Prove that\[R(Q_n) \ll 2^n.\]"
- **Back-translation** (lines 54–58): "There is $C>0$ such that for every $n\ge1$ the least $N$ for which every 2-colouring of
  $K_N$ has a monochromatic copy of $Q_n$ is at most $C\cdot2^n$." This is $R(Q_n)\ll2^n$.
- **Checks.**
  - *Non-vacuity.* `ramseyDiag181` is `sInf` of a set of naturals. If that set were empty, the value would be $0$ and the bound
    trivial. For finite `H` on $m$ vertices the set contains $\binom{2m}m$ (`forces_choose`, from `ramsey_finset`, both proved),
    so the definition is the diagonal Ramsey number.
  - *Scale.* $2^n\le R(Q_n)\le4^{2^n}$ (`variants.lower_bound`, `variants.trivial_bound`, proved). So the statement is neither
    trivially true nor trivially false.
  - *$n\ge1$.* Harmless: $R(Q_0)=1$, and the lower bound forces $C\ge1$, so including $n=0$ gives an equivalent statement.
  - *Copies.* A copy is an injective homomorphism (not induced), the standard notion for graph Ramsey numbers.

**A2. Lean semantics traps: pass.** The only arithmetic is the real comparison `(R : ℝ) ≤ C * 2 ^ n`; the casts are correct.
