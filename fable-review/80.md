## Summary

The problem (Erdős–Rothschild): let $f_c(n)$ be the maximal $m$ such that every graph
on $n$ vertices with at least $cn^2$ edges, in which every edge lies in a triangle,
must contain an edge shared by at least $m$ triangles (a "book of size $m$").
Estimate $f_c(n)$; in particular, is $f_c(n) > n^{\epsilon}$ (disproved by Fox–Loh
for $c < 1/4$), or $f_c(n) \gg \log n$ (open)? The Lean file defines `bookSize`
(common-neighbor count) and `EveryEdgeInTriangle`, and asserts the open $\log n$
conjecture directly: for every $c > 0$ there is $C > 0$ such that **every** $n$-vertex
graph meeting the hypotheses has an edge in $\geq C \log n$ triangles. The definitions
are correct and the quantifier structure matches the source, but the universal
quantification over all `n : ℕ` — with no "sufficiently large" threshold — makes the
statement false at `n = 0`: `Fin 0`'s empty graph has `edgeFinset.card = 0 ≥ c·0²`,
satisfies `EveryEdgeInTriangle` vacuously, yet `∃ u v : Fin 0, …` is unsatisfiable.
This is a formalization artifact (the same bug the prior review found and that was
fixed in the archived styled copy `deepmind/deepmind/80.lean`, but never back-ported
to `conjectures/80.lean`). With the standard `∃ N₀, ∀ n ≥ N₀` reading of $\gg$, the
statement is a faithful rendering of the open conjecture.

## A. Semantic fidelity

**A1. Statement fidelity — one defect; otherwise faithful (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $c>0$ and let $f_c(n)$ be
  the maximal $m$ such that every graph $G$ with $n$ vertices and at least $cn^2$
  edges, where each edge is contained in at least one triangle, must contain a book of
  size $m$, that is, an edge shared by at least $m$ different triangles. Estimate
  $f_c(n)$. In particular, is it true that $f_c(n)>n^{\epsilon}$ for some
  $\epsilon>0$? Or $f_c(n)\gg \log n$?"
- Independent back-translation of `conjectures/80.lean:42-49`: "for every real
  $c > 0$ there is $C > 0$ such that for **every** $n$ and every graph $G$ on `Fin n`
  with $\#E(G) \geq cn^2$ in which every edge lies in a triangle, some edge of $G$
  lies in at least $C\log n$ triangles." Modulo the missing threshold (the defect
  below), this is exactly "$f_c(n) \geq C\log n$", unfolded through the definition of
  $f_c$: $f_c(n) \geq x$ iff every admissible graph has an edge in $\geq x$
  triangles. The unfolding is term-by-term exact — `bookSize` is an integer, so the
  real comparison `(bookSize : ℝ) ≥ C·log n` is equivalent to
  `bookSize ≥ ⌈C·log n⌉`, which is the $f_c(n) \geq C\log n$ reading.
- **[defect] `n = 0` falsifier.** The theorem quantifies `∀ (n : ℕ)` with no lower
  threshold. At `n = 0`: the unique graph on `Fin 0` has
  `(G.edgeFinset.card : ℝ) = 0 ≥ c * 0 ^ 2 = 0` (premise holds, non-strict `≥`),
  `EveryEdgeInTriangle G` holds vacuously (no adjacent pairs), and the conclusion
  `∃ u v : Fin 0, …` is false (empty type). So for every `c > 0` and every `C > 0`
  the inner `∀ n` fails at `n = 0`, and the whole theorem is **provably false** —
  independent of the open conjecture's truth. The source's $\gg$ is an asymptotic
  claim; the faithful encoding is `∃ C > 0, ∃ N₀, ∀ n ≥ N₀, …`. **Fixed in
  `conjectures-v2/80.lean` (not compile-verified).**
- Equivalence note (why `n = 0` is the *only* falsifier): for `n ≥ 1` the premise
  forces `edgeFinset.card ≥ cn² > 0`, so an admissible graph has an edge, and by
  `EveryEdgeInTriangle` that edge has `bookSize ≥ 1`; hence on any finite range
  `1 ≤ n ≤ N` one can shrink `C` until `C·log n ≤ 1`, so the `∀ n ≥ 1` and the
  eventual versions of the statement are logically equivalent. The `∃ N₀` fix is thus
  both faithful to $\gg$ and mathematically conservative.
- Scope: of the two "in particular" questions, the file formalizes only the still-open
  $\log n$ one; the $n^\epsilon$ question (answered negatively by Fox–Loh for
  $c < 1/4$) is mentioned in the module docstring's remarks but its resolved content
  was not formalized, and the docstring's *statement* paragraph silently dropped that
  question relative to the source (drift; see B2/Addendum — restored, plus a solved
  variant, in v2).

**A2. Lean semantics traps — pass (after the A1 fix).**

- No ℕ subtraction, no division in the statement (the `1/4`, `n/6`,
  `K/log log n` expressions occur only in v2's variants, all in ℝ).
- `Real.log` junk values: `log 0 = log 1 = 0`; at `n = 1` the premise
  `0 = edgeCount ≥ c·1 > 0` is unsatisfiable, so only `n = 0` was live (the defect);
  under the `∃ N₀` fix all small-`n` junk is dodged.
- No `Finset.range`; no off-by-one surface.
- Vacuous quantifiers: `EveryEdgeInTriangle` is vacuously true on edgeless graphs —
  exactly the mechanism of the `n = 0` defect; harmless for `n ≥ 1` since the edge
  count premise forces edges. For `c ≥ 1/2` no graph on `n ≥ 1` vertices has `cn²`
  edges (max `n(n-1)/2 < n²/2`), so those `c` are vacuously true — matches the
  source's implicit feasible range and is harmless under `∀ c`.
- "$\gg$" encoding: `∃ C > 0` with the (fixed) eventual quantifier is the standard
  Vinogradov reading. Constant order: `C` is chosen *after* `c` (inside `∀ c`), so
  the implied constant may depend on `c` — correct: the source writes $\ll_c$ for
  Alon–Trotter and the conjecture $f_c(n) \gg \log n$ is per-fixed-$c$. No
  problem-55-class constant absorption (there is no explicit parameter factor for
  `C` to absorb).
- Strict vs non-strict: "at least $cn^2$ edges" → `≥` ✓; "at least $m$ triangles" →
  `≥` ✓; `StrictMono`/`Monotone` not used.

**A3. Definitions — pass.**

- `bookSize G u v = #(N(u) ∩ N(v))`: for `w` in the intersection, `Adj u w` and
  `Adj v w` give `w ≠ u, w ≠ v` by irreflexivity, so the count is exactly the number
  of triangles through the edge `{u,v}` when `Adj u v`. Small-case check: on `K₃`
  each edge has `bookSize = 1`; on `K₄` each edge has `bookSize = 2` ✓. The docstring
  claims the triangle interpretation unconditionally; it holds only when `{u,v}` is
  an edge (every *use* is guarded by `G.Adj u v`, so no drift — docstring caveat
  added in v2, mirroring the styled copy).
- `EveryEdgeInTriangle`: `∀ u v, Adj u v → 0 < bookSize u v` — each edge in ≥ 1
  triangle; symmetric double-quantification is harmless ✓.
- No `sorry` in any definition; definitions and theorem use agree.
- Import reachability (problem-65 class, walked in the pinned Mathlib clone):
  `neighborFinset`/`edgeFinset` are in `Combinatorics.SimpleGraph.Finite` (imported);
  the `Fintype G.edgeSet` instance needs `Fintype (Sym2 (Fin n))`, provided by
  `Sym2.instFintype` in `Data.Finset.Sym`, reachable via
  `SimpleGraph.Finite → Data.Sym.Card → Data.Finset.Sym`; `Real.log` is in
  `Analysis.SpecialFunctions.Log.Basic` (imported). No missing-import defect.

**A4. Question form and answer polarity — acceptable encoding, documented.**

- The source is a compound question; the formalized part ("is $f_c(n) \gg \log n$?")
  is a yes/no question, encoded as a **direct assertion** of the affirmative (the
