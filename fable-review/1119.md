## Summary

The problem (page banner: **INDEPENDENT**): let $\mathfrak{m}$ be an infinite cardinal
with $\aleph_0<\mathfrak{m}<\mathfrak{c}=2^{\aleph_0}$, and let $\{f_\alpha\}$ be a
family of entire functions such that for every $z_0\in\mathbb{C}$ there are at most
$\mathfrak{m}$ distinct values of $f_\alpha(z_0)$; must $\{f_\alpha\}$ have cardinality
at most $\mathfrak{m}$? This generalizes Wetzel's problem (the $\aleph_0$ case, resolved
by Erdős [Er64g] as equivalent to $\mathfrak{c}>\aleph_1$); [Ha74] notes the answer is
yes when $\mathfrak{m}^+<\mathfrak{c}$, and the remaining case
$\mathfrak{m}^+=\mathfrak{c}$ is undecidable — consistently yes (Kumar–Shelah [KuSh17])
and consistently no (Schilhan–Weinert [ScWe24]). The Lean theorem
(`conjectures/1119.lean:22–27`) takes $\mathfrak{m}$, the family, entirety, and the
pointwise value bound as hypotheses and *asserts* the conclusion
`Cardinal.mk ↥(range f) ≤ 𝔪`. Each hypothesis and the conclusion are individually
faithful renderings of the English; the defect is the overall shape: a direct assertion
of the "yes" direction of a question that is neither provable nor refutable in ZFC, in a
file whose own docstring says "Independent of ZFC".

## A. Semantic fidelity

- Recovered verbatim source statement (see Addendum): "Let $\mathfrak{m}$ be an

  $\{f_\alpha\}$ be a family of entire functions such that, for every

- Independent back-translation of lines 22–27: "for every cardinal 𝔪 with
  ℵ₀ < 𝔪 < 𝔠, every family `f : ι → ℂ → ℂ` of entire functions whose value set at each
  point has cardinality ≤ 𝔪 has at most 𝔪 distinct members." Component-by-component:
  - `ℵ₀ < 𝔪` and `𝔪 < Cardinal.continuum` (line 22) render
    $\aleph_0<\mathfrak{m}<\mathfrak{c}$; "infinite cardinal" is implied by
    `ℵ₀ < 𝔪`, and `continuum` is *defined* as `2 ^ ℵ₀`, matching
    $\mathfrak{c}=2^{\aleph_0}$. ✓
  - `∀ i, Differentiable ℂ (f i)` (line 24) = entire. ✓
  - `∀ z, Cardinal.mk ↥(range (fun i => f i z)) ≤ 𝔪` (line 25): the set of values at
    `z` is exactly `range (fun i => f i z)`, and `mk … ≤ 𝔪` is "at most 𝔪 distinct
    values". ✓
  - Conclusion `Cardinal.mk ↥(range f) ≤ 𝔪` (line 26): the *family* $\{f_\alpha\}$, as
    a set, is `range f`; counting `range f` rather than `ι` correctly measures
    *distinct* functions (a huge index set with repetitions is not a counterexample).
    ✓ — and matches the docstring's "family of distinct functions".
- Universe generality: `ι : Type` (= `Type 0`) loses nothing. Both hypotheses and the
  conclusion factor through `range f ⊆ ℂ → ℂ : Type 0`: re-indexing any family (from
  any universe) by `↥(range f)` with the coercion map preserves the value sets
  `range (fun i => f i z)` and `range f` itself. (The prior review's justification for
  this point is weaker — see Part E.)
- Indexing conventions: N/A (no sequences).
- Vacuity: for a *fixed* admissible 𝔪 the statement is substantive. The universally
  quantified reading (over all 𝔪) is vacuous under CH — but that is inherent to the
  problem, which presupposes a cardinal strictly between ℵ₀ and 𝔠; it matches the
  source rather than silently altering it. `ι` empty makes both `range` sets empty and
  the conclusion trivially true — harmless and correct.

**A4. Question form and answer polarity — DEFECT (fixed).**

- The source is a **yes/no question** ("Must $\{f_\alpha\}$ have cardinality at most
  $\mathfrak{m}$?") whose resolution is **INDEPENDENT of ZFC**. The raw file encodes it
  as a **direct assertion of the affirmative direction** (binders before the colon,
  conclusion asserted, `:= sorry`).
- The pipeline rule is that direct-assertion form for a solved problem is acceptable
  *iff the polarity is the true direction*. Here there is **no true direction**: for the
  critical case $\mathfrak{m}^+=\mathfrak{c}$ the answer is consistently yes ([KuSh17])
  and consistently no ([ScWe24]); the universally-quantified Lean statement is likewise
  independent (true in the Kumar–Shelah model, where ℵ₁ is the only admissible 𝔪, and
  vacuously true under CH; false in the Schilhan–Weinert model, where 𝔪 = ℵ₁ < 𝔠 = ℵ₂
  witnesses failure). The `sorry` can never be filled, and the negation is equally
  unprovable. Asserting either polarity misstates the resolution — this is precisely
  the situation the `answer(…) ↔` question form exists for, and indeed the archived
  styled copy (`deepmind/deepmind/1119.lean:61`) uses `answer(sorry) ↔ ∀ 𝔪, …`.
  **[defect: answer-shape]**
- Fix applied (plain Mathlib has no `answer()` elaborator): the question's proposition
  is recorded as a `Prop`-valued definition, and the ZFC-provable parts of the
  resolution (the [Ha74] easy case and both directions of [Er64g]) are formalized as
  theorems — see Addendum. The consistency results themselves are not expressible as
  single Lean statements (precedent: problem 1067's treatment of Komjáth's
  independence result).
- The binder-before-colon check for `answer()` theorems does not apply to the raw file
  (no `answer()`); in the fixed def the cardinal quantifier is correctly *inside* the
  `Prop`.
