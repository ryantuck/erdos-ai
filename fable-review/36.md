## Summary

The problem (recovered verbatim): "Find the optimal constant $c>0$ such that
the following holds. For all sufficiently large $N$, if
$A\sqcup B=\{1,\ldots,2N\}$ is a partition into two equal parts, so that
$\lvert A\rvert=\lvert B\rvert=N$, then there is some $x$ such that the number
of solutions to $a-b=x$ with $a\in A$ and $b\in B$ is at least $cN$." This is
the **minimum overlap problem** (OPEN; Guy C17); the trivial bound is
$c \ge 1/4$, Scherk proved $c \ge 1-1/\sqrt2$, and the current records are
$0.379005 < c < 0.380876$ (White [Wh22]; TTT-Discover [YKLBMWKCZGS26], after
AlphaEvolve [GGTW25] and Haugland [Ha16]). The Lean file's `repCount A B x`
correctly counts the representations $a - b = x$, and every hypothesis of the
theorem (union, disjointness, equal cardinalities, eventual-$N$ shape,
$\ge cN$ conclusion) is a faithful rendering of the *inner* statement. The
defect is at the outermost quantifier: the theorem says only that *some*
positive constant works, which is a known triviality (pigeonhole gives every
equal partition a difference with $\ge N^2/(4N-1) > N/4$ representations, so
$c = 1/4$, $N_0 = 0$ proves the statement outright); the problem asks for the
*optimal* such constant, whose value is the open question. The v2 fix pins $c$
uniquely as the threshold constant (every smaller constant eventually works;
every larger constant fails infinitely often).

## A. Semantic fidelity

**A1. Statement fidelity — inner statement faithful; outer quantifier
trivializes the problem (the defect, detailed with A4).**

- Independent back-translation of `conjectures/36.lean:26-34`: "there exist a
  real $c > 0$ and a threshold $N_0$ such that for all $N \ge N_0$ and all
  finsets $A, B \subseteq \mathbb{Z}$ with $A \cup B = [1, 2N]$, $A \cap B =
  \emptyset$, $|A| = |B| = N$, some $x \in \mathbb{Z}$ has
  $\mathrm{repCount}(A,B,x) \ge cN$."
- The *inner* proposition (for a fixed $c$) is term-by-term exact against the
  source: `A ∪ B = Finset.Icc (1:ℤ) (2*N)` + `Disjoint A B` is precisely
  $A \sqcup B = \{1,\ldots,2N\}$; the two cardinality hypotheses are the
  "equal parts" condition (mildly redundant — union + disjointness force
  $|A|+|B| = 2N$, so one of them would do — but the pair is the clearer
  transcription of $\lvert A\rvert=\lvert B\rvert=N$, no defect);
  `∃ N₀, ∀ N ≥ N₀` is the standard "for all sufficiently large $N$"; `∃ x`
  with `≥ c * N` matches "there is some $x$ … at least $cN$".
- **Trivially true as written.** The outer `∃ c` makes the whole theorem a
  known easy exercise: for any equal partition, the $N^2$ pairs $(a,b) \in
  A \times B$ have differences in $[1-2N,\, 2N-1]$, only $4N-1$ values, so
  some $x$ has $\mathrm{repCount} \ge N^2/(4N-1) \ge N/4$; hence $c = 1/4$,
  $N_0 = 0$ witnesses the statement (the $N = 0$ instance is vacuously fine:
  both sides are 0). The problem's content — *which* constant is optimal — is
  entirely absent. This fails the A1 "not trivially true" check.
  **[defect: trivially-true-statement / optimality-dropped]**
- Indexing: no sequence indexing arises; the interval $\{1,\ldots,2N\}$ is
  transcribed directly as `Icc 1 (2N)` (inclusive both ends, correct).

**A4. Question form and answer polarity — DEFECT (fixed in v2).**

- The source is a **value request** ("Find the optimal constant $c>0$…").
  The checklist's ideal shape is `… = answer(…)`; in this raw pipeline (no
  `answer()` elaborator) batch precedent (fable-review/33.md, A4) is to
  formalize the *true existence substrate* and record the value request in
  prose. But the input's substrate — mere existence of *some* $c > 0$ — is
  the wrong substrate: it is a pigeonhole triviality (A1) that does not pin
  the constant at all ($c = 10^{-6}$ also witnesses it). Unlike problem 33
  (where the substrate was a substantive finiteness statement), a faithful,
  non-trivial substrate *is* expressible here without `answer()`: the
  threshold characterization. **[defect]**
- v2 fix: `∃ c > 0` such that (i) `∀ c' < c`, the eventual lower bound at
  $c'$ holds over all equal partitions, and (ii) `∀ c' > c`, it fails at
  infinitely many $N$ (witnessed by a partition all of whose difference
  counts are $< c'N$). Verified by hand: (i)+(ii) admit at most one $c$ (two
  candidates $c_1 < c_2$ contradict each other at $(c_1+c_2)/2$ — (i) for
  $c_2$ makes it eventually work, (ii) for $c_1$ makes it fail infinitely
  often); existence holds with $c = \liminf_N m(N)/N \in [1/4, 1/2]$ where
  $m(N)$ is the min over equal partitions of the max difference count
  ((i) ⟺ $c \le \liminf$, (ii) ⟺ $\liminf \le c$); positivity is the
  pigeonhole bound. So the v2 statement is true, non-trivial, and pins $c$
  uniquely to the minimum-overlap constant whose value
  ($0.379005 < c < 0.380876$) is the open question. Upstream
  formal-conjectures (dd1c2beb) confirms this reading: its main statement is
  `atTop.Tendsto MinOverlapQuotient (𝓝 answer(sorry))` — the value request —
  with the same bounds as variants.
- No binders before the colon in either version; no `answer()` in the raw
  corpus, so the binder-scope trap does not arise.
