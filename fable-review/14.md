## Summary

The problem (OPEN): *let $A \subseteq \mathbb{N}$ and let $B \subseteq
\mathbb{N}$ be the set of integers representable in exactly one way as the sum
of two elements from $A$.* Two questions: (1) is it true that for all
$\epsilon > 0$ and large $N$, $\lvert\{1,\ldots,N\}\setminus B\rvert
\gg_\epsilon N^{1/2-\epsilon}$? (2) is it possible that
$\lvert\{1,\ldots,N\}\setminus B\rvert = o(N^{1/2})$? The Lean file defines
`reprCount` (unordered representations $n = a + b$, $a \le b$, $a, b \in A$),
`UniqueRepSum` ($= B$), and `nonUniqueRepCount`
($= \lvert\{1,\ldots,N\}\setminus B\rvert$ via `Finset.Icc 1 N`), and states
the two parts as `erdos_problem_14a` (∀ A ∀ ε > 0 ∃ C > 0, eventually
$C N^{1/2-\epsilon} \le$ count) and `erdos_problem_14b` (∃ A with count
$\le \epsilon N^{1/2}$ eventually, for every ε > 0 — the ε-definition of
little-o). Read back independently, both agree with the source questions,
asserted in the affirmative direction per this corpus's convention for open
yes/no questions, and both RHSs coincide with the fully recovered upstream
formal-conjectures encodings. I found no semantic defects; the findings are
enrichment-level (missing [ErFr91] key, no bibliography, neither of the
page's two remarks captured).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $A\subseteq
  \mathbb{N}$. Let $B\subseteq \mathbb{N}$ be the set of integers which are
  representable in exactly one way as the sum of two elements from $A$. Is it
  true that for all $\epsilon>0$ and large $N$
  $\lvert \{1,\ldots,N\}\backslash B\rvert \gg_\epsilon N^{1/2-\epsilon}$?
  Is it possible that
  $\lvert \{1,\ldots,N\}\backslash B\rvert =o(N^{1/2})$?"
- `reprCount` (`conjectures/14.lean:13-14`), back-translated: the number of
  $a \in \{0,\ldots,n\}$ with $a \in A$, $n - a \in A$, $a \le n - a$. The
  map $a \mapsto (a, n-a)$ is a bijection onto the representations
  $n = a + b$, $a \le b$, $a, b \in A$ (each such representation determines
  and is determined by its smaller element), so this is exactly the number
  of unordered representations. "Sum of two elements" is read as allowing
  $a = b$, matching the upstream formal-conjectures encoding (`a.1 ≤ a.2 ∧
  a.1 + a.2 = n`); this is the standard reading in the Sidon-set literature
  the problem belongs to (page tags: sidon sets).
- `UniqueRepSum` (`:18-19`) is $\{n : r_A(n) = 1\} = B$ — "exactly one way"
  is exactly `reprCount A n = 1` (equivalent to the upstream `∃!` over
  ordered pairs with `a.1 ≤ a.2`).
- `nonUniqueRepCount` (`:23-24`): `(Finset.Icc 1 N).filter (n ∉ B) |>.card`
  is exactly $\lvert\{1,\ldots,N\}\setminus B\rvert$ — `Icc 1 N =
  {1,…,N}`, no off-by-one, `0 ∉ Icc 1 N`. The name slightly undersells the
  content (it counts integers with zero representations too), but its
  docstring says "NOT in the unique-representation sumset", which is
  accurate; the v2 docstring makes this explicit.
- **Part 1** (`erdos_problem_14a`, `:33-37`), back-translated: for every
  $A$ and $\epsilon > 0$ there are $C > 0$ and $N_0$ with
  $C N^{1/2-\epsilon} \le \lvert\{1,\ldots,N\}\setminus B\rvert$ for all
  $N \ge N_0$. This is exactly "$\gg_\epsilon N^{1/2-\epsilon}$ for large
  $N$". The implied constant is chosen after $A$ (so may depend on $A$ as
  well as $\epsilon$, though the source subscripts only $\epsilon$): this
  is the correct reading — the upstream encoding (`∀ A, ∀ ε > 0, … ≫ …`
  with the constant inside the Vinogradov notation) quantifies identically,
  and under the leading $\forall \epsilon$ the per-$A$ and uniform-constant
  readings are in fact equivalent (a per-$A$ constant at exponent
  $1/2 - \epsilon$ yields constant $1$ at any smaller exponent
  $1/2 - \epsilon'$ for large $N$, since $N^{\epsilon'-\epsilon} \to
  \infty$). Matches.
- **Part 2** (`erdos_problem_14b`, `:49-53`): ∃ A, ∀ ε > 0, eventually
  count $\le \epsilon N^{1/2}$. For non-negative sequences this is
  precisely the definition of count $= o(N^{1/2})$ (no absolute values
  needed; `Real.rpow` at the irrelevant $N = 0$ gives $0^{1/2} = 0$,
  invisible behind `∃ N₀`). Matches "Is it possible that … $= o(N^{1/2})$"
  as an existence assertion, and coincides with the upstream
  `∃ A, IsLittleO atTop (nonUniqueSumCount A) squareRoot`.
- Not vacuous/trivial: no degenerate witness settles either part
  ($A = \emptyset$ or $A = \mathbb{N}$ give count $\sim N$; a maximal Sidon
  set still leaves $\sim N/2$ integers uncovered, so Part 2's witness must
  be a genuinely nontrivial construction; Part 1 has no known
  counterexample — the best claimed construction reaches only
  $N^{1/2+\epsilon}$, which refutes nothing).
- Internal sanity: the two affirmative assertions are **mutually
  consistent** (count $\asymp \sqrt N/\log N$ would satisfy both), so
  asserting both directions simultaneously is coherent — had the two
  affirmatives been incompatible, the encoding convention would have
  manufactured a contradiction; it does not.

**A2. Lean semantics traps — pass (all checked explicitly).**

- **ℕ subtraction:** `n - a` in `reprCount` is guarded by
  `a ∈ Finset.range (n + 1)`, i.e. $a \le n$, so the subtraction is exact —
  never truncated. Under $a \le n$, the ℕ-condition `a ≤ n - a` is exactly
  $2a \le n$, the intended "smaller half" condition. The exponent
  `(1 : ℝ) / 2 - ε` subtracts in ℝ. ✓
- **Division:** only `(1 : ℝ) / 2` (exact in ℝ). `rpow` at `N = 0`:
  `0 ^ x = 0` for `x ≠ 0` — both theorems assert bounds only for
  `N ≥ N₀`, so the `N = 0` value is irrelevant (and for `14a` a witness
  `N₀ ≥ 1` avoids it entirely). ✓
- **`Finset.range` off-by-one:** `range (n + 1) = {0, …, n}` is the correct
  domain for the smaller summand ($a = 0$ and $a = n$ both legitimate when
  `0 ∈ A`); `Icc 1 N = {1, …, N}` is the source's exact range. ✓
- **Vacuous bounded quantifiers:** none (the `∃ C, … ∃ N₀, ∀ N ≥ N₀`
  and `∀ ε > 0` structures are all non-degenerate). ✓
- **little-o / "large N" encodings:** the ε-eventually unfolding of
  $o(N^{1/2})$ and the `∃ N₀`-encoding of "large $N$" are exact
  (derivations in A1). ✓
- **Strict vs non-strict:** `0 < ε`, `0 < C` strict as required;
  `C * … ≤ count` and `count ≤ ε * …` non-strict, the standard and correct
  forms for $\gg$ and little-o. `a ≤ n - a` non-strict correctly permits
  the middle representation $n = a + a$. ✓
