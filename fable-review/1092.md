## Summary

The problem (Erdős–Hajnal–Szemerédi): let $f_r(n)$ be maximal such that if every
subgraph of $G$ on $m$ vertices is the union of a graph with chromatic number $r$ and a
graph with $\leq f_r(m)$ edges, then $\chi(G) \leq r+1$. Is $f_2(n) \gg n$? More
generally, is $f_r(n) \gg_r n$? Status: page banner OPEN; the page's remarks record
Quanyu Tang's observation that a construction of Rödl [Ro82] disproves the first
question ($f_2(n) \not\gg n$); the general question remains open (for $r \geq 3$). The
pre-fix Lean file defined a **pointwise** $f_r(m)$ — an `sSup` over $k$ such that a
*single-size-$m$* local decomposition hypothesis forces $\chi \leq r+1$ — and stated
the $r=2$ disproof and the open $r \geq 3$ question in terms of it. That pointwise set
is **empty** for every $m \geq r+3$ (and in fact for $r=2$ at every $m$), so
`maxDecompEdges r m` collapses to the junk value `sSup ∅ = 0`: the "disproof" theorem
was trivially true and the "open" theorem was provably **false**. The problem's actual
content quantifies over subgraphs of *every* size against a *function* bound; the file
was fixed to that reading.

## A. Semantic fidelity

**A1. Statement fidelity — DEFECT (pre-fix), source-verified analysis.**

- Recovered verbatim source statement (see Addendum): "Let $f_r(n)$ be maximal such
  that, if a graph $G$ has the property that every subgraph $H$ on $m$ vertices is the
  union of a graph with chromatic number $r$ and a graph with $\leq f_r(m)$ edges, then
  $G$ has chromatic number $\leq r+1$. Is it true that $f_2(n) \gg n$? More generally,
  is $f_r(n)\gg_r n$?" Note the source's own $n$/$m$ mixing: the definition is a
  property of the **function** $f_r$, quantifying over all subgraph sizes $m$
  simultaneously; "$f_r(n) \gg n$" asks whether a *linear* function is valid.
- Pre-fix `maxDecompEdges r m` (raw file, former lines 26–30) instead fixed a single
  size $m$: `sSup {k | ∀ n G, (∀ S : Finset (Fin n), S.card = m → ∃ c,
  monochromaticEdges G S c ≤ k) → G.chromaticNumber ≤ r+1}`. **This set is empty**:
  - For $m \geq r+3$, take $G = K_{m-1}$ (complete graph on `Fin (m-1)`). No
    `S : Finset (Fin (m-1))` has `S.card = m`, so the hypothesis holds vacuously,
    while $\chi(K_{m-1}) = m-1 \geq r+2 > r+1$. The implication fails for **every**
    $k$, so the set is empty and Mathlib's `Nat` `sSup` returns the junk value 0.
  - For $r = 2$ the set is empty at *every* $m \geq 3$ for a second, independent
    reason: graphs of girth $> m$ and chromatic number $> 3$ (Erdős) have every
    $m$-vertex subgraph a forest, hence bipartite with 0 monochromatic edges, so even
    $k = 0$ is not in the set. (This also shows the single-size reading of the
    *informal* statement is mathematically vacuous — the function reading is the only
    one under which the problem is a problem.)
  - Consequences: `erdos_problem_1092_r2_disproof` (∀ c>0 ∀ M₀ ∃ m ≥ M₀,
    `maxDecompEdges 2 m < c*m`) was **trivially true** (0 < c·m), encoding nothing of
    Rödl's construction; `erdos_problem_1092_general` (∃ c>0 ∃ M₀ ∀ m ≥ M₀,
    `c*m ≤ maxDecompEdges r m`) was **provably false** (c·m ≤ 0 fails for large m) —
    a formalization of an *open* problem that a compiler-checked proof could refute.
    **[defect] — fixed** (see Addendum): the definition was replaced by
    `ForcesChromaticBound r f` (all subset sizes, function bound `f : ℕ → ℝ`), the
    disproof restated as `∀ c > 0, ¬ ForcesChromaticBound 2 (fun m => c * m)`, and the
    open question as `∃ c > 0, ForcesChromaticBound r (fun m => c * m)` for `3 ≤ r`.
- Decomposition encoding (unchanged, correct): an $m$-vertex graph $H$ is the union of
  a graph with $\chi \leq r$ and a graph with $\leq k$ edges **iff** $H$ has an
  $r$-coloring with $\leq k$ monochromatic edges. (⇐: the monochromatic edges form the
  second part; ⇒: properly $r$-color the first part — every monochromatic edge lies in
  the second part.) "Chromatic number $r$" is read as "$\leq r$", the standard and
  charitable reading (a union with a $\chi < r$ graph is weaker anyway).
- Induced vs arbitrary subgraphs: quantifying over vertex subsets $S$ (induced
  subgraphs) is equivalent — a non-induced subgraph on the same vertices decomposes
  whenever the induced one does, by intersecting both parts with its edge set.
- Finite graphs (`Fin n`) suffice: by De Bruijn–Erdős, an infinite graph all of whose
  finite subgraphs are $(r{+}1)$-colorable is $(r{+}1)$-colorable, and an infinite
  counterexample (Rödl's has $\chi = \aleph_0$) yields finite counterexamples of
  chromatic number $> r+1$ inheriting the local property. So both directions of each
  question transfer; the `Fin n` quantification is faithful.
- Eventual-linear vs everywhere-linear "$\gg$": equivalent here. If a valid ℕ-valued
  $f$ has $f(m) \geq cm$ only for $m \geq N$, any $c' \leq c$ with $c' < 1/N$ makes the
  everywhere-$c'm$ hypothesis force 0 monochromatic edges below size $N$ (integer count
  $< 1$) and is $\leq cm \leq f(m)$ beyond, so it implies the $f$-hypothesis and
  validity transfers. The fixed everywhere-linear form is thus exact, not approximate.
- Not vacuous post-fix: $K_{r+2}$ fails the hypothesis for $c < 1/(r+2)$ (any
  $r$-coloring of $r+2$ vertices has a monochromatic pair by pigeonhole, and if
  adjacent, a monochromatic edge $\geq 1 > c(r+2)$ — for the complete graph every pair
  is adjacent), so small complete graphs no longer sneak through; the $r=2$ statement
  requires Rödl's genuine construction; the $r \geq 3$ statement is substantive and
  open.

**A2. Lean semantics traps — pass (post-fix; the pre-fix junk-`sSup` is the A1 defect).**

- No ℕ subtraction anywhere. `monochromaticEdges` is a `Finset.card` (ℕ, no division);
  the only division is none — the linear bound is a real multiplication `c * (m : ℝ)`
  with the count cast to ℝ before comparison. No truncation or division-by-zero sites.
- `Finset.range` is not used; `S ×ˢ S` with `p.1.val < p.2.val` counts each unordered
  edge inside `S` exactly once (adjacent pairs are never equal; `<` picks one
  orientation). No off-by-one.
- Vacuous/degenerate cases: `S = ∅` gives count 0 ≤ 0 = c·0 — harmless and correct.
  `n = 0`: only `S = ∅`, conclusion `chromaticNumber ⊥ = 0 ≤ r+1` — harmless. The
  pre-fix vacuity at `n < m` was the defect (A1), eliminated by dropping the
  `S.card = m` filter.
- "$\gg$" encoding: existential over a real constant with an everywhere-linear bound —
  exact per the equivalence argued in A1; no filter/liminf machinery needed.
- `≤` vs `<`: `χ(G) ≤ r+1` in `ℕ∞` matches the source; `0 < c` strict as required.
