## Summary

The problem poses three questions about *additive complements to the primes* (sets
$A \subset \mathbb{N}$ such that every large integer is $p + a$, $p$ prime, $a \in A$):
(1) is there such an $A$ with $|A \cap \{1,\ldots,N\}| = o((\log N)^2)$? (2) can
$O(\log N)$ be achieved? (3) must such an $A$ satisfy
$\liminf |A \cap \{1,\ldots,N\}|/\log N > 1$? Questions 1–2 are OPEN (the page shows a
\$50 prize, offered by Erdős per Guy's [Gu04] problem E1 for question 2); question 3 was
answered **yes** by Ruzsa [Ru98c], who proved $\liminf \ge e^\gamma \approx 1.781$. The
Lean file (`conjectures/32.lean`) defines the complement property and the counting
function correctly and states the affirmative directions of questions 1 (`erdos_problem_32a`,
a faithful ε–$N_0$ little-o) and 2 (`erdos_problem_32b`, a $C\log N$ bound) — both
corpus-acceptable direct-assertion encodings of open yes/no questions. Question 3 is not
formalized, mentioned, or noted anywhere in the file: a completeness defect (B2 class
"missing part of the problem", not optional enrichment — it is part of the site's
problem statement proper). One boundary nit in 32b (`∀ N ≥ 1` with $\log 1 = 0$ forces
$1 \notin A$; truth-value equivalent via a shift argument, but unfaithful at the
boundary). Fixed in `conjectures-v2/32.lean`.

## A. Semantic fidelity

- Independent back-translation of `erdos_problem_32a` (lines 31–35): "there is a set
  $A \subseteq \mathbb{N}$ that is an additive complement to the primes and whose
  counting function satisfies: for every $\varepsilon > 0$, eventually
  $|A \cap \{1,\ldots,N\}| \le \varepsilon(\log N)^2$." The ε–$N_0$ clause is exactly
  $|A \cap \{1,\ldots,N\}| = o((\log N)^2)$ (and matches the upstream `=o[atTop]`
  right-hand side). This is the affirmative of question 1 as asked. ✓
- Back-translation of `erdos_problem_32b` (lines 45–49): "there is an additive
  complement $A$ and a constant $C > 0$ with $|A \cap \{1,\ldots,N\}| \le C\log N$ for
  **all** $N \ge 1$." The informal $O(\log N)$ is asymptotic; at $N = 1$, $\log 1 = 0$
  forces $|A \cap \{1\}| = 0$, i.e. $1 \notin A$ — an artificial boundary constraint.
  **Truth value is nonetheless preserved**: formal ⇒ informal trivially; informal ⇒
  formal by replacing a witness $A$ with $A + 2 = \{a+2\}$, which is still a complement
  (for large $n$, $n-2 = p+a$ gives $n = p+(a+2)$), has
  $|(A{+}2) \cap \{1,\ldots,N\}| \le |A \cap \{1,\ldots,N\}| + 1$, contains no element
  $< 2$ (so the $N=1$ clause holds with count 0), and on the finitely many
  $2 \le N < N_0$ the bound is absorbed into $C$ since $\log N \ge \log 2 > 0$.
  Classified [polish], not [defect]; v2 restates it eventually (`∃ N₀`), matching the
  upstream `=O[atTop]`.
- **Question 3 is absent** — no theorem, no docstring mention, no omission note. The
  file's own docstrings label 32a/32b "first part"/"second part" style ("second part" is
  explicit at line 38) yet stop at two. Per checklist B2 this is a *missing part of the
  problem*, i.e. a **[defect]** (it is the one part that is actually solved, by Ruzsa).
  Fixed in v2 as `erdos_problem_32c`.
- ℕ-membership nuance: `Set ℕ` admits $0 \in A$, which the counting function ignores
  (`Icc 1 N`) but the representation clause can use ($n = p + 0$ covers primes). This
  matches the upstream encoding exactly. It does not shift any truth value: for the
  existential parts, a witness can be shifted off 0 as above; for the universal part
  (Q3), Ruzsa's lower-bound argument targets highly divisible (composite) integers, so
  discarding the prime targets that $a = 0$ can cover leaves the bound intact (and the
  formal statement quantifies over a slightly *larger* class of $A$, which is the safe
  direction for a "must"-question only insofar as the theorem still holds — it does).
  Noted, no change.
- Not vacuous/trivial: `IsAdditiveComplement` is satisfiable ($A = \mathbb{N}$), but no
  degenerate witness meets the counting bounds ($A = \mathbb{N}$ has count $N$); Ruzsa's
  $e^\gamma$ bound shows the o((log N)²) question lives in the narrow window
  $[\,e^\gamma \log N,\ o((\log N)^2)\,]$ — substantive open content. ✓
