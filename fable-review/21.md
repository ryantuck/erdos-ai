## Summary

The problem (PROVED, $500): let f(n) be minimal such that there is an
intersecting family 𝓕 of n-element sets (A ∩ B ≠ ∅ for all A, B ∈ 𝓕) with
|𝓕| = f(n) such that any set S with |S| ≤ n−1 is disjoint from at least one
A ∈ 𝓕; is it true that f(n) ≪ n? Conjectured by Erdős–Lovász, solved
affirmatively by Kahn (1994). The Lean file defines the intersecting-family
predicate, the covering predicate, f(n) via `sInf` over achievable family
cardinalities, and asserts ∃ C > 0, ∃ N, ∀ n ≥ N, f(n) ≤ C·n — the proved
"yes" direction of the question, in this corpus's direct-assertion
convention, with the correct polarity. Read back independently, the Lean and
the recovered source statement agree exactly (including the ground-set-ℕ and
eventual-form encodings, both equivalence-checked by hand); I found no
semantic defects, only scholarship/documentation nits, all addressed in
`conjectures-v2/21.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $f(n)$ be minimal
  such that there is an intersecting family $\mathcal{F}$ of sets of size $n$
  (so $A\cap B\neq\emptyset$ for all $A,B\in \mathcal{F}$) with
  $\lvert \mathcal{F}\rvert=f(n)$ such that any set $S$ with
  $\lvert S\rvert \leq n-1$ is disjoint from at least one
  $A\in \mathcal{F}$. Is it true that $f(n) \ll n$?"
- Independent back-translation of lines 39–42: "there is a real C > 0 and a
  threshold N such that for all n ≥ N, the minimum size of an intersecting
  family of n-sets covering all small sets is at most C·n." This is exactly
  "f(n) ≪ n", the proved answer to the question asked.
- **Eventual vs global ≪:** the source's f(n) ≪ n means f(n) ≤ Cn with an
  absolute constant over the whole domain (n ≥ 1); the file's ∃N eventual
  form is equivalent, since f is ℕ-valued and everywhere finite: any
  eventual witness (C, N) extends to a global one by
  C' = max(C, max₁≤n<N f(n)/n). Checked term-by-term, not just "in the
  limit". (At n = 0 the junk value f(0) = 0 — see A2 — even satisfies
  f(0) ≤ C·0, so every choice of N works, including N = 0.)
- **Ground set ℕ:** the source's family members and the covered sets S are
  abstract finite sets; the file fixes ground set ℕ for members and
  quantifies `CoversAllSmallSets` over all finite S ⊆ ℕ. No loss either
  way: any finite family embeds in ℕ, and for an abstract small S only
  S ∩ ⋃F matters (an A ∈ F ⊆ Finset ℕ disjoint from S ∩ ⋃F is disjoint
  from S), so ℕ-quantification of S is equivalent to abstract
  quantification. Verified in both directions.
- **`sInf` = the source's minimal f(n):** the feasible set of cardinalities
  {k | ∃F, |F| = k ∧ …} is nonempty for every n ≥ 1 — witness: all
  n-subsets of a fixed (2n−1)-element set (pairwise intersecting since two
  n-subsets of a (2n−1)-set must meet; any S with |S| ≤ n−1 leaves ≥ n
  points free, hence misses some member) — so `sInf` is a genuine minimum,
  matching "f(n) minimal such that there is a family with |𝓕| = f(n)".
- Not vacuous/trivial: k = 0 (F = ∅) is infeasible for n ≥ 1 (S = ∅ has
  card 0 ≤ n−1 and needs a witness member), singletons fail for n ≥ 2
  (S = {s} for s ∈ A meets the only member), and the statement asserts
  Kahn's genuine theorem. Spot-checked against the def: f(1) = 1 (F = {{x}})
  and f(2) = 3 (the triangle {a,b},{b,c},{a,c}; two 2-sets always share a
  point that a singleton S can hit) — both match the page's trivial values.

**A2. Lean semantics traps — pass.**

- **ℕ subtraction** `n - 1` in `CoversAllSmallSets` (line 18): for n ≥ 1
  exact; at n = 0 it truncates to 0, so S = ∅ still requires a witness in F
  while `IsIntersectingNFamily F 0` forces F = ∅ ((∅ ∩ ∅).Nonempty is false
  for the A = B pair, and card-0 members are ∅). Hence no family qualifies
  at n = 0, the feasible set is empty, and `Nat.sInf ∅ = 0` gives the junk
  value f(0) = 0 — invisible to the eventual statement (and even
  truth-preserving under N = 0, per A1). Documented in v2.
- **Division:** `8 / 3` occurs only in the *docstring* mathematics of the
  input (no code division anywhere); the v2 lower-bound variant writes
  `(8 / 3 : ℝ)`, which is real division, exact. No ℕ division in code.
- No `Finset.range`, no filters/liminf/limsup, no `StrictMono`/`Monotone`,
  no open/closed interval issues.
- Vacuous quantifiers: the A = B case of the pair condition is harmless for
  n ≥ 1 (self-intersection is automatic for nonempty members) and
  load-bearing only at n = 0, as analyzed above; both members' conditions
  are vacuously true for F = ∅, which correctly leaves the covering
  condition to rule ∅ out.
- Cast placement: `(erdosLovaszF n : ℝ) ≤ C * n` compares in ℝ with C : ℝ
  and n coerced — the intended arithmetic; no truncation.

   `sInf`-well-definedness in "the feasible set is nonempty for n ≥ 1, as
   demonstrated by the Erdős–Lovász upper bound constructions" — but the
   page states those constructions assume n − 1 is a prime power, so they

   pair (∅ ∩ ∅).Nonempty is false, so |F| = 1 is not vacuous. Its
   conclusion `erdosLovaszF 0 = sInf ∅ = 0` is nevertheless correct.
4. **Checked and confirmed:** its A = B harmlessness note, the
   ground-set-ℕ no-loss-of-generality argument, the "C > 0 is technically
