## Summary

The problem: let $k \geq 5$ and let $\mathcal{F}_k$ be the family of all 3-uniform
hypergraphs with $k$ vertices and $k-2$ edges; is it true that
$\mathrm{ex}_3(n, \mathcal{F}_k) \sim n^2/6$? A question of Brown–Erdős–Sós [BES73], who
proved the case $k = 4$ and that $\mathrm{ex}_3(n,\mathcal{F}_k) \asymp_k n^2$ for
$k \geq 4$; the asked asymptotic was proved independently by Bohman–Warnke [BoWa19] and
Glock–Kühn–Lo–Osthus [GKLO20], so the page banner is **PROVED** ("solved in the
affirmative"). The Lean file (`deepmind/1076.lean`) defines 3-uniform hypergraphs on
`Fin n`, embedding-based subhypergraph containment, the family
`familyF k = {G | G.edges.card = k - 2}`, freeness, and `ex3` via `sSup`, and states
`answer(True) ↔ ∀ k ≥ 5, ∀ ε > 0, ∃ N₀, ∀ n ≥ N₀, (1-ε)n²/6 ≤ ex3 n k ≤ (1+ε)n²/6`.
Read back independently, the Lean and the recovered source agree; I found no semantic
defects in the main theorem, only enrichment-level items (now applied, see Addendum).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement: "Let $k\geq 5$ and let $\mathcal{F}_k$ be the
  family of all $3$-uniform hypergraphs with $k$ vertices and $k-2$ edges. Is it true
  that $\mathrm{ex}_3(n,\mathcal{F}_k)\sim \frac{n^2}{6}$?"
- Independent back-translation of `deepmind/1076.lean:100–105`: "the answer is yes iff
  for every $k \geq 5$ and every $\varepsilon > 0$ there is $N_0$ such that for all
  $n \geq N_0$, $(1-\varepsilon)n^2/6 \leq \mathrm{ex}_3(n,\mathcal{F}_k) \leq
  (1+\varepsilon)n^2/6$." The inner formula is the standard unfolding of
  $f(n) \sim n^2/6$; the outer $\forall k$ matches the source's "Let $k \geq 5$" scoping
  (the question is asked for every such $k$). $N_0$ may depend on $k$ and $\varepsilon$
  — correct, since the source's asymptotic is per-$k$.
- **Freeness encoding (the crux).** The file uses *embedding-based* freeness (`ex3` via
  `IsSubhypergraph`, an injection `Fin k → Fin n` carrying edges to edges), whereas the
  BES literature (and sibling `deepmind/1157.lean`) uses the *configuration* notion "no
  $k$ vertices span $\geq k-2$ edges". I re-derived their equivalence from scratch:
  (i) if some $k$-set $S$ spans $\geq k-2$ edges, pick exactly $k-2$ of them and pull
  back along a bijection `Fin k ≃ S` — preimages of 3-sets under a bijection are 3-sets,
  distinct edges pull back to distinct edges, so this is a member of `familyF k`
  embedding via the bijection; (ii) conversely, if `G ∈ familyF k` embeds via injective
  $f$, then `Finset.image f` is injective on edge-sets, so the $k-2$ distinct edges of
  $G$ map to $k-2$ distinct edges of $H$ all contained in the $k$-set $f(\mathrm{Fin}\,
  k)$, which therefore spans $\geq k-2$ edges. Members of `familyF k` whose edges do not
  cover all $k$ vertices (isolated vertices) change nothing: their images still lie
  inside the $k$-element image set. Boundary case $n < k$: no injection exists, so every
  $H$ is free — and the configuration condition `∀ S, S.card = k → …` is vacuous too;
  the two notions agree for *all* $n$, and small $n$ is invisible to the limit anyway.
- Types: `ℕ` for combinatorics, `ℝ` for the asymptotic inequalities with casts
  `(ex3 n k : ℝ)` and `((n : ℝ)^2 / 6)` placed so all arithmetic is real. Correct.
- Not vacuous: `familyF k` is nonempty for $k \geq 5$ (indeed $\binom{k}{3} \geq k-2$),
  so freeness is a genuine constraint; `ex3` is a genuine extremal function (the empty
  hypergraph is free, $\binom{n}{3}$ bounds edge counts), so the two-sided asymptotic is
  a substantive claim.

**A2. Lean semantics traps — pass.**

- ℕ subtraction: `k - 2` in `familyF` truncates for $k < 2$, but every use in the file
  has $k \geq 4$; harmless. (The new variant's `n - 1` sits under a guard $n \geq 5$.)
- Division: `(n : ℝ)^2 / 6` is real division by a nonzero literal; no ℕ division occurs.
- No `Finset.range` is used; `∃ N₀, ∀ n ≥ N₀` is the standard eventually-form, with no
  off-by-one exposure.
- Vacuous quantifiers: for $n < k$ the freeness predicate is vacuously true and
  `ex3 n k = C(n,3)` (all hypergraphs free); finitely many $n$, invisible to the limit,
  and consistent with the configuration reading (see A1). For $\varepsilon \geq 1$ the
  lower bound is vacuous (LHS $\leq 0$) — standard and harmless.
- `sSup` on ℕ: the set `{m | ∃ H, IsFkFree k H ∧ H.edges.card = m}` is nonempty
  (contains 0 via the empty hypergraph — members of `familyF k` have $k-2 \geq 2$ edges
  for $k \geq 4$, none of which can map into an edgeless host) and bounded above (edge
  counts live in the finite type `Finset (Finset (Fin n))`), so `sSup` is the true
  maximum, not a junk value.
- The $\forall \varepsilon\,\exists N_0\,\forall n$ encoding of $\sim$ is exactly
  $\lim \mathrm{ex}_3(n,\mathcal{F}_k)/(n^2/6) = 1$; no `StrictMono`/interval issues
  arise.

## E. Prior-review audit (`ai-review/1076.md`)

Its central correctness analysis (§6) reaches the right conclusion — the embedding-based
and configuration-based freeness notions are equivalent — and its equivalence sketch
(injectivity of `Finset.image` under injective $f$; padding a dense sub-configuration to
$k$ vertices) is sound. I re-derived both directions independently (A1) and they check
out. Findings:

1. **Internally inconsistent framing.** §1's verdict line says reuse of 1157 is
   "blocked by a correctness concern", §6's header announces "There is a potential
   correctness issue" and bolds "These two definitions are not equivalent in general" —
   and then the same section proves they *are* equivalent, with visible mid-paragraph
   self-reversals ("Wait — actually…"). The summary table repeats "blocked by apparent
   (but ultimately non-) discrepancy". Nothing is mathematically wrong at the end, but
   the document asserts a discrepancy it then refutes — the invent-then-excuse pattern
   flagged in the 1000/1005 audits, here in mirror image (invent-then-retract). A reader
   skimming the headers would take away a defect that does not exist.
2. **Boundary case unexamined.** Its equivalence argument tacitly assumes $n \geq k$
   (an "identity-like injection on $S$" needs $k$ host vertices). For $n < k$ both
   notions are vacuously free, so the conclusion stands, but the case is never
   mentioned — the same class of gap as 1005's unexamined small-$n$ `sSup` behavior,
   which here happens to be benign.
3. **Missed the question-form defect it was positioned to catch.** §6 verifies
   `answer(True)` "matches the website" — but the file state it reviewed (matching
   `conjectures/1076.lean`) had *no* `answer()` wrapper and binder-level quantifiers; it
   audited an annotation that did not yet exist in that form and never flagged the
   direct-assertion encoding of a yes/no question. That defect was instead caught by the
   style review (`reviews/1076.md` §6, correctly) and fixed in `deepmind/1076.lean`
   before this review; nothing it flagged remains unfixed.
4. **Citation claims verified.** Its report that [Er74c] was missing and
   [BoWa19]/[GKLO20] lacked titles was accurate for the raw file and has since been
   fully remedied in `deepmind/1076.lean` (verified against the log-recovered `/latex`
   extraction). Its suggested enrichments (#207 cross-reference, $k=4$ lemma, exact-
   value remark, #1157 relationship) were valid and are now applied (Addendum).
5. **Correct minor claims spot-checked:** `sSup` well-definedness reasoning (bounded by
   $\binom{n}{3}$, contains 0) is right; the quantifier-structure and asymptotic-formula
   endorsements are right.
