## Summary

The problem (a question of Grunsky, reported in Erdős–Herzog–Piranian [EHP58, p.145]):
let $f \in \mathbb{C}[x]$ be monic with $m$ distinct roots and let $c > 0$ be small
enough that $\{z : |f(z)| \le c\}$ has $m$ distinct connected components — must all
these components be convex? The answer is **no** (Pommerenke [Po61]; page status
DISPROVED (LEAN)). The Lean statement (`deepmind/1047.lean`, theorem `erdos_1047`)
encodes this as `answer(False) ↔ ∀ f monic, ∀ c > 0, (#components of S = #distinct
roots) → every component of S is convex`, with $S = \{z : \|f(z)\| \le c\}$ and
components counted via `ncard (connectedComponentIn S '' S)`. Read back independently,
the RHS is the question as asked and `answer(False)` asserts its negation — exactly
Pommerenke's theorem. I found no semantic defects; only polish-level items.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $f\in \mathbb{C}[x]$ be a
  monic polynomial with $m$ distinct roots, and let $c>0$ be a constant small enough
  such that $\{ z: \lvert f(z)\rvert\leq c\}$ has $m$ distinct connected components.
  Must all these components be convex?" The module docstring reproduces this essentially
  verbatim.
- Independent back-translation of the theorem RHS: "for every monic $f \in \mathbb{C}[x]$
  and every $c > 0$ such that the closed sublevel set $S = \{z : \|f(z)\| \le c\}$ has
  exactly as many connected components as $f$ has distinct roots, every connected
  component of $S$ is convex." This is the universal closure of the question as asked.
  The English "let $c$ be small enough such that [S] has $m$ components" is faithfully
  rendered by conditioning on the property itself (# components $= m$) — the precise
  content of "small enough", since a closed sublevel set of a monic polynomial with $m$
  distinct roots has between 1 and $m$ components (each component contains a root, by
  the minimum modulus principle: a root-free component would contain a positive local
  minimum of $|f|$, impossible for non-constant $f$; degenerate constant $f$ handled
  below).
- `connectedComponentIn S x` (Mathlib) is the connected component of `x` inside `S` for
  `x ∈ S`; the image `connectedComponentIn S '' S` is precisely the set of connected
  components of `S` (deduplicated by set equality), and its `ncard` counts them. Since a
  polynomial closed sublevel set has finitely many components (≤ number of roots, per
  the argument above), `Set.ncard`'s junk value 0 on infinite sets is never triggered on
  instances that satisfy the hypothesis in a spurious way (checked explicitly below).
- Types: `Polynomial ℂ`, `c : ℝ`, `‖·‖` on ℂ = complex modulus, `Convex ℝ` on subsets
  of ℂ (ℂ as real vector space) — all appropriate. Closed sublevel `≤ c` matches the
  source's $\le$.
- `f.roots.toFinset.card`: over the algebraically closed field ℂ with `f` monic (hence
  ≠ 0), `f.roots` is the root multiset with multiplicity and `.toFinset.card` is the
  number of *distinct* roots — exactly $m$. Multiple roots are permitted, as they must
  be (Pommerenke's counterexample $z^k(z-a)$ has a root of multiplicity $k$).
- No indexing conventions arise.
- Not vacuous / not spuriously false. Two directions checked:
  (i) The RHS is not trivially *false* for a degenerate reason (which would make the
  theorem provable without any real mathematics): the only degenerate instances are
  constant monic $f = 1$ ($m = 0$ distinct roots). For $c < 1$, $S = \emptyset$: the
  hypothesis `ncard ∅ = 0` holds but the conclusion is vacuously true — no spurious
  counterexample. For $c \ge 1$, $S = \mathbb{C}$: 1 component ≠ 0 roots, hypothesis
  fails. Every instance that can violate the conclusion is a genuine instance of
  Grunsky's question, so `¬RHS` is exactly Pommerenke's theorem.
  (ii) The RHS is not trivially *true*: the hypothesis is satisfiable non-vacuously
  (e.g. $f = X$, any $c > 0$: $S$ is a disk, 1 component, 1 root).

**A2. Lean semantics traps — pass.**

  as shown.
- Strict vs non-strict: `≤ c` matches the source's closed sublevel set. (Goodman's

**A4. Question form and answer polarity — pass.**

  `answer(…) ↔ P` shape is required, with `P` the question as asked (the universal

- Polarity by hand: `answer(False) ↔ P` asserts `¬P`, i.e. some monic $f$ and valid

- No binders before the colon (`theorem erdos_1047 : answer(False) ↔ …` is

## E. Prior-review audit (`ai-review/1047.md`)

sublevel set, component counting, distinct-root count, real convexity, quantifier

recovered page. Findings:

1. **No degenerate-case analysis.** The review asserts `Set.ncard (connectedComponentIn

   pattern (unexamined small/degenerate cases behind a confident "correct") flagged in
   the 1000 and 1005 audits. Here, unlike 1005's `sSup` case, no false sub-claim is
   made, so this is an omission, not an error.

   incomplete: the recovered banner is DISPROVED **(LEAN)** — solved in the negative
   *with the proof verified in Lean*. The distinction matters for the category tag
   discussion (cf. fable-review/1000's PROVED (LEAN) finding). Now recorded in the
   module docstring.

**Referee-example constant caveat.** The page's LaTeX reads `$5.6^{-6/5}$`, which can
be parsed as the decimal $5.6$ to the power $-6/5$ ($\approx 0.127$) or as
$5 \cdot 6^{-6/5}$ ($\approx 0.583$). The critical points of $f(z) = z(z^5-1)$ satisfy
$6z^5 = 1$, giving $|z| = 6^{-1/5}$, $z^5 = 1/6$, and critical value
$|f| = |z|\,\lvert z^5 - 1\rvert = 6^{-1/5} \cdot \tfrac56 = 5 \cdot 6^{-6/5}$ —
exactly the second reading, which is therefore almost certainly
intended (components of the strict sublevel set at the critical value: one per each of
the 6 simple roots, maximally bulged). Because the rendering is ambiguous on the page,
the example was documented in the module docstring (with this caveat) but **not**
formalized as a variant.
