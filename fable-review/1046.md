## Summary

The problem (verbatim from the recovered page): "Let $f\in \mathbb{C}[x]$ be a monic
polynomial and $E=\{ z: \lvert f(z)\rvert <1\}$. If $E$ is connected then is $E$
contained in a disc of radius $2$?" The answer is yes — Pommerenke proved $E$ lies in
the closed disc of radius $2$ centred at the centroid of the roots — while the
companion Erdős–Herzog–Piranian conjecture that the *width* of
$\{z : |f(z)| \le 1\}$ is always at most $2$ was disproved by Pommerenke (example with
width $> \sqrt{3}\,2^{1/3} \approx 2.18$). The Lean file encodes the main question as
`answer(True) ↔ ∀ f, f.Monic → IsConnected E → ∃ c, E ⊆ closedBall c 2`, plus a
centroid strengthening and an `answer(False)` width variant. The main theorem and the
centroid variant are faithful. The width variant, pre-fix, was trivially false via the
degenerate monic constant $f = 1$ (whose closed sublevel set is all of $\mathbb{C}$:
connected, infinite width), so its `answer(False)` held for a reason unrelated to
Pommerenke — a Part A defect, fixed by adding `0 < f.natDegree`. Separately, the
`[Po59]` bibliography entry carried fabricated data (wrong title, journal, volume,
pages), corrected against the recovered `/latex/1046` bibliography.

## A. Semantic fidelity

**A1. Statement fidelity — main theorem and centroid pass (source-verified); width
variant DEFECT (fixed).**

- Independent back-translation of `erdos_1046` (line 68 post-fix): "for every monic
  $f \in \mathbb{C}[x]$, if $\{z : |f(z)| < 1\}$ is connected then it is contained in
  some closed ball of radius 2." This is exactly the question as asked. The strict
  sublevel set (`< 1`) matches the source's $\lvert f(z)\rvert < 1$; the *closed*
  sublevel set (`≤ 1`) is correctly reserved for the width variant, matching the
  page's $\lvert f(z)\rvert \le 1$ — the two remarks in the source use different
  sublevel sets and the file preserves the distinction.
- "Disc of radius 2" → `closedBall c 2` with existential centre: faithful. (Closed vs
  open disc is immaterial here in the benign direction: Pommerenke proved containment
  in the *closed* disc of radius 2 about the centroid, and that radius is sharp — for
  monic Chebyshev-type polynomials the connected sublevel set has diameter approaching
  4 — so the closed-ball form is the true statement; see also Part E item 3.)
- Degenerate inputs, main theorem: the only monic polynomial of degree 0 is $f = 1$,
  for which $E = \{z : \|1\| < 1\} = \emptyset$; Mathlib's `IsConnected` requires
  nonemptiness, so the hypothesis fails and the case is vacuous — matching the
  problem's intent. For $\deg f \ge 1$, $E$ is a nonempty open bounded set (it
  contains the roots), so the statement is a substantive theorem, not vacuous.
- `erdos_1046.variants.centroid` (line 81): $E \subseteq$
  `closedBall (f.roots.sum / (f.natDegree : ℂ)) 2`. Over $\mathbb{C}$, `f.roots` is
  the multiset of roots with multiplicity and has cardinality `natDegree` for monic
  $f$, so `f.roots.sum / natDegree` is exactly $\frac{z_1+\cdots+z_n}{n}$ as on the
  page. Degenerate $f = 1$: `natDegree = 0` gives the junk value $0/0 = 0$ in ℂ, but
  the `IsConnected ∅` hypothesis is false, so no harm.
- **[defect] `erdos_1046_width` (pre-fix, lines 78–84).** RHS was
  $\forall f$ monic, $\{z : |f(z)| \le 1\}$ connected $\to \exists$ unit $u$ with
  $|\operatorname{Re}((z_1-z_2)\bar u)| \le 2$ on the set. Take the degenerate monic
  constant $f = 1$: then $\{z : \|1\| \le 1\} = \mathbb{C}$ (note $\le$, unlike the
  main theorem's $<$), which **is** connected, and for any unit $u$ the pair
  $z_1 = 3u$, $z_2 = 0$ gives $\operatorname{Re}(3u\bar u) = 3 > 2$. So the universal
  statement was false because of $f = 1$ alone, and `answer(False)` held trivially —
  the statement did not encode the Erdős–Herzog–Piranian conjecture or Pommerenke's
  disproof at all. This is precisely the A1 "trivially false via a degenerate witness"
  failure mode. **Fixed** by adding the hypothesis `0 < f.natDegree` (and documenting
  why in the docstring). With the fix, the RHS is falsified by Pommerenke's genuine
  counterexample and by nothing degenerate; polarity `answer(False)` is unchanged and
  now meaningful. Not compile-verified.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no ℕ division. The only division is `f.roots.sum / (f.natDegree : ℂ)`
  in ℂ; division by zero occurs only at `natDegree = 0`, where the statement is
  vacuous (see A1), and ℂ's junk-value convention is harmless there.
- No `Finset.range`, no indexing at all — no off-by-one surface.
- Vacuous-hypothesis behavior at degree 0 checked per statement (A1): benign for the
  main theorem and centroid (empty set not connected), *not* benign for the width
  variant pre-fix (whole plane connected) — the asymmetry between `< 1` and `≤ 1` at
  $f = 1$ is exactly what the prior reviews missed.
- The `∃ u, ‖u‖ = 1 ∧ …` width encoding vs the infimum definition of width: for
  $\deg f \ge 1$ the set $\{z : |f(z)| \le 1\}$ is compact (closed by continuity,
  bounded since $|f(z)| \to \infty$), the directional extent
  $u \mapsto \sup_{z_1,z_2} \operatorname{Re}((z_1-z_2)\bar u)$ is Lipschitz on the
  compact unit circle, so the infimum is attained and "width $\le 2$" is equivalent to
  the existential form. Faithful (and now documented in the docstring). Non-strict
  $\le 2$ matches "at most 2".
- `starRingEnd ℂ u` is complex conjugation; $\operatorname{Re}((z_1-z_2)\bar u)$ is
  the signed projection onto direction $u$ — the correct width functional.
- `IsConnected` (connected **and** nonempty) is the right notion here; strictness of
  inequalities and open/closed sublevel sets all reconciled above.

## E. Prior-review audit (`ai-review/1046.md`)

The prior review is right about the main theorem but wrong or blind in three places:

1. **Endorsed fabricated bibliographic data as "matching the website."** Its Citations
   section reproduces the file's "*Über die Kapazität ebener Kontinuen*, Math. Ann.
   139 (1959), 64–75" and asserts "The website lists the same two references … The
   citations match." Only the *keys* match; the site's actual `[Po59]` bibliography
   entry (recoverable — it sat in the fix session's own log) is a different paper in a
   different journal with different pages. This is the recurring prior-review failure
   class of claiming external agreement that was never checked (cf. the 1001 pattern
   "claiming data is unavailable that is in fact recoverable" — here worse: claiming a
   match against data that refutes the match).
2. **Edge-case analysis stopped one theorem too early.** Its "Edge cases" paragraph
   correctly notes that for $f = 1$ the *strict* sublevel set is empty and
   `IsConnected ∅` is false — sound for the main theorem it reviewed. But its own
   Variants section proposed the width variant over the *closed* sublevel set without
   observing that the identical degenerate input flips from harmless
   ($E = \emptyset$) to fatal ($E = \mathbb{C}$, connected, infinite width). The
   variant was then added upstream exactly as proposed, defect included, and no
   subsequent review caught it. The A1 defect in this review is the direct descendant
   of that omission.
3. **Backwards strength claim.** "The formalization uses `closedBall` (closed disc),
   which is the stronger statement" — containment in a closed disc is the *weaker*
   containment (every set inside the open ball is inside the closed ball). The
   conclusion that the encoding is fine survives — Pommerenke's theorem is the
   closed-disc containment, and radius 2 is sharp so the open-disc form would be
   false in the limit-degree sense — but the stated justification is inverted; same
   invent-a-reason pattern as the 1000/1005 audits.
4. **Omission:** it never mentions the page's DISPROVED banner or reconciles it with
   `answer(True)` — even though the fetch extraction in its own session flagged the
   tension explicitly. What it got right: the `‖·‖ = |·|` observation on ℂ, the
   `answer(True)` polarity, the reuse and `let`-binding suggestions (both adopted
   upstream), and the three variant suggestions (two adopted).
