## Summary

The problem (OPEN): let $F(n)$ be maximal such that every graph on $n$ vertices contains
a regular induced subgraph on at least $F(n)$ vertices; prove that $F(n)/\log n \to
\infty$. Conjectured by Erdős, Fajtlowicz, and Staton. The Lean
(`conjectures/82.lean:30-37`) states the unfolded equivalent: for every $C > 0$ there is
$N$ such that for all $n \ge N$, every graph $G$ on `Fin n` has a vertex set $S$ with
$|S| \ge C \log n$ on which $G$ induces a regular graph (every $v \in S$ has the same
number of $S$-neighbors). Read back independently, this is exactly $\forall C\,\exists
N\,\forall n \ge N:\ F(n) \ge C\log n$, which is equivalent to $F(n)/\log n \to \infty$
(proof of equivalence in A1 below). I found no semantic defects; only polish-level nits
and enrichment opportunities.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement: "Let $F(n)$ be maximal such that every graph on
  $n$ vertices contains a regular induced subgraph on at least $F(n)$ vertices. Prove
  that $F(n)/\log n\to \infty$."
- The file deliberately avoids defining $F$ (no `sSup`) and states the unfolded
  equivalent. Equivalence verified by hand, both directions:
  - Lean ⟹ source: fix $C$; for $n \ge \max(N, 2)$ every $G$ has a regular induced $S$
    with $|S| \ge C\log n$, so $k := \lceil C\log n\rceil$ is a valid guarantee for
    every $G$, hence $F(n) \ge C\log n$, hence $F(n)/\log n \ge C$ eventually. As $C$
    is arbitrary, $F(n)/\log n \to \infty$.
  - Source ⟹ Lean: the set of valid guarantees $k$ is downward closed and achieved at
    $F(n)$, so $F(n) \ge C\log n$ means every $G$ contains a regular induced subgraph
    on $\ge F(n) \ge C\log n$ vertices. Choose $N$ per $C$ from the limit.
  This avoids the `sSup`-junk pitfalls entirely (contrast the upstream formalization,
  which uses `sSup` — soundly, since valid $k \le n$; see A5/E notes). The quantifier
  order $\forall C\,\exists N$ (N depending on C) is the correct encoding of $\to\infty$;
  the reversed order would be wrong, and no constant-absorption issue (problem-55 class)
  arises since there is no inner existential constant.
- Types: cardinality compared in ℝ (`(S.card : ℝ) ≥ C * Real.log n`), arithmetic all in
  ℝ. Appropriate.
- Indexing: no sequences; `Fin n` as vertex type matches "graph on $n$ vertices".
- Not vacuous/trivial: for $n \ge 2$, $C\log n > 0$ forces $S \ne \emptyset$, and
  regularity is a genuine constraint; the statement is the open conjecture. At $n \in
  \{0, 1\}$, `Real.log n = 0` and $S = \emptyset$ satisfies the instance trivially
  (empty $S$ is vacuously regular with any $d$), but these instances only make the
  ∀-statement *easier* at two indices that `∃ N` may skip anyway — no problem-20/80
  class vacuity: the statement's content lives at large $n$ and is not weakened.
  Smallest-parameter check by hand (problem-78 class): $C$ near 0 only weakens the bound;
  no boundary demand is created.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no ℕ division anywhere.
- `Real.log` at $n = 0$ (`log 0 = 0`) and $n = 1$: junk-free here — see A1; no
  division occurs at all (the docstring's $F(n)/\log n$ is unfolded away).
- No `Finset.range`; no off-by-one surface.
- Vacuous quantifier: `∀ v ∈ (∅ : Finset _), …` makes the empty set "regular" — analyzed
  in A1; harmless as placed (the cardinality constraint excludes ∅ whenever the bound is
  positive).
- No filters/liminf/limsup used (problem-33 class n/a); "for all sufficiently large $n$"
  is encoded by explicit `∃ N, ∀ n ≥ N`, which is correct and self-contained.
- No default-valued binders (problem-25 class n/a). Inequality `≥` vs `>` in
  `(S.card : ℝ) ≥ C * Real.log n` is immaterial for the $\to\infty$ encoding (apply with
  $2C$); non-strict matches "at least".

**A3. Definitions — pass.**

- `inducedDegree G S v = (S.filter (G.Adj v)).card` (line 13–14) is the number of
  $S$-vertices adjacent to $v$: exactly the degree of $v$ in the induced subgraph on
  $S$. `G.Adj v v` is false (irreflexivity), so $v$ never counts itself even when
  $v \in S$ — correct. Degenerate inputs: `inducedDegree G ∅ v = 0`; singleton $S$ gives
  degree 0, so singletons are 0-regular, consistent with $F(n) \ge 1$ — matches the
  informal notion.
- Regularity encoded as `∃ d, ∀ v ∈ S, inducedDegree G S v = d` — exactly "the induced
  subgraph is $d$-regular for some $d$".
- Small-case validation (problem-56/77/79 class): I brute-forced all graphs on
  $n \le 7$ vertices using this exact regularity notion (neighbors within $S$, self
  excluded) and got $F(1..7) = 1, 2, 2, 2, 3, 3, 4$ — reproducing the page's
  $F(5) = 3$, $F(7) = 4$. The encoding behaves correctly on small cases.
- No `sorry` in any definition.

**A4. Question form and answer polarity — pass.**

- The source is a direct assertion ("Prove that $F(n)/\log n \to \infty$"), so a bare
  proposition with a `sorry` proof is the right shape — no `answer()` wrapper needed in

- Polarity: asserted affirmatively, which is the conjectured (and open) direction — no
  problem-34/56/59-class mismatch; the docstring records no resolution, correctly.
- Binders: `theorem erdos_problem_82 :` is binder-free before the colon; all quantifiers
