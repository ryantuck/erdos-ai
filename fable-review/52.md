## Summary

The problem (recovered verbatim): "Let $A$ be a finite set of integers. Is it true
that for every $\epsilon>0$
$\max(\lvert A+A\rvert, \lvert AA\rvert) \gg_\epsilon \lvert A\rvert^{2-\epsilon}$?"
— the Erdős–Szemerédi sum-product conjecture, **OPEN**, $250 prize. The Lean
theorem (`conjectures/52.lean:35-40`) asserts: for every real $\epsilon > 0$ there
is $c > 0$ such that every `A : Finset ℤ` with $|A| \geq 2$ satisfies
$\max(|A+A|, |A \cdot A|) \geq c \cdot |A|^{2-\epsilon}$, with pointwise `Finset`
sumset/product set, ℝ-cast cardinalities, and a `Real.rpow` exponent. Read back
independently, this is exactly the standard unpacking of $\gg_\epsilon$ ($c$
depends on $\epsilon$ only), and it is classically equivalent to upstream
formal-conjectures' `answer(sorry) ↔ ∀ ε, 0 < ε → ε < 1 → ∃ C, 0 < C ∧ ∀ A, …`
(which uses an $\epsilon < 1$ restriction instead of a size guard to control the
degenerate cases). No semantic defects; scholarship and documentation nits only.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 36–39: "for every $\epsilon > 0$ there
  exists $c > 0$ such that every finite set of integers with at least 2 elements
  has $\max(|A+A|, |AA|) \geq c|A|^{2-\epsilon}$." The page's $\gg_\epsilon$ is
  Vinogradov notation whose standard reading is exactly this ∃-constant form, with
  the constant depending on $\epsilon$ alone. The quantifier order in the Lean
  ($\forall \epsilon\, \exists c\, \forall A$) puts $c$ before $A$ — correct; a
  $\forall A\, \exists c$ reading would have been vacuous (any single $A$ admits
  some $c$).
- Types: `Finset ℤ` for "finite set of integers"; cardinalities cast to ℝ before
  comparison; the exponent $2 - \epsilon$ is computed in ℝ (no ℕ subtraction), and
  `(A.card : ℝ) ^ (2 - ε)` elaborates to `Real.rpow` under the
  `Mathlib.Analysis.SpecialFunctions.Pow.Real` import. `A + A` / `A * A` under
  `open scoped Pointwise` are Mathlib's `image₂`-based sumset and product set,
  including self-sums $a+a$ / self-products $a \cdot a$ — the standard convention
  the page intends.
- **The $|A| \geq 2$ guard (not in the source) is sound and in fact necessary as
  quantified.** The source has no size restriction, but the Lean quantifies
  $\epsilon$ over all of $(0,\infty)$, and without the guard the statement is
  *literally false*: at $\epsilon = 2$ the exponent is $0$, `Real.rpow 0 0 = 1`,
  so $A = \emptyset$ gives LHS $= 0 < c \cdot 1 =$ RHS. (For every
  $\epsilon \neq 2$, $\emptyset$ and singletons are harmless.) With the guard the
  statement is classically equivalent to the conjecture: given the guarded form
  with constant $c$, the constant $\min(c,1)$ handles $|A| \leq 1$ for
  $\epsilon < 2$; and the guarded form for $\epsilon \geq 1$ follows from the
  $\epsilon = 1/2$ case by `rpow` monotonicity in the exponent (base $\geq 2$).
  Upstream avoids the same trap differently, restricting to $\epsilon < 1$ with no
  guard; the two encodings are equivalent (proof sketch recorded in the v2
  theorem docstring). Not a defect — but the guard's load-bearing nature deserved
  documentation (nit, fixed).
- Not vacuous, not trivial: sets with $|A| \geq 2$ abound; a uniform $c$ must tame
  the growing $|A|^{2-\epsilon}$, so no small-$c$ cheese exists (unlike a
  per-$A$ constant). For $\epsilon \geq 2$ the statement is trivially true
  ($|A|^{2-\epsilon} \leq 1 \leq |A| \leq |A+A| = $ LHS bound with $c = 1$), which
  matches the informal statement's content living at small $\epsilon$.

## E. Prior-review audit (`deepmind/ai-review/52.md`)

Written against the styled `deepmind/deepmind/52.lean` (same mathematical
content). Mostly sound on quantifiers and pointwise semantics; four findings:

1. **False claim about the guard, invented-then-excused class.** §6 asserts "the
   guard is not strictly necessary for the conjecture's truth value", arguing
   $0^{2-\epsilon} = 0$ "for $\epsilon < 2$ (which is the interesting range)".
   The theorem quantifies over **all** $\epsilon > 0$, and at exactly
   $\epsilon = 2$, `Real.rpow 0 0 = 1`, so the unguarded statement is *false*
   ($A = \emptyset$ forces $0 \geq c$). Restricting attention to "the interesting
   range" mid-proof is precisely the fabricated-justification pattern flagged in
   the 1000/1005 audits; here it flips the conclusion — the guard (or upstream's
   $\epsilon < 1$ restriction) is strictly necessary. The review's operational
   verdict (guard fine to keep) survives; its reasoning does not.
2. **Endorsed a fabricated citation title as "Correct".** §2's table lists
   "[Bl25] — 'New bounds on the sum-product problem'" and marks it "**Correct.**
   Matches docstring." The check was circular (docstring against docstring): the
   authoritative `/latex/52` extraction gives the title _Control and its
   applications in additive combinatorics_ (arXiv:2501.09470); the styled file
   was later corrected accordingly (FIX_REVIEW_ISSUES pass, logged commit
   ca19e9b7). The raw input under review never carried a [Bl25] title, so
   nothing needed fixing here, but the prior review's verification claim was
   hollow.
3. **Broken variant sketch.** §3's proposed higher-fold Lean uses
   `Finset.replicate` — no such function exists — and even granting a
   `Finset`-valued replicate, `{A, A, …, A}` deduplicates to `{A}`, so the
   proposed `Finset.sum … id` would collapse to `A` rather than the $m$-fold
   sumset; the exponent `m - ε` would also need a cast (ℕ minus ℝ does not
   elaborate). The sketch was hedged ("would need care") but is wrong as
   written, and the *right* care — the `m • A` `smulFinset`-vs-nsmul instance
   hazard — goes unmentioned (see B2).
4. **Minor.** §1 attributes the `Finset` pointwise operations to
   `Mathlib.Algebra.Group.Pointwise.Set.Basic` — that is the `Set` file; the
   `Finset` operations live in `Mathlib.Algebra.Group.Pointwise.Finset.Basic`
   (the import the file actually uses).

What it got right (re-derived): the $\forall\epsilon\,\exists c\,\forall A$
dependency analysis; self-sums included in `A + A` matching convention; the
$\epsilon \geq 2$ triviality analysis for guarded sets; status/prize/tags against
