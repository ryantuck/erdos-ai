## Summary

The problem: let $f$ map each pair of elements of $\{1,\ldots,n\}$ to an element of
$\{1,\ldots,n\}$ with $f(x,y) \neq x$ and $f(x,y) \neq y$; call $X$ independent if
$x, y \in X$ implies $f(x,y) \notin X$; let $g(n)$ be the largest quantity such that
every such $f$ admits an independent set of size $\geq g(n)$; estimate $g(n)$. The page
status is SOLVED ("resolved in some other way than a proof or disproof"):
Erdős–Hajnal [ErHa58] proved $n^{1/3} \ll g(n) \ll (n\log n)^{1/2}$, Spencer [Sp72]
proved $g(n) \gg n^{1/2}$, Conlon–Fox–Sudakov [CFS16] proved $g(n) \ll n^{1/2}$, so
$g(n) = \Theta(\sqrt n)$. The Lean file defines validity and independence for
`f : Fin n → Fin n → Fin n` and states the two halves as direct assertions: a universal
lower bound `∃ C > 0, ∀ n, ∀ valid f, ∃ independent S, |S| ≥ C√n` (`erdos_1025`) and an
existential upper bound with threshold `n₀` (`erdos_1025.variants.upper_bound`). Read
back independently, both agree with the source modulo one deliberate modeling choice —
ordered rather than unordered pairs — which is sound for the lower bound and true-but-
slightly-weaker for the upper bound (see A1); no [defect]-class findings.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified), one modeling note.**

- Recovered verbatim source statement (see Addendum): "Let $f$ be a function from all
  pairs of elements in $\{1,\ldots,n\}$ to $\{1,\ldots,n\}$ such that $f(x,y)\neq x$ and
  $\neq y$ for all $x,y$. We call $X\subseteq \{1,\ldots,n\}$ independent if whenever
  $x,y\in X$ we have $f(x,y)\not\in X$. Let $g(n)$ be such that, in every function $f$,
  there is an independent set of size at least $g(n)$. Estimate $g(n)$." The module
  docstring reproduces this essentially verbatim (page says "who could prove"; docstring
  "who proved" — no meaning change).
- Independent back-translation of `erdos_1025` (lines 78–83 post-fix): "there is an
  absolute $C > 0$ such that for every $n$ and every pair function $f$ with
  $f(x,y) \notin \{x,y\}$ for distinct $x,y$, some $f$-independent finite set has
  $|S| \geq C\sqrt n$" — exactly "$g(n) \gg \sqrt n$" (Spencer). Back-translation of the
  upper-bound variant: "there are $C > 0$ and $n_0$ such that every $n \geq n_0$ admits
  a valid $f$ all of whose independent sets have $|S| \leq C\sqrt n$" — exactly
  "$g(n) \ll \sqrt n$" (CFS16). Together: $g(n) = \Theta(\sqrt n)$, the full resolution.
- **Ordered vs unordered pairs.** The source's $f(x,y)$ is classically a set-mapping on
  2-element subsets (the [ErHa58] setting); the Lean `f : Fin n → Fin n → Fin n` takes
  ordered pairs, constrained and consulted only for $x \neq y$. Consequences, derived by
  hand (this is where the prior review's blanket justification is too coarse — see E):
  - *Lower bound (∀ over f):* enlarging the class of $f$ strengthens the statement. An
    asymmetric $f$ is equivalent to a set-mapping forbidding the ≤ 2 elements
    $\{f(x,y), f(y,x)\}$ per unordered pair; independence w.r.t. $f$ is exactly
    independence of the 3-uniform hypergraph with edges $\{x, y, f(x,y)\}$ ($\leq
    n(n-1) < n^2$ edges, each of genuine size 3 by validity). Spencer's Turán-type
    theorem for 3-graphs gives an independent set of size $\gg n^{3/2}/\sqrt{n^2}
    = \sqrt n$, so the strengthened statement is still a true theorem of [Sp72]'s
    method with an absolute constant. Sound.
  - *Upper bound (∃ over f):* enlarging the class weakens an existential. The Lean
    statement is *implied by* CFS16 (their construction is a genuine set-mapping, hence
    a symmetric ordered $f$) but does not by itself certify the unordered
    $g(n) \ll \sqrt n$: a hypothetical proof could exploit asymmetry (two forbidden
    elements per pair). Not a defect — the two Lean statements are both true, correctly
    attributed, and together pin down $\Theta(\sqrt n)$ for the file's own (ordered)
    class, a legitimate reading of the page's $f(x,y)$ notation — but the precise CFS16
    statement is the symmetric one. **Fixed by enrichment:** modeling note added to the
    module docstring and a page-confirmed symmetric variant added
    (`erdos_1025.variants.upper_bound_symmetric`); see Addendum.
- Quantifier structure: `C` outermost (absolute constant) with `n`, `f`, `S` in the
  right scopes in both theorems; `n₀` correctly encodes "for all sufficiently large
  $n$" in the upper bound. The lower bound omits a threshold, i.e. is claimed for *all*
  $n$; this is legitimate: every singleton is independent (the independence condition is
  vacuous on it), so the finitely many small $n$ are absorbed by shrinking $C$
  ($g(n) \geq 1$ for $n \geq 1$, and $C\sqrt 0 = 0$ at $n = 0$).
- Types: `Fin n` for $\{1,\ldots,n\}$ (cardinality $n$; no indexing arithmetic anywhere,
  so 0- vs 1-based is irrelevant); `Finset (Fin n)` for finite subsets; card cast to ℝ
  before comparison with `C * Real.sqrt n` so all arithmetic is real. Correct.
- Not vacuous / not trivial: lower bound is nontrivial for large $n$ (must beat the
  trivial singleton); upper bound's conclusion fails for e.g. the full set unless $f$ is
  chosen adversarially, and validity rules out degenerate $f$. For $n = 3$ the unique
  valid symmetric $f$ (third element) shows the content is real at small sizes.

**A2. Lean semantics traps — pass.**

  filters (the "sufficiently large" is via explicit `n₀`), no intervals. The only
  boundary cases are `Fin 0`/`Fin 1`, checked above: for $n = 0$ both statements hold
  with $S = ∅$ and any/no $f$; for $n = 1$ the unique $f$ is vacuously valid and

  `IsIndependentPairSet` tests only $x \neq y$ — the two guards are consistent, so the
  unconstrained diagonal values `f x x` can never affect independence. No silent
  alteration of the source.
- `Real.sqrt` on the ℕ-cast is total and correct; `(S.card : ℝ)` coercion is placed so
  the inequality is in ℝ.

## E. Prior-review audit (`ai-review/1025.md`)

Mostly accurate — its small-$n$ analysis (§6: $n = 0$, $n = 1$) and the diagonal
`f x x` consistency observation (§6 "One subtlety") both re-derive correctly, and the
[Er71] omission it flagged **was** subsequently fixed in `deepmind/1025.lean` (traced in
the styling-session log). Findings:

1. **Over-broad justification of the ordered-pair encoding (§5).** It writes: ordered
   pairs are "strictly more general … any result proved for all functions on ordered
   pairs automatically applies to symmetric functions. The quantifier structure
   correctly handles this." That argument is valid **only for the universally
   quantified lower bound**. For the *existential* upper bound, generalizing the domain
   of $f$ makes the statement *weaker*, not stronger — an asymmetric witness forbids up
   to two elements per pair and would prove less than CFS16's set-mapping construction.
   The conclusion (encoding acceptable) survives because CFS16's symmetric construction
   witnesses the ordered existential, but the review's single blanket argument does not
   establish it and would have masked a real fidelity gap on a problem where the
   existential direction carried the content. Same failure class as the 1005 audit
   (endorsing an encoding without deriving the existential direction).
2. **Unexamined truth of the strengthened lower bound.** By the same asymmetry, the
   formalized lower bound is *stronger* than the literal unordered claim, and the review
   asserts it "matches Spencer's 1972 result" without checking that Spencer's method
   covers pair-to-two-element mappings. It does (Turán-type bound for 3-uniform
   hypergraphs with $< n^2$ edges gives $\gg \sqrt n$ — re-derived in A1), so the
   conclusion stands, but the check was skipped, not passed.
3. **Minor false justification (§4).** "The `open Finset` is appropriate for the `∈`
   notation on `Finset`" — factually wrong; `∈` needs no `open` (it comes from the
   `Membership` instance), and the `open` is in fact unused in this file. (The style
   review `reviews/1025.md` §4 makes a related unexamined claim.)
4. Its citation cross-check against the website ("identical shorthand keys") is
   confirmed by the recovered page; its "no missing variants" verdict is fair for
   problem *parts*, though it did not consider the symmetric-form variant this review
   adds as enrichment.
