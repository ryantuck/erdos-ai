## Summary

The problem (Erdős–Turán, source [Va99, 5.73]): give an asymptotic formula for the
number f(n) of subgroups of Sₙ, and is there a statistical theorem on their order? The
page's remarks record Pyber's log f(n) ≍ n² [Py93] and Roney-Dougal–Tracey's
log f(n) = (1/16 + o(1))n² [RoTr25]; the overall problem is OPEN. The Lean file defines
`numSubgroups n = Nat.card (Subgroup (Equiv.Perm (Fin n)))` (correct) and directly
asserts, as the partially-resolved core, `Tendsto (Real.log (numSubgroups n) / n²)
atTop (nhds (1/16))`. Read back independently: "the *natural* log of f(n), over n²,
tends to 1/16". That is false. [RoTr25] proves f(n) = 2^{(1/16+o(1))n²} — the constant
1/16 belongs to log base 2 (it comes from counting subspaces of F₂^{n/2}, ≈ 2^{n²/16}),
so with `Real.log` the limit must be `(ln 2)/16 ≈ 0.0433`, not `1/16 = 0.0625`.
Everything else — the definition, the filter encoding, the status framing, the
acknowledged omission of the vague second part — is faithful.

## A. Semantic fidelity

**A1. Statement fidelity — one defect; otherwise pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Give an asymptotic formula for
  the number of subgroups of $S_n$. Is there a statistical theorem on their order?"
  The module docstring (`conjectures/1162.lean:16-29`) reproduces it verbatim, plus
  the Erdős–Turán attribution and both remarks, matching the page.
- The theorem (lines 39-42) formalizes the [RoTr25] partial result, not the vague full
  problem — the right scope call ("give an asymptotic formula" and "a statistical
  theorem" are not directly formalizable; the docstring says so explicitly).
- **[defect] Wrong constant (log-base mismatch), lines 40-41.** Independent
  back-translation: "ln f(n)/n² → 1/16". The true result is f(n) = 2^{(1/16+o(1))n²},
  i.e. ln f(n)/n² → (ln 2)/16. Independent corroboration: Sₙ contains an elementary
  abelian 2-subgroup of rank m = ⌊n/2⌋ (disjoint transpositions), whose subgroups are
  the F₂-subspaces, numbering ≈ 2^{m²/4} = 2^{n²/16}; so ln f(n)/n² ≥ (ln 2)/16 − o(1)
  ≈ 0.0433 and the constant 1/16 is exactly the base-2 reading. If the as-written
  statement were the truth, f(n) would be 2^{(1/(16 ln 2))+o(1))n²} = 2^{0.090…n²},
  contradicting [RoTr25]'s 1/16. The page's own "log f(n) = (1/16+o(1))n²" is
  base-ambiguous prose; `Real.log` is unambiguously natural log, so the Lean inherits
  the false reading. Fixed to `Real.log 2 / 16` in v2.
- Not vacuous: f(n) ≥ 1 for all n, the ratio is a genuine sequence, and the limit
  claim is a substantive (proved) statement.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere.
- Division is real-field division: at n = 0 the term is `Real.log 1 / 0 = 0/0 = 0` by
  the Lean convention — harmless under `atTop`.
- `Real.log (numSubgroups n : ℝ)`: `numSubgroups n ≥ 1` always (the subgroup type of a
  finite group is a nonempty finite type — the trivial subgroup exists — so
  `Nat.card ≥ 1`), hence the log argument is never 0 or negative; no `log 0 = 0` junk
  values enter, and the first terms (f(0) = f(1) = 1, log = 0) are the true values.
- No `Finset.range`, no bounded quantifiers, no off-by-one surface.
- `Tendsto _ atTop (nhds L)` is the standard, correct encoding of the limit of a real
  sequence; combined with the o(1) formulation of the source it is exactly equivalent
  (once L is corrected).
- No `StrictMono`/`Monotone` or interval issues arise.

**A3. Definitions — pass.**

- `numSubgroups` (lines 13-14) matches its docstring: `Nat.card` of the type
  `Subgroup (Equiv.Perm (Fin n))` is the number of subgroups of Sₙ. The type is finite
  (a subgroup is determined by its carrier, injecting into the finite
  `Set (Perm (Fin n))`), so `Nat.card` is the honest count, not a junk 0. Degenerate
  inputs: n = 0, 1 give the trivial group with exactly 1 subgroup — correct.
- No `sorry` in any definition.
- The theorem uses the def exactly as defined; no drift.

**A4. Question form and answer polarity — pass.**

- The formalized core is the *solved partial result*, stated as a direct assertion —
  acceptable per this pipeline for solved statements when the polarity is the true
  direction. The direction (convergence to the [RoTr25] constant) is the true one; the
  defect is the constant's value, handled under A1.
- The full problem's first part is a value request ("give an asymptotic formula") with
  no known closed-form answer, and the second part is vague; neither admits a
  non-tautological `answer()` encoding. The docstring's explicit "remains open" caveat
  is the right treatment. No `answer()` is used, so no binder-placement issue.

**A5. Solution status — pass (source-verified + mirror-verified).**
