## Summary

The problem (Erdős–Taylor, source [Va99, 6.76]): let R_n be the maximal
integer such that "almost every" random walk from the origin in ℤ² visits
every x ∈ ℤ² with ‖x‖ ≤ R_n in at most n steps; is it true that
log R_n ≍ √(log n)? The page marks it PROVED — solved in the affirmative,
independently by Révész [Re90] and Kesten — and records the stronger
Révész–Kesten conjecture lim P((log R_n)²/log n ≤ x) = e^{-4x} (sic), proved
by Dembo–Peres–Rosen–Zeitouni [DPRZ04]. The Lean file
(`conjectures/1164.lean`) defines the uniform step distribution, the walk
position, and the per-path covering radius (all essentially correct), then
asserts: ∃ c₁ c₂ > 0 such that **almost surely, eventually**,
c₁√(log n) ≤ log R_n ≤ c₂√(log n). That conclusion is false for the genuine
simple random walk: the DPRZ limit law makes (log R_n)²/log n nondegenerate
with full support on (0, ∞), so no fixed constants can bound it almost surely
eventually — the true reading of ≍ here is two-sided bounds *in probability*.
Independently, the theorem's hypotheses (`IsUniformStep` + `iIndepFun`) never
require the steps to be measurable functions, and an explicit degenerate model
(trivial σ-algebra on the path space) satisfies every hypothesis while
violating the conclusion. Both defects are fixed in `conjectures-v2/1164.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — two defects; setup faithful (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $R_n$ be the
  maximal integer such that almost every random walk from the origin in
  $\mathbb{Z}^2$ visits every $x\in\mathbb{Z}^2$ with $\| x\|\leq R_n$ in at
  most $n$ steps. Is it true that $\log R_n \asymp \sqrt{\log n}$?" The
  theorem docstring (lines 36–50) reproduces this and the remarks essentially
  verbatim.
- Interpretation of R_n: read literally, the page's "almost every random walk"
  makes R_n a *deterministic* sequence — the largest R covered almost surely
  by time n — which is degenerate: for every finite n the walk goes right n
  times with probability 4⁻ⁿ > 0 and then never visits (−1, 0), so the
  largest a.s.-covered radius is 0 for all n. The formalization's choice —
  R_n = R_n(ω), the random covering radius of the individual path
  (`coveringRadius`, lines 31–33) — is the standard reading (Révész's book)
  and the only non-degenerate one. Right call; now documented in v2.
- **[defect] Wrong encoding of ≍ (lines 43–44 of the docstring, 57–60 of the
  code): the almost-sure-with-fixed-constants statement is false.** Independent
  back-translation of lines 57–60: "there exist deterministic c₁, c₂ > 0 such
  that for a.e. ω, for all sufficiently large n,
  c₁√(log n) ≤ log R_n(ω) ≤ c₂√(log n)." Contradiction with the page's own
  stronger result: [DPRZ04] gives V_n = (log R_n)²/log n a limit law that is
  nondegenerate with support all of (0, ∞) (this holds under *any* reading of
  the page's misprinted formula — see below). If the a.s. lower bound held,
  dominated convergence would force lim P(V_n < c₁²) = 0, but the limit law
  assigns it a positive value e^{-4/c₁²}; symmetrically for the upper bound.
  Stronger: since liminf V_n and limsup V_n are a.s. constants (Hewitt–Savage
  type zero-one law), the same argument forces liminf V_n = 0 and
  limsup V_n = ∞ almost surely — even *ω-dependent* constants fail. The true
  content of "log R_n ≍ √(log n)", compatible with (indeed implied by) the
  DPRZ limit law, is the in-probability form: ∀ ε > 0 ∃ c₁ c₂ > 0 such that
  eventually P(c₁√(log n) ≤ log R_n ≤ c₂√(log n)) ≥ 1 − ε. Fixed in v2.
- **[defect] Missing measurability hypothesis: the theorem is falsifiable by a
  degenerate model.** Neither `IsUniformStep` nor Mathlib's `iIndepFun`
  requires `Measurable (X i)` (`iIndepFun` is defined via the comap
  σ-algebras; it constrains μ as an outer measure and holds or fails
  regardless of measurability). Explicit countermodel: take Ω = D^ℕ
  (D = the four steps), X i ω = ω i, the **trivial** σ-algebra {∅, Ω}, and the
  unique probability measure on it. Then μ evaluates every nonempty set to 1:
  the four step-events all get outer measure 1, so `IsUniformStep` holds (it
  only demands *equality*, not 1/4); every `iIndepFun` product identity reads
  1 = 1·…·1 or 0 = 0, so independence holds; but the always-right path has
  coveringRadius 0 forever, the exceptional set is nonempty, hence of outer
  measure 1, and the a.e. conclusion fails for every c₁, c₂. So the theorem
  as stated is false even before the ≍ issue. With `∀ i, Measurable (X i)`
  added, the four (then measurable) events partition Ω and additivity forces
  probability 1/4 each, and the hypotheses pin down the walk's law as genuine
  iid uniform steps. Fixed in v2.
- Quantifier structure otherwise matches; binders before the colon are
  hypotheses of a direct assertion (universally quantifying the model class),
  which is correct — there is no `answer()` iff to contaminate.
- Not vacuous: the (corrected) statement quantifies over a model class that
  contains the canonical construction, and its conclusion is the substantive
  Révész–Kesten theorem.

**A2. Lean semantics traps — pass (given the A1 fixes).**

- No ℕ subtraction anywhere. No ℕ division; the only division,
  (log R_n)²/log n, occurs in the docstring (and in v2's variant, where
  division by log n = 0 at n ≤ 1 yields the junk value 0, harmless under
  `atTop` and documented).
- `Finset.range n` in `walkPosition` gives S_n = X₀ + ⋯ + X_{n−1} with
  S₀ = (0,0) — the standard convention, matching the docstring.
- `coveringRadius` (line 31–33): the defining set always contains R = 0
  (S₀ = (0,0) covers the single point of the radius-0 disk, with k = 0 ≤ n),
  and is bounded above (the walk visits ≤ n + 1 distinct points while the
  disk of radius R contains ≥ 2R + 1 lattice points on the axes alone), so
  ℕ's `sSup` is a genuine maximum — no junk-value trap. The set is downward
  closed, so the sup is the largest valid R.
- `∃ k, k ≤ n` correctly reads "within the first n steps" (positions
  S₀, …, S_n). `a² + b² ≤ (↑R)²` with a, b : ℤ and R : ℕ is exactly
  ‖(a,b)‖ ≤ R for the Euclidean norm; the cast binds as `(↑R)^2`. Correct.
- `Real.log 0 = 0` and `Real.sqrt` of a negative are 0 — small-n degeneracies
  are absorbed by `∀ᶠ … atTop` (and in v2 by the in-probability form).
- Filter encodings: `∀ᵐ ω ∂μ, ∀ᶠ n in atTop` was a correct encoding of
  "a.s. eventually" — the defect is that "a.s. eventually" is the wrong
  notion, not that it was encoded wrongly. v2 uses `∀ᶠ n in atTop` over a
  measure bound with `.toReal`, avoiding the ℝ≥0∞ subtraction trap
  (`1 - ε` is computed in ℝ).

**A3. Definitions — pass with one caveat (fixed via hypothesis, not def).**

- `walkPosition` and `coveringRadius` match their docstrings, including
  degenerate inputs (n = 0). No `sorry` in any definition.
- `IsUniformStep` matches its docstring *given measurability*: "each with
  equal probability" is what it literally says, and equal-plus-partition
  forces 1/4 only when the events are measurable (see A1). v2 keeps the def
  and adds the measurability hypothesis to the theorems, documenting the

- Definitions are used consistently; no drift.

## E. Prior-review audit (`deepmind/ai-review/1164.md`)

The prior review's low-level analysis of the definitions is good, but it
endorses both Part A defects with unsound arguments — including one that
contradicts its own quoted source, the exact failure pattern flagged in this
pipeline (cf. the 1005 and 1002 audits):

1. **False claim about Mathlib semantics (measurability).** "Measurability of
   X is not explicitly required here but is implied by the `iIndepFun X μ`
   hypothesis (Mathlib's `iIndepFun` requires measurability)." **Wrong.**
   `iIndepFun` is defined as `iIndep` of the comap σ-algebras and imposes no
   measurability on the functions; μ is applied to comap-measurable sets via
   its outer-measure extension. The A1 countermodel satisfies `iIndepFun`
   with wildly non-measurable X. Same class as the 1002 audit's
   "measures of non-measurable sets" error.
2. **Unsound asymptotics argument endorsing the encoding (the big one).**
   "The DPRZ04 result implies the original conjecture: the limiting
   distribution concentrates on (0, ∞), giving the almost-sure bounds."
   **Backwards.** Convergence in distribution yields no almost-sure
   conclusions at all, and a nondegenerate limit with full support on (0, ∞)
   *refutes* almost-sure (even in-probability) fixed-constant two-sided
   bounds: P(V_n < c₁²) → e^{-4/c₁²} > 0. The review states the correct
   ingredients, then derives the opposite of what they imply — the same
   pattern as 1005's review endorsing an encoding contradicted by its own
   reading of the source.
3. **Uncritical transcription of the impossible page formula.** It quotes
   lim P((log R_n)²/log n ≤ x) = e^{-4x} without noticing that a
   nondecreasing function of x cannot converge pointwise to a strictly
   decreasing one. A one-line sanity check catches it.
4. **What it got right:** the `coveringRadius` well-definedness analysis
   (nonempty via R = 0, bounded via the πR²-vs-(n+1) count) is correct and
   essentially the argument re-derived here; the `k ≤ n` reading is right;
   the [DPRZ04] bibliographic details (Ann. of Math., 2004, 433–464, and
   volume 160) check out against the recovered extraction (volume from its
   own knowledge); its suspicion that the styled file's "[Va99] Vershik, A."
   attribution was unverified/fabricated was vindicated by the upstream fix
   session; and the 1164/1165/1166 duplication claim is true of the raw files
   here too.
5. **Omissions relative to this review:** both Part A defects; the degeneracy
   of the page's literal "almost every" definition of R_n (worth a note); the
   fact that `IsUniformStep` alone (equality without measurability) does not
   pin the step law.
