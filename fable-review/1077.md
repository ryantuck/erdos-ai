## Summary

The problem (Erdős–Simonovits [ErSi70, p.388]): calling a graph $D$-balanced when its
maximum degree is at most $D$ times its minimum degree, must every graph on $n$ vertices
with at least $n^{1+\alpha}$ edges (for $\epsilon, \alpha > 0$ and $D, n$ sufficiently
large) contain a $D$-balanced subgraph on $m > n^{1-\alpha}$ vertices with at least
$\epsilon m^{1+\alpha}$ edges? The source page marks this **DISPROVED** ("solved in the
negative"): JunGao showed the correct vertex threshold is $\asymp n^\alpha$, with the
upper bound witnessed by a complete bipartite graph and the lower bound proved by
Jiang–Longbrake [JiLo25] via a 6-balanced subgraph. The pre-fix Lean file asserted the
**positive** (refuted) direction as a bare theorem — a statement that is provably false —
while its own docstring said "(DISPROVED)". It also narrowed "subgraph" to *induced*
subgraph (vertex-subset only), whereas the source and the upstream formalization mean a
general subgraph. Both defects are fixed in place (negation of the question's statement,
general-subgraph encoding); the session logs show the polarity defect entered when a
second formalization run **overwrote an earlier, correctly negated version**.

## A. Semantic fidelity

**A1. Statement fidelity — one defect (encoding of "subgraph"), otherwise pass
(source-verified).**

- Recovered verbatim source statement (see Addendum): "We call a graph $D$-balanced (or
  $D$-almost-regular) if the maximum degree is at most $D$ times the minimum degree.
  Let $\epsilon,\alpha>0$ and $D$ and $n$ be sufficiently large. If $G$ is a graph on
  $n$ vertices with at least $n^{1+\alpha}$ edges, then must $G$ contain a $D$-balanced
  subgraph on $m>n^{1-\alpha}$ vertices with at least $\epsilon m^{1+\alpha}$ edges?"
- Independent back-translation of the pre-fix theorem: "for all $\epsilon, \alpha > 0$
  there are thresholds $D_0, N_0$ such that every graph on $n \ge N_0$ vertices with
  $\ge n^{1+\alpha}$ edges contains, for every $D \ge D_0$, a $D$-balanced **induced**
  subgraph on $> n^{1-\alpha}$ vertices with $\ge \epsilon m^{1+\alpha}$ edges." Two
  discrepancies against the source:
  1. **[defect — polarity, see A4/A5]** the source's question was answered *no*; the
     file asserted the *yes* direction as a bare theorem.
  2. **[defect — "subgraph"]** the source's "subgraph" (standard extremal-graph-theory
     usage, and the reading taken by the upstream formal-conjectures artifact, which
     uses `SimpleGraph.Subgraph`) is a *general* subgraph — edges may be deleted, which
     is exactly what makes balancing possible. The pre-fix encoding quantified only over
     induced subgraphs (`S : Finset (Fin n)` with all of `G`'s edges inside `S`),
     asserting a different (strictly stronger positive) proposition. Both propositions
     happen to be false — the bipartite counterexample kills every general subgraph, a
     fortiori every induced one — so the error is invisible to truth value, but not to
     fidelity, and after the polarity fix the induced-only negation would be a strictly
     *weaker* theorem than the one actually proved. Fixed: a general subgraph is encoded
     as `H : SimpleGraph (Fin n)` with `H.Adj ⊆ G.Adj` and all `H`-edges inside `S`;
     `m = S.card`, balance and edge count measured on `H` within `S`.
- Quantifier structure: "Let $\epsilon,\alpha>0$ and $D$ and $n$ be sufficiently large"
  → `∀ ε > 0, ∀ α > 0, ∃ D₀, ∀ D ≥ D₀, ∃ N₀, ∀ n ≥ N₀`. The pre-fix file pulled
  `N₀` out in front of `D` (`∃ D₀ N₀, ∀ D ≥ D₀, ∀ n ≥ N₀`), i.e. a uniform-in-$D$
  threshold — a stronger positive claim whose negation is the weakest reading. The fix
  restores the nested form (`N₀` may depend on `D`), matching the natural reading of
  "sufficiently large", the upstream `∀ᶠ D, ∀ᶠ n` nesting, and the earlier (clobbered)
  first-pass version. Either negation is true — the counterexample works for every
  fixed $D$ with $n \to \infty$ — so this is fidelity polish inside the defect fix, not
  an independent defect.
- Refutation re-derived by hand (so the negated statement is verifiably the true
  direction): fix any $\epsilon > 0$ and $\alpha < 1/2$, take $G = K_{a, n-a}$ with
  $a \approx 2n^\alpha$ (so $e(G) \ge n^{1+\alpha}$ for large $n$). Let $H \subseteq G$
  be $D$-balanced on vertex set $S = A' \cup B'$, $|A'| = s \le a$, $|B'| = t$, with
  $e(H) \ge \epsilon m^{1+\alpha} > 0$. Every degree is positive (an isolated vertex of
  $S$ plus any edge violates balance), some $A'$-vertex has degree $\ge e/s$, some
  $B'$-vertex degree $\le e/t$, so balance gives $t \le Ds$ and symmetrically
  $s \le Dt$; hence $m = s + t \le (1+D)s \le (1+D)a \ll_D n^\alpha < n^{1-\alpha}$ for
  large $n$ — contradiction with $m > n^{1-\alpha}$. This matches the page's
  bipartite-witness remark.
- Not vacuous: the degenerate candidates ($S = \emptyset$, edgeless $H$) fail
  `S.card > n^{1-α}` resp. the $\epsilon m^{1+\alpha} > 0$ edge requirement; for
  $\alpha \ge 1$ the edge hypothesis $e(G) \ge n^{1+\alpha} > \binom{n}{2}$ is eventually
  unsatisfiable, making those $\alpha$ vacuously fine inside the ∀ — falsity comes from
  small $\alpha$, as the hand derivation shows.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere; $1-\alpha$ and $\alpha(1-\alpha)/(1+\alpha)$ live in ℝ.
- ℕ division in `inducedEdgeCount` (`… .card / 2`) is exact: the filtered set of
  *ordered* adjacent pairs is symmetric and irreflexive (`Adj` is), so its cardinality
  is even; each unordered edge is counted exactly twice. For `S = univ` this is
  exactly $e(G)$.
- Real `rpow` (`Mathlib.Analysis.SpecialFunctions.Pow.Real` imported after the original
  session's build failure with `HPow ℝ ℝ`): `(0:ℝ) ^ (1+α) = 0` for $\alpha > -1$, so
  the $n = 0$ boundary is harmless; all arithmetic is done in ℝ after casts.
- No `Finset.range`; the only bounded quantifiers are membership-guarded and
  non-vacuous where it matters (empty `S` is excluded by `S.card > n^{1-α} ≥ 0`... 
  strictly: `> 0` for $n \ge 1$; for $n = 0$ there is no `G`-hypothesis issue since
  `Fin 0` graphs have 0 edges and $0 \ge 0^{1+\alpha} = 0$ holds — then
  `S.card > 0^{1-α} = 0` requires a nonempty `S ⊆ Fin 0`, impossible, so the inner
  existential is false at $n = 0$; inside the negation this only *helps* the true
  direction, and any honest $N_0$ exceeds it anyway).
- "Sufficiently large" encoded with explicit thresholds (`∃ D₀ … ∃ N₀ …`) rather than
  filters — equivalent to `∀ᶠ` on `atTop` and consistent with this corpus's raw style.
- Strict vs non-strict: source "at least $n^{1+\alpha}$ edges" → `≥` ✓ (note the
  upstream file uses `>` here, a slight infidelity on *its* side, Part E); "on
  $m > n^{1-\alpha}$ vertices" → `>` ✓; "at least $\epsilon m^{1+\alpha}$ edges" → `≥`
  ✓.

**A3. Definitions — pass.**

- `inducedDegree`, `inducedEdgeCount`, `isDBalanced` each match their docstrings,
  including degenerate inputs (empty `S`: degree 0, edge count 0, vacuously balanced —
  never satisfies the theorem's cardinality clause). No `sorry` in any `def`.
- `isDBalanced G S D ↔ max induced degree ≤ D · min induced degree` (over `S`): the
  pairwise form is equivalent since both sides range over the same finite set. The
  fixed file reuses the same three defs for the general-subgraph encoding by applying
  them to `H` (whose edges are confined to `S`), so `inducedDegree H S v` is exactly
  $\deg_H(v)$ and `inducedEdgeCount H S = e(H)` — no drift between defs and usage.

- Polarity of the fix verified by hand via the bipartite refutation re-derived in A1.
- No binders before the colon (`theorem erdos_problem_1077 :` is binder-free), pre- and
  post-fix.
