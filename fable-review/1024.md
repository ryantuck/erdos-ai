## Summary

The problem: let $f(n)$ be such that every $3$-uniform linear hypergraph on $n$ vertices
contains an independent set on $f(n)$ vertices; estimate $f(n)$. (Linear: any two edges
share at most one vertex; such hypergraphs are partial Steiner triple systems.) Erdős
could prove $n^{1/2} \ll f(n) \ll n^{2/3}$; Phelps and Rödl proved
$f(n) \asymp (n \log n)^{1/2}$, and the page marks the problem SOLVED. The Lean file
(`deepmind/1024.lean`) defines 3-uniform hypergraphs on `Fin n`, linearity, independence,
the independence number via `sSup`, and $f(n)$ (`linearHypergraphIndNum`) via `sInf`, then
asserts $\exists C_1, C_2 > 0, \exists N_0, \forall n \ge N_0$:
$C_1\sqrt{n\log n} \le f(n) \le C_2\sqrt{n\log n}$. Read back independently, the Lean and
the source agree; all definitions are correct including degenerate cases. The two findings
are a wrong-paper [Er71] bibliography entry (the cited p.106 cannot lie in the entered
paper's pp. 2–20) and the restyling having silently dropped the problem's task sentence
"Estimate $f(n)$." from the module docstring — both fixed.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $f(n)$ be such that every
  $3$-uniform linear hypergraph on $n$ vertices contains an independent set on $f(n)$
  vertices. Estimate $f(n)$." With the remarks: linearity means
  $\lvert A\cap B\rvert\leq 1$ for all edges; an independent set contains no edges;
  "Erdős could prove $n^{1/2} \ll f(n) \ll n^{2/3}$. Phelps and Rödl [PhRo86] proved
  $f(n) \asymp (n\log n)^{1/2}$."
- Independent back-translation of the theorem (`deepmind/1024.lean`, `erdos_1024`):
  "there are constants $C_1, C_2 > 0$ and a threshold $N_0$ such that for all
  $n \ge N_0$, $C_1\sqrt{n\log n} \le f(n) \le C_2\sqrt{n\log n}$", where $f(n)$ is the
  minimum, over linear 3-uniform hypergraphs $H$ on $n$ vertices, of the maximum size of
  an independent set in $H$. This is exactly $f(n) = \Theta(\sqrt{n\log n})$, the
  Phelps–Rödl resolution of "Estimate $f(n)$".
- The informal $f$ ("every such hypergraph contains an independent set on $f(n)$
  vertices") is correctly identified with $\min_H \alpha(H)$: independent sets are
  downward closed under subsets (any edge inside $T \subseteq S$ is inside $S$), so every
  hypergraph contains an independent set of exactly $k$ vertices iff $k \le \alpha(H)$;
  the largest uniformly valid $f$ is $\min_H \alpha(H)$, which is what
  `linearHypergraphIndNum` computes. Its docstring says precisely this.
- Quantifier structure: $C_1, C_2, N_0$ existential, $n$ universal, in the right order;
  no quantified variable is a theorem binder.
- Types: `ℕ` for $n$ and $f(n)$, `ℝ` for the bounds, with `↑(linearHypergraphIndNum n)`
  cast so the comparisons happen in ℝ. `Real.log` (natural log) is the conventional
  reading and the base is Θ-invariant anyway.
- Indexing: no sequences; `Fin n` has exactly $n$ vertices. No off-by-one surface.
- Not vacuous/trivial: both bounds carry content — the lower bound must hold for *every*
  linear hypergraph, the upper requires *witness* hypergraphs with small independence
  number for every large $n$; $C_1, C_2 > 0$ are required and $\sqrt{n\log n} \to \infty$.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no division, no `Finset.range` anywhere in the file.
- `Real.log ↑n` at $n = 0, 1$ gives $\sqrt{n \log n} = 0$; both bounds degenerate there
  but the $N_0$ threshold makes this harmless, matching the asymptotic statement.
- Vacuous quantifiers, checked deliberately: for the empty hypergraph
  (`edges = ∅`) `IsIndependent` is vacuously true for every $S$, so
  $\alpha = n$ — the correct value, and it makes the `sInf` set nonempty. For $n < 3$
  there are no 3-element subsets of `Fin n`, so the empty hypergraph is the *only* one
  and $f(n) = n$; again invisible past $N_0$.
- `independenceNumber` = `sSup {k | ∃ S, IsIndependent S ∧ S.card = k}`: the set contains
  $0$ ($S = ∅$ is independent — an edge $e \subseteq ∅$ would have `e.card = 0 ≠ 3`) and
  is bounded above by $n$ (`S.card ≤ Fintype.card (Fin n)`), so `Nat.sSup` is the true
  maximum, and by downward closure of independence it is $\alpha(H)$. No junk-value
  regime exists here (contrast the $n \le 3$ subtlety in fable-review/1005).
- `linearHypergraphIndNum` = `sInf {k | ∃ H, H.IsLinear ∧ H.independenceNumber = k}`:
  nonempty (empty hypergraph is vacuously linear, contributing $k = n$), and `Nat.sInf`
  of a nonempty set is its minimum. Exactly $f(n)$.
- No `StrictMono`/`Monotone`, filters, or interval-endpoint issues. Strictness of the
  inequalities ($\le$ throughout) matches the $\asymp$ statement.

**A3. Definitions — pass.**

- `Hypergraph3Uniform` (lines 46–48): `Finset (Finset (Fin n))` with
  `∀ e ∈ edges, e.card = 3` — a faithful 3-uniform hypergraph on $n$ labelled vertices
  (a `Finset` of edges automatically has no repeated edges). Matches its docstring.
- `IsLinear` (lines 52–53): `e₁ ≠ e₂ → (e₁ ∩ e₂).card ≤ 1`. The distinctness guard is
  necessary and correct: the source's "$\lvert A\cap B\rvert\leq 1$ for all edges" must
  implicitly mean distinct edges (an edge meets itself in 3 vertices).
- `IsIndependent` (lines 57–59): `∀ e ∈ H.edges, ¬(e ⊆ S)` — "contains no edges",
  verbatim.
- No `sorry` in any `def`/`structure`; no drift between what the defs compute and what
  the theorem needs (`independenceNumber` is used only through
  `linearHypergraphIndNum`, whose gloss matches A1's derivation).

**A4. Question form and answer polarity — pass.**

- The source is a **value/estimate request** ("Estimate $f(n)$."), not a yes/no
  question, and it is solved by a sharp asymptotic rather than a closed-form value. An
  asymptotic estimate cannot be a literal `= answer(value)`; the corpus encodes solved
  estimate problems as direct assertions of the proved asymptotics (cf.
  `deepmind/1025.lean`). The bare-proposition form with no `answer()` wrapper is
  therefore correct, and `reviews/1024.md` §6's "Case 3" call agrees.
- Polarity/direction: the asserted statement is the *true* (Phelps–Rödl) direction, both
  bounds included. No binders before the colon (line 83, `theorem erdos_1024 :`).

**A5. Solution status — pass (source-verified).**

- Recovered page banner: **SOLVED**, tooltip "This has been resolved in some other way
  than a proof or disproof" (i.e. resolved as an estimate). `@[category research
  solved]`, the module docstring, and the theorem docstring ("solved by Phelps–Rödl
  [PhRo86]") all agree. Attribution matches the page's remarks; tags "graph theory",
  "hypergraphs" (AMS 5 is apt). "Formalised statement? No" as of the access date
  2026-02-22 (this project's artifact postdates that).
