## Summary

The problem (OPEN): let $g(k) > k+1$ be the smallest $n$ such that all prime factors of
$\binom{n}{k}$ are $> k$; estimate $g(k)$. Ecklund–Erdős–Selfridge [EES74] proved
$k^{1+c} < g(k) \le \exp((1+o(1))k)$ and conjectured $g(k) < L_k = \mathrm{lcm}(1..k)$
for large $k$, $\limsup g(k+1)/g(k) = \infty$, and $\liminf g(k+1)/g(k) = 0$; Konyagin
[Ko99b] holds the record $g(k) \gg \exp(c(\log k)^2)$. The Lean file defines the witness
predicate `AllPrimeFactorsGt n k` ($n > k+1$ and every prime dividing $\binom{n}{k}$
exceeds $k$) and formalizes three statements: the proved lower bound $k^{1+c} < g(k)$
(as a bound on *every* witness), and the two [EES74] ratio conjectures (with $g(k)$,
$g(k+1)$ pinned as least witnesses). Read back independently, all three Lean statements
say exactly what the source says; I found no semantic defects. The "Estimate $g(k)$"
core is a soft estimation request with no single formalizable statement (the upstream
file likewise leaves `erdos_1095` as a TODO), so formalizing the proved bound plus the
paper's conjectures is the right scope.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement: "Let $g(k)>k+1$ be the smallest $n$ such that
  all prime factors of $\binom{n}{k}$ are $>k$. Estimate $g(k)$."
- `AllPrimeFactorsGt n k := k + 1 < n ∧ ∀ p, p.Prime → p ∣ Nat.choose n k → k < p`
  is exactly "n is an admissible witness": the $n > k+1$ guard matches the source's
  $g(k) > k+1$ (which excludes the trivial $n = k$, $\binom{k}{k}=1$, and $n = k+1$,
  $\binom{k+1}{k} = k+1$ prime, cases). Agrees with the upstream definition
  `sInf {m | k + 1 < m ∧ k < (m.choose k).minFac}` (minFac formulation is equivalent
  for $\binom{m}{k} > 1$, which holds when $m > k+1 \ge 2$... for $k \ge 1$; at $k=0$
  both make every $n \ge 2$ a witness — degenerate but identical).
- `erdos_1095_lower_bound`: back-translation — "∃ c > 0 such that eventually every
  admissible n exceeds $k^{1+c}$". Equivalence with $k^{1+c} < g(k)$ verified by hand:
  every witness is ≥ the least witness $g(k)$, so bounding all witnesses below is the
  same as bounding $g(k)$; and if the witness set were empty the ∀-form is vacuously
  true, but nonemptiness for every $k$ is part of [EES74]'s upper bound, so no strength
  is lost. Strictness (`<`) matches the source's $k^{1+c} < g(k)$.
- `erdos_1095_limsup_ratio` / `erdos_1095_liminf_ratio`: the clauses
  `AllPrimeFactorsGt n₁ k ∧ (∀ m, AllPrimeFactorsGt m k → n₁ ≤ m)` force
  $n_1 = g(k)$ (a witness that is a lower bound of all witnesses is the least witness),
  and likewise $n_2 = g(k+1)$. Then "∀ M, frequently $M \cdot g(k) < g(k+1)$" ⟺
  $\limsup g(k+1)/g(k) = \infty$ and "∀ ε > 0, frequently $g(k+1) < ε \cdot g(k)$" ⟺
  $\liminf g(k+1)/g(k) = 0$ (the ratio is nonnegative and $g(k) \ge k+2 > 0$, so the
  multiplicative form is equivalent to the ratio form; the liminf is ≥ 0 always and is
  ≤ ε for each ε, hence 0). The multiplicative encoding neatly avoids real division.
- Quantifier order is the correct one: `∀ M` / `∀ ε` *outside* `∃ᶠ k` (the reversed
  order would assert unbounded/zero values at a single k, which is false/different).
- Not vacuous: `∃ᶠ k in atTop` statements assert existence of least witnesses at
  infinitely many k, which holds (g is total); the conjectures are substantive.
- Indexing: no sequence indexing to reconcile; $k+1$ appears only as the source's own
  shift.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere.
- No division in the original three statements (ratios encoded multiplicatively). In
  the added variants (see Addendum), `c * k / Real.log k` divides by `Real.log k`,
  which is 0 at k = 0, 1 — harmless under `∀ᶠ k in atTop` and documented.
- `(k : ℝ) ^ (1 + c)` is `Real.rpow` (real exponent); at small k it is well-behaved
  and irrelevant under the eventual filter. The original session's `lake build`
  succeeded on exactly this file, confirming elaboration.
- `∀ᶠ … in atTop` ("for all sufficiently large") and `∃ᶠ … in atTop` ("for infinitely
  many") are the standard correct filter encodings on ℕ.
- No `Finset.range`, no `StrictMono`/`Monotone`, no open/closed-interval issues.
- Degenerate k: at k = 0 every n ≥ 2 is a witness (C(n,0)=1 vacuously) and at k = 1
  every n ≥ 3 is (C(n,1)=n, all prime factors > 1); this matches the definition on the
  source page verbatim and is invisible to the eventual/frequent filters.

**A3. Definitions — pass.**

- The single def `AllPrimeFactorsGt` matches its docstring and the source, including

**A4. Question form and answer polarity — pass (raw-style direct assertions).**
