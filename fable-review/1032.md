## Summary

The problem (source, verbatim): "We say that a graph is $4$-chromatic critical if it has
chromatic number $4$, and removing any edge decreases the chromatic number to $3$. Is
there, for arbitrarily large $n$, a $4$-chromatic critical graph on $n$ vertices with
minimum degree $\gg n$?" Status on the recovered page: **OPEN**. The Lean
(`deepmind/1032.lean`) defines edge-criticality (`IsCritical G k` := χ(G) = k and every
edge is a critical edge) and states `answer(sorry) ↔ ∃ c : ℝ, c > 0 ∧ ∀ N₀, ∃ n ≥ N₀,
∃ G : SimpleGraph (Fin n), IsCritical G 4 ∧ (G.minDegree : ℝ) ≥ c * n`, plus a
5-chromatic variant the page confirms is also open. Read back independently, the Lean and
the English agree: `∃ c > 0` is the standard uniform-constant reading of "minimum degree
$\gg n$", and `∀ N₀, ∃ n ≥ N₀` is exactly "for arbitrarily large $n$". No semantic
defects found; only polish-level enrichment was applied.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 76–81 (post-fix numbering; original 64–67):
  "there is a positive real $c$ such that for every threshold $N₀$ there is an
  $n \ge N₀$ and a graph $G$ on `Fin n` that is 4-edge-critical and has minimum degree
  at least $c n$." This is precisely the question asked, with $\gg n$ unfolded to
  $\ge c n$ for a fixed $c > 0$ — the standard Vinogradov-notation reading (the constant
  is uniform over the family, which matches the `∃ c` outermost position).
- The page *defines* "4-chromatic critical" as "removing any edge decreases the
  chromatic number to 3" — i.e. the source itself fixes the edge-critical reading, so
  the edge-vs-vertex-criticality ambiguity flagged as "potential" by the prior review
  does not even arise. "Decreases to 3" vs the file's `< χ(G)`: deleting a single edge
  lowers the chromatic number by at most 1, so for χ(G) = 4, χ(G − e) < 4 ⟺
  χ(G − e) = 3. Equivalent.
- Types: `c : ℝ` with the comparison in ℝ via casts (`(G.minDegree : ℝ) ≥ c * (n : ℝ)`)
  — arithmetic happens in ℝ as intended; `SimpleGraph (Fin n)` is the right "graph on
  $n$ vertices".
- Indexing: no sequences to reconcile; `n ≥ N₀` over ℕ is exact.
- Not vacuous/trivial: `IsCritical G 4` forces χ(G) = 4, so the empty graph, edgeless
  graphs, and $n = 0$ all fail the hypothesis side; a fixed $c > 0$ forces the minimum
  degree to grow linearly, so small witnesses like $K_4$ (δ = 3) cannot satisfy the
  inner clause for large $N₀$. Notably, the isolated-vertex degeneracy of the
  edge-critical predicate (see A3) is *automatically excluded here*: any graph with an
  isolated vertex has `minDegree = 0 < c·n` for $n \ge 1$.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere.
- Division: none in the main theorem; in the new Dirac variant `(n : ℝ) / 2` is field
  division in ℝ (exact); no ℕ flooring anywhere.
- No `Finset.range`; `n ≥ N₀` has no off-by-one.
- No vacuous bounded quantifiers: the `∀ e ∈ G.edgeSet` in `IsCritical` is vacuous only
  for edgeless graphs, which fail the χ = 4 conjunct anyway (χ of an edgeless graph is
  ≤ 1).
- "Arbitrarily large $n$" is encoded as `∀ N₀ : ℕ, ∃ n : ℕ, n ≥ N₀ ∧ …` — the correct
  frequently-filter encoding, and correctly *not* the stronger "for all sufficiently
  large" form.
- `≥` (non-strict) matches "minimum degree at least $c n$"; for a $\gg$ bound strict vs
  non-strict is immaterial (rescale $c$), so no fidelity issue.
- `minDegree` at degenerate inputs: for `Fin 0` Mathlib's `minDegree` returns the junk
  value 0, but $n = 0$ can never be a witness (no 4-chromatic graph on 0 vertices), so
  the junk value is unreachable in all three min-degree statements.
- `(k : ℕ∞)` cast in `IsCritical` is the correct comparison type for
  `chromaticNumber : ℕ∞`.

**A3. Definitions — pass, one documented caveat.**

- `IsCritical` (line 62, post-fix): `G.chromaticNumber = (k : ℕ∞) ∧ ∀ e ∈ G.edgeSet,
  G.IsCriticalEdge e`. The library's `IsCriticalEdge e` (recovered from the
  formal-conjectures logs, `Coloring.lean` line 77) unfolds to
  `(G.deleteEdges {e}).chromaticNumber < G.chromaticNumber`; combined with the first
  conjunct this is exactly the raw version's `< (k : ℕ∞)` and exactly the source's
  definition. Docstring matches. No `sorry` in any `def`.
- Caveat (not a defect for this problem): the predicate tolerates isolated vertices —
  $K_4 \sqcup (n-4)$ isolated vertices satisfies `IsCritical G 4`. This is harmless for
  every statement in this file (positive min-degree bounds exclude it) but would make a
  naive formalization of Toft's edge-count conjecture from the page remarks **false**
  ($K_4$ + isolated vertices has 6 edges, not $(5/3 - \varepsilon)n$). Documented in the
  module docstring; see B2 and E.

**A4. Question form and answer polarity — pass.**

- The source is a yes/no question ("Is there, for arbitrarily large $n$, …?"), so the
  `answer(sorry) ↔ P` shape is correct, and `P` is the question as asked: RHS true ⟺
  such a $c$ exists ⟺ the answer is "yes". With the problem open, `answer(sorry)` is the
  right content. Same analysis for the 5-chromatic variant (page: "This problem is also
  open for 5-chromatic critical graphs").
- No binders before the colon on either `answer()` theorem (both are
  `theorem … : answer(sorry) ↔ …`), so nothing spuriously universally quantifies the iff.
- The `∃ (_ : DecidableRel G.Adj)` binder inside the existential is truth-neutral
  (`Decidable` is a subsingleton and classically inhabited) and is the corpus idiom for
  making `minDegree` available.

**A5. Solution status — pass (source-verified).**

- Recovered page banner: **OPEN**, tooltip "This is open, and cannot be resolved with a
  finite computation.", with the owner's standard disclaimer. `@[category research
  open]` on both question theorems and both docstrings agree. The two new variants are
  known results (Simonovits/Toft construction; Dirac's example) and are tagged
  `research solved` as direct assertions.

## E. Prior-review audit (`ai-review/1032.md`)

Substantially accurate — its correctness table, quantifier-order analysis, and
"arbitrarily large vs sufficiently large" note all re-derive cleanly, and everything it
flagged was subsequently fixed in `deepmind/1032.lean` ([Va99] added; [Si72]/[To72]
completed with titles/journal/pages; the 5-chromatic variant added verbatim; the
`IsCriticalEdge` rewrite adopted). Its library line references (Coloring.lean lines 77
and 96) check out against the log-recovered library source. Findings:

1. **Imprecise mathematical claim ("strictly weaker").** It states the library's
   vertex-critical `IsCritical` "is a strictly weaker condition than edge-criticality."
   As formal predicates the two are **incomparable**, not ordered: edge-criticality (as
   defined in this file) does *not* imply vertex-criticality — $K_4$ plus an isolated
   vertex is edge-critical (every edge is critical, χ = 4) but not vertex-critical
   (deleting the isolated vertex leaves χ = 4). The folklore implication
   "edge-critical ⟹ vertex-critical" needs a no-isolated-vertices hypothesis, which this
   file's predicate does not impose. The review's *conclusion* (the library def is not a
   substitute) is correct, but the stated reason is wrong — the same pattern class as
   the 1000/1005 audits (defective justification, surviving conclusion), and here the
   overlooked degeneracy has real consequences (it falsifies the naive Toft edge-bound
   variant, see B2.4).
2. **Silent correction of the source ("edges" vs "vertices").** It reports Toft's
   conjecture as "at least $(5/3 + o(1))n$ **edges**", while the recovered page text
   literally says "**vertices**". The correction is mathematically right (the literal
   text is trivially false), but a review should have flagged the discrepancy rather
   than silently normalizing it — the reader cannot tell whether the reviewer checked
   the source or pattern-matched the folklore statement.
3. **Missed:** the isolated-vertex degeneracy of the shared `IsCritical` predicate
   (harmless here, fatal for the edge-count variant it proposed as "related but
   distinct"); and the fact that the *raw* file's direct-assertion form was itself a
   polarity defect (its §6 audits only the styled file, so this went unremarked).
4. **Minor:** the path "FormalConjectures/ErdosProblems/917.lean:54–56" is the upstream
   repo's layout, not this repo's (`deepmind/917.lean:58–60` here); and "[Va99] likely
   refers to a 1999 survey or problem collection" was a guess where the sibling corpus
   already pinned the booklet precisely.
