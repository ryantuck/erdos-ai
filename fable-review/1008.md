## Summary

The problem, verbatim from the recovered page: "Does every graph with $m$ edges contain a
subgraph with $\gg m^{2/3}$ edges which contains no $C_4$?" — a **yes/no question**,
solved in the affirmative by Conlon, Fox, and Sudakov [CFS14b] (arXiv:1401.6711); the
page banner reads **PROVED (LEAN)** ("solved in the affirmative and the proof verified in
Lean"), and a simple proof by Zach Hunter appears in the page comments. The Lean file
(`deepmind/1008.lean`) defines `ContainsCycleFour`/`CycleFourFree` and states: there is a
real $c > 0$ such that for every $n$ and every `G : SimpleGraph (Fin n)` there is a
spanning subgraph `H ≤ G` that is $C_4$-free with
`c * |E(G)|^(2/3) ≤ |E(H)|`. The mathematical content matches the question's content
exactly and is correctly quantified; the one semantic defect is the **encoding form**:
the source asks a yes/no question, so per checklist A4 and the corpus's uniform
convention (`deepmind/716.lean`, `deepmind/921.lean`, `deepmind/1000.lean`, …) the
statement must be `answer(True) ↔ P`, not a bare assertion. Fixed in place (Addendum).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified), one form defect deferred to A4.**

- Recovered verbatim source statement: "Does every graph with $m$ edges contain a
  subgraph with $\gg m^{2/3}$ edges which contains no $C_4$?" The Vinogradov $\gg$
  applied to a universally quantified statement means an absolute constant: $\exists
  c > 0$ such that every graph with $m$ edges has a $C_4$-free subgraph with $\ge
  c\,m^{2/3}$ edges.
- Independent back-translation of the pre-fix theorem (lines 62–68 of the pre-fix file):
  "there is a real $c > 0$ such that for all $n$ and all simple graphs $G$ on `Fin n`
  there is a subgraph $H \le G$ which is $C_4$-free and has at least
  $c\,|E(G)|^{2/3}$ edges." Content identical to the question's proposition; only the
  question wrapper was missing (A4).
- Quantifier order `∃ c, ∀ n G, ∃ H` makes $c$ absolute (independent of the graph) —
  correct for $\gg$.
- `SimpleGraph (Fin n)` over all `n : ℕ` captures every finite simple graph up to
  isomorphism; $C_4$-freeness and edge counts are isomorphism-invariant, so no
  generality is lost. (A graph with finitely many edges but infinite vertex set reduces
  to its finite support; the finite reading is the standard one.)
- `H ≤ G` in Mathlib's `SimpleGraph` order means `H.Adj ≤ G.Adj`: a spanning subgraph
  on the same vertex set. Every subgraph extends to a spanning one by adding isolated
  vertices, which changes neither $C_4$-freeness nor edge count — faithful.
- Not vacuous/trivial: choosing $c$ small only defuses small $m$; the bound bites for
  all large $m$, and the statement is the true CFS theorem. At $m = 0$:
  `(0 : ℝ) ^ ((2:ℝ)/3) = 0` under `rpow` (exponent ≠ 0), and `H = ⊥` works — degenerate
  case handled correctly, not a loophole.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere.
- `(2 : ℝ) / 3` is exact real division; the power is `Real.rpow` (real base, real
  exponent) on the nonnegative base `(card : ℝ)`, which agrees with the intended
  $m^{2/3}$ for all $m \ge 0$, including $0^{2/3} = 0$.
- No `Finset.range`, no bounded quantifiers, no filter encodings needed (the statement
  is uniform in $m$, not asymptotic — correctly so, since the $\exists c$ absorbs the
  asymptotics; small $m$ are harmless as noted in A1).
- Strictness: `c > 0` strict and `≤` on the edge bound — both match the $\gg$ reading.
- `edgeFinset.card` on `SimpleGraph (Fin n)` (with `open Classical`) is the number of
  edges (unordered pairs) — the correct $m$.

**A3. Definitions — pass.**

- `ContainsCycleFour` (lines 57–59): `∃ a b c d, a ≠ c ∧ b ≠ d ∧ Adj a b ∧ Adj b c ∧
  Adj c d ∧ Adj d a`. With `Adj` irreflexive, the four adjacencies force
  $a \ne b, b \ne c, c \ne d, d \ne a$; together with $a \ne c$, $b \ne d$ all six
  pairs are distinct, so the witnesses are exactly the (labelled) $C_4$ subgraphs.
  Conversely every $C_4$ subgraph yields such a tuple. The docstring says precisely
  this. Correct, including the equivalence with the raw file's 6-condition version.
- `CycleFourFree` = `¬ContainsCycleFour` — "contains no $C_4$" as a (not necessarily
  induced) subgraph, the standard reading. Correct.
- No `sorry` in any `def`; definitions used consistently by the theorem.

**A4. Question form and answer polarity — DEFECT (fixed).**

- The source problem is a **yes/no question** ("Does every graph … ?"). Per checklist
  A4 this requires the shape `answer(…) ↔ P`; since the problem was solved in the
  affirmative (CFS14b; page banner PROVED (LEAN)), the corpus convention is
  `answer(True) ↔ P` (cf. `deepmind/716.lean`, `deepmind/921.lean`,
  `deepmind/1000.lean` — all solved yes/no questions with `answer(True) ↔`).
  `erdos_1008` was instead a bare assertion. Unlike the 1005 case the bare assertion is
  at least *true* (the solved direction), so the mathematical content was not wrong,
  but the encoding form is a checklist-A4 defect and an inconsistency with the corpus.
  **[defect]** — fixed to `answer(True) ↔ ∃ c : ℝ, …` (see Addendum; not
  compile-verified).
- Polarity of the fixed form checked by hand: RHS true ⟺ such an absolute $c$ exists ⟺
  the question's answer is "yes" ⟺ `answer(True)`. Correct.
- No binders before the colon (`theorem erdos_1008 :` is binder-free), so the iff is
  not spuriously universally quantified.

**A5. Solution status — pass (source-verified).**

- The recovered page banner is **PROVED (LEAN)** with tooltip "This has been solved in
  the affirmative and the proof verified in Lean." Module docstring, theorem
  docstring, and `@[category research solved]` agree on "solved, affirmatively, by
  Conlon–Fox–Sudakov". As with fable-review/1000, the tag `research solved`
  *understates* PROVED (LEAN) (formal-conjectures would use `research formally solved

  fact is recorded in the module docstring instead of the tag (Addendum fix 2).
- The formalized statement is the true (proved) direction, not the refuted $m^{3/4}$
  version — correct.
