## Summary

This is the unit distance problem, Erdős's oldest and most famous distance conjecture
($500 prize): does every set of $n$ distinct points in $\mathbb{R}^2$ contain at most
$n^{1+O(1/\log\log n)}$ pairs at distance exactly 1? The Lean file defines an
ordered-pair unit-distance counter and asserts, as a positive theorem, that
$\exists C > 0$ with $\text{count}(A) \le |A|^{1 + C/\log\log |A|}$ for all $A$ with
$|A| \ge 2$. Two things are wrong. First, the conjecture was **disproved** in May 2026
(status "disproved (Lean)" in the `teorth/erdosproblems` mirror, updated 2026-06-07;
upstream formal-conjectures now states `answer(False)` citing Sawin, arXiv:2605.20579,
and Alon–Bloom–Gowers–Litt–Sawin–Shankar–Tsimerman–Wang–Matchett Wood,
arXiv:2605.20695) — so the artifact asserts the refuted direction, which the pipeline
brief explicitly classes as a defect. Second, even on its own terms the statement is
literally false at `A.card = 2`: $\log\log 2 < 0$, so the claimed bound is
$2^{1 + C/\log\log 2} < 2$ for every $C > 0$, while two points at unit distance give 2
ordered pairs. Both defects are repaired in `conjectures-v2/90.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — one defect (small-cardinality falsity); otherwise the
encoding shape is right.**

- Recovered verbatim source statement (log capture, see Addendum): "Does every set of
  $n$ distinct points in $\mathbb{R}^2$ contain at most $n^{1+O(1/\log\log n)}$ many
  pairs which are distance 1 apart?"
- Independent back-translation of `conjectures/90.lean:36-41`: "there is a constant
  $C > 0$ such that every finite planar set $A$ with $|A| \ge 2$ has at most
  $|A|^{1 + C/\log\log|A|}$ ordered unit-distance pairs." The
  $\exists C\,\forall A$ quantifier order is the correct rendering of a uniform
  $O(\cdot)$ constant (the constant is *not* absorbed inside the $\forall$ — checklist
  item on constant quantifier order passes).
- **[defect] False at `A.card = 2`.** $\log\log 2 = \log(0.6931\ldots) = -0.3665 < 0$,
  so the exponent $1 + C/\log\log 2 < 1$ and the RHS $2^{1+C/\log\log 2} < 2$ for
  *every* $C > 0$ (numerically checked: RHS ranges from $1.9625$ at $C=0.01$ down to
  $\approx 0$ at $C = 10$). Two points at distance 1 give `unitDistancePairs = 2`
  (ordered). Hence the theorem as written is refutable by a two-point witness,
  independently of the real mathematics. The threshold must be `3 ≤ A.card` (for
  $n \ge 3$, $\log\log n \ge \log\log 3 > 0$, enlarging $C$ only weakens the bound, and
  the $\exists C$-form becomes equivalent to the eventual form of the $O(\cdot)$
  statement). This matters doubly here: the polarity fix (A4/A5) negates the statement,
  and negating the *unrepaired* version would be trivially true via the two-point
  degenerate case — masking the actual disproof content.
- Ordered vs unordered pairs: the def counts ordered pairs (2× unordered). For
  $n \ge 3$ the factor 2 is absorbed into $C$ (since $\log 2/\log n \le
  C'\!/\log\log n$ with $C' = \log 2 \cdot \sup_{n\ge3} \log\log n/\log n < \infty$),
  so this is harmless *after* the threshold fix; the docstring's "up to a factor of 2"
  claim is false precisely at $n = 2$ as written.
- Types: `Finset (EuclideanSpace ℝ (Fin 2))` with `dist` is the right model of finite
  planar point sets with Euclidean distance; casts to ℝ before `rpow` are correctly
  placed. "Distinct points" is inherent in `Finset`.
- Not vacuous (after fixes): the corrected negated statement is non-trivial — for small
  $C$ a triangle already violates the ordered bound at $n=3$ ($6 > 3^{1+10.67C}$ for
  $C < 0.059$), but for large $C$ a violating configuration requires the genuine
  disproof construction, so no degenerate witness proves it.

**A2. Lean semantics traps — one genuine trap hit (the $\log\log$ sign), others pass.**

- No ℕ subtraction anywhere. No ℕ division; the only division is `C / Real.log
  (Real.log (A.card : ℝ))` in ℝ. At `card = 0`: `Real.log 0 = 0`, `Real.log 0 = 0`,
  `C/0 = 0`, RHS $= 0^1 = 0 \ge$ LHS $= 0$ — harmless junk. At `card = 1`:
  `log 1 = 0`, `log 0 = 0`, `C/0 = 0`, RHS $= 1 \ge 0$ — harmless. At `card = 2`: not
  a division-by-zero issue but a *sign* issue, the A1 defect above. (Degenerate-input
  checklist item: the `Real.log 0 = 0` junk values happen to be harmless here; the
  negative value at 2 is the killer.)
- No `Finset.range`; no index shifting (the statement quantifies over sets, not
  sequences).
- No vacuous bounded quantifiers.
- No filters needed: the $O(\cdot)$ is encoded by a uniform constant, which (with the
  $n \ge 3$ threshold) is equivalent to the eventual/asymptotic reading — an acceptable,
  standard encoding. (Upstream instead uses `=O[atTop]` with `maxUnitDistances`; both
  are faithful.)
- `rpow` with base `(A.card : ℝ) ≥ 0`: fine; base ≥ 3 in the guarded statement.
- No `StrictMono`/interval issues.

**A3. Definitions — pass.**

- `unitDistancePairs` (lines 18–19) matches its docstring: ordered pairs $(p,q)$,
  $p \ne q$, $\mathrm{dist}(p,q) = 1$, via `(A.product A).filter`. Hand-simulated small
  cases: two points at distance 1 → product has 4 pairs, filter keeps $(p,q),(q,p)$ →
  2; unit equilateral triangle → 6; empty/singleton → 0. All correct for the *ordered*
  convention; equals `offDiag.filter` count; upstream's `unitDistancePairsCount` is
  this quantity `/ 2`. No `sorry` in the def. The def is used consistently by the
  theorem. The docstring's factor-of-2 remark is inaccurate at $n=2$ (folded into the
  A1 defect; fixed docstring qualifies it).

**A4. Question form and answer polarity — DEFECT (fixed).**

- The source is a **yes/no question** ("Does every set … contain at most …?"). The raw
  pipeline legitimately uses direct assertions (no `answer()` elaborator is available in
  `conjectures/`), and per `FABLE_REVIEW_RUN.md` a direct assertion is acceptable *iff
  its polarity is the true direction*. The artifact asserts the conjecture positively
  — but the answer is now known to be **NO** (see A5). **[defect]** — the refuted
  direction is asserted. Fixed in `conjectures-v2/90.lean` by negating the (threshold-
  repaired) statement: `¬ ∃ C > 0, ∀ A, 3 ≤ A.card → count ≤ card^(1+C/loglog card)`,
  plus constructive disproof variants. Polarity of the fix checked by hand: the
  disproof gives $c > 0$ with $u(n) \ge n^{1+c}$ (unordered, hence also ordered) for
  infinitely many $n$; for any fixed $C$, choose such an $n \ge 3$ with
  $C/\log\log n < c$ — then the bound fails, so the negation holds. Conversely the
  negation is exactly "the answer to the question is no".
- No binders before the colon (line 36 is binder-free); nothing to quantify wrongly.
