## Summary

The problem: for x₁, …, xₙ ∈ [-1,1] let l_k be the Lagrange basis (fundamental)
functions, set x₀ = -1, x_{n+1} = 1, and let
Υ(x₁,…,xₙ) = min_{0≤i≤n} max_{x∈[xᵢ,x_{i+1}]} ∑_k |l_k(x)|. The page asks **two**
questions: (1) is Υ ≪ log n?, and (2) describe which choice of xᵢ maximises Υ. Status
PROVED ("solved in the affirmative"): de Boor–Pinkus [dBPi78] proved Erdős's guess that
the maximiser is characterised by all the interval maxima λᵢ being equal (same
characterisation as problem [1129]), whence Υ ≤ (2/π)·log n + O(1) by the [1129]
bounds. The Lean (`conjectures/1130.lean:57`) asserts ∃ C > 0, ∀ n ≥ 2, ∀ valid nodes,
∃ i, localMax ≤ C·log n — a faithful and exactly-indexed rendering of question 1 in the
proved direction, with no semantic trap violations. Question 2 is missing entirely
(theorem *and* docstring), which is the sole defect; the Er47 partial result Υ < √n and
the page's source citations [Er47], [Er67] are also absent (enrichment, applied in v2).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "For $x_1,\ldots,x_n\in [-1,1]$
  let \[l_k(x)=\frac{\prod_{i\neq k}(x-x_i)}{\prod_{i\neq k}(x_k-x_i)},\] … Let
  $x_0=-1$ and $x_{n+1}=1$ and
  \[\Upsilon(x_1,\ldots,x_n)=\min_{0\leq i\leq n}\max_{x\in[x_i,x_{i+1}]} \sum_k
  \lvert l_k(x)\rvert.\] Is it true that \[\Upsilon(x_1,\ldots,x_n)\ll \log n?\]
  Describe which choice of $x_i$ maximise $\Upsilon(x_1,\ldots,x_n)$."
- Independent back-translation of lines 57–61: "there is a single C > 0 such that for
  every n ≥ 2 and every strictly increasing family of n nodes in [-1,1], some
  subinterval of the induced partition of [-1,1] has Lebesgue-function supremum
  ≤ C·log n." Since `Fin (n+1)` is finite and nonempty, `∃ i, localMax nodes i ≤ B` is
  exactly `min_i λ_i ≤ B`, i.e. Υ ≤ B; the uniform ∃C-∀n-∀nodes shape is the standard
  unfolding of "Υ ≪ log n" as a bound uniform in the node configuration — which is the
  intended reading, given that question 2 asks for the Υ-maximising configuration.
- Indexing reconciled term-by-term: source 1-indexed nodes x₁…xₙ ↔ Lean `nodes 0 …
  nodes (n-1)`; `boundary` maps 0 ↦ -1 = x₀, j ↦ `nodes (j-1)` = x_j for 1 ≤ j ≤ n,
  n+1 ↦ 1 = x_{n+1}; `localMax i` over `Icc (boundary i) (boundary (i+1))` for
  i ∈ Fin (n+1) = the source's λ_i, 0 ≤ i ≤ n. Exact at every index.
- The source writes only "x₁,…,xₙ ∈ [-1,1]"; distinctness is forced by the l_k
  denominators and the ordering by the interval notation [xᵢ, x_{i+1}] — `ValidNodes`
  (StrictMono + Icc membership) makes exactly these implicit hypotheses explicit, and
  loses no generality (Υ is defined on sorted configurations in the source).
- The `n ≥ 2` guard is *necessary*, not cosmetic: for n = 1 the single basis function
  is l₀ ≡ 1, so Λ ≡ 1 and Υ = 1 > C·log 1 = 0 for every C; the unguarded statement
  would be false. For n ≥ 2, log n ≥ log 2 > 0, so the ∀n form absorbs the O(1) of the
  true bound (2/π)log n + O(1) into C. Not vacuous and not trivially false: valid
  configurations exist for every n, and λᵢ ≥ 1 always (∑_k l_k ≡ 1), so the claim has
  real content.
- **Question 2 is not formalized and its omission is not noted anywhere** — see B2
  (the defect).

**A2. Lean semantics traps — pass.**

- ℕ subtraction: the only occurrence is `i.val - 1` in `boundary` (line 32), guarded by
  the dite branch `¬(i.val = 0)`, so `i.val ≥ 1` and no truncation occurs; the `by
  omega` bound proof has `¬(i.val = 0)` and `i.val ≤ n` in scope. Correct.
- Field division: `(x - nodes i) / (nodes k - nodes i)` in `lagrangeBasis` has nonzero
  denominators exactly when the nodes are injective, which `StrictMono` guarantees
  wherever the theorem applies the definition; for non-valid (repeated) nodes Lean's
  x/0 = 0 junk is never relied upon. Product-of-quotients equals the source's
  quotient-of-products in a field when denominators are nonzero.
- No `Finset.range`, no bounded quantifiers, no off-by-one candidates beyond the
  boundary indexing checked above; `⟨i.val, by omega⟩`/`⟨i.val + 1, by omega⟩` in
  `localMax` are within `Fin (n+2)` since `i.val < n + 1`.
- `sSup` as "max": for valid nodes each `Icc (boundary i) (boundary (i+1))` is
  nonempty (b₀ = -1 ≤ nodes 0, nodes (j-1) < nodes j, nodes (n-1) ≤ 1) and compact,
  and Λ is continuous (finite sum of absolute values of polynomials), so the image is
  nonempty and bounded and `sSup` is the genuine attained maximum — the Real `sSup`
  junk cases (empty/unbounded) cannot arise under the theorem's hypotheses. Note the
  first/last subinterval *may be degenerate* (a single point) when a node equals ∓1;
  that matches the source (max over a point = the value there) — see E for the prior
  review's incorrect "non-degenerate" claim.
- `StrictMono` (not `Monotone`) is right: repeated nodes would make l_k undefined.
