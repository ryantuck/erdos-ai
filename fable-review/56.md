## Summary

The problem (verbatim from the recovered page, **DISPROVED (LEAN)** banner, $10): "Let
$N\geq p_k$ where $p_k$ is the $k$th prime. Suppose $A\subseteq \{1,\ldots,N\}$ is
such that there are no $k+1$ elements of $A$ which are relatively prime. An example is
the set of all multiples of the first $k$ primes. Is this the largest such set?" The
answer is **no**: disproved for $k = 212$ by Ahlswede–Khachatrian [AhKh94], and the
disproof is verified in Lean (witness $k = 212$, $N = p_{209}p_{218}$). The Lean input
(`conjectures/56.lean:43-49`) instead asserts the **refuted universal bound** — for
all $N \ge p_k$ and all admissible $A$, $|A| \le$ |multiples of the first $k$ primes|
— i.e. a false proposition, despite its own docstring (lines 39-41) correctly
recording the disproof. This is exactly the batch's problem-34 defect class (bare
assertion whose polarity was never flipped for a negatively-resolved problem).
Additionally, the helper `multiplesOfFirstKPrimes` (lines 28-30) computes the
*shifted* set $\{n-1 : n \in \{1,\dots,N\},\ p_i \mid n \text{ for some } i < k\}$ —
cardinality-equal to the intended set (all the theorem uses), but not the set its
docstring describes, and not itself an example of an admissible set. Both defects are
fixed in `conjectures-v2/56.lean`; the input file is untouched.

## A. Semantic fidelity

**A1. Statement fidelity — encoding of the question's ingredients is faithful; the
asserted direction is wrong (see A4/A5).**

- Independent back-translation of lines 43-48: "for all $N, k$ and all finsets
  $A \subseteq \{1,\dots,N\}$ (encoded `∀ a ∈ A, 1 ≤ a ∧ a ≤ N`), if
  $p_k \le N$ and $A$ has no $k+1$ pairwise coprime elements, then
  $|A| \le |\text{multiplesOfFirstKPrimes } N\ k|$." As an encoding of the *question*
  ("is the example the largest such set?") the ingredients are right:
  - "no $k+1$ elements which are relatively prime" = no $(k{+}1)$-subset that is
    pairwise coprime. The pairwise reading (rather than "gcd of all $= 1$") is
    confirmed by the page's own example set: for $k = 2$ the multiples of $2$ or $3$
    contain $\{2,3,4\}$ with overall gcd $1$, so only the pairwise reading makes the
    example admissible; upstream's `WeaklyDivisible` uses `Set.Pairwise … Coprime`
    identically. Supersets are covered: a pairwise-coprime set of size $> k+1$
    contains a pairwise-coprime $(k{+}1)$-subset.
  - $p_k \le N$ is encoded `nth Nat.Prime (k - 1) ≤ N` — `Nat.nth Nat.Prime` is
    0-indexed (`nth Nat.Prime 0 = 2`), so the 1-indexed $p_k$ is `nth (k-1)`:
    correct for $k \ge 1$ (see A2 for $k = 0$).
  - "First $k$ primes" as indices `i < k`, i.e. `nth 0`…`nth (k-1)` $= p_1,\dots,p_k$:
    correct.
- **Cardinality-only shift in the helper set:** `multiplesOfFirstKPrimes N k` is
  `(range N).filter (fun m => ∃ i < k, nth Prime i ∣ (m+1))` — elements $m \in
  \{0,\dots,N-1\}$ such that $m+1 \in \{1,\dots,N\}$ is a multiple. The map
  $m \mapsto m+1$ is a bijection onto the intended set, so `.card` (all the theorem
  uses) is exactly $|\{n \le N : p_i \mid n \text{ for some } i \le k\}|$ — the bound
  itself is numerically faithful. But the *set* is the wrong object (see A3).
- Not vacuous: for $k \ge 1$ the statement family is substantive (true for small $k$,
  famously false at $k = 212$); no degenerate witness trivializes it.

**A2. Lean semantics traps — one truncation, harmless as used; checked all.**

- **ℕ subtraction:** `k - 1` truncates at $k = 0$, making the hypothesis
  `nth Prime 0 ≤ N` i.e. $2 \le N$ — a junk instance of "$N \ge p_0$" (undefined in
  the source, which presumes $k \ge 1$). Harmless here: for $k = 0$,
  `NoPairwiseCoprimeSubset A 0` forces $A = \emptyset$ (every singleton is vacuously
  pairwise coprime), so the conclusion $0 \le \cdot$ holds and the $k=0$ instances add
  nothing false or vacuously-true-but-misleading. The v2 fix adds `0 < k` explicitly
  (required anyway so the existential disproof cannot be satisfied by junk $k$).
- **Division:** none. **`Finset.range N`:** the off-by-one is *deliberately*
  compensated by filtering on `m + 1` — cardinality exact (verified term-by-term:
  $m = 0 \leftrightarrow n = 1$, $m = N-1 \leftrightarrow n = N$), but the element
  shift is the A3 defect below.
- **Vacuous quantifiers:** `NoPairwiseCoprimeSubset A k` is vacuously true when
  $|A| \le k$ — matches the source (small sets trivially have no $k+1$ such
  elements). `PairwiseCoprime` on singletons is vacuously true — the standard
  reading.
- **Batch checks:** no default-valued binders / `optParam` (problem-25 class); no
  `liminf`/`limsup`/`sSup` junk (problem-33 class — the input avoids upstream's
  `sSup` formulation entirely by using the universal-bound form); degenerate-input
  junk in helper defs *was* found (the shift; and note the corrected definition needs
  a `1 ≤ n` guard precisely because every prime divides $0$ — handled in v2);
  polarity of a solved problem's bare assertion checked by hand — **fails**, see A4.
- `Nat.Coprime a b` is `gcd a b = 1`; on elements $\ge 1$ this is the source's
  "relatively prime" exactly.

**A3. Definitions — DEFECT (def/docstring mismatch, fixed).**

- `PairwiseCoprime` (lines 14-15) matches its docstring; standard symmetric
  formulation; fine.
- `NoPairwiseCoprimeSubset` (lines 21-22) matches its docstring, including the
  supersets remark above; degenerate $k = 0$ behavior ($A = \emptyset$) noted in v2.
- `multiplesOfFirstKPrimes` (lines 28-30) does **not** match its docstring "The set
  of all multiples of the first k primes in {1,…,N}": it is the shifted copy
  $\{n - 1 : n \text{ such a multiple}\}$. Concretely, for $k = 1, N = 4$ it is
  $\{1, 3\}$, not $\{2, 4\}$ — and $\{1,3\}$ is pairwise coprime, so the defined set
  is *not even an example* of a set with no $2$ pairwise coprime elements, although
  the docstring/source sentence says it should be. **[defect]** under A3 (def must
  match docstring and the source's definition; behavior on the actual elements is
  wrong even though the input theorem only consumes `.card`). Fixed in v2 by
  filtering `range (N+1)` on `1 ≤ n ∧ ∃ i < k, nth Prime i ∣ n` — same imports, same
  decidability shape, cardinality provably unchanged (bijection $m \mapsto m+1$), and
  the "example" sentence becomes true of the defined object (added as a variant).
- No `sorry` in any definition.

**A4. Question form and answer polarity — DEFECT (fixed).**

- The source is a **yes/no question** ("Is this the largest such set?"), resolved
  **negatively**. This pipeline accepts direct-assertion form for a solved problem
  *"if the polarity is the true direction; wrong polarity IS a defect"*
  (FABLE_REVIEW_RUN Step 1). The input asserts the universal bound — the direction
  disproved by [AhKh94] — so the formalized proposition is **false** (its own
  docstring says so: "This was **disproved** for k = 212"). This is the batch's
  problem-34 class exactly: the resolution was recorded in prose but the assertion
  was never negated. **[defect]** — fixed in v2 to the existential counterexample
  form: `∃ N k A, 0 < k ∧ A ⊆ {1,…,N} ∧ p_k ≤ N ∧ NoPairwiseCoprimeSubset A k ∧
  (multiples).card < A.card` (not compile-verified).
- Polarity of the fix verified three ways: (i) by hand, the negation of
  "$\forall$ admissible $A$, $|A| \le$ bound" over the hypothesis-satisfying
  instances is "$\exists$ admissible $A$ with $|A| >$ bound" (ℕ linear order:
  $\neg\le \leftrightarrow >$); (ii) against upstream, whose statement is
  `answer(False) ↔ ∀ᵉ (k > 0) (N ≥ (k-1).nth Nat.Prime), MaxWeaklyDivisible N k =
  (FirstPrimesMultiples N k).card` — `answer(False)` = the universal fails; (iii)
  against the machine-verified disproof itself (plby/lean-proofs `Erdos56.lean`,
  fetched during this review), which proves `(∀ᵉ (N ≥ 2) (k > 0), N ≥ k.nth Prime →
  Max = card) ↔ False` via the explicit witness $k = 212$, $N = p_{209}p_{218}$,
  $A = B \cup C$ with $|A| > |E|$. The v2 existential is precisely the witnessed
  content.
- Junk-witness audit of the fixed existential (the dual hazard): $k = 0$ forces
  $A = \emptyset$ (can't win) and is excluded by `0 < k` anyway; small $k$ give no
  cheap witnesses since the conjecture is *true* for small $k$ (page/[AhKh95]); so
  the existential is exactly AhKh94-strength, not trivially provable.
- No binders before the colon (line 43-44: quantifiers are inside the statement);
  no `answer()` in this raw corpus (acceptable per pipeline rules).
