## Summary

The problem (OPEN on the source page): with L^n f the Lagrange interpolation
polynomial of f at the n Chebyshev nodes, prove that for any closed
A ⊆ [-1,1] there exists a continuous f such that A is the set of limit
points of L^n f(x) — where **x is left free** and the site owner explicitly
remarks "I am unclear exactly what is intended here - is this meant for
fixed, arbitrary, x ∈ [-1,1]?". The page's remarks pin down the only
supported reading: Erdős [Er41] proved divergence (lim = ∞) is achievable at
x = cos(πp/q) with p, q odd, and in [Er43] claimed (without proof) the full
limit-point statement "for specific x of this shape". The Lean file
(`conjectures/1151.lean:57-61`) instead asserts the statement **for all
x ∈ [-1,1]**. That resolution is not merely over-strong — it is refutable:
for every odd order m, the node index k = (m-1)/2 gives
cos((2k+1)π/(2m)) = cos(π/2) = 0, so 0 is a Chebyshev node of every odd
order, L^m f(0) = f(0) along all odd m for every f, and therefore f(0) is
always a limit point — so the closed set A = ∅ ⊆ [-1,1] can never be
realized at x = 0, falsifying the ∀x instance. The helper definitions
(Chebyshev nodes, Lagrange basis/interpolant, limit-point set) are all
correct; the defect is confined to the resolution of the x-ambiguity.

## A. Semantic fidelity

**A1. Statement fidelity — DEFECT (fixed in v2).**

- Recovered verbatim source statement (see Addendum): "Given
  $a_1,\ldots,a_n\in [-1,1]$ let $\mathcal{L}^nf(x) = \sum_{1\leq i\leq n}
  f(a_i)\ell_i(x)$ be the unique polynomial of degree $n-1$ which agrees with
  $f$ on $a_i$ for $1\leq i\leq n$ (that is, the Lagrange interpolation
  polynomial). Let $a_i$ be the set of Chebyshev nodes. Prove that, for any
  closed $A\subseteq [-1,1]$, there exists a continuous function $f$ such
  that $A$ is the set of limit points of $\mathcal{L}^nf(x)$." Status banner
  **OPEN** (tooltip: "This is open, and cannot be resolved with a finite
  computation."), standard disclaimer. Source line `#1151: [Va99,2.41]`;
  tags analysis, polynomials.
- The variable x is **free** in the displayed statement, and the page's first
  remark acknowledges the ambiguity. The input resolves it as
  `(x : ℝ) (hx : x ∈ Set.Icc (-1 : ℝ) 1)` — universal quantification.
- **[defect: overstrong-quantifier] The ∀x resolution is provably false.**
  Counterexample re-derived independently: for odd m and k = (m-1)/2 ∈
  {0, …, m-1}, chebyshevNode m k = cos((m)π/(2m)) = cos(π/2) = 0, so 0 is a
  node of every odd order; the order-m Chebyshev nodes are pairwise distinct
  (k ↦ (2k+1)π/(2m) is strictly increasing into (0, π) and cos is strictly
  decreasing there), so ℓ_k(0) = 1 and ℓ_i(0) = 0 for i ≠ k (the product
  over `univ.erase i` contains the vanishing factor (0 − 0)/(x_i − 0)), so
  `lagrangeInterp` at x = 0 equals f(0) for every odd order. In the Lean
  indexing (order n+1), the subsequence at even n is constantly f(0), hence
  f(0) ∈ `limitPoints` for **every** f : ℝ → ℝ. Instantiating the input
  theorem at x = 0, A = ∅ (IsClosed ∅, ∅ ⊆ Icc) demands a continuous f with
  limit-point set ∅ — impossible. The theorem as stated is refutable in
  Lean. (More generally, every x = cos(πa/b) with b even in lowest terms is
  a node for infinitely many orders — take 2m = bt, 2k+1 = at with t odd —
  so a dense set of x admits the same obstruction; A = ∅ is meanwhile
  *realizable* at the [Er41] points, so it cannot be excluded as
  unintended.)
- The page-supported reading is the [Er43] claim: x = cos(πp/q) for odd
  p, q ≥ 1 (such x are never nodes: node angles (2k+1)/(2m) have even
  reduced denominator, these have odd). Fixed accordingly in v2, keeping the
  displayed statement's A ⊆ [-1,1] restriction; the remark's literal
  "any closed set A" form is added as a variant.
- Everything else in A1 checks out: "continuous function f" as
  `Continuous f : ℝ → ℝ` is equivalent to continuity on [-1,1] by Tietze
  extension (only nodal values matter); "set of limit points" as the set of
  finite cluster points is the natural reading (divergence to ∞ realizes
  A = ∅, matching [Er41]); `Set.Icc (-1) 1` correctly closed; equality
  `limitPoints … = A` (not ⊆) correctly captures "A is *the* set of limit
  points".

**A2. Lean semantics traps — pass.**

- **ℕ subtraction: none** — all arithmetic is in ℝ (`(k : ℝ)`, `(n : ℝ)`
  casts before any subtraction).
- Division: `chebyshevNode` divides by 2n; the theorem only uses order
  n + 1 ≥ 1, so the denominator is nonzero (and for n = 0 the `Fin 0` index
  type is empty — no value is ever formed). `lagrangeBasis` divides by
  (nodes i − nodes j); for the pairwise-distinct Chebyshev nodes every
  denominator is nonzero. (On degenerate repeated-node inputs a factor
  becomes 0/0 = 0 — junk, but unused; noted in the v2 docstring.)

  `univ.erase i` — no off-by-one. Order 1 (n = 0 in the sequence): a single
  node cos(π/2) = 0, empty product ℓ₀ = 1, L¹f(x) = f(0) — the correct
  degree-0 interpolant.
- Vacuous quantifiers: none. `limitPoints`'s ∀ε>0 ∀N ∃n≥N pattern is the
  standard cluster-point characterization, never vacuous.
- Encoding of "set of limit points": the ε-N definition is extensionally
  Mathlib's `{y | MapClusterPt y atTop a}` — correct capture of the
  informal notion.
- Indexing: source orders n = 1, 2, … ↔ Lean sequence index n ↦ order n+1,
  a bijection; `limitPoints` of the full sequence equals the source's limit
