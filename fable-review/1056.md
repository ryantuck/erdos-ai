## Summary

The problem (verbatim from the recovered page): "Let $k\geq 2$. Does there exist a prime
$p$ and consecutive intervals $I_1,\ldots,I_k$ such that $\prod_{n\in I_i}n \equiv 1
\pmod{p}$ for all $1\leq i\leq k$?" Status **OPEN**; Guy's problem A15 [Gu04]; Erdős
(1979 letter) established $k=2$ via $3\cdot4\equiv 5\cdot6\cdot7\equiv 1\pmod{11}$,
Makowski [Ma83] established $k=3$ mod 17. The Lean statement
(`conjectures/1056.lean:48–54`) says: for every $k \ge 2$ there exist a prime $p$ and
strictly increasing breakpoints $a : \mathrm{Fin}(k+1) \to \mathbb{N}$ such that each of
the $k$ products $\prod_{n \in [a_i,\,a_{i+1}-1]} n$ is $\equiv 1 \bmod p$. Read back
independently, this is exactly the source question's affirmative direction, with
"consecutive" correctly encoded as *adjacent* intervals via shared breakpoints — the
reading on which the problem is non-trivial. No semantic defect found; enrichments and
page-confirmed variants applied (see Addendum).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 48–54: "for all $k \ge 2$ there are a prime $p$
  and $a_0 < a_1 < \cdots < a_k$ in ℕ with $\big(\prod_{n=a_i}^{a_{i+1}-1} n\big) \bmod p
  = 1$ for each $0 \le i < k$." The $k$ intervals $I_{i+1} = [a_i, a_{i+1}-1]$ are
  nonempty (by `StrictMono`) and adjacent ($I_{i+1}$ starts at $(\text{end of } I_i)+1$),
  i.e. "consecutive intervals" in the source's sense, and each carries the congruence.
  Exact match with the question's content, universally quantified over $k \ge 2$ as the
  "Let $k \ge 2$" framing intends.
- **Adjacency is load-bearing and correct.** Under the alternative (wrong) reading of
  "consecutive intervals" as merely "intervals of consecutive integers, not necessarily
  adjacent", the problem trivializes: the $k$ singletons $\{mp+1\}$, $m = 1,\dots,k$,
  each have product $\equiv 1 \pmod p$. The source's examples (Erdős's $[3,4],[5,7]$;
  Makowski's $[2,5],[6,11],[12,15]$) and the upstream formalization both use adjacent
  intervals; the Lean encodes adjacency. Correct.
- Indexing: source intervals are 1-indexed $I_1,\dots,I_k$; Lean uses `i : Fin k` with
  $I_{i+1} = [a(\mathrm{castSucc}\, i), a(\mathrm{succ}\, i) - 1]$. Term-by-term exact
  under $I_{i+1} \leftrightarrow i$; exactly $k$ intervals.
- Not vacuous/trivially false: singleton intervals are allowed (interval lengths are
  unconstrained in the source too), but adjacent singletons are consecutive integers and
  cannot all be $\equiv 1 \pmod p$ for $k \ge 2$; no degenerate witness satisfies the
  statement. Also note the union $[a_0, a_k - 1]$ can never contain a multiple of $p$
  (that interval's product would be $\equiv 0$), so witnesses automatically live inside
  one residue window $(mp, (m+1)p)$ — the statement is a substantive open question.

**A2. Lean semantics traps — pass.**

- **ℕ subtraction** `a i.succ - 1` (line 53): safe — `StrictMono a` gives
  `a i.succ > a i.castSucc ≥ 0`, so `a i.succ ≥ 1` and no truncation occurs. No
  hypothesis needed.
- **Division:** none; only `% p` with `p` prime, so `p ≥ 2` and `x % p = 1 ↔ x ≡ 1 [MOD
  p]` (since `1 % p = 1`). The `%`-form is equivalent to the upstream `≡ 1 [MOD p]`.
- **Off-by-one:** `Icc (a i.castSucc) (a i.succ - 1)` equals `Ico (a i.castSucc)
  (a i.succ)` for `a i.succ ≥ 1` — precisely the intended interval; equals the upstream
  `Finset.Ico (boundaries i.castSucc) (boundaries (i.castSucc + 1))` encoding.
- **Vacuous quantifiers:** `∀ i : Fin k` with `k ≥ 2` is non-vacuous; no degenerate
  first term.
- **Filter encodings:** none needed (the "for every $k$" reading is correct; solutions
  for $k$ restrict to smaller $k$, so "for all $k \ge 2$" is also equivalent to the
  "arbitrarily large $k$" reading).
- **`StrictMono` vs `Monotone` — `StrictMono` is essential and correctly used.** With
  merely `Monotone`, the constant function `a ≡ c` makes every interval
  `Icc c (c - 1) = ∅` with empty product `1 ≡ 1 (mod p)` — the statement would be
  *trivially true for every k*. The file's `StrictMono` (line 50) forecloses this. A
  degenerate-witness trap correctly avoided.
- If a witness had `a 0 = 0`, the first interval contains 0 and its product is
  `0 % p = 0 ≠ 1`, so such witnesses simply fail; the existential is unharmed and no
  positivity hypothesis is needed.

**A3. Definitions — pass (trivially).** The file has no `def`/`abbrev`/`structure`; the
statement is self-contained. (The original 2026-02-22 raw file factored the condition
into a def `AllModProdEqualsOne`, as does the upstream file; the current inline form is
semantically identical — see Addendum history note.)

**A4. Question form and answer polarity — acceptable raw style, noted.**

- The source is a yes/no question ("Does there exist…?"), OPEN. The raw file states the
  affirmative direction as a bare `theorem … := sorry` — raw files here have no

  encoding's RHS (`answer(sorry) ↔ ∀ k ≥ 2, ∃ …` — same proposition inside the iff).
  The theorem docstring now states explicitly that the source poses a question and this
  asserts the affirmative direction (fix applied).
- No binders that belong after an `answer()` (no `answer()` in raw style; the `k`/`hk`
  binders universally quantify the assertion, which is the intended reading).
