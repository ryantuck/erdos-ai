## Summary

The problem (El Zahar–Erdős, OPEN): calling two disjoint vertex sets $A, B$ of a finite
graph *anticomplete* when there are no edges between them, prove that for all
$t, c \ge 1$ there exists $d \ge 1$ such that every finite graph with $\chi(G) \ge d$
and $\omega(G) < t$ contains anticomplete sets $A, B$ with
$\chi(A) \ge \chi(B) \ge c$. The Lean theorem (`conjectures/1111.lean:30-39`) states:
for $t, c \ge 1$ there is $d \ge 1$ such that for every $n$ and every
`G : SimpleGraph (Fin n)` with `(d : ℕ∞) ≤ G.chromaticNumber` and `G.CliqueFree t`,
there exist `A B : Set (Fin n)` with `Anticomplete G A B` and both induced subgraphs of
chromatic number $\ge c$. Read back independently, this matches the source statement
exactly (the source's ordering $\chi(A) \ge \chi(B) \ge c$ is equivalent to the
symmetric form by relabelling, since the anticomplete relation is symmetric). The
source is a declarative conjecture, so the bare-assertion form (no `answer()`) is
correct for this corpus. No semantic defects; the findings are scholarship enrichment
(missing page source key `[Er85b]`, missing `[NSS24]`, un-recorded page remarks) and
page-confirmed variants.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "If $G$ is a finite graph and
  $A,B$ are disjoint sets of vertices then we call $A,B$ anticomplete if there are no
  edges between $A$ and $B$. If $t,c\geq 1$ then there exists $d\geq 1$ such that if
  $\chi(G)\geq d$ and $\omega(G)<t$ then there are anticomplete sets $A,B$ with
  $\chi(A)\geq \chi(B)\geq c$."
- Independent back-translation of lines 30–39: "for all $t, c \ge 1$ there is a
  $d \ge 1$ such that every finite graph (as a graph on `Fin n`, over all $n$) with
  chromatic number $\ge d$ and no $t$-clique contains anticomplete sets $A, B$ whose
  induced subgraphs each have chromatic number $\ge c$." This is the source statement.
- Quantifier structure: `∃ d` sits inside the theorem after the binders `(t c : ℕ)`,
  and *before* `∀ n, ∀ G` — so $d$ depends only on $t, c$, not on the graph. Exactly
  the source's dependence. The hypotheses $t, c \ge 1$ and the conclusion's $d \ge 1$
  all match the source's "$t,c\geq 1$ … exists $d\geq 1$".
- Ordering: the source writes $\chi(A)\ge\chi(B)\ge c$; the Lean requires both $\ge c$.
  Equivalent: `Anticomplete G A B` is symmetric in $A, B$ (`Disjoint` is symmetric and
  `G.Adj` is symmetric), so given both $\ge c$, relabel so the larger is $A$.
  Conversely $\chi(A)\ge\chi(B)\ge c$ gives both $\ge c$ directly. No gap.
- "Finite graph" as `∀ n, SimpleGraph (Fin n)`: every finite graph is isomorphic to one
  on `Fin n`, and $\chi$, clique-freeness, and the anticomplete/induced-subgraph
  conclusion are all isomorphism-invariant, so the encoding captures "every finite
  graph".
- Not vacuous/trivial: for $t = 2$, `CliqueFree 2` (no edges) forces $\chi \le 1$, so
  the inner implication is vacuous for $d \ge 2$ — but this matches the *source*,
  which is equally vacuous at $t = 2$ ($\omega < 2$ means no edges). For $t \ge 3$
  there are clique-free graphs of unbounded chromatic number (Mycielski, Kneser,
  shift graphs), so the statement is a substantive open conjecture. The conclusion
  is not degenerately satisfiable: $\chi(G[A]) \ge c \ge 1$ forces $A \ne \emptyset$
  (the empty graph has chromatic number 0), and `Disjoint A B` rules out $A = B$.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction or division anywhere in the file.
- `(d : ℕ∞) ≤ G.chromaticNumber` and `(c : ℕ∞) ≤ …chromaticNumber`: Mathlib's
  `SimpleGraph.chromaticNumber` is `ℕ∞`-valued; the casts put the comparison in `ℕ∞`,
  the intended type. For finite graphs the value is finite, so `≤` means the ordinary
  inequality; no coercion trap.
- `G.CliqueFree t` = "no `Finset` of vertices is a $t$-clique" ⟺ $\omega(G) < t$
  (for the degenerate ends: `CliqueFree 1` ⟺ no vertices, matching $\omega < 1$;
  `CliqueFree 0` is unsatisfiable since $\emptyset$ is always a 0-clique, matching
  $\omega < 0$ being impossible — neither case is reachable with $t \ge 1$ except
  $t = 1$, where both sides make the statement vacuously true in the same way).
- No `Finset.range`, no bounded quantifiers over an empty range creating degenerate
  first terms, no filter/limit encodings, no `StrictMono`/`Monotone` or interval
  endpoints in this file.
- Vacuous-quantifier check on `Anticomplete`: the edge condition
  `∀ a ∈ A, ∀ b ∈ B, ¬G.Adj a b` is vacuously true when either set is empty, but the
  theorem's conclusion independently forces both sets nonempty via
  $\chi \ge c \ge 1$, so no degenerate witness slips through. (Contrast the NSS24
  variant added in v2, where this trap is live and is guarded explicitly — see
  Addendum.)
- `G.induce A : SimpleGraph ↥A` is the induced subgraph on the coerced subtype;
  its `chromaticNumber` is exactly $\chi(G[A])$. Correct construct.

**A3. Definitions — pass.**

- `Anticomplete` (lines 12–13) matches its docstring and the source's definition:
  disjointness plus no edges across. Degenerate inputs: for $A = \emptyset$ or

- No `sorry` in any `def`. The definition is used consistently by the theorem.

## E. Prior-review audit (`deepmind/ai-review/1111.md`)

The prior review's bottom line ("Correct and complete", no flaws) is right about the
Lean statement, and its quantifier-order, `Fin n`, `CliqueFree`, and `ℕ∞`-cast bullets
all check out. Its §3 item 3 (the $\chi(A)\ge\chi(B)\ge c$ ordering is equivalent by
WLOG relabelling) is correct — re-derived above using the symmetry of `Anticomplete`.
Its `t = 1` edge-case analysis (`CliqueFree 1` ⟺ no vertices, hypothesis unsatisfiable
on nonempty `Fin n`) is correct. Four findings:

1. **False redundancy claim about `Disjoint` (§6).** "disjointness is technically
   redundant given `SimpleGraph.loopless` (if $a = b$ then $\neg G.Adj\ a\ b$ holds
   automatically)". This is wrong: looplessness makes the edge condition *silent* on
   shared vertices, which is precisely why it fails to imply disjointness. Counter-
   example: $A = B = \{v\}$ satisfies `∀ a ∈ A, ∀ b ∈ B, ¬G.Adj a b` (irreflexivity)
   but not `Disjoint A B`. So the conjunct is a genuine constraint, not a redundant
   one; dropping it would change the predicate (allow overlapping "anticomplete"
   sets), contradicting the source's "disjoint sets of vertices". The prior review's
   *recommendation* (keep the conjunct) is right, but for the wrong reason — the same
   pattern as the unsound-justification findings in the 1000/1005 audits: an argument
   that happens to land on the right answer here would mask a real bug on a problem
   where the conjunct actually mattered.
2. **NSS24 mischaracterized as a strengthening (§2 and §3).** The prior review calls
   the Nguyen–Scott–Seymour result "a strengthened version" and says minimum degree
   $\ge c$ on $G[A]$ is "stronger than $\chi(A) \ge c$". Both directions of that
   comparison are wrong: minimum degree $\ge c$ does **not** imply $\chi \ge c$ (a
   $c$-regular bipartite graph has minimum degree $c$ and chromatic number 2), whereas
   the conjecture *implies* the NSS24 statement (apply it with $c+1$; any graph with
   $\chi \ge c+1$ contains a subgraph of minimum degree $\ge c$, and a subset of an
   anticomplete set is still anticomplete). NSS24 is a **relaxation** on the $A$ side
   — a partial result toward the conjecture (consistent with the problem remaining
   OPEN), not a stronger theorem. The recovered page states it neutrally; the
   "strengthening" framing is the prior review's own error.
3. **Silent normalization of a page typo (§3 item 2).** "The website lists
   $d(2,2)=2$, $d(3,2)=4$, $d(4,2)=5$ as exact values" — the recovered page actually
   writes "$t(2,2)=2$ and $t(3,2)=4$ and $t(4,2)=5$". The intended reading is clearly
   $d(\cdot,\cdot)$ and the prior review's correction is right, but presenting a
   silently-corrected quotation as what the website "lists" is the kind of unflagged
   source drift this pipeline exists to catch. v2 records the typo explicitly.
4. **Unjustified (though correct) $c = 1$ claim (§6).** "trivially satisfiable for any
   graph with sufficiently high chromatic number" is asserted without argument. It is
   true, but needs one: two singleton anticomplete sets exist iff $G$ is not complete,
   and completeness is excluded because a complete graph with `CliqueFree t` has at
   most $t-1$ vertices, hence $\chi \le t-1 < d$ for $d \ge t$.

Also noted: the prior review missed nothing this review classifies as a defect (there
are none), and the citation gaps it flagged (`[Er85b]`, `[NSS24]`) were never fixed in
`conjectures/1111.lean` — they were fixed only in the styled `deepmind/deepmind/`

$d(t,3)$ bound and the $d(t+1,2)$ recursion unmentioned in its variants survey.
