## Summary

The problem (OPEN, $100 prize): is it true that every subgraph of the hypercube
graph $Q_n$ with at least $(\frac12 + o(1))\, n\, 2^{n-1}$ edges contains a $C_4$?
Equivalently, with $f(n)$ the maximum size of a $C_4$-free subgraph of $Q_n$, the
conjecture is $f(n) \le (\frac12 + o(1))\, n\, 2^{n-1}$. The Lean
(`conjectures/86.lean`) defines $Q_n$ on vertex type `Fin n → Bool` with
Hamming-distance-1 adjacency (line 34), the cycle graph $C_m$ on `Fin m` (line 48),
and states (lines 59–67): for every real $\varepsilon > 0$ there is $N_0$ such that
for all $n \ge N_0$, every `SimpleGraph` on the hypercube's vertex type whose
adjacency is contained in $Q_n$'s and whose `edgeFinset.card` is at least
$(\frac12+\varepsilon)\, n\, 2^{n-1}$ admits an injective graph homomorphism from
$C_4$. Read back independently, this is exactly the $\varepsilon$–$N_0$ unfolding of
the source question, asserted in the conjectured direction. The mathematics is
faithful; the single defect is mechanical, not semantic: both `loopless` fields use
the anonymous-constructor form `⟨fun … => …⟩` against the non-inductive Pi type
`Irreflexive Adj`, a pattern documented to fail `lake build` (see D). Fixed in
`conjectures-v2/86.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim statement: "Let $Q_n$ be the $n$-dimensional hypercube graph
  (so that $Q_n$ has $2^n$ vertices and $n2^{n-1}$ edges). Is it true that every
  subgraph of $Q_n$ with $\geq \left(\frac{1}{2}+o(1)\right)n2^{n-1}$ many edges
  contains a $C_4$?" The module docstring reproduces this essentially verbatim,
  including the $f(n)$ reformulation and the remarks ([Er91] $c/n$ lower bound,
  [BHN95] $c/\sqrt n$, [BHLL14] 0.6068, [Ba12b] 0.60318 — all four constants and
  attributions match the page exactly).
- Back-translation of `hypercubeGraph86` (line 34): vertices are Boolean strings of
  length $n$ ($2^n$ of them); adjacency = differ in exactly one coordinate (the
  `u ≠ v` conjunct is redundant given card = 1, but harmless). This is $Q_n$;
  brute-force check: 0, 1, 4, 12 edges for $n = 0..3$, matching $n2^{n-1}$.
- Back-translation of `cycleGraph86 4 _` (line 48): vertices `Fin 4`, adjacency
  $i \ne j$ and consecutive mod 4 — enumeration gives exactly the edge set
  $\{01, 12, 23, 30\}$, i.e. $C_4$; no spurious diagonals (0–2, 1–3 checked absent).
- "Subgraph of $Q_n$" is encoded as any `SimpleGraph` on the full vertex type with
  `H.Adj ⊆ Q_n.Adj` (line 63) — a spanning subgraph. Vertex-deleted subgraphs add
  no generality: the edge threshold and the $C_4$ conclusion depend only on the
  edge set, and every edge set of a sub-vertex subgraph is realized by a spanning
  one. Correct.
- Edge threshold (line 64): all arithmetic in ℝ after coercion;
  $(\frac12+\varepsilon)\cdot n\cdot 2^{n-1}$ with left-associated products —
  exactly the source's threshold, with the $o(1)$ unfolded to
  $\forall \varepsilon > 0$, eventually — the standard and correct reading.
- $C_4$ containment (lines 65–66): injective `f : Fin 4 → V` with adjacency
  preservation = a copy of $C_4$ as a (not necessarily induced) subgraph — the
  correct notion ("contains a $C_4$").
- Not vacuous/trivial: for fixed $\varepsilon < 1/4$ the instances at
  $n = 0, 1, 2, 3$ are *genuinely false* ($f(3) = 9 > (\frac12+\varepsilon)\cdot 12$;
  at $n = 0$ the empty subgraph meets the threshold $0 \ge 0$ yet `Fin 4` cannot
  inject into the 1-element vertex type). The `∃ N₀` quantifier excludes them, and
  must: the [BHN95] bound $f(n) \ge (\frac12 + c/\sqrt n) n 2^{n-1}$ shows small-$n$
  failures are intrinsic to the problem, so the eventual form is exactly faithful —
  a `∀ n` version would have been false (problem-20/78/80/84-class check performed
  by hand and by brute force; the formalization passes).
