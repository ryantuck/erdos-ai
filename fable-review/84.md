## Summary

The problem (OPEN, conjectured by Erdős and Faudree): the cycle set of a graph $G$ on
$n$ vertices is the set $A \subseteq \{3,\ldots,n\}$ of cycle lengths present in $G$;
let $f(n)$ count the realizable such $A$. Prove (1) $f(n) = o(2^n)$ — solved by
Verstraëte [Ve04] — and (2) $f(n)/2^{n/2} \to \infty$ — open. The Lean
(`conjectures/84.lean`) defines the cycle spectrum (`cycleSpectrum84`, line 11), counts
realizable spectra over `SimpleGraph (Fin n)` with `Set.ncard` (`cycleSetCount84`, line
15), and states Part 1 as the ε–N unfolding of little-o (lines 35–39) and Part 2 as the
B–N unfolding of divergence with real exponent $n/2$ (lines 41–45). Read back
independently, both theorems say exactly what the source says. I found **no semantic
defects**; the nits are a missing docstring on the second theorem, a citation key
([Ne25]) used in prose but absent from any reference list, and enrichment opportunities
(page-confirmed variants) applied in `conjectures-v2/84.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim statement: "The cycle set of a graph $G$ on $n$ vertices is a set
  $A\subseteq \{3,\ldots,n\}$ such that there is a cycle in $G$ of length $\ell$ if and
  only if $\ell \in A$. Let $f(n)$ count the number of possible such $A$. Prove that
  $f(n)=o(2^n)$. Prove that $f(n)/2^{n/2}\to \infty$."
- Back-translation of `cycleSpectrum84` (line 11): the set of $\ell$ such that some
  closed walk at some vertex is a cycle of length $\ell$ — exactly "there is a cycle in
  $G$ of length $\ell$". Mathlib's `Walk.IsCycle` (closed trail, distinct internal
  vertices) is the standard cycle notion; `IsCycle.three_le_length` (verified present in
  the pinned Mathlib, `Combinatorics/SimpleGraph/Paths.lean:285`) gives length ≥ 3, and
  a cycle's vertices are distinct so length ≤ n on `Fin n`. Hence the spectrum is
  automatically $\subseteq \{3,\ldots,n\}$: the source's $A \subseteq \{3,\ldots,n\}$
  constraint is a theorem, correctly not restated as a hypothesis.
- Back-translation of `cycleSetCount84` (line 15): the number of distinct sets arising
  as spectra of graphs on the labeled vertex set `Fin n`. This is the source's $f(n)$:
  the "if and only if" in the source means $A$ *is* the spectrum (not a superset), and
  the Lean `cycleSpectrum84 G = A` matches with equality — correct. Labeled vs.
  unlabeled is immaterial since the spectrum is an isomorphism invariant, so the *set*
  of realizable spectra (hence its cardinality) is identical either way.
- Part 1 (lines 35–39): $\forall \varepsilon > 0\ \exists N\ \forall n \ge N:\ f(n) \le
  \varepsilon 2^n$. Since $f(n) \ge 0$ and $2^n > 0$, this is precisely $f(n) = o(2^n)$.
- Part 2 (lines 41–45): $\forall B > 0\ \exists N\ \forall n \ge N:\ f(n) \ge B\cdot
  2^{n/2}$ with the **real** exponent $(n:\mathbb{R})/2$, i.e. $2^{n/2} = \sqrt{2^n}$
  — the standard reading. Divergence $f(n)/2^{n/2} \to \infty$ unfolds to $\forall B\
  \exists N\ \forall n \ge N:\ f(n)/2^{n/2} \ge B$; multiplying by $2^{n/2} > 0$ gives
  the Lean form, and restricting to $B > 0$ loses nothing (for $B \le 0$ the inequality
  is automatic from $f \ge 0$). Equivalent — correct.
- Not vacuous/trivial: brute-force simulation over **all** labeled graphs on $n \le 6$
  vertices gives $f(0),\ldots,f(6) = 1,1,1,2,4,6,11$ — the count grows and the trivial
  upper bound is $2^{n-2}$, so neither statement is degenerate. Smallest-parameter check
  (problem-20/78/80 class): both theorems are asymptotic (`∃ N` may skip every small
  $n$), so the degenerate values $f(n) = 1$ for $n \le 2$ create no vacuity or falsity.
