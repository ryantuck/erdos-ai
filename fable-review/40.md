# Fable Review: Erdős Problem 40

**Verdict:** NEEDS REVISION (one Part A defect: the input formalizes the
"for what functions g(N) → ∞ …" classification question as a **universal
direct assertion over all g → ∞** — its own docstring says "We state the

## Summary

The problem (recovered verbatim): "For what functions $g(N)\to \infty$ is
it true that $\lvert A\cap \{1,\ldots,N\}\rvert \gg \frac{N^{1/2}}{g(N)}$
implies $\limsup 1_A\ast 1_A(n)=\infty$?" — OPEN, $500 prize, a stronger
form of the Erdős–Turán conjecture (#28), "since establishing this for any
function $g(N)\to\infty$ would imply a positive solution to [28]". The Lean
file's two definitions are sound: `countingFn40` is exactly
|A ∩ {1,…,N}| and `repFunction40` is exactly the ordered convolution
1_A ∗ 1_A(n) (same convention as `conjectures/28.lean` and upstream
`sumRep`), and its conclusion `∀ M, ∃ n, repFunction40 A n ≥ M` is a
correct junk-value-free encoding of limsup = ∞. But the theorem quantifies
g universally in the binders: "for **every** g → ∞ and every A with
counting ≫ √N/g(N), the representation function is unbounded". That is not
the question (a classification request, upstream:
`Erdos40ForSet answer(sorry)`), and it is false: fast-growing g make the
hypothesis nearly vacuous — with g(N) = N it asks only counting(N) ≥
C·N^{-1/2}, which A = {1} satisfies with C = 1, while
repFunction40 {1} · ≤ 1. The intended content lives at slowly growing g;
the true, open, weakest-nontrivial substrate is "**some** g → ∞ works"
(which per the page's own remark implies open #28). The v2 fix states
exactly that, keeps both definitions byte-identical, and adds the
counterexample and the #28 implication as variants.

## A. Semantic fidelity

**A1. Statement fidelity — DEFECT (outer quantifier).**

- Independent back-translation of `conjectures/40.lean:38-44`: "For every
  g : ℕ → ℝ tending to ∞, every A ⊆ ℕ for which some C > 0 has
  |A ∩ [1,N]| ≥ C·N^{1/2}/g(N) for all sufficiently large N, and every
  M, there is n with 1_A ∗ 1_A(n) ≥ M." The source asks *for which* g the
  inner implication holds; the Lean asserts it holds for *all* g → ∞.
  These are different propositions, and the Lean one is false (below).
- **Provably false as written.** Take g = (↑· : ℕ → ℝ) (so
  `Tendsto g atTop atTop` holds) and A = {1}. Then for every N ≥ 1,
  `countingFn40 A N = 1` and C·N^{1/2}/g N = C·N^{-1/2} ≤ C, so hA holds
  with C = 1 (eventually, indeed for all N ≥ 1). But
  `repFunction40 {1} n` = #{a ∈ {0,…,n} : a = 1 ∧ n − a = 1} is 1 at
  n = 2 and 0 elsewhere, so M = 2 has no witness — the conclusion fails.
  **[defect: overstrong-quantifier / trivially-false-statement]**. A
  structurally robust second witness: any infinite Sidon-type set (e.g.
  A = {4^k}: base-4 digits make representations unique, so
  repFunction40 ≤ 2) with g(N) = N. The docstring is *honest* about the
  choice ("We state the strongest form") but the chosen form destroys the
  problem: the strength of the hypothesis ≫ N^{1/2}/g(N) is monotone
  *decreasing* in g, so "for all g" takes the implication at its weakest
  hypothesis, where it is trivially refutable — the intended "strongest
  form" would be slowest-g, not all-g, and no single g can be canonically
  chosen without answering the (open) classification.
- Inner statement fidelity (for a fixed g) — pass: `∃ C, 0 < C ∧ ∀ᶠ N in
  atTop, counting ≥ C·N^{1/2}/g N` is the standard Vinogradov ≫ (constant
  uniform in N, eventual bound; upstream's `(√N / g N) =O[atTop]
  (counting)` is the same up to the eventual sign of g, which
  `Tendsto g atTop atTop` settles).
- Types: counting and rep in ℕ, cast to ℝ only where compared against
  real expressions; exponent `((1 : ℝ) / 2)` is *real* division (0.5, not
  ℕ floor) feeding real rpow. Correct.
- Indexing: `Finset.Icc 1 N` = {1,…,N} exactly; `Finset.range (n+1)` =
  {0,…,n} is the full antidiagonal range for ordered representations of
  n. No off-by-one.

**A2. Lean semantics traps — pass (none bite in the input's code; the
defect is quantifier placement, not semantics).**

- ℕ subtraction: `n - a` in `repFunction40` has `a ≤ n` from
  `a ∈ range (n+1)` — exact, never truncates.
- Division: `/ g N` is real field division; for the (finitely many) N
  with g N = 0 the RHS is 0 and the bound is vacuous — harmless, and
  `hg` forces g N ≥ 1 eventually. `(1 : ℝ)/2` is 0.5 (not ℕ division).
  `(N : ℝ) ^ ((1:ℝ)/2)` at N = 0 is rpow of base 0, positive exponent,
  = 0 — harmless under `∀ᶠ`.
- `Finset.range (n + 1)` off-by-one: none (see A1); `Icc 1 N` at N = 0 is
  empty, counting 0 — consistent.
- Vacuous quantifiers: none (the `∀ᶠ` is over atTop, never vacuous).
- limsup encoding: the source's $\limsup 1_A\ast 1_A(n)=\infty$ is encoded
  as unboundedness `∀ M, ∃ n, rep ≥ M`. Equivalent by hand: each
  `repFunction40 A n ≤ n + 1` is finite, so removing any finite prefix of
  finite values leaves the tail-sup infinite; hence unbounded ⟺
  limsup = ∞ (in ℕ∞, upstream's `limsup (rep : ℕ∞) atTop = ⊤`). Same
  convention as `conjectures/28.lean`. **Problem-33 class explicitly
  checked:** no ℝ-valued `Filter.liminf/limsup/sSup/sInf` anywhere (grep:
  only the docstring's LaTeX "limsup") — no junk-value hazard.
- **Problem-25 class explicitly checked:** no default-valued binders; the
  only `:=` tokens are the two def bodies and the theorem's `:=`+`sorry`.
  No `optParam`.
- **Problem-34 class:** status is OPEN, docstring makes no solved claim;
  polarity issue does not arise (the issue is A1's falsity instead).
- **Problem-36 class (classification/extremal not pinned): bites here.**
  The "for what g" request is not encoded; unlike problem 36 (where the
  substrate chosen was trivially *true*), the substrate chosen here is
  trivially *false*. Same disease, opposite symptom.
- `StrictMono`/intervals: not used; `≥` matches ≫'s non-strict bound.

**A3. Definitions — pass.**

- `countingFn40` (line 15) matches its docstring and the source's
  $\lvert A\cap\{1,\ldots,N\}\rvert$ exactly; degenerate N = 0 gives 0.
  0 ∈ A is never counted — consistent with the source's interval starting
  at 1 (and harmless: adjoining/removing 0 changes `repFunction40` by at
  most 2 per n, preserving both hypothesis and conclusion).
- `repFunction40` (line 22) matches its docstring "number of ways to
  write n = a + b with a, b ∈ A (i.e. 1_A ∗ 1_A(n))": for a ∈ {0,…,n} it

  a = 0, i.e. whether 0 ∈ A — matches the convolution.
