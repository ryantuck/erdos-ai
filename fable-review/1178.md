## Summary

The problem (OPEN, tags: graph theory | hypergraphs): for r ≥ 3 let d_r(e) be
the minimal d such that ex_r(n, F) = o(n²), where F is the family of r-uniform
hypergraphs on d vertices with e edges; prove that d_r(e) = (r-2)e + 3 for all
r, e ≥ 3 — the Brown-Erdős-Sós conjecture (the t = 2 case of problem 1157). The
Lean file defines r-uniformity, the (d,e)-configuration containment predicate,
the Turán number `turanNumber r n d e` via ℕ-`sSup`, and `minD r e` as the
`sInf` of the set of d for which the (real-cast) Turán number is `=o[atTop]` of
n², then asserts `minD r e = (r - 2) * e + 3` for `3 ≤ r`, `3 ≤ e` as a direct
assertion (matching the source's "Prove that…" phrasing). Read back
independently, the Lean and the English agree term-by-term, including the
avoidance-encoding equivalence and the honesty of both lattice operations; I
found no Part A defects. The genuine gaps are scholarship: the citation keys
`[BES73] [Er75b] [Er81]` are used but no bibliography exists anywhere in the
file (undefined-citation-key), and the page's `[RuSz78]`/`[EFR86]`-cited partial
results are stated or omitted without their keys (missing-citation). Both fixed
in v2 from recovered data.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "For $r\geq 3$ let
  $d_r(e)$ be the minimal $d$ such that $\mathrm{ex}_r(n,\mathcal{F})=o(n^2)$,
  where $\mathcal{F}$ is the family of $r$-uniform hypergraphs on $d$ vertices
  with $e$ edges. Prove that $d_r(e)=(r-2)e+3$ for all $r,e\geq 3$." The module
  docstring (lines 12–24) reproduces this essentially verbatim.
- Independent back-translation of `erdos_problem_1178` (lines 66–68): "for
  naturals r, e ≥ 3, the least d for which the function n ↦ ex_r(n; d, e),
  cast to ℝ, is little-o of n² along atTop equals (r-2)e + 3." This is exactly
  the assertion asked, given the encoding equivalences below.
- **Avoidance encoding is exact, not merely asymptotic.** F contains *all*
  r-uniform hypergraphs on d vertices with e edges, so H ⊆ Fin n contains a
  member of F as a (non-induced) sub-hypergraph iff there is an injection of
  some member's d vertices into Fin n carrying its e edges into H — iff some
  d-element S ⊆ Fin n contains ≥ e edges of H. That is literally
  `ContainsConfig d e n E` (line 36). The `e ≤` (rather than `=`) direction is
  right: ≥ e edges inside S yields a copy by selecting exactly e of them
  (isolated vertices in the member fill S up to d); conversely a copy gives
  ≥ e edges inside its image. For n < d no d-element S exists and the
  predicate is false — matching the embedding convention (a copy needs d
  distinct host vertices); either convention is invisible to the atTop
  statement anyway.
- **`sInf` really means "minimal d such that."** The o(n²)-set is upward
  closed in d: for n > d, any d vertices spanning e edges extend to d+1
  vertices spanning them, so (d+1,e)-freeness implies (d,e)-freeness,
  ex_r(n; d+1, e) ≤ ex_r(n; d, e) for n > d, and littleO transfers upward
  (finitely many n are irrelevant to atTop). And the set is nonempty — by
  Sárközy–Selkow (page-recovered: d_r(e) ≤ (r-2)e + 2 + ⌊log₂ e⌋) — so `sInf`
  is an attained minimum, not the ℕ junk value `sInf ∅ = 0`. Independently of
  that theorem, the asserted equality itself forces nonemptiness: the RHS
  (r-2)e + 3 ≥ 6 > 0 = `sInf ∅`, so the formal statement cannot be satisfied
  by the junk value; it is faithful unconditionally.
- **No spurious small elements.** For d < r no r-edge fits inside a d-set, so
  every r-uniform hypergraph is free, `turanNumber r n d e = C(n, r)` ~ n^r/r!
  which is not o(n²) for r ≥ 3 — small d correctly stay out of the set.
- Not vacuous: a substantive open conjecture; the hypotheses `3 ≤ r`, `3 ≤ e`
  are satisfiable and the statement is exactly the page's quantifier range.

**A2. Lean semantics traps — pass.**

- **ℕ subtraction** `(r - 2) * e + 3` (line 67) is guarded by `hr : 3 ≤ r`;
  no truncation. No other subtraction in the file.
- **Division** — none anywhere (the little-o is stated multiplicatively via
  `IsLittleO`, not as a quotient limit).
- **`Finset.range`** — not used; no off-by-one surface.
- **Vacuous quantifiers / degenerate inputs**: `ContainsConfig` with n < d is
  false (analyzed in A1); `turanNumber` at n < r has only E = ∅, value 0;
  `Fin 0` is empty, value 0 — all invisible to atTop. The defining set of
  `turanNumber` is nonempty for e ≥ 1 (the empty hypergraph is vacuously
  r-uniform, and `e ≤ 0` fails) and bounded above by C(n, r) (uniform edge
  sets are families of r-subsets of Fin n), so its ℕ-`sSup` is the honest,
  attained maximum — no junk value in the theorem's range e ≥ 3. (At e = 0
  with d ≤ n the set would be empty and `sSup ∅ = 0`; outside the theorem's
  hypotheses, now documented in v2.)
- **Filter encoding**: `(fun n : ℕ => (turanNumber r n d e : ℝ)) =o[atTop]
  (fun n : ℕ => (n : ℝ) ^ 2)` is the standard, correct encoding of
  ex_r(n; d, e) = o(n²) as n → ∞, with the cast to ℝ placed so the comparison
  happens in ℝ. Correct.
- **StrictMono/Monotone, strict vs non-strict, intervals** — none arise. The
  `e ≤ count` non-strict inequality is the correct "e or more" reading (its
  negation, "every d-set spans < e edges", is (d,e)-freeness, identical to
  sibling 1157's `IsFree`).

## E. Prior-review audit (`deepmind/ai-review/1178.md`)

Its mathematics is sound; its website claims are not. Findings:

1. **False "not on the website" claims (§2) — the recoverable-data failure
   class (cf. the 1001/1174/1175 audits).** It states "[Er75b] — Not listed
   on the website for this problem" and "[Er81] — Not listed on the website

   the website while its §2 says Er75b is not listed there.
2. **Artifact-state mismatch on the [BES73] title (§2).** "The formalization
   gives the title as 'On the existence of triangulated spheres in 3-graphs,
   and related problems'" — the raw file under review here contains **no
   titles at all** (no bibliography); the claim concerned an earlier/styled
   draft. Substantively its suspicion was right: both titles are real
   Brown–Erdős–Sós 1973 papers, and the recovered `/latex/1178` extraction
   confirms "Some extremal problems on r-graphs" is the correct expansion
   for this key (the triangulated-spheres paper is a different BES73). Its
   recommendation (fix the title; add [RuSz78]/[EFR86]) was correct — and
   was **never applied to `conjectures/1178.lean`** (the styled copy fixed
   it; the raw file still had no bibliography until this v2).
3. **Sound sSup/sInf analysis (§5) — for once.** Unlike the 1005 audit's
   unsound boundedness argument, its claims re-derive cleanly: nonemptiness
   via the empty hypergraph (valid since e ≥ 3 makes `e ≤ 0` false),
   boundedness by C(n, r) (valid given uniformity), and the sInf-junk caveat
   correctly scoped. One understatement: "the set is nonempty for
   sufficiently large d… shouldn't occur for r, e ≥ 3" — nonemptiness is not
   a hope but a *theorem* on the very page it reviewed (Sárközy–Selkow's
   upper bound), which it did not connect; and the junk value 0 would make
   the conjecture *false*, not merely ill-behaved, so the formal statement
   is self-guarding (A1).
4. **1157-equivalence claim (§6) — verified correct.** Setting t = 2 in
   1157's threshold k ≥ (r-t)s + t + 1 gives (r-2)s + 3, matching this
   problem's conjectured value; and `¬ContainsConfig d e n E` ⟺
   `Erdos1157.IsFree H d e` — both say every d-set spans < e edges.
   Re-derived against the actual 1157 file; both check out, as does its
   r = 3, e = 3 ⟹ 6 consistency check against Ruzsa–Szemerédi.
5. **What it missed.** Nothing semantic (there was nothing to find), but it
   never examined the n < d / d < r degenerate behavior or the upward
   closure that makes `sInf` mean "minimal" (this review, A1/A2), and it
   missed that the missing-key defect it flagged extends to *all* keys in
   the raw artifact (undefined-citation-key), not just the two remark keys.
