## Summary

The problem (Szemerédi's conjecture): let $A \subset \mathbb{R}^2$ be $n$ points with no
three on a line. (i) Does $A$ determine at least $\lfloor n/2\rfloor$ distinct distances?
(ii) In fact, must some single point of $A$ determine at least $\lfloor n/2\rfloor$ distinct
distances? Question (i) is OPEN ("FALSIFIABLE"); question (ii) was answered **no** by
Xichuan in the site's comments (42 points, each seeing only 20 distances), with an 8-point
counterexample of Harborth formalized upstream. The Lean file states (i) as
`answer(sorry) ↔ ∀ A, NonTrilinear A → A.card / 2 ≤ distinctDistances A` and (ii) as
`answer(False) ↔ ∀ A, A.Nonempty → NonTrilinear A → ∃ a ∈ A, A.card / 2 ≤
distinctDistancesFrom A a - 1`. Read back independently, both agree with the source
questions, including the polarity and the `- 1` correction for the zero self-distance.
The only defect found is bibliographic: the docstring's [Er75f] entry carried the wrong
title/venue, contradicting the pipeline's own recovered `/latex/1082` extraction.

Special provenance note: the authoritative upstream artifact for this problem lives in
google-deepmind/formal-conjectures (the part (ii) counterexample is proved at the pinned
commit `0aca4d71`); `deepmind/1082.lean` here is a verbatim copy of the newer upstream
statement file (docstrings + code identical, verified against a log capture of the user's
bumped clone, where it compiled) plus a locally added module-docstring bibliography.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (both captures agree): "Let $A\subset \mathbb{R}^2$
  be a set of $n$ points with no three on a line. Does $A$ determine at least
  $\lfloor n/2\rfloor$ distinct distances? In fact, must there exist a single point from
  which there are at least $\lfloor n/2\rfloor$ distinct distances?"
- Independent back-translation of `parts.i` (line 60): "the answer is yes iff every finite
  planar point set with no three collinear determines at least ⌊|A|/2⌋ distinct distances."
  `distinctDistances` (library def, log-verified at `FormalConjecturesForMathlib/Geometry/
  2d.lean:194`) is `(points.offDiag.image fun pair => dist pair.1 pair.2).card` — the number
  of distinct values of `dist p q` over ordered pairs of distinct points; symmetry of `dist`
  makes ordered vs unordered irrelevant to the image. Exactly "distinct distances
  determined by $A$".
- Back-translation of `parts.ii` (line 98): "the answer is No, i.e. it is NOT the case that
  every nonempty such set has a point $a$ with ⌊|A|/2⌋ ≤ (number of distinct distances from
  $A$ to $a$) − 1." `distinctDistancesFrom A a = (A.image fun x => dist x a).card` counts
  distinct distances from $a$ to all of $A$ *including* `dist a a = 0`; subtracting 1
  removes exactly the zero (all other distances are positive), so the RHS of `≤` is the
  number of distinct distances from $a$ to the other points — the quantity the source asks
  about.
- `NonTrilinear (A : Set ℝ²)` is (log-verified) `A.Triplewise (fun x y z ↦ ¬ Collinear ℝ
  {x, y, z})` — no three *distinct* points collinear. Correct reading of "no three on a
  line" (pairs are always collinear; `Triplewise` quantifies over distinct triples).
- Not vacuous / not trivially decided:
  - (i) holds trivially only for $|A| \le 3$ (e.g. $|A|\le 1$ gives $0 \le 0$); this
    matches the informal statement, which is likewise trivial there. The conjecture's
    content survives intact.
  - (ii): without `A.Nonempty` the inner ∀-statement would be *refuted by the empty set*
    (no witness $a$ exists), making `answer(False)` provable for a degenerate reason and
    the formalization vacuous. The `hA : A.Nonempty` hypothesis is therefore load-bearing
    and present. With it, I checked $n \le 5$ by hand (no config with every point seeing
    fewer than ⌊n/2⌋ distances exists there — e.g. four points each equidistant from the
    other three would force an equilateral 4-set, impossible in ℝ²), so the statement is
    false only for the genuine reason (Harborth's 8-point / Xichuan's 42-point configs).

**A2. Lean semantics traps — pass.**

- **ℕ subtraction** `distinctDistancesFrom A a - 1` (line 101): safe — the witness is
  bound by `a ∈ A`, so the image contains `dist a a = 0` and has card ≥ 1; no truncation
  can occur where the term is used. (Had $a$ ranged outside $A$, `card = 0` would truncate
  to `0 ≤ 0`; it cannot.)
- **ℕ division** `A.card / 2`, `A.card / 3`: floor division is exactly the source's
  $\lfloor n/2\rfloor$ (resp. the variant's $\lfloor n/3\rfloor$).
- No `Finset.range`, no filters/liminf ("infinitely many"-type encodings unused), no
  `StrictMono`/interval issues.
- Vacuous quantifiers: only the benign small-$|A|$ cases discussed in A1; they match the
  source.

**A3. Definitions — pass (with an external-dependency caveat).**

- The file defines nothing locally; `NonTrilinear`, `distinctDistances`,
  `distinctDistancesFrom` all resolve through `FormalConjectures.Util.ProblemImports` in
  the upstream (bumped) library. The refinement session's log shows the identical file
  **compiled successfully** in the user's formal-conjectures clone, so the identifiers do

  `distinctDistancesFrom ∅ pt = 0`).
- No `sorry` in any definition (there are none).

**A4. Question form and answer polarity — pass.**

- Both source questions are **yes/no questions**, and both theorems use the
  `answer(…) ↔ P` shape with `P` the question as asked. No binders precede the colon on
  either theorem (grep hit on line 60 is a false positive — the parenthesized binders sit
  inside the iff's RHS after `∀`).
- Part (i): OPEN → `answer(sorry)`. Correct.
- Part (ii) polarity checked by hand: RHS true ⟺ every admissible set has a
  ⌊n/2⌋-distance point ⟺ the question's answer is "yes". The question was answered "no"
  (Xichuan/Harborth counterexamples: 3 < ⌊8/2⌋ = 4, resp. 20 < ⌊42/2⌋ = 21), so
  `answer(False)` is correct, and the `False ↔ P` statement is the true proposition.
