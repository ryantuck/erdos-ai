## Summary

The problem (erdosproblems.com/1102, verbatim from the recovered page): $A \subseteq
\mathbb{N}$ has property $P$ if for all $n \geq 1$ only finitely many $a \in A$ have
$n + a$ squarefree; $A$ has property $Q$ if there are infinitely many $n$ such that
$n + a$ is squarefree for all $a < n$ (with $a$ implicitly ranging over $A$). How fast
must sequences $A = \{a_1 < a_2 < \cdots\}$ with properties $P$ or $Q$ increase? Status
**SOLVED (LEAN)**: van Doorn and Tao [vDTa25] show property $P$ forces density $0$ but
the density can go to $0$ arbitrarily slowly, and property $Q$ forces upper density
$\leq 6/\pi^2$, which is attained. The Lean file defines the two properties, a counting
function, upper density (limsup) and natural density (Tendsto), and states these four
results as direct assertions with `sorry` proofs. Parts 1, 3, 4 are faithful. Part 2
(`exists_sequence_with_P`, lines 64–67) is **false as written**: it demands a strictly
increasing `a : ℕ → ℕ` with `(a j : ℝ) ≤ f j * j` for *every* j, which forces
`a 0 = 0` (RHS is 0 at j = 0) and is outright unsatisfiable for admissible f that are
negative somewhere (e.g. f(j) = j − 10⁶ tends to infinity but makes the RHS negative at
j = 1). The bound must be eventual (`∀ᶠ j in atTop`) — fixed in v2.

## A. Semantic fidelity

**A1. Statement fidelity — Parts 1, 3, 4 pass (source-verified); Part 2 defect (see A2/A4 discussion below).**

- Recovered verbatim source statement (see Addendum): "We say that
  $A\subseteq \mathbb{N}$ has property $P$ if, for all $n\geq 1$, there are only
  finitely many $a\in A$ such that $n+a$ is squarefree. We say that $A$ has property
  $Q$ if there are infinitely many $n$ such that $n+a$ is squarefree for all $a<n$.
  How fast must sequences $A=\{a_1<a_2<\cdots\}$ with properties $P$ or $Q$ increase?"
- `HasPropertyP` (line 31–32): `∀ n : ℕ, 1 ≤ n → Set.Finite {a ∈ A | Squarefree (n + a)}`
  — term-by-term exact, including the source's `n ≥ 1` restriction (which also keeps
  `n + a ≥ 1`, so `Squarefree 0` never arises).
- `HasPropertyQ` (line 35–36): `Set.Infinite {n | ∀ a ∈ A, a < n → Squarefree (n + a)}`.
  The source's "for all $a<n$" leaves the range of $a$ implicit; the $a \in A$ reading
  is the only sensible one — the literal "all naturals $a < n$" would require every
  integer in $[n, 2n)$ to be squarefree, impossible for $n \geq 4$ (that interval
  contains a multiple of 4), making $Q$ unsatisfiable and the problem vacuous; and the
  page's separate property $P'$ ("for all $a \in A$", no cutoff) is only a meaningful
  contrast under this reading. The recovered summary of the upstream formal-conjectures
  file uses the same reading. Pass.
- Part 1 `density_zero_of_P` (lines 54–57), back-translated: "for every strictly
  increasing `a : ℕ → ℕ` whose range has property P, a(j)/j → ∞." The page says
  "any sequence with property P has density 0". For a strictly increasing enumeration
  the counting function satisfies $A(a_j) = j + 1$, so $A(x)/x \to 0 \iff (j+1)/a_j \to
  0 \iff a_j/j \to \infty$: the quotient form is equivalent to density 0 (both
  directions checked, not just one). Faithful. Encoding the set as `Set.range a` with
  `StrictMono a` correctly captures $\{a_1 < a_2 < \cdots\}$; 0-indexing vs the
  source's 1-indexing shifts nothing (same range, and the growth class of $a_j/j$ is
  index-shift invariant).
- Part 2 `exists_sequence_with_P` (lines 64–67), back-translated: "for every
  f : ℕ → ℝ tending to infinity there is a strictly increasing property-P sequence
  with $(a_j : ℝ) \leq f(j) \cdot j$ **for all j**." **[defect]** The universal
  quantifier makes this false — analysis under A2 (the trap is a boundary/junk-value
  interaction) and the fix under Proposed refinements. The *intended* content ("density
  can go to 0 arbitrarily slowly", i.e. the eventual bound) is the right unpacking of
  the page's remark.
- Part 3 `upper_density_Q` (lines 72–74): "any A with property Q has `upperDensity A`
  ≤ 6/π²" — exactly the page's "any sequence with property $Q$ has upper density at
  most $6/\pi^2$". Generalizing from sequences to arbitrary `Set ℕ` is harmless and
  true (finite sets have upper density 0). Pass.
- Part 4 `exists_Q_with_max_density` (lines 79–82): "there is an infinite A with
  property Q and natural density 6/π²" — exactly the page's "sequences with property
  $Q$ exist with density equal to $6/\pi^2$". `Set.Infinite` correctly rules out the
  degenerate finite witness. Pass. (The upstream file's summary states its witness is
  moreover a set of squarefree numbers — a strengthening, noted in v2, not a defect
  here.)
- Not vacuous/trivial: property-P sets exist (page remark: "it is easy to see"), so
  Part 1's universal is not vacuous; property-Q sets exist (Part 4 / page remark), so
  Part 3's is not; Parts 2 and 4 are substantive existence claims.

**A2. Lean semantics traps — one defect, otherwise pass.**

- **[defect] Vacuous/degenerate boundary of the Part 2 bound.** At j = 0 the required
  bound is `(a 0 : ℝ) ≤ f 0 * (0 : ℝ) = 0`, forcing `a 0 = 0` for every admissible f —
  already an unintended strengthening. Worse, `Tendsto f atTop atTop` constrains only
  the tail of f: take f(j) = (j : ℝ) − 10⁶. Then `hf` holds, but at j = 1 the demand is
  `(a 1 : ℝ) ≤ 1 − 10⁶ < 0`, unsatisfiable for `a 1 : ℕ`. Hence **no** sequence
  satisfies the conclusion and the theorem is **false**. Even restricting to positive
  monotone f does not rescue the ∀-form (f ≡ ½ initially forces `a j ≤ j/2`, killing
  strict monotonicity from `a 0 ≥ 0`). The bound must be eventual:
  `∀ᶠ j in atTop, (a j : ℝ) ≤ f j * j`. This matches the page's asymptotic remark
  ("density going to 0 arbitrarily slowly") and bypasses both boundary artifacts.
  Fixed in v2.
- ℕ subtraction: none in the file. (The v2 variants encode $2^k - 1$
  subtraction-free as `m + 1 = 2 ^ k`.)
- Division: `(a j : ℝ) / (j : ℝ)` at j = 0 is 0 by field convention — harmless under
  `Tendsto _ atTop atTop` (line 56). `(countingFn S N : ℝ) / (N + 1 : ℝ)` never
  divides by zero (`N + 1 ≥ 1`). The `(N+1)`-normalization against `Set.Iic N`
  (= {0,…,N}, N+1 candidates) is internally consistent and asymptotically identical to
  the textbook `A(N)/N`; all three density notions are unaffected. No ℕ division
  anywhere.
- `Finset.range`: not used; `Set.Iic N` off-by-one checked above.
- Vacuous bounded quantifiers: in `HasPropertyQ`, n = 0 satisfies the inner condition
  vacuously (no `a < 0`) and n = 1 requires at most `Squarefree 1` (true), so small n
  are always in the set — finitely many junk members, invisible to `Set.Infinite`,
  and the source's "infinitely many n" is likewise insensitive. Documented in v2.
- Filter encodings: `Set.Infinite` for "infinitely many n" ✓; `limsup` of the counting
  ratio for upper density ✓ (the ratio lies in [0,1], so the real limsup has no
  junk-value regime — checked, cf. the 1005 audit's `sSup` failure class);
  `Tendsto _ atTop (nhds d)` for natural density ✓; `Tendsto _ atTop atTop` for
  a(j)/j → ∞ ✓.
- `StrictMono` correctly captures $a_1 < a_2 < \cdots$; all inequalities (`1 ≤ n`,
  `a < n`, `≤ 6/π²`) match the source in strictness. Part 3's `≤` (not `<`) is the
  page's "at most", and is the correct polarity given Part 4's attainability.
