## Summary

The problem (verbatim from the recovered page): "If $R(k)$ is the Ramsey number for
$K_k$, the minimal $n$ such that every $2$-colouring of the edges of $K_n$ contains a
monochromatic copy of $K_k$, then $\frac{R(k)}{k2^{k/2}}\to \infty$." Status **OPEN**,
\$100 prize; Erdős offered \$1000 for a disproof while calling that offer "phoney"
because he was sure the statement is true. The Lean (`deepmind/1029.lean:57-61`)
states: for every real $C > 0$ there is $K_0$ with
`(hypergraphRamsey 2 k : ℝ) ≥ C * k * 2 ^ (k/2)` for all $k \ge K_0$ — the standard
$\forall C\,\exists K_0$ unfolding of the ratio tending to infinity, as a bare
proposition (no `answer()`), tagged `research open` with `by sorry`. Read back
independently, the Lean and the source agree; I found no semantic defects, only
polish-level items (citation stub, missing page remarks, unused `open`), now applied.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 57–61: "for every positive real $C$, for all
  sufficiently large $k$, $R(k) \ge C \cdot k \cdot 2^{k/2}$" where $R(k)$ is
  `hypergraphRamsey 2 k`. For $k \ge 1$ the factor $k \cdot 2^{k/2}$ is positive, so
  this is exactly $R(k)/(k2^{k/2}) \to \infty$; the $k = 0$ term (where the informal
  ratio is undefined) is invisible to the eventual quantifier — and the inequality even
  holds there ($0 \ge C\cdot 0$). Term-by-term exact, no hidden reindexing (no
  sequence indexing exists to shift).
- The restriction to $C > 0$ loses nothing: for $C \le 0$ the inequality is trivially
  eventual (RHS $\le 0 \le$ LHS), so divergence is fully captured.
- `hypergraphRamsey 2 k` correctness (definition recovered from the session capture of
  `FormalConjecturesForMathlib/Combinatorics/Ramsey.lean` in
  `ramsey-pr-edits/ramsey-1.md`): `sInf { m | ∀ (c : Finset (Fin m) → Bool), ∃ S,
  S.card = n ∧ ∃ color, ∀ e ⊆ S, e.card = r → c e = color }`. For $r = 2$: the
  colouring ranges over *all* finsets, but only its values on 2-sets are constrained,
  and every 2-colouring of pairs extends (arbitrarily) to a colouring of all finsets —
  so membership at $m$ is equivalent to "every 2-colouring of $E(K_m)$ has a
  monochromatic $K_k$". The membership set is upward closed (restrict a colouring of
  `Fin (m+1)`'s subsets along the embedding `Fin m ↪ Fin (m+1)`) and nonempty by
  finite Ramsey, so `sInf` is the genuine minimum: exactly $R(k)$, matching the page's
  "the minimal $n$ such that…". Degenerate values ($R(0)=0$, $R(1)=1$) are harmless
  under the eventual quantifier.
- Not vacuous/trivial: the statement is a substantive open divergence claim; no
  degenerate witness satisfies it (it asserts a genuine lower bound growing beyond
  every linear multiple of $k2^{k/2}$, strictly stronger than the known
  $\Theta(k2^{k/2})$ lower bounds).

**A2. Lean semantics traps — pass.**

- No ℕ subtraction or ℕ division in the theorem. `(k : ℝ) / 2` is real division,
  exact; `(2 : ℝ) ^ ((k : ℝ) / 2)` is real rpow, so $2^{k/2} = \sqrt{2^k}$ for odd $k$
  as intended (not a floored integer power).
- `sInf` on ℕ returns 0 on the empty set — would make the theorem false — but the set
  is provably nonempty (finite Ramsey / the [ErSz35] binomial bound); this is a proof
  obligation of any eventual proof, not a statement defect.
- No `Finset.range`, no vacuous bounded quantifiers, no strict/non-strict or
  open/closed-interval choices to get wrong ($\ge$ vs $>$ is immaterial for
  divergence). Filterless $\forall C\,\exists K_0\,\forall k \ge K_0$ encoding is
  equivalent to `Tendsto … atTop atTop`.
- (Added variants: `2 * k - 1` and `k - 1` in `variants.upper_bound` are ℕ
  subtractions, guarded by the `1 ≤ k` hypothesis and documented.)

**A3. Definitions — pass (externally deferred).**

- The file defines nothing locally; the only helper, `hypergraphRamsey`, is imported.
  The captured library definition matches its own docstring ("smallest `m` such that
  every 2-coloring of the `r`-subsets … contains a monochromatic subset of size `n`" —
  up to the harmless generalization that the Lean colouring's domain is all finsets).
  No `sorry` in any `def`. Since the library file itself is not in this repo, this item
  is verified only against the log capture: partially DEFERRED.

**A4. Question form and answer polarity — pass.**
