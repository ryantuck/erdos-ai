## Summary

The problem (verbatim from the recovered page, **OPEN** banner): "For any graph $H$ is
there some $c=c(H)>0$ such that every graph $G$ on $n$ vertices that does not contain
$H$ as an induced subgraph contains either a complete graph or independent set on
$\geq n^c$ vertices?" — the Erdős–Hajnal conjecture [ErHa89], with partial results
$\exp(c_H\sqrt{\log n})$ (Erdős–Hajnal) and $\exp(c_H\sqrt{\log n\log\log n})$
(Bucić–Nguyen–Scott–Seymour [BNSS23]). The Lean input (`conjectures/61.lean:20-28`)
asserts: for every graph $H$ on `Fin k` (k auto-bound implicit) there is $c > 0$ such
that for every $n$ and every $G$ on `Fin n` with no induced copy of $H$, some
`Finset (Fin n)` of cardinality $\ge n^c$ is a clique or an independent set. Read back
independently, this is a faithful direct assertion of the conjectured "yes" direction
of the open yes/no question (the raw-pipeline convention), with the right quantifier
order ($c$ depends on $H$ only), a correct induced-subgraph encoding (embedding with
adjacency iff), and junk-value-safe boundary behavior at $n \in \{0, 1\}$. I found no
semantic defects. The nits are: the free `k` relies on `autoImplicit` (correct
semantics here, but fragile and against sibling-file practice), and the
scholarship layer is thin — five bare citation keys with no bibliography, the [BNSS23]
key missing from the header list, the page's locators ([Er93, p.346], [Va99, 3.52])
dropped, and no status/provenance record. All addressed in `conjectures-v2/61.lean`
together with the two page-confirmed variants. The input file is untouched.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 20–27: "for every $k$ and every simple graph
  $H$ on $k$ labeled vertices, there is a real $c > 0$ such that for every $n$ and
  every simple graph $G$ on $n$ labeled vertices, if there is no vertex embedding
  $f : \mathrm{Fin}\,k \hookrightarrow \mathrm{Fin}\,n$ with $H.\mathrm{Adj}\,i\,j
  \iff G.\mathrm{Adj}\,(f i)\,(f j)$ for all $i, j$, then some vertex set $S$ with
  $|S| \ge n^c$ is a clique or an independent set in $G$." This matches the recovered
  source statement term by term.
- "For any graph $H$": $H$ ranges over `SimpleGraph (Fin k)` for all $k$. Every finite
  graph is isomorphic to a graph on `Fin k`, and both the induced-containment
  hypothesis and the conclusion are isomorphism-invariant, so the restriction to
  `Fin`-vertexed $H$ loses nothing. (The page's "graph" here means finite graph — the
  statement is about graphs on $n$ vertices.)
- Quantifier order is exactly $c = c(H)$: `∃ c` sits after `H` and before `n`, `G`. A
  single $c$ must serve **all** $n$ — see A2 for why the all-$n$ form is equivalent to
  the "sufficiently large $n$" form used by upstream, so neither reading drifts the
  content (problem-55-class check: no explicit parameter can be absorbed; $c$ cannot
  depend on $n$).
- Induced subgraph: the encoding `∃ f : Fin k ↪ Fin n, ∀ i j, H.Adj i j ↔ G.Adj (f i)
  (f j)` is precisely "the induced subgraph of $G$ on the image of $f$ is isomorphic
  to $H$" — injectivity from `↪`, adjacency both preserved and reflected by the iff.
  It is equivalent to upstream's `∃ g : α ↪ Fin n, H = G.comap g`, since SimpleGraph
  equality is `Adj`-extensionality and `(G.comap g).Adj i j ↔ G.Adj (g i) (g j)`.
  Diagonal terms are harmless: for $i = j$ both sides are false by irreflexivity.
- "Complete graph or independent set on ≥ n^c vertices": `∃ S : Finset (Fin n),
  (S.card : ℝ) ≥ (n : ℝ) ^ c ∧ (IsClique ∨ IsIndepSet)` — non-strict `≥` matches the
  page's $\geq$; the cast puts the comparison in ℝ where `n ^ c` lives.
- Not vacuous, not trivially false (checked per the batch's degenerate-input
  discipline):
  - $k = 0$: the empty embedding always exists and the `∀ i j` is vacuous, so the
    no-induced-$H$ hypothesis is unsatisfiable and the case is vacuously true —
    matching the informal fact that every graph contains the empty graph.
  - $k = 1$: any single vertex is an induced copy (both sides of the iff false), so
    the hypothesis forces $n = 0$, handled below. Matches the informal reading.
  - $n = 0$: `(0 : ℝ) ^ c = 0` for $c > 0$ (rpow junk-safe here), and $S = ∅$ has
    card $0 \ge 0$ with `IsClique ∅` true. True, harmless.
  - $n = 1$: bound $1^c = 1$; a singleton is a clique. True.
  - General case: genuinely the open conjecture — for fixed $c > 0$, $n^c$ eventually
    dominates the Ramsey-guaranteed $\tfrac12\log_2 n$, so no degenerate witness
    satisfies the statement; and $c$ small does not trivialize it.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no division, no `Finset.range`, no `StrictMono`/`Monotone`, no
  filters anywhere in the input.
- `(n : ℝ) ^ c` with `c : ℝ` is `Real.rpow` (the `HPow ℝ ℝ ℝ` instance from the
  imported `Mathlib.Analysis.SpecialFunctions.Pow.Real`). Degenerate-input audit
  (batch checklist: rpow junk values): `0 ^ c = 0` for $c \ne 0$ — the only base-0
  case is $n = 0$, where the bound correctly degenerates to 0, not to the dangerous
  `0 ^ 0 = 1`. No falsification.

  $n^c \le 2$, and every graph on $\ge 2$ vertices has a clique or independent set of
  size 2 (two vertices form an edge or a non-edge); $n \le 1$ is checked in A1. So
  the input's literal all-$n$ reading of the page is sound and neither stronger nor
  weaker in content.

- No default-valued binders (problem-25 class), no `sSup`/`sInf`/`liminf` junk-value
