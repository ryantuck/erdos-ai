## Summary

The problem (recovered verbatim): "Let $M\geq 1$ and $N$ be sufficiently
large in terms of $M$. Is it true that for every Sidon set
$A\subset \{1,\ldots,N\}$ there is another Sidon set
$B\subset \{1,\ldots,N\}$ of size $M$ such that $(A-A)\cap(B-B)=\{0\}$?" At
capture time (2026-03-05) it was OPEN with only $M \le 3$ known (Sedov); it
has since been **solved in the affirmative for all M** — the mirror records
"solved (Lean)" (2026-05-10) and upstream credits GPT 5.5 Pro (prompted by
Sandhu) with a Lean-verified proof. The Lean file defines `IsSidonSet`
(standard B₂ condition on sums) and `DisjointDifferences` (no common nonzero
difference, computed in ℤ), then asserts: for every M ≥ 1 there is N₀ such
that for all N ≥ N₀ and every Sidon A ⊆ [1,N] there is a Sidon B ⊆ [1,N]
with |B| = M and no nonzero difference in common with A. Read back
independently, this is exactly the page's question as a proposition, and the
bare assertion is the true (proved) direction. The only substantive
divergence from the upstream encoding — quantifying over *all* Sidon A
rather than *maximal* Sidon A — follows the page's own wording and is
provably equivalent. No semantic defects; polish-level nits only.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of `conjectures/42.lean:31-42`: "For every
  M ≥ 1 there is a threshold N₀ such that for every N ≥ N₀ and every finite
  Sidon set A with all elements in [1, N], there exists a finite Sidon set B
  with all elements in [1, N], exactly M elements, and no integer other than
  0 expressible both as a difference of two elements of A and as a
  difference of two elements of B." This matches the page statement clause
  by clause: "N sufficiently large in terms of M" = ∃N₀ ∀N ≥ N₀ with N₀
  after M; "Sidon set A ⊆ {1,…,N}" = `IsSidonSet A` + the membership bounds;
  "of size M" = `B.card = M`; "(A−A)∩(B−B) = {0}" = `DisjointDifferences`
  (see the equality-vs-⊆ note below).
- **Arbitrary vs maximal A.** The page (both stored copies of the capture)
  says "for every Sidon set A"; the upstream formal-conjectures encoding
  quantifies over `IsMaximalSidonSetIn A N` instead (its docstring inserts
  "maximal" into the quoted statement). The input follows the page. The two
  are equivalent: any Sidon A ⊆ [1,N] extends to a maximal Sidon A' ⊇ A in
  [1,N] (finite extension), differences of A are differences of A', so a B
  disjoint-difference from A' works for A; the converse is instantiation.
  So the input's (formally stronger-looking) universal is the same
  proposition, and — decisive for polarity — it is *true*, being implied by
  the proved maximal-A statement. Not a defect; documented in v2.
- **"= {0}" vs "no common nonzero difference".** `DisjointDifferences`
  encodes (A−A) ∩ (B−B) ⊆ {0} (implication form). The literal set equality
  additionally needs 0 in the intersection, i.e. A, B ≠ ∅. Here B is forced
  nonempty (|B| = M ≥ 1), but A may be empty (∅ is vacuously Sidon and
  vacuously within bounds), and for A = ∅ the literal equality is
  unsatisfiable while the intended reading ("no common nonzero difference")
  holds trivially. The input's implication form is therefore the *correct*
  formal reading — a literal `= {0}` encoding over arbitrary A would have
  made the theorem false at A = ∅. Good choice, not a defect; the def's
  docstring imprecision about this is a [polish] item (A3).
- **"another" Sidon set.** Not encoded as B ≠ A — correctly so: it is not a
  formal constraint in the source's mathematics. It is also nearly
  automatic: two distinct elements shared by A and B would give a common
  nonzero difference, so `DisjointDifferences A B` forces |A ∩ B| ≤ 1;
  B = A is possible only in the degenerate case |A| = M = 1, harmless.
- Not vacuous, not trivial: for each M the content is a genuine covering
  claim about all (including maximal-size ~√N) Sidon sets; it was open
  until 2026 and its resolution required real work (M ≤ 3 were the only
  known cases at capture).
