## Summary

The problem (recovered verbatim from the archived page): "Let $A(x)$ count the number
of composite $u<x$ such that $n!+1\equiv 0\pmod{u}$ for some $n$. Is it true that
$A(x)\leq x^{o(1)}$?" — a question of Erdős raised in discussions with Hardy and
Subbarao [HaSu02]; status OPEN. The Lean file defines
`IsFactorialWilsonComposite u := 1 < u ∧ ¬Nat.Prime u ∧ ∃ n, u ∣ (n! + 1)`, counts such
`u < x` via `(range x).filter`, and asserts: for every real `ε > 0` there is `N` with
`A(x) ≤ x ^ ε` (real rpow) for all `x ≥ N`. Read back independently, this is exactly
"for every ε > 0, A(x) ≤ x^ε for all sufficiently large x", which is the standard and
correct unfolding of $A(x) \le x^{o(1)}$. The formalization is faithful; the only nits
were scholarship-level (the [HaSu02] key used but never defined in the file; a
docstring reproducing the page's Wilson "iff" without the $u>1$ proviso, which is
literally false at $u=1$). Both fixed.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of `conjectures/1073.lean:40-44`: "for every real
  ε > 0, there exists N such that for all natural x ≥ N, the number of composite
  u < x dividing n!+1 for some n is at most x^ε." The source asks whether
  $A(x) \le x^{o(1)}$; since $A(x) \ge 1$ for $x \ge 26$ (as $25 = 4!+1$ is counted)
  and $A \ge 0$ always, $A(x) \le x^{o(1)}$ is equivalent to: for every $\varepsilon >
  0$, eventually $A(x) \le x^\varepsilon$. Both directions check: (⇐) define
  $f(x) = \inf$ of admissible exponents to get $f = o(1)$; (⇒) given $f \to 0$,
  for $x \ge \max(N_\varepsilon, 1)$ monotonicity of $t \mapsto x^t$ gives
  $x^{f(x)} \le x^\varepsilon$. The theorem docstring states this unfolding explicitly
  and correctly (lines 37–38 pre-edit).
- "Composite $u$": `1 < u ∧ ¬Nat.Prime u` is the correct predicate — it excludes 0, 1,
  and primes, exactly the composite naturals. Equivalent to the upstream file's
  `u.Composite`.
- "$n!+1 \equiv 0 \pmod u$ for some $n$": `∃ n : ℕ, u ∣ (n.factorial + 1)` is exact
  (`u ∣ m ↔ m ≡ 0 [MOD u]`). Allowing $n = 0, 1$ ($n!+1 = 2$) is harmless: the only
  divisor $>1$ is the prime 2, which the compositeness conjunct excludes.
- "$u < x$": `Finset.range x` = $\{0, \dots, x-1\}$ — strict inequality matches the
  source exactly (see A2 for the off-by-one check).
- Not vacuous/trivial: $A(x) \ge 1$ for $x > 25$ and the conjecture is a genuine open
  sparseness question; the statement is not satisfied by any degenerate reading.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere in the Lean code (the "(u-1)!" appears only in docstring
  prose).
- Division: none. The only exponentiation is `(x : ℝ) ^ ε` — `Real.rpow` via the
  imported `Mathlib.Analysis.SpecialFunctions.Pow.Real`. At the irrelevant boundary
  `x = 0` (excluded by any `N ≥ 1`, but even if `N = 0`): `A(0) = 0 ≤ 0 = 0^ε` for
  `ε > 0`; harmless either way.
- `Finset.range x` off-by-one: source counts $u < x$ strictly; `range x` is
  $\{0,\dots,x-1\}$, i.e. exactly $u < x$. Term-by-term exact, no shift.
- Vacuous quantifiers: none. The `∃ N, ∀ x ≥ N` prefix is the intended "sufficiently
  large" and cannot vacuously discharge (ℕ is unbounded).
- "For all sufficiently large" encoding: the explicit `∃ N, ∀ x, N ≤ x → …` is
  equivalent to `∀ᶠ x in atTop, …`; a filter was not needed and the explicit form is
  correct.
- `Decidable` for the `filter`: the predicate is a `Prop`; `open Classical` (line 7)
  brings the scoped low-priority `Classical.propDecidable` instance into scope, and the
  `noncomputable` marking is consistent with that. The originating session's
  `lake build conjectures/1073.lean` succeeded (sole warning: the expected `sorry`), so
  this is compile-verified historically.
- No `StrictMono`/`Monotone`, interval-endpoint, or liminf/limsup issues arise.

**A3. Definitions — pass.**

- `IsFactorialWilsonComposite` (lines 16–17 pre-edit) matches its docstring and the
  source's "composite $u$ with $u \mid n!+1$ for some $n$", including degenerate inputs
  (0 and 1 excluded by `1 < u`). No `sorry` in any `def`.
- `factorialWilsonCompositeCount` (lines 23–24 pre-edit) matches its docstring ("counts
  composite u < x …"); `factorialWilsonCompositeCount 0 = 0`, consistent with $A(0)=0$.
- No drift between the defs and the theorem's use of them.

**A4. Question form and answer polarity — pass for raw style (noted for styling).**

- The source is a **yes/no question** ("Is it true that $A(x)\leq x^{o(1)}$?"), OPEN.
  The raw file states the conjectured "yes" direction as a direct assertion with
  `sorry` proof — the uniform convention of this repo's `conjectures/` raw files (cf.
  `conjectures/1072.lean`, `conjectures/1074.lean`), and the polarity asserted is the
  direction Erdős conjectured. Per the review protocol, raw files are judged on
  soundness, not styled `answer()` form; **no defect**. The theorem docstring
  faithfully preserves the question form ("Is it true that A(x) ≤ x^{o(1)}?") before
  giving the assertional unfolding — the 1005-style question-dropping drift is absent.
- Any future restyling to `deepmind/` form should use
  `answer(sorry) ↔ (∀ ε > 0, ∃ N, ∀ x ≥ N, A x ≤ x ^ ε)` per corpus convention for
  open yes/no questions. For comparison, the upstream deepmind file (recovered from the
  logs) indeed uses `answer(sorry) ↔ ∃ (o : ℕ → ℝ), o =o[atTop] (1 : ℕ → ℝ) ∧
  ∀ x, A x ≤ x ^ (o x)` — a literal $x^{o(1)}$ witness encoding. The two encodings are
  equivalent (the upstream `∀ x` including small $x$ is absorbable because `o` is
  unconstrained off the tail and `A x = 0 ≤ x ^ o x` needs care only at tiny $x$, where
  `o` can be chosen large); this file's ∀ε form is arguably the cleaner unfolding and
  its docstring says exactly what it formalizes.
- No binders before the colon that misplace quantification (line 40 is binder-free; the
  ∀ε is part of the asserted proposition, which is correct for a direct assertion).

**A5. Solution status — pass (source-verified).**

- Recovered page banner: **OPEN**, tooltip "This is open, and cannot be resolved with a
  finite computation.", with the site owner's standard disclaimer. The file (raw style,

## C. Craftsmanship

**C1. Readability — good, one accuracy nit (fixed).**
