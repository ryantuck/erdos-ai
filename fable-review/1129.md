## Summary

The problem ([Er47, p.1171], [Er67, p.66]): for $x_1,\ldots,x_n \in [-1,1]$
and Lagrange basis polynomials $l_k(x) = \prod_{i\neq k}(x-x_i)/(x_k-x_i)$,
describe which choice of $x_i$ minimises the Lebesgue constant
$\Lambda = \max_{x\in[-1,1]}\sum_k |l_k(x)|$. Status: PROVED. The known
answer: Erdős and Bernstein conjectured the minimising nodes are unique and
characterised by equioscillation of the Lebesgue function's local maxima
$\lambda_i$; Kilgore–Cheney [KiCh76] proved equioscillating nodes exist,
Kilgore [Ki77] proved $\Lambda$ is minimised only when all $\lambda_i$ are
equal, and de Boor–Pinkus [dBPi78] proved the minimising choice is unique.
The Lean theorem (`conjectures/1129.lean:63-73`) asserts: for every n ≥ 2
there is a strictly increasing configuration in $[-1,1]$ that minimises
$\Lambda$, is the **unique** minimiser among all strictly increasing
configurations, and satisfies the **(n+1)-interval** equioscillation property
(with artificial endpoints $x_0 = -1$, $x_{n+1} = 1$). Read literally, this
proposition is **false for every n ≥ 3**: the Lebesgue constant's inter-node
local maxima are invariant under affine maps of the node set, so the
minimiser is a continuum, not a point, and the canonical minimiser (e.g.
$(-1,0,1)$ for n = 3) fails the (n+1)-interval equioscillation because its
outer subintervals are degenerate singletons with local maximum 1. The
proved theorems live in the canonical normalisation $x_1 = -1$, $x_n = 1$
with equioscillation over the n − 1 inter-node intervals. This is a
[defect]-class Part A finding; everything else in the file (the definitions
of `lagrangeBasis`, `lebesgueFunction`, `lebesgueConstant`, `boundary`) is
correct.

## A. Semantic fidelity

**A1. Statement fidelity — FAIL (source-verified): the theorem formalizes a
false proposition.**

- Recovered verbatim source statement (see Addendum): "For
  $x_1,\ldots,x_n\in [-1,1]$ let $l_k(x)=\frac{\prod_{i\neq k}(x-x_i)}
  {\prod_{i\neq k}(x_k-x_i)}$ … Describe which choice of $x_i$ minimise
  $\Lambda(x_1,\ldots,x_n)=\max_{x\in [-1,1]} \sum_k \lvert l_k(x)\rvert$."
  Remarks: Erdős thought the minimising choice is characterised by all
  $\lambda_i=\max_{x\in [x_i,x_{i+1}]}\sum_k \lvert l_k(x)\rvert$ being
  equal for $0\leq i\leq n$ (with $x_0=-1$, $x_{n+1}=1$); [KiCh76] existence;
  [Ki77] "minimised only when all $\lambda_i$ are equal"; [dBPi78] "unique
  minimising choice". Separately: "If $x_1=-1$ and $x_n=1$ then there is a
  unique minimising set of $x_i$, which are symmetric around $0$."
- Independent back-translation of `conjectures/1129.lean:63-73`: "for n ≥ 2
  there exists a strictly increasing `opt` in [−1,1]ⁿ such that (1) Λ(opt) ≤
  Λ(nodes) for all strictly increasing nodes in [−1,1]ⁿ; (2) any such nodes
  with Λ(nodes) = Λ(opt) equal opt; (3) the sSup of the Lebesgue function is
  equal across all n+1 subintervals cut out by −1, x₁, …, xₙ, 1."
- **The conjunction is false for every n ≥ 3.** Proof of non-uniqueness:
  each $l_k$ depends only on ratios of differences of nodes, so for an
  affine map $\phi$, $L_{\phi(\mathbf{x})}(\phi(t)) = L_{\mathbf{x}}(t)$ —
  the inter-node part of the Lebesgue function is affinely invariant. Take
  the canonical minimiser $\mathbf{x}^*$ (endpoints ±1 among its nodes,
  minimal value $\Lambda^* > 1$ for n ≥ 3) and shrink: $r\mathbf{x}^*$ for
  $r < 1$ near 1. The inter-node local maxima remain exactly $\Lambda^*$;
  the outer maxima $\max_{[rx_n^*,\,1]} L$ grow continuously from
  $L(1) = 1 < \Lambda^*$ at $r = 1$, so for $r$ close to 1 we get
  $\Lambda(r\mathbf{x}^*) = \Lambda^*$: a continuum of minimisers. (The
  same affine argument shows the free minimum equals the canonical minimum,
  so these really are global minimisers.) Concretely for n = 3: every
  configuration $(-s, 0, s)$ with $2\sqrt2/3 \le s \le 1$ has
  $\Lambda = 5/4$ — on $[0,s]$, $L(x) = 1 + x(s-x)/s^2$ with maximum $5/4$
  at $x = s/2$ *independent of s*, and $L(1) = (2-s^2)/s^2 \le 5/4$ iff
  $s \ge 2\sqrt2/3$. Numerically verified (see Addendum): $(-1,0,1)$,
  $(-0.943,0,0.943)$, $(-0.95,0,0.95)$, $(-0.97,0,0.97)$ all give
  $\Lambda = 1.25$ to 6 decimal places, while a 1500-point random search
  found nothing below 1.25; for n = 4 the Rack–Vajda canonical minimiser
  scaled by r ∈ {0.999, …, 0.98} keeps Λ = 1.4231. So conjunct (2) fails
  for whatever `opt` witnesses conjunct (1).
- The equioscillation conjunct also cannot be satisfied by the canonical
  minimisers: for $(-1,0,1)$ the subinterval $[x_0, x_1] = \{-1\}$ is a
  singleton with local maximum $L(-1) = 1 \neq 5/4 = \lambda_1$. (An
  interior minimiser — the maximally-shrunk one — does satisfy it, but the
  uniqueness conjunct still kills the ∃.)
- Root cause: the page's remarks state Kilgore's and de Boor–Pinkus's
  results loosely in the free-node formulation of the problem box, but those
  theorems hold in the canonical normalisation $x_1 = -1$, $x_n = 1$ (the
  page's own "canonical" paragraph), with equioscillation over the n − 1
  intervals between consecutive nodes. Rendered literally at face value the
  remark is false at small parameters — the same failure class as the
  EPS87 bound in fable-review/1004 (page-stated claim false as literally
  quantified; formalize the corrected version and document the
  counterexample). **[defect: missing-normalization]** — fixed in
  `conjectures-v2/1129.lean` (not compile-verified).
- n = 2 sanity check of the corrected form: the only canonical pair is
  $(-1,1)$, whose Lebesgue function is identically 1; every valid
  configuration has $\Lambda \ge 1$ (L equals 1 at any node); and the
  free-node minimiser is genuinely unique here (if $x_2 < 1$ then
  $l_2(1) = (1-x_1)/(x_2-x_1) > 1$ so $L(1) > 1$; symmetrically for
  $x_1 > -1$). The original statement was true at n = 2 — the defect bites
  exactly at n ≥ 3, all included under `hn : 2 ≤ n`.

## E. Prior-review audit (`deepmind/ai-review/1129.md`)

The prior review is thorough on surface mechanics and correctly reports the
page's remark content, but it fails on the central question and makes two
checkable false claims:

1. **Fatal miss — endorses a false theorem.** Its §6 rates the theorem
   "Mathematically sound", ticking existence, minimality, uniqueness, and
   equioscillation each with a ✓. As shown in A1, the uniqueness conjunct is
   false for every n ≥ 3 (continuum of minimisers by affine invariance),
   and the equioscillation conjunct fails at the canonical minimisers. Most
   strikingly, its own §6 contains the key insight pointed the wrong way:
   it praises `StrictMono` because "the Lebesgue constant is
   permutation-invariant, so without an ordering constraint, minimizers

   kills uniqueness), missing that a second invariance (affine, not just
   permutation) survives the ordering constraint and kills uniqueness
   anyway. This is the recurring prior-review failure pattern of

   cases (cf. the 1000 and 1005 audits); here checking n = 3 against the
   page's own "for n = 3 the points are −1, 0, 1 (with Λ = 1.25)" datum

   minimiser).

   recovered page cites **[Be31]** four times (the lower bound, the
   conjecture's co-attribution, and the n = 3 case), and the recovered
