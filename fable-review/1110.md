## Summary

The problem (verbatim from the recovered page): "Let $p>q\geq 2$ be two coprime
integers. We call $n$ representable if it is the sum of integers of the form $p^kq^l$,
none of which divide each other. If $\{p,q\}\neq \{2,3\}$ then what can be said about
the density of non-representable numbers? Are there infinitely many coprime
non-representable numbers?" — status **OPEN**, a problem of Erdős and Lewin [ErLe96],
who proved that finitely many non-representable numbers exist iff $\{p,q\} = \{2,3\}$;
Yu–Chen [YuCh22] proved the representable numbers have density zero and that
infinitely many coprime non-representable numbers exist for most parameter ranges. The
Lean theorem (`conjectures/1110.lean:57-61`) asserts: for all coprime naturals
$p > q \ge 2$ with $(p,q) \ne (3,2)$, the set of $n$ that are non-representable and
coprime to $pq$ is infinite. Read back independently, this is exactly the conjectured
affirmative direction of the problem's second (precise, yes/no) question, correctly
scoped and correctly excluding $\{2,3\}$; the first question ("what can be said about
the density?") is open-ended soft framing carrying no precise formalizable conjecture,
so its absence is not a defect — the page-confirmed Yu–Chen density partial results
are optional enrichment, added as variants in v2. I found no semantic defects.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 57–61: "for every pair of naturals $p, q$ with
  $2 \le q < p$, $\gcd(p,q) = 1$, and not ($p = 3$ and $q = 2$), the set
  $\{n : n \text{ not } (p,q)\text{-representable and } \gcd(n, pq) = 1\}$ is
  infinite." This is precisely the affirmative answer to "Are there infinitely many
  coprime non-representable numbers?" for every admissible parameter pair outside
  $\{2,3\}$ — the question as asked, with the hypothesis "If $\{p,q\} \ne \{2,3\}$"
  rendered as the `¬(p = 3 ∧ q = 2)` guard.
- The exclusion encoding is exact: under $2 \le q < p$, $\{p,q\} = \{2,3\}$ holds iff
  $p = 3 \wedge q = 2$ (the order forces it; coprimality is not even needed), so
  `¬(p = 3 ∧ q = 2)` excludes exactly the $\{2,3\}$ case. The theorem docstring says
  this explicitly and correctly. The exclusion is *necessary*: by [ErLe96] (indeed by
  the [Er92b]/Jansen result that every positive integer is $\{2,3\}$-representable),
  the $(3,2)$ instance of the conclusion is false.
- "Coprime non-representable numbers" is read as $\gcd(n, pq) = 1$
  (`Nat.Coprime n (p * q)`, equivalent to coprime to both $p$ and $q$) — the standard
  reading, and the one consistent with the page's presentation of Yu–Chen's results on
  "coprime non-representable numbers".
- "Sum of integers of the form $p^kq^l$, none of which divide each other" is encoded
  as a `Finset ℕ` of `IsPQPower`s forming a divisibility antichain, summing to $n$.
  The `Finset` forces distinct summands, which loses no generality: a repeated summand
  would divide itself, violating "none of which divide each other" — and [Er92b]'s
  phrasing ("sum of *distinct* integers of the form $2^k3^l$") confirms distinctness
  is intended. `S.Nonempty` correctly blocks the empty sum from making 0 vacuously
  representable (single-term sums remain allowed, as they should be: any $p^aq^b$ is
  itself representable).
- Types: everything in ℕ is appropriate ($p > q \ge 2$, $n$ a nonneg. integer; no
  subtraction or division occurs). No indexing conventions arise (no sequences).
- Not vacuous, not trivially false: the parameter hypotheses are satisfiable (e.g.
  $(p,q) = (5,2)$), the conclusion is a substantive infinitude claim proved by
  [YuCh22] for all but three pairs and open for $(5,2), (9,2), (5,3)$, and no
  degenerate $n$ trivializes `Set.Infinite`.

**A2. Lean semantics traps — pass on all checklist items.**

**C2. Reuse — one flag (static judgment).**

- `IsDivisibilityAntichain S` duplicates Mathlib's `IsAntichain (· ∣ ·) (S : Set ℕ)`
  (`Mathlib.Order.Antichain`): for the reflexive relation `∣` on a set's distinct
  elements, `a ≠ b → ¬a ∣ b` is equivalent to the file's `x ∣ y → x = y`. The prior
  review flagged this too, and the archived styled copy adopted `IsAntichain`. In
  this raw pipeline the swap would add an import and is compile-dependent, so it is
  *flagged, not applied*; v2 documents the equivalence in the def's docstring.
- `IsPQPower` and `IsRepresentable` have no Mathlib counterparts (correct to define
  locally; `Nat.Coprime`, `Finset.sum`, `Set.Infinite` are the right library
  notions).
