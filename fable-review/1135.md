## Summary

The problem is the infamous **Collatz conjecture**, in the "shortcut" form used by the
source page: define $f:\mathbb{N}\to\mathbb{N}$ by $f(n)=n/2$ for even $n$ and
$f(n)=\frac{3n+1}{2}$ for odd $n$; given any integer $m\geq 1$, does there exist
$k\geq 1$ such that $f^{(k)}(m)=1$? The page status is **OPEN** with a \$500 prize
banner (with an explicit caveat that Erdős never formally offered it). The Lean file
defines `collatzStep` (exactly the shortcut map), `collatzIter` (the $k$-th iterate),
and asserts `∀ m : ℕ, 1 ≤ m → ∃ k : ℕ, 1 ≤ k ∧ collatzIter k m = 1`. Read back
independently, the Lean says precisely what the page asks, in the asked ("yes")
direction, per this corpus's raw-file convention for open questions. I found **no
Part A defects**. The one checklist failure is B1: the theorem docstring cites
`[La85, Er97e, La16]` but the file contains no bibliography at all — fixed in
`conjectures-v2/1135.lean` from log-recovered data. A minor docstring nit (a conflated
quote attribution) is also fixed there.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement: "Define $f:\mathbb{N}\to \mathbb{N}$ by
  $f(n)=n/2$ if $n$ is even and $f(n)=\frac{3n+1}{2}$ if $n$ is odd. Given any integer
  $m\geq 1$ does there exist $k\geq 1$ such that $f^{(k)}(m)=1$?" The module-level
  docstring (`conjectures/1135.lean:18-26`) reproduces this faithfully.
- `collatzStep` (lines 6–7) is exactly the page's $f$ — note the page uses the
  **shortcut** odd step $(3n+1)/2$, not the classic $3n+1$, and the Lean matches the
  page (a formalizer reaching for the "well-known" classic map here would have been a
  defect; that did not happen).
- `collatzIter k n` (lines 12–15) is $f^{(k)}(n)$ with `collatzIter 0 n = n` and
  `collatzIter (k+1) n = f (collatzIter k n)` — the standard iterate, so
  `collatzIter k m = f^{(k)}(m)` for every $k$.
- Independent back-translation of the theorem (lines 28–30): "for every natural
  $m \geq 1$ there is a natural $k \geq 1$ with $f^{(k)}(m) = 1$". Quantifier order
  (∀m ∃k), both lower bounds ($m\geq 1$, $k\geq 1$), and the target value $1$ all
  match the source term-for-term.
- Types: $f:\mathbb{N}\to\mathbb{N}$ on the page, `ℕ → ℕ` in Lean; "any integer
  $m \geq 1$" is exactly `m : ℕ, 1 ≤ m`. No coercions needed; all arithmetic is in ℕ
  where the source intends it.
- The `1 ≤ k` conjunct is not vacuously satisfiable and matters at $m = 1$:
  `collatzIter 0 1 = 1` would satisfy a $k \geq 0$ version trivially at that point,
  whereas the source demands $k \geq 1$ ($f(1) = 2$, $f^{(2)}(1) = 1$, so the cycle
  $1 \to 2 \to 1$ makes the statement still true there — but the encoding follows the
  source's letter, not an equivalent-but-loosened form).
- Not vacuous/trivial: this is the genuine open conjecture; no degenerate witness
  satisfies it structurally (each $m$ requires an actual trajectory computation, and
  the universal over all $m \geq 1$ is the full strength of the conjecture).

**A2. Lean semantics traps — pass.**

- **ℕ division is exact in both branches of `collatzStep`:** if `n % 2 = 0` then
  $2 \mid n$ and `n / 2` is exact; otherwise $n$ is odd, so $3n+1$ is even and
  `(3 * n + 1) / 2` is exact. No silent flooring anywhere.
- No ℕ subtraction anywhere.
- No `Finset.range`, so no off-by-one; the iterate recursion was checked at its base
  case (`k = 0` gives the identity, as $f^{(0)}$ should).
- No bounded quantifiers, so no vacuity trap. The hypotheses `1 ≤ m` and `1 ≤ k` are
  ordinary conjuncts/antecedents, both satisfiable.
- Degenerate input $n = 0$: `collatzStep 0 = 0` (fixed point), but $m = 0$ is excluded
  by `1 ≤ m`, and trajectories from $m \geq 1$ never reach $0$ (odd $n \geq 1$ maps to
  $(3n+1)/2 \geq 2$; even $n \geq 2$ maps to $n/2 \geq 1$), so the junk fixed point at
  $0$ is unreachable and harmless.
- No filters, densities, or "infinitely many" encodings; no
  `StrictMono`/`Monotone`/interval subtleties arise.

**A3. Definitions — pass.**

- `collatzStep` matches its docstring and the source's $f$ exactly, including the
  degenerate $n = 0$ case discussed above.
- `collatzIter` matches its docstring ("the k-th iterate"); the recursion is
  structurally well-founded on `k` and agrees with $f^{(k)}$ at every index, starting
  with the correct base $f^{(0)} = \mathrm{id}$.
- No `sorry` in any `def`; the only `sorry` is the theorem proof body.
- No drift: the theorem uses `collatzIter` exactly as defined.

**A4. Question form and answer polarity — pass (raw-corpus convention).**

- Notably, the upstream `formal-conjectures` file for this problem (recovered from the
