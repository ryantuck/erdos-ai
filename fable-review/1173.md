## Summary

The problem ([Ko25b, Problem 35] [Va99, 7.88], OPEN; a problem of Erdős and
Hajnal): assume GCH; let f : ω_{ω+1} → [ω_{ω+1}]^{≤ ℵ_ω} be a set mapping with
|f(α) ∩ f(β)| < ℵ_ω for all α ≠ β — does there exist a free set of cardinality
ℵ_{ω+1}? The Lean file (`conjectures/1173.lean`) defines `GCH` (∀ o, 2^ℵ_o =

theorem asserts: given `GCH`, any `f` with `#(f α) ≤ lift ℵ_ω` and
`#(f α ∩ f β) < lift ℵ_ω` (α ≠ β) admits a free `H` with `lift ℵ_{ω+1} ≤ #H`.

question, in the corpus's direct-assertion convention for open yes/no questions

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Assume the generalised
  continuum hypothesis. Let \[f: \omega_{\omega+1}\to [\omega_{\omega+1}]^{\leq
  \aleph_\omega}\] be a set mapping such that \[\lvert f(\alpha)\cap
  f(\beta)\rvert < \aleph_\omega\] for all $\alpha\neq \beta$. Does there exist
  a free set of cardinality $\aleph_{\omega+1}$?" The module docstring
  reproduces this essentially verbatim.
- Independent back-translation of lines 50–58: "GCH implies: for every
  f : ω_{ω+1} → P(ω_{ω+1}) with every image of size ≤ ℵ_ω and pairwise
  intersections of size < ℵ_ω, there is a free set of size ≥ ℵ_{ω+1}." This is
  the asked direction of the question, with all three hypotheses (GCH, image
  bound, intersection bound) as explicit binders.
- Quantifier structure: `(h : GCH) (f …) (hf …) (hfI …) : ∃ H, …` — universal
  over set mappings, existential over the free set, matching "let f be … does
  there exist …". `hfI` quantifies over ordered pairs with `α ≠ β`, which is
  equivalent to the source's unordered "for all α ≠ β" by symmetry of `∩`.
- Types: elements are the subtype `{α : Ordinal // α < omegaOmega1}` — the
  correct concrete carrier for "ordinals below ω_{ω+1}"; images are `Set` of
  that subtype; cardinality comparisons happen in `Cardinal.{1}` with
  `Cardinal.lift.{1,0}` on the aleph side. Since `Ordinal.{0} : Type 1`, the
  subtype lives in `Type 1` and the lift is genuinely required; `lift.{1,0} :
  Cardinal.{0} → Cardinal.{1}` is the right direction.
- "Of cardinality ℵ_{ω+1}" is encoded as `lift ℵ_{ω+1} ≤ #H`. Correct: H is a
  subset of a type of cardinality `lift ℵ_{ω+1}` (the subtype of ordinals below
  `(aleph (ω+1)).ord` has cardinality `lift ((aleph (ω+1)).ord.card) =
  lift ℵ_{ω+1}`), so `≤` forces equality — the standard corpus encoding.
- **Set-mapping convention (the one subtle point), re-derived by hand.**
  Classically a set mapping requires α ∉ f(α) and H is free iff f(α) ∩ H = ∅
  for all α ∈ H. The file omits α ∉ f(α) and weakens freeness to
  `f α ∩ H ⊆ {α}`. The two problems are equivalent: given f as in the file,
  set g(α) = f(α) \ {α}; then (i) g is a classical set mapping; (ii) H is free
  for f in the file's sense iff free for g classically (for α ∈ H,
  g(α) ∩ H = (f(α) ∩ H) \ {α}, which is empty iff f(α) ∩ H ⊆ {α}); and
  (iii) — the step the prior review skipped — g inherits both cardinality
  hypotheses, since |g(α)| ≤ |f(α)| ≤ ℵ_ω and g(α) ∩ g(β) ⊆ f(α) ∩ f(β).
  Conversely a classical g is itself an admissible f with the same free sets.
  So the encoding is faithful.
- Not vacuous / not trivially false: the hypotheses are satisfiable (f ≡ ∅),
  the empty H does not satisfy the cardinality conclusion, and the
  intersection hypothesis is load-bearing — without it, f(α) = {β | β < α}
  has |f(α)| ≤ ℵ_ω yet admits no free set of size 2 (for α < β both in H,
  α ∈ f(β) ∖ {β}), so the question would be trivially "no"; that f is excluded
  precisely because |f(α) ∩ f(β)| = |min(α,β)| = ℵ_ω for suitable pairs. The
  formal statement therefore poses a genuine open question. (Hajnal's set
  mapping theorem does not apply: it needs |f(α)| < λ < κ, and here the image
  bound ℵ_ω is only one cardinal below κ = ℵ_{ω+1}.)
