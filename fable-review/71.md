## Summary

The problem (erdosproblems.com/71): is it true that for every infinite
arithmetic progression $P$ which contains even numbers there is some constant
$c = c(P)$ such that every graph with average degree at least $c$ contains a
cycle whose length is in $P$? Status **PROVED** ("solved in the affirmative"),
by Bollobás [Bo77]; Erdős credits the conjecture to himself and Burr in
[Er82e]. The Lean statement (`conjectures/71.lean:15-22`) asserts: for all
`a d : ℕ` with `1 ≤ d` and some even element `a + k*d`, there is `c : ℝ`,
`c > 0`, such that every finite nonempty simple graph with
`2·|E| / |V| ≥ c` contains a cycle whose length lies in `{a + k*d : k ∈ ℕ}`.
That is exactly the affirmative direction of the question, in direct-assertion
form — acceptable for a solved problem in this pipeline, and the polarity is
the true one. I found no semantic defects; the findings are scholarship- and
docstring-level only (the docstring's "Erdős-Burr conjecture" label is
misleading, and three of the page's four citation keys are missing).

## A. Semantic fidelity

### A1. Statement fidelity — PASS

Independent back-translation of `conjectures/71.lean:15-21`: "For all naturals
$a, d$ with $d \ge 1$ such that $a + kd$ is even for some $k$, there exists a
real $c > 0$ such that for every finite type $V$ with at least one element and
every simple graph $G$ on $V$, if $c \le 2|E(G)|/|V|$ then there exist $m$ of
the form $a + kd$, a vertex $v$, and a closed walk $p$ from $v$ that is a cycle
of length $m$." Diffed against the recovered verbatim statement:

- "infinite arithmetic progression $P$" ↦ $\{a + kd : k \in \mathbb{N}\}$ with
  $d \ge 1$. Every such pair gives an infinite AP of naturals (distinct $k$
  give distinct elements when $d \ge 1$), and every infinite AP of naturals is
  of this form; the upstream formal-conjectures encoding via
  `P.IsAPOfLength ⊤` is an equivalent parametrization. The $a = 0$ case adds
  $0 \in P$, which is harmless: `heven` becomes automatic (`Even 0`), but the
  assertion remains a true instance of Bollobás' theorem, since
  $\{d, 2d, \dots\} \subseteq P$ is itself an AP containing the even number
  $2d$, so the theorem for $(a', d') = (d, d)$ supplies the required cycle.
  No falsity or vacuity introduced.
- "contains even numbers" ↦ `∃ k : ℕ, Even (a + k * d)` — correct (one even
  element forces infinitely many, since $a + kd$ even implies $a + (k+2)d$
  even, so singular/plural is a non-issue).
- "graph" ↦ finite simple graph. Finiteness is the standard reading for
  average-degree extremal statements (the prior review argues this too, and
  the upstream file also restricts to `Fintype V`); correct.
- "average degree at least $c$" ↦ `c ≤ 2·|edgeFinset| / |V|` in ℝ with a
  `0 < Fintype.card V` guard — the standard $2|E|/n$ definition, non-strict
  as "at least" requires.
- "some constant $c = c(P)$" ↦ `∃ c : ℝ, c > 0 ∧ …` placed *outside* the
  graph quantifier and *inside* the AP parameters — precisely $c$ depending
  on $P$ only. The added `c > 0` is a harmless strengthening: any witness
  $c$ may be replaced by $\max(c, 1)$ (raising the threshold only shrinks the
  set of graphs constrained). Existence, not optimality, is what the problem
  asks (the page: "the best dependence of the constant $c(P)$ is unknown"),
  so `∃ c` is the right shape and is *not* trivially provable — it is
  Bollobás' theorem.
- "a cycle whose length is in $P$" ↦
  `∃ m, (∃ k, m = a + k * d) ∧ ∃ v p, p.IsCycle ∧ p.length = m` — a cycle
  (Mathlib `Walk.IsCycle`) with length in the AP. Correct.

Not vacuous, not trivially true; the hypothesis is satisfiable (e.g. $a = d =
1$) and the conclusion is a genuine theorem.

### A2. Lean semantics traps — PASS

- **ℕ subtraction:** none occurs.
- **Division:** the only division is real, and guarded by
  `0 < Fintype.card V` (line 18), so the denominator is nonzero. (Even
  unguarded it would be safe: $0/0 = 0 < c$.)
- **`Finset.range`:** not used.
- **Vacuous bounded quantifiers:** none. The `heven` hypothesis is genuinely
  restrictive in the intended cases (e.g. excludes odd-only APs like
  $a$ odd, $d$ even, where bipartite $K_{n,n}$ would refute the claim).
- **Filter encodings:** none needed — no liminf/limsup/junk-value risk
  (problem-33 class: n/a).
- **Strictness:** `c ≤ avg` matches "at least"; `1 ≤ d` makes the AP
  genuinely infinite; `c > 0` strict as intended.
- **Default-valued binders (problem-25 class):** none.
- **Constant quantifier order (problem-55 class):** checked explicitly above —
  `∃ c` correctly sits between the AP parameters and the graph quantifier.
- **Degenerate inputs:** empty graph excluded by the card guard; a
  one-vertex graph has average degree 0 < c, hypothesis false; elements
  $0, 1, 2 \in P$ cannot be spuriously witnessed since `IsCycle` (Mathlib
  `Paths.lean:84`, pinned rev: `IsTrail ∧ p ≠ nil ∧ p.support.tail.Nodup`)
  forces length ≥ 3 in a simple graph.
