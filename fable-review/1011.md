## Summary

The problem: let $f_r(n)$ be minimal such that every graph on $n$ vertices with
$\geq f_r(n)$ edges and chromatic number $\geq r$ contains a triangle; determine
$f_r(n)$. The page status is **OPEN**; the known results are the exact values
$f_2(n) = \lfloor n^2/4\rfloor + 1$ (Turán), $f_3(n) = \lfloor (n-1)^2/4\rfloor + 2$
(Erdős–Gallai [Er62d]), $f_4(n) = \lfloor (n-3)^2/4\rfloor + 6$ for $n \geq 150$
([RWWY24]), and Simonovits's asymptotic $f_r(n) = n^2/4 - g(r)n/2 + O(1)$ [Si74]. The
Lean file (`deepmind/1011.lean`) defines $f_r(n)$ as an `sInf` over edge-count
thresholds (`minTriangleEdges`, line 68) and states the solved Simonovits asymptotic as
a direct assertion (`erdos_1011`, line 83): for every $r \geq 2$ there exist
$g_r \in \mathbb{R}$, $C \geq 0$ with $|f_r(n) - (n^2/4 - g_r n/2)| \leq C$ for all
large $n$. Read back independently, the definition captures $f_r(n)$ exactly and the
theorem is a faithful (if deliberately existential-in-$g_r$) rendering of the Simonovits
result; the choice to formalize the solved asymptotic rather than the unformalizable
"Determine $f_r(n)$" is documented in the docstring and sound. No semantic defects found.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $f_r(n)$ be minimal such
  that every graph on $n$ vertices with $\geq f_r(n)$ edges and chromatic number
  $\geq r$ contains a triangle. Determine $f_r(n)$." The module docstring reproduces
  this verbatim.
- `minTriangleEdges r n = sInf {m | ∀ G : SimpleGraph (Fin n), G.edgeSet.ncard ≥ m →
  (r : ℕ∞) ≤ G.chromaticNumber → ¬G.CliqueFree 3}` back-translates to: the least $m$
  such that every $n$-vertex graph with at least $m$ edges and chromatic number
  $\geq r$ contains a triangle. Exactly $f_r(n)$. The defining set is upward-closed in
  $m$ (more edges required means fewer graphs constrained... precisely: if every graph
  with $\geq m$ edges satisfies the property, every graph with $\geq m+1$ edges is
  among them), and nonempty ($m = \binom{n}{2}+1$ makes the edge hypothesis
  unsatisfiable), so `sInf` on ℕ returns the genuine minimum — a well-defined threshold.
- Independent back-translation of `erdos_1011`: "for every natural $r \geq 2$ there
  exist reals $g_r$ and $C \geq 0$ such that for all sufficiently large $n$,
  $|f_r(n) - (n^2/4 - g_r/2 \cdot n)| \leq C$." This is precisely
  $f_r(n) = n^2/4 - g_r n/2 + O(1)$, the Simonovits asymptotic. The existential over
  $g_r$ does not pin $g_r$ to the page's combinatorial definition of $g(r)$ (largest
  $m$ such that every triangle-free graph with $\chi \geq r$ needs $\geq m$ vertex
  deletions to become bipartite) — a deliberate weakening, honestly documented in the
  theorem docstring ("formalizes the solved Simonovits asymptotic, not the full open
  problem of determining $g_r$ precisely").
- Quantifier order: $g_r, C$ are chosen after $r$ but uniformly in $n$ — correct for
  $O(1)$ with $r$ fixed, matching the source (the $O(1)$ is per-$r$).
- Types: vertex type `Fin n` correctly models labeled $n$-vertex graphs (edge count and
  chromatic number are isomorphism-invariant, so labeling is immaterial); comparison
  `(r : ℕ∞) ≤ G.chromaticNumber` is in the right type (Mathlib's `chromaticNumber` is
  `ℕ∞`); the asymptotic inequality is cast into ℝ before any subtraction. All appropriate.
- Not vacuous/trivial: the statement pins the sequence $n^2/4 - f_r(n)$ to within $O(1)$
  of a *linear* function — false for a generic quadratically-bounded sequence (e.g. one
  with an $n^{3/2}$ term), so the content is genuine; and since $C$ is fixed before $n$,
  no cheap witness exists.
- Degenerate parameters: for $n \leq 1$ (and $r \geq 2$) no graph attains
  $\chi \geq r$, every $m$ is in the set, and `minTriangleEdges r n = 0`; invisible to
  the `atTop` statement and consistent with the (empty) informal convention.

**A2. Lean semantics traps — pass.**

- ℕ subtraction: none in the pre-fix file (all arithmetic in the theorem is in ℝ after
  coercion). The added variants use `(n - 1)` and `(n - 3)` in ℕ under hypotheses
  $n \geq 5$, $n \geq 150$ respectively, which guard truncation.
- Division: `/ 4` and `/ 2` in the theorem are ℝ-division by nonzero literals — exact.
  In the added variants, ℕ-division `… ^ 2 / 4` is floor division — which is exactly
  the $\lfloor \cdot \rfloor$ the source formulas demand.
- `Finset.range`: not used. No off-by-one surface.
- Vacuous quantifiers: only the harmless $n \leq 1$ degeneracy noted in A1.
- "For all sufficiently large $n$" is encoded as `∀ᶠ n in atTop` — standard and correct.
- No `StrictMono`/`Monotone` or interval-endpoint issues. `¬G.CliqueFree 3` is the
  correct encoding of "contains a triangle"; `G.edgeSet.ncard` is the correct finite
  edge count on `Fin n`.

**A3. Definitions — pass.**

**B2. Variants and completeness — pass; page-confirmed enrichment applied.**

- The problem is single-part; the solved core is captured. The three exact values
  stated on the page are concrete formalizable identities and were added as variants
  (Addendum fix 3): `turan_f2`, `erdos_gallai_f3`, `ren_wang_wang_yang_f4`.
- Small-parameter corrections (cf. the 1004/EPS87 precedent), verified by hand:
  - $f_2$: the page states $f_2(n) = \lfloor n^2/4\rfloor+1$ unrestricted, but the
    formal $f_2(n) = 0$ for $n \leq 1$ (no graph has $\chi \geq 2$; the threshold
    property is vacuous at every $m$). Variant stated for $n \geq 2$; checked
    $n = 2, 3$ by hand and the general case via Mantel + $K_{\lfloor n/2\rfloor,
    \lceil n/2\rceil}$ (triangle-free, $\chi = 2$, $\lfloor n^2/4\rfloor$ edges).
  - $f_3$: page unrestricted, but the formal $f_3(n) = 0$ for $n \leq 4$ (any
    $\chi \geq 3$ graph on $\leq 4$ vertices contains an odd cycle on $\leq 4$
    vertices, i.e. a triangle, so even $m = 0$ qualifies). Variant stated for
    $n \geq 5$; checked $n = 5$ ($C_5$ shows $m = 5$ fails; any chord on $C_5$ makes a
    triangle, so $f_3(5) = 6 = \lfloor 16/4\rfloor + 2$) and $n = 6$ ($C_5$ plus a
    vertex joined to two nonadjacent cycle vertices: 7 edges, triangle-free,
    non-bipartite; formula gives 8).
  - $f_4$: page itself restricts to $n \geq 150$; variant carries that hypothesis
    verbatim. Consistency check: $\lfloor (n-3)^2/4\rfloor + 6 = n^2/4 - 3n/2 + O(1)$,
    i.e. $g(4) = 3$, coherent with the Simonovits form.
- The page's $g(r)$ bounds ($r^2\log r$ up to constants) are *not* formalized: they
  would require defining $g(r)$ (a new quantifier over all finite triangle-free graphs
  and vertex-deletion counts), i.e. constructs not present in the file — out of scope
  for Step 4's variant rule; noted as optional future enrichment, recorded in the
  docstring prose instead.
