## Summary

The problem (verbatim from the recovered page, PROVED banner): "If $G$ is a graph
with infinite chromatic number and $a_1<a_2<\cdots$ are lengths of the odd cycles
of $G$ then $\sum \frac{1}{a_i}=\infty$." Conjectured by Erdős and Hajnal
[ErHa66], proved by Liu and Montgomery [LiMo20]. The Lean
(`conjectures/57.lean:17-22`) states: for any graph `G` on any vertex type with
`G.chromaticNumber = ⊤`, for every real `B` there is a `Finset ℕ` of odd cycle
lengths of `G` whose reciprocals sum to at least `B`. Read back independently,
this is exactly the source's conclusion: unboundedness of finite partial sums
over a set of positive terms is equivalent to divergence of the series over that
set, and a `Finset` of *lengths* counts each length once, matching the source's
enumeration $a_1 < a_2 < \cdots$ of the set of odd cycle lengths. Direct-assertion
form in the true (proved) direction is correct for this solved problem. No
semantic defects; only scholarship/polish nits.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 17–22: "if `G` has no `n`-coloring for
  any finite `n`, then for every `B : ℝ` there exists a finite set `T` of natural
  numbers, each odd and each the length of some cycle of `G`, with
  `∑_{n ∈ T} 1/n ≥ B`."
- Divergence encoding: $\sum_{a \in S} 1/a = \infty$ for
  $S = \{$odd cycle lengths$\}$ ⇔ the finite partial sums over subsets of $S$
  are unbounded ⇔ `∀ B, ∃ T ⊆ S finite, B ≤ ∑ 1/n`. Exactly the Lean shape.
  Because `T : Finset ℕ` contains *lengths* (not cycles), each length is counted
  once — the encoding correctly avoids the multiset-repetition failure mode
  (counting many cycles of the same length would trivialize divergence whenever
  any single odd cycle exists).
- Hypothesis: `G.chromaticNumber = ⊤` with `chromaticNumber : ℕ∞ :=
  ⨅ n ∈ Set.ofPred G.Colorable, (n : ℕ∞)` (verified in the Mathlib clone,
  `Mathlib/Combinatorics/SimpleGraph/Coloring/Vertex.lean:216`) equals `⊤` iff
  `G.Colorable n` holds for no finite `n` — the standard and correct rendering of
  "infinite chromatic number". `V : Type*` correctly allows infinite graphs (the
  only ones that can satisfy the hypothesis; for finite or empty `V` the
  hypothesis is false and the statement vacuous there, matching the source).
- "Odd cycles" = cycles of odd length: the Lean conjunct
  `Odd n ∧ ∃ v p, p.IsCycle ∧ p.length = n` says exactly "n is odd and G has a
  cycle of length n". Mathlib's `Walk.IsCycle` (closed walk, trail, distinct
  interior support) is the standard cycle notion with `length ≥ 3`
  (`IsCircuit.three_le_length`, verified in the clone); the existential over the
  base vertex `v` is the right way to say "G contains a cycle of length n".
- Not vacuous / not trivially false: the hypothesis is satisfiable (e.g. the
  complete graph on ℕ); the conclusion genuinely requires infinitely many
  distinct odd cycle lengths (a graph with finitely many would falsify it for
  large `B`) — and a graph with *no* odd cycles is bipartite hence 2-colorable,
  so the hypothesis forces odd cycles to exist. Substantive statement.
- Indexing: the source's $a_1 < a_2 < \cdots$ is an enumeration convention of
  the set of lengths; the Lean quantifies over finite subsets of that set. No
  index arithmetic exists to get wrong.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction; no ℕ division. The only division is `1 / (n : ℝ)` in ℝ:
  `n = 0` would give the junk value `1/0 = 0`, but `Odd n` already excludes 0
  (and cycle lengths are ≥ 3); even hypothetically, a 0-term could only *weaken*
  the sum, never falsify or trivialize the statement (batch degenerate-input
  check: no junk value bites).
- No `Finset.range`; no off-by-one surface.
- Vacuous/degenerate satisfiers: `T = ∅` gives sum 0 and handles `B ≤ 0`
  trivially — consistent with divergence, harmless. `∀ n ∈ ∅, …` vacuously true —
  fine.
- "Sum = ∞" is encoded elementarily (∀ bound ∃ finite subset) rather than via
  `Summable`/`tsum`/`limsup` — the encodings are equivalent and the elementary
  one avoids this batch's problem-33 class entirely (no ℝ-valued

- No `StrictMono`/`Monotone`, no intervals. No default-valued binders
