## Summary

The problem (DISPROVED on the source page): let α > 0 be irrational; is the set
A = { n ≥ 1 : ‖αn²‖ < 1/log n }, where ‖·‖ is the distance to the nearest
integer, an additive basis of order 2 (every sufficiently large integer a sum
of two elements)? Konieczny [Ko16b] disproved it: the answer is "no" for almost
every α > 0 and also specifically for α = √2; more generally, for any
ε(n) → 0 the set { n ≥ 1 : ‖αn²‖ < ε(n) } is not a basis of order 2 for
almost every α > 0. The Lean file (`conjectures/1147.lean`) defines
`distNearestInt` (min of the fractional part and its complement), `setA α`
(the set above), and `IsAdditiveBasisOrder2` (∃ N₀, ∀ n ≥ N₀, n = a + b with
a, b ∈ S), and asserts `¬ IsAdditiveBasisOrder2 (setA (Real.sqrt 2))`
(lines 42–44) — the page's concrete refutation witness, stated as a direct
assertion of the true (negative) direction, which this pipeline accepts for
solved problems. Read back independently, the Lean and the source agree; the
only defect is bibliographic (both used citation keys undefined). The n = 1
division-by-zero boundary is a documented blemish, harmless here by a
monotonicity argument given below (the prior review asserted the harmlessness
via an invalid general principle).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $\alpha>0$ be an
  irrational number. Is the set \[A=\left\{ n\geq 1: \| \alpha n^2\| <
  \frac{1}{\log n}\right\},\] where $\|\cdot\|$ denotes the distance to the
  nearest integer, an additive basis of order $2$?" — status banner
  **DISPROVED**, tooltip "This has been solved in the negative." Remarks:
  disproved by Konieczny [Ko16b], "false both for almost every $\alpha>0$, and
  also is false specifically for $\alpha=\sqrt{2}$"; plus the general
  ε(n) → 0 statement for almost every α > 0.
- Independent back-translation of lines 42–44: "the set
  { n ≥ 1 : ‖√2·n²‖ < 1/log n } is not an additive basis of order 2 (in the
  every-sufficiently-large sense)." This is exactly the page's "false
  specifically for α = √2" instance. Since √2 is a positive irrational, this
  single witness logically entails the "no" answer to the universally
  quantified question as asked — it is the *strongest* page-supported form of
  the disproof, not a weakening. The docstring (lines 27–40) states the
  question, the disproof, the √2 particular case, and the ε(n) → 0
  generalization, all matching the page essentially verbatim.
- `distNearestInt x = min (Int.fract x) (1 - Int.fract x)` (lines 14–15):
  `Int.fract x ∈ [0,1)` for every real x (negatives included:
  fract(−0.3) = 0.7), so the min is the distance to the nearest integer,
  valued in [0, 1/2]. Correct, including at integers (0) and half-integers
  (1/2).
- "Additive basis of order 2" (lines 23–24) is encoded asymptotically
  (∃ N₀, ∀ n ≥ N₀, ∃ a ∈ S, ∃ b ∈ S, n = a + b) with repetitions allowed
  (a = b permitted) — the standard convention in this Vaughan-adjacent
  additive-number-theory context, and the convention under which Konieczny's
  disproof is stated. Equivalent to the upstream library's
  `Set.IsAsymptoticAddBasisOfOrder S 2` (see E.1).
- Not vacuous/trivial: `setA (√2)` is infinite — by Heilbronn's theorem
  ‖αn²‖ < n^(−1/2+ε) infinitely often for every real α (reviewer knowledge,
  medium confidence), and n^(−1/2) ≪ 1/log n eventually — with heuristic
  counting |A ∩ [1,N]| ≍ N/log N, comparable to the primes; so the negation
  is not true for a degenerate "sparse set" reason and the statement carries
  Konieczny's genuine content. (Even under the pessimal reading, triviality
  would not affect soundness, only interest.)

**A2. Lean semantics traps — pass, one documented blemish.**

- **Division by zero at n = 1:** `Real.log 1 = 0`, and field convention gives
  `1 / 0 = 0` (line 19); `distNearestInt ≥ 0` can never be `< 0`, so
  `1 ∉ setA α` for every α, despite the `n ≥ 1` guard admitting it — while
  the source's condition at n = 1 ("‖α‖ < 1/log 1") is undefined. Direction
  of harm checked by hand: `IsAdditiveBasisOrder2` is monotone under `⊆`
  (more elements only add representations), so ¬Basis(A ∪ {1}) ⟹
  ¬Basis(A) — the formal statement (about the possibly-smaller set) is
  implied by Konieczny's theorem whichever way the source's n = 1 is read.
  **Caution:** this is *not* harmless "because one element cannot matter" —
  a single element can flip basisness (the even numbers are not a basis of
  order 2; the evens together with 1 are). The correct argument is the
  monotonicity direction above, which only works because the statement is
  negative. [polish] — documented in the v2 `setA` docstring.
- n = 0: excluded by `n ≥ 1`; belt-and-braces, even without the guard
  `Real.log 0 = 0` gives the same never-true `< 0` condition.
- n ≥ 2: `Real.log n > 0`, division exact and positive; no further boundary
  issues.
- No ℕ subtraction anywhere (`1 - Int.fract x` is real subtraction).
- No `Finset.range`, no off-by-ones; the source's n ≥ 1 is `n ≥ 1` verbatim.
- "Every sufficiently large" is encoded by ∃ N₀ ∀ n ≥ N₀ — the correct
  filter-free rendering (equivalent to `∀ᶠ n in atTop` and, on ℕ, to
  `cofinite`). Degenerate input check: S = ∅ gives ∃ a ∈ ∅ false for every
  n ≥ N₀, and ℕ has elements ≥ any N₀, so ∅ is correctly not a basis.
- No `StrictMono`/`Monotone`, no open/closed interval subtleties.
- Cast placement: `α * (↑n) ^ 2` squares the real cast of n — arithmetic in
  ℝ as intended.

**A3. Definitions — pass.**
