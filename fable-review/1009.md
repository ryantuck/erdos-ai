## Summary

The problem asks: is it true that for every $c > 0$ there exists $f(c)$ such that every
graph on $n$ vertices with at least $\lfloor n^2/4 \rfloor + k$ edges, where $k < cn$,
contains at least $k - f(c)$ edge-disjoint triangles? The page banner is **PROVED**
("This has been solved in the affirmative") — by Győri [Gy88], who showed
$f(c) \ll c^2$. The Lean (`deepmind/1009.lean:69`) encodes this as
`answer(True) ↔ ∀ c : ℝ, c > 0 → ∃ f : ℕ, ∀ n G k, (k:ℝ) < c*n →
G.edgeFinset.card ≥ n^2/4 + k → HasEdgeDisjointTriangles G (k - f)`, with a bespoke
`HasEdgeDisjointTriangles` predicate. Read back independently, the Lean and the English
agree exactly; the truncated ℕ-subtraction and floor division are both benign here. The
one genuine defect was scholarly, not semantic: the `[Er71]` bibliography entry carried a
fabricated title ("Some problems in graph theory") introduced during restyling — the
site's global key [Er71] is the Oxford 1969 proceedings paper (pp. 97–109, consistent
with the page citation `[Er71, p.98]`), as verified from multiple independent `/latex`
extractions captured in the session logs. Fixed.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (two agreeing captures, see Addendum): "Is it true
  that, for every $c>0$, there exists $f(c)$ such that every graph on $n$ vertices with
  at least $\lfloor n^2/4\rfloor+k$ edges, where $k<c n$, contains at least $k-f(c)$
  many edge disjoint triangles?" The module docstring reproduces this essentially
  verbatim.
- Independent back-translation of lines 69–74: "for every real $c > 0$ there is a
  natural number $f$ such that for all $n$, every graph $G$ on $n$ vertices, and every
  natural $k$ with $k < cn$: if $G$ has at least $\lfloor n^2/4 \rfloor + k$ edges then
  $G$ contains $k - f$ pairwise edge-disjoint triangles." This is the question as asked;
  quantifier order gives $f$ depending on $c$ only, matching "$f(c)$".
- `≥` vs the source's implicit "with $\lfloor n^2/4 \rfloor + k$ edges": equivalent. A
  graph with $m \ge \lfloor n^2/4 \rfloor + k$ edges contains a spanning subgraph with
  exactly that many edges, whose edge-disjoint triangles are triangles of $G$; so the
  `≥` form follows from and implies the `=` form. No drift.
- `f : ℕ` vs a possibly-real $f(c)$: equivalent for this statement — only
  $\lceil f \rceil$ matters for a count lower bound, so a real witness yields a natural
  one and conversely (ai-review made the same point, correctly).
- Small-$n$ soundness of the `∀ n` quantifier: even if Győri's proof addresses large
  $n$, the formal `∀ n` version is safely true — for any finite set of small $n$, all
  admissible $k$ are bounded by $c \cdot n_0$, so enlarging $f$ to
  $\max(f_{\text{Győri}}, \lceil c n_0 \rceil)$ truncates $k - f$ to $0$ there while
  remaining a function of $c$ alone. The statement is not vacuous and not trivially
  true: it is Győri's theorem.

**A2. Lean semantics traps — pass.**

- **ℕ subtraction** `k - f` truncates at $0$ when $f \ge k$; then the conclusion is
  `HasEdgeDisjointTriangles G 0`, witnessed by the empty family `Fin 0 → Fin 3 → Fin n`
  (all three conjuncts vacuous). This matches the informal reading — "at least
  $k - f(c)$ triangles" is trivially true when $k - f(c) \le 0$. Benign.
- **ℕ division** `n ^ 2 / 4` floors — exactly $\lfloor n^2/4 \rfloor$ as in the source.
  Correct, not merely harmless.
- No `Finset.range` and no boundary-index division anywhere; the real-side comparison
  `(k : ℝ) < c * (n : ℝ)` is cast correctly so the arithmetic happens in ℝ.
- Vacuous cases: $n \le 2$ makes any $t \ge 1$ unsatisfiable (no injective
  `Fin 3 → Fin n`), but the edge hypothesis is then also unsatisfiable for $k \ge 1$
  (e.g. $n = 2$ needs $\ge 2$ edges, max is 1), and $k = 0$ gives the trivial $t = 0$
  conclusion; term-by-term consistent with the source.
- No filters, no `StrictMono`/`Monotone`, no interval endpoints arise.

**A3. Definitions — pass.**

- `HasEdgeDisjointTriangles` (lines 51–60): each `tri i` is injective (3 distinct
  vertices), pairwise adjacent (a triangle of `G`), and the final clause says no
  unordered edge $\{$`tri i₁ j₁`, `tri i₁ k₁`$\}$ equals any unordered edge of another
  triangle — the two-case disjunction under `¬` is exactly unordered-pair equality.
  Correct encoding of "contains $t$ pairwise edge-disjoint triangles".
- Degenerate inputs: $t = 0$ holds for every graph (empty family), as intended; two
  indices mapping to the *same* vertex triangle are excluded (they would share all three
  edges), so the $t$ triangles are genuinely distinct — the count is honest.
- The injectivity conjunct is technically redundant (`G.Adj` is irreflexive, so the
  adjacency conjunct forces distinctness), but it aids readability; per the checklist,
  not flagged for removal.
- No `sorry` in any definition; the definition is used consistently by all theorems.

**A4. Question form and answer polarity — pass.**

- The source is a yes/no question ("Is it true that…"), so `answer(…) ↔ P` is the right
  shape, and `P` (lines 70–74) is the question as asked. Polarity checked by hand: RHS
  true ⟺ such an $f(c)$ always exists ⟺ the answer is "yes". The page banner is PROVED,
  "solved in the affirmative", so `answer(True)` is correct.
- No binders before the colon (line 69 is binder-free); the quantifiers sit inside the
  iff as required.
- History note: the raw first pass used direct-assertion form with `(c : ℝ) (hc : c > 0)`
  binders; the style review (`reviews/1009.md` §6) correctly failed this, and the
  restyling applied exactly the recommended `answer(True) ↔ ∀ c …` recast. The
  mathematical content is unchanged by the recast.

**A5. Solution status — pass (source-verified).**

- Recovered banner: **PROVED**, tooltip "This has been solved in the affirmative."
  `@[category research solved]`, module docstring, and theorem docstring all agree:
  proved by Győri [Gy88]. Attribution matches the page remarks. The page also records
  "Formalised statement? No" as of access 2026-02-22 (this project's formalization is
  not the upstream one).

**B2. Variants and completeness — pass; enrichment applied.**

- The problem is a single question and is fully captured. The page remarks yield four
  solved partial results, all worthwhile optional variants (not missing parts): Erdős's
  $f(c) = 0$ for $c < 1/2$ (via Erdős–Gallai), Sauer's example giving $f(2) \ge 1$
  (explicit construction on $n = 2r+4$ vertices), Győri's $f(c) \ll c^2$, and Győri's

  `erdos_1009.variants.*` (Addendum fix 4; not compile-verified). Sauer's construction
  itself was recorded in the docstring but not formalized as an exact-count statement,
  since the page does not state for which $r$ the count $2n-7$ is exact; the safe
  consequence $f(2) \ge 1$ is what is formalized.
- No OEIS references on the page; tag "graph theory" is consistent with `AMS 5`.
