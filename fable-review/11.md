## Summary

The problem (erdosproblems.com/11, OPEN, banner FALSIFIABLE): *"Is every large odd
integer $n$ the sum of a squarefree number and a power of 2?"* The Lean file asserts
`∃ N : ℕ, ∀ n ≥ N, ¬Even n → ∃ s k, Squarefree s ∧ s > 0 ∧ n = s + 2 ^ k`
(`conjectures/11.lean:9`). Read back independently: "there is a threshold N beyond
which every odd n is a positive squarefree number plus a power of 2" — exactly the
"yes" direction of the question as asked, with "large" rendered by the standard
∃-threshold encoding. Under this pipeline's convention for raw files (no `answer()`
elaborator), direct assertion of the conjectured, unrefuted direction of an OPEN
question is acceptable (cf. `fable-review/3.md`, `7.md`, `9.md`) — and here even the
upstream formal-conjectures file uses a direct assertion. I found no semantic defects —
only polish-level nits (Mathlib idiom `Odd n`, a redundant `s > 0` conjunct worth
documenting, docstring enrichment) and four page-confirmed variants worth adding.

**A2. Lean semantics traps — pass.**

- No `Finset.range`, no indexing, hence no off-by-one surface.
- `2 ^ k` with `k : ℕ` allows 2^0 = 1 as a power of 2. This matches the upstream
  encoding (`∃ l, … 2 ^ l`) and the convention of the sibling problem #9, whose page
  makes "k, l ≥ 0" explicit for the same kind of sum. Correct.
- `¬Even n`: on ℕ this is exactly `Odd n` (`Nat.odd_iff_not_even`) — semantics

  proposition. Notably, the original formalization session's log justifies the guard
  with "0 is technically squarefree" — a wrong claim about Mathlib semantics (the
  recurring prior-review failure class), but one that never reached the artifact: with
  the conjunct present the statement is right whichever way `Squarefree 0` goes.
  Documented in v2.
- No vacuous bounded quantifiers; the only "for all sufficiently large" is the
  ∃-threshold form, which is the intended filter-free encoding; no
  `StrictMono`/`Monotone`, no interval endpoints.

**B2. Variants and completeness — pass; enrichment applied.**

- The problem-box question is single-part and fully captured by the theorem.
- Page-confirmed partial results worth variants (optional enrichment, not missing
  parts), all added in v2 using only constructs already present in the file:
  (i) Erdős often asked the question under the weaker assumption 4 ∤ n
  (`variants.not_div_four` — a *stronger* statement, since odd ⟹ 4 ∤ n);
  (ii) the two-powers form, which Erdős thought "perhaps easy" but which the page
  records as unresolved (`variants.two_powers`);
  (iii) Hercher's computational verification for all odd 1 < n < 2^50, subsuming
  Odlyzko's 10^7 check (`variants.hercher_range`, solved). Note the page's "all odd
  integers up to 2^50" is literally false at n = 1 (minimum representable value is
  s + 2^k ≥ 2), so v2 adds the 1 < n guard and documents the counterexample — the
  same page-bound-false-at-small-parameters pattern as 1004's EPS87 bound;
  (iv) the Granville–Soundararajan conditional (`variants.granville_soundararajan`,
  solved): conjecture ⟹ infinitely many non-Wieferich primes, a density-free
  weakening of the page's "a positive proportion of primes are non-Wieferich primes"
  (density machinery is unavailable under this file's imports; even infinitude of
  non-Wieferich primes is open unconditionally, so the weakening stays substantive).
- **Upstream polarity flag** (recovered upstream file, not this artifact): upstream's
  `erdos_11.variants.granville_soundararajan` concludes
  `{p | p.Prime ∧ 2 ^ p ≡ 2 [MOD p ^ 2]}.Infinite`. For odd p, 2^p ≡ 2 (mod p²) ⟺
  2^(p−1) ≡ 1 (mod p²), i.e. that set is the set of **Wieferich** primes — the
  *opposite* of the page's "non-Wieferich" conclusion. Sanity check of direction:
  constructing a non-representable odd n requires covering all k with congruences
  p² ∣ n − 2^k, whose moduli in k are ord_{p²}(2); these are small enough to cover
  only when ord_{p²}(2) = ord_p(2), i.e. only Wieferich primes help. So
  representability of *all* odd n constrains Wieferich primes to be sparse — i.e. the
  conjecture pushes toward *many non-Wieferich* primes, as the page says; an
  implication toward infinitude of Wieferich primes is not plausible as the theorem.
  v2 follows the page's direction and flags the upstream discrepancy in its
  docstring; verification against the printed text of [GrSo98] is DEFERRED.
- Not formalized (documented in the v2 docstring instead): Erdős "could prove that it
  is true (with a single power of two) for almost all n" — needs density machinery
  not present in the file (per Step 4's constructs-already-present rule).
- Cross-references [9], [10], [16], OEIS A001220/A377587, Guy A19, and tags recorded
