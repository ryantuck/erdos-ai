## Summary

The problem (asked by Erdős at the 1987 DMV conference in Berlin): does there exist
$A \subset \mathbb{N}$ with lower density $> 1/3$ such that $a + b \neq 2^k$ for any
$a, b \in A$ and $k \geq 0$? Density $1/3$ is trivial (multiples of 3). The page status
is **PROVED** — Müller [Mu11] answered yes, with the set of integers congruent to
$3 \cdot 2^i \pmod{2^{i+2}}$ for some $i \geq 0$ (density $1/2$), and proved lower
density $\leq 1/2$ is best possible. The Lean file defines `PowerOfTwoSumFree`
(no two elements, repetition allowed, sum to a power of 2), a counting function
$|A \cap [1, N]|$, and asserts the existence of such an $A$ with the lower-density
condition encoded as an eventual linear lower bound $\delta N \leq |A \cap [1, N]|$ for
some $\delta > 1/3$. Read back independently, the Lean asserts exactly the affirmative
answer to the question as asked, and the eventual-bound encoding is provably equivalent
to $\liminf |A \cap [1,N]|/N > 1/3$. I found **no Part A defects**. The one checklist
failure is B1: both docstrings cite `[Mu11]` but the file defines no bibliography —
fixed in `conjectures-v2/1136.lean` from the log-recovered `/latex/1136` data, along
with two page-confirmed variants (Müller's construction and the $1/2$ optimality bound).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement: "Does there exist $A\subset \mathbb{N}$ with
  lower density $>1/3$ such that $a+b\neq 2^k$ for any $a,b\in A$ and $k\geq 0$?" The
  module docstring (`conjectures/1136.lean:10-11`) reproduces it faithfully
  ($\subseteq$ vs the page's $\subset$ is pure notation — both mean subset of ℕ here).
- Independent back-translation of the theorem (lines 40–46): "there is a set
  $A \subseteq \mathbb{N}$ such that (i) for all $a, b \in A$ and all $k \in \mathbb{N}$,
  $a + b \neq 2^k$, and (ii) there are $\delta > 1/3$ and $N_0$ with
  $\delta N \leq |A \cap [1, N]|$ for all $N \geq N_0$." Clause (i) is the sum-free
  condition exactly as asked: $a = b$ is allowed (no distinctness constraint), matching
  the standard reading of "any $a, b \in A$" — and consistent with the page's own data
  points (multiples of 3: even $2a \equiv 0 \pmod 3$ is never a power of 2; Müller's
  set: every element is $2^i(4m+3)$, so every pairwise sum is $2^j \cdot \text{odd}$
  with odd part $\geq 3$). `∀ k : ℕ` covers exactly $k \geq 0$ ($2^0 = 1$ included).
- Clause (ii) — the **lower density encoding** — is equivalent to
  $\liminf_{N\to\infty} |A \cap [1,N]|/N > 1/3$, verified by hand in both directions:
  (⇒) $\delta N \leq c(N)$ for $N \geq N_0$ gives $\liminf c(N)/N \geq \delta > 1/3$;
  (⇐) if $\liminf > 1/3$, pick $\delta$ with $1/3 < \delta < \liminf$; since the
  liminf is the sup of tail-infima, some tail has infimum $> \delta$, i.e.
  $c(N)/N \geq \delta$ for all $N \geq$ some $N_0$, i.e. $\delta N \leq c(N)$. Exact,
  not merely asymptotic.
- Types: counting in ℕ, density threshold in ℝ with the cast placed so the comparison
  `δ * (N : ℝ) ≤ (count : ℝ)` happens in ℝ. Correct.
- Indexing: the counting interval is `Finset.Icc 1 N` $= [1, N]$, the site's usual
  $|A \cap [1,N]|$ convention; whether $0 \in A$ is irrelevant to the density and to
  the truth of the statement (removing 0 preserves both conjuncts).
- Not vacuous/trivially true: the trivial witness (multiples of 3) has lower density
  exactly $1/3$ and fails `δ > 1/3` — the formal statement genuinely requires Müller's
  theorem. Not trivially false either (Müller's set satisfies it).

## E. Prior-review audit (`deepmind/ai-review/1136.md`)

The prior review's final conclusions are mostly right, but it contains one outright
fabrication and several unsound supporting claims. Note it was written against an
*intermediate* version (it quotes a `countInInterval` encoding **and** an
`answer(True)` wrapper — a combination matching neither `conjectures/1136.lean` nor
the final `deepmind/deepmind/1136.lean`), so line-level claims were audited against
the mathematics, not the letter.

1. **Hallucinated attribution (§2).** "The website attributes the solution to **Joël
   Müller**" is **fabricated**: the recovered page says only "Müller", nowhere any
   first name — and the review contradicts itself two sentences later ("The website
   text does not give the author's full name or initials"). Its speculation that the
   author "is indeed Thomas W. Müller (who was at Queen Mary University of London)" is
   *also* wrong: the `/latex/1136` bibliography — fetched in the **same logged
   session** that produced this review — identifies **Helmut Müller** (the paper is in
   the Hamburg Mathematical Society's *Mitteilungen*). This is simultaneously the
   hallucinated-attribution class and the "claiming data is unavailable that is in
   fact recoverable" class (cf. the 1001 audit): the review declared the initials
   unverifiable while the settling data sat one fetch away and had in fact been
   fetched. The styled Lean file was corrected to "Müller, H."; the review text never
   was. (The "T. W. Müller, *On the sum-of-two-powers-of-two problem*" entry it quotes
   from the then-current draft was itself a hallucinated title/author, since removed.)
2. **Invented-then-excused non-equivalence (§6).** On the density encoding it first
   asserts "the converse is not immediate: a set could have lower density exactly 0.4
   without there being a single δ > 1/3 and N₀ …" — a false claim (no such set exists;
   any δ ∈ (1/3, liminf) works, by the tail-infimum characterization) — and then
   reverses itself mid-paragraph ("Actually, on further analysis, the conditions are
   equivalent"). The final conclusion is correct (re-derived in A1), but the paragraph
   ships its own refuted reasoning — the same wobble pattern as the 1000 audit's
   invented-then-excused off-by-one.
3. **False micro-claim about `Iio` (§1).** "they differ by at most one element and
   **both exclude 0** in the relevant range" — wrong: `Set.Iio b` = $\{x \mid x < b\}$
   *contains* 0 for $b \geq 1$, so `partialDensity` counts 0 while `Icc 1 N` excludes
   it. The conclusion (the two density conventions agree) is still correct — the
   counts differ by $[0 \in A] - [N \in A] \in \{-1, 0, 1\}$ — but the justification
   misstates Mathlib semantics (the 1002 failure class).
4. **Unverifiable overreach (§6).** "This matches the convention in the problem
   statement on erdosproblems.com" — the recovered page states no counting convention
   for this problem; the claim is not supported by the source it cites.
5. **Variant suggestion understates the page (§3).** Its proposed construction variant
   states `Set.lowerDensity A = 1/2`, but the page says Müller's set "has density
   1/2" — full natural density, a strictly stronger statement than lower density
   $= 1/2$ alone. The styled file adopted the weaker form; this review's v2 encodes
   the full two-sided limit.
6. **What it got right:** the equivalence conclusion (after the wobble); that allowing
   $a = b$ matches the standard interpretation; the $0 \in A$ analysis; the missing
   construction/optimality variants (both adopted here); and the reuse observation for
   the upstream repo (out of scope for this pipeline's raw file).
