## Summary

The problem (Erdős–Hajnal–Rado; [Va99, 7.80]): prove the negative partition relation
$\aleph_{\omega+1} \nrightarrow (\aleph_{\omega+1}, 3, \ldots, 3)_{\aleph_0}^2$ without
assuming the generalised continuum hypothesis — i.e. exhibit, in ZFC alone, a coloring of
the unordered pairs from a set of size $\aleph_{\omega+1}$ with countably many colors such
that no set of full size $\aleph_{\omega+1}$ is monochromatic in color $0$ and no triple
is monochromatic in any color $n \ge 1$. The Lean theorem (`conjectures/1168.lean:32–44`)
asserts: for every type $\alpha$ with $\#\alpha = \aleph_{\omega+1}$ there exists a
symmetric $c : \alpha \to \alpha \to \mathbb{N}$ such that every $S \subseteq \alpha$ of
cardinality $\aleph_{\omega+1}$ contains a pair with $c \ne 0$, and no three distinct
points pairwise share a common color $n \ge 1$. Read back independently, this is exactly
the negative relation, in the correct direct-assertion form for a "Prove that…" problem,
with no GCH hypothesis — matching "without assuming GCH". No semantic defects; the one
substantive nit is scholarship: the docstring cites [Va99, 7.80] but never defines the
key.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Prove
  that\[\aleph_{\omega+1}\not\to (\aleph_{\omega+1}, 3,\ldots,3)_{\aleph_0}^2\]without
  assuming the generalised continuum hypothesis." Remarks section: "A problem of Erdős,
  Hajnal, and Rado." — nothing else. The module docstring reproduces this faithfully.
- Independent back-translation of lines 32–43: for every type $\alpha$ of cardinality
  $\aleph_{\omega+1}$ there is a symmetric $\mathbb{N}$-coloring of ordered pairs such
  that (i) every subset of cardinality $\aleph_{\omega+1}$ contains two distinct points
  whose pair-color is nonzero, and (ii) for every $n \ge 1$ no three pairwise-distinct
  points have all three pair-colors equal to $n$. Unwinding the standard meaning of
  $\kappa \nrightarrow (\lambda_0, \lambda_1, \ldots)^2_\gamma$ — there exists a
  coloring of $[\kappa]^2$ with $\gamma$ colors admitting no color-$i$ homogeneous set of
  size $\lambda_i$ — with $\gamma = \aleph_0$, $\lambda_0 = \aleph_{\omega+1}$,
  $\lambda_n = 3$ for $n \ge 1$: (i) is precisely the negation of a color-0 homogeneous
  set of size $\aleph_{\omega+1}$, and (ii) precisely the negation of a color-$n$
  homogeneous triple. Exact agreement.
- Unordered pairs as a symmetric function: a symmetric $c : \alpha \to \alpha \to
  \mathbb{N}$ is interchangeable with a function on $[\alpha]^2$; diagonal values
  $c\,a\,a$ are never consulted (both conditions carry distinctness hypotheses), so they
  are semantically inert. Faithful encoding.
- Cardinality-target convention: the source relation asks for a homogeneous set *of
  cardinality* $\aleph_{\omega+1}$; since $S \subseteq \alpha$ forces
  $\#S \le \#\alpha = \aleph_{\omega+1}$, the file's `#S = ℵ_ (ω + 1)` is equivalent to
  the "≥ target" convention. No loss.
- "Without assuming GCH" is correctly rendered by the *absence* of any GCH hypothesis: a
  Lean proof would be a proof in Mathlib's base foundation (ZFC-like, no GCH), which is
  what the problem requests. (Caveat, corpus-wide and not a defect: Lean's type theory
  with universes is somewhat stronger than bare ZFC.)
- Not vacuous / not trivially false: witnesses for the hypothesis exist in every universe
  (e.g. `(ℵ_ (ω+1)).ord.toType`), so the outer ∀ is non-vacuous; condition (i) is
  non-vacuous since $S = \mathrm{univ}$ has full cardinality (`Cardinal.mk_univ`); and no
  degenerate coloring satisfies both conditions (a constant-0 coloring satisfies (ii)
  vacuously but fails (i) on `univ`; a coloring avoiding 0 must fight (ii) on every
  triple). The statement carries the problem's genuine content.
