## Summary

The problem (erdosproblems.com/1022, [Er71, p.105]): is there a constant $c_t$, with
$c_t \to \infty$ as $t \to \infty$, such that every finite family $\mathcal{F}$ of
finite sets, all of size at least $t$, in which every set $X$ contains $< c_t|X|$
members of $\mathcal{F}$, has property B (chromatic number 2)? The answer is **no**:
Wood [Wo13b] constructs, for every $r \ge 2$, a triangle-free 2-degenerate $r$-uniform
hypergraph with chromatic number 3, so $c_t < 2$ for all $t$. The Lean statement
(`deepmind/1022.lean`) encodes this as `answer(False) ↔ ∃ c : ℕ → ℝ, Tendsto c atTop
atTop ∧ ∀ t n F, (∀ e ∈ F, t ≤ e.card) → (∀ X, count(X) ≤ c t * |X|) → HasPropertyB F`,
with property B as a helper `def`. Read back independently, the code matches the
question with correct polarity (the RHS is false, by Wood, so `answer(False)` iff RHS is
provable-in-principle). The one defect was documentation: the theorem docstring still
described the hypothesis as strict `< c(t)·|X|` — the encoding under which the
hypothesis is unsatisfiable at $X = \emptyset$ and the whole statement trivializes —
after the code had been fixed to `≤`. The module docstring had also dropped the problem
statement entirely during restyling. Both fixed.

## A. Semantic fidelity

**A1. Statement fidelity — code pass (source-verified); docstring defect (fixed).**

- Recovered verbatim source statement (see Addendum): "Is there a constant $c_t$, where
  $c_t\to \infty$ as $t\to \infty$, such that if $\mathcal{F}$ is a finite family of
  finite sets, all of size at least $t$, and for every set $X$ there are $<c_t\lvert
  X\rvert$ many $A\in \mathcal{F}$ with $A\subseteq X$, then $\mathcal{F}$ has chromatic
  number $2$ (in other words, has property B)?"
- Independent back-translation of the theorem (pre-fix lines 55–61): "the answer is
  'no' iff there exists $c:\mathbb{N}\to\mathbb{R}$ tending to infinity such that for
  every $t$, every finite hypergraph on `Fin n` with all edges of size $\ge t$ and at
  most $c(t)|X|$ edges inside every vertex set $X$ has property B." That is the question
  as asked, modulo the deliberate `<` → `≤` guard (analyzed under A2).
- Quantifier structure: `∃ c` inside the iff; `∀ t n F` inside the `∃`; the ground set
  `Fin n` with `∀ n` correctly captures "every finite family of finite sets" (every
  finite family embeds into some `Fin n`; property B and the containment counts are
  invariant under such embeddings). "For every set $X$" is correctly read as every
  subset of the ground set: for arbitrary $X$, replacing $X$ by $X \cap V$ changes
  neither $\{A \in \mathcal{F} : A \subseteq X\}$ (edges lie in $V$) nor tightens the
  bound in a way that matters — the restriction is faithful.
- "Family" as `Finset (Finset (Fin n))` deduplicates; if the informal "family" allows
  repeats, the encodings are still equivalent: duplicates only increase the count in
  every $X$ (making the hypothesis harder) and never change 2-colorability, so the
  existence of a valid $c$ is unaffected in both directions.
- Not vacuous: the hypothesis is satisfiable (e.g. $\mathcal{F} = \emptyset$, forests),
  the conclusion is nontrivial, and the RHS is genuinely false only via Wood's
  construction — no degenerate witness decides it. I verified by hand that with `≤` the
  $X=\emptyset$ instance reads $\mathrm{count}(\emptyset) \le 0$, i.e. merely
  $\emptyset \notin \mathcal{F}$, which is automatic for $t \ge 1$ and informally
  correct for $t = 0$ (a family containing $\emptyset$ has no 2-coloring and also
  violates the informal $X=\emptyset$ instance).
- **[defect] Docstring–code mismatch:** the theorem docstring said "the number of edges
  contained in $X$ is $< c(t) \cdot |X|$" while the code says `≤`. The strict form,
  formalized literally over all `X`, is unsatisfiable at `X = ∅` (`0 < 0`), which makes
  the implication vacuously true for every `F`, the RHS trivially `True`, and the
  theorem `False ↔ True` — unprovable. That is precisely the bug `ai-review/1022.md`
  found and the fix session repaired *in the code only*; the docstring was left
  describing the broken hypothesis. A maintainer "syncing" code to docstring would
  reintroduce unprovability. Fixed: docstring now states the `≤` form and documents the
  deviation from the source's strict inequality and why it is harmless.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no division anywhere. `Finset.range` unused. Casts: the count and
  `X.card` are cast to ℝ before comparison with `c t * (X.card : ℝ)` — arithmetic
  happens in ℝ as intended.
- The `X = ∅` boundary was the file's historical trap: with the raw `<` the bounded
  quantifier `∀ X, count < c t * |X|` is *unsatisfiable* (not vacuous — anti-vacuous),
  trivializing the implication. The `≤` fix is correct and faithful. I re-derived the
  equivalence with the source's strict form by hand: (i) `≤`-yes ⟹ `<`-yes, since
  `< ` implies `≤` pointwise so the `≤`-implication is the stronger one; (ii) `<`-yes
  ⟹ `≤`-yes via $c'(t) = c(t)/2$ when $c(t) > 0$ (then count $\le c'(t)|X| < c(t)|X|$
  for nonempty $X$) and $c'(t) = -1$ when $c(t) \le 0$ (both hypotheses then
  unsatisfiable except for trivial families, which have property B); $c' \to \infty$
  still. So the existence of a valid $c$ is unchanged.
- `Tendsto c atTop atTop` is the standard, correct encoding of $c_t \to \infty$.
- `t : ℕ` quantified over all of ℕ (including 0, 1) only strengthens the requirement on
  $c$; by the negative-values-of-$c$ device above this does not change the truth value
  relative to the source's implicit $t \ge 2$, and the answer is "no" in either reading.
- Polarity of the falsity double-checked against Wood: any $c \to \infty$ has some
  $t \ge 2$ with $c(t) \ge 2$; Wood's $t$-uniform 2-degenerate non-2-colorable
  hypergraph satisfies count$(X) \le 2|X| \le c(t)|X|$ and refutes the implication. RHS
  is false; `answer(False) ↔ False` is provable-in-principle. ✓
- No `StrictMono`/`Monotone`, no interval-endpoint issues.

**A3. Definitions — pass.**

- `HasPropertyB` (lines 40–41) matches its docstring and the standard notion (weak
  2-coloring, no monochromatic edge). Degenerate cases: an empty edge makes it false
  (correct — $\emptyset$ is not 2-colorable); `F = ∅` makes it true, including at
  `n = 0` (the empty function `Fin 0 → Bool` exists) — correct and harmless. No `sorry`
  in any `def`. The theorem uses the def exactly as it means.

**A4. Question form and answer polarity — pass.**

- The source is a yes/no question ("Is there a constant $c_t$ …?"), so the
  `answer(…) ↔ P` shape is right, with `P` the existence statement as asked.
- Polarity by hand: RHS true ⟺ such a $c$ exists ⟺ answer "yes". The problem was
  resolved *negatively* (Wood; page remark "This is false, and $c_t<2$ for all $t$"), so
  `answer(False)` is correct. Note the page banner's canned tooltip ("solved in the

- No binders before the colon (`theorem erdos_1022 : answer(False) ↔ …`).
- The raw file (`conjectures/1022.lean`) stated the true direction as a bare `¬ ∃ …`
  assertion; the restyle to question form (flagged by `reviews/1022.md`) preserved the
  mathematics with correct polarity.
