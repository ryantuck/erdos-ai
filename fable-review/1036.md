## Summary

The problem (Erdős–Rényi, recovered verbatim): "Let $G$ be a graph on $n$ vertices which
does not contain a trivial (empty or complete) graph on more than $c\log n$ vertices.
Must $G$ contain at least $2^{\Omega_c(n)}$ many induced subgraphs which are not pairwise
isomorphic?" The page status is **PROVED (LEAN)** ("solved in the affirmative and the
proof verified in Lean"); the affirmative proof is Shelah's [Sh98]. The Lean statement
(`deepmind/1036.lean:76`) encodes this as `answer(True) ↔ ∀ c > 0, ∃ δ > 0, ∃ N₀,
∀ n ≥ N₀, ∀ G on Fin n, (clique bound) → (independent-set bound) → ∃ F :
Finset (Finset (Fin n)), |F| ≥ 2^(δn) ∧ pairwise non-isomorphic induced subgraphs`. Read
back independently, the Lean and the English agree; I found no semantic defects. The
defects found are scholarship-level: the `[Er93]` reference was expanded to the *wrong*
Erdős 1993 paper (a conflation the corpus had already corrected in the neighbouring files
1030–1035 but not here), the page's second source key `[Va99, 3.53]` was missing, and the
restyling dropped the problem statement/question from the module docstring (the same
drift class as the 1005 defect).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 76–90: "for every $c > 0$ there are $\delta > 0$
  and $N_0$ such that for every $n \ge N_0$ and every graph $G$ on $n$ labelled vertices,
  if every clique of $G$ has at most $c\ln n$ vertices and every independent set of $G$
  has at most $c\ln n$ vertices, then there is a family $F$ of at least $2^{\delta n}$
  vertex subsets whose induced subgraphs are pairwise non-isomorphic." This is exactly
  the affirmative content of the recovered question.
- "Does not contain a trivial graph on **more than** $c\log n$ vertices" negates to
  "every clique/independent set has $\le c\log n$ vertices" — the Lean's non-strict `≤`
  is the exact complement of the source's strict "more than". Term-exact, no off-by-one.
- $2^{\Omega_c(n)}$ unpacked as `∃ δ > 0, ∃ N₀, ∀ n ≥ N₀, count ≥ 2^(δn)` with δ, N₀
  chosen **before** $G$ — correctly uniform in $G$, depending only on $c$, which is what
  the subscript in $\Omega_c$ means.
- Counting encoding: a `Finset (Finset (Fin n))` of pairwise-non-isomorphic induced
  subgraphs of cardinality ≥ 2^(δn) exists iff the number of isomorphism classes of
  induced subgraphs of $G$ is ≥ 2^(δn) (pick one representative subset per class;
  conversely members of $F$ lie in distinct classes). Faithful.
- Log base: source writes $c\log n$, Lean uses `Real.log` (natural log). Since $c$ is
  universally quantified, the base is absorbed into $c$; the theorem docstring now states
  this explicitly (the parenthetical was in the raw file and dropped in restyling —
  restored).
- Not vacuous: for $c \ge 3$ and large $n$, Ramsey graphs with clique and independence
  number $\le 2\log_2 n \approx 2.885 \ln n \le c \ln n$ exist (random graphs), so the
  hypothesis class is non-empty and the bound is a substantive assertion. For very small
  $c$ the hypothesis is eventually unsatisfiable (any graph has a clique or independent
  set of $\ge \tfrac{1}{2}\log_2 n$ vertices) and the implication is vacuously true —
  but that is inherent in the informal statement's "for every $c$" reading, not an
  encoding artifact.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no ℕ division, no `Finset.range` anywhere.
- `Real.log n` at degenerate $n$: `log 0 = log 1 = 0`. For $n = 1$ the singleton clique
  (card 1 > 0) falsifies the hypothesis; for $n = 0$ the hypothesis holds vacuously
  (all `S = ∅`) **and** the conclusion also holds ($2^{\delta\cdot 0} = 1$ and
  $F = \{\emptyset\}$ works) — either way harmless, and the `∃ N₀` guard makes small
  $n$ irrelevant. (See Part E: the prior review got the $n = 0$ case wrong.)
- "For all sufficiently large" encoded with an explicit `∃ N₀, ∀ n ≥ N₀` rather than a
  filter — correct and equivalent to `∀ᶠ n in atTop`.
- `(2 : ℝ) ^ (δ * (n : ℝ))` is real rpow (real base, real exponent), always positive;
  the comparison `(F.card : ℝ) ≥ …` happens in ℝ with the cast on the correct side.
- `Gᶜ.IsClique ↑S` ⟺ $S$ pairwise non-adjacent in $G$ with distinct elements ⟺ $S$ is an
  independent set — the standard complement encoding (`SimpleGraph.compl` has
  `Gᶜ.Adj a b ↔ a ≠ b ∧ ¬G.Adj a b`).
- `G.induce (↑S : Set (Fin n)) ≃g G.induce ↑T` is an isomorphism between graphs on the
  subtypes `↑S`, `↑T`; when `S.card ≠ T.card` no equiv of the vertex types exists, so
  `¬Nonempty (… ≃g …)` is automatically true — matching the informal count, which also
  treats subgraphs of different orders as non-isomorphic.
- No `StrictMono`/`Monotone` or interval-endpoint issues arise.

**A3. Definitions — pass (trivially).** No `def`/`abbrev`/`structure` in the file; no
`sorry` outside proof bodies.

- Polarity by hand: Shelah proved the affirmative, the page banner says "solved in the

- No binders before the colon (line 76: `theorem erdos_1036 :` is binder-free); the

- History note: the raw first pass was a bare assertion; `reviews/1036.md` correctly
  flagged the missing `answer()` wrapper and the restyled file fixed it. Verified against

## E. Prior-review audit (`ai-review/1036.md`)

Mostly accurate on the Lean semantics; four findings:

1. **Endorsed a wrong bibliographic expansion.** "The existing citations are accurate
   and correctly attributed" — false. The `[Er93]` entry it quotes attributes
   `[Er93, p.346]` to "On some of my favourite theorems" (Bolyai, pp. 97–132), which
   cannot contain p. 346; the correct expansion (Quaestiones Mathematicae 16 (1993),
   333–350) was already in use in the corrected neighbours and upstream files. The
   review checked internal consistency but never checked the page number against the
   article's page range — the same "endorsing recoverable-data errors" class as the
   1001/1005 audit findings.
2. **Missed the `[Va99, 3.53]` source key.** The review lists what "the website
   additionally mentions" yet omits the second citation on the problem's own source
   line, plainly visible in the recovered HTML (`[Er93,p.346][Va99,3.53]`). Data it
   implicitly treated as absent was recoverable.
3. **Wrong edge-case argument (right conclusion).** "For small $n$ (e.g. $n = 0, 1$),
   `Real.log n ≤ 0`, so any singleton set … violates the clique bound, making the
   hypothesis false." For $n = 0$ there are **no** singletons — `Fin 0` is empty, every
   `S` is `∅` with `card 0 ≤ 0`, so the hypothesis is *satisfied*, not false; the
   statement still holds because the conclusion is also satisfiable
   ($F = \{\emptyset\}$, $|F| = 1 \ge 2^{\delta\cdot 0}$). The conclusion (no defect)
   survives, but the justification is the invented-then-excused pattern flagged in the
   1000/1005 audits: on a problem where the degenerate case really bites, this reasoning
   would have masked it.
4. **Minor factual slip.** "Erdős's Ramsey-theoretic context conventionally uses log
   base 2 (since $R(k,k) \sim 2^{k/2}$)" — $R(k,k) \sim 2^{k/2}$ is not a theorem (only
   the lower bound $R(k,k) \ge 2^{k/2}$ is known; the asymptotics are open). The
   surrounding conclusion (base immaterial because $c$ is quantified) is correct.

What it got right (re-derived): the clique/independence encodings; the observation that
`≃g` between subtypes automatically handles different cardinalities; the
$\Omega_c$ unpacking; `answer(True)` polarity. Also audited `reviews/1036.md`: its
`answer()` non-conformance flag was correct and was fixed in `deepmind/1036.lean`; but
its §3 checkbox "Includes a brief plain-English description of the problem" was false —
the styled module docstring contained no description of the problem at all (now it
does).
