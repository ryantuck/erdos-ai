## Summary

The problem (verbatim from the recovered `/latex/75` capture): "Is there a graph of
chromatic number ℵ₁ with ℵ₁ vertices such that for all ε > 0 if n is sufficiently
large and H is a subgraph on n vertices then H contains an independent set of size
> n^{1-ε}? What about an independent set of size ≫ n?" Conjectured by Erdős, Hajnal,
and Szemerédi [EHS82]; status **OPEN** (mirror-confirmed, 2026-08-14). The Lean file
states both parts as bare existence assertions: `erdos_problem_75a`
(`conjectures/75.lean:29-39`) asserts a graph on a type of cardinality ℵ₁, not
ℕ-colorable, in which for every ε > 0 all sufficiently large vertex subsets of size
n contain a G-independent subset larger than n^{1-ε}; `erdos_problem_75b`
(lines 48-58) asserts the linear-size (≫ n) strengthening with a uniform c > 0.
Read back independently, both match the source questions' conjectured (affirmative)
direction under three equivalences I re-derived by hand (chromatic-number encoding,
subgraph-vs-vertex-subset, and threshold-vs-all-n for Part 2). **No semantic
defects** — only scholarship gaps (no bibliography, no status/remarks) and
polish-level nits, addressed in `conjectures-v2/75.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 29-39: "There exist a type `V` (Type 0), a
  `DecidableEq V` instance, and `G : SimpleGraph V` with (i) `#V = ℵ₁`, (ii) no
  `G`-coloring by ℕ, and (iii) for every real ε > 0 there is N such that every
  `S : Finset V` with `|S| = n ≥ N` has a subset `T` pairwise non-adjacent in `G`
  with `|T| > n^{1-ε}` (real rpow)." This is the affirmative answer to question 1
  as asked. Lines 48-58 are identical except (iii) becomes "∃ c > 0 ∀ n ≥ 1 …
  `|T| ≥ c·n`" — the affirmative answer to question 2.
- **Chromatic number ℵ₁ encoding** (`#V = aleph 1 ∧ ¬Nonempty (G.Coloring ℕ)`),
  re-derived: (a) any coloring by a finite or countable type composes with an
  embedding into ℕ to give a `G.Coloring ℕ`, so its absence forces χ(G) > ℵ₀;
  (b) the identity map is a coloring by `V` (adjacent vertices are distinct since
  `SimpleGraph` is irreflexive), so χ(G) ≤ #V = ℵ₁; (c) there is no cardinal
  strictly between ℵ₀ and ℵ₁ (ℵ₁ is the successor — ZFC, no CH needed), hence
  χ(G) = ℵ₁ exactly. Faithful.
- **"Every subgraph H on n vertices" vs. vertex subsets.** The Lean quantifies over
  `S : Finset V` with `S.card = n` and demands `T` independent *in G*. Equivalent to
  the source, not merely conventionally: for any subgraph H with V(H) = S,
  E(H) ⊆ E(G[S]), so a G-independent T ⊆ S is independent in H (formal ⇒ source,
  instantiating S := V(H)); conversely the induced subgraph G[S] is a subgraph on n
  vertices whose independent sets are exactly the G-independent subsets of S
  (source ⇒ formal). Same argument pattern as the problem-73 review; correct here
  too.
- **"≫ n" reading (Part 2).** Vinogradov "independent set of size ≫ n" inside an
  n-vertex subgraph (where an independent set has size ≤ n) can only mean linear
  size: ∃ c > 0 with size ≥ c·n. The encoding matches; see A2 for the dropped
  threshold.
- **`V : Type` (universe 0) restriction**: no loss — ℵ₁ ≤ 𝔠 in ZFC, and Type-0
  types of cardinality ℵ₁ exist (e.g. `(aleph 1).ord.toType`), so the existential is
  not accidentally weakened, and any Type-0 witness is a genuine witness.
- Not vacuous/trivial: `V` is uncountable so `Finset`s of every size exist (the
  `∀ S, S.card = n → …` hypothesis is non-vacuous for every n); the ε ≥ 1 instances
  of Part 1 are trivially satisfiable by singletons but the statement's content
  lives at small ε, exactly as in the source; neither theorem is satisfiable by a
  degenerate graph, since χ = ℵ₁ plus large independent sets in every finite subset
  is precisely the open tension.

**A2. Lean semantics traps — pass.**

- **No ℕ subtraction**: `1 - ε` is real subtraction (`(1 : ℝ) - ε`), correctly
  placed; no truncation anywhere.
- **rpow junk values** (batch checklist, rpow-0-0 class, checked explicitly):
  `(n : ℝ) ^ ((1 : ℝ) - ε)` is `Real.rpow`. At n = 0: `0 ^ (1-ε) = 0` for ε ≠ 1 and
  `0 ^ 0 = 1` for ε = 1; either way the n = 0 instance demands `|T| > 0` (or > 1)
  from `T ⊆ ∅`, which is unsatisfiable — so the `∃ N` is simply forced to choose
  N ≥ 1. That is exactly what "n sufficiently large" licenses; no silent
  falsification and no trivialization. In Part 2 the guard `n ≥ 1` avoids n = 0
  outright (and even n = 0 would be harmless there: `|∅| ≥ c·0`).
- **No `Finset.range`**, no ℕ/field division, no `liminf`/`limsup`
  (problem-33 class: n/a), no default-valued binders/`optParam`
  (problem-25 class: none in file).
- **"Sufficiently large" encoding**: `∃ N, ∀ n ≥ N` with N depending on ε — matches
  the source's "for all ε > 0 if n is sufficiently large" (N(ε) reading, which is
  the only sensible one; upstream formal-conjectures uses the equivalent
  `∀ᶠ n in atTop`).
- **Dropped threshold in Part 2** (re-derived, not nodded through): "∃ c > 0,
  ∀ n ≥ N" and the file's "∃ c > 0, ∀ n ≥ 1" are equivalent. (⇐ trivial;
  ⇒ replace c by c' = min(c, 1/N): for n ≥ N use c' ≤ c; for 1 ≤ n < N a singleton
  is independent — simple graphs are loopless — and 1 ≥ n/N ≥ c'·n.) Likewise
  `≥ c·n` vs `> c·n`: interchangeable by halving c. No defect.
- **Constant quantifier order** (problem-55/73 class, checked explicitly): in Part 2
  `∃ c` stands *before* `∀ n` — load-bearing and correct: `∀ n, ∃ c` would be
  trivially satisfiable (c = 1/n via a singleton). `c` sits after `∃ G`, so it may
  depend on the graph — correct, since the question is about the existence of one
  graph with one linear constant. In Part 1, `∃ N` after `∀ ε` — correct (N may
  depend on ε).
- Strict `>` in Part 1 matches the source's "> n^{1-ε}"; `Set.Pairwise` quantifies
  over *distinct* pairs only, which is the right notion of independent set
  (singletons independent).
