## Summary

The problem (OPEN): determine whether there exists a constant $C > 1$ such
that every finite projective plane has a set of points $S$ with
$1 \le |S \cap \ell| \le C$ for all lines $\ell$ — i.e., a blocking set no
line meets more than a bounded number of times. Erdős–Silverman–Stein [ESS83]
proved the analogous statement with $|S \cap \ell| \ll \log n$ ($n$ the order
of the plane). The Lean (`conjectures/1159.lean:30-37`) asserts
$\exists C : \mathbb{N},\ 1 < C \wedge \forall$ finite
`Configuration.ProjectivePlane P L`, $\exists S :$ `Finset P`,
$\forall \ell,\ 1 \le |S \cap \ell| \le C$ — exactly the asked ("yes")
direction of the question, in the direct-assertion form that is this raw
corpus's uniform convention for open yes/no questions. Read back
independently, the Lean and the recovered source statement agree; the only
defect-class finding is bibliographic (citation keys used but never defined).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Determine whether there
  exists a constant $C>1$ such that the following holds. Let $P$ be a finite
  projective plane. Must there exist a set of points $S$ such that
  $1\leq \lvert S\cap \ell\rvert \leq C$ for all lines $\ell$?" The module
  docstring (lines 10-12) reproduces this near-verbatim.
- Independent back-translation of lines 30-37: "there is a natural number
  $C \ge 2$ such that for every pair of types $P, L$ carrying a finite
  projective-plane structure, some finite set $S$ of points meets every line
  in at least 1 and at most $C$ points." Quantifier order matches the source
  exactly: the constant is absolute (outermost $\exists$), the plane is
  universally quantified, $S$ existential per plane, $\ell$ universal per $S$.
- Types: `C : ℕ` with `1 < C` faithfully encodes the source's real "constant
  $C > 1$": since $|S \cap \ell|$ is a natural number, a real bound $C > 1$
  works iff the natural bound $\lfloor C \rfloor \ge 2$ (if $\lfloor C \rfloor
  = 1$ the real bound is equivalent to the impossible $C = 1$, see below)
  works, and conversely any natural $C \ge 2$ is a real constant $> 1$. The
  $\exists$-statements are equivalent. `Finset P` (vs `Set P`) is right under
  `Fintype P` and is what `card` needs. $|S \cap \ell|$ is encoded as
  `(S.filter (fun p => p ∈ l)).card` — correct, since $\ell$ is a line (an
  element of `L`), not a set, so intersection must go through the membership
  relation.
- Mathlib's `Configuration.ProjectivePlane P L` (with `[Membership P L]`,
  `[Fintype P]`, `[Fintype L]`) is the right structure: it extends `HasPoints`
  and `HasLines` (unique joining line / meeting point) with a nondegeneracy
  configuration, which is the standard axiomatization; adding both `Fintype`s
  makes it a finite projective plane.
- Not vacuous: (i) the class is instantiable — finite projective planes exist
  (e.g. the Fano plane), so the inner $\forall$ ranges over genuine
  structures; (ii) no degenerate witness trivializes the statement — $S =$
  `univ` satisfies the lower bound but not the upper bound (lines have $n + 1
  \ge 3$ points), and the $C = 1$ analysis below shows even the *lower*
  threshold $1 < C$ is forced. The statement is the substantive open question.
- The universe restriction `∀ (P L : Type)` (Type 0) is mathematically
  adequate: every finite projective plane is isomorphic to one on a Type-0
  carrier, and the bound $C$ transfers along isomorphisms.

## E. Prior-review audit (`deepmind/ai-review/1159.md`)

The prior review's verdict (correct and faithful) is right, but the audit
finds:

1. **Fabricated justification, right conclusion (the "ovoid" argument, its
   §6).** To justify `1 < C` it claims: "If C = 1, the blocking set would need
   to meet every line in exactly 1 point, which is an ovoid — ovoids do not
   exist in all projective planes, so the question would be trivially false at
   C = 1." This is wrong twice over. (a) A set meeting every line of a
   projective plane in exactly one point is not an ovoid — an ovoid (or in a
   plane, an oval) meets lines in at most 2 points, with tangent *and* secant
   lines. (b) The truth is much stronger than "do not exist in *all* planes":
   such a set exists in **no** projective plane whatsoever — any two distinct
   points of $S$ lie on a common line, which then meets $S$ at least twice, so
   $|S| \le 1$; a singleton misses the lines avoiding it (nondegeneracy), and
   $\varnothing$ misses everything. The conclusion ($C = 1$ is degenerate,
   `1 < C` is right) survives, but the argument names a wrong object and
   proves the wrong quantifier — the same failure family as the 1000/1005
   audits (invented justification that happens to land on the right answer,
   and would mask a real bug where the small case mattered). The correct
   two-line argument is now in the v2 module docstring. Its adjacent remark
   that requiring $C > 1$ is "an unnecessary restriction (since the C ≥ 1
   case is trivially subsumed)" is similarly muddled — allowing $C \ge 1$
   would *weaken* the requirement on the witness, and the two $\exists$-forms
   coincide precisely *because* $C = 1$ is impossible, an argument it never
   makes.
2. **Claims describing a different artifact.** "`answer(sorry)` is the correct
   pattern for an open problem" and "the namespace `Erdos1159` is consistent
   with the codebase convention" are both false of `conjectures/1159.lean`,
   which has no `answer()` and no namespace — they describe the styled copy in
   `deepmind/deepmind/1159.lean`. Expected legacy scope mismatch (per pipeline
   notes), recorded for the benchmark; against the artifact under review the
   question-form analysis has to be redone from scratch (done in A4: the
   direct assertion is the raw corpus's convention, polarity correct).
3. **It repeated the [Va99] = "Vardy, A." attribution without challenge.** Its
   §2 treats "[Va99] Vardy, A." as a real-but-incomplete citation. The
   recovered `/latex/1159` extraction shows the site's bibliography for this
   problem contains no [Va99] entry at all, and the site's canonical [Va99] is
   the Budapest 1999 booklet (established across this corpus's reviews) — the
   "Vardy" expansion is a hallucination in the styled file (sibling styled
