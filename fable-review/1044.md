## Summary

The problem (erdosproblems.com/1044, recovered verbatim from logs): let
$f(z) = \prod_{i=1}^n (z - z_i) \in \mathbb{C}[x]$ with $|z_i| \le 1$ for all $i$, and
let $\Lambda(f)$ be the maximum of the lengths of the boundaries of the connected
components of $\{z : |f(z)| < 1\}$; determine $\inf_f \Lambda(f)$. Status **SOLVED**:
Tang proved the infimum is $2$; Tang further conjectures that for fixed degree $n$ the
infimum is attained by $f_n(z) = z^n - 1$, proved for $n = 1, 2$. The Lean
(`deepmind/1044.lean`) defines the open sublevel set, $\Lambda$ as an `sSup` of
1-dimensional Hausdorff measures of component frontiers, and states
`sInf {…} = answer((2 : ℝ))` plus the fixed-degree conjecture as a variant. The encoding
machinery is correct, but the pre-fix candidate set (`f.Monic ∧ (∀ z, f.IsRoot z → ‖z‖ ≤ 1)`)
admits the degree-0 monic polynomial $f = 1$: its root condition is vacuous, its sublevel
set is empty, `maxBoundaryLength` returns the junk value `sSup ∅ = 0`, so the left-hand
`sInf` is $0 \ne 2$ and the theorem as written was **false**. The same hole was present
in the raw first pass (there it falsified the `∀ f, Λ(f) ≥ 2` conjunct), so it predates
restyling. Fixed by adding `0 < f.natDegree`.

## A. Semantic fidelity

**A1. Statement fidelity — one defect (fixed); otherwise faithful, source-verified.**

- Recovered verbatim source statement (see Addendum): "Let
  $f(z)=\prod_{i=1}^n(z-z_i)\in\mathbb{C}[x]$ where $\lvert z_i\rvert\leq 1$ for all
  $i$. If $\Lambda(f)$ is the maximum of the lengths of the boundaries of the connected
  components of $\{ z: \lvert f(z)\rvert<1\}$ then determine the infimum of
  $\Lambda(f)$."
- Independent back-translation of the pre-fix theorem: "the infimum, over monic
  $f \in \mathbb{C}[z]$ all of whose roots lie in the closed unit disk, of the supremum
  of the $H^1$-measures of the frontiers of the components of $\{|f| < 1\}$, equals 2."
  Encoding of $f$: `Monic` + `∀ z, f.IsRoot z → ‖z‖ ≤ 1` is exactly "monic with all
  roots in the closed unit disk", which over $\mathbb{C}$ is exactly the product form
  $\prod (z - z_i)$, $|z_i| \le 1$ — **provided $n \ge 1$**.
- **[defect] Degree-0 escape hatch.** The source's $f = \prod_{i=1}^n (z-z_i)$ has at
  least one root ($n \ge 1$; for $n = 0$, $\Lambda$ would be a maximum over an empty
  collection, undefined). The Lean set had no degree hypothesis, so
  $f = 1$ (`Polynomial.monic_one`) qualifies: `IsRoot` is vacuously satisfied,
  `lemniscateSublevel (fun z => 1) = {z | (1:ℝ) < 1} = ∅`, the `sSup` set in
  `maxBoundaryLength` is empty, and `Real.sSup ∅ = 0`. Hence $0$ belongs to the
  `sInf` set; since every member is $\ge 0$ (each is a `toReal` value or the junk $0$),
  the LHS `sInf` equals $0$, and `sInf {…} = 2` is **false as stated**. Fixed by adding
  `0 < f.natDegree` (deepmind/1044.lean:79; not compile-verified). With the fix, for
  every admissible $f$ the sublevel set is nonempty (it contains the roots), has at
  most $\deg f$ components (minimum-modulus principle), each with compact
  algebraic-curve frontier of finite $H^1$, so `maxBoundaryLength` is the genuine
  maximum and the statement is Tang's theorem.
- Not vacuous/trivial post-fix: the candidate set is nonempty ($f = z$ gives
  $\Lambda = 2\pi$), the value set is bounded below by 0, and `Real.sInf` is honest.
  The infimum-2 content is substantive (each petal of $\{|z^n - 1| < 1\}$ has perimeter
  $\to 2$ as $n \to \infty$, degenerating to a segment of length $\to 1$; the lower
  bound $\Lambda > 2$ is Tang's contribution).
- Indexing conventions: no sequences/indices in the statement; N/A.

**A2. Lean semantics traps — pass (with the junk values now documented).**

- No ℕ subtraction. `X ^ n - 1` lives in `Polynomial ℂ` (ring subtraction). Fine.
- No division anywhere.
- `sSup`/`sInf` on ℝ: junk value 0 on the empty set — this is precisely the defect
  vehicle above; post-fix the sets are nonempty and bounded, and the junk behavior is
  documented in `maxBoundaryLength`'s docstring.
- `ENNReal.toReal` maps `⊤` to 0: harmless here (polynomial component boundaries are
  compact subsets of the real-algebraic curve $\{|f| = 1\}$, of finite length);
  documented in the docstring.
- Strict vs non-strict: `‖f z‖ < 1` (strict, matches $\{|f(z)| < 1\}$) and `‖z‖ ≤ 1`
  (closed disk, matches $|z_i| \le 1$). Both correct.
- Filter/`StrictMono` traps: N/A.

**A3. Definitions — pass.**

- `lemniscateSublevel` matches its docstring and the source set exactly; no `sorry` in
  any `def`.
- `maxBoundaryLength` matches the source's $\Lambda$ on the intended inputs:
  `connectedComponentIn S x` with `x ∈ S` enumerates exactly the components; `frontier`
  of a component of an open set is its topological boundary; `Measure.hausdorffMeasure 1`
  is the standard formalization of curve length ($H^1$ of a rectifiable curve is its arc
  length; component boundaries here are closed curves, injective off a finite set of
  critical points — e.g. the petal boundaries of $\{|z^n-1|<1\}$ all pass through 0 — so
  $H^1$ agrees with the classical boundary length). Degenerate-input behavior (empty
  sublevel set → junk 0, infinite measure → junk 0) is now documented rather than
  silent.
- No drift between what the defs compute and what the theorems need — after the
  positive-degree fix.

**A4. Question form and answer polarity — pass.**

- The source is a **value request** ("then determine the infimum of $\Lambda(f)$"), so
  the correct shape is `… = answer(value)` with a concrete value; the file has
  `sInf {…} = answer((2 : ℝ))`. Non-tautological, concrete.
- The value 2 matches the recovered page's resolution ("Tang … proved that the infimum

- No binders before the colon on the `answer()` theorem (`theorem erdos_1044 :` is

- The raw first pass used the direct-assertion conjunction

  boundedness below — the two are equivalent. The restyling *improved* the form and did

## E. Prior-review audit (`ai-review/1044.md`)

The review's structural observations are accurate, but it fails on exactly the recurring
pattern this pipeline watches for — identifying a degenerate case and then excusing it
unsoundly:

1. **False "benign" claim masking the defect (its caveat 2).** It writes: "If
   `lemniscateSublevel f = ∅` (which can't happen for a nonconstant monic polynomial …)
   then `sSup ∅ = 0` … This is benign for the theorem since monic polynomials always
   have nonempty sublevel sets at level 1." The final clause is **false** — the constant
   monic polynomial $f = 1$ has an empty sublevel set — and self-contradicts its own
   parenthetical ("nonconstant"). The theorem quantified over *all* monic polynomials
   with the vacuous root condition, so the case it waved off is exactly the one that
   falsifies the statement (sInf $= 0 \ne 2$). Same failure class as the 1000 audit
   (invent/excuse asymptotically) and the 1005 audit (unsound `sSup` boundedness
   argument): a junk-value edge case acknowledged and then dismissed with a false lemma.
2. **"No mathematical flaws identified" / "The `sInf`/`sSup` structure correctly
   formalizes …" — both false** as consequences of (1).
3. **Correct claims, verified:** caveat 1 (`toReal` sends `⊤` to 0; harmless for
   polynomial lemniscates) — correct; caveat 3 (finitely many components, `sSup` = max,
   at most $n$ components) — correct for degree $\ge 1$; the reuse survey — all five
   named declarations exist where claimed (`Erdos116.lemniscateInterior` at 116.lean:54,
   `Erdos115.lemniscate` at 115.lean:40, `Erdos1120.lemniscateSet` at 1120.lean:38,
   `Erdos114.arcLength` at 114.lean:57, `connectedComponentIn` use in 1047/1048),
   with the minor looseness that 116's version takes a `Polynomial ℂ`, not a `ℂ → ℂ`.
4. **Timeline artifacts.** Its §3 "the Tang variant is not formalized" was true when
   written and was subsequently fixed (the variant is in the current file). Its citation
   check ("matches the website") is confirmed by the recovered page for the key/authors/
   title, though the `/latex` extraction lacks the volume number it implicitly blessed.
5. **Style review (`reviews/1044.md`), for the record:** it reviewed a superseded
   version (it describes the raw conjunction form as the content of
   `deepmind/1044.lean` and reports "no variants"); both its findings (missing module
   docstring description; `answer()` form) were addressed in the current file before
