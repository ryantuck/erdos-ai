## Summary

Erdős's original problem ([Er71, p.107]): for a sequence $x_1, \ldots, x_n$ of distinct
real numbers, determine $\max(\sum x_{i_r})$ over all monotonic subsequences — posed, as
the site itself says, "rather ambiguous[ly]". The site's precise reformulation (van
Doorn) asks for the largest constant $c$ with $\max(\sum x_{i_r}) >
(c-o(1))\frac{1}{\sqrt n}\sum x_i$ for all real sequences; Cambie's stronger conjecture —
$k^2$ distinct positive reals summing to $1$ always contain a monotonic subsequence of
sum $\ge 1/k$ — was proved by Tidor–Wang–Yang [TWY16] (also implicit in Wagner [Wa17]),
giving $c = 1$, and the page status is **SOLVED (LEAN)**. The Lean file formalizes
exactly Cambie's conjecture: `erdos_1026` (`deepmind/1026.lean`) takes `k ≥ 1`,
`x : Fin (k ^ 2) → ℝ` positive, injective, summing to 1, and asserts a `Finset` of
indices that is pairwise-monotone with sum `≥ 1 / (k : ℝ)`. Read back independently, the
Lean matches the page's statement of the conjecture term for term; I found no semantic
defects, only scholarship enrichment (missing [Ha57]/[St95] references, missing remarks),
which has been applied.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement: "Let $x_1,\ldots,x_n$ be a sequence of distinct
  real numbers. Determine $\max(\sum x_{i_r})$, where the maximum is taken over all
  monotonic subsequences." Recovered remarks give van Doorn's precise question and
  Cambie's stronger conjecture verbatim; the module docstring reproduces all three layers
  faithfully (and, post-fix, the $c \le 1$ construction and Hanani's bound too).
- Independent back-translation of the theorem (lines 92–99): "for every $k \ge 1$ and
  every positive injective $x : \{0,\dots,k^2-1\} \to \mathbb{R}$ with $\sum x_i = 1$,
  there is a set $S$ of indices on which $x$ is either strictly increasing or strictly
  decreasing along the index order, with $\sum_{i \in S} x_i \ge 1/k$." This is exactly
  Cambie's conjecture as the page states it.
- A subsequence is correctly encoded as a subset of indices with the induced order:
  `IsIncreasingSubseq` demands `i < j → x i < x j` for all pairs in `S`, which for a
  finite index set is precisely "the values along increasing indices form an increasing
  run". Since the $x_i$ are distinct (`hx_inj`), strict vs non-strict monotonicity
  coincide, so no generality is lost by using strict inequalities.
- Indexing: the source's $x_1,\dots,x_{k^2}$ vs Lean's `Fin (k ^ 2)` is a pure relabeling;
  no arithmetic depends on index values, only on their order. No off-by-one is possible.
- Not vacuous, and not degenerate-witness-cheatable: the empty `Finset` is vacuously
  monotone but has sum $0 < 1/k$ (for $k \ge 1$), so it can never witness the
  existential; singletons *are* legitimate length-1 monotone subsequences and are
  correctly allowed (for $k = 1$ the singleton of the unique element, of value 1, is the
  intended witness). The Lean statement is exactly equivalent to the informal one, not
  weaker or stronger.
- `hk : k ≥ 1` is mathematically redundant — at $k = 0$ the hypothesis
  `hx_sum : ∑ i, x i = 1` is the false `0 = 1` (empty sum), so the instance is vacuous
  with or without `hk` — but it is harmless and aids clarity. (See Part E for the prior
  review's incorrect justification of it.)

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere.
- Division: the only division is `1 / (k : ℝ)` — field division with `k ≥ 1`, hence
  nonzero denominator; no division-by-zero convention is ever exercised. (`k ^ 2` is ℕ
  exponentiation, exact.)
- No `Finset.range`; sums are over `Fin (k ^ 2)` (full) and over `S` — both correct.
- Vacuous quantifiers: `IsIncreasingSubseq`/`IsDecreasingSubseq` are vacuously true on
  `∅` and singletons; as analyzed in A1 this matches the source's intent (singletons are
  monotone subsequences; the empty set cannot satisfy the sum bound).
- No filters/limits: the formalized statement is the finitary Cambie conjecture, so no
  "infinitely many"/o(1) encoding is needed. (The o(1) in van Doorn's question is
  precisely what the formalization deliberately avoids; see B2.)
- Strictness: strict `<`/`>` in the subsequence definitions is correct under the
  distinctness hypothesis (equivalent to non-strict there); the conclusion's `≥ 1/k`
  matches the source's "at least $1/k$".

**A3. Definitions — pass.**

- All three defs (`IsIncreasingSubseq`, `IsDecreasingSubseq`, `IsMonotoneSubseq`, lines
  53–66) match their docstrings and the informal notion, including degenerate inputs
  (empty/singleton, discussed above). No `sorry` in any def. The theorem uses them with
  exactly the meaning they compute — no drift.

**A4. Question form and answer polarity — pass, with a documented scope choice.**

- The original problem is a value request ("Determine …"), but the site itself calls it
  "rather ambiguous"; the community-precise version (van Doorn's largest constant $c$)
  is a derived formulation whose faithful `… = answer(1)` encoding would require
  defining $c$ as an `sSup` over constants of an eventual inequality quantified over
  *all* real sequences — machinery (o(1), `Real.sqrt`, sign issues when $\sum x_i \le
  0$, empty-subsequence conventions) far beyond the file, and delicate to get right.
- What is formalized is Cambie's stronger conjecture, a **direct assertion** that has
  been *proved* — Case 3 of the checklist: bare proposition, no `answer()` wrapper,
  stated in the true (proved) direction. Polarity checked by hand: the Lean asserts the
  conjecture itself, which is the direction Tidor–Wang–Yang established. This matches
  how the page frames the resolution ("In particular, this shows that $c=1$") and is the
  same encoding the raw pass used; no drift and no wrong-polarity risk.
- No binders-before-colon issue arises (there is no `answer()` and the theorem's binders
  are genuine hypotheses of the assertion).

**A5. Solution status — pass (source-verified).**

- Recovered page banner: **SOLVED (LEAN)** — tooltip "This has been resolved in some
  other way than a proof or disproof, and that resolution verified in Lean." Remarks:
  first proved by Tidor–Wang–Yang [TWY16], implicit in Wagner [Wa17]; "A proof was given
  and formalised by Aristotle (see the comments), with an alternative proof provided by

- `@[category research solved]` and both docstrings agree with this. A more precise tag
  (`research formally solved using lean4 at "<link>"`) would need the Aristotle

## E. Prior-review audit (`ai-review/1026.md`)

Broadly sound on the formalization itself (its empty-set moot-ness argument is correct
and its endorsement of the encoding is justified), but four findings:

1. **Wrong Lean semantics in the `hk` justification.** It claims `hk : k ≥ 1` "correctly
   excludes the degenerate case $k = 0$ (where $k^2 = 0$ and the statement would be
   vacuously true but $1/k$ undefined)". Two errors: (a) in Lean, `1 / (0 : ℝ) = 0` —
   nothing is "undefined"; (b) the $k=0$ instance is vacuous *regardless of `hk`*,
   because `hx_sum` becomes the unprovable `0 = 1` (and even ignoring that, `S = ∅`
   would witness `0 ≥ 1/0 = 0`). The conclusion (`hk` is fine) survives, but both
   reasons are wrong — the same "wrong claims about Mathlib semantics" failure class as
   the 1002 audit.
2. **Fabricated bibliography reproduced without flagging it.** It quotes the then-current
   stub `[TWY16] Tidor, J., Wang, V., and Yang, K., *Weighted monotone subsequences*
   (2016)` and calls it "acceptable but incomplete". Both the title and the third
   author's initial were fabrications of the raw pass: the real paper is Tidor–Wang–
   Yang **B.**, "1-color avoiding paths, special tournaments, and incidence geometry",
   arXiv:1608.04153 (confirmed by the recovered `/latex/1026` extraction). Worse, for
   [Wa17] it *recommends inventing* a title ('"Wagner, A. Z., *Refining the
   Erdős–Szekeres theorem* (2017)" or similar') — the real title is "Large subgraphs in
   rainbow-triangle free colorings". The later upstream edit happened to fix both with
   correct data, but the review's method (guess-and-fill) is exactly the fabrication
   this pipeline prohibits.
3. **Missed citation keys.** It discusses Hanani's decomposition result yet never notes
   that [Ha57] — and [St95], which it never mentions at all — are first-class citation
   keys on the page, absent from the docstring. Both now added (Addendum fix 2).
4. **Muddled but harmless singleton discussion.** "its value is at most 1 while $1/k <
   1$ could potentially be met" — garbled reasoning (a singleton may certainly meet the
   bound when some $x_i \ge 1/k$; that is a feature, not a concern). No wrong
   conclusion follows.

Verified correct: the OEIS ids A391431/A391490 and the [Er71, p.107] source attribution
(both confirmed against the recovered page); the empty-`Finset` analysis; the
