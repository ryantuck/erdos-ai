## Summary

The problem (verbatim from the recovered page): "Let
$f(z)=\prod_{i=1}^n(z-z_i)\in \mathbb{C}[z]$ with $|z_i| < 1$ for all $i$. Must there
always exist a path of length less than $2$ in $\{z: |f(z)| < 1\}$ which connects two
of the roots of $f$?" Status **OPEN** (banner FALSIFIABLE: "Open, but could be disproved
with a finite counterexample"), tags *analysis*, *polynomials*, citation `[EHP58, p.139]`;
the remark records that Erdős–Herzog–Piranian proved the sublevel set always has a
connected component containing at least two of the roots. The Lean theorem
(`conjectures/1041.lean`, `erdos_problem_1041`) asserts: for every $n \ge 2$ and every
tuple of roots in the open unit disk, there are indices $i \ne j$ and a path
$\gamma$ from $\text{roots}_i$ to $\text{roots}_j$ with
$\lvert\prod_k(\gamma(t)-\text{roots}_k)\rvert < 1$ for all $t$ and total variation
(arc length) $< 2$. Read back independently, this is exactly the affirmative answer to
the question as asked, in the repo's standard raw direct-assertion form for open
questions. No semantic defects found; findings are polish-level (docstring/scholarship
enrichment, now applied — see Addendum).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified against recovered snapshot).**

- Independent back-translation of the theorem (post-fix lines 39–46): "for all
  $n \ge 2$ and all $z_1,\dots,z_n$ with $|z_i| < 1$, there exist $i \ne j$ and a
  continuous path from $z_i$ to $z_j$, along which $|f| < 1$ throughout (where
  $f(z) = \prod_k (z - z_k)$), of arc length $< 2$." This matches the recovered
  problem text; the docstring reproduces the source essentially verbatim.
- The polynomial is encoded by its root tuple `roots : Fin n → ℂ` and the product
  `∏ k : Fin n, (γ t - roots k)` — literally $f(\gamma(t))$ for the monic $f$ with
  exactly those roots (with multiplicity). This mirrors the source, which *defines*
  $f$ by its roots; no `Monic`/`natDegree` side conditions are needed because the
  parameterization builds them in. (The upstream file instead takes `f : ℂ[X]`,
  `Monic`, `natDegree = n`, `rootSet ⊆ ball 0 1` — equivalent by the fundamental
  theorem of algebra; see Part E.)
- **Explicitation `2 ≤ n` is correct and necessary.** The source leaves $n$
  unquantified, but "connects two of the roots" presupposes at least two roots (with
  multiplicity): for $n \le 1$ the assertion is falsified degenerately (no pair
  exists), which is plainly not the question's intent. The upstream file makes the
  identical `n ≥ 2` restriction.
- **Multiplicity convention.** `i ≠ j` requires distinct *indices*, not distinct
  *values*: a repeated root counts as two roots, and the constant path (variation 0,
  $|f| = 0 < 1$ at the root) is then a legitimate trivial witness. This is the right
  reading, not a loophole: under a distinct-values reading the conjecture would be
  trivially **false** (e.g. $f(z) = z^2$ has only one distinct root, so no path could
  ever "connect two roots"), so counting with multiplicity is forced; it is also
  EHP58's own convention and exactly the upstream encoding
  (`({z₁, z₂} : Multiset ℂ) ≤ f.roots`, which permits $z_1 = z_2$ precisely at a
  multiple root). Now documented in the docstring (applied fix).
- Not vacuous / not trivially true: for distinct roots the constraint is the genuine
  open problem — any two points of the open disk are at distance $< 2$, but the
  straight segment can leave $\{|f| < 1\}$, and the strict budget $2$ is the
  substantive content. Endpoints satisfy the sublevel condition automatically
  ($f(\text{root}) = 0$), consistently.

**A2. Lean semantics traps — pass (each checked explicitly).**

- **ℕ subtraction:** none — all subtraction is in ℂ.
- **Division:** none anywhere.
- **`Finset.range`:** not used; `∏ k : Fin n` is over `Finset.univ`, i.e. all $n$
  roots — correct.
- **Vacuous quantifiers:** `∀ t` ranges over `unitInterval` (nonempty); `∀ i` over
  `Fin n` with $n \ge 2$ (nonempty). The only "degenerate witness" is the constant
  path at a repeated root, which is intended (A1).
- **Length encoding:** `eVariationOn γ.extend (Set.Icc 0 1) < 2` — `Path.extend` is
  the `IccExtend` of γ (constant outside $[0,1]$, agreeing with γ on it), so the
  total variation over `Set.Icc (0:ℝ) 1` is precisely the arc length of the path,
  valued in ℝ≥0∞; `< 2` (with `2 : ℝ≥0∞`) forces rectifiability plus the strict
  bound, exactly "a path of length less than 2". This is the *literal* reading of
  "length of a path"; upstream's `μH[1] (Set.range γ) < 2` is a mathematically
  equivalent alternative (see Part E).
- **Strict vs non-strict:** `‖roots i‖ < 1`, `‖∏ …‖ < 1`, `… < 2` — all strict,
  matching the source's $<$ throughout. No `StrictMono`/interval-endpoint issues
  arise.
- Sublevel membership is imposed pointwise (`∀ t, ‖f(γ t)‖ < 1`), which is
  extensionally the same as `Set.range γ ⊆ {z | ‖f z‖ < 1}`.

- Docstring citation `[EHP58, p.139]` vs page `#problem_id`: **match**.
- Docstring remark (component lemma) vs page remark: **match** ("who proved that this
  set always has a connected component containing at least two of the roots").
- Pre-fix omissions relative to the page (now applied): OPEN/FALSIFIABLE status and a
  References entry. Neither was a misrepresentation — missing enrichment only.
- **Upstream comparison** (upstream content recovered from three agreeing log
  captures): upstream takes `f : ℂ[X]` monic of degree $n \ge 2$ with
  `rootSet ℂ ⊆ Metric.ball 0 1` and asserts
  `∃ z₁ z₂, ({z₁,z₂} : Multiset ℂ) ≤ f.roots ∧ ∃ γ : Path z₁ z₂, range γ ⊆
  {z | ‖f.eval z‖ < 1} ∧ μH[1] (range γ) < 2`. Differences from this repo's file, each
  checked for equivalence: (a) polynomial-with-hypotheses vs root-tuple
  parameterization — equivalent over ℂ (every monic degree-$n$ polynomial is
  $\prod(z - z_i)$, and `rootSet ⊆ ball` ⟺ every $z_i$ in the ball); (b) multiset
  pair vs index pair — equivalent encodings of "two roots with multiplicity";
  (c) Hausdorff measure of the range vs arc length — arc length ≥ $\mathcal{H}^1$ of
  the range always, and conversely the range is a continuum, so if
  $\mathcal{H}^1(\text{range}) < 2 < \infty$ the classical rectifiability theorem for
  continua of finite $\mathcal{H}^1$ measure (e.g. Falconer, *Geometry of Fractal
  Sets*, §3) yields an arc between the endpoints inside the range of length
  $\le \mathcal{H}^1(\text{range}) < 2$. Hence the two existence statements are
  mathematically equivalent, and the arc-length form here is the more literal
  rendering of "a path of length less than 2". No discrepancy of substance; the
  upstream file remains authoritative for the formal-conjectures repo.
