## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of `conjectures/1104.lean:43–51`: "there exist positive
  reals $c_1$, $c_2$ and a natural $N_0$ such that for every $n \ge N_0$, both
  $c_1 \cdot (n/\log n)^{1/2} \le f(n)$ and $f(n) \le c_2 \cdot (n/\log n)^{1/2}$,"
  where $f(n)$ is the supremum of chromatic numbers of triangle-free graphs on `Fin n`.
  This matches the theorem docstring (lines 37–42) word for word in content, and is the
  standard Θ-encoding of the page's displayed bounds.
- The source question "Estimate $f(n)$" is an open-ended estimation request; the page's
  precise content is the pair of displayed bounds. Formalizing the Θ-statement (a true,
  solved proposition per the page's own remarks) is the right scope. The upstream
  formal-conjectures file for 1104 — recovered from the logs — makes the same call:
  it leaves the headline `erdos_1104` as a `TODO` and encodes exactly these two bounds
  as `research solved` variants (`∃ c₁, 0 < c₁ ∧ c₁ ≤ 1 ∧ ∀ᶠ n, c₁·√n/√(log n) ≤ f(n)`
  and `∃ c₂, 2 ≤ c₂ ∧ ∀ᶠ n, f(n) ≤ c₂·√n/√(log n)`), mathematically the same shape as
  this file's statement (for $n \ge 2$, $\sqrt{n}/\sqrt{\log n} = (n/\log n)^{1/2}$).
  Agreement between two independent formalizations is good corroboration.
- Quantifier structure: $c_1$, $c_2$, $N_0$ existential, $n$ universal inside — correct
  for "there exist constants … for all sufficiently large $n$". Sharing one $N_0$
  between the two bounds is equivalent to separate thresholds (take the max).
- Types: `erdos1104_f : ℕ → ℕ` cast to ℝ for the comparison; `(n : ℝ) / log (n : ℝ)`
  and the `rpow` exponent `(1 : ℝ)/2` keep all analysis in ℝ. Correct placement — no
  ℕ-division anywhere.
- Indexing: no sequences; $n$ is the vertex count in both source and Lean. `Fin n` has
  exactly $n$ vertices. Term-by-term exact.
- Not vacuous, not trivially false: the upper bound with *any* constant $c_2$ is the
  hard Johansson/Davies–Illingworth-type theorem, and the lower bound with any
  $c_1 > 0$ needs the triangle-free process/Ramsey machinery — neither side is
  degenerate, and the conjunction pins the true order of magnitude.

**A2. Lean semantics traps — pass.**

- **ℕ subtraction:** none.
- **Division:** real division only. At $n = 0$ and $n = 1$, `Real.log n = 0`, so
  `(n : ℝ) / log n = 0` by the division-by-zero convention, and `(0 : ℝ) ^ ((1:ℝ)/2) =
  0` (`rpow` of zero base, nonzero exponent). The lower bound then reads $0 \le f(n)$
  (true), but the upper bound at $n = 1$ would read $f(1) = 1 \le 0$ — **false**. This
  is harmless *only* because $N_0$ is existentially quantified: any proof takes
  $N_0 \ge 2$, where $\log n > 0$ and the base is positive. Checked and now documented
  in the v2 docstring. (Had the statement been $\forall n$, this would have been a
  defect of the false-at-small-parameters class.)
- **`Finset.range`:** none.
- **Vacuous bounded quantifiers:** none; `∃ N₀, ∀ n ≥ N₀` is a correct, self-contained
  encoding of "for all sufficiently large $n$".
- **`sSup` junk value:** `Nat.sSup` of an unbounded set is 0. Here the defining set
  $\{c \mid \exists G \text{ triangle-free on } \mathrm{Fin}\ n,\ \chi(G) = c\}$ is
  (i) nonempty — `⊥` is `CliqueFree 3`, contributing $c = 0$ for $n = 0$ and $c = 1$
  for $n \ge 1$; and (ii) bounded above by $n$ — every graph on `Fin n` is
  $n$-colorable, so `chromaticNumber ≤ n`. Hence `sSup` is a genuine maximum at every
  $n$ (including $f(0) = 0$, $f(1) = 1$, $f(2) = 2$, matching the informal $f$). No
  junk behavior.
- **`ℕ∞` equality:** `G.chromaticNumber = (c : ℕ∞)` — `chromaticNumber` is
  `ℕ∞`-valued, but on a finite vertex type it is always finite ($\le n$), so the set is
  exactly the image of $\chi$ over triangle-free graphs; the cast-equality encoding
  loses nothing and the `⊤` case never bites.
- **Strict vs non-strict:** the page's displayed bounds are non-strict $\le$ on both
  sides; the Lean uses $\le$ on both sides. Match. No `StrictMono`/interval issues.
