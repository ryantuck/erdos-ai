## Summary

The problem (recovered verbatim): "Let $f_d(n)$ be minimal such that in any collection
of $n$ points in $\mathbb{R}^d$, all of distance at least $1$ apart, there are at most
$f_d(n)$ many pairs of points which are distance $1$ apart. Estimate $f_d(n)$." Status
OPEN; this is the *contact number problem*. The Lean file defines `contactNumber d n`
as the `sSup` of achievable unit-distance-pair counts over 1-separated configurations
of `n` points in `EuclideanSpace ℝ (Fin d)` — exactly the max/min-dual reading of the
source — and formalizes the known partial results: $f_1(n) = n-1$, Harborth's exact
planar formula, and the general bounds $(d-o(1))n \le f_d(n) \le 2^{O(d)}n$. The
definitions and three of the four theorems are faithful. The fourth
(`erdos_problem_1084_general_lower`) encoded the lower bound's $o(1)$ as $d \to \infty$
uniformly in $n \ge 1$, which is **false** (already at $n = 1$: $f_d(1) = 0 < d -
\varepsilon$); the correct reading is $o(1)$ as $n \to \infty$ for each fixed $d$.
Fixed in place (not compile-verified).

## A. Semantic fidelity

**A1. Statement fidelity — pass after fix (source-verified).**

- The source defines $f_d(n)$ as *minimal such that every* 1-separated $n$-point set
  has *at most* $f_d(n)$ unit pairs — i.e. $f_d(n) = \max$ over packings of the number
  of unit pairs. `contactNumber` is the `sSup` of the set of achievable counts, whose
  elements are bounded by $\binom{n}{2}$; a nonempty bounded set of naturals has
  `sSup` = its greatest element, which is the maximum achievable count. The
  max-formulation in the file's docstring is the correct dualization of the page's
  min-formulation. Match.
- "Collection of $n$ points, all of distance at least 1 apart": encoded as
  `pts : Fin n → EuclideanSpace ℝ (Fin d)` with `IsPacking` (`i ≠ j → 1 ≤ dist`).
  `IsPacking` forces injectivity (coincident points would have distance $0 < 1$), so
  this is exactly $n$ distinct points, pairwise $\ge 1$ apart. Match.
- "Pairs of points which are distance 1 apart": `unitDistPairs` counts pairs
  `p.1 < p.2` with `dist = 1` — each unordered pair once, distance exactly 1. Match.
- The soft "Estimate $f_d(n)$" main question has no single formalizable core; the file
  (like the upstream artifact) formalizes the known partial results. Acceptable scope;
  noted, not a defect.
- Vacuity/degeneracy audit of `contactNumber`: for $d = 0$, $n \ge 2$ no packing
  exists, the defining set is empty and `sSup ∅ = 0` (junk, but no theorem depends on
  it after the fix — `general_upper` still holds there since $0 \le C^0 \cdot n$). For
  all $d \ge 1$ the set contains $0$ (spread points far apart) and is bounded, so the
  definition is well-behaved everywhere the theorems use it.

**A2. Lean semantics traps — one real trap caught (the defect), rest pass.**

- **ℕ subtraction:** `n - 1` in `dim1` is guarded by `hn : 1 ≤ n`; no truncation. (At
  $n = 0$ the statement would incidentally still hold — $f_1(0) = 0 = 0 - 1$ in ℕ —
  but the guard matches the intended reading.)
- **Coercions in Harborth's formula:** `Real.sqrt (12 * n - 3)` elaborates with
  expected type ℝ, so the subtraction is real, not ℕ-truncated (and even under ℕ
  reading, $12n - 3 \ge 21$ for $n \ge 2$ — harmless either way). The argument
  $3n - \sqrt{12n-3}$ is $\ge 6 - \sqrt{21} > 0$ for $n \ge 2$, so `Nat.floor`
  (`⌊·⌋₊`) agrees with the source's $\lfloor\cdot\rfloor$. Spot checks: $n=2$:
  $\lfloor 6-\sqrt{21}\rfloor = 1$ ✓; $n=3$: $\lfloor 9-\sqrt{33}\rfloor = 3$
  (triangle) ✓; $n=4$: $5$ (double triangle/rhombus) ✓.
- **Quantifier/filter encoding of $o(1)$ — DEFECT (fixed).** The page's
  $(d-o(1))n \le f_d(n)$ has its $o(1)$ as $n \to \infty$ for each fixed $d$ (the
  witness is a grid $[m]^d$, contact ratio $d(1-1/m)$ with $n = m^d$, needing
  $n \approx (d/\varepsilon)^d$ to reach $d - \varepsilon$). The file encoded
  `∀ ε > 0, ∃ d₀, ∀ d ≥ d₀, ∀ n ≥ 1, (d - ε)·n ≤ f_d(n)` — $o(1)$ as $d \to \infty$,
  *uniform in* $n \ge 1$. Counterexample: fix any $\varepsilon$, take $d \ge d_0$ with
  $d > \varepsilon$ and $n = 1$; then $f_d(1) = 0$ (no pairs exist) but
  $(d-\varepsilon)\cdot 1 > 0$. The statement is literally false; no choice of $d_0$
  repairs it, and even excluding small $n$ by a fixed $n_0$ fails since the needed
  threshold $(d/\varepsilon)^d$ grows with $d$. **Fixed** to
  `∀ d, ∀ ε > 0, ∃ n₀, ∀ n ≥ n₀, (d - ε)·n ≤ f_d(n)` (see Addendum; not
  compile-verified).
- **`general_upper` encoding of $2^{O(d)}$:** `∃ C > 0, ∀ d n, 1 ≤ n → f_d(n) ≤ C^d·n`
  with real `C` and monoid power `C ^ d` (no rpow needed). For $d \ge 1$,
  $\exists C: f \le C^d n$ is equivalent to $f \le 2^{O(d)}n$ (constants absorb into
  $C$); at $d = 0$ it demands $f_0(n) \le n$, true ($f_0(n) \in \{0\}$). The statement
  is true (per point, unit-distance neighbours in a packing form a kissing
  configuration of balls of radius $1/2$, so degree $\le$ kissing number
  $\le 2^{O(d)}$). Faithful.
- No `Finset.range`, no division, no `StrictMono`/interval issues arise.
