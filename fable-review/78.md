## Summary

The problem (verbatim from the recovered page): "Let $R(k)$ be the Ramsey number for
$K_k$, the minimal $n$ such that every $2$-colouring of the edges of $K_n$ contains a
monochromatic copy of $K_k$. Give a constructive proof that $R(k)>C^k$ for some
constant $C>1$." Status OPEN, $100 prize. The Lean file (`conjectures/78.lean:28-33`)
asserts: ∃ C > 1 such that for **all k ≥ 2** there is an n with C^k ≤ n and a graph on
`Fin n` that is `CliqueFree k` with `CliqueFree k` complement. The intended reading
(R(k) exceeds an exponential) is right, and the acknowledged inability to formalize
"constructive" is documented in the docstring. However, the k = 2 instance of the
formal statement is unsatisfiable: C > 1 forces the witness n ≥ 2, and no graph on
two or more vertices is simultaneously edgeless (`CliqueFree 2`) and complete
(`Gᶜ.CliqueFree 2`). So the theorem, read literally, is false — a Part A defect. The
fix (quantify over k ≥ 3) is a one-token change that preserves the problem's entire
asymptotic content.

## A. Semantic fidelity

**A1. Statement fidelity — FAIL: false at k = 2 [defect].**

- Independent back-translation of lines 28–32: "there is a real C > 1 such that for
  every k ≥ 2 there exist n ≥ C^k and a graph G on n vertices with no k-clique and no
  k-independent set." Since a graph on n vertices with no monochromatic K_k in either
  G or Gᶜ certifies R(k) > n, the statement encodes: ∃ C > 1, ∀ k ≥ 2, R(k) > some
  integer n ≥ C^k — i.e. R(k) ≥ ⌈C^k⌉ + 1. Modulo the k = 2 boundary (below) and the
  integer rounding, this is the source inequality R(k) > C^k, correctly *without* the
  constructivity requirement, which the docstring explicitly (and reasonably)
  relegates to the nature of the proof. Direction is correct: a lower bound on R(k).
- **The k = 2 instance is unsatisfiable.** Fix any C > 1. Then (C² : ℝ) ≤ n forces
  n ≥ 2 (n is a natural and C² > 1). In Mathlib, `G.CliqueFree 2` says G has no
  2-clique, i.e. no edge, i.e. G is edgeless; `Gᶜ.CliqueFree 2` says Gᶜ is edgeless,
  i.e. G is complete. For n ≥ 2 pick v ≠ w in `Fin n`: edgeless gives ¬G.Adj v w,
  complete gives G.Adj v w — contradiction. So no witness graph exists at k = 2, the
  inner ∀ fails, and `erdos_problem_78` is **false**. Note the informal statement
  survives at k = 2: R(2) = 2 > C² holds for any 1 < C < √2. It is precisely the
  integer-witness encoding (which demands R(2) > n for some integer n ≥ C² > 1, i.e.
  R(2) ≥ 3) that kills it. The smallest-diff repair is k ≥ 3: then C = 1.1 works —
  for 3 ≤ k ≤ 16, ⌈1.1^k⌉ ≤ 5 < 6 = R(3) ≤ R(k), and for k ≥ 17 the Erdős (1947)
  bound R(k) > 2^{k/2} dominates ⌈1.1^k⌉ since (2^{1/2}/1.1)^k grows. Asymptotic
  content is unchanged (the informal problem has no k-range at all; even informally
  "∀ k ≥ 1" would be false since R(1) = 1).
- Quantifier structure otherwise matches and matters: ∃ C sits **outside** ∀ k, so C
  is uniform in k, exactly as "for some constant C > 1" requires (a ∀ k ∃ C reading
  would be trivially true; the file avoids that trap — cf. the problem-55/36 classes).
- Types: C : ℝ with the ℕ-power C^k (`Monoid.npow`) and the cast `(↑n : ℝ)` put the
  inequality in ℝ; witness count n : ℕ and vertex type `Fin n` are appropriate.
- Not vacuous (after the fix): for k ≥ 3 the statement is a substantive exponential
  lower bound; it *is* classically provable (probabilistic method), which is the
  documented, deliberate encoding limitation for this "Give a constructive proof"
  problem — the OPEN status lives in the proof-method demand, not the proposition.
  The docstring says this in so many words, satisfying the problem-64-class
  requirement to document the encoding choice explicitly.

**A2. Lean semantics traps — pass (one boundary already covered by A1).**

## E. Prior-review audit (`deepmind/ai-review/78.md`)

The prior review is thorough on context and constructivity but wrong on the one thing
that matters most:

1. **Endorsed a false statement (§6).** It asserts "The constraint k ≥ 2:
   Appropriate… Requiring k ≥ 2 avoids these edge cases" and concludes "**Verdict:
   Correct.** The mathematical content is faithfully captured." As shown in A1, k = 2
   makes the theorem false for every C > 1. The review checked the degenerate cases
   k = 0, 1 and stopped one short — exactly the reviewed-boundary-minus-one failure
   mode this pipeline keeps finding (problem-25/33/56 classes: right neighbourhood,
   wrong boundary).
2. **Wrong Mathlib semantics claim (§6).** "any graph is `CliqueFree 0`" is
   backwards: the empty set is a 0-clique of every graph, so `CliqueFree 0` is False
   for **every** graph (even on an empty vertex type). Its companion claim about
   `CliqueFree 1` ("graph has no vertices") is correct. Same error class as the
   measure-semantics slip on 1002.
3. **Proposed an unsatisfiable variant (§3, adopted downstream).** Its
   `erdos_78_variant_sqrt` demands `∀ n, f n < n`, which is impossible at n = 0
   (no natural is < 0), and even granting n ≥ 1 it forces f 1 = 0 with
   `CliqueFree 0` False. The proposal is trivially false as written — and it was
   copied verbatim into the styled `deepmind/deepmind/78.lean` as a `research
   solved` theorem. The v2 file re-encodes the o(√n) variant soundly (f(n)² = o(n),
   no pointwise `f n < n` constraint).
4. **Its "more faithful" §5 sketch inherits the same falsity.** The suggested
   `erdos_78_constructive` keeps `k ≥ 2` with `C^k ≤ g k`, so g 2 ≥ 2 and the same
   K₂/co-K₂ contradiction applies.

   nontrivial Ramsey-type estimates (and the proposed `erdos_78_log` needs c large —
   small c > 0 makes `⌈c log n⌉₊ = 1` and the statement false at that c; the outer
