## Summary

The problem (verbatim from the recovered page): "Let $f(N)$ be the size of the largest
subset $A\subseteq \{1,\ldots,N\}$ such that every $n\in A+A$ is squarefree. Estimate
$f(N)$. In particular, is it true that $f(N)\leq N^{o(1)}$, or even
$f(N) \leq (\log N)^{O(1)}$?" — status **OPEN**, first studied by Erdős–Sárközy
[ErSa87] ($\log N \ll f(N) \ll N^{3/4}\log N$, lower bound guessed nearer the truth),
improved by Konyagin [Ko04] to $\log\log N(\log N)^2 \ll f(N) \ll N^{11/15+o(1)}$. The
Lean theorem (`conjectures/1109.lean:21–28`) asserts: there exist $C > 0$, $k > 0$, and
$N_0$ such that for all $N \ge N_0$, every $A \subseteq \{1,\dots,N\}$ (as a
`Finset ℕ` with `1 ≤ a ∧ a ≤ N`) whose pointwise sumset $A+A$ is entirely squarefree
has $|A| \le C(\log N)^k$. Read back independently, this is exactly the affirmative
direction of the *stronger* question, correctly encoded; but the *weaker* $N^{o(1)}$
question — genuinely distinct, since the two tiers can have different answers — is
absent from both the code and the docstring, which misstates the problem as only the
polylog question. That omission is the review's one defect; everything else is
scholarship-level enrichment.

## A. Semantic fidelity

**A1. Statement fidelity — the formalized tier passes (source-verified); one tier of
the question is missing (deferred to B2/refinements as the [defect]).**

- Independent back-translation of lines 21–28: "there are constants $C > 0$ (real) and
  $k > 0$ (natural) and a threshold $N_0$ such that for every $N \ge N_0$ and every
  finite set $A$ of naturals contained in $[1, N]$, if every element of $A + A$ is
  squarefree then $|A| \le C \cdot (\log N)^k$." Since
  $f(N) = \max\{|A| : A \subseteq \{1,\dots,N\},\ A+A \text{ squarefree}\}$, bounding
  every admissible $A$ is exactly bounding $f(N)$, and
  "$\exists C, k$, eventually $f(N) \le C(\log N)^k$" is precisely
  "$f(N) \le (\log N)^{O(1)}$". Faithful for the stronger tier.
- `∀ a ∈ A, 1 ≤ a ∧ a ≤ N` correctly encodes $A \subseteq \{1, \ldots, N\}$ (in
  particular excluding $0$, as the source's index set does).
- `A + A` under `open Pointwise` is `{a + b | a ∈ A, b ∈ A}` including the diagonal
  $a + a$ (`Finset.mem_add`), the standard sumset and exactly the page's $A+A$.
- $k$ restricted to positive naturals loses no generality against a real exponent
  $K$: for $\log N \ge 1$ (i.e. $N \ge 3$), $(\log N)^{\lceil K\rceil} \ge (\log N)^K$,
  and the $\exists N_0$ absorbs the threshold. Similarly $C > 0$ is WLOG ($C \le 0$
  makes the bound unsatisfiable for $A = \{1\}$). Equivalent to the informal statement.
- The `∃ N₀` ("sufficiently large") is not decoration — it is **necessary**: at $N = 1$
  the admissible $A = \{1\}$ (with $A + A = \{2\}$, squarefree) has
  $|A| = 1 > C(\log 1)^k = 0$ for every $C, k$, so the unrestricted-$N$ statement is
  false. Matches the asymptotic reading of $(\log N)^{O(1)}$.
- Not vacuous, not trivially false: the hypotheses are satisfiable at every $N \ge 1$
  ($A = \{1\}$), no fixed $(C, k)$ trivializes an unbounded-$N$ claim, and the assertion
  is the genuinely open conjecture. Empty $A$ is harmless: $0 \le C(\log N)^k$ holds
  since $\log$ of a ℕ-cast is never negative (see A2).
- **[defect — the B2 missing part]** The source poses a graded pair of questions, and
  they are genuinely different: e.g. $f(N) = \exp(\sqrt{\log N})$ would answer the
  $N^{o(1)}$ question "yes" and the $(\log N)^{O(1)}$ question "no". The input encodes
  only the stronger tier, and its docstring (line 10) restates the problem as "Is it
  true that $f(N) \leq (\log N)^{O(1)}$?" — silently dropping "Estimate $f(N)$" and the
  entire $N^{o(1)}$ sub-question. A docstring that misstates the scope of the source
  problem over a correct theorem is still a defect. Fixed in v2 (new theorem
  `erdos_problem_1109_subpolynomial` + restored module docstring).

## E. Prior-review audit (`deepmind/ai-review/1109.md`)

The prior review was written against the styled copy (`deepmind/deepmind/1109.lean`,
which used `answer(sorry) ↔` and carried full-looking bib entries), not the raw file
under review here. Its mathematics is largely sound; findings:

1. **Correct suspicion, now confirmed (its best call).** §2 flagged that the styled
   file's [ErSa87] title "On the number of pairs of integers with least common
   multiple not exceeding $x$" "does not match the topic of squarefree sumsets" and
   was "likely incorrect". The recovered `/latex/1109` extraction confirms it: the
   real title is *On divisibility properties of integers of the form $a+a'$* (Acta

   input under review here never carried the bogus title (it has no full entries at
   all), so this is not a defect of `conjectures/1109.lean`.
2. **Wrong claim about Mathlib semantics (minor, recurring class).** §6 says: "When
   `N = 0` or `N = 1`, `Real.log N ≤ 0`, so `(Real.log N) ^ k` could be 0 **or
   negative (for odd k)**." The negativity claim is false: `N` is a ℕ-cast, so
   `(N : ℝ) ≥ 0`, and `Real.log` is `0` at `0` and `1` and positive for `N ≥ 2` — it
   is *never* negative on ℕ-casts, for any parity of `k`. The conclusion (the

   *fails outright* at `N = 1` (`f(1) = 1 > 0`), which the prior review never
   exhibits — the same invent-then-excuse pattern flagged in the 1000/1005 audits,
   here in a mild form (its excuse was aimed at a non-existent negativity issue while
   the actual small-`N` failure went unmentioned).

   "avoiding the edge case where `Squarefree 0` is false". Mis-aimed: if `0 ∈ A` then
   `0 = 0 + 0 ∈ A + A` and the squarefree hypothesis *itself* excludes such `A` — no
   edge case arises with or without the conjunct. The conjunct's real job is fidelity
   to the source's $\{1, \ldots, N\}$. Conclusion (encoding correct) stands.
