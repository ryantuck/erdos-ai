## Summary

The problem: let $h_3(k)$ be the minimal $n$ such that there exists a triangle-free graph
on $n$ vertices with chromatic number $k$. Find an asymptotic for $h_3(k)$, and also
**prove** $\lim_{k\to\infty} h_3(k+1)/h_3(k) = 1$. Status on the source page: OPEN. The
Lean file defines `h3 k` as `sInf {n | ∃ G : SimpleGraph (Fin n), G.CliqueFree 3 ∧
G.chromaticNumber = (k : ℕ∞)}` and states the limit as an ε–$K_0$ proposition
(`deepmind/1013.lean:84–88`), a direct assertion with no `answer()` wrapper — correct for
a "prove that" problem, with correct open status. Read back independently, the Lean and
the source's second (formalizable) part agree exactly. The defect is not in the Lean but
in the theorem docstring: a note claiming the limit "would follow from the known
asymptotic bounds $(1/2-o(1))k^2\log k \le h_3(k) \le (1+o(1))k^2\log k$" — false (bounds
with a constant-factor gap cannot force the ratio to 1; if they could, the problem would
not be open). The note was added by the fix session following the prior ai-review's
unsound §3 claim.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $h_3(k)$ be the minimal $n$
  such that there exists a triangle-free graph on $n$ vertices with chromatic number $k$.
  Find an asymptotic for $h_3(k)$, and also prove
  $\lim_{k\to \infty}\frac{h_3(k+1)}{h_3(k)}=1$."
- `h3` (line 64–65): "least $n$ such that some triangle-free graph on $n$ vertices has
  chromatic number exactly $k$" — term-for-term the source's definition. `CliqueFree 3`
  is triangle-free; `SimpleGraph (Fin n)` is a graph on exactly $n$ vertices;
  `chromaticNumber = (k : ℕ∞)` demands the chromatic number *exactly* $k$, as the source
  requires.
- Independent back-translation of the theorem (lines 84–88): "for every real
  $\varepsilon > 0$ there is $K_0$ such that for all $k \ge K_0$,
  $|h_3(k+1)/h_3(k) - 1| \le \varepsilon$" — precisely $h_3(k+1)/h_3(k) \to 1$. The
  ε-formulation with `≤ ε` is equivalent to the `< ε` and `Tendsto` forms.
- Two-part problem: the "Find an asymptotic" part is an open-ended estimate request with
  no conjectured formula stated on the page; the "prove the limit" part is the
  formalizable core and is what is formalized. The omission of part 1 is now documented
  in the module docstring, and the known partial results toward it are added as variants
  (see B2). Pre-fix, the module docstring had silently dropped part 1 (restyling drift —
  see below).
- Not vacuous or trivial: $h_3$ is strictly increasing for $k \ge 1$ (from a
  vertex-critical $(k+1)$-chromatic triangle-free graph, deleting a vertex gives
  chromatic number $k$ on fewer vertices), so the ratio is $> 1$ and the claim that it
  tends to 1 is a substantive open statement.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no `Finset.range`, no vacuous bounded quantifiers.
- Division: real-field division. `h3 k = 0` only at $k = 0$ (see A3), where Lean gives
  `(h3 1 : ℝ) / 0 = 0` and `|0 - 1| = 1`, so for $\varepsilon < 1$ any witness needs
  $K_0 \ge 1$ — harmless, since the existential supplies $K_0$; for $k \ge 1$,
  `h3 k ≥ 1` (Mycielski graphs witness nonemptiness, and any graph with chromatic
  number $k \ge 1$ has $\ge 1$ vertex), so no degenerate division occurs in the tail.
- `sInf` on ℕ: the defining set is nonempty for **every** $k$ — for $k = 0$ the set is
  exactly $\{0\}$ (the empty graph on `Fin 0` is vacuously `CliqueFree 3` and has
  `chromaticNumber = 0`; any graph on $n \ge 1$ vertices needs $\ge 1$ color), and for
  $k \ge 1$ Mycielski's construction provides members. The `sInf ∅ = 0` junk-value
  convention is never exercised (contrary to the prior review's account — see E).
- `chromaticNumber : ℕ∞`: on `Fin n` the chromatic number is finite ($\le n$), so
  equality with the coercion `(k : ℕ∞)` is a sound encoding with no `⊤` corner case.
- Encoding of the limit: ε–$K_0$ over ℝ, equivalent to `Tendsto _ atTop (nhds 1)`;
  correct. No `StrictMono`/`Monotone` or interval-endpoint issues arise.

**A3. Definitions — pass.**

- `h3` matches its own docstring and the source, including degenerate input
  ($h_3(0) = 0$ via genuine membership of $n = 0$, a reasonable convention invisible to
  the limit). No `sorry` in any `def`. The definition is used consistently by the
  theorem and the added variants.

**A4. Question form and answer polarity — pass.**

- The formalized part of the source is a **direct assertion** ("…and also **prove**

- Nit (fixed): the pre-fix *module* docstring rephrased the problem as a yes/no question
  ("Is it true that the ratio … tends to 1?"), mismatching both the source's imperative
  phrasing and the theorem's assertion form. Restored to the source-verbatim statement.
- No binders before the colon (line 84 is binder-free); all quantifiers live in the
  theorem type.

**B2. Variants and completeness — one gap documented, enrichment applied, one
page-constant discrepancy found.**

- Part 1 of the problem ("Find an asymptotic for $h_3(k)$") is not directly formalizable
  as stated (open-ended value request, no conjectured formula on the page); the omission
  is now explicitly documented in the module docstring rather than silent.
- Page-confirmed partial results added as variants (Addendum fix 4): Graver–Yackel
  $h_3(k) \gg \frac{\log k}{\log\log k}k^2$ (solved, [GrYa68]); the lower bound
  $(1/2-o(1))k^2\log k \le h_3(k)$ (solved — follows from the $f(n)$ upper bound of
  Davies–Illingworth stated at #1104); the upper bound $h_3(k) \le (2+o(1))k^2\log k$
  (solved — see next bullet for the constant).
- **Page-constant discrepancy.** The 1013 page claims the #1104 bounds
  $(1-o(1))(n/\log n)^{1/2} \le f(n) \le (2+o(1))(n/\log n)^{1/2}$ (cross-verified
  against the recovered 1104 page HTML, same edition date) imply
  $h_3(k) \le (1+o(1))k^2\log k$. Re-deriving the inversion: $f(n) \ge k$ implies
  $h_3(k) \le n$ (delete vertices to make the chromatic number exactly $k$; the
  subgraph has $\le n$ vertices); setting $k = (1-o(1))(n/\log n)^{1/2}$ gives
  $n = (1+o(1))k^2 \log n = (2+o(1))k^2\log k$ since $\log n = (2+o(1))\log k$ — i.e.
  the stated $f$-bounds yield only $(2+o(1))k^2\log k$. (The lower bound checks out:
  $k \le (2+o(1))(n/\log n)^{1/2}$ at $n = h_3(k)$ gives
  $n \ge (1/4-o(1))k^2\log n = (1/2-o(1))k^2\log k$.) Whether a stronger direct
  construction justifies the page's $(1+o(1))$ cannot be verified offline; following the
  1004/EPS87 precedent, the **safe corrected form** $(2+o(1))$ is formalized, with the
  derivation and the page's stronger claim documented in the variant's docstring.
  DEFERRED: resolving the true best-known constant.
- The duality $h_3(k) = n \iff n$ minimal with $f(n) = k$ is quoted in the module
  docstring; formalizing it would require #1104's `f` (not present in `deepmind/`) —
  optional upstream enrichment, skipped.

## E. Prior-review audit (`ai-review/1013.md`)

Accurate on the Lean encoding itself, but three substantive findings:

1. **False implication, subsequently baked into the artifact (major).** §3 claims "The
   known bounds $(1/2-o(1))k^2\log k \le h_3(k) \le (1+o(1))k^2\log k$ would immediately
   imply the ratio result." This is false: the bounds leave a factor-2 gap, giving only
   $\limsup h_3(k+1)/h_3(k) \le 2+o(1)$ — the ratio limit is exactly the part *not*
   captured by constant-factor bounds, which is why the problem is open. §4 repeats the
   claim with a hedge ("if the bounds … are tight enough"). The fix session then
   implemented §4's recommendation by adding the false note verbatim to the theorem
   docstring (recovered Edit in
   `claude-session-logs-formal-conjectures/f7c0b4ee-795f-4c03-9afa-c09313b61d41.jsonl`,
   log line 24) — a case of a prior review's unsound asymptotic argument *creating* a
   defect downstream. Same failure class as the 1000 and 1005 audits (invented/unsound
   asymptotic reasoning that happens to sound plausible).
2. **Wrong claim about the formalization's degenerate-case mechanism (minor).** §5
   asserts the defining set "could potentially be empty" and that "for $k = 0$,
   `h3 0 = 0` (via `sInf ∅ = 0`)". In fact the set is nonempty for *every* $k$: at
   $k = 0$ it equals $\{0\}$, since the empty graph on `Fin 0` is vacuously
   `CliqueFree 3` with `chromaticNumber = 0` in Mathlib, while any graph on $n \ge 1$
   vertices has chromatic number $\ge 1$. So `h3 0 = 0` by genuine membership; the
   `sInf ∅` convention is never exercised. Right conclusion, wrong Mathlib-semantics
   justification — same class as the 1002 audit finding.
3. **Unverified page constant propagated.** §2 repeats the page's
   $(1+o(1))k^2\log k$ upper bound without checking it against the #1104 $f$-bounds
   quoted in the same breath; the inversion yields $(2+o(1))k^2\log k$ (see B2).

What it got right (re-derived): the division-by-zero analysis at $k = 0$
($|0/0 - 1| = 1$, handled by choosing $K_0 \ge 1$) is correct; the `≤ ε`/`< ε`
equivalence is correct; the duality $h_3(k) = \min\{n \mid f(n) \ge k\}$ is correct
(vertex deletion decreases the chromatic number by at most 1, and isolated-vertex
padding preserves triangle-freeness and chromatic number); the reuse survey matches the
`conjectures/` files it names; the `Tendsto` alternative it sketches is equivalent. Its
actionable recommendations (cross-references to #920/#1104, OEIS line, context note)
were all applied by the fix session — but the context note in a false form, and the
"variant stating the asymptotic formula question" recommendation was never acted on
(now addressed via the three bound variants plus an explicit docstring note on why
part 1 admits no direct formalization).
