## Summary

The problem (OPEN on the source page): let G be a random graph on n vertices with
each edge included independently with probability 1/2 (i.e. G(n,1/2), the uniform
distribution over all labelled graphs on n vertices). Part 1: is there a constant C
such that χ(G) is almost surely concentrated on at most C values? Part 2: is it true
that if ω(n) → ∞ sufficiently slowly, then for *every* function f(n),
P(|χ(G) − f(n)| < ω(n)) < 1/2 for all sufficiently large n? The Lean file declares a
probability primitive `chromaticNumberProb n P` ("P(χ(G(n,1/2)) satisfies P)") and
asserts the two parts as separate theorems: ∃ C, ∀ ε > 0, eventually ∃ S with
|S| ≤ C and P(χ ∈ S) ≥ 1 − ε; and ∃ ω → ∞ such that ∀ f, eventually
P(|χ − f(n)| < ω(n)) < 1/2. Read back independently, both statements are faithful
renderings of the two questions' "yes" directions (the corpus convention for open
yes/no questions), including the exact universal-over-f quantifier the page states in
Part 2. The defect is beneath the statements: the primitive is `def … := sorry`, a
data-level `sorry` riding on `sorryAx`, so the file pins down no semantics at all —
and unlike sibling 1155's process, G(n,1/2) *is* cheaply definable concretely, so v2
defines it.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified), modulo the A3 defect.**

- Recovered verbatim source statement (see Addendum): "Let $G$ be a random graph on
  $n$ vertices, in which every edge is included independently with probability $1/2$.
  / Is there some constant $C$ such that that [sic] chromatic number $\chi(G)$ is,
  almost surely, concentrated on at most $C$ values? / Is it true that, if
  $\omega(n)\to \infty$ sufficiently slowly, then for every function $f(n)$
  $\mathbb{P}(\lvert\chi(G)-f(n)\rvert<\omega(n))<1/2$ if $n$ is sufficiently large?"
  The module docstring reproduces both questions faithfully (modulo the site's "that
  that" typo, silently corrected — harmless).
- Independent back-translation of `erdos_problem_1156_concentration` (lines 48–53):
  "there is C : ℕ such that for every ε > 0, for all sufficiently large n, some
  finite set S of naturals with |S| ≤ C has P(χ ∈ S) ≥ 1 − ε." The informal "almost
  surely concentrated on at most C values" means: sets S_n of ≤ C values exist with
  P(χ ∈ S_n) → 1. The two are equivalent: writing g(n) for the maximum of
  P(χ ∈ S) over sets S of at most C values — a maximum over finitely many relevant
  choices, since only membership of the attainable values 0…n matters, so it is
  achieved by some S_n — the Lean statement says g(n) → 1 in ε-form, and the informal
  one says P(χ ∈ S_n) = g(n) → 1 for the maximizing S_n. Letting S depend on ε as
  well as n (it sits under both quantifiers) therefore adds no strength and loses
  none. C is correctly pinned outside all other quantifiers: one constant, uniform in
  ε and n. Term-by-term faithful.
- Independent back-translation of `erdos_problem_1156_anticoncentration` (lines
  64–68): "there is ω : ℕ → ℝ with ω(n) → ∞ such that for every f : ℕ → ℝ, for all
  sufficiently large n, P(|χ − f(n)| < ω(n)) < 1/2." The source's "if ω(n) → ∞
  sufficiently slowly, then P(ω)" idiom means: some growth threshold exists below
  which every ω → ∞ works. The ∃ω encoding is equivalent: the event
  |χ − f(n)| < ω(n) is monotone in ω (shrinks as ω decreases), so any ω' → ∞ growing
  more slowly than a witnessing ω₀ is eventually ≤ ω₀ and inherits the property;
  conversely a "sufficiently slow" threshold yields a witness. The universal
  quantifier over f, the strict `<` on both the window and the 1/2 bound, and the
  per-f threshold on n (`∀ f, ∀ᶠ n`) all match the page exactly.
- Indexing: no sequence indexing arises; the vertex count n is the only index and is
  used uniformly. No off-by-one exposure.
- Non-vacuity, mathematical: Part 1 does not follow from, and is not refuted by, the
  known results ([HeRi23] concerns *interval* concentration; a set of ≤ C values
  need not lie in one short interval — noted in the v2 module docstring since a
  careless reader might think the parts conflict). Part 2 is the anticoncentration
  direction consistent with [He21]/[HeRi23] but not implied by them (they are
  conditional i.o. statements). Both are substantive open questions. Non-vacuity,
  formal: with the input's `sorry` def the *formal* propositions are contingent on
  an arbitrary unspecified function — see A3; with the v2 concrete definition they
  are genuine statements about G(n,1/2).

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere: `1 - ε` and `(k : ℝ) - f n` are ℝ subtraction; `k` is
  cast before subtracting. Correct.
- Division: `1 / 2` is exact ℝ division. (In v2 the new definition divides by
  `Nat.card (SimpleGraph (Fin n))` = 2^(n choose 2) ≥ 1, never zero, including
  n = 0.)
- No `Finset.range`; `∀ᶠ n in atTop` carries no off-by-one exposure.
- No vacuous bounded quantifiers. Degenerate witnesses: in Part 1, S = ∅ gives
  probability 0 < 1 − ε, so it cannot cheat; C = 0 forces S = ∅, so a proof must
  pick C ≥ 1. In Part 2, ω must tend to ∞, so no degenerate ω (e.g. constant or
  negative) can trivialize the claim.
- Filter encodings: `∀ᶠ n in atTop` is the standard, correct encoding of "for all
  sufficiently large n"; `Tendsto ω atTop atTop` correctly encodes ω(n) → ∞. The
  "almost surely" of Part 1 is correctly rendered in ε-form (probability → 1), the
  standard w.h.p. meaning for a sequence of finite probability spaces.
- Strict vs non-strict: `≥ 1 - ε` (non-strict) for the concentration bound and
  strict `< ω n`, `< 1 / 2` for Part 2 — the page displays exactly these (the ≥ in
  Part 1 is the docstring's own ε-form gloss of "almost surely"; either strictness
  is equivalent there under ∀ε). No `StrictMono`/`Monotone` issues arise.

**A3. Definitions — DEFECT.**

- `noncomputable def chromaticNumberProb (n : ℕ) (P : ℕ → Prop) : ℝ := sorry`
  (line 39) is a `sorry` inside a `def` — this corpus's `sorry-in-definition` defect
  class (cf. fable-review/1123, 1137, 1155). A data-level `sorry` elaborates via
  `sorryAx : ∀ α, Bool → α`, an unsound placeholder axiom inhabiting every type, so
  both theorems inherit dependence on it; the originating session's build log shows
  the warning at 39:18. Beneath the mechanics, the file pins down no semantics: no
  axiom ties the constant to any probability space, so the theorems are
  specifications, not statements about random graphs. **[defect]**
- Unlike sibling 1155 (a sequential random process, where v2 demoted the constants
  to honest `opaque`), G(n,1/2) has a three-line concrete definition: since
  p = 1/2, it is exactly the uniform distribution over all 2^(n choose 2) labelled
  simple graphs on n vertices, so `chromaticNumberProb n P` is the fraction of
  graphs on `Fin n` whose chromatic number satisfies P. **Fix applied (v2):**

  ```lean
  noncomputable def chromaticNumberProb (n : ℕ) (P : ℕ → Prop) : ℝ :=
    (Nat.card {G : SimpleGraph (Fin n) // P G.chromaticNumber.toNat} : ℝ) /
      (Nat.card (SimpleGraph (Fin n)) : ℝ)
  ```

  Design notes: (a) Mathlib's `SimpleGraph.chromaticNumber` is ℕ∞-valued (the prior
  review's proposed snippet overlooked this — see Part E); for a graph on `Fin n` it
  is at most n, never ⊤, so `.toNat` is faithful. (b) `Nat.card` needs no
  `Fintype`/decidability instances, and its value on the (mathematically finite)
  types involved is the true count regardless of instance availability — so the
  definition's meaning is unconditional, and the denominator 2^(n choose 2) ≥ 1
  makes the division safe for every n. (c) One new import,
  `Mathlib.SetTheory.Cardinal.Finite` (for `Nat.card`), follows compiled siblings
  1042/1106. **Not compile-verified** — flagged in the docstrings.
- The def's docstring matches the source's model description ("equivalently the
  uniform distribution over all simple graphs on n labelled vertices") — the input's
  docstring already said this; v2's definition makes it true rather than aspirational.
- No other defs exist; the theorems use the primitive consistently (P instantiated
  at `(· ∈ S)` and at the window predicate), with no drift between the def's meaning
  and the theorems' use.

**A4. Question form and answer polarity — pass (corpus convention).**
