## Summary

The problem (erdosproblems.com/7, OPEN, banner "VERIFIABLE — open, but could be proved
with a finite example", $25 shown): *"Is there a distinct covering system all of whose
moduli are odd?"* Asked by Erdős and Selfridge (sometimes with Schinzel); Erdős believed
yes ($25 for a disproof), Selfridge believed no ($300, later $2000, for an explicit
example) [FFK00]. The Lean file (`conjectures/7.lean:40-45`) asserts
`∃ S : Finset (ℤ × ℕ), IsCoveringSystem S ∧ HasDistinctModuli S ∧ ∀ p ∈ S, Odd p.2`,
where `IsCoveringSystem` requires nonemptiness, *positive* moduli, and covering. Read
literally this is **trivially true**: `S = {(0, 1)}` is nonempty, `0 < 1`, `1 ∣ (n − 0)`
for every `n : ℤ`, distinctness is vacuous on a singleton, and `Odd 1` holds. Erdős's
notion of covering system — his standard usage `1 < m₁ < m₂ < ⋯ < mₖ` [ErGr80], the
convention under which the page's own Hough–Nielsen remark is a theorem — requires the
moduli to exceed one. The file encodes distinctness correctly (`HasDistinctModuli`, the
predicate this cluster's problem-2 review borrowed) but drops the `1 < m` half of the
convention, converting the open question into a one-line exercise. This is the mirror
image of the problem-2 defect: there, omitted *distinctness* made a true statement
false; here, omitted *modulus > 1* makes an open question trivially true.

## A. Semantic fidelity

**A1. Statement fidelity — DEFECT.**

- Recovered verbatim source statement (`tidy/7.html:13`): "Is there a distinct covering
  system all of whose moduli are odd?" Status banner VERIFIABLE ("Open, but could be
  proved with a finite example."), $25.
- Independent back-translation of `conjectures/7.lean:40-45`: "there exists a nonempty
  finite set S of pairs (a, m) ∈ ℤ × ℕ with all m > 0, covering ℤ (every n satisfies
  m ∣ n − a for some (a, m) ∈ S), with no two pairs sharing a modulus, and all moduli
  odd."
- **The Lean proposition is trivially true as written.** Witness `S = {((0 : ℤ), (1 :
  ℕ))}`: `S.Nonempty` ✓; `0 < 1` ✓; for every `n : ℤ`, `(1 : ℤ) ∣ (n − 0)` ✓;
  `HasDistinctModuli` is trivial on a singleton ✓; `Odd 1` ✓ (`1 = 2·0 + 1`). So the
  "open question" as formalized is a decidable-in-one-step theorem — precisely the A1
  degenerate-witness failure mode ("a degenerate witness … satisfying the formal
  statement while violating the problem's intent").
- The root cause is a missing hypothesis: "covering system" in Erdős's usage means
  congruences with distinct moduli **all greater than one** (`1 < m₁ < ⋯ < mₖ`,
  [ErGr80]). Three corroborations, none needing outside literature: (i) the page's own
  remark "Hough and Nielsen [HoNi19] proved that at least one modulus must be divisible
  by either 2 or 3" is *false* under the file's definitions (`{(0, 1)}` has no such
  modulus), so the page must be using the `m > 1` convention; (ii) the file's docstring
  repeats that HoNi19 claim over its own definitions — an internal inconsistency
  (docstring-stated theorem falsified by the definitions it sits above); (iii) the
  problem-2 review in this batch established from the recovered [ErGr80]-citing upstream
  sources that Erdős's covering-system convention is the restrictive one, and explicitly
  noted that modulus 1 was "harmless" for problem 2's bounded-modulus direction — here
  it is fatal, because the statement is an existential that modulus 1 satisfies.
- Distinctness, by contrast, is handled correctly: `HasDistinctModuli` (lines 17-18)
  demands that equal moduli force equal pairs, i.e. the modulus map is injective on `S`
  — exactly "pairwise distinct moduli". (Verified independently of the problem-2
  review's reliance on this file: without it, `{(0,3),(1,3),(2,3)}` would be an "odd
  covering system", trivializing the question a second way.)
- With `(∀ p ∈ S, 1 < p.2)` added, the statement is exactly the open question. **Fixed
  in `conjectures-v2/7.lean`** (not compile-verified).
- Not-vacuous check of the fixed statement: with moduli odd, distinct, and > 1, no
  known witness exists and BBMST22 rules out the squarefree subcase — this is the
  genuine open problem; the smallest admissible modulus is 3.

**A2. Lean semantics traps — pass (no issues beyond A1).**

- No ℕ subtraction: `n - p.1` is ℤ subtraction (`p.1 : ℤ`); the modulus is cast
  `(p.2 : ℤ)` before use. Correct.
- No division anywhere; `(p.2 : ℤ) ∣ (n - p.1)` with `p.2 > 0` is the standard exact
  encoding of `n ≡ a (mod m)`. Modulus 0 is excluded by `0 < p.2` (and `(0 : ℤ) ∣ x`
  would anyway mean `x = 0`, never satisfiable for all `n`).
- No `Finset.range`, no index arithmetic, no off-by-one surface.
- No vacuous quantifiers: `S.Nonempty` is explicit (and in fact implied by the covering
  clause since ℤ is inhabited — harmless redundancy, see C1).
- `Odd p.2` on ℕ is the correct parity notion (`∃ m, p.2 = 2m + 1`); no
  `StrictMono`/interval issues arise.

**A3. Definitions — pass relative to their own docstrings; the defect is at the
statement/convention layer.**

- `IsCoveringSystem` (lines 9-12) matches its own docstring ("every modulus is positive
  and every integer satisfies at least one congruence"), including degenerate inputs
  (empty set excluded by `S.Nonempty`; modulus 0 by positivity). `HasDistinctModuli`
  (lines 17-18) matches its docstring exactly. No `sorry` in any definition.
- However, the pair (definitions + theorem) jointly diverges from the source's term
  "distinct covering system" by omitting `m > 1` — the A1 defect. The fix adds the
  condition as a theorem hypothesis rather than editing `IsCoveringSystem`, keeping the
  smallest diff and cross-file consistency with `conjectures-v2/2.lean`, which shares
  the predicate verbatim (there, adding `1 < m` to the shared def would be wrong: the
  problem-2 statement legitimately tolerates modulus 1, and its Owens variant would be
  unaffected but the def would drift from problem 2's reviewed form).

**A4. Question form and answer polarity — acceptable form per pipeline rule; noted.**

- The source is a **yes/no question**, OPEN. The file states the existence ("yes")
  direction as a direct assertion, without an `answer()` wrapper. In this raw pipeline
  (plain Mathlib imports, no `answer()` elaborator available) direct assertion of the
  conjectured, unrefuted direction is the corpus norm (cf. `fable-review/3.md` §A4,
  accepted there for the same OPEN-question situation). Here the asserted existential
