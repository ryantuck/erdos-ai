## Summary

The problem (verbatim from the recovered page): "If $G$ is a graph on $n$ vertices which
contains no trivial (empty or complete) subgraph on $\geq 10\log n$ many vertices, then
must $G$ contain an induced non-trivial regular subgraph on $\gg \log n$ many
vertices?" — a **yes/no question** of Erdős, Fajtlowicz, and Staton, status **PROVED**
(affirmatively, by Prömel and Rödl [PrRo99] in the strong universality form). The Lean
statement (`deepmind/1031.lean`) encodes the hypotheses as
`G.CliqueFree ⌈10 * Real.log n⌉₊` and `Gᶜ.CliqueFree ⌈10 * Real.log n⌉₊` and the
conclusion as the existence of `S : Finset (Fin n)` with `|S| ≥ c log n` on which the
induced subgraph is `d`-regular with `1 ≤ d ≤ |S| − 2`, with the absolute constant `c`
and threshold `N₀` existentially quantified up front. The mathematical content is a
faithful, in fact term-by-term exact, rendering. The single semantic defect is form: the
source asks a question, so per checklist A4 and the corpus's uniform convention the
statement must be `answer(True) ↔ P`; it was instead a bare direct assertion. Fixed in
place (line 71), together with docstring enrichment and two page-confirmed variants.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of the (pre-fix) theorem: "there exist an absolute
  constant $c > 0$ and a threshold $N_0$ such that for all $n \ge N_0$ and every graph
  $G$ on $n$ vertices, if $G$ has no clique of size $\lceil 10\ln n\rceil$ and no
  independent set of size $\lceil 10\ln n\rceil$, then some vertex set $S$ with
  $|S| \ge c\ln n$ induces a $d$-regular graph with $1 \le d \le |S|-2$." This is
  exactly the content of the question asked (modulo the question-form defect, A4).
- Hypothesis threshold is **exactly** equivalent, not "slightly weaker" (contrast the
  generating session's private hesitation, Part E): "no trivial subgraph on
  $\ge 10\log n$ vertices" ⟺ $\omega(G) < 10\log n$ ⟺ (integer clique sizes)
  $\omega(G) \le \lceil 10\log n\rceil - 1$ when $10\log n \notin \mathbb{Z}$, and
  $\omega(G) \le 10\log n - 1$ when $10\log n \in \mathbb{Z}$ — in both cases precisely
  `CliqueFree ⌈10 log n⌉₊`. Same for $G^c$ vs independent sets.
- "Trivial subgraph" in the hypothesis must be read as *induced* (a non-induced "empty
  subgraph" of any size exists in every graph, which would make the hypothesis
  unsatisfiable and the problem vacuous); the clique/independent-set reading is the
  standard and the only sensible one, and matches the raw pass's gloss.
- Quantifier order: `∃ c, ∃ N₀, ∀ n, ∀ G` — the constant is absolute (uniform in $n$
  and $G$), which is what Erdős's $\gg$ means. Correct.
- Non-triviality: `d ≥ 1` excludes the empty induced graph, `d + 1 < S.card` (i.e.
  $d \le |S|-2$ over ℕ) excludes the complete one; a regular graph is empty iff $d=0$
  and complete iff $d=|S|-1$, so "neither empty nor complete" ⟺ $1 \le d \le |S|-2$
  exactly. (This implicitly forces $|S| \ge 3$, harmless at size $\ge c\log n$.)
- Not vacuous: for large $n$ the hypothesis class is non-empty (a uniform random graph
  has clique and independence number $\sim 2\log_2 n \approx 2.885\ln n < 10\ln n$
  a.a.s.), and the conclusion is a genuine structural claim. For $n \le 3$ the
  hypothesis is unsatisfiable (`CliqueFree 0/1/2` on both $G$ and $G^c$ fails or forces
  a contradiction), but those $n$ sit below any effective $N_0$; no silent alteration.
- Log base: the site writes $\log$; the file uses `Real.log` (natural log). Since the
  existential $c$ absorbs any base change and the constant 10 is generous in any base,
  this is a standard, harmless choice (and sibling 1036 from the same paper does the
  same).

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere (`d + 1 < S.card` deliberately avoids `S.card - 1`). No
  division anywhere.
- `⌈·⌉₊` (`Nat.ceil`) of `10 * Real.log n`: at `n = 0, 1` the argument is `0` (Lean's
  `Real.log 0 = 0`) giving `CliqueFree 0`, which is false for every graph — the
  implication is then vacuously true for those `n`, subsumed under `N₀`. No trap fires.
- `Finset.range` does not occur; the only cardinality comparison is the cast
  `(S.card : ℝ) ≥ c * Real.log n`, with arithmetic done in ℝ after the cast — correct
  placement.
- No vacuous bounded quantifier: `∀ v ∈ S, …` with the *same* `d` witnessing all
  vertices; if `S = ∅` the regularity clause is vacuous but `d + 1 < 0` is
  unsatisfiable, so the empty set can never be a degenerate witness. Good.
- "For all sufficiently large $n$" is encoded by explicit `∃ N₀, ∀ n ≥ N₀` — correct
  (no filter needed).
- `∀ _ : DecidableRel G.Adj` is the standard idiom letting `S.filter (G.Adj v)`
  elaborate; the filter's cardinality is independent of the instance chosen, so
  quantifying over all instances is harmless and standard.
- Regularity via `(S.filter (G.Adj v)).card = d`: `SimpleGraph.Adj` is irreflexive, so
  `v` never counts itself; this is exactly the degree of `v` in the induced subgraph
  on `S`. `StrictMono`/interval issues do not arise.

**A3. Definitions — pass (trivially).** No `def`/`abbrev`/`structure` in the file; no
`sorry` outside proof bodies.

**A4. Question form and answer polarity — DEFECT (fixed).**

- The recovered source phrases the problem as a **yes/no question** ("…then **must**
  $G$ contain an induced non-trivial regular subgraph on $\gg\log n$ many
  vertices**?**"). Checklist A4 requires the shape `answer(…) ↔ P`; the corpus encodes
  solved-affirmative yes/no questions as `answer(True) ↔ P` in 172 `deepmind/` files —
  including the sibling `deepmind/1036.lean`, a solved question *from the same paper*
  [Er93]. `erdos_1031` was instead a bare assertion. **[defect]** — fixed to
  `theorem erdos_1031 : answer(True) ↔ ∃ c : ℝ, …` (line 71; not compile-verified).
- Polarity of the fixed form checked by hand: RHS true ⟺ such a regular induced
  subgraph always exists in the stated regime ⟺ the question's answer is "yes";
  Prömel–Rödl proved exactly this, so `answer(True)` is correct.
- Provenance of the drift: unlike 1005 (where restyling introduced it), here the *raw
  first pass* already asserted "then $G$ must contain…" without the question mark, in
  both docstring and code; restyling preserved the assertion form. Both prior reviews
  then rubber-stamped it (see Part E).
- No binders before the colon (line 71 is binder-free), so the iff is not spuriously
  universally quantified.

**A5. Solution status — pass (source-verified).**

- Page banner: **PROVED**, tooltip "This has been solved in the affirmative." Docstrings
  and `@[category research solved, AMS 5]` agree; the solver credited in prose
  (Prömel–Rödl) appears in the bibliography. "Formalised statement? No" on the page (as
  of access 2026-02-22) is consistent with this being a new formalization.
