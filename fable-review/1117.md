**Verdict:** NEEDS REVISION (one defect: the problem box asks **two** questions —

## Summary

The problem (Problem 2.16 in Hayman's collection [Ha74], attributed to Erdős): let
$f$ be an entire function which is not a monomial and let $\nu(r)$ count the points
$z$ with $|z| = r$ at which $|f(z)| = \max_{|z|=r}|f(z)|$ (a finite quantity for
non-monomial $f$). The page asks two questions: is it possible that
$\limsup \nu(r) = \infty$? (answered yes by Herzog–Piranian [HePi68]) and is it
possible that $\liminf \nu(r) = \infty$? (still open; an 'approximate' affirmative
answer by Glücksam–Pardo-Simón [GlPa24]). The Lean file (`conjectures/1117.lean`)
defines `IsMonomial`, `maxModulus` (via `sSup`), and `nu` (via `Set.ncard`), and
asserts the existence of an entire non-monomial $f$ with $\nu(r) \to \infty$ — a
faithful, non-vacuous rendering of the liminf question in the conjectured direction,
with every junk value pointing the harmless way. The one defect is completeness, not
fidelity: the limsup question is part of the problem box itself, not a mere remark,
and it is absent as a formal statement (noted only in prose as "the analogous
question").

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified) for the formalized half; the other
half is missing (see B2/defect).**

- Recovered verbatim source statement (see Addendum): "Let $f(z)$ be an entire
  function which is not a monomial. Let $\nu(r)$ count the number of $z$ with
  $\lvert z\rvert=r$ such that $\lvert f(z)\rvert=\max_{\lvert z\rvert=r}\lvert
  f(z)\rvert$. (This is a finite quantity if $f$ is not a monomial.) Is it possible
  for $\limsup \nu(r)=\infty$? Is it possible for $\liminf \nu(r)=\infty$?"
- Independent back-translation of `erdos_problem_1117` (lines 42–45): "there exists
  $f : \mathbb{C} \to \mathbb{C}$, differentiable over $\mathbb{C}$ (= entire), not
  of the form $cz^n$, such that for every $N$ there is an $R$ with $\nu(r) \ge N$
  for all $r \ge R$." For the ℕ-valued $\nu$, "$\forall N\,\exists R\,\forall r \ge
  R,\ \nu(r) \ge N$" is exactly $\nu(r) \to \infty$, which is exactly
  $\liminf_{r\to\infty} \nu(r) = \infty$. This matches the second question's
  affirmative direction.
- `nu` (line 23–24) counts $\{z : \|z\| = r,\ \|f z\| = M(r)\}$ with `maxModulus`
  (line 18–19) as $\sup\{\|f z\| : \|z\| = r\}$ — term-by-term the source's
  definition of $\nu(r)$.
- Types: circles as $\{z : \mathbb{C} \mid \|z\| = r\}$ with $r : \mathbb{R}$;
  counting in ℕ; comparison `N ≤ nu f r` in ℕ. All appropriate; no coercion issues.
- Not vacuous, and no degenerate witness: every junk value pushes *against* the
  asserted property. For $r < 0$ the sphere is empty, `maxModulus` = `sSup ∅` = 0
  (Real junk) and `nu` = 0, so negative radii could only *fail* `N ≤ nu f r` (and
  are anyway excluded by choosing $R > 0$). If the argmax set were infinite,
  `ncard` returns 0 — again failing, not passing. And an argmax set cannot be
  infinite here: if $|f|$ is constant on a circle of radius $r > 0$, then $f$ is a
  monomial — for constant modulus $c \neq 0$, $f$ agrees on the disc with a constant
  times a finite Blaschke product (identity theorem), whose entirety forces all
  zeros to the origin, i.e. $f = c'z^m$; for $c = 0$ the identity theorem gives
  $f \equiv 0$, a monomial with $c = 0$. So for non-monomial entire $f$,
  $\theta \mapsto |f(re^{i\theta})|$ is non-constant real-analytic, and its maximum
  set is finite and nonempty: $1 \le \nu(r) < \infty$ for all $r > 0$, vindicating
  the source's parenthetical and the `ncard` encoding.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no division anywhere.
- `sSup` on ℝ: for $r \ge 0$ and continuous $f$ (entire ⟹ continuous) the set
  $\{\|f z\| : \|z\| = r\}$ is a compact nonempty image, so `sSup` is the attained
  maximum and the argmax set in `nu` is nonempty. Empty-set junk (`sSup ∅ = 0`)
  arises only for $r < 0$, harmless as analyzed in A1.
- `Set.ncard` junk value 0 on infinite sets: cannot create a false positive
  (analyzed in A1); on the relevant circles the set is provably finite.
- No `Finset.range`, so no off-by-one surface. No 0-/1-indexing to reconcile
  (the variable is a real radius).
- No vacuous bounded quantifiers: `∀ N, ∃ R, ∀ r, R ≤ r → …` has no degenerate
  first instance (`N = 0` is trivially satisfied, as "liminf ≥ 0" should be).
- Filter encoding: the ∀∃∀ form is the correct arithmetization of
  $\liminf_{r\to\infty}\nu(r) = \infty$ for an ℕ-valued function; no
  `liminf`/`Filter` machinery needed, and the encoding does not silently weaken
  the notion.
- No `StrictMono`/`Monotone`, no interval-endpoint choices.

**A3. Definitions — pass.**

- `IsMonomial` matches its docstring and the intended exclusion: it includes
  constants ($n = 0$) and the zero function ($c = 0$) — precisely the entire
  functions with modulus constant on every origin-centered circle, which the
  problem must exclude for $\nu$ to be finite. Correct scope ($n : \mathbb{N}$ is
  right for entire monomials).
- `maxModulus` and `nu` match their docstrings and the source; degenerate inputs
  ($r < 0$, $r = 0$: the circle is $\{0\}$, $\nu = 1$) behave harmlessly.
- No `sorry` in any `def`. No drift between what the defs compute and what the
  theorem needs.

## E. Prior-review audit (`deepmind/ai-review/1117.md`)

The prior review was written against the styled `deepmind/deepmind/1117.lean`
(`answer(sorry) ↔ …`, single import, attributes), so its `answer()` remarks do not
apply verbatim to the raw file; its mathematics was audited claim by claim.

1. **Citation "verification" contradicted by the source it cites (hallucinated
   titles rubber-stamped).** The review lists the styled file's three bibliography
   entries and marks each "✅ Matches" the website. Against the actually recovered
   `/latex/1117` bibliography, **two of the three titles are wrong**:
   - Styled file/review: [HePi68] "*Sets of radii of parity for entire functions*".
     Site: "*The counting function for points of maximum modulus*" (1968, 240–243).
     The endorsed title appears to be a hallucination.
   - Styled file/review: [GlPa24] "*An approximate answer to a question of Erdős*".
     Site: "*An approximate solution to Erdős' maximum modulus points problem*",
     J. Math. Anal. Appl. (2024), Paper No. 127768.
   - [Ha74] "Research Problems in Function Theory, Athlone Press, 1967 (updated
     1974)" describes the book; the site's entry is "Research problems in function
     theory: new problems (1974), 155–180" (the 1974 'new problems' supplement).
     "✅ Matches" is false as a claim about the website's data.
   This is the recurring failure class "claiming source verification the source
   contradicts" (cf. the 1005 audit). The raw file under review here carries no
   bibliography, so it inherits none of these errors; v2 uses the recovered data.
2. **Wrong Mathlib semantics, harmless here.** "sSup … returns 0 (or more
   precisely, `⊥` in the conditionally complete lattice) when the set is empty or
   unbounded" — ℝ is a `ConditionallyCompleteLinearOrder` with no `⊥`;
   `Real.sSup` returns the junk value 0 by definition, not a bottom element. The
   conclusion (harmless for the theorem) is right; the justification misstates the
   library (same class as the 1002 audit finding).
3. **Its proposed limsup variant is subtly weaker than limsup = ∞.** The review's
   suggested fix encodes the Herzog–Piranian statement as
   `∀ N : ℕ, ∃ r : ℝ, N ≤ nu f r` — unboundedness of $\nu$ over *all* radii, with
   no requirement that the large values occur at arbitrarily large $r$. Since
   $\nu(r)$ is finite for each fixed $r$ but not obviously locally bounded in $r$,
   this is not (without proof) equivalent to $\limsup_{r\to\infty}\nu(r) = \infty$.
   The v2 variant adds the missing "beyond every bound $R$" constraint.
4. **What it got right** (re-derived): the finiteness of the maximum-modulus set on
   each circle for non-monomial entire $f$ (its justification is asserted as
   "well-known" without the monomial-circle argument, supplied in A1 above); the
   `ncard`-junk analysis; the harmlessness of $r < 0$; the correctness of the ∀∃∀
   liminf encoding; the `IsMonomial` scope remark ($n : \mathbb{N}$); and — its
   most important finding — **the missing limsup half**, which it correctly
   identified ("The limsup variant is currently missing") but under-classified as
   an optional variant of a "single statement" problem (its checklist §10 even
   says "No variants present … this is appropriate" in the style pass). This
   review classifies it as a defect and fixes it.
5. **Minor:** the review's claim that the problem is "attributed this way"
   (Problem 2.16 from [Ha74]) missing from the docstring was correct and is
   addressed in v2.
