## Summary

The problem: for $k \ge 3$, does there exist a finite set $A \subset \mathbb{R}^2$ such
that in any 2-colouring of $A$ there is a line containing at least $k$ points of $A$, all
points of $A$ on that line having the same colour? Status on the recovered page: **PROVED**
("This has been solved in the affirmative") — Graham and Selfridge proved $k = 3$ per
Erdős [Er75f, p.106], and Zach Hunter observed the general case follows from the
Hales–Jewett theorem via a generic projection of $[k]^n$ into $\mathbb{R}^2$. The Lean
(`deepmind/1090.lean:43`) states `answer(True) ↔ ∀ k ≥ 3, ∃ A : Finset (EuclideanSpace ℝ
(Fin 2)), ∀ c : … → Fin 2, ∃ L` a 1-dimensional affine subspace with `k ≤ ncard (A ∩ L)`
and all $A$-points on $L$ monochromatic. Read back independently, the Lean and the English
agree; I found no semantic defects, only polish-level enrichment (applied — see Addendum).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement: "Let $k\geq 3$. Does there exist a finite set
  $A\subset \mathbb{R}^2$ such that, in any $2$-colouring of $A$, there exists a line
  which contains at least $k$ points from $A$, and all the points of $A$ on the line have
  the same colour?" The module and theorem docstrings reproduce this verbatim.
- Independent back-translation of lines 43–49: "for every natural $k \ge 3$ there is a
  finite set $A$ of points of $\mathbb{R}^2$ such that for every 2-colouring $c$ of the
  plane there is an affine subspace $L$ with 1-dimensional direction containing at least
  $k$ points of $A$, and some colour is taken by every point of $A$ on $L$." This is the
  question as asked, with the source's "Let $k \ge 3$" parameter correctly universalized
  inside the iff (the page's affirmative solution covers all $k$, so the ∀-form has the
  same truth value as the parameterized family).
- **Coloring domain:** `c : EuclideanSpace ℝ (Fin 2) → Fin 2` colours all of ℝ² rather
  than just $A$. Equivalent to colouring only $A$: the condition evaluates `c` only at
  points of $A$, every colouring of $A$ extends to the plane, and every plane colouring
  restricts to $A$ — so the ∀-quantifier ranges over exactly the relevant data.
- **Line encoding:** `L : AffineSubspace ℝ (EuclideanSpace ℝ (Fin 2))` with
  `Module.finrank ℝ L.direction = 1` is exactly a line: an *empty* affine subspace has
  `direction = ⊥` (`vectorSpan ∅`), finrank 0 ≠ 1, so the rank condition forces $L$
  nonempty, and a nonempty affine subspace with 1-dimensional direction is a line.
- **Monochromaticity reading:** the source's "all the points of $A$ on the line have the
  same colour" is interpretation (a) — *every* $A$-point on $L$ shares one colour — which
  is what `∃ color, ∀ p ∈ A, p ∈ L → c p = color` says. Correct (and the stronger of the
  two conceivable parses; see Part E).
- Not vacuous/trivial: `k ≤ ncard {p | p ∈ A ∧ p ∈ L}` with $k \ge 3$ rules out the
  empty set, singletons, and any $A$ without $k$ collinear points; no degenerate witness
  satisfies the RHS, and the RHS is a substantive theorem (Hales–Jewett-strength), not a
  triviality.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no division, no `Finset.range`, no `StrictMono`/`Monotone`, no
  interval endpoints anywhere in the statement.
- `Set.ncard` on `{p | p ∈ (A : Set _) ∧ p ∈ L}`: the set is a subset of the finite
  coercion of the `Finset` $A$, hence finite, so `ncard` is the true cardinality (no
  junk-value-0 hazard from infinite sets).
- Vacuous quantifiers: `∀ p ∈ A, p ∈ L → …` cannot be vacuously discharged in a way that
  cheats, because the separate conjunct `k ≤ ncard (A ∩ L)` forces at least $k \ge 3$
  points of $A$ on $L$.
- `Fin 2` correctly encodes 2-colourings; `∃ color : Fin 2` correctly encodes "the same
  colour".

**A3. Definitions — pass (trivially).** No helper `def`/`abbrev`/`structure` in the file;
nothing to check, no `sorry` outside proof bodies.

**A4. Question form and answer polarity — pass.**

- The source is a yes/no question ("Does there exist…?"), so the `answer(…) ↔ P` shape is
  required and used, with `P` the question as asked. Polarity by hand: RHS true ⟺ for
  every $k \ge 3$ such an $A$ exists ⟺ the answer to the question is "yes"; the page says
  it was solved in the affirmative, so `answer(True)` is correct.
- No binders before the colon: line 43 is `theorem erdos_1090 : answer(True) ↔ ∀ (k : ℕ),
  k ≥ 3 → …` — the `(k : ℕ)` sits *inside* the iff, as required. (The mechanical Part D
  grep flags this line as a false positive because `(k : ℕ)` textually follows
  `answer(`; manual inspection confirms the theorem itself is binder-free.)
- Raw-vs-styled: the raw `conjectures/1090.lean` stated the solved problem as a direct
  assertion with binders `(k : ℕ) (hk : k ≥ 3)` before the colon — acceptable raw style
  for a solved problem with true polarity. The restyling to `answer(True) ↔ ∀ k ≥ 3, …`
  correctly internalized the binders; the ∃/∀/∃ body was transplanted verbatim. No drift.

**A5. Solution status — pass (source-verified).**
