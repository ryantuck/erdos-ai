## Summary

The problem ([Er81b, p.31]): can $\mathbb{R}^n$ be decomposed into countably many sets,
such that within each set all the pairwise distances are distinct? The page's banner is
**INDEPENDENT** ("Independent of the usual axioms of set theory (ZFC)."): under CH the
answer is yes for $n=1$ (Erdős–Kakutani [ErKa43], who proved CH *equivalent* to
decomposing $\mathbb{R}$ into countably many $\mathbb{Q}$-linearly independent sets),
for $n=2$ (Davies [Da72]), and for all $n$ (Kunen [Ku87]); and the CH assumption is
necessary (Erdős–Hajnal). The Lean file (`conjectures/1127.lean:13-20`) encodes the
decomposition as a coloring `f : EuclideanSpace ℝ (Fin n) → ℕ` and the distinct-distance
condition as a correct four-point implication — every component of the encoding is
faithful — but *asserts the affirmative answer as a bare theorem*, `theorem
erdos_problem_1127 (n : ℕ) : ∃ f, …`. That proposition is equivalent to CH, hence
neither provable nor refutable in Lean, and the file's own docstring says "(Independent
of ZFC)" two lines above the unconditional claim. This is the identical defect class
fixed for problem 1119, and it is fixed here the same way.

## A. Semantic fidelity

**A1. Statement fidelity — components pass (source-verified); overall form defective
(see A4).**

- Recovered verbatim source statement (see Addendum): "Can $\mathbb{R}^n$ be decomposed
  into countably many sets, such that within each set all the pairwise distances are
  distinct?" The module docstring (lines 6–7) reproduces it essentially verbatim.
- Independent back-translation of lines 13–19: "for every $n$, there is a coloring
  $f : \mathbb{R}^n \to \mathbb{N}$ such that for any four points $a,b,c,d$ of one color
  class with $a \ne b$, $c \ne d$ and $|ab| = |cd|$, the unordered pairs $\{a,b\}$ and
  $\{c,d\}$ coincide." Contrapositive: distinct unordered pairs of distinct points
  within one class always have distinct distances — exactly "within each set all the
  pairwise distances are distinct". The inner encoding is correct:
  - the coloring encodes a decomposition into countably many (possibly empty, hence also
    finitely many — the standard reading) sets;
  - `f a = f b → f a = f c → f a = f d` puts all four points in one class;
  - `{a, b} = {c, d}` as `Set` equality with `a ≠ b`, `c ≠ d` is precisely unordered-pair
    equality, correctly identifying $(a,b)$ with $(b,a)$ (`dist` is symmetric);
  - quantifying the *pair of pairs* (a quaternary condition) is the right shape; no
    triple-wise shortcut exists.
- Types: `EuclideanSpace ℝ (Fin n)` with its metric `dist` is the correct model of
  $\mathbb{R}^n$ with Euclidean distance. No coercions, sequences, or indexing arise.
- Degenerate dimension: $n = 0$ gives a one-point space where the statement is
  vacuously true; harmless and consistent with the universal reading (verified: with
  `Fin 0` empty, the Pi type is a singleton, so `a ≠ b` is unsatisfiable).
- Not vacuous/trivial *as a proposition about each $n \ge 1$*: the claim is a genuine
  set-theoretic statement (equivalent to CH). The defect is not vacuity but
  assertability — see A4.

**A5. Solution status — the docstring is right; the theorem contradicts it (part of
the A4 defect).**

- The docstring status "(Independent of ZFC)" and the attribution sentences (true under
  CH for $n=1$ by Erdős–Kakutani, $n=2$ by Davies, all $n$ by Kunen; CH-dependence

- But the *theorem* asserts the affirmative unconditionally — internal inconsistency
  between docstring and statement, subsumed under A4.

     same-class solution of $x_1 - x_2 = x_3 - x_4$ in distinct reals gives the two
     coincidences $|x_1-x_2| = |x_3-x_4|$ and $|x_1-x_3| = |x_2-x_4|$, hence $\le 4$
     distinct values among the six distances — matching the page's "only four
     distances" exactly). This is the same handling as 1004's false EPS87 page bound:
     formalize the corrected version, document the counterexample.
