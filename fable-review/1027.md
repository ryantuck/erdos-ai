## Summary

The problem: fix $c > 0$ and let $n$ be sufficiently large depending on $c$; let
$\mathcal{F}$ be a family of at most $c \cdot 2^n$ finite sets, each of size $n$, and
$X = \bigcup_{A \in \mathcal{F}} A$. Must there exist $\gg_c 2^{|X|}$ sets $B \subset X$
which intersect every member of $\mathcal{F}$ yet contain none of them? (The existence of a
single such $B$ is Property B / 2-chromaticity of $\mathcal{F}$, Problem 901; this asks for
a quantitative strengthening.) The page status is **PROVED** ("solved in the affirmative"),
via a proof by Koishi Chan in the page's comment section. The Lean
(`deepmind/1027.lean:56`, pre-fix numbering) encodes this as
`answer(True) ↔ ∀ c > 0, ∃ δ > 0, ∃ N₀, ∀ n ≥ N₀, ∀ F (n-uniform, |F| ≤ c·2^n),
|{B ∈ powerset(⋃F) : B crosses F}| ≥ δ·2^{|⋃F|}`. Read back independently, the Lean and the
recovered source statement agree; I found no semantic defects — only polish-level items,
now applied (see Addendum).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $c>0$, and let $n$ be
  sufficiently large depending on $c$. Suppose that $\mathcal{F}$ is a family of at most
  $c2^n$ many finite sets of size $n$. Let $X=\cup_{A\in \mathcal{F}}A$. Must there exist
  $\gg_c 2^{\lvert X\rvert}$ many sets $B\subset X$ which intersect every set in
  $\mathcal{F}$, yet contain none of them?"
- Independent back-translation of the theorem RHS: "for every $c>0$ there are
  $\delta > 0$ and a threshold $N_0$ such that for every $n \ge N_0$ and every family $F$
  of finite subsets of ℕ, each of cardinality $n$, with $|F| \le c\,2^n$, the number of
  $B \subseteq \bigcup F$ with $A \cap B \ne \emptyset$ and $A \not\subseteq B$ for all
  $A \in F$ is at least $\delta\,2^{|\bigcup F|}$." This is exactly the question asked:
  $\gg_c 2^{|X|}$ unpacks to $\ge \delta_c\,2^{|X|}$ with $\delta$ depending only on $c$
  (correctly placed: `∃ δ` after `∀ c`, before `∀ n`/`∀ F`), and "sufficiently large
  depending on $c$" is `∃ N₀, ∀ n ≥ N₀` with $N_0$ after `∀ c` — both dependences match.
- $B \subset X$ is encoded inclusively via `X.powerset` (`⊆`). This is the right reading:
  (a) erdosproblems.com routinely writes `⊂` for `⊆`; (b) under the strict reading the
  degenerate family $F = \emptyset$ ($X = \emptyset$, only crossing set
  $B = \emptyset = X$) would give count 0 and *falsify* the statement, so the strict
  reading cannot be the intended one for a problem proved true; (c) for nonempty $F$ the
  two readings agree anyway ($B = X$ contains every $A \in F$ and is filtered out). The
  interpretation is now documented in the module docstring (Addendum fix 2).
- "Family" = set of sets with no multiplicity: `Finset (Finset ℕ)` is faithful; ℕ as an
  infinite ground type imposes no capacity constraint, and the problem is
  isomorphism-invariant.
- Not vacuous, not trivially false: degenerate cases check out — $F = \emptyset$ gives
  count $1 \ge \delta$ (satisfiable, $\delta \le 1$); a single $n$-set gives
  $2^n - 2 \ge \delta 2^n$; the union bound handles $c < 1/2$ but fails for large $c$, so
  the statement has genuine content there — precisely what Chan's proof supplies. The
  claim quantified over *all* admissible $F$ is the proved one, so `answer(True)` does not
  assert a falsehood at any edge case I could construct.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no ℕ division, no `range`, no interval endpoints, no
  `StrictMono`/`Monotone` anywhere in the statement.
- Powers: `(2 : ℝ) ^ n` and `(2 : ℝ) ^ X.card` are real powers with ℕ exponents
  (`Monoid.npow`) — total, no trap. Casts `(F.card : ℝ)` and `(… .card : ℝ)` put both
  inequalities in ℝ, as intended.
- Vacuous quantifiers: `∀ A ∈ ∅, …` makes the empty family satisfy both filter conditions
  vacuously — analyzed above, matches the source's intent (constrains $\delta \le 1$,
  nothing more).
- `let X := F.biUnion id` binds the ground set once and is used consistently in the filter
  domain and the exponent. `Finset.biUnion id` is exactly $\bigcup_{A \in F} A$.
- `≥ δ * 2^|X|` (non-strict, $\delta$ existential) is the standard and correct unpacking
  of $\gg_c$.

**A3. Definitions — pass (trivially).**

- No `def`/`abbrev`/`structure` in the file; nothing to check, no `sorry` outside proof

- History note: the raw first pass (`conjectures/1027.lean:27`) was a bare assertion; the

## E. Prior-review audit (`ai-review/1027.md`)

Broadly accurate — the best of the prior reviews audited in this series — but four
findings:

1. **Speculation later laundered into the docstring.** §2 says of Cambie: "His role
   (likely problem formulation or partial results) should be acknowledged." The recovered
   page supports neither guess — Cambie appears only in the boilerplate "Additional
   thanks" credit line. The fix session followed the recommendation and wrote "with
   contributions from Stijn Cambie" into the docstring as fact. The review's
   *recommendation* (mention Cambie) was fine; the unhedged causal guess produced a
   misattribution downstream. Fixed (Addendum fix 1).
2. **Muddled but conclusion-correct argument on the `B ⊆ X` restriction.** §6 argues that
   elements outside $X$ "could only help with non-containment (vacuously)". Re-derived:
   for $A \in F$ we have $A \subseteq X$, so junk elements outside $X$ affect *neither*
   condition ($A \subseteq B \cup J \iff A \subseteq B$ when $J \cap X = \emptyset$, and
   likewise intersection) — they neither help nor hurt; the real point is that without the
   restriction the count over `Finset ℕ` would be unbounded whenever any crossing set
   exists, so restricting to `X.powerset` is what makes the count the intended finite one.
   Its "tightest possible bound" framing is not meaningful. Conclusion (encoding correct)
   stands.
3. **The strict-⊂ reading was never considered.** The source writes $B \subset X$; the
   review nowhere checks whether strictness matters. It happens not to (see A1: the
   degenerate-$F$ analysis actually *forces* the inclusive reading, and nonempty $F$ makes
   the readings coincide), but the check was skipped, and its own §6 "empty family"
   paragraph — which correctly computes count 1 via $B = \emptyset = X$ — is exactly the
   case where the two readings diverge; it analyzed the case without noticing it was
   resolving an ambiguity.
4. **Verified claims.** Its website citations (status PROVED, keys [Er64e]/[Er71, p.107],
   credits, comment-section proof, Problem 901 remark) all match the recovered page. Its
   Property-B equivalence argument (color classes $\{B, X \setminus B\}$; edge
   monochromatic ⟺ $A \subseteq B$ or $A \cap B = \emptyset$) re-derives correctly. Its
   quantifier-structure and edge-case analyses check out. What it flagged (missing
   citations, Cambie mention, 901 note) was subsequently fixed in `deepmind/1027.lean`.
