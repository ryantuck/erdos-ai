## Summary

The problem (PROVED, $10000): is it true that for every $C > 0$ there are
infinitely many $n$ with
$p_{n+1} - p_n > C \frac{\log\log n \log\log\log\log n}{(\log\log\log n)^2}\log n$?
The quantitative form comes from Rankin (1938), who proved it for some fixed
$C$; the full question was answered affirmatively by Maynard [Ma16] and
Ford–Green–Konyagin–Tao [FGKT16] (both 2016), and all five authors [FGKMT18]
later removed the square from the denominator. The Lean file defines
`erdosPrimeGapBound n` as exactly the displayed expression (real logs,
`a / b * c` parsed as `(a/b)*c`, correctly) and states: for every real
$C > 0$ and every $N$ there is $n \ge N$ with
$(p_{n+1} : \mathbb{R}) - (p_n : \mathbb{R}) > C \cdot \mathrm{bound}(n)$,
where $p_n = $ `Nat.nth Nat.Prime n` (0-indexed). Read back independently
this is the source statement, in the affirmed polarity, up to a harmless
unit index shift and finitely many junk values of the bound at small $n$ —
neither of which affects an infinitely-many statement. No defect found;
verdict capped only by nits.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (`tidy/4.html`, byte-identical in the
  session-log capture): "Is it true that, for any $C>0$, there are infinitely
  many $n$ such that
  $p_{n+1}-p_n> C\frac{\log\log n\log\log\log\log n}{(\log\log \log n)^2}\log n$?"
- Independent back-translation of `conjectures/4.lean:33-38`: "for every real
  $C > 0$ and every natural $N$ there exists $n \ge N$ such that the real
  difference of the $(n{+}1)$-st and $n$-th primes (0-indexed) exceeds
  $C \cdot B(n)$", with $B$ = `erdosPrimeGapBound`. The
  `∀ N, ∃ n ≥ N` shape is the standard correct encoding of "infinitely many
  $n$", and `∀ C > 0` sits outside it, matching the source's quantifier
  order.
- `erdosPrimeGapBound` (lines 17-20) is term-by-term the displayed
  expression: numerator $\log\log x \cdot \log\log\log\log x$ (four nested
  `Real.log`), denominator $(\log\log\log x)^2$, postfactor $\log x$. Lean's
  `a / b * c` associates as `(a / b) * c` — the intended
  $\frac{\text{num}}{\text{den}} \cdot \log x$.
- Indexing: `Nat.nth Nat.Prime` is 0-indexed ($p_0 = 2$), the source is
  1-indexed ($p_1 = 2$), so Lean's index $n$ is the source's $n+1$. The gap
  compared is between consecutive primes either way; only the argument of
  $B$ shifts by one. Since $B(n+1)/B(n) \to 1$ and the claim is quantified
  over **all** $C > 0$, the shifted and unshifted statements are equivalent
  (absorb the $1+o(1)$ factor into $C$). Verified at the first index too:
  Lean $n = 0$ compares $p_1 - p_0 = 3 - 2$ against $C \cdot B(0) = 0$ —
  a junk instance, but one of finitely many (below), so it cannot create or
  destroy infinitude.
- Not vacuous, not trivially true: the truth value of `∀ N, ∃ n ≥ N, …` is
  determined by arbitrarily large $n$, where $B$ is the intended (positive)
  expression; the degenerate instances are confined to $n \le e^{e^e}$
  (finitely many, see A2). And the statement is substantive: it is the
  affirmed content of a $10000 problem.

**A2. Lean semantics traps — pass.**

- **ℕ subtraction avoided correctly:** the gap is computed as
  `(nth Nat.Prime (n+1) : ℝ) - (nth Nat.Prime n : ℝ)` — both casts happen
  *before* the subtraction, so this is real subtraction (and the difference
  is positive anyway since `Nat.nth` of an infinite set is strictly
  monotone). The classic trap is dodged.
- **Division:** real division. Denominator $(\log\log\log n)^2 = 0$ exactly
  when $n \le 2$ (for $n \le 2$, $\log\log n \le 0$, whose `Real.log` is
  junk 0), where division-by-zero returns 0 — so $B(0)=B(1)=B(2)=0$.
  Checked numerically: for $3 \le n \le 15$ ($n < e^e \approx 15.154$),
  $\log\log\log n < 0$, so the fourth log is `Real.log` of a negative
  number, i.e. junk 0, giving $B(n) = 0$; for
  $16 \le n \le 3\,814\,279$ ($n < e^{e^e} \approx 3.814 \times 10^6$),
  $\log\log\log n \in (0,1)$ so the fourth log is genuinely negative and
  $B(n) < 0$ (inequality trivially true at those $n$); for
  $n \ge 3\,814\,280$ every factor is positive and $B$ is the intended
  expression. All degenerate cases are finite in number, hence harmless for
  the infinitely-many statement — but the input file documents none of this
  (nit, fixed in v2).
- **`Finset.range`:** not used; no off-by-one to check.
- **Vacuous bounded quantifiers:** none.
- **Infinitude encoding:** `∀ N, ∃ n ≥ N` — the standard, correct finitary
  encoding; no filter machinery needed.
- **Strict vs non-strict:** strict `>` matches the source's strict `>`.
