## Summary

The problem (erdosproblems.com/72, $100 prize): is there a set $A \subset
\mathbb{N}$ of density 0 and a constant $c > 0$ such that every graph on
sufficiently many vertices with average degree $\geq c$ contains a cycle whose
length is in $A$? Status **PROVED** ("solved in the affirmative"), by
Verstraëte [Ve05] non-constructively; Liu–Montgomery [LiMo20] later showed the
powers of 2 work, contradicting Erdős's own belief. The Lean statement
(`conjectures/72.lean:25-33`) asserts: there exist a density-zero set
$A \subseteq \mathbb{N}$, a real $c > 0$, and a threshold $N_0$ such that
every simple graph on $n \ge N_0$ vertices with $2|E| \ge cn$ contains a
cycle whose length lies in $A$. That is exactly the affirmative direction of
the question, in direct-assertion form — acceptable for a solved problem in
this pipeline, and the polarity is the true one. I found no semantic defects;
the findings are scholarship-level (citation keys used but undefined in the
file, the page's headline Liu–Montgomery variant unformalized, page remarks
absent).

## A. Semantic fidelity

### A1. Statement fidelity — PASS

Independent back-translation of `conjectures/72.lean:25-33`: "There exists a
set $A$ of naturals such that for every $\varepsilon > 0$ eventually
$|A \cap \{0,\dots,n\}| \le \varepsilon n$, and there exist a real $c > 0$
and a natural $N_0$, such that for every $n \ge N_0$ and every simple graph
$G$ on `Fin n` (with a decidability instance for its adjacency), if
$2|E(G)| \ge c \cdot n$ then some $k \in A$ is the length of a cycle in $G$."
Diffed against the recovered verbatim statement:

- "set $A \subset \mathbb{N}$ of density $0$" ↦ `HasDensityZero A` — an ε-N
  encoding of upper natural density zero, equivalent to the standard
  definition (see A3). Correct.
- "a constant $c > 0$" ↦ `∃ c : ℝ, c > 0` — the page's own phrasing includes
  the positivity, so `c > 0` is not even a strengthening here. Correct.
- "every graph on sufficiently many vertices" ↦ `∃ N₀, ∀ n ≥ N₀,
  ∀ G : SimpleGraph (Fin n)` — the ∃-threshold reading of "sufficiently
  many", with every finite simple graph on $n$ vertices representable on
  `Fin n` up to isomorphism (and cycle lengths are isomorphism-invariant).
  Correct.
- "average degree $\geq c$" ↦ `2 * |edgeFinset| ≥ c * n` in ℝ — the standard
  $2|E|/n \ge c$ cleared of its denominator, exact for $n > 0$ and harmless
  at $n = 0$ (see A2). Non-strict, as "≥" requires. Correct.
- "contains a cycle whose length is in $A$" ↦
  `∃ k, k ∈ A ∧ ∃ v, ∃ p : G.Walk v v, p.IsCycle ∧ p.length = k` — a cycle
  (Mathlib `Walk.IsCycle`) with length in $A$. Correct.

Not vacuous, not trivially true: density-zero sets exist but the conclusion
constrains all sufficiently large dense graphs, so a degenerate $A$ (empty,
finite) cannot satisfy the statement — complete graphs have unbounded average
degree yet only cycle lengths $3,\dots,n$, so $A$ must be infinite. The
statement is a genuine theorem (Verstraëte). Direct-assertion polarity is the
true direction.

### A2. Lean semantics traps — PASS

- **ℕ subtraction:** none occurs.
- **Division:** none occurs — the average-degree condition is stated
  multiplicatively (`2|E| ≥ c·n`), deliberately avoiding the $n = 0$
  denominator issue.
- **`Finset.range`:** not used. `Set.Iic n` = $\{0,\dots,n\}$ matches the
  helper docstring's "{0, ..., n}" exactly.
- **Vacuous bounded quantifiers:** none. Degenerate small $n$: at $n = 0$
  the hypothesis `0 ≥ 0` holds but `∃ v : Fin 0` is false, so the inner
  statement is false at $n = 0$ (likewise unsatisfiable at $n = 1, 2$ for
  small $c$: no cycles exist there); this is harmless because $N_0$ is
  existentially quantified by the prover (choose $N_0 \ge 3$), and it
  faithfully mirrors "sufficiently many vertices". No silent alteration.
- **Filter encodings:** density zero is encoded directly by ε-N, not via
  `liminf`/`limsup` — no `Real.sSup`/junk-value risk (problem-33 class: n/a).
- **Strictness:** `ε > 0`, `c > 0` strict as intended; `≥` non-strict in the
  degree hypothesis and `n ≥ N` thresholds, as the source requires.
- **Default-valued binders (problem-25 class):** none — `A` is a genuine
  existential, constrained by `HasDensityZero A` inside the conjunction.
- **Constant quantifier order (problem-55 class):** checked explicitly —
  `∃ A, … ∃ c, … ∃ N₀` all precede `∀ n, ∀ G`, so neither $c$ nor $A$ can
  absorb graph-dependent information. This is the load-bearing quantifier
  check for this problem, and it is right.
- **Degenerate-input junk:** `Set.ncard (A ∩ Set.Iic n)` is applied to a
  subset of the finite set `Iic n`, so it is the true cardinality, never the
  infinite-set junk value 0. Elements $0, 1, 2 \in A$ cannot be spuriously
  witnessed as cycle lengths: Mathlib's `IsCycle` (pinned rev 8f9d9cff,
  `Paths.lean:84`: trail + `≠ nil` + `support.tail.Nodup`) forces length
  ≥ 3 in a simple graph.
- **`∀ (hd : DecidableRel G.Adj)` + `haveI := hd`:** quantifying over the
  instance is semantically inert — any two `Fintype G.edgeSet` instances
  yield equal `edgeFinset` (membership-determined) hence equal `card`. The
  standard pattern; no drift.

### A3. Definitions — PASS

One helper, `HasDensityZero` (`conjectures/72.lean:13-15`). It matches its
docstring ("for every ε > 0, for all sufficiently large n,
|A ∩ {0, ..., n}| ≤ ε · n") term for term, and is equivalent to the standard
natural-density-zero: the counts over $\{0,\dots,n\}$ vs $\{1,\dots,n\}$ (or
$[0,n)$) differ by at most 1, absorbed since ε is arbitrary (given standard
density zero and ε, pick $N \ge 2/\varepsilon$ with
$|A \cap [1,n]| \le (\varepsilon/2)n$; then
$|A \cap [0,n]| \le (\varepsilon/2)n + 1 \le \varepsilon n$). Sanity on small
cases (problem-56 class): $A = \mathbb{N}$ fails it for $\varepsilon < 1$,
evens fail for $\varepsilon < 1/2$, powers of 2 satisfy it — behaves
correctly. No `sorry` in any def. The def is used exactly as the theorem
needs it.
