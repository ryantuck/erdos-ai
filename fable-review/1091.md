## Summary

The problem (source [Er76c, p.4]): let $G$ be a $K_4$-free graph with chromatic number
$4$ — **must** $G$ contain an odd cycle with at least two diagonals? More generally, is
there some $f(r) \to \infty$ such that every graph with chromatic number $4$, in which
every subgraph on $\leq r$ vertices has chromatic number $\leq 3$, contains an odd cycle
with at least $f(r)$ diagonals? The first question was solved affirmatively by Voss
[Vo82] (Erdős's original one-diagonal question having been settled by Larson [La79]);
the general question is open and the page banner is OPEN. The Lean file defines
`HasOddCycleWithDiagonals` (odd cycle as an injective `Fin (2m+3) → V` with cyclic
adjacency; diagonals counted as ordered-once vertex pairs that are adjacent but not
cyclically consecutive) — this definition is correct, including degenerate cases — and
states both questions. The second question's encoding (`answer(sorry) ↔ ∃ f, …`) is
faithful. The defect: the first question, a yes/no "Must…?" question, was encoded as a
bare direct assertion with theorem binders instead of the corpus-standard
`answer(True) ↔ ∀ …` shape (cf. `deepmind/1027.lean`, `deepmind/1037.lean`,
`deepmind/1047.lean`, all solved "Must" questions with the wrapper).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified), one form defect deferred to A4.**

- Recovered verbatim source statement (see Addendum): "Let $G$ be a $K_4$-free graph
  with chromatic number $4$. Must $G$ contain an odd cycle with at least two diagonals?
  … More generally, is there some $f(r)\to \infty$ such that every graph with chromatic
  number $4$, in which every subgraph on $\leq r$ vertices has chromatic number
  $\leq 3$, contains an odd cycle with at least $f(r)$ diagonals?"
- `HasOddCycleWithDiagonals` back-translated independently: "there exist $m \ge 0$ and
  an injective $f : \{0,\dots,2m+2\} \to V$ with $f(i) \sim f(i+1 \bmod 2m+3)$ for all
  $i$, such that at least $d$ pairs $i < j$ have $f(i) \sim f(j)$ with $j$ not the
  cyclic successor of $i$ and $i$ not the cyclic successor of $j$." That is exactly: $G$
  contains a (simple) odd cycle of length $\ge 3$ carrying $\ge d$ diagonals. Cycle
  lengths $2m+3$ enumerate all odd lengths $\ge 3$; injectivity makes the cycle simple;
  the wrap-around edge $(2m+2, 0)$ is correctly excluded from the diagonal count by the
  second non-consecutiveness condition ($((2m+2)+1) \bmod (2m+3) = 0$). For $m = 0$
  (triangle) every pair is consecutive and the count is 0, as it should be.
- Main theorem content: for all finite graphs, $K_4$-free ∧ $\chi = 4$ →
  `HasOddCycleWithDiagonals G 2`. Matches the first question's content (question *form*
  is the A4 issue). Second theorem: ∃ $f$ with $f(r) \to \infty$ s.t. ∀ $r, n, G$:
  $\chi(G) = 4$ ∧ (every induced subgraph on $\le r$ vertices has $\chi \le 3$) →
  `HasOddCycleWithDiagonals G (f r)`. Matches the second question.
- "Every **subgraph** on $\leq r$ vertices" (source) vs "every **induced** subgraph"
  (Lean): equivalent, since $\chi$ of a subgraph is at most $\chi$ of the induced
  subgraph on the same vertex set, so the universal conditions coincide. Now noted in
  the variant docstring.
- Finiteness restriction (`Fin n`): the source says "graph" without qualification. WLOG
  by de Bruijn–Erdős: if an infinite $G$ has $\chi(G) = 4$, some finite subgraph $H$ has
  $\chi(H) = 4$ exactly ($\ge 4$ by non-3-colorability plus compactness, $\le 4$ by
  monotonicity), $H$ inherits $K_4$-freeness/the local condition, and an odd cycle with
  $d$ diagonals in $H$ is one in $G$. So the finite version implies the infinite one,
  and trivially conversely. Harmless (uses AC, as does $\chi$ itself).
- Not vacuous/trivial: the hypothesis class is nonempty (Grötzsch graph: triangle-free,
  hence $K_4$-free, $\chi = 4$); the conclusion is not free (e.g. $K_4$ itself has
  $\chi = 4$ and *no* odd cycle with any diagonal — its only odd cycles are triangles —
  which is exactly why $K_4$-freeness is needed). For the variant, small $r$ (e.g.
  $r \le 3$) admits $K_4$ as a qualifying graph, forcing $f(r) = 0$ there; that is
  compatible with $f(r) \to \infty$ and matches the problem's intent.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no division anywhere.
- `(i.val + 1) % (2 * m + 3)`: modulus is $\ge 3 > 0$, and `Nat.mod_lt _ (by omega)`
  supplies the bound proof for the `Fin` constructor. Standard cyclic-successor idiom;
  no off-by-one (checked at $i = 2m+2$: successor 0, the wrap edge).
- `Finset.univ.filter` over `Fin (2m+3) × Fin (2m+3)` with `p.1.val < p.2.val` counts
  each unordered pair exactly once and excludes self-pairs; decidability comes from the
  scoped `Classical.propDecidable` instance (`open Classical`), hence the (harmless)
  `noncomputable` on a `Prop`-valued def.
- No vacuous bounded quantifiers: the cycle length is $\ge 3$ by construction, so the
  adjacency ∀ is never vacuous.
- `Tendsto f atTop atTop` is the standard, correct encoding of $f(r) \to \infty$ for
  $f : ℕ → ℕ$.
- `chromaticNumber = (4 : ℕ∞)` / `≤ (3 : ℕ∞)`: Mathlib's `chromaticNumber : ℕ∞`, so the
  coercions are in the right type; equality (not $\ge$) correctly captures "chromatic
  number 4"; `≤ 3` correctly captures 3-colorability of the (finite) induced subgraphs.
- No `StrictMono`/`Monotone` or interval-endpoint issues arise.

**A3. Definitions — pass.**

- `HasOddCycleWithDiagonals` matches its docstring and the source notion, including
  degenerate inputs ($d = 0$ is satisfied by any odd cycle, e.g. any triangle; $m = 0$
  gives a diagonal-free triangle). No `sorry` in any def. The def is used consistently
  by all theorems (`G 2`, `G (f r)`, `G 1`, `G 3`).

**A4. Question form and answer polarity — DEFECT (fixed).**

- The source's first question is a **yes/no question** ("Must $G$ contain an odd cycle
  with at least two diagonals?"). Per the checklist and the uniform corpus convention
  for solved "Must" questions (`deepmind/1027.lean` `answer(True) ↔ ∀…`;
  `deepmind/1037.lean`, `deepmind/1047.lean` `answer(False) ↔ ∀…`), it must be encoded
  `answer(True) ↔ P` with the quantifiers *inside* the iff. `erdos_1091` was instead a
  bare direct assertion with `n`, `G`, and both hypotheses as theorem binders.
  **[defect]** — fixed to `answer(True) ↔ ∀ (n : ℕ) (G : SimpleGraph (Fin n)),
  G.CliqueFree 4 → G.chromaticNumber = 4 → HasOddCycleWithDiagonals G 2` (see Addendum;
  not compile-verified). Polarity checked by hand: RHS true ⟺ every such graph has the
  odd cycle ⟺ the answer to "Must…?" is yes; Voss proved yes, so `answer(True)`.
- The second question ("is there some $f(r) \to \infty$…?") is an open yes/no question;
  `answer(sorry) ↔ ∃ f, …` is the correct shape and the RHS is the question as asked
  (so `True` would mean "yes"). Binder-free before the colon — correct.
- Note the origin: the raw pass stated *both* parts as bare assertions; restyling
  correctly added `answer(sorry) ↔` to the open part but left the solved part as an
  assertion. The defect entered at the raw stage and survived restyling and both prior
  reviews.

## E. Prior-review audit (`ai-review/1091.md`)

Accurate on the definition-level mathematics, but it missed the review's one defect:

1. **Question form endorsed by mischaracterization.** Its §3 renders the source as "The
   website states two parts: 1. **Solved (Voss):** K₄-free graphs with χ = 4 **must
   contain** an odd cycle with ≥ 2 diagonals" — silently converting the site's
   interrogative ("Must $G$ contain…?") into an assertion, and its §6 then blesses the
   binder-carrying direct-assertion encoding without ever raising A4. This is the same
   failure pattern as the 1005 audit (endorsing an encoding that contradicts the
   source's own question form). The style review compounds it: `reviews/1091.md` §6
   asserts "Case 3 (direct assertion: 'Let G be … Then G contains …')" — quoting the
   *formalization's* docstring as if it were the problem statement; against the
   recovered source text this is factually false.
2. **Compactness aside: conclusion right, argument half-stated.** Its §6 claim that
   restricting to finite graphs is harmless is correct, but its stated reason ("any
   counterexample to the finite version would also be a counterexample to the infinite
   version, and conversely, a compactness argument…") leaves the substantive direction
   as a wave. Re-derived here (A1): de Bruijn–Erdős extracts a finite subgraph with
   $\chi = 4$ exactly, hypotheses are subgraph-hereditary, and diagonal-bearing cycles
   transfer upward. Sound, with AC.
3. **Citation stubs not flagged.** "Citations are consistent with the website. No
   issues" — the keys do match (now verified), but [La79]/[Vo82] carry no bibliographic
   data whatsoever, which B1 should have flagged as stubs needing `/latex/1091`.
4. **Module docstring gap not flagged.** It reviewed docstring quality (§4 "no
   improvements needed") without noticing the module docstring contained no statement of
   the problem at all.

What it got right (re-derived): the diagonal-count filter analysis (ordered-once pairs,
both cyclic-successor exclusions, wrap-around) is correct; $m=0$ triangle case correct;
the subgraph/induced-subgraph equivalence claim in §5 is correct; the observation that
the variant rightly drops $K_4$-freeness matches the recovered page ("every graph"), and
its remark that $r = 4$ locality is exactly $K_4$-freeness checks out ($\chi(H) = 4$ for
$|H| = 4$ iff $H = K_4$).
