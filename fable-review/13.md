## Summary

The problem (erdosproblems.com/13, **PROVED**, $100 prize): *"Let
$A\subseteq \{1,\ldots,N\}$ be such that there are no $a,b,c\in A$ such that
$a\mid(b+c)$ and $a<\min(b,c)$. Is it true that $\lvert A\rvert\leq N/3+O(1)$?"*
Asked by Erdős and Sárközy; answered affirmatively by Bedert [Be23]. The Lean file
defines `IsSumDivFree A` (no triple a, b, c ∈ A with a ∣ (b+c) and a < min(b,c)) and
asserts `∃ C : ℝ, ∀ N, ∀ A ⊆ Finset.Icc 1 N, IsSumDivFree A → (A.card : ℝ) ≤ N/3 + C`
(`conjectures/13.lean:27`). Read back independently: "there is a uniform real constant
C such that every sum-divisibility-free subset of {1,…,N} has at most N/3 + C
elements" — exactly the "yes" direction of the question, which is the proved
direction. This is also, up to a definitional rephrasing of the predicate,
**identical to the upstream google-deepmind/formal-conjectures `erdos_13`** (the
user's own hand contribution in PR #1793, recovered and compared in full). I found no
semantic defects — only polish-level nits (a `→ False` idiom, docstring enrichment,
one page-confirmed variant worth adding).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (capture in
  `claude-session-logs/837adb7b-c151-4eb2-89a8-2b0a0a2a2b27.jsonl`, line 12 — the
  original formalization session's Read of the then-extant `tidy/13.html`): "Let
  $A\subseteq \{1,\ldots,N\}$ be such that there are no $a,b,c\in A$ such that
  $a\mid(b+c)$ and $a&lt;\min(b,c)$. Is it true that $\lvert A\rvert\leq N/3+O(1)$?"
- Independent back-translation of lines 27–32: ∃C ∀N ∀A ⊆ {1,…,N}, if A has no triple
  a,b,c with a ∣ (b+c) and a < min(b,c), then |A| ≤ N/3 + C. The `∃ C … ∀ N` order is
  the correct encoding of the uniform O(1): C may not depend on N. Term-for-term this
  is the source's "yes" direction.
- `IsSumDivFree` (lines 17–18): `∀ a ∈ A, ∀ b ∈ A, ∀ c ∈ A, a ∣ (b + c) →
  a < min b c → False` is precisely ¬∃ a,b,c ∈ A (a ∣ (b+c) ∧ a < min(b,c)).
- Distinctness nuance (checked, not a defect): the Lean quantification permits
  a, b, c to coincide. `a < min b c` already forces a ≠ b and a ≠ c, so the only
  freedom is b = c, which additionally forbids a ∣ 2b for a < b. This matches the
  page's **literal** quantification ("no $a,b,c\in A$", with no distinctness
  requirement) — in deliberate contrast to problem #12, whose recovered page says
  "no **distinct** $a,b,c\in A$". The upstream formal-conjectures predicate makes the
  same choice. Since the b = c-forbidding class of sets is contained in the
  distinct-only class, the formalized bound is implied by (and no stronger than)
  Bedert's theorem under either reading, and the Erdős–Sárközy tightness example
  works under both.
- Types: `Finset ℕ` for A, `Finset.Icc 1 N` = {1,…,N} exactly (0 correctly
  excluded), cardinality cast to ℝ before comparing with N/3 + C — arithmetic happens
  in ℝ as intended.
- Not vacuous/trivially true: for no fixed C does |A| ≤ N/3 + C hold for all
  A ⊆ {1,…,N} (take A = {1,…,N} itself: it is not sum-div-free — e.g. 1 ∣ 2+3 — so
  no triviality that way either; the hypothesis class is rich, containing
  (2N/3, N] ∩ ℕ of size ⌈N/3⌉, so the bound is genuinely sharp and the statement is
  Bedert's substantive theorem).
