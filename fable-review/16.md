## Summary

The problem (DISPROVED): *is the set of odd integers not of the form
$2^k + p$ (p prime, $k \ge 0$) the union of an infinite arithmetic
progression and a set of density 0?* Erdős called the conjecture "rather
silly"; he had proved [Er50] via covering congruences that the set *contains*
an infinite AP, and Chen [Ch23] proved the answer is **no**. The Lean file
defines `oddNotPowerOfTwoPlusPrime` ($\{n : \text{Odd } n,\ \forall k\,
\forall \text{prime } q,\ n \ne 2^k + q\}$), `HasNaturalDensityZero`
($|S \cap \{1,\ldots,N\}|/N \to 0$), and `IsInfiniteAP`
($\exists a, d > 0,\ AP = \{a + md\}$), and states
`erdos_problem_16 : ¬ ∃ AP D, IsInfiniteAP AP ∧ HasNaturalDensityZero D ∧
oddNotPowerOfTwoPlusPrime = AP ∪ D`. Read back independently, this is exactly
the negation of the question as asked — the direct assertion of the solved
problem in its true direction, the acceptable form for this pipeline. I found
no semantic defects; the findings are enrichment-level (no reference entries
anywhere, the Er50 partial result unformalized, no provenance recorded).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Is the set of odd
  integers not of the form $2^k+p$ the union of an infinite arithmetic
  progression and a set of density $0$?" — problem source `[Er95, p.167]`.
- `oddNotPowerOfTwoPlusPrime` (`conjectures/16.lean:14-15`), back-translated:
  odd naturals $n$ such that no $k \ge 0$ and prime $q$ give $n = 2^k + q$.
  Exactly "odd integers not of the form $2^k + p$". `Odd 0` is false, so the
  set contains only positive integers; $1$ belongs (min of $2^k + p$ is
  $2^0 + 2 = 3$), matching A006285's leading term per reviewer knowledge.
- **The $k \ge 0$ vs $k \ge 1$ convention is immaterial to the theorem** (a
  point the prior review argued only from literature convention): the two
  readings differ in at most the single element $3$ ($3 = 2^0 + 2$ is
  representable iff $k = 0$ is allowed; for $k \ge 1$, $3 - 2 = 1$ is not
  prime and $3 - 2^k < 0$ otherwise), and the property "equals
  $AP \cup D$ with $AP$ an infinite AP and $D$ density-zero" is invariant
  under finite symmetric difference: adding a finite set enlarges $D$ by a
  density-zero set; deleting a point of $AP$ leaves an infinite AP tail
  $\{a + (m_0+1)d + md\}$ plus a finite set absorbable into $D$. So the
  encoding choice (which matches [Er50] and the OEIS convention) cannot flip
  the truth value.
- `HasNaturalDensityZero` (`:20-22`): `Set.Icc 1 N` $= \{1,\ldots,N\}$ is the
  source's exact window; requiring the limit to exist and equal 0 is the
  standard "density 0" (equivalent to upper density 0 since lower density
  $\ge 0$). No off-by-one.
- `IsInfiniteAP` (`:28-29`): one-sided infinite AP $\{a + md : m \in \mathbb{N}\}$
  with $d > 0$ — the correct reading in ℕ; $d > 0$ is essential (else the
  singleton $\{a\}$ would qualify) and present.
- `erdos_problem_16` (`:46-51`), back-translated: "there do not exist an
  infinite AP and a density-zero set whose union equals the set." Exactly
  Chen's theorem, i.e. the "no" answer to the question as asked. `D` is not
  required disjoint from `AP` or odd — matching the source's unrestricted
  "set of density 0"; quantifier structure (∃ AP ∃ D under one negation)
  matches.
- Not vacuous/trivial: the negation is substantive precisely because of
  [Er50] — the set *contains* an infinite AP, so it has positive lower
  density and the candidate decomposition $S = AP \cup (S \setminus AP)$
  fails only because $S \setminus AP$ never has density zero (Chen); nothing
  degenerate satisfies or refutes the statement trivially. Note also that
  since $S$ contains an infinite AP, $S$ itself is not density-zero, so even
  degenerate near-decompositions (e.g. $D = S$) are genuinely excluded.
