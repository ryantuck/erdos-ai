## Summary

The problem (SOLVED — disproved): let $f(z)$ be an entire function of finite order and
$\Gamma$ a rectifiable path on which $f(z) \to \infty$, with $\ell(r)$ the length of
$\Gamma$ in the disc $|z| < r$; can such a $\Gamma$ always be found with
$\ell(r) \ll r$? Gol'dberg and Eremenko [GoEr79] disproved it: for any
$\phi(r) \to \infty$ there is an entire $f$ with $\log M(r) \ll \phi(r)(\log r)^2$ and
no path $\Gamma$ on which $f \to \infty$ and $\ell(r) \ll r$. The Lean
(`conjectures/1115.lean:57-61`) asserts the refutation directly:
`∃ f, IsEntire f ∧ HasFiniteOrder f ∧ ∀ γ : ArcLengthPath, TendsToInfinityAlong f γ →
¬(ℓ(r) = O(r) eventually)`. The supporting definitions are individually correct and
well-crafted, and direct-assertion form in the true direction is acceptable here — but
the statement as written is **trivially true**: take `f := 0`. A constant is entire of
finite order, and `TendsToInfinityAlong 0 γ` (i.e. `Tendsto (fun t => ‖(0:ℂ)‖) atTop
atTop`) is false for every path, so the `∀ γ` clause holds vacuously and the theorem is
provable in a few lines while carrying none of Gol'dberg–Eremenko's content. This is
exactly the A1 "degenerate witness" failure. v2 adds the conjunct
`∃ γ, TendsToInfinityAlong f γ` — matching the problem's own setup, which presupposes
paths on which $f \to \infty$ exist — after which the statement says precisely
"asymptotic paths exist, and every one of them is long."

## A. Semantic fidelity

**A1. Statement fidelity — one [defect]: trivially-true statement via degenerate
witness; everything else exact (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $f(z)$ be an entire function
  of finite order, and let $\Gamma$ be a rectifiable path on which $f(z)\to \infty$.
  Let $\ell(r)$ be the length of $\Gamma$ in the disc $\lvert z\rvert<r$. / Find a path
  for which $\ell(r)$ grows as slowly as possible, and estimate $\ell(r)$ in terms of
  $M(r)=\max_{\lvert z\rvert=r}\lvert f(z)\rvert$. / In particular, can such a path
  $\Gamma$ be found for which $\ell(r)\ll r$?"
- Scope: the middle paragraph ("find a path… estimate $\ell(r)$ in terms of $M(r)$") is
  a soft optimization request, not a single proposition; formalizing the "in
  particular" yes/no core is the correct choice (its omission is now noted in the v2
  module docstring). The question was answered NO, so the direct assertion of the
  Gol'dberg–Eremenko refutation is the right content: informally, $\exists f$ entire of
  finite order such that no path $\Gamma$ has both $f \to \infty$ along $\Gamma$ and
  $\ell(r) \ll r$ — and "no path with (P ∧ Q)" is correctly rendered
  `∀ γ, P γ → ¬ Q γ` (lines 59–60).
- **[defect] The rendering is trivially true as written.** The informal statement
  quantifies, per its own setup ("let $\Gamma$ be a rectifiable path on which
  $f(z)\to\infty$"), over $f$ for which such paths *exist*; the counterexample's force
  is that its asymptotic paths — which exist, by Iversen's classical theorem that
  $\infty$ is an asymptotic value of every nonconstant entire function — are all long.
  The Lean statement drops that presupposition, so `f := 0` (or any constant) is a
  witness: `IsEntire 0` holds (`Differentiable ℂ (fun _ => 0)`); `HasFiniteOrder 0`
  holds with $\rho = 0, C = 0, R = 1$ (`‖0‖ = 0 ≤ exp 0 = 1`… indeed
  $0 \le \exp(0 \cdot \|z\|^0)$); and for every `γ`, `TendsToInfinityAlong 0 γ` is the
  false proposition that the constant $0$ tends to `atTop`, so the implication on lines
  59–60 is vacuous. The theorem is provable without any complex analysis, violating the
  A1 requirement that the statement not be "vacuously true… a degenerate witness…
  satisfying the formal statement while violating the problem's intent." **Fixed in v2**
  by adding the conjunct `(∃ γ : ArcLengthPath, TendsToInfinityAlong f γ)` before the
  universal clause. The fix is sound in both directions: it excludes every degenerate
  witness (constants, and any hypothetical $f$ with no rectifiable asymptotic path, for
  which the `∀ γ` would equally be vacuous), and it is satisfied by the
  Gol'dberg–Eremenko function — nonconstant, so by Iversen it has an asymptotic path
  with $f \to \infty$, which may be taken polygonal (connect points of the nested
  unbounded components of $\{|f| > n\}$ by polygonal arcs inside those open connected
  sets), hence locally rectifiable, of infinite total length, and reparameterizable by
  arc length; the reparameterization is continuous, unit-speed
  (`eVariationOn` on $[0,T]$ equal to $T$), and satisfies `tendsToInfinity`
  automatically since $|f(\gamma(t))| \to \infty$ forces $|\gamma(t)| \to \infty$
  ($f$ is bounded on every disc). Not compile-verified.
- Class of paths: `ArcLengthPath` (lines 23–29) — continuous $\gamma : \mathbb{R} \to
  \mathbb{C}$, $|\gamma(t)| \to \infty$, and unit-speed on $[0,\infty)$ in the
  `eVariationOn` sense. Quantifying the negative clause over this class instead of all
  rectifiable paths loses nothing: any rectifiable path to infinity with
  $f \to \infty$ and $\ell(r) \ll r$ arc-length reparameterizes to an `ArcLengthPath`
  with the same trace, the same $f \to \infty$ property, and the same $\ell(r)$
  (unit speed makes time-in-disc equal length-in-disc, with multiplicity — matching the
  informal "length of $\Gamma$ in the disc"). The domain being all of ℝ is inert: only
  $t \ge 0$ is constrained (`isArcLength`, `pathLengthInDisk`) or used (`atTop`), and
  any path on $[0,\infty)$ extends constantly to ℝ without affecting any field.
- $O(r)$ encoding: `∃ C R, ∀ r ≥ R, pathLengthInDisk γ r ≤ C * r` (line 60) is the
  standard "eventually $\ell(r) \le Cr$" reading of $\ell(r) \ll r$. $C$ and $R$
  unconstrained in sign is harmless (enlarging them preserves the bound).
- Open vs closed disc: the source's $\ell(r)$ counts length in $|z| < r$;
  `pathLengthInDisk` uses $\|\gamma(t)\| \le r$. For the $O(r)$ statement these agree:
  $\ell$ is monotone in $r$ and $\ell_{\mathrm{closed}}(r) \le
  \ell_{\mathrm{open}}(r+1)$, so each version of "$\ell(r) = O(r)$" implies the other
  (e.g. $\ell_{\mathrm{closed}}(r) \le C(r+1) \le 2Cr$ for $r \ge 1$). Not a defect;
  now documented in the v2 module docstring.
- With the fix, the statement is neither vacuous nor trivially false: it fails for
  every polynomial and for $e^z$ (a ray $\gamma(t) = te^{i\theta}$ has
  $\ell(r) = r$), and holds exactly by the Gol'dberg–Eremenko construction — a
  substantive theorem.
