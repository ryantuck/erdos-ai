## Summary

The problem (OPEN, no prize): is $\sum_{n\geq 2} \frac{1}{n!-1}$ irrational? The sum
converges (comparison with $\sum 2/n!$) to $\approx 1.2535$ (OEIS A331373), and its
irrationality is open; Erdős [Er88c] noted that $\sum 1/(n!+t)$ "should be
transcendental for every integer $t$" — the $t=-1$ instance would imply a "yes". The
Lean file asserts `Irrational (∑' (n : ℕ), if n < 2 then 0 else (1 : ℝ) /
(n.factorial - 1))` — a direct assertion of the conjectured affirmative direction,
which is this corpus's convention for open yes/no questions. Read back
independently, the tsum with its `if n < 2` guard is exactly $\sum_{n\geq 2}
1/(n!-1)$ in ℝ, term-for-term identical to the upstream formal-conjectures encoding
(which reindexes via `(n + 2).factorial` inside `answer(sorry) ↔ …`). I found no
semantic defects; only enrichment-level nits (encoding choice undocumented,
bibliography stubs, OEIS reference, and a page-confirmed Weisenberg-identity
variant), all addressed in `conjectures-v2/68.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement: "Is $$\sum_{n\geq 2}\frac{1}{n!-1}$$
  irrational?" The docstring (lines 11–14 of `conjectures/68.lean`) reproduces it
  and both page remarks accurately.
- Independent back-translation of line 17: "the real number
  $\sum_{n=0}^{\infty} t_n$ is irrational, where $t_n = 0$ for $n < 2$ and
  $t_n = 1/(n!-1)$ for $n \ge 2$." The guard `n < 2` excludes exactly $n \in
  \{0,1\}$, so the tsum is $\sum_{n\geq 2} 1/(n!-1)$ — the question's sum, with no
  index shift to reconcile (the tsum runs over all of ℕ with a guard rather than
  reindexing; upstream's `(n + 2).factorial` version describes the same series).
  First-term check: $n = 2$ gives $1/(2!-1) = 1$, matching the source's first term.
- Quantifier structure: none needed — a single closed-form real; nothing is
  universally or existentially quantified.
- Types: the sum is taken in ℝ (`(1 : ℝ)` forces real division and, via `binop%`
  elaboration, real subtraction of the cast `(↑n.factorial : ℝ) - 1`); `Irrational`
  is Mathlib's `x ∉ Set.range ((↑) : ℚ → ℝ)`. Appropriate throughout.
- Not vacuous/trivial: the series is summable ($1/(n!-1) \le 2/n!$ for $n \ge 2$),
  so `∑'` denotes the honest limit, a specific transcendental-candidate real
  $\approx 1.2535$, and `Irrational` of it is a genuinely open proposition. Had the
  series been divergent, `∑'` would junk-default to 0 and silently *falsify* the
  statement — checked explicitly per this batch's tsum/junk-value warning; it does
  not arise here.

**A2. Lean semantics traps — pass.**

- **ℕ subtraction:** `n.factorial - 1` sits under `(1 : ℝ) / ·`, so the `binop%`
  elaborator produces real subtraction of the cast, not truncated ℕ subtraction.
  Even under the ℕ-subtraction reading the values would coincide: for the guarded
  $n \ge 2$, $n! \ge 2$ so no truncation; for $n < 2$ the branch is dead.

- **`Finset.range` off-by-one:** not used; the `if n < 2` guard is the exact
  complement of $\{n \ge 2\}$. No off-by-one.
