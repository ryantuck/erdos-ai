## Summary

The problem (Erdős–Révész, source [Va99, 6.77]): for a random walk
s₀, s₁, … in ℤ² started at the origin, let f_n(x) count the 0 ≤ k ≤ n with
s_k = x and let F(n) = {x : f_n(x) = max_y f_n(y)} be the favourite sites;
find ℙ(|F(n)| = r infinitely often) for r ≥ 3. The page marks it SOLVED:
Tóth [To01] proved the probability is 0 for every r ≥ 4, and Hao, Li,
Okada, and Zheng [HLOZ24] proved it is 1 for r = 3. The Lean file
(`conjectures/1165.lean`) models the simple random walk via iid uniform
four-direction steps (`IsUniformStep` + `iIndepFun`), defines local time,
visited sites, maximum local time, and favourite sites (all exactly right,
including the subtle max-over-ℤ² vs max-over-visited-sites agreement), and
asserts the true resolution as a direct two-part conjunction: a.s.
|F(n)| = 3 i.o., and for each r ≥ 4 a.s. |F(n)| = r only finitely often.
The one defect is inherited verbatim from sibling 1164: nothing requires
`Measurable (X i)`, and the trivial-σ-algebra model on the path space
satisfies `IsUniformStep` and `iIndepFun` while making both parts false.
Fixed in v2 by adding `hMeas : ∀ i, Measurable (X i)`.

## A. Semantic fidelity

**A1. Statement fidelity — pass modulo the A2/A4-adjacent measurability
defect (source-verified).**

- Recovered verbatim source statement (see Addendum): "Given a random walk
  $s_0,s_1,\ldots$ in $\mathbb{Z}^2$, starting at the origin, let $f_n(x)$
  count the number of $0\leq k\leq n$ such that $s_k=x$. Let
  $F(n)=\{ x: f_n(x) = \max_y f_n(y)\}$ be the set of 'favourite values'.
  Find $\mathbb{P}(\lvert F(n)\rvert=r\textrm{ infinitely often})$ for
  $r\geq 3$." The theorem docstring (lines 46–57) reproduces this
  essentially verbatim (writing "favourite sites" for the page's "favourite
  values" — the standard literature term; harmless).
- "Random walk" is not qualified on the page; the formalization commits to
  the *simple* random walk (uniform nearest-neighbour steps). That is the
  standard reading of the Erdős–Révész favourite-site problem and the
  setting of both solving papers (each has "simple random walk" in its
  title). Right call; now documented in v2 (interpretation note 1).
- Term-by-term back-translation of the conclusion (lines 63–69): "(1) for
  μ-a.e. ω there are infinitely many n with |F(n)(ω)| = 3; (2) for every
  natural r ≥ 4, for μ-a.e. ω there are only finitely many n with
  |F(n)(ω)| = r." Encoding ℙ(E) = 1 as "E a.s." and ℙ(E) = 0 as "¬E a.s."
  is exact for measurable E (and the i.o. events here are measurable once
  `hMeas` is added: each {ω | |F(n)(ω)| = r} is a countable union of
  finite intersections of walk-position level sets, and i.o. = ⋂ₙ⋃_{m≥n}).
  Together the two parts state precisely the page's resolution for every
  r ≥ 3.
- **[defect] Missing measurability hypothesis: the theorem as stated is
  falsified by a degenerate model.** Neither `IsUniformStep` nor Mathlib's
  `iIndepFun` requires `Measurable (X i)`: `iIndepFun` is `iIndep` of the
  comap σ-algebras and constrains μ only through its outer-measure
  extension. Explicit countermodel (same as validated in the 1164 review
  of the identical `IsUniformStep`): Ω = D^ℕ with D the four steps,
  X i ω = ω i, the **trivial** σ-algebra {∅, Ω}, and its unique
  probability measure, under which every nonempty set has outer measure 1.
  Then `IsUniformStep` holds (the four nonempty step events all get outer
  measure 1 — *equal*, as the def demands), and `iIndepFun` holds (any
  finite intersection of nonempty coordinate-cylinder events across
  distinct coordinates is nonempty by the product structure, giving
  1 = 1·…·1; if any factor is empty, both sides are 0). But both
  conclusions fail: the always-right path (1,0), (1,0), … has all n + 1
  positions distinct, so every visited site has local time 1,
  F(n) = all visited sites, |F(n)| = n + 1 — equal to 3 only at n = 2,
  not i.o., so the Part-1 exceptional set is nonempty, hence of outer
  measure 1 ≠ 0. And the path cycling around the unit square
  (1,0), (0,1), (−1,0), (0,−1), … has all four corner sites tied at
  maximal local time at every n ≡ 3 (mod 4), so |F(n)| = 4 i.o. on a
  nonempty set — Part 2 fails at r = 4 too. With
  `hMeas : ∀ i, Measurable (X i)` added, the four step events partition Ω
  measurably, additivity forces probability 1/4 each, and the hypotheses
  pin down the walk's law as genuine iid uniform steps. **Fixed in v2.**
- Not vacuous: with `hMeas` the model class contains the canonical
  construction (product space, product σ-algebra, product measure), and
  the conclusion is the substantive Tóth/HLOZ resolution.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction and no division anywhere in the file.
- `Finset.range (n + 1)` = {0, …, n} in `localTime` and `visitedSites`
  exactly matches the source's 0 ≤ k ≤ n (positions S₀, …, S_n, with
  S₀ = origin as the empty sum in `walkPosition`). No off-by-one.
- `Finset.range n` in `walkPosition` gives S_n = X₀ + ⋯ + X_{n−1},
  S₀ = (0,0) — matches the docstring and the source's "starting at the
  origin".
- No vacuous bounded quantifiers: `r ≥ 4` is satisfiable; Part 2 is a
  genuine countable family of assertions. At n = 0, F(0) = {origin},
  |F(0)| = 1 — degenerate but harmless under i.o.
- `∃ᶠ n in atTop, P n` is exactly "infinitely many n" for ℕ, and
  `¬∃ᶠ` is "finitely often": the correct filter encodings.
- No `StrictMono`/`Monotone` or interval-endpoint issues arise.

**A3. Definitions — pass; two exactness subtleties verified and now
documented.**

- `walkPosition`, `localTime`, `visitedSites` match their docstrings and
  the source, including degenerate inputs (n = 0: one visited site, local
  time 1 at the origin). No `sorry` in any definition.
- `maxLocalTime` takes `Finset.sup` over *visited* sites while the source's
  max_y ranges over all y ∈ ℤ². These agree for every n and ω: the sup is
  ≥ localTime(origin at k = 0) ≥ 1... precisely, the origin (or S₀'s site)
  is visited with local time ≥ 1, so the visited-sup is ≥ 1, while every
  unvisited site has f_n = 0 < 1. `visitedSites` is never empty
  (`range (n+1)` is nonempty), so no `sup`-of-empty junk (`⊥ = 0`) is ever
  taken. Exact, not merely asymptotically so. Documented in v2.
- `favouriteSites` filters *visited* sites for f_n(x) = max, while the
  source's F(n) is {x ∈ ℤ² : f_n(x) = max}. Exact for the same reason:
  any x attaining the max (≥ 1) is visited. Documented in v2.
- Definitions are used consistently; no drift between defs and theorem.

**A4. Question form and answer polarity — acceptable form, correct
polarity.**

- The source is a **value request** ("Find ℙ(…) for r ≥ 3"). The checklist's
  canonical shape would be `… = answer(…)`; the raw file instead directly
  asserts the known resolution (probability 1 for r = 3 via "a.s. i.o.",
  probability 0 for each r ≥ 4 via "a.s. finitely often"). Per this

  solved problem is acceptable when the polarity is the true direction —

  attributions exactly, covering all r ≥ 3. No `answer()` appears, so no

- Quantifier placement in Part 2 (`∀ r, r ≥ 4 → ∀ᵐ ω`) reads "for each
  fixed r, a.s." — the natural reading of the source; the a.s.-uniform
  form `∀ᵐ ω, ∀ r ≥ 4` is equivalent here since a countable intersection
  of full-measure sets has full measure. Fine as stated.

## E. Prior-review audit (`deepmind/ai-review/1165.md`)

The prior review's low-level verification of the definitions is good, but
it spots the measurability gap and then argues itself out of it with two
false claims — the exact "wrong claims about Mathlib semantics" failure
pattern flagged for this pipeline (cf. the 1002 and 1164 audits):

1. **Identified the defect, then dismissed it with a wrong argument.** §5:
   "In practice, on the discrete σ-algebra of `ℤ × ℤ`, all functions are
   measurable, so this is not a mathematical issue." **Wrong on both
   counts.** Measurability of X i : Ω → ℤ × ℤ is a condition on the
   σ-algebra of **Ω**, which the theorem leaves as an arbitrary
   `[MeasurableSpace Ω]`; a discrete *codomain* σ-algebra makes
   measurability *harder* (every singleton preimage must be measurable in
   Ω), not automatic. And it *is* a mathematical issue: the theorem
   quantifies over all models, and the trivial-σ-algebra countermodel of
   §A1 falsifies it outright.
2. **False forcing claim.** §6: "Combined with `IsProbabilityMeasure`, the
   four equal-probability conditions force each step probability to be
   1/4." **Wrong without measurability**: additivity applies only to
   measurable sets; in the countermodel all four step events have outer
   measure 1, satisfying the equalities with total "mass" 4. The forcing
   argument is valid exactly when the events are measurable — i.e. it
   silently assumes the missing hypothesis.
3. **Consequently the verdict "mathematically correct and complete; no
   flaws identified" is wrong** — the statement as written is falsifiable.
4. **What it got right** (re-derived here): the `Finset.range (n+1)` visit
   counting and S₀ = (0,0) empty-sum conventions; `visitedSites`
   nonemptiness making the `sup` safe; the Part-2 quantifier-order remark,
   including the correct observation that the r-uniform form is equivalent
   by countability; that the two parts fully resolve r ≥ 3 with no missing
   variants (source-verified); that [To01]/[HLOZ24] attributions match the
   website; the [Va99] fabrication/inconsistency across the *styled*
   sibling files (verified from the upstream logs — "Vize, R." in styled
   1165, "Vershik, A." in 1164, "Varga, L." in 1166 — later fixed upstream
   to the canonical booklet citation); and the styled 1164/1166
   `answer(True) ↔ ∀ Ω…` pattern claim (verified: `deepmind/deepmind/
   1164.lean:79`, `1166.lean:96`). Note its [Va99] finding concerns the
   styled file — the raw file under review here contains no [Va99]
   expansion at all, so nothing needed excising.
5. **Omissions relative to this review:** the countermodel (it had all the
   ingredients in hand); the max-over-ℤ² vs max-over-visited exactness
   argument (it asserts `favouriteSites` "correctly filters" without
   noticing there is something to check); the unqualified-"random walk" →
   simple-random-walk modeling step; the Tóth-dimension attribution
   nuance.
