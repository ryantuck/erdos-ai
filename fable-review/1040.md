## Summary

The problem: for a closed infinite set $F \subseteq \mathbb{C}$, let $\mu(F)$ be the
infimum of the Lebesgue measure of $\{z : |f(z)| < 1\}$ over all monic polynomials
$f = \prod (z - z_i)$ with every root $z_i \in F$. The source asks **two** questions:
"Is $\mu(F)$ determined by the transfinite diameter of $F$? In particular, is
$\mu(F) = 0$ whenever the transfinite diameter of $F$ is $\geq 1$?" The status banner is
OPEN (this refers to the "in particular" question; the first question was answered *no*
by Aletheia [Fe26]). The Lean file (`deepmind/1040.lean`) builds the transfinite diameter
from scratch (`pairwiseDistProd` → `nthTransfiniteDiam` → `transfiniteDiameter`) and the
infimum `sublevelMeasure`, and states `erdos_1040 : answer(sorry) ↔ ∀ F, IsClosed F →
F.Infinite → transfiniteDiameter F ≥ 1 → ∀ Haar μ, sublevelMeasure F μ = 0` — a faithful,
correct rendering of the "in particular" question (subordinating the soft first question
to the concrete one mirrors the corpus's handling of 1039's "Determine … In particular
…"). The definitions are sound, including all degenerate cases I checked by hand. The
defect is completeness, not translation: the first question — a genuine part of the
problem, and a *solved* one — appeared nowhere in the file, and the [Fe26]/[ErNe73]
bibliography entries were dangling (defined but never explained in prose). Fixed by
restoring the full two-question statement, the remarks, and four page-confirmed variants.

## A. Semantic fidelity

**A1. Statement fidelity — pass for `erdos_1040` (source-verified); completeness defect
recorded under B2/A5.**

- Recovered verbatim source statement (see Addendum): "Let $F\subseteq \mathbb{C}$ be a
  closed infinite set, and let $\mu(F)$ be the infimum of $|\{ z: |f(z)| < 1\}|$, as $f$
  ranges over all polynomials of the shape $\prod (z-z_i)$ with $z_i\in F$. … Is
  $\mu(F)$ determined by the transfinite diameter of $F$? In particular, is $\mu(F)=0$
  whenever the transfinite diameter of $F$ is $\geq 1$?"
- Independent back-translation of the pre-fix `erdos_1040` RHS: "for every closed
  infinite $F$ with transfinite diameter $\geq 1$ and every additive Haar measure $\mu$
  on $\mathbb{C}$, the infimum over $n$ and root tuples $z \in F^{n+1}$ of
  $\mu\{w : \|\prod_i (w - z_i)\| < 1\}$ is $0$." This is exactly the "in particular"
  question. Term-by-term:
  - "closed infinite set" ↔ `IsClosed F ∧ F.Infinite` ✓;
  - "polynomials of the shape $\prod(z-z_i)$" ↔ monic products over `Fin (n+1)` —
    at least one factor, which matters: allowing the empty product $f = 1$ would give
    sublevel set $\emptyset$ and trivialize $\mu(F) = 0$ everywhere. The `Fin (n+1)`
    choice correctly excludes it (and is documented). Repeated roots allowed — the
    standard reading. ✓;
  - "Lebesgue measure" ↔ `∀ μ Haar` — a sound generalization: on $\mathbb{C} \cong
    \mathbb{R}^2$ every additive Haar measure is $c \cdot \mathrm{vol}$ with
    $c \in (0,\infty)$, infima scale by $c$, and $c x = 0 \iff x = 0$; so the
    $\forall$-Haar statement is equivalent to the Lebesgue statement. ✓ (now noted in
    the theorem docstring);
  - "transfinite diameter $\geq 1$" ↔ `transfiniteDiameter F ≥ 1` — exact for bounded
    $F$; for **unbounded** $F$ the encoding assigns $0$ (see A2), silently excluding
    them from the hypothesis although informally their transfinite diameter is $\infty
    \geq 1$. This does **not** change the truth value of the RHS: every unbounded $F$
    satisfies $\mu(F) = 0$ unconditionally — pick two roots $a, b \in F$ with
    $|a - b| = R$; if $\|(w-a)(w-b)\| < 1$ then $\min(|w-a|,|w-b|) < 2/R$ (else the
    product is $\geq R^2/4 > 1$), so the sublevel set sits in two discs of radius
    $2/R$, area $\leq 8\pi/R^2 \to 0$. Hence formal RHS ⟺ informal proposition. Encoding
    artifact, not a defect; now documented in `transfiniteDiameter`'s docstring.
- Not vacuous: the hypothesis class is nonempty (closed disc of radius 1 has
  transfinite diameter exactly 1) and the conclusion is a substantive open claim there.

**A2. Lean semantics traps — pass (each checked explicitly).**

- **ℕ subtraction:** none. The exponent `(2 : ℝ) / (↑n * (↑n - 1))` subtracts *after*
  casting to ℝ (for $n = 0$: $0 \cdot (-1) = 0$), so no truncation.
- **Division by zero:** for $n \in \{0, 1\}$ the exponent is $2/0 = 0$ (field
  convention), and `rpow x 0 = 1`, so `nthTransfiniteDiam F 0 = nthTransfiniteDiam F 1 =
  sSup {1} = 1` — junk, invisible to the `atTop` limit. Harmless; now documented.
- **`Real.sSup` junk:** for bounded infinite closed (= compact) $F$ and $n \geq 2$ the
  achieved-value set is nonempty ($0$ via a repeated tuple) and bounded above, so
  `sSup` is the true $d_n(F)$. For unbounded $F$, $n \geq 2$, the set is unbounded above
  and `Real.sSup` returns the junk value $0$ — so the $d_n$ sequence is $(1,1,0,0,\dots)$,
  which *converges to $0$*; consequences analyzed in A1 (harmless, documented).
- **`lim`:** `lim (atTop.map …)` is `Classical.epsilon`-junk only for non-convergent
  filters. Here the sequence always converges: for compact $F$, $d_n$ is the classical
  nonincreasing (for $n \geq 2$) sequence converging to $\rho(F)$; for unbounded $F$ it
  is eventually $0$. `atTop.map f` is NeBot and ℝ is T2, so `lim` returns the actual
  limit in every case reachable by the theorems. No junk leaks.
- **`Finset.range`/off-by-one:** the only indexing is `Fin (n+1)` for roots (degree
  $\geq 1$, correct, see A1) and the pair-filter `p.1 < p.2` over `Fin n × Fin n`,
  which enumerates each unordered pair exactly once — matching $\prod_{i<j}$. Exponent
  $2/(n(n-1)) = 1/\binom{n}{2}$ matches the page's definition. ✓
- **Vacuous quantifiers:** `⨅ (_ : ∀ i, z i ∈ F), …` contributes `⊤` for infeasible
  tuples — correct infimum encoding. `∀ i, z i ∈ F` over `Fin 0` never arises in
  `sublevelMeasure` (always `Fin (n+1)`).
- **Strict inequalities:** `‖…‖ < 1` matches the source's $|f(z)| < 1$; `≥ 1` matches
  "$\geq 1$". ✓

## E. Prior-review audit (`ai-review/1040.md`)

Mostly sound on the definitions (§6b n∈{0,1} junk, §6c infimum encoding, §6d Haar
scaling, §6e `answer(sorry)` shape all re-derived and confirmed), but four findings:

1. **Wrong Mathlib semantics in §6a (the 1002 failure pattern).** It claims that for
   unbounded $F$ "$d_n(F) \to \infty$ and the limit does not converge in ℝ. In this
   case, `transfiniteDiameter F` is a junk value, and the hypothesis
   `transfiniteDiameter F ≥ 1` may or may not hold." Wrong twice: `Real.sSup` of a set
   unbounded above is *definitionally* $0$, so the formalized $d_n(F)$ is $0$ for every
   $n \geq 2$ — not $\to \infty$; the sequence $(1,1,0,0,\dots)$ *converges*, `lim`
   returns exactly $0$, and the hypothesis definitively **fails** for every unbounded
   set. No indeterminate junk is involved. The practical conclusion (unbounded sets are
   mishandled but harmlessly so) survives, but by luck, not by its argument.
2. **Unsound repair argument in §6a.** "Unbounded F with transfinite diameter ≥ 1
   trivially satisfies the conclusion by a compactness argument (you can approximate
   with compact subsets)" — approximating $F$ by compact subsets $F_k$ gives
   $\mu(F) \leq \mu(F_k)$, but nothing forces $\mu(F_k) \to 0$ (a compact piece of an
   unbounded set can have transfinite diameter $< 1$ where the conclusion is not even
   conjectured); the argument is a non sequitur. The correct easy proof is the
   two-far-roots computation (sublevel set inside two discs of radius $2/R$), which
   also shows why the un-boundedness caveat matters for the *small-diameter* variant
   (see B2) — a consequence the prior review never explored.
3. **Missed the completeness defect.** The prior review *itself quotes* the page's first
   question and Aletheia's negative answer (its §2 and §3.3), yet never notices that the
   Lean file formalizes and even mentions only the second question, and never proposes
   restoring the dropped docstring sentence. Its §3.3 note "this does not resolve the
   main question about diameter ≥ 1" is correct but is used to file a *solved part of
   the problem statement* under "optional variants".
4. **Minor.** Its line citations refer to the upstream `ErdosProblems/1040.lean` paths;
   its §2 correctly flagged the missing [ErNe73]/[Fe26] references, and the upstream fix
   session added them (verified in the session log) together with the disc/segment
   variants it suggested — but the fix session left the references dangling in prose,
   so the flag was only half-resolved until now.

Also audited `reviews/1040.md` (style review): it predates the variants ("N/A: No
variants present") and asserts "The problem is a single yes/no question" — factually
false against the recovered source; its quotation of the problem reproduces the
