## Summary

The problem (erdosproblems.com/1097, verbatim from the recovered page): "Let $A$ be a
set of $n$ integers. How many distinct $d$ can occur as the common difference of a
three-term arithmetic progression in $A$? Are there always $O(n^{3/2})$ many such
$d$?" Posed by Erdős in the 1989 problem session of Great Western Number Theory
[GWNT89]; page status OPEN. The remarks record: Erdős–Ruzsa constructed sets achieving
$n^{1+c}$ differences, Erdős–Spencer achieved $n^{3/2}$ probabilistically, and Erdős
speculated $n^{3/2}$ best possible — **but** Chan observed (and the page states as an
exact equivalence) that the greatest achievable exponent equals the smallest constant
in Bourgain's sums-differences question [Bo99], for which the known bounds are
$1.77898\cdots \le c \le 11/6$ (Lemm [Le15] / AlphaEvolve [GGTW25]; Katz–Tao
[KaTa99]). Since $1.77898 > 3/2$, the answer to the yes/no question is **no**. The
Lean file defines `apDiffs A` — correctly, the finset of all $d$ with
$a, a+d, a+2d \in A$ for some $a$ — but its pre-fix theorem asserted the affirmative
$\exists C > 0,\ \forall A,\ |\mathrm{apDiffs}(A)| \le C\,|A|^{3/2}$: the refuted
direction. The original formalization session demonstrably had the full page (with the
Chan/Lemm remark) in context and asserted the affirmative anyway. Fixed by negation,
with the open residue (the exact exponent) and the page-confirmed partial results
documented and added as variants.

## A. Semantic fidelity

**A1. Statement fidelity — pass on content, defect on direction (see A4/A5).**

- `apDiffs` (`conjectures/1097.lean`, def at line 102 post-fix; lines 14–16 pre-fix):
  membership unfolds to "$d$ is a difference of two elements of $A$ **and**
  $\exists a \in A$ with $a+d, a+2d \in A$". The first conjunct is implied by the
  second ($d = (a+d) - a$ with both in $A$), so the `image`-then-`filter` realizes
  exactly $\{d : \exists a \in A,\ a, a+d, a+2d \in A\}$ as a `Finset` — the set of
  common differences of three-term APs in $A$. Faithful.
- Degenerate-$d$ conventions: the Lean set contains $d = 0$ whenever $A \neq \emptyset$
  (constant progression) and is symmetric under $d \mapsto -d$. Against a reading of
  the source that counts only nondegenerate (or only positive) differences, the Lean
  count differs by at most a factor of 2 plus 1, which cannot affect the truth of any
  statement of the form "$\exists C,\ \mathrm{count} \le C n^{3/2}$" (for $n \ge 1$,
  $n^{3/2} \ge 1$ absorbs the $+1$; the factor 2 folds into $C$) nor of its negation
  or of any power-type lower bound. Not a defect; now documented in the def docstring.
- Quantifier shape: "$\exists C > 0,\ \forall A$" is the right rendering of "always
  $O(n^{3/2})$" over all finite sets — the eventual-only form is equivalent here
  because small sets obey the trivial $n^2 \le N^{1/2} n^{3/2}$ bound for $n \le N$,
  so any eventual constant enlarges to a global one. Term-by-term exact, no indexing
  issues (no sequences involved).
- Not vacuous: both the affirmative and the negation are substantive; the empty and
  singleton sets satisfy the affirmative's inequality trivially but do not witness
  anything.

**A2. Lean semantics traps — pass.**

- All arithmetic on the set elements is in ℤ (`p.2 - p.1`, `a + 2 * d`): no ℕ
  truncation anywhere.
- `(3 : ℝ) / 2` is exact real division (= 1.5), not ℕ floor division — correctly
  parenthesized with the cast inside.
- `(A.card : ℝ) ^ ((3 : ℝ) / 2)` is `Real.rpow` on a nonnegative base. At
  `A = ∅`: `(0 : ℝ) ^ (3/2 : ℝ) = 0` and `apDiffs ∅ = ∅`, so the affirmative
  inequality reads $0 \le 0$ — consistent; the fixed negation is likewise unaffected.
- No `Finset.range`, no filters/limits, no `StrictMono`/`Monotone`, no vacuous bounded
  quantifiers.

**A3. Definitions — pass.**

- `apDiffs` matches its docstring and the source notion (checked above, including
  degenerate inputs: `apDiffs ∅ = ∅`, singleton gives `{0}`). No `sorry` in any def.
- `noncomputable` is likely unnecessary (the filter predicate is a decidable bounded
  existential over a `Finset` with decidable membership, and the pre-fix file compiled
  as-is in the original session), but harmless; compiler-dependent — deferred.

**A4. Question form and answer polarity — DEFECT (fixed).**

- The source's formalizable core is a **yes/no question** ("Are there always
  $O(n^{3/2})$ many such $d$?"). In this repo's raw style (cf.
  `conjectures/1004.lean`), open questions are stated as a direct assertion of the
  conjectured direction, and per the pipeline instructions direct assertion is
  acceptable raw style **if the polarity is the true direction; wrong polarity IS a
  defect**.
- The pre-fix theorem asserted the affirmative: $\exists C > 0,\ \forall A,\
  |\mathrm{apDiffs}(A)| \le C |A|^{3/2}$. Per the recovered page's own remarks this is
  **false**: the exact equivalence with Bourgain's sums-differences question plus
  Lemm's bound gives sets with $n^{1.77898 - o(1)} \gg n^{3/2}$ distinct differences.
  Re-derivation of the load-bearing transfer direction (sums-differences example
  $\Rightarrow$ 3AP-differences construction): given $G \subseteq A \times B$, let
  $S = 2A \cup (A \overset{G}{+} B) \cup 2B$; then
  $|S| \le 3\max(|A|,|B|,|A\overset{G}{+}B|) =: 3M$, and for each $(a,b) \in G$ the
  triple $2b,\ a+b,\ 2a \in S$ is an AP with difference $a - b$, so $S$ has at least
  $|A \overset{G}{-} B| \ge M^{c'}\ge (|S|/3)^{c'}$ distinct differences. A family
  witnessing Lemm's $c' = 1.77898$ (max sizes necessarily $\to \infty$) defeats every
  uniform $C n^{3/2}$ bound. **[defect]** — fixed by negating the statement
  (preserving the inner proposition verbatim under `¬`), per the 1054 precedent; not
  compile-verified.
- Polarity of the fix checked by hand: the negation is the true direction per the
  page; the docstring states the answer is NO and cites the chain of reasoning.
  The upstream artifact stays noncommittal (`answer(sorry) ↔ …`, recovered skeleton
  line 40), which is also sound; a bare affirmative assertion is not.
- No `answer()` machinery exists in raw files; no binders-before-colon issue arises
  (the theorem is binder-free).

**A5. Solution status — pass after fix (source-verified, with a nuance).**

- Page banner: **OPEN**, tooltip "This is open, and cannot be resolved with a finite
  computation.", plus the owner's standard disclaimer. The docstring's "(OPEN)" label
  was literally correct but misleading as attached to an affirmative assertion whose
  falsity the same page records. The fixed docstrings now say precisely this: the
  yes/no sub-question is answered NO by the page's remarks; the OPEN status refers to
  the headline value question — determine the optimal exponent, currently only known
  to lie in $[1.77898\cdots, 11/6]$. (Same page pattern as problem 1054: OPEN banner
  retained while the remarks refute one asked alternative.)
- The pre-fix docstring sentence "The conjecture is that this is the best possible"
  reported Erdős's 1989 speculation as if current, omitting that the page's remarks
  refute it — fixed.
