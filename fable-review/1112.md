# Fable Review: Erdős Problem 1112

**Verdict:** ACCEPT WITH NITS

## Summary

The problem (OPEN, [ErGr80, p.18], with the page's own caveat that it is "a generous
interpretation of a very ambiguous remark" of Erdős–Graham): for $1 \le d_1 < d_2$ and
$k \ge 3$, does there exist an integer $r$ such that every lacunary $B$ with
$b_{i+1} \ge r b_i$ is avoided ($(kA) \cap B = \emptyset$) by some positive sequence $A$
with consecutive gaps in $[d_1, d_2]$? Equivalently: does $r_k(d_1,d_2)$ (smallest such
$r$, per Bollobás–Hegyvári–Jin) exist? The Lean (`conjectures/1112.lean:35-43`) is a
direct assertion of the uniform *non-existence* direction: for all admissible
$(d_1,d_2,k)$ and every $r$, some ratio-$r$ lacunary $B$ meets the $k$-fold sumset of
every gap-bounded $A$. Read back independently, the quantifier structure, lacunarity and
gap encodings, and the sumset definition are all correct; the direction choice is the
only uniform rendering not already refuted (BHJ proved $r_3(2,3)$ does not exist, killing
the universal *existence* reading), is transparently flagged in the docstring, and follows
this corpus's raw-file convention for open questions. No Part A defect; the nits are
docstring/scholarship-level (loose attribution of $r_2(2,3)=2$, missing citation keys and
bibliography, missing interpretation caveat).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified), with an interpretation caveat.**

- Recovered verbatim source statement (see Addendum): "Let $1\leq d_1<d_2$ and
  $k\geq 3$. Does there exist an integer $r$ such that if $B=\{b_1<\cdots\}$ is a
  lacunary sequence of positive integers with $b_{i+1}\geq rb_i$ then there exists a
  sequence of positive integers $A=\{a_1<\cdots\}$ such that
  $d_1\leq a_{i+1}-a_i\leq d_2$ for all $i\geq 1$ and $(kA)\cap B=\emptyset$, where $kA$
  is the $k$-fold sumset?"
- Independent back-translation of lines 35–43: "for all $d_1 \ge 1$, $d_2 > d_1$,
  $k \ge 3$, and every $r$, there exists a strictly increasing positive $B$ with
  $B_{i+1} \ge r B_i$ such that every strictly increasing positive $A$ with
  $d_1 \le A_{i+1} - A_i \le d_2$ has $kA \cap B \ne \emptyset$." This is exactly
  "$r_k(d_1,d_2)$ exists for no admissible parameters" — the negation of the question's
  existential, uniformized over parameters, with the inner negation
  $\lnot(\forall B\,\exists A\,\text{avoid})$ correctly converted (classically) to
  $\exists B\,\forall A\,\text{hit}$, and $(kA)\cap B\neq\emptyset$ correctly rendered as
  `∃ n, n ∈ kFoldSumset k (Set.range A) ∧ n ∈ Set.range B`.
- **The interpretation question.** The source is a parameterized yes/no question, and its
  answer *varies with parameters*: the universal existence reading is refuted
  ($r_3(2,3)$ does not exist, [BHJ97], confirmed on the page), yet the page banner is
  OPEN, and the remarks pin down what is open: "The more general question of existence of
  $r_k(a,b)$ for $k\geq 3$ remains open." So no single truth-valued statement is "the"
  problem. The raw file's choice — assert uniform non-existence — is the only
  universally-quantified direction consistent with all known results (every known
  $k \ge 3$ result is a non-existence result: BHJ for $(2,3)$, Tang–Yang's "further
  technical non-existence results"), and the docstring flags the choice explicitly
  (lines 28–31: "We state the non-existence direction (consistent with all known
  results)"). Under this corpus's raw-file convention for open questions (direct
  assertion of the evidenced direction with a docstring note — cf.
  `conjectures-v2/1060.lean`, `1061.lean`, `1054.lean`), this is acceptable, not a
  defect. It *is* an interpretive strengthening: if some $r_k(d_1,d_2)$ exists, the
  statement is false — now documented prominently in the v2 docstrings (fix 1).
- Indexing: source 1-indexed ($b_1, a_1$), Lean 0-indexed; gap condition
  $d_1 \le a_{i+1}-a_i \le d_2$ for $i \ge 1$ ↔ `∀ i : ℕ, … A (i+1) - A i …` is
  term-by-term exact under $a_{i} = A(i-1)$. Same for $b_{i+1} \ge r b_i$.
- Not vacuous, not trivially false: witnesses $A$ satisfying the hypotheses exist
  (e.g. $A_i = 1 + i d_1$), so the inner `∀ A` is not vacuous; for $r \ge 2$ the
  existential over $B$ demands a genuinely lacunary sequence, so the claim is
  substantive. (For $r \le 1$ the instance is trivially true via $B = $ all positive
  integers — harmless easy instances of a universal statement, matching the fact that
  the integer ratio $r=1$ can never suffice for avoidance.)

**A2. Lean semantics traps — pass.**

- ℕ subtraction: `A (i + 1) - A i` truncates, but as a *hypothesis* bounded below by
  `d₁ ≥ 1` it forces `A (i+1) ≥ A i + d₁`, so no silent truncation can weaken the
  statement; `StrictMono A` is then formally redundant (harmless, aids clarity). The
  upper bound `A (i + 1) - A i ≤ d₂` reads correctly for strictly increasing `A`.
- No division anywhere. No `Finset.range`, so no off-by-one. No filter encodings needed
  ("lacunary" is a pointwise growth condition, encoded pointwise).
- Vacuous bounded quantifiers: none (`∀ i` over all of ℕ, first index included exactly
  as in the source).
- `StrictMono` vs `Monotone`: `StrictMono` matches $b_1 < b_2 < \cdots$ and
  $a_1 < a_2 < \cdots$. For `B` with `r ≤ 1` the ratio condition alone would not force
  strictness, so the explicit `StrictMono B` is doing real work — correct.
- `r * B i ≤ B (i + 1)` correctly models $b_{i+1} \ge r b_i$ with no subtraction or
  division. `r : ℕ` vs the source's "integer $r$": negative $r$ impose weaker
  conditions subsumed by $r = 0$, so ℕ loses nothing.

**A3. Definitions — pass.**

- `kFoldSumset` (lines 8–10) matches its docstring and the standard $k$-fold sumset
  (repetitions allowed): `kFoldSumset 0 S = {0}`, and by induction
  `kFoldSumset 1 S = {a + 0} = S`, `kFoldSumset k S = {s₁ + ⋯ + s_k : sᵢ ∈ S}`. The
  degenerate `k = 0` case is never used (`hk : 3 ≤ k`; variants use `k = 2, 3`).
  Behavior on `S = ∅` (`kFoldSumset (k+1) ∅ = ∅`) is irrelevant since `Set.range A` is
  never empty. No `sorry` in any definition; no drift between the def and its uses.

**A4. Question form and answer polarity — pass under the raw-file convention (judgment
call, documented).**

- The source is a yes/no question, so a styled encoding would be `answer(…) ↔ P` — but
  the literal universal `P` ("for all admissible $(d_1,d_2,k)$, $\exists r$…") is
  **provably false** by BHJ, so `answer(sorry) ↔ (∀ params, ∃ r, …)` would mislabel a
  decided statement as open (this is precisely the trap the styled
  `deepmind/deepmind/1112.lean` originally fell into; see Part E), and
  `answer(False) ↔ …` resolves a problem the site marks OPEN by silently narrowing it to
  its refuted literal reading. A faithful `answer()` form would have to be
  per-parameter, which plain-Mathlib raw files cannot express (`answer` is a
  formal-conjectures elaborator).
- Given that, the raw file's direct assertion of the uniform non-existence direction is
  the corpus-conventional encoding, its polarity is *not refuted* by anything known, its
  $(2,3,3)$ instance is a theorem of [BHJ97], and the choice is declared in the
  docstring. Verified by hand: proving the statement would answer the source question
  "no, for every admissible parameter choice" — a genuine resolution of the general
  question the page calls open.
- Binders before the colon are correct here: this is a direct assertion (universal
  quantification intended), not an `answer()` iff.

**A5. Solution status — pass (source-verified).**

- Recovered banner: **OPEN**, tooltip "This is open, and cannot be resolved with a
  finite computation." The docstring's "(Open)" (line 13) and its known-results summary
  agree with the page's remarks. The statement formalized is not a refuted direction
  (A4). One nuance now documented in v2: the $(2,3,3)$ *instance* of the open universal
  statement is solved [BHJ97].

**C2. Reuse — flagged, deliberately not applied.**

- `kFoldSumset k S` coincides with the `AddMonoid (Set ℕ)` iterated-sumset action
  (`k • S` under `open Pointwise`, the additive counterpart of `Set.pow`). The swap is
  *not* made: for ℕ scalars `•` on sets sits in documented tension with the pointwise
  scalar action (dilation `{k * s}`), a known Mathlib footgun; resolving which instance
  elaborates requires a compiler this container lacks. The local definition is
  unambiguous and self-contained. (See also Part E on the prior review's version of
  this suggestion.)

   Chen's $r_2(a,2a) \ge 2$ (and $r_2(2,3) = 2$ with its lower half) as solved

6. **What it got right besides (1):** the missing `[ErGr80]` page number (p.18); the
