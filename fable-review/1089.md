## Summary

The problem (a question of Kelly, from [Er75f, p.105]): let $g_d(n)$ be minimal such that
every collection of $g_d(n)$ points in $\mathbb{R}^d$ determines at least $n$ many
distinct distances; estimate $g_d(n)$ — in particular, does
$\lim_{d\to\infty} g_d(n)/d^{n-1}$ exist? The page status is **SOLVED**: for $n \ge 2$,
$\binom{d+1}{n-1}+1 \le g_d(n) \le \binom{d+n-1}{n-1}+1$ (lower bound Aletheia [Fe26],
upper bound Bannai–Bannai–Stanton [BBS83]), whence the limit exists and equals
$1/(n-1)!$. The Lean file (`deepmind/1089.lean`) defines the distinct-distance count of a
finite point set and $g$ via `sInf`, and states
`answer(True) ↔ ∀ n, 2 ≤ n → Tendsto (g d n / d^(n-1)) atTop (nhds (1/(n-1)!))`. Read
back independently, the Lean matches the resolved question with correct polarity; I found
no semantic defect. The one genuine artifact defect is scholarly: the theorem docstring
credited the lower bound to "Aletheia-Zomlefer", a surname that appears in **no** archived
source — the page and every sibling file say "Aletheia [Fe26]". Fixed.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $g_d(n)$ be minimal such that
  every collection of $g_d(n)$ points in $\mathbb{R}^d$ determines at least $n$ many
  distinct distances. Estimate $g_d(n)$. In particular, does
  $\lim_{d\to\infty} g_d(n)/d^{n-1}$ exist?"
- Independent back-translation of lines 85–89: "the answer is yes iff for every
  $n \ge 2$, $g_d(n)/d^{n-1} \to 1/(n-1)!$ as $d \to \infty$." This is the resolved form
  of the asked limit question, restricted to $n \ge 2$ exactly as the page's resolution
  is ("whence, for $n\geq 2$, $\lim = 1/(n-1)!$"). The restriction loses only degenerate
  cases: $g_d(1) = 2$ for every $d \ge 1$ (two points give one distance), so at $n=1$
  the ratio is constantly $2$ — the limit exists but equals $2 \ne 1/0! = 1$; the page's
  own value claim is likewise stated only for $n \ge 2$. Faithful scope.
- `g` (lines 70–72): `sInf {m | ∀ S, S.card ≥ m → distinctDistanceCount S ≥ n}`. The
  source's "every collection of $g_d(n)$ points" is an exact-cardinality reading; the
  Lean uses `card ≥ m`. These define the same set: the `≥` predicate is trivially implied
  by itself for larger sets, and the `=` predicate implies the `≥` predicate because
  `distinctDistanceCount` is monotone under `⊆` (`offDiag` and `image` are monotone), so
  any set of $\ge m$ points contains an $m$-subset already forcing $n$ distances. Both
  predicates carve out the same upward-closed set of $m$, and `sInf` picks its minimum:
  exactly the informal $g_d(n)$.
- Well-definedness of the `sInf` (non-junk): for $d \ge 1$ the defining set is nonempty
  by the [BBS83] bound (any $(n-1)$-distance set in $\mathbb{R}^d$ has at most
  $\binom{d+n-1}{n-1}$ points, so $m = \binom{d+n-1}{n-1}+1$ qualifies); for $d = 0$ the
  space `EuclideanSpace ℝ (Fin 0)` is a subsingleton, every `Finset` has card $\le 1$,
  and $m = 2$ qualifies vacuously, giving $g\,0\,n = 2$ for $n \ge 1$ — a degenerate but
  well-defined value, invisible to the `atTop` limit.
- Not vacuous or trivially false: the RHS is the substantive resolved asymptotic; no
  degenerate witness satisfies it trivially.

**A2. Lean semantics traps — pass.**

- ℕ subtraction: every `n - 1` (exponent, factorial) sits under the hypothesis
  `2 ≤ n`, so no truncation occurs where it matters (`n - 1 ≥ 1`).
- Division: `(g d n : ℝ) / (d : ℝ) ^ (n - 1)` divides by zero at `d = 0` (since
  $0^{n-1}=0$ for $n \ge 2$), yielding `0` by field convention — harmless under the
  `atTop` filter, which ignores finitely many indices.
- No `Finset.range` appears; no off-by-one surface.
- No vacuous bounded quantifiers in the theorem; the vacuity in `g 0 n` (no sets of
  card $\ge 2$ in a subsingleton space) is analyzed above and harmless.
- Filter encoding: `Tendsto _ atTop (nhds L)` is the standard, correct encoding of the
  limit existing and equalling $L$.
- No `StrictMono`/`Monotone` or interval-endpoint issues arise.

**A3. Definitions — pass.**

- `distinctDistances` (lines 61–62): `S.offDiag.image (fun pq => dist pq.1 pq.2)` — the
  set of distances over ordered pairs of *distinct* elements of `S`. Distinct elements of
  a `Finset` over `EuclideanSpace ℝ (Fin d)` are genuinely distinct points of a metric
  space, so all collected distances are positive (self-distance 0 correctly excluded);
  symmetric duplicates are deduplicated by the `Finset` image. Matches its docstring and
  the standard meaning. Degenerate inputs: `∅` and singletons give `∅`, count 0 —
  correct.
- `distinctDistanceCount`, `g`: match their docstrings; the `g` docstring says "any
  collection of that many points", consistent with the `card ≥ m` encoding per the A1
  argument. No `sorry` in any definition; no drift between defs and theorem usage.

**A4. Question form and answer polarity — pass, one remark.**

- The source is a yes/no question ("does $\lim$ exist?"), so `answer(…) ↔ P` is the right
  shape; the problem is solved affirmatively, so `answer(True)` has the right polarity.
  Verified by hand: RHS true ⟺ the limit exists (with the known value) for all
  $n \ge 2$ ⟺ the question's answer is "yes". Both sides are established facts.
- Remark (not a defect): the RHS is *stronger* than the literal question — it pins the
  limit's value $1/(n-1)!$ rather than asserting bare existence
  (`∃ L, Tendsto … (nhds L)`). For a solved value-bearing question this is the corpus's
  standard and more informative encoding (the page itself states the value), and it
  entails the literal "yes". Noted for the record.
- No binders before the colon (line 85: `theorem erdos_1089 :` is binder-free), so the
  iff is not spuriously universally quantified. The raw first pass had `(n) (hn)` as
  theorem binders on a direct assertion; the restyling correctly moved them inside the
  iff when introducing `answer(True)` (the drift flagged by `reviews/1089.md` §6 was
  fixed).

**A5. Solution status — pass (source-verified).**

- Recovered page banner: **SOLVED** (tooltip: "This has been resolved in some other way
  than a proof or disproof."). `@[category research solved]`, module docstring, and
  theorem docstring all agree. Attribution chain (question of Kelly; lower bound
  Aletheia [Fe26]; upper bound Bannai–Bannai–Stanton [BBS83]) matches the page after the

## E. Prior-review audit (`ai-review/1089.md`)

Sound on the Lean semantics, but its citation section is wrong on the facts, and one
justification is unsound:

1. **False claims about the source's citations.** It asserts: "the website does not use
   this citation key [[Fe26]] … the website simply credits 'Aletheia' without a bracketed
   reference," and "The website does not provide this citation key either [[BBS83]]."
   Both claims are **false**: the recovered page cites the lower bound as
   "Aletheia [Fe26]" and the upper bound as "Bannai, Bannai, and Stanton [BBS83]" with
   exactly those bracketed keys (each wired to the site's `/bibs/` loader), and the
   `/latex/1089` fetch in the pipeline logs carries full entries for both. This is the
   recurring "claiming data is unavailable that is in fact recoverable" failure pattern
   (cf. the 1001 audit) — and it led the prior review to recommend possibly *dropping*
   a correct key.
2. **Missed the actual citation defect.** While disputing the key, it repeated the
   fabricated name "Aletheia-Zomlefer" from the docstring uncritically — even writing
   "the website refers to this person as 'Aletheia'" in the same bullet — and never
   flagged that "Zomlefer" is unattested anywhere. The one real scholarship error in the
   artifact went unreported.
3. **Unsound nonemptiness justification (right conclusion).** For the `sInf` it argues
   the defining set is nonempty for $n \ge 2$ "(take enough points in general
   position)". That argument is backwards: membership requires *every* large set to
   determine many distances, not that *some* well-chosen set does; general-position
   examples prove nothing about worst-case sets. The correct justification is the
   [BBS83] $s$-distance bound (any set with more than $\binom{d+n-1}{n-1}$ points has
   $\ge n$ distances). It also missed the $d = 0$ subsingleton case, where nonemptiness
   holds by vacuity with junk-free value $g\,0\,n = 2$. Same fabricated-justification
   class as the 1000/1005 audits.
4. **Minor.** Its attribution list for the small cases ("$g_1(3)=4$, $g_2(3)=6$,
   $g_3(3)=7$ due to Croft") reads as crediting all three to Croft; the page credits
   Croft only with $g_3(3)=7$ ($g_1(3)=4$ is "trivial", $g_2(3)=6$ "easy").

What it got right: the `offDiag` reuse recommendation (subsequently applied); the
positive-distance argument for distinct `Finset` elements; the `d = 0` division-by-zero
analysis; the `answer(True)` polarity endorsement; and the observation that the binomial
bounds would make worthwhile standalone statements (now added as variants).
