## Summary

The problem (recovered verbatim): "Does there exist $B\subset\mathbb{N}$ which
is not an additive basis, but is such that for every set
$A\subseteq\mathbb{N}$ of Schnirelmann density $\alpha$ and every $N$ there
exists $b\in B$ such that
$\lvert (A\cup (A+b))\cap \{1,\ldots,N\}\rvert\geq (\alpha+f(\alpha))N$ where
$f(\alpha)>0$ for $0<\alpha<1$?" [Er56, p.136]. The archived page (2026-03-05)
said OPEN, but the teorth/erdosproblems mirror (commit a09c7a21, 2026-08-14)
records **proved (Lean)** as of 2026-05-01, and upstream
formal-conjectures (commit dd1c2beb) marks it `research solved` with
`answer(True)`: a sparse random set $B$ works, with
$f(\alpha)\gg\alpha(1-\alpha)^2$ (solution by GPT 5.5 Pro, prompted by
gebyjaff, cleanup by Liam Price; Lean proof linked from the site's forum
thread). The Lean file asserts exactly the affirmative: ∃ B not an additive
basis ("at most k elements" convention), ∃ f positive on (0,1), such that
∀ A, ∀ N ≥ 1, ∃ b ∈ B with
|(A ∪ (A+b)) ∩ [1,N]| ≥ (α + f(α))·N where α is A's Schnirelmann density. Read
back independently, the Lean and the English agree term-for-term, the quantifier
order (f fixed before A, as intended) matches, and the direct-assertion form
carries the **true** polarity of the now-solved question. No semantic defects.

## A. Semantic fidelity

**A1. Statement fidelity — pass.**

- Independent back-translation of `conjectures/38.lean:44-52`: "There is a set
  B ⊆ ℕ such that (i) no k makes every natural number a sum of at most k
  elements of B, and (ii) some f : ℝ → ℝ, positive on (0,1), satisfies: for
  every A ⊆ ℕ and every positive integer N there is b ∈ B with
  #{m ∈ [1,N] : m ∈ A ∪ (A+b)} ≥ (d_s(A) + f(d_s(A)))·N." This is exactly the
  question's property, asserted affirmatively.
- Quantifier structure: `∃ B, ¬basis ∧ ∃ f, positivity ∧ ∀ A ∀ N ∃ b` — the
  single function f is attached to B and fixed *before* A and N, which is the
  intended (stronger) reading of the source's trailing "where f(α)>0 for
  0<α<1"; upstream formal-conjectures encodes the identical quantifier order.
- `∀ N : ℕ+` renders the source's "every N" (implicitly N ≥ 1, since the page
  divides by N in the density and counts {1,…,N}). Upstream uses `N : ℕ`
  including the vacuous N = 0 case (both sides 0); the two are equivalent in
  content, and the input's choice is the tighter match to the source.
- Types: counting in `Finset` (`Finset.Icc 1 N |>.filter (· ∈ A ∪ …)`), cast to
  ℝ before comparison with `(α + f α) * N` — arithmetic happens in ℝ throughout.
  `(· ∈ A ∪ translateSet A b)` parses as membership in the union (∪ binds
  tighter than ∈). Correct.
- Indexing: `Finset.Icc 1 N` = {1,…,N} exactly matches the source's
  $\{1,\ldots,N\}$; no 0-vs-1 shift anywhere (`Finset.range` is not used).
- Not vacuous/trivial: B = ∅ fails (the inner `∃ b ∈ B` needs a witness);
  B = {0} fails (b = 0 gives A ∪ (A+0) = A, and for A attaining ratios
  arbitrarily close to its density α ∈ (0,1) the fixed gain f(α) > 0 is
  violated). f is unconstrained at α ∈ {0, 1}, exactly as the source's
  "f(α)>0 for 0<α<1" prescribes — the prover may take f ≤ 0 there, and the
  A-of-density-0 cases become trivial *by design of the source*, not by an
  encoding slip. The statement has genuine content (and is now a theorem).

**A2. Lean semantics traps — all pass.**

**A3. Definitions — pass.**

- `schnirelmannDensity` (lines 11-12) matches its docstring and the page's
  displayed definition $d_s(A)=\inf_{N\geq 1}|A\cap\{1,\ldots,N\}|/N$; it also
  coincides with Mathlib's `schnirelmannDensity`
  (`Mathlib/Combinatorics/Schnirelmann.lean:55`, `⨅ n : {n // 0 < n},
  #{a ∈ Ioc 0 n | a ∈ A} / n` — `Ioc 0 n = Icc 1 n` on ℕ), which is what
  upstream formal-conjectures uses for this very problem. Degenerate inputs:
  A = ∅ gives 0; A ⊇ ℕ≥1 gives 1. Sound.
- `kFoldSumset` (lines 17-19): by induction, `kFoldSumset B k` is exactly the
  set of sums of at most k elements of B with repetition (base: {0} = the empty
  sum; step: (sums of ≤ k) + one element, unioned with sums of ≤ k). Matches
  its docstring. Degenerate: k = 0 gives {0}, correct for "at most 0 elements".
- `IsAdditiveBasis` (lines 25-26): ∃ k, ∀ n, n ∈ kFoldSumset B k — the "at
  most k" (weak/Schnirelmann) basis convention. This is the right convention
  here: upstream's file notes explicitly that in [Er56] (top of p. 135) Erdős
  uses "sum of at most k elements", and upstream's `Set.IsWeakAddBasis`
  (`FormalConjecturesForMathlib/Combinatorics/Additive/Basis.lean:208-212`,
  additivized `∃ n, ∀ a, ∃ m ≤ n, a ∈ A ^ m`) is extensionally the same
  predicate.
- `translateSet` (lines 31-32): {a + b | a ∈ A} = A + b. Matches docstring and
  the page's $A + b$.
