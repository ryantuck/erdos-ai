## Summary

The problem (erdosproblems.com/1038, OPEN, [EHP58, p.131]): determine the infimum
and supremum of $\lvert\{x \in \mathbb{R} : |f(x)| < 1\}\rvert$ as $f$ ranges over
all non-constant monic real polynomials with all roots real and in $[-1,1]$. Known:
$\sup = 2\sqrt{2}$ (solved; Tao, Dec 2025 per the upstream file), and
$2^{4/3} - 1 \le \inf \le 1.835\cdots$ (open). The Lean file defines the class
(`MonicRealRootsInUnitInterval`) and the sublevel measure, then (pre-fix) stated
two theorems: $\left(\bigsqcup f,\ \text{measure}\right) = 2\sqrt2$ — correct and
the true solved direction — and $\left(\bigsqcap f,\ \text{measure}\right) > 0$ — a
true but severely weakened stand-in for the open infimum half, with no docstring
and no source for the bound. The definitions and the sup statement are faithful;
the infimum treatment is the sole defect (a regression: an earlier pipeline session
had already written and *compiled* the real bounds, and a later session overwrote
them). Fixed in place per Step 4.

## A. Semantic fidelity

**A1. Statement fidelity — pass after fix (source-verified).**

- Recovered verbatim source statement (see Addendum): "Determine the infimum and
  supremum of $\lvert\{x\in\mathbb{R} : \lvert f(x)\rvert < 1\}\rvert$ as
  $f\in\mathbb{R}[x]$ ranges over all non-constant monic polynomials, all of whose
  roots are real and in the interval $[-1,1]$."
- Independent back-translation of the class definition (`conjectures/1038.lean`,
  `MonicRealRootsInUnitInterval`): monic, degree ≥ 1 (non-constant — correct:
  `natDegree ≥ 1` ⟺ non-constant), splits into linear factors over ℝ (see A2 on
  `f.Splits`), every real root in $[-1,1]$ (closed interval, matching the source).
  Monic + Splits + root-location jointly force $f = \prod (x - r_i)$ with all
  $r_i \in [-1,1]$ — exactly the intended class. The `Splits` conjunct is
  essential: without it, e.g. $x^2+1$ would enter vacuously through the
  real-roots-only quantifier. Present and correct.
- Sup theorem back-translation: "the supremum over the class of the Lebesgue
  measure of $\{x : |f(x)|<1\}$ equals $2\sqrt2$" — exactly the solved supremum
  half (see A2 for why the `=` sits *outside* the `⨆`). Value verified against the
  page ($\sup = 2\sqrt2 \approx 2.828$). Not vacuous: the class is nonempty and
  the sup is even attained — $f(x)=x^2-1$ has sublevel set
  $(-\sqrt2,\sqrt2)\setminus\{0\}$ of measure exactly $2\sqrt2$ (reviewer
  computation: $|x^2-1|<1 \iff 0<x^2<2$).
- Inf theorem (pre-fix): $(\inf > 0)$ is true (it follows from the page's bound
  $\inf \ge 2^{4/3}-1 \approx 1.519$) and genuinely a statement about the infimum
  (not per-polynomial trivia — see A2), but it is **not** the problem, **not** any
  bound stated on the page, and strictly weaker than what was already formalized
  and compiled in this repo by the earlier session (see Addendum). **[defect]**
  under A1/B2: the open half of a two-part "determine" problem was reduced to an
  unsourced consequence with no docstring. Fixed: added the page's actual best
  bounds (`erdos_problem_1038_inf_lower`, `erdos_problem_1038_inf_upper`) and the
  [EHP58]-citable `inf < 2` (`erdos_problem_1038_inf_lt_two`); the positivity
  statement retained with a docstring marking it as a weak consequence.

**A2. Lean semantics traps — pass (two traps investigated in depth, both benign).**

- **`f.Splits` with no ring hom is correct at this repo's Mathlib.** Mathlib's
  classical `Polynomial.Splits (i : K →+* L) (f : K[X])` would make bare
  `f.Splits` ill-typed, and an intermediate draft indeed used
  `Splits (RingHom.id ℝ) f` — which *failed to build*. The authoring session's
  build log (recovered; see Addendum) shows this repo's Mathlib (Lean 4.28.0)
  has the newer one-argument predicate
  `def Splits (f : R[X]) : Prop := f ∈ Submonoid.closure ({C a | a : R} ∪ {X + C a | a : R})`,
  i.e. products of constants and monic linear factors over the *base ring* — for
  monic $f$ over ℝ exactly "all roots real". The final file **built successfully**
  with only `sorry` warnings. Correct as written.
- **`⨆ f ∈ S, sublevelMeasure f = c` parses as `(⨆ …) = c`, not as a Prop-valued
  sup of equations.** Mathlib's `⨆`/`⨅` `notation3` parses the body at precedence
  60, while `=`/`<`/`>` sit at 50, so the binder body stops before the relation
  (this is what makes Mathlib's own `iSup_const : ⨆ _ : ι, a = a` a sane
  statement). Both theorems therefore mean the intended lattice statements; there
  is no hidden `∃ f ∈ S, …`/`∀ f ∈ S, …` reading. (Had the binder swallowed the
  relation, the sup theorem would have asserted attainment and the inf theorem
  would have been per-polynomial trivial; neither occurs.)
- Measure arithmetic in `ℝ≥0∞`: no subtraction/division anywhere; `ENNReal.ofReal
  (2 * Real.sqrt 2)` is the right embedding (argument ≥ 0). Sublevel sets are
  open, hence measurable; for $f$ in the class $\{|f|<1\} \subseteq [-3,3]$
  (for $|x|\ge 3$, $|f(x)| = \prod|x-r_i| \ge 2$), so all measures are finite.
- Strict `<` in `{x | |f.eval x| < 1}` matches the source's $|f(x)| < 1$; closed
  $[-1,1]$ via `-1 ≤ r ∧ r ≤ 1` matches the source's closed interval.
- No ℕ subtraction, no division, no `range`, no vacuous bounded quantifiers; the
  class is nonempty (e.g. $X$), so `⨆`/`⨅` junk values for empty families do not
  arise.

**A3. Definitions — pass.**
