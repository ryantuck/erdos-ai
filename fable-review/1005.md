## Summary

The problem: let $a_1/b_1, a_2/b_2, \ldots$ be the Farey fractions of order $n \ge 4$,
and let $f(n)$ be the largest integer such that whenever $1 \le k < l \le k + f(n)$ the
fractions $a_k/b_k$ and $a_l/b_l$ are similarly ordered, i.e.
$(a_k - a_l)(b_k - b_l) \ge 0$. Estimate $f(n)$ — in particular, **is there** a constant
$c > 0$ with $f(n) = (c + o(1))n$? The status on the source page is OPEN. The Lean file
defines the Farey list, the similarly-ordered relation (in ℤ arithmetic on `Rat.num`/
`Rat.den`), and $f(n)$ via `sSup`, and its `Tendsto (f n / n) atTop (nhds c)` existence
statement is a faithful rendering of the asked limit. The definitions are correct,
including degenerate cases; the one semantic defect is that the source asks a **yes/no
question** while `erdos_1005` was encoded as a **direct assertion** (no
`answer(sorry) ↔` wrapper), contrary to the checklist's A4 and this corpus's uniform
convention (`deepmind/657.lean`, `deepmind/1053.lean`, etc.). The raw first pass's
docstring even phrased it as a question ("Is there a constant $c>0$…?"); the restyling
drifted it into an assertion.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified), one form defect deferred to A4.**

- Recovered verbatim source statement (see Addendum): "Let $\frac{a_1}{b_1},
  \frac{a_2}{b_2},\ldots$ be the Farey fractions of order $n\geq 4$. Let $f(n)$ be the
  largest integer such that if $1\leq k<l\leq k+f(n)$ then $\frac{a_k}{b_k}$ and
  $\frac{a_l}{b_l}$ are similarly ordered - in other words, $(a_k-a_l)(b_k-b_l)\geq 0$.
  Estimate $f(n)$ - in particular, is there a constant $c>0$ such that
  $f(n)=(c+o(1))n$ for all large $n$?"
- Independent back-translation of the pre-fix theorem (`deepmind/1005.lean`): "there is a
  positive real $c$ with $f(n)/n \to c$." Since $f(n) = (c+o(1))n$ for large $n$ is
  definitionally $f(n)/n - c = o(1)$, i.e. $f(n)/n \to c$, the RHS matches the question's
  content exactly. The "Estimate $f(n)$" preamble is the usual soft framing; formalizing
  the specific "in particular" question is correct scope.
- `fareyFractions n` (lines 55–58): denominators $b \in [1, n]$ (`Icc 1 n`), numerators
  $a \in \{0, \dots, b\}$ (`range (b+1)`), coprimality filter, image $a/b$ in ℚ, sorted
  ascending. This is exactly $F_n$ including $0/1$ and $1/1$: `Nat.Coprime 0 b ↔ b = 1`
  so $0$ enters once (as $0/1$); `Nat.Coprime b b ↔ b = 1` so $1$ enters once (as $1/1$);
  distinct coprime pairs give distinct rationals, and the `Finset` image dedups by value
  anyway. Length $= 1 + \sum_{b\le n}\varphi(b) = |F_n|$.
- Indexing: source is 1-indexed with window condition $l \le k + f(n)$; Lean is 0-indexed
  with `i < j → j ≤ i + d`. Under $k = i+1$, $l = j+1$: $k < l \iff i < j$ and
  $l \le k + d \iff j \le i + d$. **Term-by-term exact**, no off-by-one.
- Not vacuous: for $n \ge 4$ the pair $1/4, 2/3 \in F_n$ has
  $(1-2)(4-3) = -1 < 0$, so the defining set of `fareySimOrderFn` is a *proper* bounded
  initial segment of ℕ and $f(n)$ is a genuine finite maximum; the limit statement is a
  substantive open question.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere: `similarlyOrdered` subtracts in ℤ (`p.num - q.num` is ℤ;
  `(p.den : ℤ) - q.den` casts the ℕ denominator before subtracting). Correct.
- Division: `(a : ℚ) / (b : ℚ)` has $b \ge 1$ (from `Icc 1 n`), never 0. The outer
  `(fareySimOrderFn n : ℝ) / (n : ℝ)` returns 0 at $n = 0$ (field convention), harmless
  under `atTop`.
- `range (b + 1)` = $\{0, \dots, b\}$ correctly realizes $0 \le a \le b$, i.e. fractions
  in $[0,1]$ inclusive. No off-by-one.
- Degenerate/vacuous cases of `fareySimOrderFn`: $d = 0$ is always in the set
  (`i < j ∧ j ≤ i + 0` is unsatisfiable), so the set is nonempty; the set is
  downward-closed in $d$; for $n \le 3$ **every** pair in $F_n$ is similarly ordered
  (checked exhaustively for $F_1, F_2, F_3$), so the set is all of ℕ, unbounded, and
  Mathlib's `Nat` `sSup` returns the junk value 0. This deviates from the informal
  "largest integer" (which does not exist there) but is invisible to the `atTop` limit
  and is precisely why the source restricts to $n \ge 4$. Now documented in the
  docstring (Addendum fix 3). For $n \ge 4$ boundedness holds via the $1/4, 2/3$
  witness, and `sSup` of a bounded nonempty ℕ-set is its maximum, which (by downward
  closure) is the largest valid $d$ — exactly $f(n)$.
- Filter encoding `Tendsto _ atTop (nhds c)` is the standard, correct encoding of
  $f(n)/n \to c$; combined with $c > 0$ it captures "$f(n) = (c+o(1))n$ for large $n$".
- No `StrictMono`/`Monotone` or interval-endpoint issues arise.

**A3. Definitions — pass.**

- `similarlyOrdered` uses `Rat.num`/`Rat.den`, which are the *reduced* numerator and

- Polarity of the fixed form checked by hand: RHS true ⟺ such a $c$ exists ⟺ the

## E. Prior-review audit (`ai-review/1005.md`)

Mostly accurate on the definitions, but three substantive findings:

1. **Unsound boundedness argument (false lemma, conclusion partially survives).** The
   prior review justifies `sSup` well-definedness with: "For fixed $n$, the Farey
   sequence has finite length, so no $d$ larger than the list length can introduce new
   constraints. The set is bounded above by the list length." This is **wrong twice
   over**. (a) "No new constraints beyond the length" proves the property is eventually
   *constant* in $d$ — which is an argument for *unboundedness* whenever $d =$ length
   works, the opposite of what was claimed. (b) The conclusion itself is false for
   $n \le 3$: there *every* pair is similarly ordered (exhaustive check), the set is all
   of ℕ, and `sSup` silently returns 0 — the set is *not* bounded by the list length.
   Boundedness for $n \ge 4$ needs a concrete dissimilar pair (e.g. $1/4, 2/3$:
   $(1-2)(4-3) = -1 < 0$), which the prior review never exhibits. The final statement
   survives only because `atTop` ignores $n \le 3$ — the same pattern as the 1000
   audit's invented-then-excused off-by-one: a fabricated justification that would mask
   a real bug on a problem where small cases *do* matter.
2. **Question-form call endorsed incorrectly.** The prior review writes "The original
   problem asks 'does such a $c$ exist?' — so the formalization correctly treats this as
   an existential claim." It correctly identifies the source as a question, then blesses
   the assertion encoding — missing the A4 defect this review found. The style review
   (`reviews/1005.md` §6) compounds it: "Case 3 applies — the problem is stated as a
   direct assertion" is factually false against the recovered source text.
3. **Minor:** its line references (e.g. "`fareyFractions` (lines 41–44)",
   "`erdos_1005` (lines 69–72)") match neither `conjectures/1005.lean` nor
   `deepmind/1005.lean`; and its claim that the website "provides minimal detail" for
   [vD25b] undersells the `/latex/1005` page, which carries the full title and arXiv id
   (recovered from logs).

What it got right: the missing [Ma42] and incomplete [vD25b] citations it flagged were
subsequently fixed in `deepmind/1005.lean` (verified against the log-recovered `/latex`
extraction); the `fareyFractions` correctness bullets (coprimality corner cases
`Coprime 0 1`, `Coprime b b`) all check out; the ℤ-arithmetic observation on
`similarlyOrdered` is correct.
