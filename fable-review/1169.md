## Summary

The problem (Erdős–Hajnal; [Va99, 7.85]): is it true that, for all finite
$k < \omega$, $\omega_1^2 \not\to (\omega_1^2, k)^2$ — i.e. is there (provably
in ZFC) a 2-coloring of the pairs of ordinals below $\omega_1^2$ with no
homogeneous set of order type $\omega_1^2$ in the first color and none of order
type $k$ in the second? The page displays the $k = 3$ instance (which is
equivalent to the "all $k \ge 3$" reading); status **NOT DISPROVABLE** — Hajnal
[Ha71] proved the relation under CH, so ZFC cannot refute it, but ZFC-provability
is open. The Lean file (`conjectures/1169.lean:43–45`) defines the partition
relation `OrdinalPartitionPair` via strictly monotone embeddings — a faithful
encoding — and asserts its negation at $(\omega_1^2, \omega_1^2, k)$ for **every**
`k : ℕ`. That universal statement is provably false: for $k = 0, 1, 2$ the
positive relation holds trivially, so the theorem as stated is refutable in
ZFC/Lean. The prior ai-review caught exactly this, and the fix (restrict to
$3 \le k$) was applied to the styled archive copy — but never to the raw file
under review. The v2 file adds the `3 ≤ k` hypothesis, plus recovered citations
and a page-confirmed CH variant.

## A. Semantic fidelity

**A1. Statement fidelity — one [defect]; otherwise faithful (source-verified).**

- Recovered verbatim source statement (see Addendum): "Is it true that, for all
  finite $k<\omega$,\[\omega_1^2 \not\to (\omega_1^2, 3)^2?\]" — note the page's
  internal mismatch: the prose quantifies over $k$, the displayed formula shows
  the instance $3$. The two readings agree mathematically: a homogeneous set of
  order type $k \ge 3$ contains one of order type $3$, so a coloring witnessing
  $\not\to (\omega_1^2, 3)^2$ witnesses $\not\to (\omega_1^2, k)^2$ for every
  $k \ge 3$; hence "$k=3$" ⟺ "all finite $k \ge 3$". The original formalizer
  session explicitly noted the mismatch and normalized to $k$ (reasonable), but
  dropped the implicit $k \ge 3$ floor (the defect below).
- Independent back-translation of lines 43–45: "for every natural $k$, there
  exists a pair-coloring $f$ of $\{x < \omega_1^2\}$ by `Bool` such that no
  strictly monotone $g : \{x < \omega_1^2\} \to \{x < \omega_1^2\}$ has all
  increasing pairs colored `true`, and no strictly monotone
  $g : \{x < k\} \to \{x < \omega_1^2\}$ has all increasing pairs colored
  `false`." Unfolding `¬(∀ f, A ∨ B)` to `∃ f, ¬A ∧ ¬B`, this is precisely the
  negative relation $\omega_1^2 \not\to (\omega_1^2, k)^2$ — the right content
  for each **individual** $k \ge 3$.
- **[defect — overstrong-quantifier]** The theorem binder `(k : ℕ)` ranges over
  $k = 0, 1, 2$, where the *positive* relation holds trivially, making
  `¬ OrdinalPartitionPair (omega1 ^ 2) (omega1 ^ 2) ↑k` provably **false** and
  the theorem as a whole refutable in ZFC. Verified by hand against the exact
  encoding:
  - $k = 0$: `{x : Ordinal // x < (0 : Ordinal)}` is empty; the empty function
    into `{x < ω₁²}` is vacuously `StrictMono` and the monochromatic condition
    is vacuous, so the second disjunct of `OrdinalPartitionPair` holds for every
    $f$. The relation is true; its negation false.
  - $k = 1$: `{x // x < 1}` is a subsingleton; any constant map to the (nonempty,
    since $0 < \omega_1^2$) target is vacuously `StrictMono` with no pairs
    $i < j$. Second disjunct again always holds.
  - $k = 2$: given $f$, either some $a < b$ below $\omega_1^2$ has
    $f\,a\,b = \mathrm{false}$ — then $g(0) = a$, $g(1) = b$ is a strictly
    monotone map from `{x // x < 2}` witnessing the second disjunct — or
    $f\,a\,b = \mathrm{true}$ for **all** $a < b$, and the identity embedding
    (with $\beta = \alpha = \omega_1^2$) witnesses the first disjunct.
  So `∀ k : ℕ, ¬ …` misstates the problem as a false proposition rather than
  the open conjecture. **Fix (applied in v2): add the hypothesis `3 ≤ k`**,
  matching the page's displayed $k = 3$ floor and the styled archive's own
  correction. (With the floor, no smaller-$k$ triviality survives, and the
  statement is the genuine open problem.)
- Not vacuous/trivial after the fix: for $k \ge 3$ neither disjunct-killer is
  degenerate; the statement is exactly the open $\not\to$ question.

**A2. Lean semantics traps — pass (checked exhaustively; no arithmetic surface).**

- No ℕ subtraction, no division, no `Finset.range`, no filters/limits anywhere.
- `omega1 ^ 2`: the exponent `2` elaborates as ℕ (`Monoid.npow`), giving
  $\omega_1 \cdot \omega_1$; ordinal exponentiation (`opow`) at exponent 2 gives
  the same value, so either elaboration is $\omega_1^2$ as intended. Ordinal
  multiplication non-commutativity is moot for a square.
- `omega1 = (aleph 1).ord` is the standard, correct definition of $\omega_1$
  (the least ordinal of cardinality $\aleph_1$).
- `(↑k : Ordinal)` (`Nat.cast`): `{x : Ordinal // x < ↑k}` is the set of
  ordinals $< k$, order type exactly $k$. Correct for every $k$, including the
  degenerate cases dissected in A1.
- Encoding "subset of order type $\beta$" as a `StrictMono` function from
  `{x // x < β}`: a strictly monotone map between linear orders is an order
  isomorphism onto its image, so its image is a subset of order type $\beta$;
  conversely any subset of order type $\beta$ (or more) yields such a map by
  enumeration. Faithful in both directions.
- The coloring `f` is a function on ordered pairs (diagonal included), but the
  homogeneity conditions only consult `f (g i) (g j)` with `g i < g j` (from
  `StrictMono g` and `i < j`), so diagonal and "reversed" values are
  semantically inert — the standard reduction of unordered-pair colorings.
  Faithful.
- Vacuous bounded quantifiers: the `i < j` guards are exactly where the $k \le 2$
  degeneracy enters — analyzed in A1; for the fixed $k \ge 3$ statement nothing
  vacuous remains.
- `StrictMono` (not `Monotone`) is the right notion — an injective order
  embedding is required; `Monotone` would allow constant maps and break the
  order-type reading.
- Universe note: `Ordinal` in a Mathlib-only file is universe-polymorphic;
  `omega1` and the theorem will pick up auto-bound universe parameters,
  uniformly instantiated. Semantically inert (the sibling 1172 file with the
  identical pattern compiled).

**A3. Definitions — pass, one label nit.**

   (a) It asserts [Va99] "refers to: Hajnal, A. and Larson, J.A., *Partition
   relations*, Handbook of Set Theory, Springer, 2010", excusing the tag

3. **§4 Readability — mathematically wrong "clarification".** It recommends
   glossing "not disprovable" as "independent of ZFC (consistent with ZFC but
   not provable from ZFC alone)". That is an overclaim: Hajnal's CH result
   shows ZFC cannot *refute* the statement (consistency of the "yes"

   independence (which additionally requires the consistency of the negation)

4. **§3 Variants — loose but harmless.** "The formalization captures the
   general case (`∀ k : ℕ`), which is the stronger and intended reading" is
   doubly off: the unrestricted `∀ k : ℕ` is not a stronger reading but a
   false statement (as its own §6 establishes), and for $k \ge 3$ the general
