## Summary

The problem (verbatim from the recovered page): "Let $k\geq 0$. Let $G$ be a graph such
that every subgraph $H$ contains an independent set of size $\geq (n-k)/2$, where $n$
is the number of vertices of $H$. Must $G$ be the union of a bipartite graph and
$O_k(1)$ many vertices?" Status: **PROVED** ("This has been solved in the
affirmative"), by Reed [Re99]. The Lean statement (`conjectures/73.lean:26-33`) asserts:
for every $k$ there is a $C$ such that every finite graph $G$ in which every vertex
subset $S$ contains an independent set $I$ with $2|I| \ge |S| - k$ admits a set $T$ of
at most $C$ vertices whose removal leaves a 2-colorable graph. Read back independently,
this is exactly the affirmative answer to the question as asked, with the constant
depending only on $k$. I found **no semantic defects** — only scholarship gaps
(missing bibliography, missing page remarks/cross-references) and polish-level nits,
all addressed in `conjectures-v2/73.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 26–32: "∀k ∃C ∀n ∀G on `Fin n`: if every
  `S : Finset (Fin n)` contains an `I ⊆ S`, pairwise non-adjacent in `G`, with
  `2|I| ≥ |S| − k` (ℕ), then some `T` with `|T| ≤ C` and some `f : Fin n → Bool`
  properly 2-colors every edge both of whose ends avoid `T`." This matches the source
  question's affirmative direction.
- **"Every subgraph" vs. induced subgraphs.** The source says "every subgraph $H$";
  the Lean quantifies over vertex subsets `S` and demands `I` independent *in $G$*,
  i.e. independent in the induced subgraph $G[S]$. These readings are **equivalent**,
  not merely conventionally identified: any subgraph $H$ with $V(H) = S$ has
  $E(H) \subseteq E(G[S])$, hence $\alpha(H) \ge \alpha(G[S])$, so the
  for-every-subgraph hypothesis holds iff the for-every-induced-subgraph hypothesis
  holds. The formalization is correct under either reading.
- $n = |V(H)|$ ↔ `S.card`; "independent set of size ≥ (n−k)/2" for an integer-sized
  set is $2|I| \ge n - k$ over ℤ — see A2 for the ℕ-truncation analysis. Non-strict
  `≥` matches the source. Term-by-term exact; no indexing conventions in play.
- "Union of a bipartite graph and $O_k(1)$ many vertices" ↔ delete a set `T` of at
  most `C` vertices, remainder 2-colorable. `f` is total on `Fin n` with values on `T`
  unconstrained, and the coloring condition is imposed only on edges avoiding `T` —
  a faithful encoding of "$G - T$ is bipartite" (`Colorable 2` on the induced
  subgraph, extended arbitrarily).
- Not vacuous/trivial: the hypothesis is satisfiable (every bipartite graph satisfies
  it for every $k$, since one side of any induced subgraph has ≥ half its vertices;
  a triangle satisfies it for $k \ge 1$), and the conclusion with a *uniform* `C` is a
  substantive claim over all $n$. Degenerate instances behave correctly: $n = 0$
  (both sides vacuous), $S = ∅$ (take $I = ∅$), $|S| \le k$ (hypothesis vacuous there,
  as intended — see A2).

**A2. Lean semantics traps — pass.**

- **ℕ subtraction** (`S.card - k`, line 30): truncates at 0, so for `S.card ≤ k` the
  condition `2 * I.card ≥ S.card - k` is trivially satisfied by any `I` (e.g. `∅`).
  This *matches* the mathematical intent: over ℤ, $2|I| \ge |S| - k$ is likewise
  trivially true when $|S| \le k$ since the RHS is $\le 0$. Formally, in ℕ,
  `a - b ≤ x ↔ a ≤ x + b` (`Nat.sub_le_iff_le_add`), so the file's encoding is
  provably equivalent to the truncation-free `2 * I.card + k ≥ S.card` used by the
  sibling `conjectures/922.lean` (verified: its line 31). No defect.
- No division anywhere (the informal $(n-k)/2$ is encoded multiplicatively — the right
  choice).
- No `Finset.range`, no filters, no `StrictMono`/intervals.
- Vacuous quantifiers: only the harmless ones analyzed above.
- **Constant quantifier order** (problem-55-class check, done explicitly): `∃ C` sits
  *before* `∀ n`, so `C` depends only on `k` — exactly $O_k(1)$. The reversed order
  `∀ n, ∃ C` would be trivially provable (take `T` = all `n` vertices), so this order
  is load-bearing and is correct as written.
- No default-valued binders / `optParam` (problem-25-class check: none in file); no
  `liminf`/`limsup` (problem-33-class: n/a).

**A3. Definitions — pass.**

- `SimpleGraph.IndepSetIn` (lines 9–11) matches its docstring: `I ⊆ S` plus pairwise
  non-adjacency with a `u ≠ v` guard. Small-case check (problem-56-class): `I = ∅` and

- Junk-value scan of degenerate inputs: none of the batch's junk-value generators
