## Summary

The problem (OPEN): let $t, k, r \ge 2$ and let $\mathcal{F}$ be the family of
all $r$-uniform hypergraphs with $k$ vertices and $s$ edges; determine
$\mathrm{ex}_r(n, \mathcal{F})$. The page's remarks record the [BES73] lower
bound $\mathrm{ex}_r(n,\mathcal{F}) \gg_{k,s} n^{(rs-k)/(s-1)}$ (all $k > r$,
$s > 1$) and the general Brown–Erdős–Sós conjecture: for all $r > t \ge 2$ and
$s \ge 3$, $f_r(n;k,s) = o(n^t)$ whenever $k \ge (r-t)s + t + 1$. The Lean file
(`conjectures/1157.lean`) defines $r$-uniform hypergraphs on `Fin n`, the
$(k,s)$-free property (`isFree`, line 23), the extremal number $f_r(n;k,s)$ via
`sSup` (line 28), and formalizes the conjecture as a direct assertion in
$\varepsilon$–$N_0$ form (lines 60–65). Read back independently, the Lean and
the source conjecture agree exactly, including the guarded ℕ subtraction
`r - t` and the "$k \ge$" form of the vertex-count hypothesis; the only
defect-class finding is bibliographic (undefined citation keys), and the file
also silently — and correctly — repairs a genuine typo on the source page
(`ex_t` for `ex_r` in the conjecture display).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $t,k,r\geq 2$. Let
  $\mathcal{F}$ be the family of all $r$-uniform hypergraphs with $k$ vertices
  and $s$ edges. Determine $\mathrm{ex}_r(n,\mathcal{F})$." Recovered
  conjecture (remarks): "for all $r>t\geq 2$ and $s\geq 3$,
  $\mathrm{ex}_t(n,\mathcal{F})=o(n^t)$ whenever $k\geq (r-t)s+t+1$."
- Independent back-translation of lines 60–65: "for all $r > t \ge 2$,
  $s \ge 3$, $k \ge (r-t)s + t + 1$: for every $\varepsilon > 0$ there is
  $N_0$ with $f_r(n;k,s) \le \varepsilon n^t$ for all $n \ge N_0$" — i.e.
  $f_r(n;k,s) = o(n^t)$, exactly the conjecture. The
  $\varepsilon$–$N_0$ encoding of little-o is correct here because
  $f_r \ge 0$; at $n = 0$ both sides are $0$ (see A2), and the quantifier
  order ($\varepsilon$ before $N_0$) is right.
- **The `ex_t` typo on the page is real and the file's silent correction to
  `ex_r` is right.** The extremal function is that of $r$-uniform hypergraphs;
  the exponent uses $t$. Verified from the page's own cross-references: it
  lists $s = r = 3$, $k = 6$ (hence $t = 2$, $k = (3-2)\cdot 3 + 2 + 1 = 6$) as
  problem [716], the Ruzsa–Szemerédi theorem $\mathrm{ex}_3(n,\mathcal{F}) =
  o(n^2)$ — a statement about **3-uniform** hypergraphs, not graphs. If the
  subscript were genuinely $t$, that special case would concern
  $\mathrm{ex}_2$. The v2 file now documents this correction instead of making
  it silently.
- The identification $\mathrm{ex}_r(n,\mathcal{F}) = f_r(n;k,s)$ ("no $k$
  vertices span $s$ or more edges"), asserted without proof in the docstring,
  is correct: $\mathcal{F}$ contains *all* $r$-uniform hypergraphs with $k$
  vertices and $s$ edges, including those with isolated vertices, so for
  $n \ge k$ a copy of a member of $\mathcal{F}$ is precisely a $k$-set
  spanning $\ge s$ edges (pad any $\le k$-vertex configuration of $s$ edges
  with unused vertices); for $n < k$ both freeness notions hold vacuously.
  Also `S.card = k` (exact) vs "at most $k$" is immaterial: for $n \ge k$ a
  smaller spanning set extends to a $k$-set spanning the same edges. Now
  recorded in the v2 module docstring.
- The "$k \ge (r-t)s+t+1$" hypothesis matches the page's "whenever" clause
  verbatim. It is also mathematically coherent: $f_r(n;k,s)$ is non-increasing
  in $k$ for $n > k$ (a $k$-set spanning $s$ edges extends to a $(k{+}1)$-set
  spanning them), so the "$\ge$" form follows from the base case — the
  conjecture is not accidentally strengthened.
- Not vacuous/trivial: the hypothesis set is satisfiable ($r=3, t=2, s=3,
  k=6$), $f_r(n;k,s)$ can be as large as $\binom{n}{r} \sim n^r$ with $r > t$,
  and the [BES73] lower bound $n^{t - 1/(s-1)}$ at the critical $k$ sits just
  below $n^t$ — the statement is a substantive open conjecture.
- Nit [polish, fixed]: the module docstring opened "Let r ≥ 2" where the page
  says "Let $t,k,r\geq 2$"; restored verbatim in v2.

**A2. Lean semantics traps — pass.**

- **ℕ subtraction:** `r - t` in `hk` (line 61) is guarded by `hr : r > t`, so
  `r - t ≥ 1` with no truncation, and the hypothesis is term-for-term the
  page's $(r-t)s + t + 1$. No other subtraction occurs.
- **Division:** none in the file.
- **`sSup` on ℕ** (line 29): for $s > 0$ the set is nonempty (the empty
  hypergraph is $(k,s)$-free since $0 < s$) and bounded above (edge sets are
  finsets of subsets of `Fin n`, cardinality $\le 2^n$), so `sSup` is the
  honest maximum. Degenerate $s = 0$ with $n \ge k$: no hypergraph satisfies
  `edgesSpannedBy H S < 0`, the set is empty, and `sSup ∅ = 0` is a junk
  value — invisible under the theorem's `hs : s ≥ 3` but now documented in the
  v2 docstring (same precedent as fable-review/1005).
- **`Finset.range` off-by-ones:** none (`range` unused).
- **Vacuous quantifiers:** for $n < k$ there is no `S` with `S.card = k`, so
  `isFree` holds vacuously and `extremalNumber` is the unconstrained maximum
  $\binom{n}{r}$; this matches the informal notion (no $k$-set exists to
  violate) and is in any case absorbed by the `∃ N₀` eventual form. At
  $n = 0$: `edges = ∅` forced (no $r$-subsets of `Fin 0` for $r \ge 3$), so
  `extremalNumber = 0 ≤ ε · 0^t = 0` — the base case of the bound holds.
- **Filter encoding:** the `∀ ε > 0, ∃ N₀, ∀ n ≥ N₀` shape is the standard
  unfolding of `=o[atTop]` for a nonnegative quantity; correct.
- **Strictness:** `edgesSpannedBy H S < s` correctly renders "spans **fewer
  than** $s$" = "no $k$ vertices span $s$ **or more** edges"; `r > t` and
  `t ≥ 2` match the page's $r > t \ge 2$ exactly.
