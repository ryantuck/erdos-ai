## Summary

The problem (erdosproblems.com/1085, [Er75f,p.103], status **OPEN**): "Let $f_d(n)$ be
minimal such that, in any set of $n$ points in $\mathbb{R}^d$, there exist at most
$f_d(n)$ pairs of points which distance $1$ apart. Estimate $f_d(n)$." — i.e. $f_d(n)$
is the maximum number of unit-distance pairs among $n$ points in $\mathbb{R}^d$. The
hard open cases are $d = 2$ (the unit distance problem, = Erdős #90) and $d = 3$; for
$d \ge 4$ with $p = \lfloor d/2\rfloor$ the answer is asymptotically
$\frac{p-1}{2p}n^2$ (Lenz lower bound, Erdős upper bound via Erdős–Stone [Er60b]). The
Lean file defines the unordered unit-distance pair count and $f_d(n)$ (via `sSup`), and
formalizes, as a direct assertion, the **solved** $d \ge 4$ upper bound in
$\varepsilon$–$N_0$ form: for every $\varepsilon > 0$, all sufficiently large finite
$A \subseteq \mathbb{R}^d$ satisfy
$\#\{\text{unit pairs}\} \le (\frac{p-1}{2p} + \varepsilon)|A|^2$. Read back
independently, this is exactly the page's $f_d(n) \le (\frac{p-1}{2p} + o(1))n^2$, in
the true direction — acceptable raw style for a solved partial result of an
"Estimate…" problem. I found no semantic defects; the nits are scholarship gaps (page
remarks and eight of the nine citation keys missing) and one dead definition, both
addressed in the Addendum.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (both captures agree): "Let $f_d(n)$ be minimal
  such that, in any set of $n$ points in $\mathbb{R}^d$, there exist at most $f_d(n)$
  pairs of points which distance $1$ apart. Estimate $f_d(n)$."
- The docstring's paraphrase "the maximum number of pairs of points at distance 1 in
  any set of n points" is exactly equivalent to the source's "minimal such that … at
  most" formulation (minimal uniform upper bound over $n$-point sets = maximum attained
  count; the count set is finite and nonempty, so the max exists).
- Independent back-translation of the theorem (lines 39–46 pre-fix): "for all
  $d \ge 4$, writing $p = d/2$ (ℕ-floor), for every real $\varepsilon > 0$ there is
  $N_0$ such that every finite $A \subseteq \mathbb{R}^d$ with $|A| \ge N_0$ has at
  most $(\frac{p-1}{2p} + \varepsilon)|A|^2$ unit-distance pairs." Since
  $f_d(n) = \max_{|A|=n}\#\{\text{pairs}\}$ and the maximum is attained, quantifying
  over sets is exactly equivalent to $f_d(n) \le (\frac{p-1}{2p}+o(1))n^2$ — the page's
  statement of Erdős's [Er60b] result, term-for-term.
- Scope choice: "Estimate $f_d(n)$" has no single canonical formal core (the upstream
  artifact concurs: it contains only variants and a literal `-- TODO: Add erdos_1085`).
  Formalizing the flagship solved $d \ge 4$ asymptotic under the main name, with an
  honest docstring saying so, is a legitimate editorial choice for a raw file. The
  omitted page results ($d=2$, $d=3$ bounds; exact determinations) are optional
  enrichment, not missing parts — $d=2$ is literally problem #90, separately formalized
  in this repo (`conjectures/90.lean`).
- Not vacuous/trivial: $\frac{p-1}{2p} = \frac12 - \frac1{2p} < \frac12$ strictly,
  while the trivial pair bound is $\binom{n}{2} \approx \frac12 n^2$; the statement
  asserts a genuine, and (by Lenz) sharp, separation from the trivial bound. The
  hypothesis `4 ≤ d` matches the source's $d \ge 4$ proviso (the statement happens to
  remain true for $d < 4$, so no vacuity lurks there either).

**A2. Lean semantics traps — pass.**

- **ℕ subtraction:** none. The only subtraction, `↑p - 1`, happens in ℝ after the cast,
  and $p \ge 2$ under `hd`, so it is the intended $p - 1 \ge 1$.
- **ℕ division:** `d / 2` is precisely the source's $\lfloor d/2 \rfloor$ — flooring is
  *wanted* here. `.card / 2` in `unitDistancePairsD` is exact: the filtered set of
  ordered pairs is invariant under the swap involution, which is fixed-point-free on
  it (the filter requires `p.1 ≠ p.2`), so the cardinality is even.
- **Field division:** `(↑p - 1) / (2 * ↑p)` has denominator $\ge 4$ under `hd`; no
  division-by-zero convention is engaged. (For $d \le 1$ it would return junk 0, but
  such $d$ are excluded.)
- **`Finset.range` / off-by-one:** not used.
- **Vacuous quantifiers:** none; `∃ N₀, ∀ A, N₀ ≤ A.card → …` is the standard
  "sufficiently large" encoding and correctly captures the $o(1)$ (with $N_0$ allowed
  to depend on $d$ and $\varepsilon$, matching "for fixed $d$").
- **`sSup` on ℕ** (`maxUnitDistancePairs`): for $d \ge 1$ the achievable-count set is
  nonempty ($n$-point sets exist in an infinite space) and bounded above by $n^2$, so
  `sSup` is the genuine maximum. Degenerate case: for $d = 0$ the space is a single
  point, so for $n \ge 2$ the set is empty and `sSup ∅ = 0` is a junk value —
  invisible to the theorems (which assume $d \ge 4$), now documented in the docstring
  (Addendum fix 1).
- **Decidability of the filter predicate** (`dist p.1 p.2 = 1` on ℝ): resolved
  classically inside `noncomputable section`; the original pipeline session's
  `lake build conjectures/1085.lean` succeeded (only the expected `sorry` warning),
  recorded in `claude-session-logs/05636496….jsonl`.
- `StrictMono`/`Monotone`, open/closed intervals: not applicable.

**A3. Definitions — pass, one nit (fixed).**

- `unitDistancePairsD` matches its docstring ("unordered pairs {p,q} with p ≠ q and
  dist = 1") including degenerate inputs (empty set → 0; $d = 0$ → 0). `dist` on
  `EuclideanSpace ℝ (Fin d)` is the Euclidean ℓ² metric — correct space and metric.
- `maxUnitDistancePairs` matches its docstring and the source's $f_d(n)$ (see A2 for
  the `sSup` analysis). No `sorry` in any definition.
- Nit [polish, fixed]: `maxUnitDistancePairs` was **dead code** — defined,
  docstring-labeled "f_d(n)", but unused by the theorem (which quantifies over sets
  directly, an equivalent and legitimate formulation). The added Lenz variant
  (Addendum fix 3) now uses it, resolving the drift risk between the def and the
  theorem's implicit $f$.

**A4. Question form and answer polarity — pass (raw-file rules).**

- The source is a soft **value/estimate request** ("Estimate $f_d(n)$"), status OPEN,
  with no yes/no question posed; there is no canonical `answer()` encoding for it. The
  raw file states a *solved* partial result as a direct assertion — per the pipeline's
  raw-file rule, direct-assertion form for a solved result is acceptable when the
  polarity is the true direction, which it is ($f_d(n) \le (\frac{p-1}{2p}+o(1))n^2$
  is Erdős's theorem, not a refuted claim).
- Polarity double-checked by hand at $d = 4, 5$: $p = 2$, coefficient $\frac14$ —
  matches the Lenz construction's two orthogonal circles giving $\sim n^2/4$ cross
  pairs, and the page's formula.
- Binders `(d : ℕ) (hd : 4 ≤ d)` before the colon universally quantify a direct
  assertion over the intended range — correct here (no `answer()` iff to contaminate).

**A5. Solution status — pass (source-verified, post-fix).**
