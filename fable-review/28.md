## Summary

The problem is the Erdős–Turán conjecture on additive bases (OPEN, $500):
if $A \subseteq \mathbb{N}$ is such that $A + A$ contains all but finitely
many integers, then $\limsup 1_A \ast 1_A(n) = \infty$. The Lean file
(`conjectures/28.lean:25-28`) asserts: for every `A : Set ℕ` with
`{n | n ∉ A + A}.Finite`, `∀ M, ∃ n, repFunction A n ≥ M`, where
`repFunction A n` (`conjectures/28.lean:12-13`) is the `Set.ncard` of the
ordered pairs $(a,b) \in A \times A$ with $a + b = n$. Read back
independently this is: cofinite sumset implies unbounded representation
function — and unboundedness is *equivalent* to $\limsup = \infty$ for
ℕ-valued sequences (verified by hand, §A1), so the Lean and the source
agree. The direct-assertion form is correct for an open "If … then …"
conjecture. No semantic defects; the findings are polish-level (two page
citation keys missing from the docstring's list, no bibliographic data,
page remarks/status not recorded, two page-stated stronger conjectures
available as variants).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "If
  $A\subseteq \mathbb{N}$ is such that $A+A$ contains all but finitely
  many integers then $\limsup 1_A\ast 1_A(n)=\infty$."
- Independent back-translation of lines 25–28: "for every set A of
  naturals whose sumset A + A omits only finitely many naturals, and for
  every M, some n has at least M representations n = a + b with
  a, b ∈ A (ordered pairs)."
- **Hypothesis.** `{n : ℕ | n ∉ (A + A)}.Finite` is exactly "$A + A$
  contains all but finitely many" naturals; over ℕ, "all but finitely
  many" and "all sufficiently large" coincide, so the asymptotic-basis
  reading is captured. `A + A` under `open Pointwise` is the sumset
  $\{a + b : a, b \in A\}$ — a, b need not be distinct, matching the
  convolution $1_A \ast 1_A$.
- **Representation function.** $1_A \ast 1_A(n) = \sum_{a+b=n} 1_A(a)
  1_A(b)$ counts *ordered* pairs. `repFunction` counts
  `{p : ℕ × ℕ | p.1 ∈ A ∧ p.2 ∈ A ∧ p.1 + p.2 = n}` — ordered pairs,
  identical. Cross-checked against the upstream human-reviewed
  formalization's `sumRep` (recovered from the sparse clone,
  `FormalConjecturesForMathlib/Combinatorics/Additive/Convolution.lean`):
  `sumRep A n = ((antidiagonal n).filter (fun p ↦ p.1 ∈ A ∧ p.2 ∈ A)).card`
  — the same ordered-pair count, in `Finset` clothing. Semantically equal
  to `repFunction` via the bijection p ↦ p.
- **The conclusion encoding is the one nontrivial equivalence, verified
  by hand.** The source says $\limsup r(n) = \infty$ (i.e. every threshold
  M is exceeded at *infinitely many* n); the Lean says only `∀ M, ∃ n,
  r n ≥ M` (unboundedness). For an ℕ-valued sequence these are equivalent:
  suppose r is unbounded but `{n | r n ≥ M}` were finite for some M. By
  unboundedness, for every K there is n_K with r(n_K) ≥ K; for K ≥ M each
  n_K lies in that finite set F, yet r on F attains only finitely many
  values, bounded by max_{n∈F} r(n) — contradiction for
  K > max_{n∈F} r(n). So every threshold is exceeded infinitely often,
  which is limsup = ∞ (in ℕ∞ along `atTop`, as upstream writes it). The
  converse is immediate. Faithful — and the same encoding is used by the
  corpus's directly-related `conjectures/40.lean` and
  `conjectures/1145.lean`, so the cluster is internally consistent.
- **0 ∈ ℕ / 0 ∈ A.** Lean's ℕ contains 0 and the theorem quantifies over
  sets that may contain 0 (for which $A \subseteq A + A$, slightly
  enlarging the hypothesis class relative to a strictly-positive-integers
  reading of the source). Checked by hand: whether n = 0 is required in
  A + A is immaterial (cofinite condition); instances with 0 ∈ A reduce to
  "A' ∪ (A'+A') cofinite ⟹ r_{A'} unbounded" for A' = A \ {0} (since
  r_A − r_{A'} ≤ 2 everywhere), which is the same conjecture with the
  standard nonneg-integers convention of the additive-basis literature.
  The upstream human-reviewed file makes the identical choice
  (`A : Set ℕ`, `(A + A)ᶜ.Finite` — note `(A+A)ᶜ.Finite` and
  `{n | n ∉ A+A}.Finite` are definitionally the same set). Not a defect;
  documented.
- Not vacuous / not trivially false: the hypothesis is satisfiable
  (A = ℕ, or A = squares ∪ small sets, etc.), the conclusion is a
  substantive open conjecture, and no degenerate A trivializes it (a
  finite A never satisfies the hypothesis, since its sumset is finite).
