## Summary

The problem (OPEN on the source page): let $f$ be a random completely
multiplicative function, where for each prime $p$ we independently choose
$f(p) \in \{-1,1\}$ uniformly at random; is it true that
$\limsup_{N\to\infty} (\sum_{m\le N} f(m))/\sqrt{N} = \infty$ with
probability 1? — [Va99, 1.11], with Atherfold [At25] having proved the
almost-sure upper bound $\sum_{m\le N} f(m) \ll N^{1/2}(\log N)^{1+o(1)}$.
The Lean (`conjectures/1144.lean:46-54`) states, for every probability space
$(\Omega,\mu)$ and family `ε : ℕ → Ω → ℝ` with each `ε k` Rademacher
(`IsRademacher`: everywhere ±1-valued with `μ{ε k = 1} = μ{ε k = -1}`) and
`iIndepFun ε μ`, that almost surely every real $C$ has infinitely many $N$
with $S_N > C\sqrt N$ — the right shape, with correct quantifier order,
indexing, and limsup encoding. But no measurability is required of the `ε k`,
and in Mathlib neither `iIndepFun` (comap-σ-algebra independence) nor `μ`
applied to the non-measurable sets `{ε k = ±1}` (an outer measure) supplies
it. The hypotheses therefore admit a pathological model — Bernstein-set signs
realizing a fixed deterministic character-like multiplicative function with
$O(\log N)$ partial sums on a set of full outer measure — on which the
conclusion fails, so the statement as written is provably false while the
problem is open. Adding `hMeas : ∀ k, Measurable (ε k)` restores exact
faithfulness.

## A. Semantic fidelity

**A1. Statement fidelity — one defect (A2/A3 interaction), otherwise exact
(source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $f$ be a random
  completely multiplicative function, where for each prime $p$ we
  independently choose $f(p)\in \{-1,1\}$ uniformly at random. Is it true
  that \[\limsup_{N\to \infty}\frac{\sum_{m\leq N}f(m)}{\sqrt{N}}=\infty\]
  with probability $1$?" The theorem docstring (lines 33–44) reproduces this
  faithfully.
- Independent back-translation of lines 46–54: "for every probability space,
  every family of everywhere-±1-valued functions with equal μ-masses on the
  two value sets, mutually independent in the `iIndepFun` sense, almost every
  ω has: for all C, infinitely many N with $S_N(ω) > C\sqrt N$." Modulo the
  measurability gap (below), this is the asked "yes" direction.
- Conclusion shape: `∀ᵐ ω, ∀ C, ∃ᶠ N in atTop, S_N > C·√N` is exactly
  "a.s. $\limsup S_N/\sqrt N = \infty$": for $N \ge 1$,
  $S_N > C\sqrt N \iff S_N/\sqrt N > C$ ($\sqrt N > 0$), and $N = 0$ (where
  `partialSum` is an empty `Icc 1 0` sum $= 0$ and $C\sqrt 0 = 0$) can never
  be a needed witness under `∃ᶠ _ in atTop`. Multiplying by $\sqrt N$ instead
  of dividing neatly avoids division conventions. The a.e. quantifier is
  outermost, i.e. $\mathbb P(\limsup = \infty) = 1$ — the faithful form (the
  ∀C-outside form is equivalent by countable reduction but less direct).
- Indexing: `Icc 1 N` = $\{1,\dots,N\}$ = the source's $m \le N$ (its sums
  start at 1); `randMultFun` at $n = 0$ (value 0) is never read. Term-by-term
  exact.
- Scope of the hypotheses: `hRad`/`hIndep` are imposed at *all* `k : ℕ`
  though `randMultFun` reads `ε` only at primes. Equivalent packaging: a
  prime-indexed independent Rademacher family on $\Omega$ extends to an
  all-of-ℕ family on $\Omega \times \{\pm 1\}^{\mathbb N}$ with fresh
  independent coordinates at non-primes, the partial sums do not change, and
  an a.s. conclusion on the product pulls back a.s. on $\Omega$ by Fubini.
  Acceptable; noted in the v2 docstring.
- Not vacuous: the canonical model (product of uniform ±1 signs, coordinate
  maps) satisfies all hypotheses including measurability, so the statement
  has content. It is also — this is the defect — *falsifiable* as written.

**A2. Lean semantics traps — one defect [missing-measurability]; all listed
traps otherwise clean.**

- **The defect.** Mathlib's `iIndepFun ε μ` is defined as `iIndep` of the
  comap σ-algebras `(borel ℝ).comap (ε k)` and imposes **no** measurability
  on the `ε k` (measurability enters only in downstream lemmas, always as a
  separate hypothesis). Likewise `μ s` for non-measurable `s` is the induced
  outer measure. Consequently `IsRademacher` (line 17) does *not* force the
  masses to be 1/2: for a set $A$ with $\mu^*(A) = \mu^*(A^c) = 1$ (a
  Bernstein set), the constraint `μ{X=1} = μ{X=-1}` holds as $1 = 1$. The
  hypotheses then admit a genuine counter-model, so the theorem as stated is
  **refutable in ZFC** while the problem is open:
  * There is a deterministic completely multiplicative $\tau : \mathbb N \to
    \{\pm1\}$ with $|\sum_{n\le N} \tau(n)| = O(\log N)$: take
    $\tau(p) = \chi_3(p)$ for primes $p \ne 3$ and $\tau(3) = 1$, where
    $\chi_3$ is the nontrivial character mod 3. Then for $n = 3^a m$,
    $(m,3)=1$, $\tau(n) = \chi_3(m)$, so $\sum_{n \le N}\tau(n) =
    \sum_{a \ge 0}\sum_{m \le N/3^a}\chi_3(m)$, at most $\log_3 N + 1$ terms
    each bounded by 1. Hence $S_N^\tau/\sqrt N \to 0$.
  * On $[0,1]$ with Lebesgue measure, fix a Bernstein set $W$ and, inside
    $W^c$, build by transfinite induction (length $\mathfrak c$, meeting
    every (perfect set, finite sign-pattern) pair) sets $\{T_p\}_{p\text{
    prime}}$ all of whose finite Boolean combinations meet every perfect set,
    hence have outer measure 1. Set $A_p = W \cup T_p$ if $\tau(p) = 1$ and
    $A_p = T_p$ if $\tau(p) = -1$, and let $\varepsilon_p = 1$ on $A_p$, $-1$
    off it. Every finite intersection pattern of the $A_p^{(\pm)}$ contains a
    finite combination of the $T_p^{(\pm)}$, so has outer measure 1; thus
    every `iIndep` product condition reads $1 = 1\cdots1$ (patterns with
    $\emptyset$ read $0 = 0$), and `hRad` reads $1 = 1$. Adjoin fresh genuine
    Rademacher coordinates at non-prime indices on a product factor
    $\{\pm1\}^{\mathbb N}$; mixed products check out because
    $(\mu\otimes\nu)^*(K \times M) = \mu^*(K)\,\nu(M)$ for arbitrary $K$ and
    measurable $M$ (Fubini on a measurable cover/section argument).
  * For every $\omega \in W$ the sign pattern is exactly $\tau$, so
    $S_N(\omega) = S_N^\tau = O(\log N)$ and the conclusion fails at
    $\omega$ (take $C = 1$). The failure set contains $W \times \{\pm1\}^
    {\mathbb N}$ of outer measure 1, so `∀ᵐ` fails. **[defect]** — fixed by
    adding `hMeas : ∀ k, Measurable (ε k)` (Addendum fix 1). With `hMeas`,
    the two value sets are measurable complements of masses summing to 1,
    each gets 1/2, `iIndepFun` becomes genuine mutual independence, the
    joint law is the canonical product law, and the a.s. event (measurable
    in the product σ-algebra) has the canonical probability — the statement
    then says precisely "the canonical limsup event has probability 1".
- ℕ subtraction: none anywhere. Division: none (see A1; the formalization
  multiplies by `Real.sqrt` instead). `Real.sqrt` of a natural cast is
  total and nonnegative — no trap.
- `Finset.Icc 1 N` vs `range`: correct inclusive interval; no off-by-one
  (checked at $N = 0, 1$: empty sum, then $f(1) = 1$ via empty
  `factorization.support` product).
- Vacuous bounded quantifiers: none. The only degenerate case ($N = 0$
  witness) is harmless under `atTop` as analyzed in A1.
- "Infinitely many": `∃ᶠ N in atTop` is the correct filter encoding;
  combined with the outer `∀ C` it is the standard rendering of
  $\limsup = \infty$.
- No `StrictMono`/`Monotone` or interval-endpoint issues arise.
