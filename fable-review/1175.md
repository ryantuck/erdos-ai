## Summary

The problem ([Va99, 7.92], OPEN, tags: set theory | chromatic number) asks:
let κ be an uncountable cardinal — must there exist a cardinal λ such that
every graph with chromatic number λ contains a triangle-free subgraph with
chromatic number κ? The page's sole remark: Shelah proved that a negative
answer is consistent if κ = λ = ℵ₁. The Lean file defines
`HasChromaticNumber G κ` (κ is the least palette cardinality admitting a
proper colouring) and states, as a direct assertion, that for every
κ ≥ ℵ₁ there is a cardinal `mu` such that every graph with chromatic number
`mu` has a subgraph `H ≤ G` with `H.CliqueFree 3` and chromatic number
exactly κ. Read back independently, the Lean and the English agree
term-by-term; I found no semantic defects. The one genuine gap is
scholarship: the citation key `[Va99, 7.92]` is used in the theorem docstring
but defined nowhere in the file (no bibliography at all) — the same
undefined-citation-key defect as sibling 1174, fixed the same way in v2.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $\kappa$ be an
  uncountable cardinal. Must there exist a cardinal $\lambda$ such that every
  graph with chromatic number $\lambda$ contains a triangle-free subgraph with
  chromatic number $\kappa$?" The module docstring (lines 14–16) reproduces it
  essentially verbatim, and the remark line 18 matches the page's Shelah
  sentence exactly.
- Independent back-translation of `erdos_problem_1175` (lines 48–53): "for
  every cardinal κ ≥ ℵ₁ there is a cardinal mu such that every simple graph G
  (on any universe-0 vertex type) whose chromatic number is exactly mu has a
  spanning subgraph H with no 3-clique whose chromatic number is exactly κ."
  Modulo the encoding equivalences checked below, this is exactly the
  affirmative answer to the question asked.
- Quantifier structure: source is "∀ uncountable κ, ∃ λ, ∀ graphs with
  χ = λ, ∃ triangle-free subgraph with χ = κ"; Lean is
  `∀ κ, ℵ₁ ≤ κ → ∃ mu, ∀ V G, HasChromaticNumber G mu → ∃ H, …` — identical
  order and scope. "Uncountable" ⟺ `aleph 1 ≤ κ` is the standard, correct
  rendering. The binder `mu` stands for the problem's λ (`lambda` is a Lean
  keyword); noted in the v2 docstring.
- **`HasChromaticNumber G κ` ⟺ χ(G) = κ** (derived by hand, both
  directions). Write S(G) = {#α | Nonempty (G.Coloring α)}. The second
  conjunct says κ is a lower bound for S(G); the first says some element of
  S(G) is ≤ κ. Together: min S(G) = κ. S(G) is nonempty (the identity
  colouring `V → V` is proper, since adjacent vertices are distinct in a
  simple graph), and cardinals are well-ordered, so the minimum exists and is
  attained; hence the predicate holds for exactly one κ, the chromatic
  cardinal. Exactness (not ≥) on both the hypothesis (χ(G) = mu) and the
  conclusion (χ(H) = κ) matches the source's "with chromatic number λ/κ"
  wording precisely.
- **Subgraph encoding `H ≤ G`** (spanning subgraph: same vertex set, subset
  of edges) loses no generality against subgraphs on a vertex subset W ⊆ V:
  extending by isolated vertices preserves the chromatic number whenever it
  is ≥ 1 (colour the isolated vertices with any existing colour; the palette
  is nonempty since κ ≥ ℵ₁), and restriction cannot raise it. So the class of
  achievable (triangle-free, χ = κ) subgraphs is the same under either
  reading. Pass.
- **`CliqueFree 3`** is "no 3-clique", i.e. triangle-free — exactly the
  source's condition. Pass.
- **Universe check**: `κ, mu : Cardinal.{0}`, `V : Type`, `α : Type`.
  `Cardinal.{0}` is by definition the quotient of `Type 0`, so every
  `c : Cardinal.{0}` is `#α` for some `α : Type`; in particular the complete
  graph on such an α has chromatic number exactly c. Hence (i) `∀ κ ≥ ℵ₁` and
  `∃ mu` range over all set-sized cardinals of the model, and (ii) for every
  candidate `mu` the hypothesis `HasChromaticNumber G mu` has witnesses — the
  inner universal quantifier is never vacuous. The statement is the standard
  universe-0 relativization; no hidden restriction.
- **Not vacuous / no degenerate witness.** No cheat value of `mu` exists:
  every cardinal is the chromatic number of some graph (so the hypothesis is
  never unsatisfiable), and since χ is monotone under `≤`, any subgraph H of
  a graph with χ(G) = mu has χ(H) ≤ mu — so mu < κ fails outright, mu = κ
  can consistently fail at κ = ℵ₁ by Shelah, and the statement is the
  genuinely deep open question. Pass.

**A2. Lean semantics traps — pass (mostly n/a).**

- No ℕ subtraction, no division, no `Finset.range`, no filters, no
  liminf/limsup, no `StrictMono`/`Monotone`, no intervals anywhere in the

- Vacuous-quantifier scan: the only universal hypotheses are
  `Nonempty (G.Coloring α) → …` (never vacuous — every graph has colourings,

## E. Prior-review audit (`deepmind/ai-review/1175.md`)

The prior review's mathematics is sound; its scholarship section speculated
an attribution. Findings:

1. **Correct and re-derived (§1): the `chromaticCardinal` equivalence.** Its
   claim that `HasChromaticNumber G κ ⟺ G.chromaticCardinal = κ` checks out:
   (⇒) the second conjunct lower-bounds the `sInf` set by κ and the first
   conjunct puts an element ≤ κ into it (note the set membership needs
   `#C = κ'` exactly, but `#α ≤ κ` still gives `sInf ≤ #α ≤ κ`), so the
   infimum is κ; (⇐) well-orderedness plus nonemptiness (identity colouring)
   attains the infimum at some C with `#C = κ`, giving the first conjunct,
   and every colouring palette's cardinality lies in the set, hence ≥ sInf
   = κ, giving the second. Its "infimum is attained" step is sound —
   unlike the 1005 audit's unsound `sSup` argument, this one survives
   re-derivation.

   (1999)" — a guessed expansion of `[Va99]` ("Vaugn" is not a person;
   presumably a mangling of Vaughan, whose 1999 paper is a *different*
   `[Va99]` used by problem 1143). The correct site-wide expansion for the

   fixes.

   styled-vs-raw conflation as the 1174 audit. Harmless to its conclusions.
