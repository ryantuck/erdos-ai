## Summary

The problem (Erdős–Révész, source [Va99, 6.78]): for a random walk s₀, s₁, …
in ℤ² started at the origin, let f_k(x) count the times 0 ≤ l ≤ k with
s_l = x, and let F(k) = {x : f_k(x) = max_y f_k(y)} be the set of favourite
sites ("favourite values" in the page's wording). Is it true that
|⋃_{k≤n} F(k)| ≤ (log n)^{O(1)} almost surely, for all but finitely many n?
The page marks it PROVED — solved in the affirmative: almost surely
|⋃_{k≤n} F(k)| ≪ (log n)², via the eventual bound |F(n)| ≤ 3 (Problem 1165)
and the Erdős–Taylor [ErTa60] bound T_n ≪ (log n)² on the maximum number of
visits to any fixed point. The Lean file (`conjectures/1166.lean`) builds the
walk from `IsUniformStep` + `iIndepFun` hypotheses and defines local time,
visited sites, max local time, favourite sites, and their cumulative union
(all correct, including degenerate cases), then asserts
`∃ C : ℕ, ∀ᵐ ω, ∀ᶠ n in atTop, card ≤ (Real.log n)^C` — a faithful and
correctly-quantified rendering of the question's true (affirmative) answer.
The single defect is inherited from the shared setup: neither `IsUniformStep`
nor Mathlib's `iIndepFun` forces the steps to be measurable, and an explicit
degenerate model (trivial σ-algebra on the path space) satisfies every
hypothesis while making |⋃_{k≤n} F(k)| grow linearly on a non-null set — so
the theorem as stated is false. Fixed in v2 by adding
`hMeas : ∀ i, Measurable (X i)`.

## A. Semantic fidelity

**A1. Statement fidelity — one defect (hypotheses); conclusion faithful
(source-verified).**

- Recovered verbatim source statement (see Addendum): "Given a random walk
  $s_0,s_1,\ldots$ in $\mathbb{Z}^2$, starting at the origin, let $f_k(x)$
  count the number of $0\leq l\leq k$ such that $s_l=x$. Let
  $F(k)=\{ x: f_k(x) = \max_y f_k(y)\}$ be the set of 'favourite values'. Is
  it true that $\left\lvert \bigcup_{k\leq n}F(k)\right\rvert \leq (\log
  n)^{O(1)}$ almost surely, for all but finitely many $n$?" The theorem
  docstring (lines 52–67) reproduces this and the remarks essentially
  verbatim (writing 'favourite sites' for the page's 'favourite values' — the
  standard name; harmless).
- Independent back-translation of lines 68–74: "for every probability space
  and every family X of steps satisfying `IsUniformStep` and `iIndepFun`,
  there is a natural number C such that for a.e. ω, for all sufficiently
  large n, |cumulativeFavouriteSites(n)| ≤ (log n)^C." Conclusion-side this
  is exactly the source question's affirmative content: (log n)^{O(1)} with a
  deterministic exponent, almost surely, for all but finitely many n. The
  quantifier order `∃ C` before `∀ᵐ ω` before `∀ᶠ n` is right: O(1) is a
  deterministic constant, the exceptional ω-set is fixed once C is chosen,
  and the threshold in n may depend on ω. (An ω-dependent C would also be
  formally weaker-to-state but nonstandard; and the known proof gives the
  deterministic form — |F(n)| ≤ 3 eventually plus T_n ≪ (log n)² with the
  Erdős–Taylor a.s. limsup normalization ≤ 1/π give a.s. eventually
  card ≤ (log n)³, i.e. C = 3 works.)
- "Random walk in ℤ²" is read as the simple random walk (i.i.d. uniform
  steps on the four unit vectors), as in siblings 1164/1165 — the standard
  interpretation for this problem family; now documented in v2.
- **[defect] Missing measurability hypothesis: the theorem is falsifiable by
  a degenerate model.** Identical to the defect found in the 1164 review
  (fable-review/1164.md), whose `IsUniformStep`/`iIndepFun` setup this file
  shares verbatim. Neither `IsUniformStep` nor Mathlib's `iIndepFun`
  requires `Measurable (X i)` (`iIndepFun` is `iIndep` of the comap
  σ-algebras: it constrains μ, as an outer measure, on preimage sets, and
  holds or fails regardless of measurability of the functions). Explicit
  countermodel: Ω = D^ℕ with D = {(1,0),(-1,0),(0,1),(0,-1)}, X i ω = ω i,
  the **trivial** σ-algebra {∅, Ω}, and its unique probability measure μ.
  Then μ evaluates every nonempty set to 1 (the only measurable superset is
  Ω): the four step-events all get outer measure 1, so `IsUniformStep` holds
  (it demands only *equality*, not the value 1/4); every `iIndepFun` product
  identity reads 1 = 1·…·1 (all preimages nonempty) or 0 = 0 (some preimage
  empty), so independence holds. But for the always-right ω (ω i = (1,0) for
  all i) the walk visits (0,0), (1,0), …, (n,0), each site exactly once, so
  every visited site has local time 1 = maxLocalTime, F(k) = all k+1 visited
  sites, and |⋃_{k≤n} F(k)| = n + 1 — eventually larger than (log n)^C for
  *every* C. The set of ω violating the eventual bound is therefore nonempty
  for every C, hence of outer measure 1 ≠ 0, so `∀ᵐ` fails for every C and
  the `∃ C` statement is false. With `∀ i, Measurable (X i)` added, the four
  step events are measurable, partition Ω (by the range constraint), and the
  equalities force probability 1/4 each; the hypotheses then pin down the
  walk's law as genuine i.i.d. uniform steps. **Fixed in v2.**
- Not vacuous: with measurability added, the model class contains the
  canonical construction (product measure on D^ℕ) and the conclusion is the
  substantive Erdős–Révész theorem.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere; no division anywhere (the bound is a power, not
  a quotient).
- `Finset.range (k + 1)` in `localTime`/`visitedSites` gives l ∈ {0, …, k} —
  exactly the source's 0 ≤ l ≤ k, both endpoints included. `Finset.range n`
  in `walkPosition` gives S_n = X₀ + ⋯ + X_{n−1} with S₀ = (0,0) (empty
  sum) — the walk starts at the origin as required, and s₀, s₁, …
  corresponds to walkPosition at 0, 1, … term-by-term. `Finset.range (n+1)`
  in `cumulativeFavouriteSites` gives k ∈ {0, …, n} = ⋃_{k≤n}. No
  off-by-ones.
- No vacuous quantifiers: at k = 0, visitedSites = {(0,0)}, localTime at the
  origin is 1, maxLocalTime = 1, F(0) = {(0,0)} — all degenerate cases are
  the mathematically correct ones, not silent alterations.
- `∀ᵐ ω ∂μ, ∀ᶠ n in atTop` is the correct encoding of "almost surely, for
  all but finitely many n" (the finite exceptional set of n may depend on
  ω — matching the source). The `∃ C` sits correctly outside both.
- Small-n degeneracies of the bound: Real.log 0 = Real.log 1 = 0 and
  log 2 < 1, so for small n the RHS can be below the card (which is ≥ 1);
  all absorbed by `∀ᶠ … atTop`. For C = 0 the RHS is 1 — a legitimate (if
  useless) instantiation; the ∃ picks a working C.
- `(card : ℝ) ≤ Real.log n ^ C` casts the ℕ card into ℝ before comparing;
  `^` with C : ℕ is the Monoid power on ℝ — no `rpow` subtleties.
- No `StrictMono`/`Monotone` or interval-endpoint issues arise.

**A3. Definitions — pass.**

- All six defs match their docstrings and the source, including degenerate
  inputs. `localTime` counts positions S_0, …, S_k of value x — exactly
  f_k(x). `maxLocalTime` takes `Finset.sup` over `visitedSites`, which
  always contains the origin (l = 0), so the sup is a genuine maximum, never
  the junk ⊥ = 0 of an empty sup; and since unvisited sites have local time
  0 < 1 ≤ max, the max over visited sites equals the source's max over all
  y ∈ ℤ². `favouriteSites` filters visitedSites for local time = max; the
  restriction to visited sites again loses nothing (an unvisited site can
  never attain the max ≥ 1) — so F(k) matches the source's unrestricted
  {x : f_k(x) = max_y f_k(y)}. Both equivalences now documented in v2's
  docstrings.
- No `sorry` in any def. Definitions are used consistently; no drift between
  what they compute and what the theorem needs.
- `IsUniformStep` matches its docstring *given measurability* — "each with
  equal probability" is literally equalities of measures, which pin down 1/4
  only for measurable events (see A1). v2 documents this in the def's
  docstring, as in 1164 v2.
