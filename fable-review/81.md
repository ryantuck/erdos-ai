## Summary

The problem (verbatim from the recovered page): "Let $G$ be a chordal graph on $n$
vertices - that is, $G$ has no induced cycles of length greater than $3$. Can the
edges of $G$ be partitioned into $n^2/6+O(n)$ many cliques?" Status OPEN; asked by
Erdős, Ordman, and Zalcstein [EOZ93], who proved a $(1/4-\epsilon)n^2$ upper bound;
the complete-graph-joined-to-independent-set example shows $n^2/6+O(n)$ is sometimes
necessary. The Lean file defines induced cycles and chordality from scratch, then
asserts: ∃ C > 0 such that for every n and every chordal G on `Fin n` there is a
`Finset (Finset (Fin n))` of cliques covering every edge, with no edge in two
distinct cliques, of cardinality ≤ n²/6 + C·n. Read back independently, this is
exactly the affirmative direction of the question with the standard uniform-constant
reading of O(n); the encoding of "partition of the edge set into cliques" via
vertex-sets with covering + no-shared-edge conditions is faithful. I found no
semantic defects; the findings are scholarship gaps (undefined citation key, missing
page remarks/cross-references) and optional enrichment, all addressed in
`conjectures-v2/81.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 40–54: "There is a real C > 0 such that for
  every n and every chordal graph G on n vertices, some finite family P of vertex
  subsets exists with (a) each member a clique of G, (b) every edge of G inside some
  member, (c) no two distinct members both containing both endpoints of any edge,
  and (d) |P| ≤ n²/6 + Cn." Conditions (a)–(c) say precisely that the edge sets of
  the members of P partition E(G): by (a), each member S contributes the C(|S|,2)
  edges it spans; (b) is covering; and (a)+(c) force distinct members to share at
  most one vertex (two shared distinct vertices would be adjacent by (a),
  contradicting (c)), i.e. edge-disjointness. So the Lean statement is "the edges of
  G can be partitioned into at most n²/6 + Cn cliques" — the question as asked,
  asserted affirmatively.
- Quantifier structure: ∃C before ∀n/∀G is the standard (and only correct) reading
  of the uniform O(n) bound. Checked against the problem-55 class explicitly: the
  reversed order ∀n ∃C would be trivially true (for fixed n take C ≥ n/3, since any
  graph's edges partition into ≤ n(n−1)/2 ≤ n²/6 + (n/3)·n single-edge cliques), so
  the file's order is essential. The n² coefficient 1/6 is fixed outside C's reach;
  C can only absorb the linear term, exactly as O(n) requires.
- Types: cardinality compared in ℝ with `(P.card : ℝ) ≤ (n : ℝ)^2/6 + C*(n : ℝ)` —
  no ℕ division/floor anywhere in the bound. `Finset (Finset (Fin n))` is the right
  container: a genuine edge partition never repeats a clique (a repeated clique with
  ≥ 2 vertices would violate edge-disjointness with itself as a distinct copy — and
  in a `Finset` duplicates are impossible anyway), so no multiset is needed.
- Degenerate-witness check (problem-25/36 class): empty and singleton members of P
  are cliques with no edges; they can appear but only *increase* `P.card`, making
  the ∃P claim harder, never easier. No default-valued binders, no `optParam`.
  n = 0 and n = 1: the empty partition works and the bound is ≥ 0 — harmless, no
  small-n falsity in the affirmative direction (worst chordal graphs on small n need
  ≤ n(n−1)/2 cliques, absorbed by C·n).
- Not vacuous / not trivially false: the statement sits strictly between the trivial
  n²/4-regime upper bounds and the n²/6 lower-bound example — precisely the open
  question.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere. The only `%` arithmetic is `(i.val + 1) % k` on ℕ with
  `i : Fin k`, so `i.val + 1 ≤ k` and the wraparound at `i.val = k − 1` is exactly
  the intended consecutive-mod-k relation; `% 0` never executes on an inhabited
  `Fin k` path (`Fin 0` is empty, the ∃f is then false for k > 0 anyway... for
  k = 0 the empty function satisfies everything vacuously, see A3).
- Division: only real division by the literals 6 (and 16, 4 in the v2 variants);
  never by a variable, never by zero.
- No `Finset.range`, no bounded quantifiers with vacuous first terms in the main
  statement; `IsChordal`'s `∀ k ≥ 4` guard is exactly the source's "length greater
  than 3".
- No filters/liminf/limsup (problem-33 class n/a); no `sSup` junk values; no
  `StrictMono`/`Monotone` or interval-endpoint issues. Strict `0 < C` vs `0 ≤ C` is
  immaterial for an ∃C upper-bound statement (any witness can be enlarged).

**A3. Definitions — pass (simulation-verified).**

- `HasInducedCycle` (lines 13–16) matches its docstring: injective `f : Fin k → V`
  with adjacency *iff* consecutiveness mod k — the biconditional is what makes the
  cycle induced (chordless), and for k ≥ 3 the relation
  `(i+1) % k = j ∨ (j+1) % k = i` is exactly the edge set of the cycle graph C_k.
- `IsChordal` (lines 22–23): no induced cycle of any length ≥ 4 — the standard
  definition and the source's parenthetical one. For k > |V| the ∃f is
