## Summary

The problem (erdosproblems.com/1101, verbatim from the recovered page): if
$u = \{u_1 < u_2 < \cdots\}$ is a sequence of integers with $(u_i, u_j) = 1$ for all
$i \neq j$ and $\sum 1/u_i < \infty$, let $\{a_1 < a_2 < \cdots\}$ be the integers not
divisible by any $u_i$, and define $t_x$ by
$u_1 \cdots u_{t_x} \leq x < u_1 \cdots u_{t_x} u_{t_x+1}$. The sequence is *good* if
for all $\epsilon > 0$ and sufficiently large $x$,
$\max_{a_k < x}(a_{k+1} - a_k) < (1+\epsilon)\, t_x \prod_i (1 - 1/u_i)^{-1}$. Two
OPEN yes/no questions: is there a good sequence with $u_n < n^{O(1)}$ (Erdős believed
no), and is there a good sequence with $u_n \leq e^{o(n)}$ (Erdős believed yes)? The
Lean file packages the hypotheses as a structure `GoodSeqData`, defines the sifted set,
partial products, $t_x$ (via `Nat.find`), the max gap (via `sSup`), the infinite
product (via `iSup` of partial products), and `IsGoodSeq`, then states Question 1 as
"every good sequence fails polynomial growth" (the believed *no*) and Question 2 as
"a good sequence with $\log u_n / n \to 0$ exists" (the believed *yes*), both
`:= sorry`. Read back independently, every definition and both statements are faithful;
the only pointwise deviation (the `maxGap` window `b ≤ x` vs the source's `a_k < x`) is
provably invisible to `IsGoodSeq`. No Part A defects; nits and enrichment only.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "If $u=\{u_1<u_2<\cdots\}$ is a
  sequence of integers such that $(u_i,u_j)=1$ for all $i\neq j$ and
  $\sum \frac{1}{u_i}<\infty$ then let $\{a_1<a_2<\cdots\}$ be the sequence of integers
  which are not divisible by any of the $u_i$. For any $x$ define $t_x$ by
  $u_1\cdots u_{t_x}\leq x< u_1\cdots u_{t_x}u_{t_x+1}$. We call such a sequence $u_i$
  good if, for all $\epsilon>0$, if $x$ is sufficiently large then
  $\max_{a_k<x} (a_{k+1}-a_k) < (1+\epsilon)t_x \prod_{i}(1-\frac{1}{u_i})^{-1}$. Is
  there a good sequence such that $u_n< n^{O(1)}$? Is there a good sequence such that
  $u_n\leq e^{o(n)}$?"
- `GoodSeqData` (lines 18–23): infinite sequence `u : ℕ → ℕ`, `StrictMono`
  ($u_1 < u_2 < \cdots$), `2 ≤ u i`, pairwise `Nat.Coprime` for $i \neq j$
  ($(u_i,u_j)=1$), `Summable (1/u i)` ($\sum 1/u_i < \infty$; positive terms, so
  summability is exactly finiteness of the sum). The explicit `ge_two` is a faithful
  explicitization, not an addition: $u_i = 1$ would empty the sifted sequence and make
  $(1-1/u_i)^{-1}$ undefined, so the source's formulas force $u_i \geq 2$; negative or
  zero terms are likewise excluded by the source's reciprocal sum and divisibility
  language. Lean index $i$ ↔ source index $i+1$.
- `siftedSet` (line 29): positive integers not divisible by any $u_i$ — exactly the
  $a$-sequence (as a set; the source's enumeration $a_1 < a_2 < \cdots$ is recovered by
  ordering). Note $1$ is always sifted, and the set is infinite for every `GoodSeqData`
  (split the sieve at $M$ with tail $\sum_{i>M} 1/u_i < \delta_0/2$ where
  $\delta_0 = \prod(1-1/u_i) > 0$: at least $x\delta_0/2 - O_M(1)$ sifted integers up
  to $x$).
- `partialProd` (lines 34–36): `partialProd n` $= u_0 \cdots u_{n-1} = u_1 \cdots u_n$
  (1-indexed) — term-by-term exact, with `partialProd 0 = 1` the empty product.
- `tOfX` (line 55): `Nat.find` gives the least $n$ with $x <$ `partialProd n`; minus 1
  gives the largest $t$ with $u_1\cdots u_t \leq x$. Since `partialProd` is strictly
  increasing (factors ≥ 2), for $x \geq 1$ this satisfies *exactly* the source's
  defining pair of inequalities $u_1\cdots u_{t_x} \leq x < u_1\cdots u_{t_x}u_{t_x+1}$
  — verified term-by-term, not just in the limit. ($x = 0$: see A2.)
- `maxGap` (lines 61–64): sSup of $b - a$ over consecutive sifted pairs $a < b \le x$
  ("consecutive" = no sifted $c$ strictly between — correct). The window differs
  pointwise from the source's $\max_{a_k<x}$ (left-endpoint indexing, bridge gap
  included) but defines the same `IsGoodSeq` class — full argument in A2.
- `inverseProd` (lines 70–71): $\sup_n \prod_{i<n} u_i/(u_i-1)$; each factor equals
  $(1-1/u_i)^{-1}$, the partial products are increasing, and summability of $1/u_i$
  (with $u_i \geq 2$, so $\log\frac{u}{u-1} \leq 2/u$) bounds them, so the `iSup` is
  the genuine value of the convergent infinite product — the unbounded-`iSup` junk
  value cannot occur for a `GoodSeqData`.
- `IsGoodSeq` (lines 78–80): $\forall \varepsilon > 0$, eventually in $x$,
  `maxGap` $< (1+\varepsilon)\, t_x \cdot$ `inverseProd` — the source's definition of
  good, with the same strict `<`. Quantifying $x$ over ℕ rather than ℝ is harmless:
  both sides of the source inequality only change at integers.
- **Theorem 1** (lines 89–92), back-translated: "for every good sequence and every
  $C > 0$ there are infinitely many $n$ with $u_n > n^C$." This is exactly the
  negation of "$\exists C$, $u_n \leq n^C$ for all sufficiently large $n$", i.e. of
  "$u_n < n^{O(1)}$": $\neg\exists C\,\forall^\infty \Leftrightarrow \forall C\,
  \exists^\text{freq}$, with `∃ᶠ … in atTop` the correct "infinitely many"; strict vs
  non-strict and the restriction $C > 0$ lose nothing (bump $C$; and $C \leq 0$ is
  unsatisfiable anyway since $u_1 \geq 2 > 1 = 1^C$). The "for all $n$" reading of
  $u_n < n^{O(1)}$ is unsatisfiable at $n = 1$ for the same reason, so the eventual
  reading — the one negated here — is the only sensible one. The 0- vs 1-indexing
  shift preserves the polynomial-growth class ($(m+1)^C \leq m^{C+1}$ for $m \geq 2$).
  Faithful encoding of the believed answer NO to Question 1.
- **Theorem 2** (lines 100–103), back-translated: "there is a good sequence with
  $\log(u_n)/n \to 0$." Equivalent to $u_n \leq e^{o(n)}$: given $u_n \leq e^{f(n)}$
  with $f(n)/n \to 0$, squeeze $0 < \log(u_n)/n \leq f(n)/n \to 0$ (using
  $u_n \geq 2$); conversely take $f = \log \circ u$. Faithful encoding of the believed
  answer YES to Question 2.
- Not vacuous/trivial: `GoodSeqData` is inhabited (e.g. $u_i = p_i^2$ — pairwise
  coprime, $\sum 1/p_i^2 < \infty$; the page's own [208] remark is about exactly this
  sequence), and good sequences exist (Erdős proved so, per the page's remarks), so
  Theorem 1's universal is not vacuous; Theorem 2 is a substantive existence claim.

**A2. Lean semantics traps — pass; two documented degeneracies, one windowing analysis.**

- **ℕ subtraction in `tOfX`** (line 56): at $x = 0$, `Nat.find` returns 0 (since
  `partialProd 0 = 1 > 0`) and `0 - 1` truncates to the junk value 0. For every
  $x \geq 1$, `Nat.find ≥ 1` and the subtraction is safe and exact. Harmless:
  `IsGoodSeq` consumes `tOfX` only under `∀ᶠ x in atTop`. Documented in the v2
  docstring; no hypothesis needed. [polish]
- **`maxGap` window `b ≤ x` vs source `max_{a_k<x}`.** The source indexes gaps by the
  left endpoint ($a_k < x$; the single gap bridging $x$ is included), the Lean by the
  right endpoint ($b \leq x$; bridge excluded), so the two maxima differ pointwise.
  They nevertheless define the **same class of good sequences**, so `IsGoodSeq` — and
  hence both theorems — are unaffected. Proof: (⇐) the Lean gap set at $x$ is a subset
  of the source's, so source-good ⇒ Lean-good trivially. (⇒) Assume Lean-good; fix
  $\varepsilon$, choose $\varepsilon''$ with $(1+\varepsilon'')^2 < 1+\varepsilon$,
  and let $X_0$ witness Lean-goodness for $\varepsilon''$. For $x \geq X_0$ the only
  gap in the source max missing from the Lean max is the bridge $(a_K, a_{K+1})$ with
  $a_K < x < a_{K+1}$ (when $x$ is itself sifted there is none). Apply Lean-goodness
  at $x' = a_{K+1} \geq x$: $g_K < (1+\varepsilon'')\,t_{x'}P$ where
  $P = \prod(1-1/u_i)^{-1}$. Since $t_{x'} \leq \log_2 x'$ (factors ≥ 2) this gives
  $x' \leq x + O(\log x')$, so $x' \leq 2x$ for large $x$; and consecutive partial
  products differ by a factor $u_{t+1} \geq 2$, so at most one partial product lies in
  $(x, 2x]$ and $t_{x'} \leq t_{2x} \leq t_x + 1$. As $t_x \to \infty$, eventually
  $(1+\varepsilon'')(t_x+1) \leq (1+\varepsilon)t_x$, so
  $g_K < (1+\varepsilon)\,t_x P$ and the source bound holds. Both directions hold for
  *every* `GoodSeqData` (they use only $P < \infty$ and $t_x \to \infty$), so the
  encoding is sound. Documented in the v2 docstring. [polish — documentation, not a
  defect]
- **`sSup` on ℕ in `maxGap`**: the gap set is always bounded above by $x$ (since
  $1 \leq a < b \leq x$), so no unbounded-set junk — unlike the 1005 case there is no
  parameter range where the set is all of ℕ. For small $x$ (fewer than two sifted
  elements $\leq x$) the set is *empty* and `sSup ∅ = 0`; harmless under `∀ᶠ`.
- **`iSup` on ℝ in `inverseProd`**: bounded (see A1), so no junk value.
- **Division**: all divisions are field divisions in ℝ (`1/u i`, `u/(u-1)`,
  `log(u n)/n`). Denominators: `u i ≥ 2` throughout; `(u i : ℝ) - 1 ≥ 1` (real
  subtraction — no ℕ-subtraction trap); `/(n : ℝ)` at $n = 0$ yields 0, harmless
  inside `Tendsto … atTop`. No ℕ division anywhere.
- **`Finset.range n`** in `inverseProd` gives $i < n$: the $n$-th partial product has
  exactly the first $n$ factors — consistent with `partialProd`'s convention; no
  off-by-one.
- **Vacuous quantifiers**: none created (`∀ i j, i ≠ j → …` and the gap set's inner
  `∀ c` behave correctly on all inputs).
- **Filter encodings**: `∀ᶠ x in atTop` = "for sufficiently large $x$" ✓;
  `∃ᶠ n in atTop` = "for infinitely many $n$" ✓; `Tendsto … atTop (nhds 0)` =
  "$\to 0$" ✓.
- **`StrictMono`** correctly captures $u_1 < u_2 < \cdots$; all inequality
  strictness (`<` in the good condition, `≤ x` window, `2 ≤ u i`) checked against the
  source.
- **rpow**: `(n : ℝ) ^ C` with `C : ℝ` is `Real.rpow` (the import is present);
  degenerate bases $0^C = 0$ (for $C > 0$) and $1^C = 1$ are both $< u_n \geq 2$, so
  they add two harmless indices to a "frequently" statement — no trap.
