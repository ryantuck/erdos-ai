## Summary

The problem (Erdős–Szüsz–Turán, [Er64b]): let $S(N,A,c)$ be the (Lebesgue) measure of the
set of $\alpha \in (0,1)$ with $|\alpha - x/y| < A/y^2$ for some $N \le y \le cN$,
$\gcd(x,y)=1$. Does $\lim_{N\to\infty} S(N,A,c) = f(A,c)$ exist, and what is its explicit
form? The Lean (`deepmind/1001.lean`) defines `approxSet N A c` as exactly this set,
`sMeasure` as `(volume …).toReal`, and states the yes/no half as
`answer(True) ↔ ∀ A c, 0 < A → 1 < c → ∃ L, Tendsto (fun N => sMeasure N A c) atTop (nhds L)`,
plus the EST58 partial answer to the value half as a second theorem asserting the limit is
$12A\log c/\pi^2$ when $0 < A < c/(1+c^2)$. Read back independently, the Lean and the
recovered source statement agree; I found no semantic defects, only polish-level items.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered page statement (verbatim): "Let $S(N,A,c)$ be the measure of the set of those
  $\alpha\in (0,1)$ such that $\left\lvert \alpha-\frac{x}{y}\right\rvert < \frac{A}{y^2}$
  for some $N\leq y\leq cN$ and $(x,y)=1$. Does $\lim_{N\to \infty}S(N,A,c)=f(A,c)$ exist?
  What is its explicit form?"
- Independent back-translation of `approxSet` (lines 66–71): the set of $\alpha \in (0,1)$
  such that there exist $x \in \mathbb{Z}$, $y \in \mathbb{N}$ with $N \le y$,
  $y \le cN$ (compared in ℝ, correctly, since $cN$ need not be an integer),
  $\gcd(|x|,y)=1$, and $|\alpha - x/y| < A/y^2$. This matches the source term-for-term.
  `Nat.Coprime (Int.natAbs x) y` is a correct rendering of $(x,y)=1$ for $x \in \mathbb{Z}$.
- Quantifiers: `A`, `c` universally quantified *inside* the iff with explicit positivity
  (`0 < A`) and range (`1 < c`) hypotheses — the source leaves the parameter ranges
  implicit; $A>0$, $c>1$ is the standard and correct reading (for $c \le 1$ the question
  degenerates: $S \le 2A/N \to 0$, and the EST58 formula needs $\log c > 0$).
- Not vacuous: for fixed $A>0$, $c>1$, `sMeasure` is a genuinely nontrivial sequence
  (eventually a union of $\asymp N$ short intervals of total length $\approx 12A\log c/\pi^2$
  when $A$ is small); existence of its limit is the real Kesten–Sós theorem, and no
  degenerate witness satisfies the statement trivially.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere. The only subtraction (`1 - ε` in the new variant) is in ℝ.
- Division: `(x : ℝ) / (y : ℝ)` and `A / (y : ℝ)^2` at `y = 0` both return 0 in Lean.
  This can only arise when `N = 0` (then `(y:ℝ) ≤ c*0` forces `y = 0`), where the
  membership condition becomes `|α - 0| < 0`, false — so `approxSet 0 A c = ∅` and
  `sMeasure 0 A c = 0`. A single degenerate index-0 term is invisible to `atTop`
  convergence, and the source's $S(N,\cdot)$ is only meaningful for $N \ge 1$ anyway.
  `c / (1 + c^2)` is never division by zero.
- No `Finset.range`; the denominator range `N ≤ y ∧ (y:ℝ) ≤ c*N` is the source's closed
  interval $[N, cN]$, both endpoints inclusive, exactly.
- No vacuous bounded quantifiers.
- `Tendsto … atTop (nhds L)` (and `∃ L, …`) is the standard correct encoding of "the
  limit exists"; `nhds (12 * A * Real.log c / Real.pi ^ 2)` (parsed
  $((12A)\log c)/\pi^2$) is the correct encoding of "the limit equals $12A\log c/\pi^2$".
- Strict inequality `|α - x/y| < A/y^2` matches the source's strict `<`; `Ioo 0 1`
  matches the open interval $(0,1)$.

**A3. Definitions — pass.**

- `approxSet` (lines 64–71) and `sMeasure` (lines 73–75) match their docstrings and the
  source, including degenerate `N = 0` (empty set, measure 0) as analyzed above.
  `sMeasure`'s `.toReal` is safe: the set is contained in `Ioo 0 1`, so the measure is
  finite. No `sorry` in any definition.
- `noncomputable` on `approxSet` is likely unnecessary (a `Set ℝ` is Prop-valued);
  compiler-dependent, deferred.

**A4. Question form and answer polarity — pass.**

- The source's first half is a yes/no question ("Does … exist?"), so the
  `answer(…) ↔ P` shape is right, with `P` the question as asked. Polarity checked by
  hand: `P` = "for all admissible $(A,c)$ the limit exists"; Kesten–Sós proved exactly
  this, so `answer(True)` means "yes, the limit exists" — correct.
- The second half ("What is its explicit form?") is a value request that remains
  unanswered in general (the recovered page: KeSo66 proved existence "without a method to
  determine its value"). It is represented by the known partial answer, the EST58
  formula, as a direct assertion (no `answer()` wrapper) — appropriate for a proved
  partial result. A general `= answer(sorry)` formalization of $f$ would be an
  open-ended function-determination problem and is reasonably omitted.
- No binders before the colon on the `answer()` theorem (line 92: `theorem erdos_1001 :
  answer(True) ↔ …`); the `∀ A c` correctly sits inside the iff.

**A5. Solution status — pass (source-verified).**

- The recovered page banner is **SOLVED**, tooltip: "This has been resolved in some other
  way than a proof or disproof" (i.e. the existence question is answered yes, but the
  explicit form of $f$ is not determined in general). `research solved` on all three
  statements is consistent: existence (Kesten–Sós), the explicit formula in the
  restricted range and the boundedness result (both Erdős–Szüsz–Turán) are all proved
  results. Module docstring, theorem docstrings, and tags agree. The page shows
  "Formalised statement? No" — no Lean-verification status to record.

## E. Prior-review audit (`ai-review/1001.md`)

Mostly accurate on the Lean semantics; three corrections:

1. **False claim about the website's bibliographic data.** It asserts "The website does
   not provide full bibliographic data beyond author names and years" and rates
   author-year stubs as "consistent with the website". The site's `/latex/1001` source
   (recovered from the logs) carries full title/journal/pages for `[EST58]`, `[KeSo66]`,
   `[Bo08]`, `[XiZa06]`. The reviewer looked only at the rendered page, whose
   bibliography loads lazily via `/bibs/` requests, and mistook the missing render for
   missing data. (Its citation table is also stale: it describes the pre-enrichment
   stub entries, which the current artifact has long since completed.)
2. **Edge-case argument imprecise but conclusion right.** For `N = 0` it argues the set
   is empty because "`A / (0:ℝ)^2 = 0` and `|α - x/0| = |α| > 0`". Re-derived: `y = 0` is
   indeed forced, `(x:ℝ)/0 = 0`, so the condition is `|α| < 0`, false — empty set,
   `sMeasure 0 = 0`, invisible to `atTop`. Here the asymptotic dismissal is genuinely
   valid (unlike the invented off-by-one in the 1000 review, there is no source term at
   $N=0$ to disagree with). Its `Nat.Coprime` degenerate-case claims (`Coprime n 0 ↔
   n = 1`, `Coprime 0 y ↔ y = 1`) check out.
3. **Flagged but never fixed / missed.** Its two variant recommendations were half
   actioned: the EST58 explicit formula *was* added to the artifact, but the
   $\min(A,c) > 10$ boundedness result was not (fixed by this review). It also missed
   the polarity/`answer()` analysis entirely (caught by `reviews/1001.md`) and did not
   notice that a literal "for all $N$" reading of the boundedness result would be false
   in this formalization ($S(1,A,c) = 1$ when $A > 1$) — exactly the kind of
   first-index subtlety this pipeline exists to catch.
