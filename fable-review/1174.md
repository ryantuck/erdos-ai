## Summary

The problem ([Va99, 7.91], OPEN, tags: set theory | ramsey theory) asks two
questions of Erdős and Hajnal: (1) does there exist a K₄-free graph G such that
every edge colouring of G with countably many colours contains a monochromatic
K₃; (2) does there exist a graph with no K\_{ℵ₁} such that every edge colouring
with countably many colours contains a monochromatic K\_{ℵ₀}? The page's sole
remark: Shelah proved that a graph with either property can *consistently*
exist. The Lean file states both parts as direct existential assertions
(`erdos_problem_1174a`, `erdos_problem_1174b`), encoding colourings as total
symmetric functions `V → V → ℕ` and the clique conditions via
`IsNClique`/`IsClique` with cardinality bounds. Read back independently, both
statements match the source questions exactly; I found no semantic defects. The
one genuine gap is scholarship: the citation key `[Va99, 7.91]` is used in both
theorem docstrings but defined nowhere in the file (no bibliography at all).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Does there exist a graph
  $G$ with no $K_4$ such that every edge colouring of $G$ with countably many
  colours contains a monochromatic $K_3$?" and "Does there exist a graph $G$
  with no $K_{\aleph_1}$ such that every edge colouring of $G$ with countably
  many colours contains a monochromatic $K_{\aleph_0}$?" The module docstring
  (lines 12–17) reproduces both essentially verbatim.
- Independent back-translation of `erdos_problem_1174a` (lines 35–41): "there is
  a type V and a graph G on V such that no 4-element vertex set is a 4-clique,
  and for every symmetric function col : V → V → ℕ there is a 3-clique S and a
  colour c with every pair of distinct vertices of S coloured c." Modulo the
  colouring-encoding equivalence checked below, this is exactly question (1).
- Back-translation of `erdos_problem_1174b` (lines 54–60): "there is a graph G
  with no clique of cardinality ≥ ℵ₁ such that every symmetric ℕ-colouring
  admits a monochromatic clique of cardinality ≥ ℵ₀." Exactly question (2),
  given the ≥-vs-exact equivalences below.
- **Colouring encoding equivalence** (both directions, derived by hand). The
  informal object is a map on E(G) with countable palette; the Lean object is a
  total symmetric `col : V → V → ℕ`.
  (⇐) Any edge colouring c extends to a total symmetric col (colour non-edges
  and the diagonal 0); a monochromatic clique produced for col is monochromatic
  for c, since all inspected pairs are distinct clique vertices, hence edges.
  (⇒) Any symmetric col restricts to an edge colouring; a monochromatic clique
  for the restriction is one for col, for the same reason. So the ∀-quantified
  statements are equivalent — the extra colourings of non-edges/diagonal are
  never inspected by the conclusion (`u ≠ v` guards the diagonal; clique
  membership guards non-edges).
- **"Countably many colours" = ℕ palette**: the arrow notation G → (K₃)²\_{ℵ₀}
  quantifies over *all* functions into a countable palette, not only surjective
  ones; and every colouring with a finite or countably infinite colour set
  injects into ℕ. Universal quantification over `V → V → ℕ` is therefore
  exactly the informal class. Pass.
- **"No K₄" via `∀ S : Finset V, ¬IsNClique 4 S`**: any clique on ≥ 4 vertices
  contains a 4-element subclique (subsets of cliques are cliques), so
  "no 4-clique" also excludes larger cliques — matching "$G$ with no $K_4$".
  Every K₄ is finite, so `Finset` quantification loses nothing in infinite
  graphs. Pass.
- **"No K\_{ℵ₁}" via `¬∃ S : Set V, aleph 1 ≤ #S ∧ IsClique S`**: K\_{ℵ₁} means
  a clique on exactly ℵ₁ vertices; a clique of cardinality ≥ ℵ₁ contains one of
  cardinality exactly ℵ₁ (choice; Mathlib has it), so the ≥-form is equivalent.
  Dually, "contains a monochromatic K\_{ℵ₀}" ⟺ "has an infinite monochromatic
  clique" ⟺ `aleph 0 ≤ #S` for a monochromatic clique S. Pass. (Note
  `Cardinal.aleph_zero : aleph 0 = ℵ₀`.)
- **Universe check**: `∃ V : Type` fixes universe 0. `Cardinal.{0}` is by
  definition the quotient of `Type 0`, so every set-sized cardinality — in
  particular ≥ ℵ₁, which any Part-2 witness needs — is realized by some
  `V : Type`. No hidden restriction; `aleph 1 ≤ Cardinal.mk ↥S` elaborates at
  universe 0 consistently. Pass.
- **Not vacuous / no degenerate witness.** Empty or countable V cannot witness
  either part: a graph with countably many edges admits an *injective* edge
  colouring into ℕ, under which no triangle (a fortiori no infinite clique) is
  monochromatic. So any witness is uncountable, and the statements are the
  genuinely deep open questions. (Sanity check for Part 2: K\_{ℵ₀} on ℕ itself
  fails — colour each pair by its minimum; any 3 vertices a < b < c use two
  distinct minima, so there is no monochromatic triangle, let alone an infinite
  monochromatic clique.) Pass.
