## Summary

The problem (verbatim from the recovered page, **PROVED** banner): "If $G$ is a graph
which contains odd cycles of $\leq k$ different lengths then $\chi(G)\leq 2k+2$, with
equality if and only if $G$ contains $K_{2k+2}$." Conjectured by Bollobás–Erdős
([Er90] is the source key), confirmed for $k=1$ by Bollobás–Shelah, and proved in full
by Gyárfás [Gy92]. The Lean input (`conjectures/58.lean:35-40`) states, for a finite
graph with `(oddCycleLengths G).ncard ≤ k`, the conjunction
`χ(G) ≤ 2k+2 ∧ (χ(G) = 2k+2 ↔ ∃ s, G.IsNClique (2k+2) s)`. Read back independently,
this is a faithful direct-assertion rendering of the proved statement with the correct
(affirmative) polarity; I found no semantic defects. The nits are scholarship-level:
the docstring cites `[Gy92]` without defining it, and the page's source key `[Er90]`
and the Gao–Huo–Ma strengthening `[GaHuMa21]` are missing — all added in
`conjectures-v2/58.lean`, together with a page-confirmed variant for the Gao–Huo–Ma
result. The input file is untouched.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of lines 35–39: "for every finite simple graph $G$ and
  every $k$, if the set of odd cycle lengths of $G$ has at most $k$ elements, then
  $\chi(G) \le 2k+2$, and $\chi(G) = 2k+2$ iff $G$ has a clique on $2k+2$ vertices."
  This matches the recovered source statement term by term; "contains $K_{2k+2}$"
  (as a subgraph) is exactly "has a $(2k+2)$-clique".
- The equality biconditional is correctly scoped *under* the hypothesis `hk` (both
  conjuncts inside the same implication), matching "…then χ(G) ≤ 2k+2, with equality
  iff…". Both directions are genuine under `ncard ≤ k` (not just `= k`): (←) a
  $(2k+2)$-clique gives $\chi \ge 2k+2$, and with the first conjunct, equality; (→) is
  Gyárfás's theorem, vacuously true when the actual count $j < k$ since then
  $\chi \le 2j+2 < 2k+2$.
- Not vacuous / not trivial: $K_{2k+2}$ itself has odd cycle lengths exactly
  $\{3, 5, \dots, 2k+1\}$ — $k$ values — so the hypothesis is satisfiable with the
  bound attained; the statement is the substantive proved theorem.
- Instance checks (batch checklist: verify helper + statement on small cases, not just
  cardinality): $k=1$, $G=K_4$: odd lengths $\{3\}$, $\chi = 4 = 2\cdot1+2$, contains
  $K_4$ ✓ (the Bollobás–Shelah case). $G=C_5$: odd lengths $\{5\}$, $\chi = 3 \le 4$,
  $\chi \ne 4$ and no $K_4$ ✓. Petersen: odd lengths $\{5,9\}$, $k=2$:
  $\chi = 3 \le 6$, no $K_6$, $\chi \ne 6$ ✓.
- `[Fintype V]` restricts to finite graphs where the source says "graph". This is the
  setting of Gyárfás's proof and the standard corpus convention (upstream 751.lean
  does the same with a de Bruijn–Erdős note); it also makes the `ncard` encoding
  honest (see A2). Noted as a limitation in the v2 docstring, not a defect.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no division, no `Finset.range` anywhere.
- **`Set.ncard` junk value** (this batch's degenerate-input class): `ncard` of an
  infinite set is 0, which would make `hk` vacuously true and the statement false for
  graphs with infinitely many odd cycle lengths. Guarded here: with `[Fintype V]`,
  every `Walk.IsCycle` has distinct support-tail vertices, so its length is at most
  `Fintype.card V`; `oddCycleLengths G` is therefore finite and `ncard` counts it.
  Checked explicitly, no defect.
- `chromaticNumber : ℕ∞`; both `≤ (2*k+2 : ℕ)` and `= (2*k+2 : ℕ)` compare after the
  standard `ℕ → ℕ∞` coercion — no junk, no `⊤` issues on a finite graph.
- Cycle-length parity: `p.length` counts edges; a cycle on $n$ vertices has $n$ edges,
  so `Odd n` is exactly "odd cycle". Mathlib cycles have length ≥ 3, so the degenerate
  "length-1 odd cycle" cannot enter the set.
- Vacuous-quantifier check at $k = 0$: hypothesis = no odd cycles = bipartite;
  conclusion: $\chi \le 2$ and $\chi = 2 \leftrightarrow \exists K_2$ — both correct
  (including empty/edgeless graphs: $\chi \in \{0,1\}$, no $K_2$, iff holds with both
  sides false).
- No liminf/limsup, no filters, no `StrictMono`/`Monotone`, no default-valued binders,
  no `∃C`-absorption pattern (no existential constants at all).
