## Summary

The problem: let $A \subset \mathbb{N}$ be such that every large integer can be written
as $n^2 + a$ with $a \in A$, $n \ge 0$ (an *additive complement of the squares*).
**Part 1:** what is the smallest possible value of
$\limsup |A \cap \{1,\ldots,N\}| / N^{1/2}$? **Part 2:** is
$\liminf |A \cap \{1,\ldots,N\}| / N^{1/2} > 1$? Status OPEN (the open content is Part 1
and the quantitative liminf constant; Part 2 as literally asked was answered "yes" by
Moser [Mo65] with $> 1.06$, best known $\ge 4/\pi$ [Ci93][Ha95][BaRa01]). The Lean file
defines the complement predicate and the normalized counting function
$f_A(N) = |A \cap \{1,\ldots,N\}|/N^{1/2}$ (both correct), then states (i)
`erdos_problem_33_liminf`: for every such $A$,
`1 < Filter.liminf (fun N => f A N) atTop` in ℝ, and (ii)
`erdos_problem_33_limsup_finite`: some such $A$ has uniformly bounded $f_A$. Statement
(ii) is faithful and true. Statement (i) is **provably false as written**: for
$A = \mathbb{N}$ (which satisfies the predicate via $m = 0^2 + m$), $f_A(N) = \sqrt N \to
\infty$, Mathlib's ℝ-valued liminf degenerates to the junk value
$0 = \operatorname{sSup}$ of a set that is not bounded above, and $1 < 0$ fails. The
intended proposition ("liminf $> 1$ in the extended-real sense") is true and proved;
only the encoding is wrong. Fixed in v2 with the junk-free encoding
$\exists c > 1$ eventually $f_A(N) \ge c$, following the problem-1132 precedent.

## A. Semantic fidelity

**A1. Statement fidelity — Part 2 defect (encoding, see A2); rest pass (source-verified).**

- Recovered verbatim source statement (session log `0a7847b8`, single capture): "Let
  $A\subset\mathbb{N}$ be such that every large integer can be written as $n^2+a$ for
  some $a\in A$ and $n\geq 0$. What is the smallest possible value of
  $\limsup \lvert A\cap\{1,\ldots,N\}\rvert/N^{1/2}$? Is
  $\liminf \lvert A\cap\{1,\ldots,N\}\rvert/N^{1/2}>1$?" The module-level docstring
  (lines 24–37) reproduces this faithfully, including the [Er56, p.134] source key.
- `IsAdditiveComplementOfSquares` (lines 15–16): "∃ N₀, ∀ m ≥ N₀, ∃ n a, a ∈ A ∧
  m = n² + a" — exactly "every large integer is $n^2 + a$"; `n : ℕ` makes $n \ge 0$
  automatic; addition and squaring are in ℕ with no truncation issues. (The upstream
  formal-conjectures file strengthens to "every integer" with a formalisation note;
  this file matches the page verbatim instead — both are legitimate, and the class of
  admissible $A$ differs only by finite modifications, which cannot change the
  liminf/limsup quantities.)
- `sqrtNormalizedCount` (lines 21–22): `((Finset.Icc 1 N).filter (· ∈ A)).card / (N:ℝ)
  ^ ((1:ℝ)/2)` — the window `Icc 1 N` is exactly the source's $\{1,\ldots,N\}$
  (term-by-term, not just asymptotically), the cast is applied before division, and the
  exponent is real rpow. Correct.
- Back-translation of `erdos_problem_33_liminf` (lines 38–41): "for every additive
  complement $A$, the ℝ-valued liminf of $f_A$ along atTop exceeds 1." As a
  *mathematical* sentence this matches Part 2's affirmative direction **only when**
  $f_A$ is eventually bounded above; otherwise the Lean value is junk and the statement
  diverges from the source — and unbounded $f_A$ does occur for admissible $A$
  (e.g. $A = \mathbb{N}$). **[defect]** — details in A2, fix in v2.
- Back-translation of `erdos_problem_33_limsup_finite` (lines 47–50): "some additive
  complement has $f_A(N) \le C$ for all $N \ge 1$." Uniform boundedness is equivalent
  here to finite limsup (each $f_A(N)$ is a finite real; eventual boundedness plus
  finitely many finite exceptions gives a global bound), so this faithfully captures
  "there exist $A$ for which the limsup is finite" — the existence presupposition of
  Part 1, true by Erdős's observation and witnessed explicitly by van Doorn's
  construction. It avoids `Filter.limsup` entirely, so no junk-value risk.
- Part 1's actual question (the *smallest* value of the limsup) is a value request
  about an open quantity; it is mentioned in the docstring ("we ask for the smallest
  possible value") but not formalized — see A4/B2.
- Not vacuous/trivial: the predicate is satisfiable ($A = \mathbb{N}$), the liminf
  claim (once correctly encoded) is a nontrivial proved theorem, and the boundedness
  claim requires a genuinely sparse-yet-complementary witness; no degenerate set
  satisfies both sides trivially.

**A2. Lean semantics traps — one failure, the [defect].**

- **ℝ-valued `Filter.liminf` junk value (defect).** Mathlib:
  `liminf u f = limsInf (map u f)` and `limsInf F = sSup {a | ∀ᶠ n in F, a ≤ n}`
  (`Mathlib/Order/LiminfLimsup.lean:59,69`, verified in the scratchpad mathlib4 clone),
  with `Real.sSup` returning **0** for sets not bounded above
  (`Real.sSup_of_not_bddAbove`, used e.g. in `Mathlib/Data/Real/Pointwise.lean:63`).
  Take `A = Set.univ : Set ℕ`: it satisfies `IsAdditiveComplementOfSquares` (witness
  `N₀ = 0`, `n = 0`, `a = m`), and `sqrtNormalizedCount univ N = N / √N = √N → ∞`, so
  `{c | ∀ᶠ N, c ≤ √N} = Set.univ` is not bounded above, the liminf evaluates to the
  junk value 0, and the asserted `1 < 0` is false. The universally quantified theorem
  `erdos_problem_33_liminf` is therefore **provably false as written**, independent of
  the (true) mathematics it intends. Fix: encode "liminf > 1 in the extended-real
  sense" junk-free as `∃ c : ℝ, 1 < c ∧ ∀ᶠ N in atTop, c ≤ f A N` (equivalent to
  `1 < liminf` over `EReal`; proof of equivalence: ⇐ eventual bound gives liminf ≥ c >
  1; ⇒ pick real c strictly between 1 and the liminf, then some element of the
  defining set exceeds c, giving the eventual bound). Applied in v2.
- ℕ subtraction: none anywhere. Pass.
- Division: real division only. At `N = 0` the denominator is `(0:ℝ) ^ ((1:ℝ)/2) = 0`
  (rpow of zero base, nonzero exponent), so `f A 0 = 0/0 = 0` — harmless under
  `atTop`, and the second theorem guards with `0 < N` anyway. Pass.
- `Finset.Icc 1 N` vs `Finset.range`: `Icc 1 N = {1,…,N}` matches the source window
  exactly; no off-by-one. Pass.
- Vacuous quantifiers: none (the `∃ N₀, ∀ m ≥ N₀` shape is the standard "sufficiently
  large" encoding and is satisfiable/nontrivial). Pass.
- "For all sufficiently large" / liminf encodings: the *predicate's* eventual
  quantification is correct; the *liminf* encoding is the defect above.
- `StrictMono`/`Monotone`, strict vs non-strict, open vs closed intervals: not
  applicable / consistent (`>1` strict matches the source question; `≤ C` for a bound
  is the right non-strict form).
- Problem-25 checklist addition: **no default-valued binders** — `grep -nE
  '\(\s*[A-Za-z_][^)]*:='` finds nothing; no `optParam` can silently unconstrain
  anything. Pass.
- `filter (· ∈ A)` over an arbitrary `Set ℕ` needs decidability — supplied by
  `open Classical` (line 9). Pass.
