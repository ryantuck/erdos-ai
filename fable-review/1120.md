## Summary

The problem (Problem 4.22 in Hayman's 1974 "new problems" collection [Ha74], attributed
to Erdős): let $f\in\mathbb{C}[z]$ be a monic polynomial of degree $n$ with all roots in
the closed unit disk, and let $E=\{z:\lvert f(z)\rvert\le 1\}$. What is the shortest
length of a path in $E$ joining $z=0$ to $\lvert z\rvert=1$? The page's remarks pin the
formalizable core: the interesting quantity is the *worst-case* behaviour in $n$, and
Erdős wrote "presumably this tends to infinity with $n$, but not too fast". The status
is OPEN. The Lean file (`conjectures/1120.lean:29`) asserts Erdős's conjectured
direction directly: for every $C>0$, for all sufficiently large $n$ there is an
admissible $f$ of degree $n$ such that every continuous path in $E$ from $0$ to the
unit circle has arc length (total variation) $\ge C$. Read back independently, this is
exactly "the worst-case shortest length $W(n)\to\infty$", which is the right
formalizable content, in the corpus's standard direct-assertion form for open
conjectures with a stated expected direction. I found no semantic defects; the nits are
scholarship-level (the `[Ha74]` key is used but never defined — the raw file has no
module docstring or bibliography) and optional page-confirmed variants.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $f\in \mathbb{C}[z]$ be a
  monic polynomial of degree $n$, all of whose roots satisfy $\lvert z\rvert\leq 1$.
  Let \[E= \{ z : \lvert f(z)\rvert \leq 1\}.\] What is the shortest length of a path
  in $E$ joining $z=0$ to $\lvert z\rvert =1$?" Remarks: Erdős's "presumably this tends
  to infinity with $n$, but not too fast"; trivial lower bound $1$ achieved by
  $f(z)=z^n$; "the interesting side of this question is what the worst case behaviour
  is (as a function of $n$)"; Clunie–Netanyahu path existence (personal communication
  reported in [Ha74]).
- Independent back-translation of lines 29–38: "for every $C>0$ there is $N$ such that
  for every $n\ge N$ there is a monic $f$ of degree $n$ with all roots in the closed
  unit disk such that every continuous $\gamma:\mathbb{R}\to\mathbb{C}$ mapping
  $[0,1]$ into $E$, with $\gamma(0)=0$ and $\lvert\gamma(1)\rvert=1$, has total
  variation on $[0,1]$ at least $C$."
- Equivalence with the conjecture, checked by hand: let $L(f)=\inf_\gamma \text{length}
  (\gamma)$ and $W(n)=\sup_f L(f)$ over admissible degree-$n$ $f$. The Lean statement
  says $\forall C\,\exists N\,\forall n\ge N\,\exists f: L(f)\ge C$, which implies
  $W(n)\ge C$ eventually, i.e. $W(n)\to\infty$. Conversely $W(n)\to\infty$ gives, for
  $n$ large, $W(n)\ge C+1$, hence (sup possibly not attained) some $f$ with
  $L(f)\ge C$. The universal quantification over all $C>0$ absorbs the attainment gap,
  so the two are equivalent. This matches the prior review's conclusion, with the
  sup-attainment subtlety made explicit.
- Quantifiers: $C$, $N$, $n$, $f$, $\gamma$ in the right order; degree is *exactly*
  $n$ (`f.natDegree = n` with `f.Monic`), and existence of admissible $f$ for every
  $n$ is witnessed by $z^n$, so the $\exists f$ is never over an empty class.
- Types: `Polynomial ℂ` with `f.eval`; `f.roots` over the algebraically closed field ℂ
  gives the full multiset of roots (with multiplicity) for the nonzero (monic) $f$, so
  `∀ z ∈ f.roots, ‖z‖ ≤ 1` is exactly "all roots in the closed unit disk". Closed disk
  (`≤ 1`) matches the source's $\lvert z\rvert\le 1$; the lemniscate uses non-strict
  `≤ 1` matching the source's $E$.
- Path encoding: `γ : ℝ → ℂ` with `Continuous γ` (global) constrained on `Icc 0 1` is
  equivalent to quantifying over continuous paths on $[0,1]$: restriction preserves
  the hypotheses in one direction, and constant extension
  ($\gamma(t)=p(\max(0,\min(1,t)))$) preserves them, and the variation on `Icc 0 1`,
  in the other. Endpoint on the circle *and in $E$* (since `1 ∈ Icc 0 1`) is the
  correct reading of "a path in $E$ joining $z=0$ to $\lvert z\rvert=1$"; any path in
  $E$ reaching the circle can be truncated at its first circle hit, so this loses no
  generality for the shortest-length question.
- Not vacuous/trivial: $0\in E$ automatically ($|f(0)|=\prod_i|r_i|\le 1$), and the
  Clunie–Netanyahu theorem guarantees an admissible path exists for every admissible
  $f$, so the inner `∀ γ` is never satisfied vacuously; no degenerate witness makes
  the statement trivially true. (Even in the hypothetical of an $f$ with no connecting
  path, the informal shortest length would be $\inf\varnothing=+\infty\ge C$, so the
  encoding would still agree with the intent.) The statement is trivially true for
  $C\le 1$ via the distance bound — harmless, since $C$ ranges over all positive
  reals and the content lives at large $C$.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction, no division anywhere. `N ≤ n` on ℕ is safe.
- No `Finset.range`; the only interval is `Set.Icc (0:ℝ) 1`, closed on both ends as
  required for path endpoints.
- `ENNReal.ofReal C ≤ eVariationOn γ (Icc 0 1)`: `eVariationOn` is `ℝ≥0∞`-valued —
  total variation, which is the arc length for rectifiable paths and `⊤` for
  non-rectifiable ones (then the inequality holds, correctly: a non-rectifiable path
  is certainly not shorter than $C$). For $C>0$, `ENNReal.ofReal C` is exactly $C$;
  no truncation issue.
- No liminf/limsup/filter encodings; "tends to infinity with $n$" is unfolded
  ε-N-style (`∀ C > 0, ∃ N, ∀ n ≥ N, …`), which is the correct arithmetization.
- No `StrictMono`/`Monotone` issues. Strict vs non-strict: `C > 0` hypothesis, `≥ C`
  conclusion — either strictness convention encodes divergence; consistent.

**A3. Definitions — pass.**

- `lemniscateSet` (lines 11–12) matches its docstring and the source's $E$ exactly,
  including degenerate inputs: for the zero polynomial `eval` is $0$, `‖0‖ ≤ 1`, so
  the set is all of ℂ — irrelevant here since the theorem constrains to monic $f$.
  For $n=0$ (monic constant $1$), $E=\mathbb{C}$ and the shortest length is $1$;
  handled harmlessly by the `∃ N` cutoff. No `sorry` in any `def`. No drift between
  the def and its use in the theorem.

**A4. Question form and answer polarity — pass (with encoding note).**

- The source is a **value request** ("What is the shortest length…?") whose answer

  "presumably this tends to infinity with $n$" — the right target with the right
  polarity. Erdős's "but not too fast" is a qualitative upper-bound sentiment with no
  precise content to formalize; correctly omitted (now noted in the v2 docstring).
- No binders before the colon (line 29 is binder-free), so nothing is spuriously
  universally quantified.

**A5. Solution status — pass (source-verified).**
