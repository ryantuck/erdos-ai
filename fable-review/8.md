## Summary

The problem (erdosproblems.com/8, DISPROVED): *"For any finite colouring of the integers
is there a covering system all of whose moduli are monochromatic?"* — conjectured by
Erdős and Graham [ErGr80, p.25]. The answer is **no**, by Hough's theorem [Ho15] that
every covering system (distinct moduli > 1) contains a modulus below an absolute bound
(10¹⁶, improved to 616000 by [BBMST22]): colour all small integers distinctly and all
large ones with one fresh colour. The Lean file (`conjectures/8.lean:37-40`) asserts the
correct negated direction — `∃ k, 0 < k ∧ ∃ χ : ℕ → Fin k, ∀ S, IsCoveringSystem S →
¬HasMonochromaticModuli χ S` — but its `IsCoveringSystem` (lines 8–11) requires only
nonemptiness, positive moduli, and covering, **not distinct moduli and not moduli > 1**.
Read literally the proposition is false: for *every* colouring χ, the complete residue
system `{(0, 2), (1, 2)}` is a covering system whose moduli (both equal to 2) are
trivially monochromatic; so is the singleton `{(0, 1)}`, which even has distinct moduli.
The intended disproof sketch in the file's own docstring silently relies on the
distinctness the definition never states. This is the same defect family as
`conjectures/2.lean` (reviewed this batch), verified here independently; unlike
problem 2, here the modulus-1 degeneracy is also fatal, so the fix needs both
`HasDistinctModuli` and `1 < p.2`.

## A. Semantic fidelity

**A1. Statement fidelity — DEFECT.**

- Recovered verbatim source statement: "For any finite colouring of the integers is
  there a covering system all of whose moduli are monochromatic?" Status banner
  DISPROVED ("This has been solved in the negative.").
- Independent back-translation of `conjectures/8.lean:37-40`: "there is a positive
  number of colours k and a colouring χ of ℕ with k colours such that no nonempty
  finite set S of pairs (a, m) ∈ ℤ × ℕ with all m > 0 covering ℤ (every n satisfies
  m ∣ (n − a) for some (a, m) ∈ S) has all its moduli of one χ-colour." This is the
  correct shape for "answer no": ¬(∀ colouring ∃ monochromatic covering system) ≡
  ∃ colouring ∀ covering systems ¬monochromatic.
- **The Lean proposition is false as written.** Two independent counterexamples, each
  defeating *every* colouring χ : ℕ → Fin k:
  1. `S₁ = {(0, 2), (1, 2)}`: nonempty; moduli 2 > 0; every `n : ℤ` is ≡ 0 or 1
     (mod 2), so `IsCoveringSystem S₁`; and `HasMonochromaticModuli χ S₁` holds with
     `c = χ 2` since both elements have modulus 2. (Repeated-modulus degeneracy —
     the same complete-residue-system trick as problem 2's counterexample.)
  2. `S₂ = {(0, 1)}`: nonempty; modulus 1 > 0; `(1 : ℤ) ∣ (n − 0)` for all n, so
     `IsCoveringSystem S₂`; monochromatic with `c = χ 1` (a singleton is always
     monochromatic). Note `S₂` even satisfies `HasDistinctModuli`, so distinctness
     alone does not repair the statement — the modulus-1 exclusion is independently
     necessary.
  Hence the `∀ S` clause fails for every χ, the existential is false, and the file
  formalizes a false proposition in place of the true resolution.
- Root cause: "covering system" in Erdős's usage means congruences with distinct
  moduli `1 < m₁ < m₂ < … < mₖ` [ErGr80]. Corroborations internal to this corpus:
  (i) `conjectures/7.lean:17-18` defines `HasDistinctModuli` for exactly this reason;
  (ii) the file's own docstring disproof sketch (lines 26–32) only works under
  distinctness — "a small modulus with a unique colour" forces all moduli equal to it,
  which contradicts covering only when moduli cannot repeat and exceed 1; (iii) the
  page's DISPROVED status presupposes this reading — under the file's literal reading
  the original question would be trivially answered "yes" by `{(0,2),(1,2)}`, the
  opposite direction; (iv) this batch's problem-2 review established the same
  convention from the upstream `StrictCoveringSystem` docstring citing [ErGr80].
- Fixed in `conjectures-v2/8.lean` by adding two hypotheses to the theorem:
  `HasDistinctModuli S` (encoding copied verbatim from `conjectures/7.lean`) and
  `∀ p ∈ S, 1 < p.2` (not compile-verified). The fixed statement is true: take
  χ(n) = n for n ≤ 616000 and one fresh colour above; any qualifying S contains a
  modulus m ≤ 616000 [BBMST22] whose colour is unique to m, so monochromaticity forces
  all moduli = m, whence by distinctness |S| = 1, and one congruence mod m > 1 does
  not cover ℤ.
- Not-vacuous check of the fixed statement: distinct-moduli covering systems with all
  moduli > 1 exist (Erdős's classical `{0 (2), 0 (3), 1 (4), 5 (6), 7 (12)}`), so the
  `∀ S` clause quantifies over a rich class and the claim is the substantive resolved
  theorem, not a vacuity.

**A2. Lean semantics traps — pass (no issues beyond A1).**

- No ℕ subtraction: `n - p.1` is subtraction in ℤ; the modulus is cast `(p.2 : ℤ)`
  before use.
- No division; `(p.2 : ℤ) ∣ (n - p.1)` with `p.2 > 0` is the standard exact encoding
  of `n ≡ a (mod m)`.
- No `Finset.range`, no index arithmetic, no off-by-one surface.
- No vacuous quantifiers: `S.Nonempty` is explicit (and implied by the covering clause
  since ℤ is inhabited — harmless redundancy); `HasMonochromaticModuli` on a nonempty
  `S` is a genuine constraint.
- No filters/limits. Strictness: the theorem's `0 < p.2` (via `IsCoveringSystem`)
  should effectively be `1 < p.2` for this problem — part of the A1 defect, handled
  there.
- Minor observation (not a defect): the `0 < k` conjunct is redundant — for `k = 0`
  no function `χ : ℕ → Fin 0` exists (ℕ is inhabited, `Fin 0` is empty), so the inner
  existential is already false. Kept for clarity.

**A3. Definitions — pass relative to their own docstrings; the defect is seated here.**

- `IsCoveringSystem` (lines 8–11) matches its own docstring, including degenerate
  inputs (empty set excluded, modulus 0 excluded). `HasMonochromaticModuli`
  (lines 17–18) matches its docstring exactly (∃ colour received by every modulus).
  No `sorry` in any definition.
- However, definition and theorem *jointly* diverge from the source's "covering
  system" (distinct moduli > 1) — the A1 defect. The fix adds separate hypotheses
  rather than changing `IsCoveringSystem`, keeping the smallest diff and cross-file
  consistency with `conjectures/2.lean`/`7.lean` and this batch's
  `conjectures-v2/2.lean`.
- Colouring domain: `χ : ℕ → Fin k` colours ℕ while the problem colours "the
  integers"; only the colours of moduli (positive naturals) are ever queried, so the
  restriction is harmless — same judgment as the prior review, re-derived.

**A4. Question form and answer polarity — acceptable form, polarity correct.**

- The original is a yes/no question ("…is there a covering system…?"), solved in the
  negative. The file uses direct-assertion form stating the true direction (the

  of the question.
- No `answer()` wrapper, so no binder-before-colon hazard; `erdos_problem_8` is
  binder-free before the colon (line 37); the colouring is correctly existentially
