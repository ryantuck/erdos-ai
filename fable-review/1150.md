## Summary

The problem (OPEN on the source page): does there exist a constant c > 0
such that, for all large n and all polynomials P of degree n with
coefficients ±1, max_{|z|=1} |P(z)| > (1+c)√n? Equivalently (page remark,
with flipped polarity): do ultraflat ±1 polynomials *not* exist — Kahane
showed they do exist if the coefficients may be arbitrary unimodular
complex numbers (site problem [230]), and a weaker two-sided flatness
question is site problem [228]. The Lean file (`conjectures/1150.lean`,
lines 36–43) asserts: there exist c > 0 and N₀ such that for every n ≥ N₀
and every ε : Fin (n+1) → ℤ with all values in {−1, 1}, some z on the unit
circle has (1+c)√n < ‖∑ᵢ ε i · zⁱ‖. Read back independently, this is
exactly the asked ("yes") direction of the displayed question, in the
direct-assertion form this raw corpus uniformly uses for open yes/no
questions — and it matches, proposition for proposition, the RHS of the
upstream formal-conjectures `answer(sorry) ↔ …` encoding recovered from the
logs. I found no semantic defects; the one defect is bibliographic (both
citation keys used are defined nowhere).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Does there exist a
  constant $c>0$ such that, for all large $n$ and all polynomials $P$ of
  degree $n$ with coefficients $\pm 1$,
  $\max_{\lvert z\rvert=1}\lvert P(z)\rvert > (1+c)\sqrt{n}$?" — status
  banner **OPEN** (tooltip: "This is open, and cannot be resolved with a
  finite computation."), with the owner's standard disclaimer. Source line
  `#1150: [Ha74,4.31][Va99,2.36]`; tags analysis, polynomials.
- Independent back-translation of lines 37–42: "there exist c > 0 and a
  threshold N₀ such that for every n ≥ N₀ and every ±1 coefficient sequence
  ε of length n+1, some z with ‖z‖ = 1 satisfies
  (1+c)·√n < ‖∑_{i=0}^{n} ε i · zⁱ‖." This is the displayed question as
  asked.
- **max vs ∃-witness:** the source's max_{|z|=1}|P(z)| > (1+c)√n is encoded
  as ∃ z, ‖z‖ = 1 ∧ (1+c)√n < ‖P(z)‖. For a *strict* lower bound this is
  equivalent to sup > bound for any nonempty index set, even without
  attainment (and here the max is attained anyway: ‖P‖ is continuous on the
  compact circle). The encoding is exactly right, and it sidesteps the
  `⨆`-over-sphere machinery the upstream file needs (a conditionally
  complete sup on ℝ). Sound choice.
- **Degree exactly n:** "polynomials of degree n with coefficients ±1" ↔
  ε : Fin (n+1) → ℤ, ∀ i, ε i ∈ {−1, 1}. The leading coefficient ε n is ±1
  ≠ 0, so the represented polynomial has degree exactly n; conversely every
  degree-n Littlewood polynomial is of this shape. Faithful in both
  directions, with no separate `natDegree = n` hypothesis needed (upstream
  needs one because it quantifies over all of ℂ[X]).
- Quantifier structure: ∃ c, 0 < c ∧ ∃ N₀, ∀ n ≥ N₀, ∀ ε … — c is uniform
  over all large n and all P, exactly the source's "a constant c > 0 such
  that, for all large n and all polynomials". ∃ N₀, ∀ n ≥ N₀ is the correct
  filter-free rendering of "for all large n" (upstream: `∀ᶠ n in atTop`).
- Types: coefficients ℤ (cast to ℂ at evaluation), evaluation in ℂ, bound
  in ℝ with `Real.sqrt ↑n` and complex-modulus norm — arithmetic happens in
  the intended structures throughout. Strict `<` matches the source's
  strict `>`.
- Indexing: the sum ∑ i : Fin (n+1), ε i · z^(i:ℕ) runs over exponents
  0, …, n — exactly ∑_{i=0}^n. No off-by-one; no 1-indexed sequence to
  reconcile.
- Not vacuous or trivially true/false: the ∀-over-ε makes it a substantive
  universal lower-bound claim (Erdős's well-known conjecture, still open);
  for n below N₀ nothing is claimed, and no degenerate witness family
  trivializes it. Computational cross-check (this review): for all n ≤ 10,
  the minimum over all sign patterns of the sampled sup-norm exceeds
  1.14·√(n+1), comfortably above √n — consistent with the conjectured
  direction and with the statement biting.

**A2. Lean semantics traps — pass.**

- **ℕ subtraction: none.** The −1 values live in ℤ (ε : … → ℤ) and are cast
  to ℂ; no natural subtraction anywhere.
- Division: none anywhere.
- `Finset.range`: not used; the complete `Fin (n+1)` sum has no boundary
  trap, and `Fin (n+1)` is never empty.
- Vacuous quantifiers: `∀ n ≥ N₀` over ℕ is never vacuous; the inner ∀ ε is
  over a nonempty type. At the degenerate n = 0 (only relevant if N₀ = 0):
  P = ±1, √0 = 0, and ‖P(z)‖ = 1 > 0 — the statement is true there, not
  vacuous, and in any case N₀ absorbs small n exactly as "for all large n"
  intends.
- "For all sufficiently large": ∃ N₀, ∀ n ≥ N₀ — correct encoding (see A1).
- No `StrictMono`/`Monotone`; strict inequality and the closed condition
  ‖z‖ = 1 both match the source (the unit circle, not the disc).
