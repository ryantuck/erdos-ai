## Summary

The problem (Erdős–Hajnal, [ErHa66, p.77][ErHa85]): *does every graph with chromatic
number ℵ₁ contain an infinitely connected subgraph with chromatic number ℵ₁?* — where a
graph is infinitely connected if any two vertices are joined by infinitely many pairwise
(internally vertex-)disjoint paths. The answer is **no**: Komjáth [Ko13] proved
consistency of "no", Soukup [So15] gave a ZFC counterexample, Bowler–Pitz [BoPi24] a
simpler one; the page status is **DISPROVED (LEAN)**. The Lean file (pre-fix) asserted
the negation `¬ (∀ V G, ¬CardColorable ℵ₀ → ∃ S, (G.induce S).IsInfinitelyConnected ∧
¬(G.induce S).CardColorable ℵ₀)` with local defs `CardColorable`,
`Walk.internalVertices`, `IsInfinitelyConnected`. Polarity (negation = answer "no") is
correct and the overall architecture is sound, but back-translation exposed two semantic
defects: (1) the disjointness clause admits duplicate paths, so adjacent vertex pairs
satisfy the "infinitely many disjoint paths" condition vacuously via n copies of the
single-edge path — making the asserted negation a strictly stronger, unestablished claim;
(2) "chromatic number ℵ₁" was weakened to "not countably colorable" (χ ≥ ℵ₁), which is
not the same proposition as the source's/upstream's exact ℵ₁. Both fixed.

## A. Semantic fidelity

**A1. Statement fidelity — two defects (both fixed).**

- Recovered verbatim source statement: "Does every graph with chromatic number
  $\aleph_1$ contain an infinitely connected subgraph with chromatic number $\aleph_1$?"
  The file's docstring reproduces it verbatim. Recovered remark: "We say a graph is
  infinitely connected if any two vertices are connected by infinitely many pairwise
  disjoint paths." Since distinct u–v paths necessarily share their endpoints, the
  file's internally-vertex-disjoint reading is the only coherent one (the site treats
  Thomassen's *edge*-disjoint version as a separate variant), so that interpretation is
  correct.
- **[defect 1] Duplicate-path loophole.** Pre-fix, `IsInfinitelyConnected` required
  `∀ i j, i ≠ j → Disjoint (paths i).internalVertices (paths j).internalVertices` with
  no distinctness requirement on `paths`. The unique length-1 path along an edge u–v has
  `internalVertices = ∅`, and `Disjoint ∅ ∅` is `True`; hence for every **adjacent**
  pair u,v and every n, the constant family `fun _ => edgePath` satisfies `IsPath` and
  pairwise disjointness. So K₂ — indeed any complete graph, via connectivity alone —
  counts as "infinitely connected". Impact analysis: the buggy predicate is *weaker*
  than the intended one, so inside the negated universal the existential `∃ S` becomes
  easier to satisfy, the universal harder to refute, and the theorem's asserted negation
  **strictly stronger** than the literature's theorem. Soukup's/Bowler–Pitz's results
  say every *genuinely* infinitely connected subgraph of their graphs is countably
  chromatic; they do not obviously rule out an uncountably chromatic induced subgraph
  that passes the weak test only because its "bad" pairs are adjacent. The pre-fix
  statement is therefore not established by the cited solution (and is possibly false).
  **Fixed** by adding pairwise distinctness `paths i ≠ paths j` to the disjointness
  clause. With distinctness the encoding is exact: at most one member of a disjoint
  family can have empty internal vertex set (the edge path is the unique path with
  support ⊆ {u,v}).
- **[defect 2] Exact ℵ₁ vs "uncountably chromatic".** The source and the upstream
  formalization (`G.chromaticCardinal = ℵ_ 1`) read "chromatic number ℵ₁" as *exactly*
  ℵ₁. Pre-fix, both hypothesis and conclusion used only `¬CardColorable ℵ₀`
  (χ ≥ ℵ₁). These are different propositions: the pre-fix universal quantifies over a
  strictly larger class of graphs (e.g. ℵ₂-chromatic ones), so its negation is a priori
  weaker. The two negations are *not* interderivable by ZFC trivialities: converting an
  uncountably-chromatic witness into an exactly-ℵ₁-chromatic one needs chromatic-number
  reflection ("χ ≥ ℵ₁ implies a subgraph with χ = ℵ₁"), and chromatic incompactness
  phenomena (consistently, ℵ₂-chromatic graphs whose small subgraphs are countably
  chromatic) show such reflection principles are delicate. The pre-fix negation was
  still *true* (any exact witness is an uncountable witness: an induced infinitely
  connected subgraph H of a χ = ℵ₁ witness has χ(H) ≤ ℵ₁, so χ(H) > ℵ₀ would force
  χ(H) = ℵ₁, contradiction), with correct polarity — but it was a corollary, not the
  problem. **Fixed** to `CardColorable (ℵ_ 1) ∧ ¬CardColorable ℵ₀` in hypothesis and
  conclusion, which pins χ to exactly ℵ₁ since no cardinal lies strictly between ℵ₀ and
  ℵ₁ (monotonicity of `CardColorable` in κ, plus κ < ℵ₁ ↔ κ ≤ ℵ₀).
- **Induced vs arbitrary subgraph — benign, documented.** The source says "subgraph";
  upstream uses `∃ H : G.Subgraph`. The file uses `∃ S : Set V, G.induce S`. These are
  equivalent for this property by an elementary argument: if H ⊆ G is any subgraph that
  is infinitely connected with χ(H) = ℵ₁, then G induced on H's vertex set has ⊇ H's
  edges, so it is still infinitely connected (the same paths work) and its chromatic
  number is ≥ χ(H) yet ≤ χ(G) = ℵ₁, hence exactly ℵ₁. Unlike defect 2's reflection
  issue, this equivalence is robust and elementary; kept as-is, now documented in the
  docstring.
- Quantifier structure: `V : Type` (Type 0) suffices — ℵ₁ ≤ 2^ℵ₀ always (every countable
  ordinal is coded by a real), so Type 0 contains vertex types of cardinality ℵ₁ and the
  known counterexamples are realizable; upstream also uses `(V : Type)`.
- Not vacuous/trivial: the negation demands a genuine counterexample graph; no
  degenerate instance (empty S is excluded by `Connected`'s `Nonempty`; singleton or
  countable S fail the χ = ℵ₁ conclusion).

**A2. Lean semantics traps — pass after fix.**

- No ℕ subtraction or division anywhere.
- `Disjoint` on `Set V` is lattice disjointness — correct; the ∅-∅ corner case is
  exactly defect 1, now neutralized by distinctness.
- "Infinitely many" is encoded as `∀ n : ℕ, ∃ paths : Fin n → …` rather than an infinite
  family. With distinctness this is *equivalent* to the existence of an infinite
  pairwise internally disjoint family, because walks are finite: if no infinite disjoint
  family exists, a maximal disjoint family F is finite, every path not in F meets the
  finite set W = ⋃ internal vertices of F (else F ∪ {p} contradicts maximality — the
  only W-avoiding paths are F's members), so any disjoint family has size ≤ |W| + |F|,
  contradicting ∀n. Documented in the def's docstring. `n = 0, 1` are trivially
  satisfiable — harmless.
- Vacuous quantifiers: `∀ u v, u ≠ v → …` correctly excludes the diagonal ("any two
  vertices" = distinct); a one-vertex graph is vacuously `IsInfinitelyConnected` but can
  never satisfy the χ = ℵ₁ conclusion — harmless.
- `#α ≤ κ` with `α : Type u`, `κ : Cardinal.{u}` is universe-consistent; at the use
  sites `V : Type` and `↥S : Type`, so `ℵ₀, ℵ_ 1 : Cardinal.{0}` — consistent.
- No `StrictMono`/`Monotone`, `Finset.range`, or interval-endpoint issues arise.

**A3. Definitions — pass after fix.**

- `CardColorable` matches its docstring ("colorable with at most κ colors"): `∃ α, #α ≤
  κ ∧ Nonempty (G.Coloring α)`. Degenerate κ = 0 gives colorability only for empty V —
  correct. No `sorry` in any def.
- `Walk.internalVertices` = support minus the two endpoints — matches its docstring,
  including the length-1 path (∅) and the u–x–v path ({x}).
- `IsInfinitelyConnected` pre-fix contradicted its own docstring ("n paths … with
  pairwise disjoint internal vertices" implies *distinct* paths informally, but the code
  did not); post-fix, code and docstring agree.
- New `IsInfinitelyEdgeConnected` (added for the Thomassen variant) is
  `(G.deleteEdges s).Connected` unfolded into walk language (nonempty + for every finite
  edge set s, every pair joined by a walk avoiding s) so as to use only constructs
  already reachable from the file's imports; a walk in `G.deleteEdges s` is exactly a
  G-walk whose edges avoid s.

**A4. Question form and answer polarity — pass (raw style).**

- The source is a yes/no question; the raw file uses direct-assertion form, which is
  acceptable raw style for a solved problem when the polarity is the true direction. The
  answer is "no" and the file asserts the **negation** of the universally quantified
  question — polarity correct. (The upstream styled artifact uses `answer(False) ↔ ∀ …`,
  the question-form equivalent; both encode "the answer is no".)
- No binders before the colon; the theorem is binder-free and the ∀ V G sits inside the
  negation, so nothing is spuriously universally quantified.

**A5. Solution status — pass (source-verified).**

- Recovered banner: **DISPROVED (LEAN)** — "This has been solved in the negative and the
