## Summary

The problem (erdosproblems.com/2, DISPROVED, $1000 prize): *"Can the smallest modulus
of a covering system be arbitrarily large?"* — Erdős's "perhaps my favourite problem".
Hough [Ho15] answered no: the smallest modulus of a covering system **with distinct
moduli** is at most 10¹⁶, improved to 616000 by Balister–Bollobás–Morris–Sahasrabudhe–
Tiba [BBMST22]; Owens [Ow14] constructed one with minimum modulus 42. The Lean file
(`conjectures/2.lean:26-29`) asserts `∃ B : ℕ, ∀ S, IsCoveringSystem S → ∃ p ∈ S,
p.2 ≤ B`, where `IsCoveringSystem` (lines 8–11) requires only nonemptiness, positive
moduli, and covering — **not distinct moduli**. Read literally, that proposition is
false: for any `B`, the complete residue system mod `B + 1`, i.e.
`{(0, B+1), (1, B+1), …, (B, B+1)}`, satisfies `IsCoveringSystem` and every one of its
moduli exceeds `B`. Erdős's question is only non-trivial (and Hough's theorem only
true) for covering systems with pairwise distinct moduli — this is Erdős's own standard
usage [ErGr80], is how Hough's paper states the minimum modulus problem, and is even
spelled out in this repo's own `conjectures/7.lean` (`HasDistinctModuli`) and in the
upstream library's `StrictCoveringSystem` docstring ("this corresponds to the notion of
a covering system that Erdos was using in [ErGr80]"). The prior ai-review explicitly
considered this point and endorsed the wrong side of it.

## A. Semantic fidelity

**A1. Statement fidelity — DEFECT.**

- Recovered verbatim source statement: "Can the smallest modulus of a covering system
  be arbitrarily large?" Status banner DISPROVED ("This has been solved in the
  negative."), $1000 prize.
- Independent back-translation of `conjectures/2.lean:26-29`: "there is a natural
  number B such that every nonempty finite set S of pairs (a, m) ∈ ℤ × ℕ, with all
  m > 0, such that every integer n satisfies m ∣ (n − a) for some (a, m) ∈ S, contains
  a pair with m ≤ B."
- **The Lean proposition is false as written.** Counterexample: fix any `B` and let
  `m = B + 1`, `S = {(0, m), (1, m), …, (m−1, m)} : Finset (ℤ × ℕ)`. Then `S` is
  nonempty; every modulus is `m > 0`; and every `n : ℤ` has `n ≡ r (mod m)` for its
  residue `r ∈ {0, …, m−1}`, with `(r, m) ∈ S`. So `IsCoveringSystem S` holds, yet
  every `p ∈ S` has `p.2 = B + 1 > B`. Hence `¬∃ B, …` — the file formalizes a false
  statement in place of Hough's theorem.
- The root cause is a missing hypothesis, not wrong polarity: "covering system" in
  Erdős's minimum-modulus problem means a system with **pairwise distinct moduli**
  (Erdős's convention [ErGr80]; Hough's paper poses exactly the distinct-moduli
  version; with repeated moduli allowed the question answers itself trivially "yes"
  via complete residue systems, contradicting the page's DISPROVED = "answer no").
  Three internal corroborations, none requiring outside literature: (i)
  `conjectures/7.lean:17` defines `HasDistinctModuli` and its docstring calls the
  distinct-moduli notion "a **distinct covering system**"; (ii) the upstream library's
  `StrictCoveringSystem` (recovered from the formal-conjectures session logs) is
  exactly `CoveringSystem` + `injective_moduli` and its docstring says this "corresponds
  to the notion of a covering system that Erdos was using in [ErGr80]"; (iii) the page
  itself, by marking the problem DISPROVED with a 10¹⁶ bound, presupposes the
  distinct-moduli reading — under the file's reading the correct resolution would be
  "yes, trivially", the opposite direction.
- With the distinctness hypothesis added, the statement is exactly the resolved form:
  ∃ B bounding the minimum modulus of every distinct-moduli covering system. **Fixed
  in `conjectures-v2/2.lean`** (not compile-verified).
- Not-vacuous check of the fixed statement: it is Hough's Annals theorem — substantive,
  with the witness B = 616000 currently best. The modulus-1 corner (`{(0,1)}` is a
  distinct-moduli covering system with smallest modulus 1) only makes the bounded
  statement easier, never false, and is documented in the v2 docstring.

**A2. Lean semantics traps — pass (no issues beyond A1).**

- No ℕ subtraction: `n - p.1` is subtraction in ℤ (`p.1 : ℤ`); the modulus is cast

- No division anywhere; `(p.2 : ℤ) ∣ (n - p.1)` with `p.2 > 0` is the standard, exact

- `∃ B : ℕ` / `p.2 ≤ B` — non-strict bound over ℕ matches "at most B". No

## E. Prior-review audit (`deepmind/ai-review/2.md`)

The prior review is well-organized and gets the page metadata right, but its central
correctness judgment is wrong, and the error is of the most consequential kind on
record in this corpus:

1. **Explicitly endorsed the falsifying encoding (§6, "Distinct vs. non-distinct
   moduli").** It writes: "The definition does not require distinct moduli. This is
   correct — Problem 2 is about general covering systems (not 'distinct' or 'strict'
   covering systems as in Problem 7). The `Finset` type prevents duplicate *pairs* but
   allows multiple congruences with the same modulus (different residues), which is the
   correct behavior." Every clause of this is backwards: Problem 2 *is* the
   distinct-moduli minimum modulus problem (Hough's paper, Erdős's [ErGr80] usage, the
   upstream library's own `StrictCoveringSystem` note), and the allowed same-modulus
   freedom is exactly what makes the formal statement false (complete residue system
   counterexample, §A1). The review considered the precise failure point, had the
   sibling Problem 7 distinction in hand, and blessed the wrong side. Its verdict
   "**The formalization is mathematically correct** … No mathematical flaws" is false.
2. **Its own §5 reasoning contradicts §6.** §5 argues the original question is
   equivalent to ¬(∃ B, …) and that the formalization "correctly captures the negation
   of Erdős's expectation." Under the non-distinct definition it endorsed in §6, the
   original question's answer would be trivially *yes* (mod-m complete residue
   systems), i.e. Erdős's expectation would hold vacuously — flatly inconsistent with
   the page's DISPROVED status the review itself reports in §2. This is the
   1005-pattern failure ("endorsing an encoding that contradicts its own reading of
   the source") in its purest form.
3. **Its proposed variants inherit the defect (§3).** The suggested `erdos_2_upper`
   (∀ covering system, ∃ modulus ≤ 616000) is *false* without distinctness, and the
   suggested `erdos_2_lower` (∃ covering system with all moduli ≥ 42) is *trivially
   true* without distinctness — the 42-bound achievement it credits to Owens would be
