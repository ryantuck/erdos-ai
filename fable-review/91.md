## Summary

The problem asks: for sufficiently large $n$, if $A \subset \mathbb{R}^2$ has $|A| = n$
and minimises the number of distinct distances, prove that there exist at least two (and
probably many) non-similar such $A$. Status: **OPEN**. The Lean file defines
`numDistinctDistances` (the distinct-distance count for a finite planar point set) and
`AreSimilar` (geometric similarity via a distance-scaling map), then states
`erdos_problem_91`: for large enough $n$, every $n$-point minimiser admits a non-similar
minimiser. Read back independently, the Lean and the English agree; no semantic defects
found.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $n$ be a sufficiently large
  integer. Suppose $A\subset \mathbb{R}^2$ has $|A|=n$ and minimises the number of
  distinct distances between points in $A$. Prove that there are at least two (and
  probably many) such $A$ which are non-similar."
- Independent back-translation of `erdos_problem_91` (lines 31–42): "There exists $N$
  such that for all $n \ge N$, for every $n$-element subset $A$ of $\mathbb{R}^2$ that
  minimises the number of distinct distances among all $n$-element subsets, there exists
  another $n$-element subset $A'$ that also minimises the distinct-distance count and is
  not similar to $A$." This matches the source.
- "At least two non-similar minimisers" ⟺ "every minimiser has a non-similar companion":
  if all minimisers were mutually similar, pick any one; if not, any minimiser either has
  a non-similar companion or is itself the outlier. The formalisations are logically
  equivalent. ✓
- Not vacuous: the statement is a substantive open conjecture about the structure of
  distance-minimising configurations; the minimiser hypothesis is nontrivial (such
  configurations are known to exist for every $n$).
- Quantifier structure matches: $\exists N, \forall n \ge N, \forall A$ (minimiser),
  $\exists A'$ (minimiser, not similar). ✓

- Definitions used consistently in the theorem. No drift. ✓
