## Summary

The problem (DISPROVED, $100 prize): an $\epsilon$-almost covering system is
a set of congruences $a_i \pmod{n_i}$ for distinct moduli
$n_1 < \ldots < n_k$ such that the density of integers satisfying none of
them is $\leq \epsilon$; is there a constant $C > 1$ such that for every
$\epsilon > 0$ and $N \geq 1$ there is an $\epsilon$-almost covering system
with $N \leq n_1 < \cdots < n_k \leq CN$? Filaseta, Ford, Konyagin,
Pomerance, and Yu [FFKPY07] proved the answer is no. The Lean file
(`conjectures/27.lean:40-50`) asserts the negation directly:
`¬ ∃ C > 1, ∀ ε > 0, ∀ N ≥ 1, ∃ S` with distinct moduli, nonempty, moduli
$\geq 2$ and in $[N, CN]$, and `uncoveredDensity S ≤ ε`, where
`uncoveredDensity` computes the proportion of one LCM-period left uncovered
(`conjectures/27.lean:35-38`). Read back independently, this is the proved
(true) direction of the disproved question; the auxiliary side conditions
(`S.Nonempty`, moduli $\geq 2$) are harmless — I verified by hand that they
do not change the truth value (see A1). No semantic defects; the findings
are polish-level (no bibliography at all, no theorem docstring, redundant
`Finset.` qualification, undocumented degenerate cases of the density
helper).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "An $\epsilon$-almost
  covering system is a set of congruences $a_i\pmod{n_i}$ for distinct
  moduli $n_1<\ldots<n_k$ such that the density of those integers which
  satisfy none of them is $\leq \epsilon$. Is there a constant $C>1$ such
  that for every $\epsilon>0$ and $N\geq 1$ there is an $\epsilon$-almost
  covering system with $N\leq n_1<\cdots <n_k\leq CN$?"
- Independent back-translation of lines 40–50: "there is no real $C > 1$
  such that for every real $\epsilon > 0$ and every natural $N \geq 1$ there
  is a finite set $S$ of (residue, modulus) pairs with pairwise-distinct
  moduli, $S$ nonempty, all moduli $\geq 2$, all moduli in $[N, CN]$, and
  the uncovered proportion of one LCM-period at most $\epsilon$." This is
  the negation of the question as asked — the FFKPY07 result.
- Quantifier order `∃ C, ∀ ε, ∀ N, ∃ S` matches "a constant $C$ … for every
  $\epsilon$ and $N$ … there is a system" exactly; the negation wraps the
  whole existential, as it must.
- "Distinct moduli $n_1 < \cdots < n_k$" is distinctness plus an ordering
  convention; `hasDistinctModuli S` (`S.card = (S.image Prod.snd).card`,
  line 25–26) is exactly injectivity of the modulus projection on `S`, and a
  `Finset` of pairs needs no ordering. Faithful.
- **Side conditions checked by hand.** The source does not state
  `S.Nonempty` or moduli $\geq 2$; both make the inner existential *harder*,
  so the negated statement is formally weaker. I verified the truth value is
  unchanged: (i) for $N \geq 2$ the constraint $N \leq p.2$ makes both
  automatic; (ii) at $N = 1$ the unrestricted question is trivially
  satisfiable via the modulus-1 congruence, and the restricted one is
  satisfiable for every $C \geq 12$ via the classical covering system
  $\{0\,(2), 0\,(3), 1\,(4), 5\,(6), 7\,(12)\}$ (distinct moduli in
  $[2,12]$, covers $\mathbb{Z}$ — checked residue-by-residue mod 12, density
  0); (iii) `P(C)` is monotone in $C$ (a system in $[N, CN]$ is in
  $[N, C'N]$ for $C' \geq C$), so $\exists C\, P(C)$ may be tested on
  $C \geq 12$, where restricted and unrestricted agree. Hence the two
  negations are equivalent, not merely both true. No defect; the modulus
  $\geq 2$ guard follows the standard covering-system convention.
- Not vacuous: the negation is the substantive FFKPY07 theorem. Sanity
  check of the polarity's truth: for fixed $C$ and large $N$, any admissible
  system has uncovered density $\geq (1-o(1))\prod_i(1-1/n_i) \geq
  (1-o(1))\prod_{N \le n \le CN}(1-1/n) = (1-o(1))\frac{N-1}{CN} \to 1/C
  > 0$, so $\epsilon < 1/(2C)$ defeats every $C$ — the assertion is the true
  direction.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction: the only subtraction is `(↑x - p.1)` in ℤ (line 38),
  with `x : ℕ` cast before subtracting. Correct.
- Division: `card / (L : ℝ)` (line 38) — for the theorem's witnesses
  (nonempty, all moduli $\geq 2$) the LCM satisfies $L \geq 2$, so no
  division by zero. On degenerate inputs outside the theorem's constraints
  the def yields junk (`S = ∅` → $1/1 = 1$, correct in spirit; a modulus 0 →
  $L = 0$ → junk value 0) — I checked these cannot leak into the theorem:
  a witness with modulus 0 fails `N ≤ p.2` (and `p.2 ≥ 2`), so no
  trivially-covered junk witness exists. Documented in the v2 docstring.
- `Finset.range L` is $\{0, \dots, L-1\}$ — exactly one full period; since
  every modulus divides $L$, coverage of $x$ depends only on
  $x \bmod L$, so the proportion equals the natural density of the
  uncovered integers (over ℕ or ℤ — the set is periodic, densities agree).
  No off-by-one.
- Membership test `(↑p.2 : ℤ) ∣ (↑x - p.1)` is precisely
  $x \equiv a_i \pmod{n_i}$; the filter keeps the integers satisfying
  *none* of the congruences, matching "satisfy none of them".
- No vacuous bounded quantifiers with degenerate effect: `∀ p ∈ S, …` over
  an (enforced nonempty) `Finset`; the `∀ ε > 0` / `∀ N ≥ 1` guards match
  the source ranges.
- No `StrictMono`/`Monotone`, interval-endpoint, or filter-encoding issues

  periodicity).
- Checklist addition (problem-25 pattern): **no `:=`-defaulted binders**

  arguments. Pass.

## E. Prior-review audit (`deepmind/ai-review/27.md`)

The prior review (written against the styled copy) is largely accurate —
its correctness section is genuinely careful (it checks the `S = ∅` LCM
edge case, the `N = 1` modulus-1 shortcut, and the polarity of
`answer(False)` correctly). Findings:

1. **Proposed variant falls into the ℕ-arithmetic trap it should guard
   against.** Its §3 sketch for the averaging variant writes
   `uncoveredDensity S ≤ ∏ m in Finset.Icc m₁ m₂, (1 - 1 / m)` with
   `m : ℕ` and no cast: in ℕ, `1 / m = 0` for `m ≥ 2` and so `1 - 1/m = 1`,
   making the right side `1` (or `0` if `m₁ ≤ 1`) — the proposed statement
   is trivially true, not the page's bound. Exactly the A2 division/
   subtraction failure mode this checklist exists for. The v2 variant casts
   to ℝ (`(1 - 1 / (m : ℝ))`) and pins the moduli set to
   `S.image Prod.snd = Icc m₁ m₂` (the page says the system uses *the* set
   of moduli $[m_1,m_2] \cap \mathbb{N}$, not a subset).
2. **Volume number supplied without provenance.** It states the full FFKPY07
   citation "J. Amer. Math. Soc. **20** (2007), no. 2, 495–517" as fact;
   the recovered `/latex/27` extraction has no volume numbers, so the
   volume/issue came from model knowledge. It happens to be consistent with
   the sibling corpus and my own knowledge, and a later logged fc-session
   normalized the styled file's citation accordingly — but per this
   pipeline's rules such data must be provenance-flagged (done in v2), and
   its own §2 table says nothing about where "20, no. 2" came from.
3. **Missing-citation call understated.** "No missing critical citations" —
   yet the styled file (and a fortiori the raw file) defines no `[Er95]`
   entry, the problem's *source* reference (`#27: [Er95,p.4]` on the page).
   It also treats `[Ho15]`/`[BBMST22]` as optional context, which is fair,
   but the omission of the source key should have been flagged.
4. **What it got right, re-derived.** The `answer(False) ↔ P` polarity
   analysis; the `p.2 ≥ 2` redundancy-for-`N ≥ 2` observation; the
   periodicity argument identifying the LCM-proportion with natural density;
