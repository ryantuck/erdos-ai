## Summary

The problem (recovered verbatim from the archived page): "Let $f(n)$ be the size of the
largest subset $A\subseteq \{1,\ldots,n\}$ such that there are no three distinct elements
$a,b,c\in A$ such that $a\mid b$ and $a\mid c$. How large can $f(n)$ be? Is
$\lim f(n)/n$ irrational?" Status: **OPEN**. The Lean file defines `HasDivisorFork`
(three distinct elements with $a \mid b$, $a \mid c$), defines
$f(n)$ = `maxNoDivisorForkSize n` as the max cardinality over the fork-free members of
the powerset of `Icc 1 n`, and asserts `∃ α : ℝ, Irrational α ∧ Tendsto (f n / n) atTop
(nhds α)` — i.e. the limit exists and is irrational, the conjectured affirmative answer.
The definitions are exactly right, including degenerate cases; the encoding coincides
with the `P` side of the upstream `P ↔ answer(sorry)` statement (`erdos_1062.parts.ii`,
recovered from the logs). The one defect was documentary: the pre-fix theorem docstring
stated "The limit lim f(n)/n exists and is irrational." as if it were the problem's
content, silently converting the open question into an assertion and dropping the "How
large can f(n) be?" sentence — the same drift pattern as the 1005 defect. Notably, an
earlier git version of this very file (commit 0d9074d5, session 687043fe) had the
question form and fuller remarks; the current rewrite (session 40fa71fe, commit
f31c8395) regressed them. Fixed in place.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of the theorem (`conjectures/1062.lean`, pre-fix lines
  39–43): "there is an irrational real α such that
  `maxNoDivisorForkSize n / n → α` as `n → ∞`." This is the conjectured "yes" to the
  page's question "Is $\lim f(n)/n$ irrational?" (which presupposes/includes existence
  of the limit); it is literally the proposition `P` in the upstream open-question
  encoding `P ↔ answer(sorry)`.
- `HasDivisorFork` (lines 11–13 pre-fix): ∃ three *pairwise distinct* elements with
  $a \mid b$ and $a \mid c$ — exactly the source's forbidden configuration, with all
  three distinctness conditions present (dropping `b ≠ c` would wrongly forbid mere
  divisor pairs).
- `maxNoDivisorForkSize` (lines 24–27 pre-fix): `Finset.sup` of `card` over the
  fork-free members of `(Icc 1 n).powerset`. `Finset.Icc 1 n` = $\{1,\dots,n\}$ — the
  1-indexing is term-by-term exact. The empty set is always fork-free, so the filtered
  powerset is nonempty and `sup` is the genuine maximum — **no `sSup`-junk-value issues**
  (contrast the 1005 encoding); at $n = 0$, $f(0) = 0$ correctly.
- Not vacuous/trivial: by Lebensold $f(n)/n$ eventually lies in $[0.6725, 0.6736]$, so
  the existence-plus-irrationality assertion is a substantive open claim; no degenerate
  witness satisfies `Tendsto` trivially.
- The soft "How large can $f(n)$ be?" estimate request is not directly formalizable; the
  irrationality question is the formalizable core (upstream likewise formalizes it as
  `parts.ii`). Noted, not a defect; the growth remarks are now recorded and the two
  page-stated bounds added as variants.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere.
- ℕ division: none. Field division `(f n : ℝ) / (n : ℝ)` returns 0 at `n = 0`
  (Lean convention) — harmless under `atTop`.
- No `Finset.range`; `Icc 1 n` handles the source's $\{1,\dots,n\}$ exactly.
- No vacuous bounded quantifiers. For $|A| \le 2$, `HasDivisorFork A` is correctly
  false (no three distinct elements exist), matching the informal notion.
- `Tendsto _ atTop (nhds α)` is the standard, correct encoding of
  $\lim f(n)/n = \alpha$; bundling `Irrational α` under the ∃ correctly renders "the
  limit exists and is irrational".
- No `StrictMono`/`Monotone` or interval-endpoint issues.

**A3. Definitions — pass, two docstring nits (fixed).**

- Both defs match the source; no `sorry` in any def/instance (the `DecidablePred`
  instance is a real `infer_instance` proof, and the pipeline log records a clean
  `lake build` of exactly the current code).
- Nit (fixed): `HasDivisorFork`'s docstring said "A subset A of {1,...,n}" although the
  def takes an arbitrary `Finset ℕ` — the ambient-set restriction lives in
  `maxNoDivisorForkSize`, not here.
- Nit [deferred]: `noncomputable` on `maxNoDivisorForkSize` is likely unnecessary given
  the `DecidablePred` instance (`filter`/`sup` are computable); harmless, and removal is
  compiler-dependent — left in place.

**A4. Question form and answer polarity — acceptable raw style; docstring drift was the
defect (fixed).**

- The source is a yes/no question ("Is $\lim f(n)/n$ irrational?"), and the problem is
  OPEN. This repo's raw conjecture style has no `answer()` wrapper; raw files uniformly
  state open conjectures as direct assertions with `sorry` (cf. `conjectures/1005.lean`
  pre-styling, whose assertion form the 1005 review accepted *for the raw file*, and
  `conjectures/1004.lean`, `1059.lean`). Judged on soundness: the asserted direction is
  the conjectured affirmative, and it coincides exactly with the `P` side of the
  upstream `erdos_1062.parts.ii : P ↔ answer(sorry)` — so nothing is asserted with
  wrong polarity, and any future styling pass has the correct `P` to wrap.
- **[defect] (docstring):** the pre-fix theorem docstring stated "The limit lim f(n)/n
  exists and is irrational." flatly, as though that were the problem statement — the
  question sentence was dropped, precisely the 1005 restyling-drift pattern (open
  question silently converted to bare assertion). An earlier git version of this file
  kept the question and added "Formulated as: the limit exists and is irrational."; the
  current rewrite lost that honesty. **Fixed**: the docstrings now quote both source
  questions and label the assertion as the conjectured-affirmative formalization
  (not compile-verified — no `lake build` in this container, though the code region is
  unchanged).
- No binders before the colon on the main theorem (binder-free `theorem
  erdos_problem_1062 :`).

**A5. Solution status — pass (source-verified, post-fix).**

- Recovered page banner: **OPEN**, tooltip "This is open, and cannot be resolved with a
  finite computation.", plus the owner's standard disclaimer. Both captures agree. Raw
  files carry no `@[category]` attributes, so there is nothing to contradict; pre-fix

   banner, OEIS A038372, and both citation keys' data were all absent pre-fix; all
   recoverable items are now recorded.
3. **Upstream fragment audit (context, not a defect of this file).** The recovered
   upstream docstring line "The interval `[⌊n/3⌋, n]` is fork-free" is **literally
   false** for every $n \ge 3$: with $k = \lfloor n/3 \rfloor \ge 1$ one has
   $3k \le n$, so $\{k, 2k, 3k\}$ is a divisor fork inside $[\lfloor n/3\rfloor, n]$.
   The correct witness is the half-open version $\{\lfloor n/3\rfloor + 1, \dots, n\}$
   (equivalently the page's $[m+1, 3m+2]$), which has exactly
   $\lceil 2n/3 \rceil$ elements — so upstream's *theorem*
   $\lceil 2n/3 \rceil \le f(n)$ is still true; only its docstring witness is off by
   one. The variant added here documents the corrected witness. (Same failure class as
   the invented-then-excused justifications caught in the 1000/1005 audits: a plausible
   witness that fails at the boundary.)
4. **Original pipeline sessions audited.** Two sessions formalized 1062 independently
   (687043fe on 2026-02-22; 40fa71fe on 2026-03-06); both built successfully and encode
   the same mathematics with different $f$ encodings; the later one silently overwrote
