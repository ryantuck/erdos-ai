## Summary

The problem (OPEN, asked by Erdős and Sárközy [ErSa70]): *let $A$ be an infinite set
such that there are no distinct $a,b,c \in A$ with $a \mid (b+c)$ and $b,c > a$.*
Three questions: (1) is there such an $A$ with
$\liminf |A \cap \{1,\ldots,N\}| / N^{1/2} > 0$? (2) does there exist an absolute
constant $c > 0$ such that there are always infinitely many $N$ with
$|A \cap \{1,\ldots,N\}| < N^{1-c}$? (3) is it true that $\sum_{n \in A} 1/n < \infty$?
The Lean file defines `SumDivFree` (the triple condition) and `counting`
($|A \cap \{1,\ldots,N\}|$ via `Finset.Icc 1 N`) and states the three parts as
`erdos_problem_12a` (∃ A with an eventual lower bound $\varepsilon \le$ count$/\sqrt N$
— the correct unfolding of liminf > 0), `erdos_problem_12b` (∃ c > 0, ∀ A, arbitrarily
large N with count < $N^{1-c}$), and `erdos_problem_12c` (∀ A, all finite partial sums
of $1/n$ bounded — i.e. summability). Read back independently, all three agree with the
source questions, asserted in the affirmative direction per this corpus's convention
for open yes/no questions. I found no semantic defects; the findings are
enrichment-level (missing keys [Er97b], [Er97e], [Er98]; no bibliography; none of the
page's four partial results captured).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $A$ be an infinite set such
  that there are no distinct $a,b,c\in A$ such that $a\mid (b+c)$ and $b,c>a$. Is there
  such an $A$ with $\liminf \frac{\lvert A\cap\{1,\ldots,N\}\rvert}{N^{1/2}}>0$? Does
  there exist some absolute constant $c>0$ such that there are always infinitely many
  $N$ with $\lvert A\cap\{1,\ldots,N\}\rvert<N^{1-c}$? Is it true that
  $\sum_{n\in A}\frac{1}{n}<\infty$?"
- `SumDivFree` (`conjectures/12.lean:13-16`), back-translated: for all $a,b,c \in A$,
  pairwise distinct, with $a < b$ and $a < c$: $a \nmid b+c$. This is exactly "no
  distinct $a,b,c \in A$ with $a \mid (b+c)$ and $b,c > a$": the source's condition
  makes $a$ the strict minimum of the triple, and both orderings of the unordered pair
  $\{b,c\}$ are covered by the symmetric quantification. The `a ≠ b`/`a ≠ c` hypotheses
  are redundant (implied by `a < b`/`a < c`); the substantive distinctness is `b ≠ c`
  (without it the condition would wrongly forbid $a \mid 2b$). Correct.
- `counting` (`:19-20`): `(Finset.Icc 1 N).filter (· ∈ A) |>.card` is exactly
  $|A \cap \{1,\ldots,N\}|$; `Icc 1 N = {1,…,N}` — no off-by-one, `0 ∉ Icc 1 N`.
- **Part 1** (`erdos_problem_12a`, `:29-32`), back-translated: there is an infinite
  `SumDivFree` set $A$ and $\varepsilon > 0$ with count$/\sqrt N \ge \varepsilon$ for
  all large $N$. For a real sequence, $\liminf x_N > 0 \iff \exists \varepsilon > 0$
  with $x_N \ge \varepsilon$ eventually (⇐: liminf ≥ ε > 0; ⇒: take
  $\varepsilon = \liminf/2$) — an exact unfolding, valid also when the ratio is
  unbounded. Matches the question.
- **Part 2** (`erdos_problem_12b`, `:42-46`): ∃ c > 0 (absolute — quantified *outside*
  $A$, as "absolute constant" requires), ∀ infinite `SumDivFree` $A$,
  ∀ M ∃ N ≥ M with count < $N^{1-c}$. "Always" = for every such $A$; "infinitely many
  $N$" = "arbitrarily large $N$" (correct for a predicate on ℕ). Matches.
- **Part 3** (`erdos_problem_12c`, `:55-60`): for every infinite `SumDivFree` $A$,
  some $M$ bounds $\sum_{n \in F} 1/n$ over all finite $F \subseteq A$. For
  non-negative terms, boundedness of all finite partial sums is equivalent to
  $\sum_{n \in A} 1/n < \infty$ (and to Mathlib `Summable`, the upstream encoding).
  Matches.
- Not vacuous/trivial, all three: Part 1 is a genuine existence question (the best
  known construction, Elsholtz–Planitzer [ElPl17], falls short of $\sqrt N$ by log
  factors, and the $p^2$, $p \equiv 3 \pmod 4$ example achieves only
  $\sqrt N/\log N$); Part 2 asserts a bound no known construction contradicts (the
  Erdős–Sárközy best-possible theorem produces count $> N/f(N)$ only for *infinitely
  many* $N$, not all, so it does not refute Part 2); Part 3 is open (note the three
  parts are mutually consistent as formalized: a Part-1 witness has $n$-th element
  $\ll n^2/\varepsilon^2$... in fact $\gg$, giving $\sum 1/n < \infty$, and Part 2
  with $c \le 1/2$ coexists with Part 1).
- Mutual consistency/internal sanity: for the $p^2$ example the property holds because
  $p \equiv 3 \pmod 4$ makes $-1$ a quadratic non-residue mod $p$, so
  $p \mid q^2 + r^2$ would force $p \mid q, r$, impossible for primes $q, r > p$ — the
  page's example checks out mathematically (recorded in v2's docstring; not
  formalized, see B2).
