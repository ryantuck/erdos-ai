## Summary

The problem [EHP58, p.142]: if $f \in \mathbb{C}[x]$ is a monic polynomial with all roots
satisfying $|z| \le r$ for some $r < 2$, must $\{z : |f(z)| < 1\}$ have a connected
component with diameter $> 2 - r$? Pommerenke [Po61] proved the answer is **no** for
$r > 1$ (via $f(z) = z^n - r^n$, whose sublevel set breaks into $n$ components of
vanishing diameter) and **yes** for $0 < r \le 1$; the page banner is DISPROVED (LEAN).
The Lean file (`deepmind/1048.lean`) encodes this as `answer(False) ↔ P` with `P` the
universally quantified question, which is the right shape and polarity. However, as
written `P` was falsified at *every* radius by the degenerate witness `f = 1` (monic,
vacuously root-bounded, empty sublevel set), so the theorem was trivially provable
without any of Pommerenke's mathematics and the formal question disagreed with the
source's "yes" range $0 < r \le 1$. Fixed by adding a nonconstancy hypothesis
`0 < f.natDegree`.

## A. Semantic fidelity

**A1. Statement fidelity — one [defect], otherwise pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "If $f\in \mathbb{C}[x]$ is a monic
  polynomial with all roots satisfying $\lvert z\rvert \leq r$ for some $r<2$, then must
  $\{ z: \lvert f(z)\rvert <1\}$ have a connected component with diameter $>2-r$?"
- Independent back-translation of the pre-fix theorem: "`False` iff: for every real
  $r \in (0,2)$ and every monic $f \in \mathbb{C}[X]$ with all roots of norm $\le r$,
  the set $S = \{z : |f(z)| < 1\}$ contains a point whose connected component in $S$ has
  diameter $> 2-r$." Quantifier order, types (ℝ radius, `Polynomial ℂ`, `Set ℂ`),
  the strict `< 1` sublevel set, and the strict `2 - r < diam` all match the source.
- **[defect] Degenerate witness trivializes the statement.** The constant polynomial
  `f = 1` is `Monic`, its `roots` multiset is empty (so `∀ z ∈ f.roots, ‖z‖ ≤ r` holds
  vacuously), and $S = \{z : \|1\| < 1\} = \emptyset$, so `∃ z ∈ S, …` fails. Hence the
  pre-fix RHS `P` was false at **every** $r \in (0,2)$ for a junk reason:
  `answer(False) ↔ P` was provable by exhibiting `f = 1` at any single $r$, bypassing
  Pommerenke entirely. Worse for fidelity: restricted to $0 < r \le 1$ the formal `P`
  was still false, whereas the source's answer there is **yes** — the formal question
  and the informal question genuinely disagree. This is exactly A1's "degenerate witness
  … satisfying the formal statement while violating the problem's intent". **Fixed** by
  inserting `0 < f.natDegree →` (nonconstant $f$); then $S$ contains every root of $f$,
  so $S \ne \emptyset$, and `P` becomes false only via Pommerenke's substantive
  counterexamples in $1 < r < 2$ while true on $0 < r \le 1$, matching the source.
  Not compile-verified.
- The `0 < r` hypothesis (absent from the verbatim source, which only says $r < 2$) is a
  faithful reading, not drift: the page's own analysis treats $r$ as a positive radius
  ("if $0<r\leq 1$…"), negative $r$ admits no roots at all, and at $r = 0$ the forced
  witness $f = z^n$ gives a component of diameter exactly $2$, failing the *strict*
  $> 2 - 0$ for a boundary reason. The recovered upstream commit (see Addendum) shows
  `0 < r` was deliberately added for precisely this reason.
- Indexing: no sequences/indices occur; nothing to reconcile.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction or ℕ division anywhere: $2 - r$ is real subtraction; no `range`.
- Division: none in the statement (the only fractions are in docstrings).
- Vacuous quantifiers: the root condition `∀ z ∈ f.roots, ‖z‖ ≤ r` is vacuous exactly
  for rootless $f$ — this was the [defect] above, now closed by `0 < f.natDegree`
  (a degree-$n \ge 1$ monic polynomial over ℂ has $n$ roots with multiplicity).
- `Metric.diam` junk values: `diam ∅ = 0` and `diam` of an *unbounded* set is 0. Neither
  bites post-fix: for nonconstant $f$, $S$ is nonempty (contains the roots) and bounded
  ($|f(z)| \to \infty$), and `connectedComponentIn S z` with `z ∈ S` is nonempty.
- Strict vs non-strict: `< 1` in $S$ and `2 - r < diam` both match the source exactly.
  Pommerenke's counterexample is quoted on the page for $\{|f| \le 1\}$; since
  $\{|f| < 1\} \subseteq \{|f| \le 1\}$ and `connectedComponentIn` is monotone in the
  set, the small-diameter conclusion transfers to the strict set — the encoding of the
  question with `<` is unaffected.
- `connectedComponentIn S z` correctly renders "connected component of $S$" once
  `z ∈ S` is required by the existential.

**A3. Definitions — pass (trivially).**

- No `def`/`abbrev`/`structure` in the file; the sublevel set is a `let`-bound set
  literal inside the statement. No `sorry` outside proof bodies.

**A4. Question form and answer polarity — pass.**

- The source is a yes/no question ("must … have …?"), so `answer(…) ↔ P` is the right
  shape, with `P` the question as asked (affirmative universal form).
- Polarity verified by hand: `P` true would mean "yes"; Pommerenke disproved it, so
  `answer(False)` is correct — and post-fix, `¬P` holds *because of* the $r > 1$
  counterexamples rather than trivially.
- No binders before the colon (`theorem erdos_1048 : answer(False) ↔ …` is binder-free);
  all quantifiers sit inside the iff.

**A5. Solution status — pass (source-verified).**

- Recovered page banner: **DISPROVED (LEAN)** — "This has been solved in the negative
  and the proof verified in Lean." Module docstring, theorem docstring, and
  `@[category research solved]` agree on solved-in-the-negative by Pommerenke [Po61].
  The tag now *understates* the Lean-verified status (formal-conjectures would use

**B2. Variants and completeness — pass; enrichment applied.**

- The problem is single-part; the yes/no question is fully captured.
- The recovered page yields well-confirmed companion results: (i) the answer is no for
  $r > 1$ [Po61]; (ii) the answer is yes for $0 < r \le 1$ [Po61]; and three refined
  positive bounds — (iii) $0 \le r \le 1/2$: component of $0$ has diameter $\ge 2$
  ($f = z^n$ best possible); (iv) $1/2 < r \le (\sqrt5-1)/2$: diameter $> 1/r$;
  (v) $(\sqrt5-1)/2 \le r \le 1$: diameter $> 2 - r^2$; plus the example
  $f(z) = (z^n+1)(z-1)^2(z-\omega)^{-1}(z-\bar\omega)^{-1}$, $\omega = e^{i\pi/n}$,
  showing maximum diameter $< 1 + o(1)$ at $r = 1$. Variants added for (i), (ii),
  (iii); (iv) and (v) deferred — (iv) needs `Real.sqrt`, a construct not in the file,
  and (v) is **literally false at $r = 1$ under the strict sublevel set**: for
  $f(z) = z - 1$ (all roots of modulus $1 \le r$), $|f(0)| = 1$, so $0 \notin S$,
  `connectedComponentIn S 0 = ∅`, `diam = 0`, refuting the claimed $> 2 - r^2 = 1$.
  The page's bullet presumably refers to $\{|f| \le 1\}$ (as in its $r>1$ remark) or
  tacitly assumes $0 \in S$; the caveat is documented in the module docstring rather
  than formalizing a guess.

## E. Prior-review audit (`ai-review/1048.md`)

Accurate on shape, citations, and the small-$r$ edge cases it chose to examine, but it
missed the central defect:

1. **Missed the `f = 1` triviality despite holding the mechanism in its hands.** Its
   §6 edge-case analysis for $r < 0$ says: "only rootless monic polynomials qualify
   (i.e., f = 1 …). Then S = … = ∅, and the existential `∃ z ∈ S, ...` is vacuously
   false." That is precisely the degenerate falsifier — but `f = 1` qualifies at
   **every** $r$, not just $r < 0$. The review confined the observation to $r < 0$,
   labeled it "a **minor inelegance**, not an error", and concluded "**No mathematical
   flaws identified**… a faithful encoding". In fact the theorem was trivially provable
   and the formal question contradicted the page's "yes" on $0 < r \le 1$. This is the
   recurring prior-review pattern (cf. 1000, 1005): a real degeneracy is spotted, then
   excused instead of followed through.
2. **"Citations are correct and complete" overclaims.** Keys, authors, titles, years,
   and pages check out against the recovered extractions, but the volume numbers appear
   in no recoverable source and remain DEFERRED; "complete" was not verifiable.
3. **Its `0 < r` suggestion (§4) was adopted upstream** — the recovered commit diff
   shows `0 < r` added to the upstream file citing exactly its rationale; the deepmind
   file under review already includes it. Credit where due: that suggestion was correct
   and material (it removes the $r \le 0$ and $r = 0$ junk falsifiers it identified).
4. Minor: its §6 claim that `answer(False) ↔ P` "correctly encodes" the disproof is
   right about shape/polarity but wrong about substance, per item 1; its §3 variant list
   matches the recovered page bullets but omits the page's $1 + o(1)$ example and does
