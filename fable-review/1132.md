## Summary

The problem: for $x_1, \ldots, x_n \in [-1,1]$ let
$l_k(x) = \prod_{i \neq k}(x - x_i)/(x_k - x_i)$ be the Lagrange basis polynomials, and
for an infinite sequence $x_1, x_2, \ldots \in [-1,1]$ let
$L_n(x) = \sum_{1 \le k \le n} |l_k(x)|$ (the Lebesgue function of the first $n$
points). **Part 1:** must there exist $x \in (-1,1)$ with
$L_n(x) > \frac{2}{\pi}\log n - O(1)$ for infinitely many $n$? **Part 2:** is
$\limsup_n L_n(x)/\log n \ge 2/\pi$ for almost all $x \in (-1,1)$? Status: OPEN. The
Lean file (`conjectures/1132.lean`) defines the basis polynomials, the Lebesgue
function, prefix extraction, and a validity predicate (injective, in $[-1,1]$), and
states both parts as raw-style direct assertions of the conjectured affirmative. Part 1
(lines 67–71) is a faithful, exact translation. Part 2 (lines 80–83) is **not**: it
uses Mathlib's ℝ-valued `Filter.limsup`, which returns the junk value
$0 = \mathrm{sInf}\,\emptyset$ whenever $L_n(x)/\log n$ has no eventual upper bound —
and I exhibit a concrete valid sequence (nodes clustering at $0$) for which that
happens at a.e. $x$, making the formalized Part 2 provably false regardless of the
open conjecture. This is a [defect]; the corrected junk-free encoding
($\forall c < 2/\pi$, frequently $L_n(x)/\log n \ge c$) is applied in v2.

## A. Semantic fidelity

**A1. Statement fidelity — Part 1 pass; Part 2 defect (deferred to A2).**

- Recovered verbatim source statement (see Addendum): "For $x_1,\ldots,x_n\in [-1,1]$
  let \[l_k(x)=\frac{\prod_{i\neq k}(x-x_i)}{\prod_{i\neq k}(x_k-x_i)},\] which are
  such that $l_k(x_k)=1$ and $l_k(x_i)=0$ for $i\neq k$. Let $x_1,x_2,\ldots\in
  [-1,1]$ be an infinite sequence, and let \[L_n(x) = \sum_{1\leq k\leq n}\lvert
  l_k(x)\rvert,\] where each $l_k(x)$ is defined above with respect to
  $x_1,\ldots,x_n$. Must there exist $x\in (-1,1)$ such that \[L_n(x)
  >\frac{2}{\pi}\log n-O(1)\] for infinitely many $n$? Is it true that
  \[\limsup_{n\to \infty}\frac{L_n(x)}{\log n}\geq \frac{2}{\pi}\] for almost all
  $x\in (-1,1)$?" The module docstring (lines 17–38) reproduces this faithfully.
- Independent back-translation of Part 1 (lines 67–71): "for every injective sequence
  in $[-1,1]$, there exist $x \in (-1,1)$ and $C \in \mathbb{R}$ such that
  $L_n(x) > \frac{2}{\pi}\log n - C$ for infinitely many $n$." This is exactly the
  question's content: "$> \frac{2}{\pi}\log n - O(1)$ infinitely often" means
  $\exists C$ fixed with the strict inequality holding infinitely often, i.e.
  $\limsup_n (L_n(x) - \frac{2}{\pi}\log n) > -\infty$. Quantifier order
  $\exists x, \exists C$ correctly lets the constant depend on the point. Strict `>`
  matches the source; `Set.Ioo` matches the open interval $(-1,1)$; `Set.Icc` in
  `ValidSeq` matches the closed $[-1,1]$ for nodes.

  `Filter.limsup (fun n => L seq n x / log n) atTop ≥ 2/π`." As a *mathematical*
  sentence this matches the source **only when** $L_n(x)/\log n$ is eventually bounded
  above at $x$; otherwise the Lean value is junk (see A2) and the statement diverges
  from the source. **[defect]** — fixed in v2.
- Indexing: `firstN seq n = fun i => seq i.val` uses Lean indices $0,\dots,n-1$ =
  source points $x_1,\dots,x_n$ — term-by-term exact; $L_n$ is built from exactly the
  first $n$ points, with nested prefixes as the source requires.
- Universal quantification over the sequence (theorem binders `seq`, `hseq`) matches

  is universally quantified over sequences. Binders before the colon are legitimate
  here (direct assertions, no `answer()` wrapper; cf. D).
- Not vacuous (Part 1): points $x$ equal to some node $x_j$ give $L_n(x_j) = 1$ for

**A2. Lean semantics traps — one defect (Part 2 limsup), the rest pass.**

- **`Filter.limsup` junk value [defect].** Mathlib defines
  `Filter.limsup f atTop = sInf {a | ∀ᶠ n in atTop, f n ≤ a}` and `Real.sInf ∅ = 0`.
  If $L_n(x)/\log n$ is *not* eventually bounded above (mathematical limsup $+\infty$
  — which *satisfies* the source's condition), the Lean limsup is $0$ and
  `0 ≥ 2/π` is **false**. This is not a boundary curiosity; it makes the theorem as
  stated provably false. Concrete counterexample: take the valid sequence
  $x_k = 1/(k+1)$ (Lean: `seq k = 1/(k+2)`; injective, values in $(0,\tfrac12]
  \subset [-1,1]$). Fix any $x \in (-1,1)$ outside the countable set
  $\{0\} \cup \{x_k\}$; then $\delta(x) := \inf_k |x - x_k| > 0$ (only finitely many
  nodes lie within $|x|/2$ of $x$, each at positive distance since $x$ is not a node;
  the rest are at distance $\ge |x|/2$). For the basis polynomial of the newest node
  $x_n = 1/(n+1)$:
  $\prod_{i=1}^{n-1} |x_n - x_i| = \prod_{i=1}^{n-1} \frac{n-i}{(i+1)(n+1)} =
  \frac{(n-1)!}{n!\,(n+1)^{n-1}} = \frac{1}{n(n+1)^{n-1}}$ exactly, while the
  numerator satisfies $\prod_{i=1}^{n-1} |x - x_i| \ge \delta(x)^{n-1}$. Hence
  $|l_n(x)| \ge n\,(\delta(x)(n+1))^{n-1} \to \infty$ superexponentially (since
  $\delta(x)(n+1) \to \infty$), so $L_n(x)/\log n \to \infty$ for every such $x$ —
  a co-null set. At all these $x$ the set of eventual upper bounds is empty, the Lean
  limsup is $0$, and the a.e. property fails on a full-measure set: for this `seq`,
  `erdos_problem_1132_part2` is **false**, independently of the open conjecture.
  Fix applied in v2: encode the extended-sense limsup as
  `∀ c < 2/π, ∃ᶠ n in atTop, L seq n x / log n ≥ c`, which is exactly equivalent to
  $\limsup \ge 2/\pi$ in $[-\infty,+\infty]$ ((⇒) any $c < 2/\pi$ is exceeded
  frequently; (⇐) the extended limsup dominates every $c < 2/\pi$, hence their
  supremum $2/\pi$) and has no junk regime. This is also the encoding the styled
  `deepmind/deepmind/1132.lean` (lines 105–109) now carries.
- Division: `L seq n x / Real.log n` at $n = 0, 1$ divides by `log 0 = 0`/`log 1 = 0`,
  giving junk $0$ — harmless under `∃ᶠ n in atTop` (finitely many indices never
  witness "frequently") and, pre-fix, under limsup at `atTop`. Division inside
  `lagrangeBasis` is guarded: `firstN seq n` inherits injectivity from `ValidSeq`, so
  all denominators are nonzero wherever the defs are consumed.
- No ℕ subtraction anywhere ($2/\pi\cdot\log n - C$ is real arithmetic; `(n : ℝ)` cast
  before `Real.log`).
- No `Finset.range` off-by-ones: `Fin n` indexing, and the `firstN` prefix
  correspondence is exact (A1).
- Vacuous/degenerate cases: $n = 0$ gives $L \equiv 0$ (empty sum); $n = 1$ gives
  $L \equiv 1$ (empty product inside the single $|l_k|$). Both invisible to `∃ᶠ … atTop`.
- Filter encodings: `∃ᶠ n in atTop, P n` = "infinitely many $n$" — correct for
  Part 1; `∀ᵐ x ∂(volume.restrict (Set.Ioo (-1) 1))` = "for almost all
  $x \in (-1,1)$" — the standard, correct encoding (null sets of the restricted
  measure are exactly sets meeting $(-1,1)$ in Lebesgue-null sets).
- Strict vs non-strict: Part 1 `>` and Part 2 `≥` both match the source; `Ioo`/`Icc`
  placement matches the source's $(-1,1)$ vs $[-1,1]$ exactly.
