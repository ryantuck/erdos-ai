## Summary

The problem (PROVED, tags: additive combinatorics | probability): for 0 < ε < 1
let g_ε(N) be the minimal k such that a uniformly random k-subset A of an abelian
group G of order N has, with probability → 1 as N → ∞, all subset-sum counts
F_A(g) = #{S ⊆ A : Σ_{x∈S} x = g} within a factor (1 ± ε) of 2^k/N. Estimate
g_ε(N); in particular, is g_ε(N) = (1 + o_ε(1)) log₂ N for all ε? The answer is
yes: the trivial lower bound log₂ N plus the Erdős–Hall bound
(1 + O_ε(log log log N / log log N)) log₂ N [ErHa76] resolve it affirmatively.
The Lean file (`conjectures/1179.lean`) defines F_A via `subsetSumCount`, the
uniformity predicate, the good-subset fraction, and a threshold function `g_eps`,
and asserts `g_eps ε N / logb 2 N → 1`. The definitions are individually correct,
but `g_eps` discretizes "with probability → 1" as "good fraction ≥ 1 − 1/N"
(line 63), coupling the confidence level to N — and that changes the mathematics:
for the elementary abelian groups (ℤ/2ℤ)^t the 1/N failure budget forces
g_eps(2^t) ≥ (2 − o(1))·t, so the stated limit is **false** along N = 2^t. This is
a [defect]; the fixed-confidence encoding (explicit δ, quantified over all fixed
δ ∈ (0,1)) is the faithful reading, and is what v2 states.

## A. Semantic fidelity

**A1. Statement fidelity — one [defect]; everything else matches (source-verified).**

- Recovered verbatim source statement (see Addendum) agrees with the module
  docstring (lines 13–31) essentially word for word, including the remarks
  paragraph (trivial lower bound, [ErRe65] and [ErHa76] bounds).
- `subsetSumCount` (lines 36–38): counts S ⊆ A (via `A.powerset`, which includes
  ∅ — correct: the source's set {S ⊆ A : g = Σ_{x∈S} x} includes S = ∅ with sum 0,
  and consistently Σ_g F_A(g) = 2^k) with `S.sum id = g`. Exactly F_A(g).
- `isApproxUniform` (lines 43–47): ∀ g, |F_A(g) − 2^k/N| ≤ ε·2^k/N with N =
  Fintype.card G and k = A.card. `ε * (2:ℝ)^k / N` parses as (ε·2^k)/N = ε·(2^k/N).
  Exact match to the displayed inequality.
- `goodFraction` (lines 51–55): #good k-subsets / #all k-subsets, real division —
  the uniform-measure probability. Correct model of "uniformly random subset of
  size k".
- **[defect] `g_eps` (lines 60–63): the threshold `≥ 1 − 1/N` is not a faithful
  encoding of "with probability → 1 as N → ∞", and it falsifies the theorem.**
  The informal definition is a threshold-function idiom (the property should hold
  with probability tending to 1); any rigorization must pick a confidence level.
  Picking the *N-coupled* level 1 − 1/N demands failure probability ≤ 1/N, which is
  a much stronger requirement than "→ 1" and changes the asymptotics of the
  minimal k. Concretely, take G = (𝔽₂)^t, N = 2^t, and any fixed ε ∈ (0,1),
  η ∈ (0,1), k ≤ (2−η)t:
  * If A ⊆ H for one of the N − 1 index-2 subgroups H, then every subset sum of A
    lies in H, so F_A(g) = 0 for g ∉ H, while ε < 1 requires
    F_A(g) ≥ (1−ε)·2^k/N > 0. Such A is not ε-approximation-uniform.
  * The probability a uniform k-subset lies in some H is bounded below by
    Chung–Erdős: P(∪_H E_H) ≥ (Σ P(E_H))² / (Σ P(E_H) + Σ_{H≠H'} P(E_H ∩ E_{H'})),
    with P(E_H) = C(N/2,k)/C(N,k) = 2^{−k}(1 + O(k²/N)) and, for H ≠ H' (their
    intersection has index 4), P(E_H ∩ E_{H'}) = C(N/4,k)/C(N,k) =
    4^{−k}(1 + O(k²/N)). This gives P(bad) ≥ (1 − o(1))·N2^{−k}/(1 + N2^{−k}) ≥
    (1/3)·min(N2^{−k}, 1) ≥ (1/3)·2^{−(1−η)t} for k ≤ (2−η)t and t large — which
    is ≫ 1/N = 2^{−t}.
  * Hence the good fraction is < 1 − 1/N for every k ≤ (2−η)t, so
    `g_eps ε 2^t ≥ (2−η)·t` for all large t (the defining set contains no such k;
    and it is nonempty for large t — k = N works, see A3 — so `sInf` returns a
    genuine element, not junk). The ratio `g_eps ε N / logb 2 N` is therefore
    eventually ≥ 2 − η along N = 2^t, and `Tendsto … atTop (nhds 1)` (lines 80–83)
    is **false**: atTop convergence to 1 requires the ratio to be eventually
    within (1/2, 3/2) over *all* N, contradicted along the subsequence.
  The problem itself is unaffected (with any *fixed* confidence 1 − δ, the
  hyperplane-capture probability ≈ N·2^{−k} is already ≤ δ at
  k = log₂ N + log₂(1/δ), consistent with (1+o(1))log₂ N and with [ErHa76]).
  Fixed in v2 by making the confidence δ an explicit parameter with 0 < δ < 1,
  universally quantified — the standard fixed-confidence rigorization of a
  w.h.p. threshold function.
- Quantifying over all `G : Type` with `Fintype.card G = N` (lines 61–62)
  correctly renders "if G is an abelian group of size N" as worst case over
  groups of each order — the right reading, since the informal probability
  statement must hold whichever group is presented. Universe 0 realizes every
  finite abelian group, and the property is isomorphism-invariant, so no
  generality is lost.
- ε handling: the source's setup fixes 0 < ε < 1 (the "for all ε > 0" in the
  question is the same statement given the setup's range); the theorem binds
  ε with `0 < ε` and `ε < 1` (line 80) — matches. As a direct assertion, binders
  before the colon are correct, and ε sitting outside the `Tendsto` correctly
  makes the convergence rate ε-dependent (the o_ε(1) of the source).
- Not vacuous: with the v2 fix the statement is the substantive proved asymptotic;
  the limit constant 1 is non-tautological (the lower bound alone gives only
  liminf ≥ 1, [ErRe65] alone only limsup ≤ 2).

**A2. Lean semantics traps — pass apart from the A1 defect (which is itself a
threshold-encoding trap).**

- No ℕ subtraction anywhere: both subtractions (`… - (2:ℝ)^k/N`, `1 - 1/(N:ℝ)`)
  are in ℝ.
- Division: in `isApproxUniform`, N = Fintype.card G ≥ 1 always (groups are
  nonempty), so /N never divides by zero. In `goodFraction`, `good.card /
  all.card` elaborates with ℕ→ℝ coercions on both operands (expected type ℝ);
  when k > N there are no k-subsets and 0/0 = 0 results — *benign and in fact
  helpful*: it keeps k > N out of the defining set (0 < 1 − 1/N for N ≥ 2),
  matching the implicit constraint k ≤ N for k-subsets of G. In the theorem,
  `logb 2 N = 0` at N ∈ {0, 1} makes the ratio 0/0 = 0 — harmless under `atTop`.
- `sInf` on ℕ returns 0 on the empty set. The defining set is all of ℕ at N = 0
  (no group of order 0 exists — vacuous hypothesis) and is genuinely **empty** at
  some small N: for N = 3, ε < 1/2 (and the input's threshold 1 − 1/3 = 2/3),
  exhaustive check of ℤ/3ℤ: k = 0 needs ε ≥ 1 (|1 − 1/3| ≤ ε/3 fails); k = 1
  needs ε ≥ 1; k = 2: {1,2} is good iff ε ≥ 1/2, {0,1} and {0,2} need ε ≥ 1, so
  fraction ≤ 1/3 < 2/3; k = 3: A = G good iff ε ≥ 1/2 (F(0) = 4 vs 8/3); k > 3:
  fraction 0. So `g_eps ε 3 = 0` (junk) for ε < 1/2. For all N large in terms of
  ε alone the set is nonempty: k = N works, since for the unique N-subset A = G a
  character computation gives F_G(g) = (1/N)Σ_χ χ̄(g)·Π_{x∈G}(1 + χ(x)) with
  nontrivial χ of even order contributing 0 and of odd order m ≥ 3 contributing
  magnitude 2^{N/m} ≤ 2^{N/3}, so |F_G(g) − 2^N/N| ≤ 2^{N/3} ≤ ε·2^N/N once
  2^{2N/3} ≥ N/ε. Hence junk values occur at only finitely many N — invisible to
  `atTop` — and the falsity argument in A1 concerns genuine values, not junk.
  (Documented in the v2 docstring.)
- `Finset.range`: unused; no indexing conventions arise (no sequences).
- Filter encoding: `Tendsto _ atTop (nhds 1)` is the correct rendering of
  "= (1 + o(1)) log₂ N" *given a correct g_eps* — the ratio-limit form is exactly
  the o(1) statement, and `logb 2` is log base 2 as required.
- No `StrictMono`/`Monotone` or interval-endpoint issues.

## E. Prior-review audit (`deepmind/ai-review/1179.md`)

The prior review is accurate on the component definitions and the citation data,
but its central modeling judgment is wrong:

   correctly notices the discretization ("These are not identical — the original
   is a limit statement for fixed k, while the formalization is a uniform bound
   for each N") and then waves it through: "for defining the threshold function

   invented asymptotic-equivalence argument instead of testing it on a structured
   family — here, precisely the elementary abelian groups whose subgroup-richness
   is the problem's probabilistic heart.
