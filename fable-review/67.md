## Summary

The problem ($500 prize, the Erdős Discrepancy Problem, **PROVED**): if
$f:\mathbb{N}\to\{-1,+1\}$, is it true that for every $C>0$ there exist $d,m\ge 1$
with $\left|\sum_{1\le k\le m} f(kd)\right| > C$? Solved in the affirmative by Tao
[Ta16], who also proved the generalization to unit-sphere-valued $f$. The Lean
statement (`conjectures/67.lean:16-22`) asserts: for every $f:\mathbb{N}\to\mathbb{Z}$
with $f(n)\in\{1,-1\}$ everywhere and every $C:\mathbb{N}$, there are $d,m>0$ with
$C < \left|\sum_{k\in\mathrm{range}\,m} f((k{+}1)d)\right|$. Read back independently,
this is exactly the affirmative direction of the question — the true direction —
stated as a direct assertion, which is the acceptable form for a solved problem in
this pipeline. The indexing is term-by-term exact and the $C:\mathbb{N}$ threshold is
equivalent to the source's real $C>0$ because the sum is integer-valued. I found no
semantic defects; the nits are scholarship-level (the page's `[Va99,1.30]` citation
key is missing, no reference carries any bibliographic data, and the page's two
remarks — Erdős's $\gg \log x$ strengthening and the multiplicative special case —
are unrecorded).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement: "If $f:\mathbb{N}\to \{-1,+1\}$ then is it
  true that for every $C>0$ there exist $d,m\geq 1$ such that
  $\left\lvert \sum_{1\leq k\leq m}f(kd)\right\rvert > C$?" The input docstring
  (lines 10-11) reproduces it faithfully modulo dropping the interrogative frame
  (see A4).
- Independent back-translation of lines 16-21: "for every $\pm 1$-valued
  $f:\mathbb{N}\to\mathbb{Z}$ and every natural $C$ there exist $d>0$ and $m>0$
  with $C < \left|f(d)+f(2d)+\cdots+f(md)\right|$." This is precisely the
  affirmative answer to the question as asked.
- Indexing: `∑ k ∈ range m, f ((k + 1) * d)` sums $k=0,\dots,m-1$, i.e. arguments
  $d, 2d, \dots, md$ — exactly $\sum_{1\le k\le m} f(kd)$. Term-by-term exact at the
  first index ($k=0 \mapsto f(d)$), not merely asymptotically.
- Types: $f$ into $\mathbb{Z}$ with the two-point constraint `hf` is a faithful
  rendering of $\{-1,+1\}$-valued (the upstream repo instead uses the subtype
  `({-1, 1} : Finset ℝ)`; both are correct). The threshold $C:\mathbb{N}$ vs the
  source's real $C>0$: **equivalent**, because the sum is an integer — for real
  $C>0$ apply the Lean statement to $\lceil C\rceil \ge C$ (and conversely the
  natural-number instances are a subset after casting); the extra $C=0$ instance is
  strictly weaker than $C=1$ and harmless. The comparison `C < |∑ …|` casts
  $C$ into $\mathbb{Z}$, so the arithmetic happens in $\mathbb{Z}$ as intended.
- `hf` also constrains $f(0)$, which the source's $f$ on $\mathbb{N}$ (used only at
  $kd\ge 1$) arguably leaves free. Harmless in both directions: $f(0)$ appears in no
  sum, and any $\pm1$ function on the positive integers extends by $f(0)=1$. Not a
  defect.
- Not vacuous or trivially false: with $0<m$ the sum is nonempty; the statement is
  Tao's genuine theorem, and no degenerate witness satisfies it trivially.
