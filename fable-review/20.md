## Summary

The problem (OPEN, $1000 — the Erdős–Rado sunflower conjecture): let
f(n,k) be minimal such that every family F of n-uniform sets with
|F| ≥ f(n,k) contains a k-sunflower; is it true that f(n,k) < c_k^n for
some constant c_k > 0? The Lean file defines `NUniform` (every member has
cardinality n) and `IsSunflower G k` (card G = k and a common core C with
S₁ ∩ S₂ = C for all distinct S₁, S₂ ∈ G), and asserts: for every k ≥ 1
there is c > 0 such that every n-uniform family with (card F : ℝ) ≥ c^n
contains a k-sunflower subfamily. This threshold form is, for n ≥ 1, an
exactly faithful rendering of "f(n,k) < c_k^n" (the ∃c absorbs the
constant slack in both directions), and the quantifier order ∀k ∃c ∀n,F
correctly makes c depend on k only. But the file quantifies over *all*
n : ℕ including n = 0, where c^0 = 1 unconditionally and F = {∅} is a
counterexample for every k ≥ 2 — so the statement as written is false,
which is a Part A defect (the same n = 0 degeneracy the upstream
formal-conjectures file explicitly guards with `n > 0`). One docstring
misattribution (the record bound (Ck log n)^n credited to ALWZ rather
than to the Rao/FKNP/BCW refinements, contra the page) and
scholarship-level gaps (no reference entries at all; the page's [Va99]
key dropped) round out the findings.

## A. Semantic fidelity

**A1. Statement fidelity — one defect (degenerate-case falsity); otherwise
faithful (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $f(n,k)$ be
  minimal such that every family $\mathcal{F}$ of $n$-uniform sets with
  $\lvert\mathcal{F}\rvert \geq f(n,k)$ contains a $k$-sunflower. Is it
  true that \[f(n,k) < c_k^n\] for some constant $c_k>0$?"
- Independent back-translation of lines 35–41: "for every k ≥ 1 there is a
  real c > 0 such that for every type α with decidable equality, every
  n : ℕ, and every n-uniform family F of finsets over α with
  (card F : ℝ) ≥ c^n, some subfamily G ⊆ F is a k-sunflower."
- Threshold-form equivalence (n ≥ 1), checked both directions by hand:
  (⇐) if f(n,k) < c^n then any F with card F ≥ c^n has card F > f(n,k),
  hence card F ≥ f(n,k), hence contains a k-sunflower; (⇒) the Lean
  statement gives f(n,k) ≤ ⌈c^n⌉ ≤ c^n + 1 ≤ 2·M^n < (3M)^n with
  M = max(c,1) for every n ≥ 1, and the existential over the constant
  absorbs c ↦ 3M. So the encoding is faithful — *for n ≥ 1*.
- **[defect] n = 0 falsifies the statement.** `n` ranges over all of ℕ.
  At n = 0: `c ^ 0 = 1` for every real c (Monoid.npow), and the family
  `F = {∅} : Finset (Finset α)` satisfies `NUniform F 0` with
  `(card F : ℝ) = 1 ≥ 1`. A k-sunflower subfamily needs card G = k, but
  every G ⊆ {∅} has card ≤ 1 — impossible for k ≥ 2. Hence for every
  k ≥ 2 *no* c > 0 works and the ∃c clause is false; since the theorem
  claims ∀ k ≥ 1, `erdos_problem_20` is literally false. This is not a
  quirk of the formalization's ≥-threshold: the source's f(0,k) is
  undefined/infinite for k ≥ 2 (no threshold forces a k-sunflower among
  0-uniform sets, there being only one such set), so the intended
  question is n ≥ 1. The upstream formal-conjectures file (recovered
  from logs, see Addendum) states exactly this guard: "for all n > 0",
  `∀ n k, n > 0 → f n k < (c k) ^ n`. **Fix applied in v2:** `1 ≤ n →`
  hypothesis added; not compile-verified.
- Quantifier structure otherwise matches: c is chosen after k and before
  (α, n, F), so the constant depends on k alone — the nontrivial reading
  (c after n would trivialize, since f(n,k) is finite for each fixed
  pair). The ground set is universally quantified via α, which is
  faithful (f's defining quantification is over arbitrary families; the
  threshold property transfers along embeddings, and quantifying over all
  α with the family a `Finset` loses nothing — thresholds are finite, and
  a finite subfamily above the threshold witnesses for infinite
  families).
- Types: family and members as `Finset` — appropriate (members are
  n-element sets; family finiteness is WLOG as above). The cast
  `(Finset.card F : ℝ) ≥ c ^ n` puts the comparison in ℝ, correct.
- Not vacuous/trivial *after the fix*: for n ≥ 1 the statement is the
  genuine open conjecture (true for k = 1 with any c; substantive for
  k ≥ 2, where the best known threshold is (Ck log n)^n, superexponential
  in the conjectured sense only by the log factor).

**A2. Lean semantics traps — pass (input file); one guarded ℕ-subtraction
introduced in v2.**

- No ℕ subtraction, no division, no `Finset.range` in the input file.
- `c ^ n` with c : ℝ, n : ℕ is `Monoid.npow`: total, `c ^ 0 = 1` — this
  is precisely what makes the n = 0 defect bite (the hypothesis cannot be
  made unsatisfiable by choosing c large), documented under A1.
- Vacuous quantifiers: the inner pairwise condition of `IsSunflower` is
  vacuous for card G ≤ 1 — standard convention (any singleton is a
  1-sunflower), consistent with the upstream file, which proves the empty
  and singleton cases as `test` lemmas. For k = 1 the main statement is
  harmlessly true (c^n > 0 forces F nonempty, and any singleton
  subfamily works). No silent alteration of the source.
- No "infinitely many"/filter/`StrictMono` encodings arise. Strict vs
  non-strict: the source's "f(n,k) < c_k^n" vs the file's
  "card F ≥ c^n → …" reconcile exactly as computed in A1.
- v2 note: the added Erdős–Rado variant uses `(k - 1) ^ n` in ℕ; under
  the `1 ≤ k` hypothesis the truncated subtraction is exact (and at
  k = 0 it would truncate to 0, making the variant vacuously-true-side
  harmless anyway).

**A3. Definitions — pass.**

  "n-uniform" exactly; degenerate inputs fine (`NUniform ∅ n` true,

- `IsSunflower` (line 19) matches its docstring: card k plus a common
  core for all distinct pairs. Distinctness of the k sets is automatic

**B2. Variants and completeness — single-part problem, captured; page

- The page's remarks support four natural variants; three are added in
