## Summary

The problem (recovered verbatim): "Does every finite colouring of the
integers have a monochromatic solution to $1=\sum \frac{1}{n_i}$ with
$2\leq n_1<\cdots <n_k$?" The answer is yes, proved by Croot [Cr03]
(Annals of Mathematics, 2003) — indeed, with infinitely many disjoint
monochromatic solutions — and the page banner is **PROVED (LEAN)**: the
proof itself has been verified in Lean (upstream links plby/lean-proofs).
The Lean input states: for every finite type α and every colouring
c : ℕ → α, there is a nonempty `Finset ℕ` S with all elements ≥ 2, all of
one colour, whose reciprocals (summed in ℚ) equal 1. Read back
independently, this is exactly the question's proposition in the "yes"
direction, which is the true direction for this solved problem — the
acceptable direct-assertion form for this raw corpus. No semantic
defects; polish-level nits only (missing bibliography, missing page
remarks/variants, undocumented encoding choices).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Independent back-translation of `conjectures/46.lean:14-18`: "For every
  finite type α and every function c : ℕ → α, there exists a finite set
  S of naturals, nonempty, with every element ≥ 2, all elements sharing
  one c-value, and ∑_{n∈S} 1/n = 1 in ℚ." This matches the page's
  question clause by clause: "every finite colouring" = arbitrary
  `c : ℕ → α` with `[Finite α]`; "monochromatic" = `∃ color, ∀ n ∈ S,
  c n = color`; "$2 \le n_1 < \cdots < n_k$" = `Finset` membership
  (distinctness for free) + `∀ n ∈ S, n ≥ 2`; "$1 = \sum 1/n_i$" =
  `(∑ n ∈ S, (1:ℚ)/(n:ℚ)) = 1`.
- **Colouring domain.** The page colours "the integers" (in effect the
  integers ≥ 2 — only those can appear in a solution); the Lean colours
  all of ℕ. Equivalent: every colouring of {2, 3, …} extends to ℕ with
  the same finite palette, the values at 0 and 1 cannot enter any
  witness S (blocked by the `n ≥ 2` conjunct), and restriction preserves
  colourings. Not a defect; documented in v2.
- **Polymorphic finite palette vs upstream's finite range.** Upstream
  (`FormalConjectures/ErdosProblems/46.lean` at HEAD dd1c2beb) uses
  `𝓒 : ℕ → ℕ` with `(Set.range 𝓒).Finite` and monochromaticity as
  `(𝓒 '' S).Subsingleton`. The input's `(α : Type*) [Finite α]` version
  is equivalent: a finite-range ℕ-colouring factors through a finite
  type; conversely post-composing `c` with an injection α ↪ ℕ gives a
  finite-range colouring with the same colour classes, and for nonempty
  S, `∃ color, ∀ n ∈ S, c n = color` ↔ image subsingleton. Not a defect.
- **`S.Nonempty` is redundant** (the empty sum is 0 ≠ 1, so the
  reciprocal-sum condition already forces S ≠ ∅) but harmless — it
  cannot change satisfiability in either direction since it is implied
  by the last conjunct. [polish]: undocumented; documented in v2.
  (Upstream omits it.)
- Not vacuous, not trivial. For empty α no colouring `ℕ → α` exists and
  the statement is vacuously true over that binder — correct, since
  there is no such colouring informally either. For inhabited α the
  statement demands a genuinely monochromatic Egyptian-fraction
  decomposition of 1 within one colour class of an adversarial
  colouring — precisely Croot's theorem, which resolved a
  then-conjecture (Erdős–Graham). No degenerate witness: singletons
  need 1/n = 1, i.e. n = 1, excluded by `n ≥ 2`.
