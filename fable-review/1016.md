## Summary

The problem: let $h(n)$ be minimal such that there is a graph on $n$ vertices with
$n + h(n)$ edges containing a cycle on $k$ vertices for every $3 \le k \le n$ (a
*pancyclic* graph). Estimate $h(n)$ — in particular, **is it true** that
$h(n) \ge \log_2 n + \log^* n - O(1)$? Status on the source page: OPEN. The Lean file
defines cycle containment (injective cyclic adjacency map), pancyclicity, $h(n)$ via
`sInf` over exact edge counts, and a ℕ-valued iterated logarithm, and states the main
question as `answer(sorry) ↔ ∃ C : ℕ, ∀ n ≥ 3, pancyclicExcess n + C ≥ Nat.log 2 n +
iteratedLog₂ n` — a faithful $O(1)$-encoding of the asked inequality with correct
question form and polarity. Two solved companion theorems capture Bondy's claimed
bounds (upper bound proved by George–Khodkar–Wallis; lower bound proved by Griffin).
Three defects were found and fixed: the Griffin lower-bound theorem stated a strictly
*weaker* (floored) inequality than the source bound; the `pancyclicExcess` docstring
made a false claim about the $n < 3$ degenerate case (vacuous-quantifier error imported
verbatim from the prior AI review); and the upper-bound theorem's docstring contained
garbled leftover drafting text.

## A. Semantic fidelity

**A1. Statement fidelity — main theorem pass (source-verified); lower-bound variant
DEFECT (fixed).**

- Recovered verbatim source statement (see Addendum): "Let $h(n)$ be minimal such that
  there is a graph on $n$ vertices with $n+h(n)$ edges which contains a cycle on $k$
  vertices, for all $3\leq k\leq n$. Estimate $h(n)$. In particular, is it true
  that\[h(n) \geq \log_2n+\log_*n-O(1),\]where $\log_*n$ is the iterated logarithmic
  function?"
- Independent back-translation of `erdos_1016` (line 109): "the truth value
  `answer(sorry)` holds iff there is a $C \in \mathbb{N}$ with
  $h(n) + C \ge \lfloor\log_2 n\rfloor + \log^*_{\mathbb N}(n)$ for all $n \ge 3$."
  The RHS is exactly the asked inequality up to $O(1)$-absorbable substitutions:
  $\lfloor\log_2 n\rfloor \le \log_2 n < \lfloor\log_2 n\rfloor + 1$, and the ℕ-orbit
  of $\lfloor\log_2\cdot\rfloor$ descends at least as fast as the real orbit (floor ≤
  id, pointwise induction), so $\log^*_{\mathbb N}(n) \le \log^*_{\mathbb R}(n) \le
  \log^*_{\mathbb N}(n) + O(1)$ (the real orbit stays within an additive 2 of the ℕ
  orbit while the latter is ≥ 2). Both directions of the equivalence hold, and
  restricting to $n \ge 3$ is equivalent to "for all (large) $n$" because the deficit
  on any finite range is a finite maximum absorbable into $C$. Faithful.
- `pancyclicExcess` (line 80): `sInf {h | ∃ G, G.edgeFinset.card = n + h ∧ IsPancyclic
  G}` — exact-edge-count minimality, matching the source's "minimal $h(n)$ such that
  there is a graph … with $n + h(n)$ edges" literally. $h$ ranging over ℕ is correct:
  a pancyclic graph contains $C_n$ (Hamiltonian cycle), hence has $\ge n$ edges, so the
  informal $h$ is never negative. For $n \ge 3$ the set is nonempty ($K_n$ is
  pancyclic, $\binom n2 \ge n$), so `sInf` is a genuine minimum.
- `ContainsCycle` (line 61): an injective $f :$ `Fin k → Fin n` with
  $f(i) \sim f((i+1) \bmod k)$ for all $i$ is exactly a (not necessarily induced) $C_k$
  subgraph on $k$ distinct vertices — the standard meaning of "contains a cycle on $k$
  vertices". The closing edge $f(k{-}1) \sim f(0)$ is supplied by the $\bmod k$ index.
  `SimpleGraph` irreflexivity + injectivity make it simple. Correct for $k \ge 3$.
- **[defect] `erdos_1016_lower` (pre-fix line 127):** stated
  `pancyclicExcess n + 1 ≥ Nat.log 2 (n - 1)`, i.e. $h(n) \ge \lfloor\log_2(n-1)\rfloor
  - 1$. The source bound (Bondy claimed, Griffin proved) is the *real-log* inequality
  $h(n) \ge \log_2(n-1) - 1$, whose exact integer content is
  $h(n) + 1 \ge \lceil\log_2(n-1)\rceil$ — i.e. `Nat.clog`, not `Nat.log`. The floored
  form is strictly weaker whenever $n-1$ is not a power of 2: at $n = 6$ the true bound
  forces $h(6) \ge 2$ (indeed a connected graph with $6 + 1$ edges has cycle-space
  dimension 2, hence at most $2^2 - 1 = 3$ distinct cycles, fewer than the 4 required
  lengths), but the floored form only gives $h(6) \ge 1$. Note the cycle-space counting
  argument $2^{h+1} - 1 \ge n - 2$ *is* the Bondy lower bound and yields exactly the
  `clog` form, confirming it as the true statement. **Fixed** to `Nat.clog 2 (n - 1)`
  with an explanatory docstring; not compile-verified. Small-parameter sanity checks:
  $n=3$: $h(3)=0$, $0+1 \ge \operatorname{clog}_2 2 = 1$ ✓; $n=4$: $h(4)=1$ (4 vertices
  4 edges is unicyclic, cannot contain both $C_3$ and $C_4$; $C_4$+chord works),
  $2 \ge \operatorname{clog}_2 3 = 2$ ✓; $n=5$: $h(5)=1$ ($C_5$ + a distance-2 chord
  gives $C_3, C_4, C_5$), $2 \ge \operatorname{clog}_2 4 = 2$ ✓ — the corrected bound
  is not falsified at small parameters (cf. the 1004/EPS87 precedent check).
- Not vacuous: the main statement is a substantive open strengthening of the proven
  lower bound by the $+\log^* n$ term; no degenerate witness trivializes it.

**A2. Lean semantics traps — pass (one vacuity documented).**

- **Vacuous quantifier at $n < 3$:** `IsPancyclic` is *vacuously true* for every graph

  affected — but the pre-fix docstring's account of this case was false (see A3).

  $16 \mapsto 3$ — the standard $\log^*$. Fuel adequacy verified by the invariant
  "fuel ≥ input" ($\lfloor\log_2 m\rfloor \le m - 1$ for $m \ge 2$), so `n` fuel always
  suffices and the recursion computes the exact value, matching its docstring.

  load-bearing place ($n \ge 3$, $n - 1 \ge 2$).

## E. Prior-review audit (`ai-review/1016.md`)

Sound on the main-theorem encoding, but four findings:

1. **False vacuity claim, propagated into the artifact (§6b).** "For `n < 3`, no graph
   can be pancyclic (since pancyclicity requires cycles of length 3, needing at least
   3 vertices), so the set is empty and `sInf ∅ = 0`." Wrong about the formal
   definition: `IsPancyclic` universally quantifies over $3 \le k \le n$, which is
   *vacuous* for $n < 3$, so every graph qualifies; at $n = 0$ the set is $\{0\}$, not
   empty. This is precisely the vacuous-bounded-quantifier trap the checklist warns
   about, and — worse than the 1000/1005 patterns of merely unsound justifications —
   the wrong claim was *transcribed into the styled file's docstring* when the review's
   §4 suggestion ("a comment noting this edge case would be helpful") was implemented.
   The reviewed conclusion (theorems unaffected, $n \ge 3$ guard sufficient) survives.
2. **Recoverable data declared minimal (§2, the 1001 pattern).** The citations table
   says the website "does not give further bibliographic detail either" for
   [Bo71]/[Er71]. The site's `/latex/1016` page carries full author/title/journal/
   year/pages data — recovered from the logs and now in the file. The claim conflated
   the problem page with the bibliography source the checklist names as authoritative.
3. **Attribution overstated (§2).** "The website credits Griffin with the first proof
   of the lower bound" — the recovered page says "A proof of the above lower bound is
   provided by Griffin", with "first published proof" reserved for [GKW16]'s upper
   bound. The invented "first" propagated into the styled module docstring (fixed).
4. **Missed floor-vs-real weakening (§3).** In recommending the Griffin lower bound as
   a variant it wrote the bound as "$\log_2(n-1) - 1 \le h(n)$" without flagging that a
   ℕ-encoding via `Nat.log` weakens it; the implementer then used `Nat.log`, producing
   the A1 defect. (Its §6c discussion of the analogous $O(1)$-absorbable discrepancy
   for the *main* theorem is correct — the point is that no $O(1)$ slack exists in the
   exact lower bound.)

What it got right: the `numEdges` → `edgeFinset.card` and missing-[Gr13]/[GKW16]
citation flags (both subsequently applied); the $C : \mathbb{N}$ vs $\mathbb{Z}$
argument (§6d) is correct; the $n=5$-type examples where ℕ- and ℝ-iterated logs differ
by 1 are real; its variant recommendations were adopted. Its §1 file references
(`FormalConjectures/ErdosProblems/1012.lean:45-47`) describe the upstream repo, not
