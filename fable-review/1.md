**Verdict:** NEEDS REVISION (one Part A defect: the statement as written is falsified by

## Summary

The problem (OPEN, $500): if $A \subseteq \{1,\ldots,N\}$ with $|A| = n$ has all
$2^n$ subset sums $\sum_{a \in S} a$ distinct, then $N \gg 2^n$ — i.e. there is an
absolute constant $C > 0$ with $N \ge C \cdot 2^n$. This is Erdős's "perhaps my first
serious problem" (dated by him to 1931); powers of 2 show $2^n$ would be best possible,
and the current record lower bound is $N \ge \binom{n}{\lfloor n/2 \rfloor}$
(Dubroff–Fox–Xu 2021, constant $\sqrt{2/\pi}$ first due to Elkies–Gleason,
unpublished). The Lean file defines `DistinctSubsetSums` correctly and states
`∃ C : ℝ, 0 < C ∧ ∀ N n A, (A ⊆ {1..N}) → A.card = n → DistinctSubsetSums A →
(N : ℝ) ≥ C * 2 ^ n`. Read back independently this matches the source *except* at the
degenerate instance N = 0, A = ∅, n = 0, which satisfies every hypothesis and demands
$0 \ge C > 0$: the formal statement is **refutable as written** while the problem is
open. One added hypothesis (`N ≠ 0`, matching the upstream formal-conjectures guard)
repairs it; everything else checks out.

## A. Semantic fidelity

**A1. Statement fidelity — one defect; otherwise pass (source-verified).**

- Recovered verbatim source statement (`tidy/1.html`, identical in the session-log
  capture): "If $A\subseteq \{1,\ldots,N\}$ with $\lvert A\rvert=n$ is such that the
  subset sums $\sum_{a\in S}a$ are distinct for all $S\subseteq A$ then
  \[N \gg 2^{n}.\]"
- Independent back-translation of `conjectures/1.lean:27-34`: "there is a real
  $C > 0$ such that every finite $A \subseteq \mathbb{N}$ with elements in $[1, N]$,
  cardinality $n$, and distinct subset sums satisfies $N \ge C \cdot 2^n$." The
  $\exists C\, \forall N, A$ quantifier order correctly makes $C$ an *absolute*
  constant — the right unfolding of the Vinogradov $\gg$.
- `(∀ a ∈ A, 1 ≤ a ∧ a ≤ N)` (line 30) is exactly $A \subseteq \{1,\ldots,N\}$
  (elementwise `Finset.Icc 1 N` membership). The binder `n` with `A.card = n` is a
  redundant but harmless name for `A.card`.
- **[defect] Degenerate-case falsity.** Take N = 0, A = ∅, n = 0. Then
  `∀ a ∈ ∅, …` holds vacuously, `A.card = 0`, and `DistinctSubsetSums ∅` holds
  (the only subset is ∅). The conclusion demands `(0 : ℝ) ≥ C * 2 ^ 0 = C`,
  contradicting `0 < C`. So for *every* C > 0 the inner ∀ fails, and the theorem as
  written is **false** — a trivial disproof of a statement recorded as an open
  conjecture. The informal statement never contemplates $N = 0$ (and $\gg$ absorbs
  small cases informally, but the formal ∀ does not). Notably the upstream
  google-deepmind formal-conjectures statement of this problem (recovered from the
  logs, see Addendum) guards with `N ≠ 0 →`. Fix applied identically:
  add `N ≠ 0 →`. With the guard, all small cases are consistent (e.g. N ≥ 1,
  A = ∅ needs $N \ge C$, fine for $C \le 1$), and the statement is exactly the open
  conjecture.
- Not otherwise vacuous or trivial: with the guard, the statement remains the
  substantive open bound (known truth would require $N \gtrsim 2^n/\sqrt{n}$, and the
  conjecture strengthens this to $2^n$).

**A2. Lean semantics traps — pass.**

- No ℕ subtraction anywhere.
- No division in the main statement. (`C * 2 ^ n` elaborates in ℝ: `C : ℝ` forces
  `(2 : ℝ) ^ (n : ℕ)` via `Monoid.npow` — the intended real quantity.)
- No `Finset.range`, so no off-by-one; the interval is encoded elementwise as
  `1 ≤ a ∧ a ≤ N`, matching the closed interval $\{1,\ldots,N\}$.
- Vacuous quantifiers: the A = ∅ instance is precisely the defect above; recorded
  there.
- No filter/density encodings needed: the $\gg$ is correctly unfolded into an
  explicit constant, the standard finitary encoding used across this corpus.
- Non-strict `≥` here vs the upstream file's strict `<`: immaterial — the two forms
  are interchangeable for a $\gg$ bound (rescale $C$), and non-strict matches
  "$N \ge C \cdot 2^n$".

**A3. Definitions — pass.**

- `DistinctSubsetSums` (lines 12-14) matches its docstring and the source: injectivity

  (∅ and {a} have sums 0 ≠ a). Membership `S ∈ A.powerset` is `S ⊆ A` — correct.
- No `sorry` in any def; the single `sorry` is the theorem's proof body.
- No drift between the def and its use in the theorem.

**A4. Question form and answer polarity — pass.**
