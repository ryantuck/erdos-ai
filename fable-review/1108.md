## Summary

The problem: let $A = \{\sum_{n\in S} n! : S\subset \mathbb{N}\text{ finite}\}$; if
$k \ge 2$, does $A$ contain only finitely many $k$-th powers? Does it contain only
finitely many powerful numbers? The status is OPEN (page banner), asked by Erdős at
Oberwolfach in 1988, motivated in part by a problem of Mahler; Brindza–Erdős [BrEr91]
proved the bounded-length case. The Lean file defines `IsFactorialSubsetSum1108` (m is a
sum of factorials over a `Finset ℕ`) and `IsPowerful1108` (positivity plus
$p \mid n \to p^2 \mid n$), and states both parts as `Set.Finite` assertions: part (a)
for every $k \ge 2$ the $k$-th powers in $A$ form a finite set, part (b) the powerful
numbers in $A$ form a finite set. Read back independently, both theorems assert exactly
the affirmative directions of the two questions as asked. I found no semantic defects;
the findings are scholarship-level nits (citation keys used but never defined; OPEN
status and the direct-assertion convention undocumented; the page's [BrEr91] key and
Mahler remarks absent) plus three page-confirmed enrichment variants, all applied in
`conjectures-v2/1108.lean`.

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- Recovered verbatim source statement (see Addendum): "Let $A = \left\{\sum_{n\in S}n! :
  S\subset \mathbb{N}\textrm{ finite}\right\}.$ If $k\geq 2$, then does $A$ contain only
  finitely many $k$th powers? Does it contain only finitely many powerful numbers?" The
  module docstring (lines 14–15) reproduces this essentially verbatim, and the
  Oberwolfach-1988 / problem-#398 remark (lines 17–18) matches the page's first remark
  word for word.
- Independent back-translation of `erdos_problem_1108a` (lines 39–41): "for every
  $k \ge 2$, the set of $m$ that are simultaneously a sum of factorials indexed by a
  finite $S \subseteq \mathbb{N}$ and a perfect $k$-th power is finite." That is the
  affirmative content of part (a), read per-$k$ — the same reading the recovered
  upstream file takes (`∀ k ≥ 2, Set.Finite …`). Quantifier order is right: $k$ is a
  universal theorem binder, correct for a direct assertion.
- Back-translation of `erdos_problem_1108b` (lines 49–51): "the set of powerful members
  of $A$ is finite" — exactly part (b).
- **ℕ-convention check (settled by the page itself).** `S : Finset ℕ` includes $0$, so
  both $0! = 1$ and $1! = 1$ are available as summands; e.g. $4 = 0! + 1! + 2! \in A$
  under this reading but $4 \notin A$ if indices start at 1 (sums of distinct elements
  of $\{1, 2, 6, 24, \dots\}$ skip 4). The two readings differ on infinitely many
  elements, so this could have been a genuine fidelity question — but the source page
  resolves it: Mahler's example on the same page, $400 = 1 + 7 + 7^2 + 7^3 =
  \sum_{n \in \{0,1,2,3\}} 7^n$, uses the exponent $0$ in the exactly analogous
  $S \subset \mathbb{N}$ construction, so the site's $\mathbb{N}$ here includes $0$ and
  `Finset ℕ` is the intended reading. The recovered upstream formalization makes the
  identical choice. Documented in the v2 docstrings; not a defect.
- Both parts of the two-part problem are formalized (B2 confirms nothing is missing).
- Not vacuous: neither statement is trivially true or false. $A$ contains infinitely
  many elements, and it genuinely contains squares beyond the degenerate ones
  ($25 = 1! + 4!$, $121 = 1! + 5!$, $4 = 0! + 1! + 2!$), so finiteness is a substantive
  open assertion; likewise for powerful numbers. No degenerate witness settles either
  set's finiteness.

**A2. Lean semantics traps — pass on all checklist items.**

- ℕ subtraction: none in the file. The only arithmetic is `∑`, `^`, `factorial`.
- Division: none.
- `Finset.range`: not used in the input (the v2 Brindza–Erdős variant introduces
  `range r`, checked there: `{0, …, r−1}` has exactly $r$ terms, matching
  $n_1, \dots, n_r$).
- Vacuous/degenerate cases: the empty `S` puts $0 \in A$, and $0 = 0^k$ is a $k$-th
  power, so $0$ lies in part (a)'s set; $1 = 1^k \in A$ likewise. Finitely many
  degenerate members cannot affect a `Set.Finite` assertion — harmless. For part (b),
  the `0 < n` conjunct in `IsPowerful1108` excludes $0$ (which would otherwise be
  vacuously "powerful" since $p \mid 0$ and $p^2 \mid 0$ for every $p$); with or
  without the conjunct the finiteness assertion differs by at most the single element
  $0$, so the choice is semantically safe, and it keeps the definition aligned with the
  standard notion (1 is powerful vacuously — standard).
- "Only finitely many" is encoded as `Set.Finite` — the correct, standard encoding; no
  filter/liminf machinery is needed or used.
- `StrictMono` vs `Monotone`, strict vs non-strict, open vs closed intervals: none
  arise. `2 ≤ k` is the correct non-strict reading of "$k \geq 2$".
