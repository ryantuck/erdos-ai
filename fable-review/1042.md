## Summary

The problem (Erdős–Herzog–Piranian [EHP58, p.139]): let $F \subset \mathbb{C}$ be a
closed set of transfinite diameter $1$ not contained in any closed disc of radius $1$;
for $f(z) = \prod_{i=1}^n (z - z_i)$ with all $z_i \in F$, **can** $\{z : |f(z)| < 1\}$
have $n$ connected components? And if the transfinite diameter of $F$ is $< 1$, **must**
the set have at most $(1-c)n$ components with $c > 0$ depending only on $F$? The page
banner is **PROVED** ("solved in the affirmative"), by Ghosh and Ramachandran [GhRa24].
The Lean file defines the transfinite diameter (via pairwise-distance products, `sSup`,
and `lim atTop`) and the lemniscate sublevel set, then states three theorems: an
existence statement for part 1, an upper bound for part 2, and the $d \le 1/4$
connectedness result. The definitions are correct, including degenerate cases, but the
pre-fix file had three defects: `variants.upper_bound` quantified over **all** $n$ and
is literally false at $n = 1$; `variants.connected_unique_component` included $n = 0$,
where the empty sublevel set has $0 \ne 1$ components; and both question parts were
encoded as bare assertions instead of `answer(True) ↔ P`, contrary to the recovered
source (both parts are explicit questions) and the corpus convention
(`deepmind/1000.lean`, `deepmind/1046.lean`, `deepmind/1008.lean`).

## A. Semantic fidelity

**A1. Statement fidelity — one defect in each of the two variant theorems (fixed);
main statement's mathematical content faithful.**

- Recovered verbatim source statement (see Addendum): "Let $F\subset\mathbb{C}$ be a
  closed set of transfinite diameter $1$ which is not contained in any closed disc of
  radius $1$. If $f(z)=\prod_{i=1}^n(z-z_i)\in\mathbb{C}[x]$ with all $z_i\in F$ then
  can $\{ z: \lvert f(z)\rvert < 1\}$ have $n$ connected components? If the transfinite
  diameter of $F$ is $<1$ then must this set only have at most $(1-c)n$ connected
  components, where $c>0$ depends only on $F$ (or just the transfinite diameter of
  $F$)?"
- Independent back-translation of `erdos_1042` (RHS): "there is a closed $F$ with
  encoded transfinite diameter $1$, not contained in any closed ball of radius $1$,
  such that the set of $n$ admitting roots in $F$ with exactly $n$ components of the
  sublevel set is infinite." This matches the page's solution bullet ("there are
  examples with $d=1$ such that, for infinitely many $n$, the set can have $n$
  connected components") combined with the question's premise (the not-in-a-unit-disc
  condition — necessarily met by the solution, since the page marks the question as
  asked solved in the affirmative, and the in-disc case was already settled by
  [EHP58]'s $f(z) = z^n + 1$).
- **[defect 1] `variants.upper_bound` was false as stated.** Pre-fix it asserted
  $\exists c > 0,\ \forall n,\ \forall z \in F^n$, `Nat.card (ConnectedComponents …)`
  $\le (1-c) n$. The hypotheses force $F \neq \emptyset$ (empty $F$ has encoded
  diameter $0$, excluded by `hd_pos`). Take $z_1 \in F$, $n = 1$: the sublevel set is
  the open unit disc around $z_1$ — nonempty and connected, so the count is $1$, and
  $1 \le (1-c)\cdot 1$ forces $c \le 0$, contradicting $c > 0$. The informal
  "at most $(1-c)n$" is meaningful only asymptotically (as with 1004's EPS87 bound).
  **Fixed** to `∀ᶠ n : ℕ in atTop, …` with the counterexample documented in the
  docstring.
- **[defect 2] `variants.connected_unique_component` was false as stated.** It
  asserted the count is $1$ for **all** $n$, including $n = 0$: the empty product is
  $f \equiv 1$, `sublevelSet` $= \{w : \|1\| < 1\} = \emptyset$, `ConnectedComponents`
  of the empty subspace is empty, `Nat.card = 0 \ne 1$. (`IsConnected F` does force
  $F$ nonempty, but no root is needed when $n = 0$.) **Fixed** by adding `0 < n →`,
  with the degenerate case documented.
- Not vacuous: post-fix, all statements are substantive; the existence set contains
  the trivial member $n = 0$ (count $0 = n$), which is harmless for `Set.Infinite`
  (finitely many trivial members) — documented in the docstring.
- Types: `Set ℂ` for $F$, `Fin n → ℂ` for the root tuple (allowing repeated roots, as
  the source's $\prod(z - z_i)$ does), `ℝ` for the diameter, `Nat.card` on
  `ConnectedComponents` of the subspace `↥(sublevelSet z)` — all appropriate. The
  component count is genuinely finite (each component of $\{|f| < 1\}$ contains a
  root, by the minimum-modulus principle on its closure, so there are at most $n$),
  hence `Nat.card`'s infinite-type junk value $0$ never masks anything.

**A2. Lean semantics traps — pass (all checked).**

- **No ℕ subtraction**: in `nthTransfiniteDiam`, the exponent
  `(2 : ℝ) / (↑n * (↑n - 1))` elaborates entirely in ℝ (the division forces the
  casts), so `↑n - 1` is real subtraction, $= -1$ at $n = 0$. No truncation.
- **Division by zero**: at $n \in \{0, 1\}$ the exponent is $2/0 = 0$ (field junk),
  making every achievable $t = x^0 = 1$ (`rpow`), so $d_0(F) = d_1(F) = 1$ for
  nonempty $F$. Invisible to the `atTop` limit; matches the classical convention that
  $d_n$ is only meaningful for $n \ge 2$. Harmless.
- **`sSup` junk values**: for unbounded $F$ and $n \ge 2$ the defining set is
  unbounded above, so `Real`'s `sSup` returns $0$; for empty $F$ and $n \ge 1$ it is
  `sSup ∅ = 0`. Hence `transfiniteDiameter` encodes unbounded $F$ (true diameter
  $\infty$) and $\emptyset$ as $0$. This makes `hd_pos`/`0 <` hypotheses restrict to
  bounded nonempty (= compact nonempty) closed sets — exactly the sets the solved
  result covers, and it is *load-bearing*: with only `transfiniteDiameter F < 1`, an
  unbounded $F$ (e.g. $F = \mathbb{R}$, encoded value $0$) would slip in and falsify
  the upper bound. Documented in the `transfiniteDiameter` docstring (fix).
- **`lim` junk**: `lim (atTop.map …)` is a genuine limit in every reachable case —
  for compact nonempty $F$, $d_n$ is non-increasing in $n \ge 2$ (Fekete) and bounded
  below, hence convergent; for unbounded/empty $F$ the sequence is eventually
  constant $0$. No non-convergent case arises.
- **Exponent vs the page**: the page defines $\rho(F)$ with exponent $1/\binom{n}{2}$;
  the Lean uses $2/(n(n-1))$ — equal for $n \ge 2$. The `filter (p.1 < p.2)` over
  `Fin n × Fin n` enumerates each unordered pair exactly once; empty for $n \le 1$,
  giving the empty product $1$. Correct.
- **Vacuous bounded quantifiers / off-by-one**: none (no `range`, no windowed
  indices). "Infinitely many $n$" as `Set.Infinite` and "for all sufficiently large
  $n$" as `∀ᶠ … atTop` (post-fix) are the standard correct encodings.
- Strict `< 1` in `sublevelSet` matches the source's $\lvert f(z)\rvert < 1$ (open
  lemniscate interior). `Metric.closedBall c 1` matches "closed disc of radius 1".

**A3. Definitions — pass.**

- `pairwiseDistProd`, `nthTransfiniteDiam`, `transfiniteDiameter`, `sublevelSet` each
  match their docstrings and the page's definition of the transfinite diameter,
  including degenerate inputs analyzed above. No `sorry` in any `def`. No drift
  between the defs and the theorems' use of them.

**A4. Question form and answer polarity — DEFECT (fixed).**

- **[defect 3]** Both parts of the source problem are explicit **yes/no questions**
  ("…then can … have $n$ connected components?"; "…then must this set only have at
  most $(1-c)n$ connected components…?"). Per the checklist and the corpus convention
  for solved-affirmative questions (`deepmind/1000.lean`, `deepmind/1046.lean`;
  multi-part: `deepmind/1008.lean`), each should be `answer(True) ↔ P`. Pre-fix, both
  `erdos_1042` and `erdos_1042.variants.upper_bound` were bare assertions. **Fixed**:
  both now read `answer(True) ↔ …`, with the RHS of `upper_bound` universally
  quantifying $F$ *inside* the iff (its former theorem binders `(F : Set ℂ) (hF …)`
  would otherwise quantify the iff, which A4 forbids).
- Polarity verified by hand: part 1 — RHS true ⟺ such an $F$ exists ⟺ the answer to
  "can it?" is yes; the page says "solved in the affirmative", so `True` is correct.
  Part 2 — RHS true ⟺ every closed $F$ with $0 < d < 1$ admits $c > 0$ with the
  eventual $(1-c)n$ bound ⟺ the answer to "must it?" is yes; correct. (Note the
  *literal* all-$n$ reading of part 2 is false at $n = 1$; the affirmative solution
  is the asymptotic reading, which is what the fixed RHS states.)
- `connected_unique_component`, `unit_disc`, `half_disc`, `segment` are partial
  results/notes from the solution, not questions posed by the source — direct
  assertion is the right form for them (cf. `erdos_1040_disc`,
  `erdos_1046_centroid`).
- No binders before the colon on either `answer()` theorem (lines 110, 138 post-fix).

**A5. Solution status — pass (source-verified).**

- Recovered banner: **PROVED**, tooltip "This has been solved in the affirmative."

## E. Prior-review audit (`ai-review/1042.md`)

Accurate on reuse and citations-as-keys; four substantive findings:

1. **"Overall correctness: Sound. No mathematical errors detected" is false.** The
   review's §6 explicitly checked `upper_bound` at $n = 0$ ("the bound holds
   trivially. This is fine.") and stopped there — the very next case, $n = 1$,
   falsifies the theorem for every nonempty $F$ (one component vs. bound
   $(1-c)\cdot 1 < 1$). Checking the vacuous boundary case and declaring the
   quantifier range safe is precisely the invent-or-skip-the-small-case failure
   pattern seen in the 1000 and 1005 audits; here the small case *does* matter and
   the endorsed statement was false.
2. **The missing variant it proposed was added with a fresh defect.** Its §3
   correctly flagged the absent $d \le 1/4$ result, and
   `variants.connected_unique_component` was subsequently added to
   `deepmind/1042.lean` — quantified over all $n$ including $n = 0$, where it is
   false. The review's own template ("for all $n$ and all $z_1,\ldots,z_n$") carried
   the bug; nobody re-checked the degenerate case it had itself just exercised for
   `upper_bound`.
3. **Question form missed.** §5 quotes the source's first part as a question ("Can
   the set … have $n$ connected components?") and §6 never objects to the bare
   assertion encoding — missing the A4 defect. The style review (`reviews/1042.md`
   §6) is worse: "The original problem is a two-part **assertion** … Both are Case 3
   — direct assertions (no yes/no question…)" is factually false against the
   recovered source, in which both parts end in question marks. Same failure as
   1005's style review.
4. **Minor.** (a) §5 calls "for infinitely many $n$" "the strongest natural reading"
   of the question, then §6 correctly concedes it is weaker than "for all $n$" — the
   two passages contradict each other; the encoding choice (match the proved result)
   is nonetheless right. (b) §6's claim that `sSup … ^ (2/0)` at $n \in \{0,1\}$
   yields $d_n = 1$ for nonempty $F$ is correct, as is its note that `Real.sSup`
   returns $0$ on empty/unbounded sets. (c) Its citation section did not question the
   "[GhRa24] Ghosh, S. and Ramachandran, D." initials, which the page (which it
   claims to have checked) does not contain — an unflagged fabrication. (d) The
   "Piranien" site-typo observation is confirmed by the recovery.
