## Summary

The problem (Erdős–McKay conjecture, PROVED, $100): for any ε > 0 there exists
δ = δ(ε) > 0 such that any graph on n vertices with no independent set or clique of size
≥ ε log n contains an induced subgraph with exactly m edges for every m ≤ δn². Solved by
Kwan–Sah–Sauermann–Sawhney [KSSS22]. The Lean statement (`conjectures/88.lean:24-33`)
says: ∀ ε > 0, ∃ δ > 0, ∀ n and every graph G on `Fin n` with
`G.CliqueFree ⌈ε·log n⌉₊` and `Gᶜ.CliqueFree ⌈ε·log n⌉₊`, every natural m with
(m : ℝ) ≤ δn² is realized as `inducedEdgeCount G S` for some vertex set S. Read back
independently, this is exactly the source statement; I found no semantic defects, only
scholarship/polish nits (missing Erdős reference keys, no bibliography block, a confirmed
partial-result variant worth recording).

## A. Semantic fidelity

**A1. Statement fidelity — pass (source-verified).**

- The recovered page statement (capture in
  `claude-session-logs/026ea112-7658-4b75-9d1e-b64ed79a8b25.jsonl`, a read of
  `tidy/88.html`) matches the theorem docstring essentially verbatim.
- Independent back-translation of lines 24-32: for every ε > 0 there is a δ > 0 such
  that for every n and every graph G on n vertices in which neither G nor its complement
  has a clique on ⌈ε ln n⌉ vertices, every integer edge count m with m ≤ δn² is attained
  by some induced subgraph. This is the conjecture as asked.
- Quantifier structure: δ depends only on ε (bound before n, G — correct; a δ inside the
  ∀ n would be a wrong, much weaker statement). m is universally quantified innermost —
  correct ("for all m ≤ δn²").
- "Independent set in G" = "clique in Gᶜ": the complement encoding is exact.
- "No clique of size ≥ x" for real x = ε log n: clique sizes are integers, so
  size ≥ x ⟺ size ≥ ⌈x⌉, and `CliqueFree ⌈x⌉₊` (no ⌈x⌉-clique ⟺ no clique of size
  ≥ ⌈x⌉, since cliques are downward closed) is exactly right, including when ε log n is
  an exact integer.
- Not vacuous / not trivial: for ε above the Ramsey-construction threshold the
  hypotheses are satisfiable for infinitely many n, and δ must then serve unboundedly
  many m as n → ∞, so no degenerate δ works. For ε below the Ramsey lower-bound
  threshold the inner statement is vacuous for large n — but that is inherent to the
  informal statement itself, not an encoding artifact.
- The ∀-n form (no "sufficiently large n") matches the page verbatim, and is anyway
  equivalent to the eventually-form: shrink δ so δn² < 1 for all n below the threshold,
  leaving only m = 0, witnessed by S = ∅.

**A2. Lean semantics traps — pass.**

- No ℕ subtraction or division anywhere.
- `Real.log 0 = 0` and `Real.log 1 = 0` in Lean, so for n ≤ 1 the clique bound is
  `⌈ε·0⌉₊ = 0`; `CliqueFree 0` is False (the empty set is a 0-clique), so the
  hypotheses are unsatisfiable and the cases are vacuous — consistent with the source's
  degenerate cases (informally, the empty set is a clique of size 0 ≥ 0 too).
- `Nat.ceil` of a nonpositive real is 0 — only triggered in the vacuous n ≤ 1 cases
  above (for n ≥ 2 and ε > 0, ε log n > 0).
- `(m : ℝ) ≤ δ * (n : ℝ) ^ 2`: comparison in ℝ after coercion — no truncation; m : ℕ
  makes m ≥ 0 automatic, matching "0 ≤ m ≤ δn²".
- The binder `(h : DecidableRel G.Adj)` with `haveI := h`: `DecidableRel G.Adj` is
  never empty (classical instances always exist), so the ∀-h quantification introduces
  no vacuity; and `Finset.card ∘ Finset.filter` is instance-irrelevant, so the truth of
  the statement does not depend on which h is supplied. `Gᶜ.CliqueFree` needs no
  decidability at all.
- No filters/liminf/limsup; no `StrictMono`/interval issues. Strictness audit: both
  "size ≥ ε log n" (via the ceiling, see A1) and "m ≤ δn²" (non-strict `≤`) match the
  source.

   any threshold, leaving only m = 0 (witnessed by S = ∅). Same failure class as the
   1000 review's invented-then-excused discrepancy.
