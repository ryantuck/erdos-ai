## Summary

Its remark is "Yes, as shown by Pilatte [Pi23]."

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Does there exist an infinite Sidon set which is an asymptotic basis of order 3?" Remark: "Yes, as
  shown by Pilatte [Pi23]."
- **Back-translation of the input's theorem:** "There is a set `A` of natural numbers which is infinite, such that
  `a + b = c + d` with `a, b, c, d ∈ A` forces `{a, b} = {c, d}`, and such that every sufficiently large natural number is
  a sum of three (not necessarily distinct) elements of `A`."
- **Checks.**
  - *Sidon.* The standard definition (all sums `a + b`, with `a = b` allowed, determine `{a, b}`), as in Problems 152 to 156.
  - *Asymptotic basis of order 3.* The standard definition: the 3-fold sumset contains every large integer, with repetition
    allowed. `variants.basis_iff_add` proves in Lean that it is "`n ∈ A + A + A` for all large `n`" for Mathlib's pointwise sum.
    The page gives no definition of its own.
  - *Infinite.* `Set.Infinite A` is redundant: a set of which every large number is a sum of three elements is infinite
    (`infinite_of_basis`), because a finite set has finitely many 3-sums. `variants.infinite_redundant` proves the
    equivalence, so this conjunct does not strengthen the statement.
  - *The element $0$.* `A : Set ℕ` may contain `0`, whereas the page speaks of sets of positive integers. Translating `A` by
    `1` preserves the Sidon property and turns an asymptotic basis of order 3 into one (the 3-fold sumset is shifted by 3),
    so the two readings are equivalent: `variants.positive_version`, proved in Lean.
  - *"Exactly three" or "at most three".* The input uses exactly three summands. With `0 ∈ A` the two coincide, and the
    translation shows that no generality is lost for `0 ∉ A`. If the page meant "at most three", the input would be the
    stronger statement, and it is still the one Pilatte proves as the model recalls (three summands; not checked here).
    **DEFERRED:** the wording of his theorem.
  - *Direction.* The question is a yes/no existence question, answered YES; the input asserts the existence, so it is the
    true direction.
  - *Non-triviality.* Both conjuncts are individually easy (the integers form a basis of order 3; $\{2^i\}$ is an infinite
    Sidon set) and the statement is not: a Sidon set has $O(\sqrt N)$ elements up to $N$ and a basis of order 3 needs at
    least about $N^{1/3}$, and a Sidon set cannot be a basis of order 2 (counting; background, not formalized).
