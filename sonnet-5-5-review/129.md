## Summary

The page asks to prove that $R(n;3,r)<C^{\sqrt n}$ for some $C=C(r)>1$, where $R(n;k,r)$ is the least
$N$ such that every $r$-colouring of the edges of $K_N$ leaves some $n$ vertices without a copy of
$K_k$ in at least one colour. It records that Erdős and Gyárfás proved a lower bound
$R(n;3,r)>C^{\sqrt n}$, Erdős's belief in a general two-sided bound, and Girao's observation that the
statement as written is easily disproved. It says it is unclear what Erdős meant.

The Lean encodes the proposition as written and the definitions are right. The proposition is
false, so the theorem asserts the wrong direction, and the module docstring even says so. The
degenerate $r=1$ case is true only through a junk value, and the reference key is undefined.

## A. Semantic fidelity

**A1. Statement fidelity: pass for the proposition as written.**

- **Source** (verbatim): "Let $R(n;k,r)$ be the smallest $N$ such that if the edges of $K_N$ are
  $r$-coloured then there is a set of $n$ vertices which does not contain a copy of $K_k$ in at least
  one of the $r$ colours. Prove that there is a constant $C=C(r)>1$ such that
  $R(n;3,r)<C^{\sqrt{n}}$."
- **Back-translation:** "For every $r\ge1$ there is $C>1$ such that for every $n$, the least $N$ for
  which every $r$-colouring of $K_N$ has an $n$-set with no monochromatic triangle in some colour is
  below $C^{\sqrt n}$."
- **Item by item.**
  - $R(n;k,r)$: `multicolorRamseyNum n k r`, the `sInf` of the set of $N$ such that every colouring
    has an $n$-set that is $K_k$-free in some colour;
  - "does not contain a copy of $K_k$ in at least one colour": `∃ c, IsMonoKkFree χ c k S`, with
    `IsMonoKkFree` saying no $k$-subset has all its pairs in colour $c$;
  - "$C=C(r)$": `∃ C` after `∀ r`. The page does not say for which $r$ and $n$. The first pass
    takes every $r\ge1$ and every $n$, which is the natural reading, with the caveats in A2.
- **Ordered pairs.** `EdgeColoring N r` colours ordered pairs, with no symmetry condition. This gives
  the same Ramsey number as symmetric colourings. A $c$-clique under $\chi$ needs all ordered pairs
  to have colour $c$. Replacing $\chi\,x\,y$ by $\chi\,(\min x\,y)\,(\max x\,y)$ gives a symmetric
  colouring with at least the same $c$-cliques, so a set that is $K_k$-free for the symmetric
  colouring is $K_k$-free for $\chi$. So $N$ has the property for all colourings iff it has it for all
  symmetric colourings, and the two `sInf`s are equal.

**A2. Lean semantics traps: one finding.**

- **`sInf ∅ = 0` at $r=1$ (machine-checked).** For one colour every triple is a monochromatic
  triangle, so for $n\ge3$ no $N$ is admissible and the set is empty. Then
  `multicolorRamseyNum n 3 1 = 0`. That is `variants.one_color_junk`, proved in v2. So the $r=1$
  instance of the first pass's proposition reads $0<C^{\sqrt n}$ and is true only through the junk
  value. On the page $R(n;3,1)$ does not exist. This does not affect the verdict, because the
  proposition fails at $r=2$.
- **Nonempty for $r\ge2$.** By Ramsey's theorem some colour class contains an $n$-set, and that set
  has no triangle in any other colour. So the `sInf` is the true minimum for $r\ge2$.
- **$n=0$ (machine-checked).** $N=0$ is admissible, so $R(0;3,r)=0$ for $r\ge1$. In the main
  statement the bound at $n=0$ reads $0<C^0=1$, which is true. It matters for lower-bound
  statements (Part E).
- **Real power.** `C ^ Real.sqrt (n : ℝ)` is a real power with $C>1$, and the Ramsey number is cast
  to ℝ. No subtraction.
- **Subsets.** `T ⊆ S` with `T.card = k` over `Finset (Fin N)` is the right notion of a $k$-subset.

**A3. Definitions: pass.** The three definitions match their docstrings, apart from a wording nit

**A4. Question form and answer polarity: defect.**

- **[defect: wrong-polarity]** The page's "Prove that…" is a statement, not a question, and as
  written it is false. The input asserts it.
- **Re-derivation of the refutation** (Girao's argument, as the page sketches it). Colour the edges
  of $K_N$ red or blue independently and uniformly.
  - Every $n$-set contains at least $cn^2$ edge-disjoint triangles for an absolute $c>0$. In a
    maximal family the uncovered edges form a triangle-free graph, which has at most $n^2/4$ edges
    (Mantel). So the family covers at least $n^2/4-n/2$ edges, and each triangle covers three.
  - A fixed $n$-set contains none of its $m\ge cn^2$ edge-disjoint triangles in red with
    probability $(7/8)^m$, since the triangles are independent. The same holds for blue.
  - There are at most $N^n$ sets. If $\ln N\le\varepsilon n$ with $\varepsilon<c\ln(8/7)$, the
    expected number of $n$-sets lacking a red or a blue triangle is at most
    $2\exp\bigl(n\ln N-cn^2\ln(8/7)\bigr)\le2\exp\bigl(n^2(\varepsilon-c\ln(8/7))\bigr)\to0$.
  - So some colouring of $K_N$, with $N=\lfloor e^{\varepsilon n}\rfloor$, has a red and a blue
    triangle in every $n$-set. No $n$-set is triangle-free in either colour, hence
    $R(n;3,2)>e^{\varepsilon n}$ for large $n$.
  - For any $C'>1$, $C'^{\sqrt n}<e^{\varepsilon n}$ once $\sqrt n>\ln C'/\varepsilon$. So the
    proposition fails at $r=2$.
- **Fix.** v2 asserts `¬ (…)` with the first pass's proposition byte-identical inside, the corpus
  convention for a refuted statement. `variants.girao` states the bound
  $R(n;3,2)\ge C^n$ for large $n$, and `variants.main_of_girao` proves in Lean that it implies the
  main theorem. So the single analytic input is isolated.
