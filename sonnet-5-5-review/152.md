## Summary

The page (OPEN at capture; the problem is tagged "sidon sets") asks that for every $M\ge1$ a sufficiently large finite
Sidon set $A\subset\mathbb N$ has at least $M$ elements $a\in A+A$ with $a+1,a-1\notin A+A$. It remarks that there may
even be $\gg\lvert A\rvert^2$ such $a$, and that a similar question can be asked for truncations of infinite Sidon sets.

The Lean defines Sidon sets, the sumset and isolation on `Finset ℕ`, and states the question as "for every `M` there is
`N` such that every Sidon set with at least `N` elements has at least `M` isolated points in its sumset".

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "For any $M\geq 1$, if $A\subset \mathbb{N}$ is a sufficiently large finite Sidon set then
  there are at least $M$ many $a\in A+A$ such that $a+1,a-1\not\in A+A$."
- **Back-translation of the input's theorem:** "For every natural number `M` there is `N` such that for every finite
  Sidon set `A` of natural numbers with at least `N` elements, the number of `a ∈ A + A` with `a + 1 ∉ A + A` and
  (`a = 0` or `a - 1 ∉ A + A`) is at least `M`."
- **Checks.**
  - *Sidon.* `IsSidonSet A` says `a + b = c + d` with all four in `A` forces `{a, b} = {c, d}`, the standard definition
    (all sums `a + b` with `a ≤ b` are distinct, equivalently all positive differences are distinct), including the
    cases `a = b` and `c = d`.
  - *The sumset.* `sumset A` is the image of `A × A` under addition, so it contains the sums `a + a`.
    `variants.sumset_eq_add` proves in Lean that it is Mathlib's pointwise `A + A`.
  - *Isolated.* `isIsolatedIn a S` is `a + 1 ∉ S` and (`a = 0` or `a - 1 ∉ S`). For `a = 0` the left neighbour is $-1$,
    not a natural number and not a sum, so the page's "$a-1\notin A+A$" holds, and the clause `a = 0 ||` states that.
    Subtraction in `ℕ` would test `0 ∉ S`, which is wrong; the input avoids it. `variants.count_zero_five` evaluates
    the boundary: all three sums of `{0, 5}` (namely 0, 5, 10) are isolated.
  - *The count.* The filter runs over `sumset A`, so every counted `a` is in `A + A`, as the page requires.
  - *Quantifiers.* `∀ M, ∃ N, ∀ A, Sidon → N ≤ |A| → M ≤ count` is "sufficiently large" for every `M`. The page says
    $M\ge1$; `M = 0` is trivial. This is the statement "$f(n)\to\infty$" for $f(n)$ the least number of isolated points
    over Sidon sets of size $n$, which is how upstream states it.
  - *Indexing.* The count is invariant under translation of `A` (the clause for `0` is what makes it so), so it does
    not matter whether $\mathbb N$ includes $0$.
  - *Non-triviality.* "Sufficiently large" is needed: `{0, 1}` has no isolated point (`variants.count_zero_one`). The
    statement is not vacuous: Sidon sets of every size exist, for example the powers of two.
  - *Evidence for the statement.* The minimum number of isolated points over Sidon sets of size $n$, found by exhaustive
    search (Addendum), is $1,0,1,2,2,3,5,5$ for $n=1,\dots,8$. It is small but non-decreasing from $n=2$, consistent with
    $f(n)\gg n^2$ with a small constant.
- **Comparison with upstream.** Upstream's `erdos_152` (`df3f12d`) is `answer(True) ↔ Tendsto f atTop atTop` with
  `f n` the infimum, over Sidon sets of size `n`, of `#{s | s - 1 ∉ A + A ∧ s ∈ A + A ∧ s + 1 ∉ A + A}`. It is the same
  statement. Its `s - 1` is natural-number subtraction, so it never counts `s = 0` (where `0 - 1 = 0`), a difference of
  at most one in the count for sets containing `0`, which does not change the limit.
