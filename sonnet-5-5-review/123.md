## A. Semantic fidelity

**A1. Statement fidelity: DEFECT (fixed).**

- **Source** (verbatim): "Let $a,b,c\geq 1$ be three integers which are pairwise coprime. Is
  every large integer the sum of distinct integers of the form $a^kb^lc^m$ ($k,l,m\geq 0$),
  none of which divide any other?"
- **Back-translation of the input:** "for all $a,b,c\ge1$ pairwise coprime, there is $N$ such
  that every $n\ge N$ is the sum of a finite set of distinct elements of
  $\{a^kb^lc^m\}$ that is an antichain under divisibility."
- **[defect: false-at-small-parameters]** The hypotheses admit degenerate triples:
  1. **$(1,1,1)$.** Pairwise coprime holds, and the set is $\{1\}$. A sum of distinct elements
     is at most $1$, so no $n\ge2$ works. The theorem is false there. v2 proves this in Lean as
     `variants.first_pass_false`.
  2. **$(1,1,c)$, $c\ge2$.** The set is $\{c^m\}$. Since $c^i\mid c^j$ for $i\le j$, an
     antichain has at most one element, so only the powers of $c$ are representable. False.
  3. **$(1,b,c)$, $b,c\ge2$ coprime.** The set is $\{b^lc^m\}$. By Erdős and Lewin [ErLe96],
     as recorded on the page of Problem #1110, finitely many $n$ fail to be representable if
     and only if $\{b,c\}=\{2,3\}$. So the theorem is false at $(1,3,5)$, $(1,2,5)$, $(1,5,7)$
     and every such triple except $\{2,3\}$.
  - **Brute force** (exhaustive over divisibility antichains), for $n\le900$:

    | triple | non-representable $n\le900$ | largest of them |
    |---|---|---|
    | $(1,2,3)$ | 0 | none |
    | $(1,3,5)$ | 726 | 892–898, 900 |
    | $(1,2,5)$ | 373 | 878, 880, 884, 886–888, 892, 894 |
    | $(1,5,7)$ | 850 | 893–900 |

    $\{2^k3^l\}$ is the one $d$-complete two-power set. The others keep non-representable
    numbers right up to $900$.
- **The page's "$\ge1$" cannot be the intended range.** It includes triples for which the
  statement is false. The page also points to #1110 "for the case of two powers", as a
  different problem. Upstream uses $a,b,c>1$ and notes that the integers must be greater than
  one and distinct, or the problem reduces to the two-integer case.
- **v2.** `2 ≤ a`, `2 ≤ b`, `2 ≤ c`. The statement is otherwise byte-identical.

- **The antichain.** `DivisibilityAntichain s` is `∀ x ∈ s, ∀ y ∈ s, x ∣ y → x = y`, which is "no
