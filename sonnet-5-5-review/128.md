## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $G$ be a graph with $n$ vertices such that every induced subgraph on
  $\geq \lfloor n/2\rfloor$ vertices has more than $n^2/50$ edges. Must $G$ contain a triangle?"
- **Back-translation:** "For every finite graph $G$ on $n$ vertices, if every vertex set $S$ with
  $\lvert S\rvert\ge\lfloor n/2\rfloor$ induces more than $n^2/50$ edges, then $G$ has three
  pairwise adjacent vertices."
- **Item by item.**
  - "graph with $n$ vertices": `[Fintype V]` and `hn : Fintype.card V = n`;
  - "induced subgraph on $\ge\lfloor n/2\rfloor$ vertices": `S : Finset V` with `n / 2 ≤ S.card`,
    where natural division is the floor;
  - "more than $n^2/50$ edges": `50 * inducedEdgeCount G S > n ^ 2`. For naturals,
    $e>n^2/50\iff 50e>n^2$, with no rounding;
  - "contain a triangle": three distinct, pairwise adjacent vertices.
- **Upstream** writes the size condition as `2 * V'.ncard + 1 ≥ Fintype.card V`. For $n=2m$ that is
  $\lvert V'\rvert\ge m-\tfrac12$, so $\ge m$. For $n=2m+1$ it is $\ge m$. In both cases it equals
  $\lfloor n/2\rfloor\le\lvert V'\rvert$. Upstream's conclusion `¬ G.CliqueFree 3` is the explicit
  triple. So the two formulations coincide.

**A2. Lean semantics traps: pass.**

- **`inducedEdgeCount`** counts the ordered pairs $(u,v)\in S\times S$ with $u\ne v$ and `G.Adj u v`,
  then halves. Each edge of $G[S]$ gives exactly two ordered pairs, so `/ 2` is exact and there is no
  junk value from natural division. The test `p.1 ≠ p.2` is redundant, since `G.Adj` is irreflexive,
  and harmless.
- **No subtraction, no rounding.** The only arithmetic is `50 * e > n ^ 2` over ℕ.
- **Small $n$.** The hypothesis is vacuous for $n\le3$, because a set of $\lfloor n/2\rfloor\le1$
  vertices has no edges, and for $n\le1$ the empty set qualifies. For $n=4,5$ every pair must be an
  edge, so $G=K_n$, which has triangles. For $n=6,7$ the sets of $3$ vertices need an edge, so $G$
  has no independent triple, and $R(3,3)=6$ gives a triangle. So the statement holds for $n\le7$.
- **Not vacuous.** $K_n$ satisfies the hypothesis for every $n\ge4$, since a set of $\lfloor n/2\rfloor$
  vertices has $\binom{\lfloor n/2\rfloor}2$ edges and $50\binom{\lfloor n/2\rfloor}2>n^2$.
- **Universe and instances.** `{V : Type*}` with `[Fintype V] [DecidableEq V]` and
  `[DecidableRel G.Adj]` as arguments is the standard encoding. `Fintype.card V` does not depend on
  the choice of instance.
- **The extremal examples respect the strict inequality.** If a triangle-free graph satisfied the
  hypothesis, the statement would be false. The Petersen graph and the $C_5$ blow-ups do not (C1).
