## Summary

The page (OPEN; tag "sidon sets") asks: does there exist a maximal Sidon set $A\subset\{1,\dots,N\}$ of size $O(N^{1/3})$?
It records that this is a question of Erdős, Sárközy and Sós, that the greedy construction gives size $\gg N^{1/3}$ (easy),
that Ruzsa constructed one of size $\ll(N\log N)^{1/3}$, and "See also [340]".

The Lean defines Sidon sets on `Finset ℕ`, a maximal Sidon set in `range N` (a Sidon subset of `range N` to which no other
element of `range N` can be added), and states the question as "there is `C > 0` such that eventually in `N` some maximal
Sidon set `A` has `A.card ≤ C * N ^ (1/3)`".

- **Checks.**
  - *Sidon.* `IsSidonSet` is the standard definition (all sums `a + b`, with `a = b` allowed, determine `{a, b}`), as in

  - *Maximality.* `A ⊆ range N`, `A` Sidon, and for every `n ∈ range N` not in `A`, `insert n A` is not Sidon: inclusion-maximal

    weaker than maximum (`maximal_not_maximum`: in `{0, …, 6}` both `{1, 2, 5}` and `{0, 1, 4, 6}` are maximal).
  - *The interval.* The page uses $\{1,\dots,N\}$ and the Lean uses `range N = {0, …, N - 1}`. The Sidon property is
    invariant under translation, and so is maximality in the translated interval, so the two readings agree.

    `C * N ^ (1/3)` eventually.

    the real power of a nonnegative base.

    $1/2$, since every maximal Sidon set in `range N` has at least $N^{1/3}/2$ elements; and Ruzsa's bound shows that sets of
    size $(N\log N)^{1/3}$ exist, so only the logarithm is at stake.

- **The easy bound.** For a maximal Sidon $A$ in $\{0,\dots,N-1\}$, every $x\notin A$ in the interval cannot be added, so
  $x+x=c+d$ or $x+a=c+d$ for some $a,c,d\in A$ (`sidon_insert`), i.e. $x=(c+d)/2$ or $x=c+d-a$. That gives at most

  $\lvert A\rvert\ge N^{1/3}/2$ (`lower_bound`: from $N\le3\lvert A\rvert^3$ for $\lvert A\rvert\ge1$). The page states the
  bound for the greedy construction; the argument gives it for every maximal Sidon set.
- **The gap.** The page's question is whether this lower bound is attained up to a constant, with Ruzsa's bound off by
  $(\log N)^{1/3}$.

  `IsGreedySidonSequence`).
