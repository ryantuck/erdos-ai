## Summary

The page (OPEN; tags "additive combinatorics" and "arithmetic progressions"; edited 02 December 2025) defines $h(N)$ as the
smallest $k$ such that $\{1,\dots,N\}$ can be coloured with $k$ colours so that every four-term arithmetic progression
contains at least three distinct colours, and asks to estimate $h(N)$. It records: investigated by Erdős and Freud;
LeechLattice shows $h(N)\ll N^{2/3}$ on MathOverflow; Hunter improves this to $N^{\log3/\log22+o(1)}$ (with
$\log3/\log22\approx0.355$) in a comment; and Hunter's observation with [BlSi23] and [KeMe23] gives
$h(N)\gg\exp(c(\log N)^{1/9})$.

The Lean defines `RainbowOn4AP N k f` (every 4-term progression `a, a + d, a + 2d, a + 3d` in `{1, …, N}` has more than two
distinct colours under `f : ℕ → Fin k`) and `AdmitsRainbow4AP N k` (such an `f` exists), and states
`∀ k, ∃ N₀, ∀ N ≥ N₀, ¬ AdmitsRainbow4AP N k`.

## A. Semantic fidelity

**A1. Statement fidelity: defect (wrong target; trivially true).**

- **Source** (verbatim): "Let $h(N)$ be the smallest $k$ such that $\{1,\ldots,N\}$ can be coloured with $k$ colours so that
  every four-term arithmetic progression must contain at least three distinct colours. Estimate $h(N)$."
- **Back-translation of the input's theorem:** "For every `k` there is `N₀` such that for every `N ≥ N₀` there is no colouring
  of `{1, …, N}` with `k` colours in which every 4-term arithmetic progression contained in `{1, …, N}` has at least three
  distinct colours." That is: the least number of colours $h(N)$ is unbounded.
- **Checks.**
  - *The definitions.* `RainbowOn4AP` requires `2 < card {f a, f (a + d), f (a + 2d), f (a + 3d)}` for every `a ≥ 1`, `d ≥ 1`
    with `a + 3d ≤ N`: at least three distinct colours on each 4-term progression inside $\{1,\dots,N\}$, as the page says.
    Only the values of `f` on `{1, …, N}` matter, so `f : ℕ → Fin k` is no restriction. The definitions are right.
  - *The target.* The page asks to *estimate* $h(N)$ and records bounds that differ enormously: $h(N)$ is between
    $\exp(c(\log N)^{1/9})$ and $N^{0.355+o(1)}$. The statement "$h(N)\to\infty$" is much weaker than the lower bound the
    page records, so it is not a formalization of the request, whatever answer the request has.
  - *The statement is a theorem.* A monochromatic 4-term progression exists in every $k$-colouring of $\{1,\dots,N\}$ for
    $N\ge W(4,k)$ (van der Waerden), and it has a single colour, so it has fewer than three. `variants.first_pass` proves
    the input's statement in Lean from Mathlib's Hales–Jewett theorem (`Combinatorics.Line.exists_mono_in_high_dimension`):
    colour the cube $(\mathrm{Fin}\,4)^m$ by $f(\sum x_i+1)$, take a monochromatic combinatorial line, and read its four
    points as a progression $b+1,\,b+1+s,\,b+1+2s,\,b+1+3s$ in $\{1,\dots,3m+1\}$, with $s$ the number of moving
    coordinates of the line. The file nevertheless leaves it as a
    `sorry`, which the corpus reserves for open or unproved statements.
  - *`h` itself.* The input never defines $h$. In v2 it is `minRainbowColours`, the `sInf` of a nonempty set (`admits_self`:
    `N + 1` colours suffice), with `h 1 = 1`, `h 4 = 3` and `h` nondecreasing, all proved in Lean. Exhaustive search gives
    the values in the Addendum: $h=1,3,4,5,6$ from $N=1,4,13,23,36$.
  - *Degenerate cases.* For `N ≤ 3` there is no 4-term progression, so one colour suffices (`h 1 = 1`); with fewer than three
    colours no progression can have three, so `h` jumps from `1` to `3` at `N = 4` (`h 4 = 3`).
- **What v2's main theorem says.** For some closed-form `f` (built from constants and the identity by sums, products,
  reciprocals, `exp` and `log`) and constants `c, C > 0`, `c · f(N) ≤ h(N) ≤ C · f(N)` for all large `N`. This reads "estimate"
  as an order of magnitude, as `142.lean` and `148.lean` do; the class of closed forms is an editorial choice, and the
  statement is OPEN.
