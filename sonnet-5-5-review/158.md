## Summary

The page (OPEN; tag "sidon sets") asks: for an infinite set $A\subset\mathbb N$ such that every $n$ has at most 2
solutions to $a+b=n$ with $a\le b$, must $\liminf_{N\to\infty}\lvert A\cap\{1,\dots,N\}\rvert/N^{1/2}=0$? It remarks that
replacing 2 by 1 makes $A$ a Sidon set, for which Erdős proved this is true.

The Lean defines `repCount A n` (the number of pairs `(a, b)` of elements of `A` with `a ≤ b` and `a + b = n`, by
`Set.ncard`), `countBelow A N` (the cardinality of `A ∩ {1, …, N}`), and states: for every infinite `A` with
`repCount A n ≤ 2` for all `n`, `liminf (countBelow A N / √N) = 0`.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $A\subset \mathbb{N}$ be an infinite set such that, for any $n$, there are most $2$ solutions
  to $a+b=n$ with $a\leq b$. Must $\liminf_{N\to\infty}\frac{\lvert A\cap \{1,\ldots,N\}\rvert}{N^{1/2}}=0$?" The page's
  "most" is a typo for "at most". Remark (the page's first-person plural replaced by the bracketed words): "If [one replaces]
  $2$ by $1$ then $A$ is a Sidon set, for which Erdős proved this is true."
- **Back-translation of the input's theorem:** "For every infinite set `A` of natural numbers such that, for every `n`, there
  are at most two pairs `(a, b)` with `a, b ∈ A`, `a ≤ b` and `a + b = n`, the limit inferior of `|A ∩ {1, …, N}| / √N` as
  `N → ∞` is `0`."
- **Checks.**
  - *The representation count.* `repCount A n` counts the pairs of the page's "solutions to $a+b=n$ with $a\le b$". The set
    of pairs is finite (both entries are at most `n`), so `Set.ncard` is the true number and not the junk value `0` of an
    infinite set (`repSet_finite`, proved in Lean).
  - *The counting function.* `countBelow A N = ncard (A ∩ Icc 1 N)` is $\lvert A\cap\{1,\dots,N\}\rvert$, a finite set.
  - *The `liminf`.* `Filter.liminf` of a real sequence is `sSup {a | ∀ᶠ n, a ≤ u n}`, which is the junk value `0` when that
    set is empty or unbounded above, so for a sequence tending to infinity "`liminf = 0`" would hold only because of the
    junk value. Here the sequence is bounded: for a set with at most two representations of each `n`, the $k=\lvert A\cap[1,N]\rvert$
    elements give $k(k+1)/2$ pairs $a\le b$ with sums in $[2,2N]$, each sum used at most twice, so $k^2\le8N+4$
    (`variants.count_sq_le`), and the quotient is at most 4 (`variants.bounded`). So the `liminf` is the genuine one.
    `variants.main_iff_frequently` proves that it is $0$ iff for every $\epsilon>0$ there are infinitely many $N$ with
    $\lvert A\cap[1,N]\rvert<\epsilon\sqrt N$, the page's meaning.
  - *The element $0$.* `A : Set ℕ` may contain `0`, whereas the page speaks of $\mathbb N$ as positive integers.
    `countBelow` ignores `0`, and `A \ {0}` is again infinite with at most two representations, so the statement is
    equivalent to the one for sets of positive integers (`variants.positive_version`, proved in Lean).
  - *Sidon case.* `variants.repCount_le_one_iff` proves in Lean that "at most one representation of every `n`" is exactly
    the four-variable Sidon property of Problems 152–157, so the remark "replace 2 by 1 and $A$ is a Sidon set" holds for
    this encoding.
  - *Non-triviality.* The statement is a conditional, so its hypotheses must be satisfiable. They are: the set
    $\{2^n-1\}$ is infinite and Sidon (`variants.hypotheses_satisfiable`, proved in Lean), hence has at most one, so at
    most two, representations of every `n`. The conclusion is not automatic: the counting bound gives only $\lvert A\cap[1,N]\rvert\le\sqrt{8N+4}$,
    so the quotient is bounded, and the question is whether it must become arbitrarily small along a subsequence.
