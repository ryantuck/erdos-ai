## Summary

The page (PROVED (LEAN); tag "sidon sets") asks whether, for a Sidon set $A\subset\{1,\dots,N\}$ with
$\lvert A\rvert\sim N^{1/2}$, the sumset $A+A$ is well-distributed over small moduli, in particular whether about half of
its elements are even. It records that Lindström [Li98] proved this for $A$ itself, strengthened by Kolountzakis [Ko99],
and that it then follows immediately that $A+A$ is similarly well-distributed.

The Lean defines Sidon sets, the sumset and the proportion of a finite set in a residue class, and states the conclusion
for sequences of Sidon sets $A_n\subseteq\{0,\dots,n\}$ with $\lvert A_n\rvert/\sqrt n\to1$.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $A\subset \{1,\ldots,N\}$ be a Sidon set with $\lvert A\rvert\sim N^{1/2}$. Must $A+A$ be
  well-distributed over all small moduli? In particular, must about half the elements of $A+A$ be even and half odd?"
- **Back-translation of the input's theorem:** "For every sequence of finite Sidon sets $A_n\subseteq\{0,\dots,n\}$ with
  $\lvert A_n\rvert/\sqrt n\to1$, every $m\ge1$ and every $r<m$, the number of elements of $A_n+A_n$ congruent to $r$
  modulo $m$, divided by $\lvert A_n+A_n\rvert$, tends to $1/m$."
- **Checks.**
  - *Sidon and sumset.* `IsSidonSet` is the standard definition. `sumset A` is `A + A` with the sums `a + a`;
    `variants.sumset_eq_add` proves in Lean that it is Mathlib's pointwise sum.
  - *The asymptotic regime.* "A ⊂ {1,…,N} with |A| ∼ N^{1/2}" is a family of sets indexed by `N`, formalized as a sequence
    `A n ⊆ {0,…,n}` with `|A n| / √n → 1`. The upper bound is `range (n + 1)`, so `0` is allowed; a translation of `A` by
    one changes the residues of `A` and of `A + A` and does not affect equidistribution. Upstream allows an arbitrary
    `N k → ∞` (and `m ≥ 2`), which is slightly more general.
  - *"Well-distributed over all small moduli".* For every fixed `m ≥ 1` and every residue `r < m` the proportion of
    `A + A` in the class tends to `1 / m`. "Small" is read as "fixed", the standard reading, and `m = 2` is the page's
    "half even and half odd".
  - *`modFraction`.* The proportion is `count / card`; for an empty set it is `0 / 0 = 0`, which can happen only for
    finitely many `n`, since `|A n| / √n → 1` forces `|A n| → ∞` (`erdos_problem_154.tendsto_card`, proved in Lean).
  - *The docstring's counting claim.* The input says that for `e` even and `o` odd elements `A + A` has exactly
    `e(e+1)/2 + o(o+1)/2` even and `e·o` odd elements, all distinct by the Sidon property. `variants.card_sumset` proves
    that a Sidon set with `n` elements has `n(n+1)/2` sums, and `variants.parity_counts` proves the counts, in Lean.
  - *The reduction.* `variants.sumset_of_lindstrom` proves in Lean that if `A n` is equidistributed modulo `m` (each class has
    `∼ √n / m` elements, Lindström's theorem) and `|A n| / √n → 1`, then `A n + A n` is equidistributed modulo `m`. So the
    theorem is exactly Lindström's theorem transported to the sumset, as the page says, and nothing in the input's
    statement is stronger than that.
  - *Satisfiable hypotheses.* Sidon sets with `|A| ∼ √N` exist for every `N` (Singer's and Bose–Chowla's constructions with a
    prime of the right size), so the statement is not vacuous. This is not formalized.
