## Summary

The page (DISPROVED, \$250) asks whether a planar set of $n$ points in which any four points determine
at least five distinct distances must determine $\gg n^2$ distinct distances, and records Erdős's even
stronger conjecture (a subset of $\gg n$ points with all distances distinct). Tao answered no: for all
large $n$ there is such a set with $\ll n^2/\sqrt{\log n}$ distinct distances.

The Lean defines the number of distinct distances and the four-point property correctly, then asserts
the refuted statement, with no size bound, so that a single point refutes it.

## A. Semantic fidelity

**A1. Statement fidelity: defects (fixed).**

- **Source** (verbatim): "Let $A\subset \mathbb{R}^2$ be a set of $n$ points such that any subset of
  size $4$ determines at least $5$ distinct distances. Must $A$ determine $\gg n^2$ many distances?"
- **Back-translation of the input's theorem:** "There is $c>0$ such that every finite $A\subset\mathbb
  R^2$ with the four-point property determines at least $c|A|^2$ distinct distances."
- **[defect: wrong-polarity]** This is the refuted answer.
- **[defect: false-at-small-parameters]** The statement has no size guard.
  - $A=\{0\}$: `FourPointFiveDist A` holds vacuously, since no subset has $4$ elements.
  - `numDistances A = 0`, since the filter over $A\times A$ for distinct points is empty.
  - The conclusion `c * 1 ^ 2 ≤ 0` is false for every $c>0$. So the proposition is false outright.
  - `variants.first_pass_false` proves this in Lean for the first pass's proposition.
- **Reading of "$\gg n^2$".** The standard meaning of $f(n)\gg g(n)$ is $f\ge cg$ for all large $n$. The
  guard `∃ N, ∀ A, N ≤ A.card → …` expresses that.
- **v2 main theorem:** `¬ ∃ c > 0, ∃ N, ∀ A, N ≤ A.card → FourPointFiveDist A → c * A.card² ≤
  numDistances A`. It follows from Tao's theorem, and `variants.main_of_tao` proves that in Lean.

**A2. Lean semantics traps: pass for v2.**

- **`numDistances`** counts the distinct values of `dist p q` over ordered pairs of distinct points.
  An unordered pair gives the same value in both orders, so the image has the same elements, and the
  count is the number of distinct distances. It equals upstream's `distinctDistances`, which is the card
  of the image of `offDiag`. `offDiag` is also the set of ordered pairs.
- **`FourPointFiveDist`** says every $4$-element subset has at least $5$ distinct distances. Four points
  have $6$ pairs, so at most one coincidence is allowed. It is vacuous for $|A|\le3$.
- **Why the guard matters at $n=1$ and not only at $n=0$.** For $n=0$ the bound reads $0\le0$ and
  holds. For $n=1$ it reads $c\le0$ and fails. The prior review evaluates the $n=1$ case as true (E).
- **Real arithmetic.** The bound is stated in ℝ, with `(A.card : ℝ) ^ 2` and a cast of the distance
  count, so there is no natural-number truncation.
