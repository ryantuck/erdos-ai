## Summary

The page asks (OPEN) for which number-theoretic functions $f$ the following holds: for every
$F$ with $f(n)/F(n)\to0$ for almost all $n$, the ratio
$\#\{n:n+f(n)\in(x,x+F(x))\}/F(x)$ is unbounded. It reports that [EPS97] proved this for the
divisor function and for $\omega$, and that Erdős believed it false for $\varphi$ and $\sigma$.

The input encodes the literal text and asserts the two positive instances. Because the literal
text lets $F$ be huge, no $f$ qualifies. v2 states and proves that, and records the gap.

## A. Semantic fidelity

**A1. Statement fidelity: DEFECT (fixed).**

- **Source** (verbatim): "For which number theoretic functions $f$ is it true that, for any
  $F(n)$ such that $f(n)/F(n)\to 0$ for almost all $n$, there are infinitely many $x$ such
  that $\#\{ n\in\mathbb N: n+f(n)\in (x,x+F(x))\}/F(x)\to\infty$?"
- **Back-translation of `HasErdos122Property f`:** "for every positive $F:\mathbb N\to\mathbb R$
  such that, for every $\varepsilon>0$, $\{n:f(n)/F(n)\ge\varepsilon\}$ has natural density $0$,
  and for every $C$, infinitely many $x$ have ratio $>C$." That is the literal text.
- **[defect: trivially-false-statement]** The property fails for every $f:\mathbb N\to\mathbb N$.
  1. **The adversarial $F$.** Put $F(n)=(n+1)(f(n)+1)>0$.
  2. **The density hypothesis holds.** $f(n)/F(n)\le1/(n+1)$, so $\{n:f(n)/F(n)\ge\varepsilon\}$
     is finite, hence of density $0$.
  3. **The ratio is bounded.**
     - `shiftCount` filters `range (x + ⌈F x⌉₊ + 1)`, so it is at most $x+\lceil F(x)\rceil+1$.
     - Since $\lceil F(x)\rceil<F(x)+1$ and $F(x)\ge x+1\ge1$, the count is below $x+F(x)+2\le
       2F(x)+1\le3F(x)$.
     - So the ratio is at most $3$, and "$>3$ for infinitely many $x$" fails.
  4. **So `erdos_problem_122` is false** for $\tau$ and for $\omega$, and `HasErdos122Property`
     is an empty property.
- **The same argument applies to the page's text.** The page's wording "for any $F(n)$ such
  that $f(n)/F(n)\to0$ for almost all $n$" has the same counterexample, whatever the type of
  $x$ or $F$. So the page's report that [EPS97] proved it for $\tau$ and $\omega$ cannot be
  about this statement. The page must omit a size restriction on $F$.
- **Numeric check** (pure Python, sieved $\tau,\omega,\varphi,\sigma$ up to $8\cdot10^5$). With
  $F(n)=(n+1)(f(n)+1)$, the maximum ratio over $1\le x<400$ is:

  | $f$ | max ratio | $f$ | max ratio |
  |---|---|---|---|
  | $\tau$ | 1.0012 | $\sigma$ | 0.4115 |
  | $\omega$ | 1.0029 | $0$ | 0.9975 |
  | $\varphi$ | 0.6545 | | |

  All are far below the bound $3$.
- **How small must $F$ be?**
  - For $\tau$ and $F(x)=\sqrt x$, numerics give ratio $0.80,\,0.95,\,0.97,\,1.002$ at
    $x=10^2,\dots,10^5$.
  - By the same count, the ratio is $F+O(x^{o(1)})$ over $F$, since $\tau(n)\le n^{o(1)}$. So
    it tends to $1$.
  - So any theorem for $\tau$ can only concern $F$ with $F(x)\le x^{o(1)}$ at the relevant $x$.
    This is an inference from the count, not recovered from the source.
- **v2.** The definitions stay. The false theorem is replaced by `∀ f, ¬ HasErdos122Property f`
  (see A4 for the choice).

**A2. Lean semantics traps: pass for the definitions; they all behave as intended.**

- **`⌈F x⌉₊`** is the natural ceiling of a positive real. The search range
  `range (x + ⌈F x⌉₊ + 1)` is $\{0,\dots,x+\lceil F(x)\rceil\}$. That covers every $n$ with
  $n\le n+f(n)<x+F(x)$, so it is sufficient.
- **`n = 0`.** For the divisor functions, $0+0=0\notin(x,\cdot)$, so it never counts.
- **Division.** `/ F x` is by a positive number. `/ (N : ℝ)` in the density is $0/0=0$ at $N=0$,

- **The hypothesis is satisfiable.** `AlmostAllRatioVanishes f F` holds for suitable $F$, so

- **Casts.** `x : ℕ` is cast to ℝ for the comparison. No ℕ subtraction.
