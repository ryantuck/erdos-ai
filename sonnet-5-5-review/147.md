## Summary

The page (DISPROVED, prize \$500) records the Erdős–Simonovits conjecture: if $H$ is bipartite with minimum
degree $r$, then $\mathrm{ex}(n;H)\gg n^{2-\frac1{r-1}+\epsilon}$ for some $\epsilon=\epsilon(H)>0$. A
probabilistic argument gives $n^{2-\frac2r+\epsilon}$. Janzer disproved the conjecture for even $r\ge4$ [Ja23]
and for $r=3$ [Ja23b], with, for every $\epsilon>0$, a $3$-regular bipartite $H$ with
$\mathrm{ex}(n;H)\ll n^{4/3+\epsilon}$. Janzer conjectures that $n^{2-\frac2r+\epsilon}$ is sharp.

The input asserts the conjecture, and its statement is moreover false at the graph on no vertices.

## A. Semantic fidelity

**A1. Statement fidelity: defect (false at the empty graph), fixed.**

- **Source** (verbatim): "If $H$ is bipartite with minimum degree $r$ then there exists $\epsilon=\epsilon(H)>0$
  such that $\mathrm{ex}(n;H) \gg n^{2-\frac{1}{r-1}+\epsilon}.$"
- **Back-translation of the input's theorem:** "For every $r\ge2$ and every finite simple graph $H$ that is
  $2$-colourable and has all degrees $\ge r$, there are $\epsilon>0$, $C>0$ and $N_0$ such that
  $C\,n^{2-1/(r-1)+\epsilon}\le\mathrm{ex}(n;H)$ for all $n\ge N_0$."
- **Checks.**
  - **The empty graph (defect).** See the verdict. The proof in Lean: `U := PEmpty`, `H := ⊥`, the colouring is
    the empty function, `∀ v : PEmpty, …` is vacuous, `containsSubgraph147 F H` holds for every `F`, so the set
    in `turanNumber147` is empty and `sSup ∅ = 0`, and then `C * n ^ … ≤ 0` contradicts `C > 0`. The fix is
    `[Nonempty U]`, as upstream has.
  - *"Minimum degree $r$" versus "at least $r$".* The input takes $r$ as a lower bound. This is equivalent for the
    universal statement. If the bound holds for every $H$ with its exact minimum degree $d$, it holds for
    $r\le d$ a fortiori, because $2-\frac1{r-1}$ increases with $r$. Taking $r=d$ gives the page's form.
  - *The exponent.* `(2 : ℝ) - 1 / ((r : ℝ) - 1) + ε` has a real subtraction, and $r-1\ge1$ for $r\ge2$, so there
    is no division by zero. The page's condition for the exponent to make sense is $r\ge2$, which the input has.
  - *"$\gg$" and the dependence.* $\epsilon$ and $C$ depend on $H$ (and on $r$), as the page writes
    $\epsilon=\epsilon(H)$. The quantifiers come after `H`, so this is right. "$\gg$" is a lower bound for large
    $n$, which `∃ N₀, ∀ n ≥ N₀` states.
  - *The Turán number.* `variants.containsSubgraph_iff` and `variants.turanNumber_eq_extremalNumber` prove in
    Lean that the input's `turanNumber147` is built from Mathlib's `H ⊑ F` and equals
    `SimpleGraph.extremalNumber n H`.
  - *The conjecture at $r=2$ is true.* The probabilistic exponent $2-\frac2r$ equals $2-\frac1{r-1}$ at $r=2$, so
    the page's probabilistic bound proves the $r=2$ case. The refutation lives at $r\ge3$.
- **The disproof, checked.** For $r=3$ the conjecture needs $C\,n^{3/2+\epsilon}\le\mathrm{ex}(n;H)$. A $3$-regular
  bipartite $H$ with $\mathrm{ex}(n;H)\le C_1\,n^{4/3+1/12}=C_1\,n^{17/12}$ (Janzer, with $\epsilon=1/12$) would give
  $C\,n^{1/12+\epsilon}\le C_1$ for large $n$, which fails because $n^{1/12+\epsilon}\to\infty$.
  `variants.refutation_of_cubic` proves exactly this in Lean, from the statement of [Ja23b] as a hypothesis.
