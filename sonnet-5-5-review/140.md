## Summary

The page (PROVED, \$500) defines $r_3(N)$ as the size of the largest subset of $\{1,\dots,N\}$ without a
non-trivial 3-term arithmetic progression and asks to prove $r_3(N)\ll N/(\log N)^C$ for every $C>0$. It was
proved by Kelley and Meka, and Erdős–Graham and Erdős conjectured that the same holds for every $k$-term
progression.

The Lean defines 3-progression-free finite sets, the function `r3`, and the theorem in $\forall C\,\exists
K\,\forall^\infty N$ form.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $r_3(N)$ be the size of the largest subset of $\{1,\ldots,N\}$ which does not
  contain a non-trivial $3$-term arithmetic progression. Prove that $r_3(N)\ll N/(\log N)^C$ for every $C>0$."
- **Back-translation of the input's theorem:** "For every $C>0$ there is $K>0$ such that, for all large
  $N$, $r_3(N)\le K\cdot N/(\log N)^C$, where $r_3(N)$ is the maximum size of a set $S\subseteq\{1,\dots,N\}$
  with $a+c=2b\Rightarrow a=b$ for all $a,b,c\in S$."
- **Checks.**
  - *Non-trivial.* A progression $a,b,c$ with $a+c=2b$ has $a=b=c$ exactly when it is trivial, so
    "$a+c=2b\Rightarrow a=b$" is "no non-trivial 3-term progression".
    `variants.isThreeAPFree_iff_isAPFree` proves in Lean that it equals "no $a$, $d>0$ with $a$, $a+d$, $a+2d$
    in $S$", and `variants.isThreeAPFree_iff_threeAPFree` that it is Mathlib's `ThreeAPFree`.
  - *Quantifier structure.* $\ll$ for every $C$ means $\forall C>0\,\exists K\,\forall N\ge N_0$, with $K$ and $N_0$
    depending on $C$. That is the input's order, with `∀ᶠ` for $N_0$.
  - *The power.* `(Real.log N) ^ C` is `Real.rpow` with a real exponent. For $N\ge2$ the base is positive. At
    $N=0,1$ the base is $0$, the quotient is $0$ in Lean, and the inequality fails at $N=1$; "for all large $N$"
    excludes those.
  - *Indexing.* The input uses $\{1,\dots,N\}$ as the page does.
- **Not vacuous.** `variants.r3_fourteen_ge` proves in Lean that $r_3(14)\ge8$, from the 3-progression-free set
  $\{1,2,4,5,10,11,13,14\}$, so the maximum is not forced to be small by a defect in the definition.
- **The statement is the Kelley–Meka shape.** `variants.main_of_exp_bound` proves that any bound
  $r_3(N)\le N\exp(-c(\log N)^\delta)$ with $c,\delta>0$ implies the input's theorem, for every $C$ with
  $K=1$. The page does not give Kelley–Meka's exponent, so none is asserted.

**A2. Lean semantics traps: pass.**

- **`sSup` over ℕ.** `r3 N` is the `sSup` of the sizes of 3-progression-free $S\subseteq\{1,\dots,N\}$. The set of
  sizes contains $0$ (`S = ∅`) and is bounded by $N$ (`card_le_r3`), so `sSup` is its maximum. The junk value
  of `sSup` on an unbounded or empty set does not occur.
- **ℕ subtraction and division:** none occur in the definitions. The statement divides in ℝ.
- **Vacuous quantifiers.** `∀ x ∈ S, 1 ≤ x ∧ x ≤ N` is vacuous for $S=\emptyset$, which is the intended
  empty set.
- **`∀ᶠ N`** is "for all sufficiently large $N$", which is the content of $\ll$ for an asymptotic bound.
