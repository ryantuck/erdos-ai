## Summary

The page (OPEN, prize \$10000) defines $r_k(N)$ as the largest size of a subset of $\{1,\dots,N\}$ with no
non-trivial $k$-term arithmetic progression, and asks to prove an asymptotic formula for it. Erdős called the
problem "probably unattackable at present". The page records that he offered \$1000 in [Er97c] and \$10000
in [Er81], where he calls it "probably enormously difficult". It records the best upper bounds (Kelley–Meka for
$k=3$, Green–Tao for $k=4$, Leng–Sah–Sawhney for $k\ge5$), says that an asymptotic formula is out of reach
even for $k=3$, and says that in [Va99] Erdős asks "much more reasonably" for the order of magnitude.

The Lean states "for every $k\ge3$ there is a function $f$ with $r_k(N)/f(N)\to1$".

## A. Semantic fidelity

**A1. Statement fidelity: defect (trivially true), fixed.**

- **Source** (verbatim): "Let $r_k(N)$ be the largest possible size of a subset of $\{1,\ldots,N\}$ that does
  not contain any non-trivial $k$-term arithmetic progression. Prove an asymptotic formula for $r_k(N)$."
- **Back-translation of the input's theorem:** "For every $k\ge3$ there is a function $f:\mathbb N\to\mathbb R$
  with $f(N)>0$ for all large $N$ such that $r_k(N)/f(N)\to1$."
- **Checks.**
  - *The statement is trivially true.* For $k\ge2$ and $N\ge1$ the set $\{0\}$ is $k$-progression-free, so
    $r_k(N)\ge1$. Then $f(N)=r_k(N)$ is positive for $N\ge1$ and $r_k(N)/f(N)=1$, so the ratio tends to $1$.
    `variants.first_pass_trivial` proves exactly the input's statement in Lean from this (with the helper
    `one_le_rk`). Every eventually positive sequence is asymptotic to itself.
  - *This is not a loose reading of the page.* "An asymptotic formula" means an explicit closed form. The page
    says that a formula is far out of reach even for $k=3$, which cannot be said of the existence of a function
    asymptotic to $r_k$. Upstream keeps the requirement by leaving the function as `answer(sorry)`:
    `r k N ~ answer(sorry)`. The input turned the unknown formula into an unconstrained existential, and
    the problem disappeared.
  - *What a repair needs.* A formula needs a class of admissible functions. The page names none. v2 takes the
    closed forms built from constants and the identity by $+$, $\times$, reciprocals, $\exp$ and $\log$
    (`IsExpLog`). That class contains $x^a$, $(\log x)^b$, $x\exp(-c(\log x)^\delta)$ and every nesting of
    these. These are the shapes of the bounds that the model recalls (Behrend's lower bound and the
    Kelley–Meka and Leng–Sah–Sawhney upper bounds), although the page gives none of those formulas. The class
    contains no function of arithmetic nature: there is no `sin`, floor, cast from ℕ, `if`, or divisor
    function. Hence $f=r_k$ is not an obvious witness, and the statement is no longer trivially true.
  - *Is the class loose enough to be trivial again?* The model expects not, but this is an informal argument
    and was not formalized. The only discontinuities available are Lean's junk values `x⁻¹ = 0` at `0` and
    `log 0 = 0` (and `log` of a negative number is `log |x|`). Hardy's theorem says that a germ at $+\infty$
    built from exp-log operations is eventually of constant sign, so a denominator or a logarithm argument is
    eventually either never zero or identically zero, and the junk values are harmless. The model recalls this
    theorem and did not check a source for it.
  - *Is the class tight enough to be unfair?* A true formula would have to be exp-log for the main theorem to
    hold. That cannot be decided now. The page has no known formula, and the problem is open. So the statement
    is neither provable nor refutable by what is known.
  - *The $k\ge3$ guard.* By inspection of the definitions, `rk 0 N = rk 1 N = 0` and `rk 2 N = 1` for
    $N\ge1$. The ratio $r_k/f$ cannot tend to $1$ for $k\in\{0,1\}$, and for $k=2$ the problem is trivial, so
    `3 ≤ k` is right, in the input and in v2.
- **The positivity clause is redundant but harmless.** Since $r_k(N)\ge1$, a ratio close to $1$ forces $f(N)>0$.
  The clause is kept as in the input.

**A2. Lean semantics traps: pass.**

- **ℕ subtraction and division:** none occur in the statement or in `APFree`, which uses `a + i * d`.
- **`sSup` over ℕ.** `rk` is `sSup` of the sizes of $k$-progression-free subsets of `range N`. For $k\ge1$ the
  set of sizes contains `0` (from `∅`) and is bounded by `N`, so `sSup` is the maximum and not a junk value.
  `card_le_rk` proves the part that matters: every such subset has at most `rk k N` elements, using
  `BddAbove`.
- **Junk values in the ratio.** `r / f N` with `f N = 0` is `0` in Lean. The ratio cannot tend to $1$ through
  such values, so no junk witness arises, and the positivity clause is not load-bearing.
- **Asymptotics at small $N$.** `∀ᶠ` and `atTop` ignore finitely many $N$, so no guard for $N=0,1$ is needed.
  Compare Problem 135, where an unguarded statement was false at one point.
- **Types.** v2 takes `f : ℝ → ℝ` so that `exp` and `log` compose, and evaluates at `(N : ℝ)`.

**A3. Definitions: pass.**

- **`APFree k S`:** for all `a` and `d > 0` there is `i < k` with `a + i * d ∉ S`. That is the negation of "S
  contains `a, a + d, …, a + (k-1) * d`", with $d\ge1$ for non-trivial progressions. The start `a` may be
  `0`, which matches the range $\{0,\dots,N-1\}$.
- **`rk k N`:** the maximum size of an `APFree k` subset of `range N`, that is, of $\{0,\dots,N-1\}$. The page
  uses $\{1,\dots,N\}$. A shift by one maps progression-free subsets of one range onto those of the other, so
  the two maxima agree.
- **Checked on an instance.** `variants.rk_three_nine` proves in Lean that `rk 3 9 = 5`, the classical value
  $r_3(9)=5$, with the extremal set $\{1,2,4,8,9\}$ shifted to $\{0,1,3,7,8\}$. The upper bound is a finite
  check over the $2^9$ subsets, which `apFree_iff_bounded` makes possible: for $k\ge2$ and $S\subseteq[0,N)$,
  `APFree k S` only needs $a,d<N$. A search (Addendum) computes $r_3,\dots,r_6$ for $N\le36$, and the $r_3$
  values agree with the classical values that the model recalls.
- **`IsExpLog` (new in v2):** an inductive predicate on `ℝ → ℝ`, with constructors `const`, `id`, `add`, `mul`,
  `inv`, `exp` and `log`. Subtraction and division are obtained from `mul` by the constant $-1$ and from
  `inv`.

**A4. Question form and answer polarity: pass, with the note below.** The problem asks for an object ("Prove an
