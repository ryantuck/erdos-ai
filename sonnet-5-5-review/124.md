## Summary

Two questions about writing large integers as sums of numbers whose base-$d_i$ digits are
all $0$ or $1$. The first, due to Erdős, has a positive answer. The second, a conjecture of
Burr, Erdős, Graham and Li with the extra condition $\gcd=1$, is open and known for
$\{3,4,7\}$. The input states both in the "yes" direction. Only the status label of the first
is wrong.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim, with the page's $d_r$ typo): "Let $3\leq d_1<d_2<\cdots <d_r$ be
  integers such that $\sum_{1\leq i\leq r}\frac{1}{d_r-1}\geq 1$. Can all sufficiently large
  integers be written as a sum of the shape $\sum_i c_ia_i$ where $c_i\in \{0,1\}$ and
  $a_i\in P(d_i,0)$? If we further have $\gcd(d_1,\ldots,d_r)=1$ then, for any $k\geq 1$, can
  all sufficiently large integers be written as a sum of the shape $\sum_i c_ia_i$ where
  $c_i\in \{0,1\}$ and $a_i\in P(d_i,k)$?"
- **The typo.** The page writes $1/(d_r-1)$ inside a sum over $i$, which would just give
  $r/(d_r-1)$. The intended summand is $1/(d_i-1)$, which is what the input uses, and what
  Pomerance's necessary condition requires.
- **Part 1, back-translation.** "For every finite set `ds` of integers $\ge3$ with
  $\sum_{d\in ds}1/(d-1)\ge1$, there is $N_0$ such that every $N\ge N_0$ equals $\sum_{d\in
  ds}f(d)$ with each $f(d)\in P(d,0)$." That is the page's question: strictly increasing is
  automatic for a `Finset`, and $c_i\in\{0,1\}$ is absorbed because $0\in P(d,k)$.
- **Part 2, back-translation.** The same, plus `ds.gcd id = 1`, and for every $k\ge1$ a threshold
  $N_0$ with $f(d)\in P(d,k)$. Matches the page. $N_0$ may depend on `ds` and $k$.
- **`powerSumSet d k`** is $P(d,k)$: $n=\sum_{i\in S}d^i$ with every $i\in S$ at least $k$.
  For $d\ge3$ this is the set of integers with digits in $\{0,1\}$ vanishing below position $k$.
  The docstring says this.

**A2. Lean semantics traps: pass.**

- **No ℕ subtraction.** The hypothesis casts $d$ to ℝ before subtracting $1$. As $d\ge3$,
  $d-1\ge2>0$.
- **The sum condition is not vacuous, and not trivial.** It forces $r\ge3$, since $1/2+1/3=5/6<1$.
- **Empty case.** For `ds = ∅` the sum is $0<1$, so the hypothesis fails.
- **Quantifier order.** `∃ N₀, ∀ N ≥ N₀, ∃ f` is the standard form of "all sufficiently large
  integers".
- **`ds.gcd id`** is the gcd of the elements, for a `Finset ℕ`.
- **Numeric check** (pure Python, sumsets of $P(d,k)$ up to the stated bound):

  | `ds` | $k$ | $\sum1/(d-1)$ | non-representable $n\le$ bound |

  | $\{3,4,6\}$ | 0 | 1.0333 | none up to 4000 |
  | $\{3,5,6,7\}$ | 0 | 1.1167 | none up to 4000 |
