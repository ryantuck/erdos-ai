## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $A\subset\mathbb{R}^2$ be an infinite set which contains no three points
  on a line and no four points on a circle. Consider the graph with vertices the points in $A$, where
  two vertices are joined by an edge if and only if they are an integer distance apart. How large can
  the chromatic number and clique number of this graph be? In particular, can the chromatic number be
  infinite?"
- **Back-translation:** "There is an infinite $A\subseteq\mathbb R^2$ with no three distinct collinear
  points and no four distinct concyclic points, such that the graph on $A$ joining two points at a
  positive integer distance is not finitely colourable."
- **Item by item.**
  - "infinite set": `A.Infinite`, for any cardinality, as on the page;
  - "no three points on a line": the first conjunct, over distinct triples, with
    `Collinear ℝ {p, q, r}`;
  - "no four points on a circle": the second conjunct, over distinct quadruples, with `Concyclic`,
    which asks for one centre and one positive radius at which all four points lie;
  - "an integer distance apart": `∃ n : ℕ, 0 < n ∧ dist p q = n` for `p ≠ q`;
  - "the chromatic number is infinite": `chromaticNumber = ⊤`.
- **What is formalized.** Only the "in particular" part. The first question, how large the chromatic
  number and the clique number can be, is open-ended and not a precise statement (B2).
- **Upstream** uses `InGeneralPosition A` (`NonTrilinear A` and no four-element cospherical subset)
  and `IntegerDistancePlaneGraph A` (adjacent iff `∃ n : ℕ, 0 < n ∧ dist x y = n`). These are
  equivalent to the input's definitions. A positive distance forces distinctness, so the explicit
  `≠` in `intDistGraph` is redundant, and `ncard = 4` selects exactly the distinct quadruples.

**A2. Lean semantics traps: pass.**

- **Distinctness.** Both general-position clauses quantify over distinct points, as they must: three
  equal points are trivially collinear and four equal points trivially concyclic.
- **Lines and circles.** Four collinear points are not concyclic, but they are excluded by the first
  clause, so "no four on a circle" loses nothing.
- **`Concyclic`.** The radius is positive. For four distinct points that is automatic, and it rules
  out the degenerate zero-radius circle.
- **The graph** lives on the subtype `↥A`, with `symm` and `loopless` proved. The positivity condition
  `0 < n` is redundant for distinct points and harmless.
- **`chromaticNumber`** has type `ℕ∞`, and `⊤` holds exactly when no finite colouring is proper
  (`SimpleGraph.chromaticNumber_ne_top_iff_exists` in Mathlib). That is the reading of "infinite
  chromatic number".
- **Not made trivial by the encoding.** Edges need a positive integer distance, and general position
  rules out collinear sets, which are the obvious infinite integer-distance cliques.

**A3. Definitions: pass.** The three definitions match their docstrings. No `sorry` in definitions.

- **The sub-question the page answers.** "Erdős also asked whether such a graph could contain an
  infinite complete graph, but this is impossible" is a solved sub-question. The first pass recorded
  it only through the false remark of C1. `no_infinite_clique` is the correct statement.
- **The clique half of the first question and Problem 213.** An infinite general-position set whose
  graph has an $n$-clique exists iff there are $n$ points in general position with all pairwise
  distances integers: such a set extends to an infinite general-position set by adding points off the
  finitely many lines and circles it determines. Problem 213 asks for exactly such sets for every $n$.
  Upstream lists it as open, with $n=7$ the best known construction (Kreisel and Kurz). If such sets
  existed for every $n$, the chromatic number would be infinite at once: place integral sets of every
  size in generic position relative to each other. So the clique half is open and not formalized.
- **Not formalized:** the quantitative "how large" question, since it asks to determine a set of
  values rather than to prove a statement.

## C. Craftsmanship

**C1. Readability: one false docstring claim (fixed).**

- **[defect: misleading-docstring-remark]** The docstring says "Note: The clique number is always
  finite", citing the Anning–Erdős theorem, and then "Hence arbitrarily large finite chromatic number
  (or infinite chromatic number) would be an example of a graph with finite clique number and infinite
  chromatic number."
  - The theorem gives no infinite clique. It does not bound the sizes of finite cliques. A graph with
    cliques of every finite size and none infinite has an infinite supremum of clique sizes.
  - Whether the clique sizes in $G_A$ are bounded for every general-position $A$ is open. By the
    Problem 213 argument in B2, it is equivalent to the failure of Problem 213 for some $n$.
  - The second sentence mixes finite and infinite chromatic number and does not follow.
  - v2 states what the theorem gives (`no_infinite_clique`) and says that the finite cliques are not
    bounded by it.
