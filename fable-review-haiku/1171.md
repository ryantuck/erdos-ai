# Fable Review: Erdős Problem 1171

**Verdict:** NEEDS REVISION
**Confidence:** high — The source problem's yes/no form is clear and the defects are unambiguous. The structured partition relation is standard mathematics.

## Summary

The problem asks: "Is it true that, for all finite k < ω, ω₁² → (ω₁·ω, 3, ..., 3)²_{k+1}?" That is, for every (k+1)-coloring of pairs of ordinals below ω₁², either there is a homogeneous set of order type ω₁·ω for the first color, or there is a monochromatic triple for one of the remaining k colors.

The Lean formalization defines `OrdinalPartitionMulticolor` to capture this partition relation precisely and statements it for ω₁², ω₁·ω, and 3. However, the theorem statement has a critical structural defect: **the universal quantifier over k appears as a binder before the colon** (making it a parameter to the theorem) rather than inside the proposition. Additionally, **the theorem lacks the `answer(sorry) ↔` wrapper** required for yes/no questions per the review checklist. These defects cause the theorem to claim a different proposition than what the source problem asks.

## A. Semantic fidelity

**A1. Statement fidelity — DEFECT (question form encoding; see A4).**

- Back-translation of the current statement (line 41–42): "For a given k, the partition property ω₁² → (ω₁·ω, 3, ..., 3)_{k+1} holds." This asserts the property as true for an arbitrary k, which is not what the source asks.
- The source asks: "Is there a proof that for *all* k, the property holds?" This is a yes/no question about the truth of a universally quantified statement.
- Quantifier structure defect: k is currently a theorem binder (parameter). Per the checklist (Part A4, "binders before the colon"), quantified variables should appear *inside* the proposition after `answer()`, not as theorem binders.
- The intended reading after fixes: ∀ k : ℕ, the partition property — which the source restricts to "finite k < ω" (satisfied since all ℕ count as finite).

**A2. Lean semantics traps — pass.**

Standard approach.
- Ordinal arithmetic: `omega1 ^ 2` (ω₁²), `omega1 * omega0` (ω₁·ω), and `3` (literal 3 in Ordinal) are all standard. Note ω₁·ω < ω₁² as required by the problem (target strictly less than source).
- No ℕ division/subtraction issues arise.
- No off-by-one issues in the existential structure.

**A3. Definitions — pass.**

**A4. Question form and answer polarity — DEFECT (both aspects).**

The source problem is phrased as a yes/no question: "Is it true that...?" 

Per the review checklist (Part A4), yes/no questions require the shape `answer(…) ↔ P` where P is the question as asked. The current theorem lacks this wrapper entirely.

Furthermore, the universal quantifier over k should appear *inside* the proposition (as `∀ k : ℕ, ...`), not as a theorem binder before the colon. The current form with `(k : ℕ)` as a binder is incorrect for `answer()` theorems.

**Correct form:** `theorem erdos_problem_1171 : answer(sorry) ↔ ∀ k : ℕ, OrdinalPartitionMulticolor (omega1 ^ 2) k (omega1 * omega0) 3 := by sorry`

**Current form (defective):** `theorem erdos_problem_1171 (k : ℕ) : OrdinalPartitionMulticolor (omega1 ^ 2) k (omega1 * omega0) 3 := sorry`

The current form claims the property holds for a *particular* k (theorem parameter), whereas the source asks whether it holds for *all* k.
