# Fable Review: Erdős Problem 1176

**Verdict:** NEEDS REVISION

## Summary

The problem asks whether, for a graph with chromatic number ℵ₁, there exists an edge coloring with ℵ₁ colors such that for every countable vertex coloring, some vertex color class contains all edge colors (i.e., every edge color appears on at least one edge with both endpoints in that class). This is an open yes/no question about infinite chromatic numbers and ramsey-theoretic properties. The formalization has three defects: (1) it omits the `answer()` wrapper required for yes/no questions, presenting the statement as a direct assertion instead; (2) the hypothesis ¬G.CardColorable1176 ℵ₀ encodes "chromatic number > ℵ₀" rather than "chromatic number = ℵ₁", generalizing the problem; (3) the citation key [Va99] is used but never defined in the file.

## A. Semantic fidelity

### A1. Statement fidelity — FAIL (wrong question form; chromatic-number condition too weak)

**Back-translation:** The Lean statement, read literally, asserts: "For every graph G and every hypothesis that G is not ℵ₀-colorable, there exists an edge coloring with ℵ₁ colors such that for every countable vertex coloring, there is a vertex color class b such that every edge color appears on at least one edge with both endpoints in b."

**Quantifier structure issue (critical defect):** The problem is phrased as a yes/no question: "Is it true that there is a colouring of the edges...?" Per FABLE_REVIEW.md §A4, yes/no questions must use the shape `answer(B) ↔ P` where `B` is the truth value and `P` is the question as asked. This statement is instead formalized as a bare universal assertion, collapsing the yes/no distinction.

**Chromatic number condition (defect):** The hypothesis ¬G.CardColorable1176 ℵ₀ encodes "the graph is not ℵ₀-colorable", i.e., chromatic number > ℵ₀. But the problem specifies "chromatic number ℵ₁" (equal to ℵ₁, not just > ℵ₀). A graph with chromatic number ℵ₂ would satisfy the hypothesis and be covered by the theorem, but the problem asks specifically about ℵ₁. This is a mathematical generalization of the intended statement.

**Encoding of the main property (pass):** Given the chromatic number issue, the rest of the encoding is sound. The edge coloring EC is quantified with cardinality ℵ₁, and the property — that every edge color appears on at least one edge completely contained in some vertex color class — is correctly formalized as `∀ ec, ∃ e, edgeColor e = ec ∧ (∀ v ∈ e.val, vertexColor v = b)`.

### A2. Lean semantics traps — pass

- No ℕ subtraction.
- No division.
- No Finset.range.
- The inner quantifier `∀ ec : EC` is not vacuous; EC is a non-empty type with #EC = ℵ₁.
- No `StrictMono` or open/closed interval issues.

### A3. Definitions — pass

`SimpleGraph.CardColorable1176 κ` is defined as `∃ (α : Type u), #α ≤ κ ∧ Nonempty (G.Coloring α)`, matching the standard definition of "κ-colorable" (the graph admits a proper coloring using a type of cardinality ≤ κ). The definition includes no `sorry` and degenerate cases (empty graph, single vertex) are handled correctly by the `Nonempty (G.Coloring α)` condition.

### A4. Question form and answer polarity — FAIL

The source problem is phrased as a yes/no question ("Is it true that...?"), so the formalization should use `answer(B) ↔ P` where B is True/False/sorry. Instead, it uses a bare universal assertion, treating the problem as a direct assertion ("Prove that for all graphs with chromatic number ≥ ℵ₁, the property holds") rather than a yes/no proposition ("Is the property true?"). These are different formally, even if they converge in interpretation for open problems.

The docstring correctly attributes the problem to Erdős, Galvin, and Hajnal, with consistency proved by Hajnal and Komjáth. The bare `sorry` does not claim to have solved it.
