## Summary

Problem 1138 asks a yes/no question: given x/2 < y < x and C > 1, is the asymptotic formula π(y + Cd) - π(y) ~ Cd / log y true, where d is the maximal prime gap below x? The source page (accessed 2026-02-23) marks it OPEN; the teorth metadata mirror shows a later update to "disproved (Lean)" as of 2026-05-11. The Lean formalization correctly encodes the asymptotic in ε-N form but violates the checklist's A4 requirement for yes/no questions: it uses a bare existential assertion instead of the corpus-standard `answer(sorry) ↔` wrapper. This is a semantic defect in the *statement form*, not in the mathematical content. The maxPrimeGap definition and all supporting Lean semantics are sound.

## A. Semantic fidelity

- Independent back-translation of lines 35–41: "for given C > 1 and ε > 0, there exists N such that for all x ≥ N, for all y with x/2 < y < x, the absolute value of (π(y+Cd) - π(y)) / (Cd/log y) - 1 is less than ε." This faithfully encodes the asymptotic π(y+Cd) - π(y) ~ Cd / log y (meaning the ratio tends to 1).
- Quantifier structure: universally quantified over C, ε with existential N over x, y — standard asymptotic encoding. ✓
- Types: ℝ for C, ε, the asymptotic ratio; ℕ for x, y, indices — appropriate. Coercions placed correctly. ✓

- Not vacuous: for large x and y in range, maxPrimeGap(x) > 0 and log(y) > 0, so the denominator is nonzero; the asymptotic is a substantive open question. ✓

**A2. Lean semantics traps — pass.**
