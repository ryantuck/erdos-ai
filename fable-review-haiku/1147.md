## Summary

The problem asks: given an irrational α > 0, is the set A(α) = {n ≥ 1 : ‖αn²‖ < 1/log n} (where ‖·‖ is distance to nearest integer) an additive basis of order 2? The problem was disproved by Konieczny in 2016; specifically, for α = √2, the answer is no. The Lean file defines the distance function, the set A(α), and the property IsAdditiveBasisOrder2 correctly. The theorem `erdos_problem_1147 : ¬ IsAdditiveBasisOrder2 (setA (Real.sqrt 2)) := sorry` encodes the correct mathematical content but violates the corpus convention for yes/no questions: it uses a direct assertion rather than the `answer(False) ↔` form required by the checklist.
