## Summary

The problem: for $n$ distinct nodes $x_1, \ldots, x_n \in [-1,1]$, define Lagrange basis polynomials $\ell_k(x) = \prod_{i \ne k} \frac{x - x_i}{x_k - x_i}$ and the Lebesgue function $\lambda(x) = \sum_k |\ell_k(x)|$. **Is it true that** for any fixed subinterval $[a,b] \subseteq [-1,1]$, the maximum $\max_{x \in [a,b]} \lambda(x) > (2/\pi - o(1)) \log n$? (Bernstein and Erdős proved this for the full interval $[-1,1]$ with a Chebyshev-optimal bound.) The problem was **solved affirmatively**. The Lean file correctly formalizes the definitions and the statement; the mathematics are sound. The one defect is formal encoding: the source is a **yes/no question** and should use `answer(True) ↔ P` form per corpus convention (following FABLE_REVIEW.md A4 and exemplar 1005), but the raw file uses a bare direct assertion instead.
