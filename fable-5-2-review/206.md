## Summary

For $x>0$ let $R_n(x)$ be the largest sum of $n$ distinct unit fractions that is $<x$. The page (DISPROVED) asks whether, for
almost all $x$, eventually $R_{n+1}(x)=R_n(x)+1/m$ with $m$ the least new denominator keeping the sum below $x$. Kovač proved
that the set of such $x$ has measure zero.

The Lean defines `unitFracSum`, `bestUnderapprox` (an `sSup`), `IsEventuallyGreedy`, and asserts
`volume {x : ℝ | 0 < x ∧ IsEventuallyGreedy x} = 0`.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Let $x>0$ be a real number. For any $n\geq 1$ let $R_n(x) = \sum_{i=1}^n\frac{1}{m_i}<x$ be the
  maximal sum of $n$ distinct unit fractions which is $<x$. Is it true that, for almost all $x$, for sufficiently large $n$,
  we have $R_{n+1}(x)=R_n(x)+\frac{1}{m}$, where $m$ is minimal such that $m$ does not appear in $R_n(x)$ and the right-hand
  side is $<x$? (That is, are the best underapproximations eventually always constructed in a 'greedy' fashion?)" And: "Kovač
  [Ko24b] has proved that this is false - in fact as false as possible: the set of $x\in (0,\infty)$ for which the best
  underapproximations are eventually 'greedy' has Lebesgue measure zero."
- **Back-translation** (lines 58–60): "The set of $x>0$ for which there is $N_0$ such that for all $n\ge N_0$ every set of $n$
  positive integers whose unit-fraction sum is $<x$ and equals $R_n(x)$ can be enlarged by its least admissible new
  denominator to a set whose sum equals $R_{n+1}(x)$, is Lebesgue-null."
- **Checks.**
  - *The example.* `bestUnderapprox_one_eleven_24`, `bestUnderapprox_two_eleven_24`, `not_greedy_eleven_24` (proved): the
    values are $1/3$ and $9/20$, and $1/3+1/k=9/20$ has no solution ($k=60/7$). The greedy extension of $\{3\}$ is $k=9$, with
    sum $4/9<9/20$.
  - *The supremum is a maximum.* The set is bounded above by $x$ and nonempty for $x>0$ (`bddAbove`, `exists_underapprox`,
    proved). Attainment, by hand: there is no strictly increasing infinite sequence of sums of $n$ unit fractions (induction on
    $n$: the least denominator is at most $n/s_1$, so it is constant along a subsequence; subtract it). A supremum that is not
    attained would give such a sequence.
  - *No vacuity.* For $x>0$ an optimal $n$-set exists for every $n$, so the hypothesis "`unitFracSum S = bestUnderapprox n x`"
    is satisfiable. For $x\le0$ the set under the `sSup` is empty and `IsEventuallyGreedy x` holds vacuously; the theorem's
    guard `0 < x` excludes this.
  - *The question as asked.* `not_ae_of_main` (proved): measure zero implies `¬ ∀ᵐ x > 0, IsEventuallyGreedy x`.
  - *Reading of "eventually greedy".* If $S$ attains $R_n(x)$, $n\ge1$, and $k$ is the least admissible new denominator, then
    $k>\max S$: otherwise replacing $\max S$ by $k$ gives a larger sum, still $<x$. So if $x$ is eventually greedy in the
    input's sense, starting from an optimal $N_0$-set the greedy steps produce optimal sets that are prefixes of one increasing
    sequence. Hence the input's set is contained in the chain set (`IsEventuallyGreedyChain`), and the main theorem follows
    from `variants.kovac_chain`. The converse inclusion can fail only if some $R_n(x)$ has two representations.
