## Summary

The page (DISPROVED) asks whether some $n$ admits residues $a_d$, one for each divisor $d>1$ of $n$, such that the classes
$a_d\pmod d$ cover $\mathbb Z$ and two classes meet only when their moduli are coprime. Adenwalla proved there is no such $n$.

The Lean defines `DisjointDivisorCovering n a` (covering, and "meeting classes have coprime moduli" for $d\ne d'$) and asserts
that for every $n>0$ no `a : ℕ → ℤ` satisfies it.

## A. Semantic fidelity

**A1. Statement fidelity: pass.**

- **Source** (verbatim): "Are there $n$ such that there is a covering system with moduli the divisors of $n$ which is 'as
  disjoint as possible'? That is, for all $d\mid n$ with $d>1$ there is an associated $a_d$ such that every integer is congruent
  to some $a_d\pmod{d}$, and if there is some integer $x$ with $x\equiv a_d\pmod{d}$ and $x\equiv a_{d'}\pmod{d'}$ then
  $(d,d')=1$."
- **Back-translation** (lines 32–35): "For every $n>0$ there is no assignment $d\mapsto a_d$ such that every integer lies in
  some class $a_d \pmod d$ with $d\mid n$, $d>1$, and any two such classes with $d\ne d'$ that share an integer have
  $\gcd(d,d')=1$."
- **Checks.**
  - *$d\ne d'$.* Read literally with $d=d'$ the page's clause would demand $(d,d)=1$; the input's `d ≠ d'` is the only
    sensible reading.
  - *$n=0$.* `Nat.divisors 0 = ∅`, so the covering clause fails (`not_covering_zero`, proved), and the theorem is equivalent
    to the form without `n > 0` (`iff_not_exists`, proved).
  - *Why "as disjoint as possible".* Classes with coprime moduli always meet (Chinese remainder theorem), so the second clause
    demands disjointness exactly where it is possible.
  - *Prime powers.* For $n=p^k$ no covering exists even without the second clause (`not_covering_prime_pow`, proved): lift an
    integer step by step from $p^j$ to $p^{j+1}$; of the $p\ge2$ lifts at most one lies in the class modulo $p^{j+1}$
    (`exists_uncovered`). This covers $n=1$ and the primes (`not_covering_one`, `not_covering_prime`).
  - *Two primes, by hand.* For $n=pq$ the three classes cover a set of density $1/p+1/q-1/(pq)+1/(pq)=1/p+1/q<1$. The general
    case is [Ad25].
